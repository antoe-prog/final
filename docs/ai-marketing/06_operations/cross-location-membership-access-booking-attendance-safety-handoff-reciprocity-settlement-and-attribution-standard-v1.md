- 기준일: 2026-09-18

- 적용 범위: 홈 지점 회원의 타 지점 수업 이용, 일시 방문, 정기 교차 이용, 지점 변경 요청, 사업자 사유 대체수업

- 내부 수치 상태: 데이터 미연결

## 1. 핵심 판단

다지점 운영에서 다음 사건은 서로 같지 않다.

`타 지점 문의 ≠ 이용 자격 확인 ≠ 자리 제안 ≠ 예약 확정 ≠ 체크인 ≠ 실제 수업 참여 ≠ 홈 지점 변경 ≠ 신규회원 ≠ 정산 확정 ≠ 실제 지점 간 이전`

회원이 다른 지점을 방문했다고 해서 신규회원, 복귀회원 또는 지점 이동 회원으로 자동 분류하지 않는다. 타 지점의 체크인이 존재해도 실제 참여와 안전 인계, 회원권 차감, 정산이 모두 완료됐다고 가정하지 않는다.

권장 흐름은 다음과 같다.

`회원권·홈 지점 확인 → 교차 이용 적격성 확인 → 방문 지점·수업·정원 확인 → 회원 선택 → 예약 확정 → 필요한 최소 안전 인계 → 현장 체크인 → 실제 참여 → 회원권 차감 → 예외·사건 종결 → 정산 적격성 확인 → 지점 간 정산 → 유지·재등록 관찰`

## 2. 네 목표와의 연결

| 목표 | 교차 이용의 역할 | 분리해야 할 결과 |
|---|---|---|
| 신규 체험회원 확보 | 친구·가족·지역 이동 문의의 적절한 지점 연결 | 신규 체험과 기존회원 타 지점 이용 |
| 휴면회원 복귀 | 접근 가능한 지점·시간 선택지를 제공 | 복귀 의사·예약·재출석·홈 지점 변경 |
| 기존회원 재등록·만족 | 일정·거리 변화에 유연한 수련 경로 제공 | 편의성·실제 이용·재등록·장기 유지 |
| 매출 증대 | 공용 회원권·지점 간 정산의 정확한 수납 귀속 | 청구·실수납·회원권 차감·정산·순수납 |

교차 이용 횟수 자체를 만족, 재등록 또는 증분 매출로 간주하지 않는다.

## 3. 기존 기준과의 경계

이 문서는 다음 기준을 대체하지 않는다.

- 수업 정원 기준: 안전 정원, 기존회원 보호석, 체험석, 대기명단
- 가격 기준: 공개 가격, 견적, 계약, 청구, 실수납, 환불
- 회원권 기준: 휴회, 만료, 재개, 해지, 재등록
- 문의 기준: 채널 중복 제거, 담당 지점 라우팅, 응답 SLA
- 개인정보 기준: 연락 동의, 보호자 권한, 접근권한, 보존기간
- 수업 변경 기준: 휴강, 코치 변경, 대체수업, 서비스 회복
- 성과 귀속 기준: 신규·복귀·재등록·지점 이동의 구분

이 문서는 홈 지점이 아닌 곳에서 실제 서비스를 이용할 때 발생하는 자격, 예약, 인계, 출석, 회원권 소비, 정산과 성과 연결만 다룬다.

## 6. 이용 적격성 게이트

교차 이용 승인 전에 다음을 확인한다.

1. 활성 회원권과 적용 계약 버전
2. 홈 지점과 계약 책임 주체
3. 이용 가능한 방문 지점·프로그램·연령·레벨
4. 기간제·횟수제·무제한권 등 이용권 유형
5. 교차 이용 횟수·기간·예약 우선순위의 승인 기준
6. 방문 회차의 실제 정원과 기존회원 보호석
7. 담당 코치와 프로그램 적합성
8. 미성년자의 보호자 권한과 연락 주체
9. 필요한 최소 안전 인계와 접근 권한
10. 회원권 차감·취소·노쇼·사업자 취소 규칙
11. 정산 발생 여부와 승인된 산식
12. 분쟁·예외 담당자

하나라도 미확정이면 자동 예약·자동 차감·자동 정산을 하지 않는다.

## 7. 예약·정원·대기명단 원칙

- 교차 이용자는 방문 지점의 실제 수업 회차에 예약한다.
- 반복 시간표와 날짜별 실제 회차를 분리한다.
- 기존회원 보호석, 체험석, 복귀석과 교차 이용석을 구분할 수 있어야 한다.
- 홈 지점의 이용 가능 상태가 방문 지점의 잔여 자리를 보장하지 않는다.
- 자리 제안은 회원 수락 전 예약 확정이 아니다.
- 대기명단 자동 승급은 승인된 확인 방식 없이 사용하지 않는다.
- 방문 지점의 사업자 취소를 회원 노쇼로 처리하지 않는다.
- 취소 자리 복원과 회원권 차감 취소를 각각 확인한다.
- 지점 간 경쟁을 이유로 정원·예약 규칙을 임의로 완화하지 않는다.

## 8. 안전·지도 인계 원칙

- 방문 수업에 필요한 프로그램·레벨·최근 운영상 주의사항만 전달한다.
- 건강·부상·장애 관련 정보는 실제 수업 안전에 필요한 범위와 권한을 확인한다.
- 미성년자의 민감정보를 보호자 권한 없이 지점 간 공유하지 않는다.
- 담당 코치는 수업 전 필요한 정보의 수신 여부를 확인한다.
- 전체 회원 기록이나 상담 원문을 방문 지점에 복제하지 않는다.
- 응급연락, 사고 보고와 서비스 불편 인계를 별도 절차로 관리한다.
- 방문 뒤 발생한 사건은 방문 지점이 사실을 기록하고 홈 지점에 필요한 범위만 인계한다.
- 안전 인계 완료를 의료적 적합성 판단으로 표현하지 않는다.

## 9. 회원 경험·CRM 원칙

- 회원에게 홈 지점과 방문 지점의 역할을 명확히 안내한다.
- 교차 이용 불가 사유를 추정하거나 회원 책임으로 자동 처리하지 않는다.
- 방문 완료 뒤 만족·불편·다음 이용 선택을 확인할 수 있으나 광고성 연락 적격성을 별도로 판정한다.
- 타 지점 방문을 홈 지점 불만이나 이탈 신호로 자동 해석하지 않는다.
- 반복 교차 이용은 지점 변경 의사일 수 있으나 회원의 직접 확인 전에는 이동으로 확정하지 않는다.
- 홈 지점 변경은 계약·결제·회원권·연락 책임의 별도 승인 사건으로 처리한다.
- 복귀회원의 타 지점 첫 출석을 신규회원으로 집계하지 않는다.
- 교차 이용 경험은 재등록에 영향을 줄 수 있지만 인과관계는 확인된 응답·실험 없이는 단정하지 않는다.

## 10. 지점 간 정산 원칙

- 정산 기준은 방문 횟수, 실제 참여, 서비스 유형, 승인 단가, 월 정액 등 하나의 버전으로 고정한다.
- 예약·체크인만으로 정산 적격을 확정하지 않는다.
- 회원 실수납, 방문 지점 제공 서비스와 지점 간 이전을 분리한다.
- 비현금 회원권 차감도 서비스 제공 의무와 정산 원가를 가질 수 있다.
- 환불·차지백·사업자 취소·중복 체크인의 조정 기준을 둔다.
- 정산 예정액, 승인액과 실제 이전액을 분리한다.
- 본사 수수료·로열티·광고 분담금과 교차 이용 정산을 합치지 않는다.
- 지점별 매출 비교는 동일한 정산 버전과 관찰기간일 때만 수행한다.
- 내부 단가·마진·정산액은 공개 저장소와 홍보 콘텐츠에 넣지 않는다.

### 권장 계산 구조

`교차 이용 정산 적격 회차 = 실제 참여 확인 ∩ 회원권 소비 확인 ∩ 중복·취소 제외 ∩ 승인된 정산 버전`

`방문 지점 정산 예정액 = 적격 회차 × 승인 단가 또는 승인된 정액 산식`

`정산 순액 = 승인액 - 실제 조정액`

실제 산식과 금액은 데이터 미연결이며 대표·재무 승인 전 확정하지 않는다.
