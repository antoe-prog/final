# 유도 승급·승단 심사 자격·신청·참가·결과·띠/증서 인도·재등록·매출 귀속 기준 v1

- 문서 상태: 공개 가능한 운영 기준 초안
- 기준일: 2026-09-19
- 적용 범위: 파이널유도멀티짐의 내부 승급, 외부 승단, 기술 진도, 심사 운영, 결과 안내, 만족·재등록 및 매출 측정
- 실제 회원·출석·기술평가·심사·결제 데이터: 데이터 미연결
- 주의: 이 문서는 대한유도회·시도회·주최기관의 최신 승단 자격이나 심사 규정을 대신하지 않는다.

## 1. 오늘의 운영 판단

승급·승단은 한 번의 ‘합격’ 사건이 아니라 다음의 연결 과정이다.

1. 적용 규정과 심사 버전 확인
2. 회원별 기술·기간·출석 등 후보 신호 수집
3. 코치의 사람 검토
4. 심사 대상 안내
5. 회원·보호자의 신청과 동의
6. 참가비 청구와 실정산
7. 실제 심사 참가
8. 공식 결과 수신과 검증
9. 내부 등급 반영
10. 띠·증서·기념품의 실제 인도
11. 결과 후 피드백과 다음 학습 목표
12. 이후 실제 참여·재등록·순수납 관찰

`후보`, `자격 확인`, `초대`, `신청`, `결제`, `참가`, `합격`, `등급 반영`, `인도`, `재등록`을 같은 상태로 처리하지 않는다.

## 2. 내부 승급과 외부 승단 분리

| 구분 | 내부 승급 | 외부 승단 |
|---|---|---|
| 기준 소유자 | 승인된 도장 운영 기준 | 대한유도회·시도회·주최기관 등 공식 기준 |
| 결과 권한 | 도장 내부 승인자 | 해당 심사 주관기관 |
| 효력 범위 | 도장 프로그램·수업 운영 | 공식 단증·등록 체계 |
| 변경 가능성 | 내부 승인으로 버전 관리 | 외부 공고·규정 변경에 따라 갱신 |
| 공개 표현 | 내부 승급임을 명확히 표시 | 공식 확인 전 합격·승단 단정 금지 |

내부 띠 변경을 공식 승단으로 표현하지 않고, 외부 승단 후보 안내를 합격 보장으로 표현하지 않는다.

## 4. 버전과 기준일

모든 심사에는 다음을 고정한다.

- 기준 소유자
- 규정명과 버전
- 확인일
- 효력 시작일과 종료일
- 대상 프로그램·연령·등급
- 최소 기간·출석·기술 등 확인 항목
- 예외와 승인 권한
- 참가비·추가 비용·환불 기준의 승인 버전
- 심사일·장소·접수 마감일
- 결과 통지 책임자

공식 기준이 확인되지 않은 항목은 `확인 필요`로 남기며 과거 기준이나 다른 지점의 관행을 적용하지 않는다.

## 5. 자격 신호와 자격 확정

### 5.1 후보 신호

다음 정보는 사람 검토를 위한 후보 신호일 뿐 자동 자격 확정이 아니다.

- 등록 후 경과 기간
- 출석 횟수 또는 수련일수
- 특정 기술을 다룬 수업 참석
- 기술 연습 횟수·시간
- 코치의 진도 기록
- 현재 띠·급·단
- 이전 심사일과 결과

### 5.2 확정 전 검토

- 출석 누락·중복·대리 체크인 확인
- 수업 참여와 기술 숙련을 구분
- 기술 기록의 작성자·기준·시각 확인
- 부상·건강정보는 필요한 담당자에게만 제한
- 휴회·지점 이동·프로그램 변경 반영
- 공식 규정과 내부 기준의 충돌 확인
- 연령·보호자 동의·신원 요구사항 확인

출석 횟수가 충족됐다는 이유만으로 기술 숙련이나 심사 합격 가능성을 단정하지 않는다.

## 7. 신청·참가·결과 분리

### 신청

신청서 제출이나 참가비 결제만으로 실제 심사 참가를 확정하지 않는다. 신청에는 대상 회차·참여자·동의자·마감·취소 기준을 연결한다.

### 참가

현장 접수와 실제 응시를 구분한다. 체크인만 있고 심사를 완료하지 않은 경우 `EXAM_ATTENDED`로 올리지 않는다.

### 결과

구두 전달, 현장 분위기, 코치의 예상은 공식 결과가 아니다. 승인된 결과 원천과 책임자를 확인한 뒤 `PASSED_VERIFIED`로 변경한다.

### 등급 반영

합격 결과와 회원 프로필 변경을 분리한다. 결과가 확인됐더라도 등급 반영이 실패하거나 지연될 수 있다.

## 8. 기술 진도 기록

기술 진도는 다음을 분리한다.

- 기술을 배운 수업에 참석
- 기술을 연습한 횟수·시간
- 코치 피드백을 받음
- 코치가 숙련을 확인
- 특정 심사 요구사항을 충족

기술 숙련 표시는 작성자·판정일·적용 기준 버전과 함께 저장한다. 자동 체크인으로 기술을 ‘통과’ 처리하지 않는다.

같은 기술명이라도 프로그램·연령·등급에 따라 요구 수준이 다를 수 있으므로 하나의 전역 통과 값을 무조건 재사용하지 않는다.

## 9. 참가비·띠·증서·상품 매출

다음을 별도 거래로 구분한다.

- 심사 참가비
- 협회·주최기관 납부액
- 띠·도복·증서 케이스 등 상품 판매
- 배송·재발급·사진 등 부가 비용
- 면제·할인·장학 처리

### 금지되는 등식

- 청구서 생성 = 실수납
- 결제 승인 = 정산 완료
- 합격 = 띠·증서 인도
- 띠 인도 = 심사비 수납
- 심사비 수납 = 재등록
- 상품 구매 = 회원 유지

순수납은 실정산에서 실제 환불·차지백·취소 정산을 차감한다. 외부기관 전달 금액과 도장 귀속 금액도 구분한다.

## 10. 만족·재등록 귀속

심사 운영은 만족과 재등록에 영향을 줄 수 있지만 인과를 자동 확정하지 않는다.

다음 사건을 분리한다.

- 심사 전 수련 참여 변화
- 심사 신청과 실제 참가
- 결과 후 피드백 완료
- 다음 수업 실제 참여
- 회원권 만료예정 안내
- 재등록 의사
- 재등록 계약 반영
- 재등록 실정산

합격자를 재등록으로 자동 승격하지 않는다. 불합격·보완 대상자를 이탈 위험으로 자동 분류하지 않으며, 결과 후 실제 참여와 성숙한 관찰기간을 확인한다.

- 확정 전 `전원 합격`, `자동 승단`, `몇 개월이면 단증` 표현 금지
- 결과 발표 시 개인정보와 미성년자 공개 동의 확인

### 당근

- 승인되지 않은 심사비·무료 띠·단증 제공 약속 금지
- 특정 기간만 수련하면 자격이 생긴다는 단정 금지

## 13. 콘텐츠 소재 설계

실제 규정·회원 사례 없이도 다음의 일반 교육 콘텐츠는 준비할 수 있다.

- ‘심사 대상’과 ‘심사 합격’이 다른 이유
- 출석 횟수와 기술 숙련이 다른 이유
- 심사 전 확인할 준비물·일정 질문
- 결과를 받은 뒤 다음 수업에서 정할 한 가지 목표
- 띠 색보다 수련 기록을 보는 방법

공식 자격·금액·일정이 필요한 콘텐츠는 대표와 담당기관 확인 전 초안 상태를 넘기지 않는다.

## 14. 역할별 책임

### CMO

- 승급·승단을 단기 매출 행사가 아닌 신뢰·성장 경험으로 관리
- 합격률·매출보다 기준의 일관성과 회원 이해 가능성 우선

### Growth Analyst

- 후보·초대·신청·정산·참가·결과·반영·인도·재등록 퍼널 분리
- 분자·분모·기간·원천이 없는 전환율 계산 금지

### Acquisition Marketer

- 투명한 성장 경로는 설명하되 단기 승급·합격을 모집 약속으로 사용하지 않음
- 신규 체험과 기존회원 승급 데이터를 분리

### CRM Marketer

- 자격 후보와 확정 대상 분리
- 결과별 후속에서 압박·수치심·합격 보장 금지
- 회원·보호자별 연락 권한 확인

### Content Strategist

## 17. 실험 EXP-420

### 가설

자격·신청·정산·참가·결과·등급·인도·재등록을 분리하면 심사 관련 만족·매출·유지 성과의 오분류를 막을 수 있다.

- 진도·출석 사건 4,800건
- 자격 판정·신청 1,440건

- 청구·결제·환불 사건 1,440건

4. [Gymdesk — Digital Point-of-sale](https://docs.gymdesk.com/en/help/docs/pos) — 2026-09-19 확인. 상품 판매, 수동 결제, 청구서 생성과 실제 결제 처리를 구분하는 구조를 확인했다.
