- 적용 범위: 정규수업·체험수업·특강·개인지도 등 예약형 수업

## 1. 오늘의 판단

수업 운영의 우선 과제는 예약 수를 늘리는 것이 아니라 `정원 확정 → 예약 신청 → 예약 확정 → 대기 등록 → 자리 발생 → 승격 통지 → 수락 → 체크인 → 실제 참여 → 취소·노쇼 → 수납·환불`을 분리하는 것이다.

예약 신청·대기 승격·체크인은 실제 수업 참여가 아니다. 정원을 초과해 예약을 받거나, 대기 승격 뒤 응답할 시간을 주지 않고 노쇼로 처리하거나, 체험 자리를 기존회원에게 불투명하게 제한하면 신규 확보와 재등록 만족이 함께 훼손될 수 있다.

현재 지점별 수업 정원, 시간표, 예약·출석·결제 원장이 연결되지 않았으므로 실제 정원 변경, 취소 수수료 부과, 자동 알림, 회원 연락은 실행하지 않는다.

## 2. 공개 자료에서 확인한 변화

1. Gymdesk 공식 문서는 한 수업 안에서도 예약 옵션별 대상·정원·가격·노출 범위를 구분하며, 전체 정원을 하나로 관리하려면 단일 예약 옵션을 쓰도록 안내한다.
2. 정원이 찬 뒤 대기명단을 활성화하면 취소 시 다음 사람을 자동 추가하고 이메일로 알릴 수 있다. 자동 추가는 실제 통지 수신·수락·참여와 구분해야 한다.
3. 예약 설정에는 취소 가능 시점, 환불, 노쇼 세션 차감, 확인·리마인더·노쇼 알림을 각각 다룰 수 있다. 기능이 존재한다는 사실이 파이널유도에서 현재 설정됐다는 뜻은 아니다.

## 3. 운영 원칙

### 3.1 정원은 수업별 승인값

- 정원은 매트 면적, 수업 형식, 연령·숙련도, 지도 인력, 안전 운영을 기준으로 책임자가 승인한다.
- 실제 승인 없이 경쟁 도장·소프트웨어의 정원 숫자를 복사하지 않는다.
- 정규회원·체험·보강·개인지도용 자리를 분리할 경우 각 할당과 해제 시점을 공개 가능한 정책으로 고정한다.
- 여러 예약 옵션이 동일한 물리적 자리를 공유한다면 합산 정원이 초과되지 않도록 단일 좌석 원장을 사용한다.
- 코치의 현장 추가 수용은 예외 승인과 이유를 남기며 상시 정원 확대의 근거로 자동 전환하지 않는다.

### 3.2 대기명단의 공정성

- 기본 순서는 검증된 대기 등록 시각을 사용한다.
- 우선권이 있다면 대상·근거·적용 기간을 사전에 승인한다.
- 직원 임의 끼워넣기, 보이지 않는 지인 우선, 여러 지점 동시 대기 중복 점유를 허용하지 않는다.
- 자리 발생 시 `승격 통지`와 `예약 확정` 사이에 승인된 응답 시간을 둔다.
- 통지 실패·야간 승격·응답시간 부족을 자동 노쇼로 처리하지 않는다.
- 다음 순번 승격 전 이전 후보의 응답 만료·거절·연락 실패를 구분한다.

### 3.3 취소와 노쇼의 분리

- 회원 취소, 도장 취소, 코치 취소, 시스템 오류, 중복 예약 제거, 질병·부상 등 승인 예외를 분리한다.
- `LATE_CANCEL` 기준 시각과 노쇼 판정 시점을 지점·프로그램별로 승인한다.
- 체크인 누락만으로 노쇼를 확정하지 않고 코치의 실제 참여 확인을 대조한다.
- 취소 수수료·횟수 차감·이용 제한은 공개된 조건과 실제 계약을 기준으로 처리한다.
- 미성년자의 경우 보호자 통지 대상과 권한을 별도로 확인한다.

### 3.4 알림과 연락

- 예약 확인, 대기 등록, 승격, 취소, 변경, 리마인더, 노쇼 안내를 서로 다른 알림 유형으로 관리한다.
- 운영 알림과 광고성 재등록·혜택 메시지를 섞지 않는다.
- 수신거부·연락 동의·야간 조건은 기존 연락 억제 원장을 따른다.
- 자동 알림의 발송은 전달·열람·사람 응답으로 계산하지 않는다.

## 5. 좌석 원장과 중복 방지

### 5.1 최소 필드

- `class_id`, `location_id`, 프로그램, 시작·종료 시각
- 승인 정원, 예약 옵션별 할당, 공용 좌석 여부
- 예약 ID, 회원·리드 내부 식별자, 보호자 관계 여부
- 상태 변경 시각, 변경 주체, 근거 시스템
- 대기 순번·승격 통지·응답 기한
- 체크인·실참여·취소·노쇼 검증 시각
- 청구·차감·환불·복구 사건 ID

개인별 원장은 공개 저장소에 저장하지 않는다.

### 5.2 불변식

- 동일 `class_id`의 확정 좌석 수는 승인 정원을 초과하지 않는다.
- 같은 사람은 동일 시간대 중복 수업의 자리를 동시에 점유하지 않는다.
- 취소된 자리는 한 사람에게만 승격 제안한다.
- 승격 제안과 확정 예약은 별도 사건이다.
- 체크인과 실제 참여는 별도 사건이다.
- 수수료 청구와 실수납은 별도 사건이다.
- 환불·차지백·횟수 복구를 순수납과 이용 가능 횟수에 반영한다.

## 6. 신규 체험·기존회원·휴면회원 적용

### 신규 체험

- 체험용 자리 할당이 있다면 수량·해제 시점·예약 조건을 승인한다.
- 체험 신청·예약 확정·실제 방문·실참여·등록을 각각 측정한다.
- 대기 등록만으로 체험 리드나 방문 성과를 만들지 않는다.

### 기존회원·만료예정회원

- 정규회원의 예약 실패·대기 체류·당일 취소·노쇼를 만족·재등록 분석과 연결하되 인과로 단정하지 않는다.
- 반복적으로 자리가 부족한 수업은 정원 확대보다 시간대·지도 인력·프로그램 조정을 우선 검토한다.
- 예약 실패를 회원 탓이나 이탈 의도로 해석하지 않는다.

### 휴면회원

- 복귀 캠페인 전에 참여 가능한 실제 수업과 좌석을 확인한다.
- 자리가 없는 수업을 제안하거나 예약 미확정 상태를 복귀 성과로 집계하지 않는다.
- 연락 동의·수신거부·빈도 상한을 기존 CRM 기준에 따른다.
