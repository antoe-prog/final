# Green Dojo형 환경 실천의 주장·증거·회원참여·지역 마케팅 파일럿 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-26
- 적용 범위: 파이널유도멀티짐의 검토 단계
- 실험 ID: EXP-454
- 현재 내부 상태: `NOT_EVALUATED`
- 주의: 파이널유도멀티짐이 IJF Green Dojo 인증을 받았거나 아래 활동을 시행 중이라는 뜻이 아니다.

## 1. 오늘의 판단

환경 메시지를 곧바로 홍보 문구로 쓰지 않는다. 먼저 한 지점에서 시설·행동의 기준선을 확인하고, 실제 실행 증거와 회원 참여를 축적한 뒤에만 공개한다.

우선순위는 다음과 같다.

1. 사실 확인
2. 낭비 감소 행동의 운영 가능성 확인
3. 회원·보호자에게 부담을 전가하지 않는 참여 설계
4. 실행 증거 확보
5. 지역 채널 공개
6. 신규·복귀·재등록·실수납과의 별도 대조

인증·친환경·탄소절감 같은 표현은 각각 별도의 증거가 필요하다.

## 2. 발견한 공개 사례

IJF는 2026년 9월 25일 아르헨티나 Club Náutico Hacoaj가 팬아메리카 최초 IJF Green Dojo로 인정된 사례를 공개했다.

공개 사례의 실행 축은 다음 세 가지였다.

- 에너지 효율
- 폐기물 감소
- 물 절약

기사에는 조명·장비 끄기 절차, 자연광 우선, 냉방 운영 기준, 절수 설비, 분리배출, 다회용 물병, 대회 후 주변 쓰레기 수거, 교육과 승급 과정의 연계가 소개됐다.

이 사례는 해외 단일 클럽의 인증 사례다. 파이널유도의 비용 절감, 회원 만족, 신규 유입 또는 재등록 효과를 증명하지 않는다.

## 3. 주장 상태

| 상태 | 의미 | 공개 가능 표현 |
|---|---|---|
| `NOT_EVALUATED` | 시설·운영·인증 모두 미확인 | 검토 중이라는 내부 표기만 가능 |
| `BASELINE_VERIFIED` | 지점·기간·측정법이 확인됨 | 현재 상태와 개선 목표를 사실 그대로 설명 |
| `ACTION_LIVE` | 승인된 행동이 실제 운영 중 | 행동·시작일·적용 지점만 공개 |
| `EVIDENCE_ACCUMULATING` | 전후 데이터와 실행 증거가 축적 중 | 수치의 기간·단위·출처를 함께 공개 |
| `THIRD_PARTY_RECOGNISED` | 외부 기관의 유효한 인정이 검증됨 | 기관명·등급·유효기간·확인 링크와 함께 공개 |

`Green Dojo`, `IJF 인증`, `친환경 도장`, `탄소 중립`, `환경에 좋은 도장`은 근거 없이 사용하지 않는다.

## 4. 실행 전 사실 확인

한 지점 단위로 아래 항목을 확인한다.

### 시설

- 조명 종류와 구역
- 냉난방 장비와 설정 권한
- 샤워·세면·화장실 수전 종류
- 정수기 또는 음수대 존재 여부
- 분리배출 가능 품목과 건물 수거 체계
- 임대인·건물 관리자의 변경 승인 필요 여부
- 소방·환기·위생·안전 기준

### 운영

- 개관·마감 책임자
- 조명·장비·냉난방 점검 절차
- 청소와 폐기물 반출 방식
- 대회·외부행사 이동 시 쓰레기 관리
- 회원 안내 책임자
- 기록 주기와 보관 위치

### 증거

- 계량기 또는 고지서의 측정 범위
- 지점 전용값인지 공용부 포함값인지
- 측정 시작일과 비교기간
- 사진 촬영 위치·시각·담당자
- 외부 인증의 발급기관·등급·유효기간

## 6. 네 목표와의 연결

### 신규 체험

환경 행동을 체험 혜택이나 무료 제공으로 포장하지 않는다. 지역 프로필에서 시설 운영의 실제 변화가 확인된 뒤, 문의 출처와 체험 실제 참석을 분리해 기록한다.

### 휴면회원 복귀

복귀 메시지는 승인된 수신 대상에게만 발송한다. 환경 캠페인 참여와 수업 복귀를 같은 사건으로 계산하지 않는다.

### 기존회원 만족·재등록

참여 의향, 불편 신고, 수업 만족, 재등록 실수납을 분리한다. 회원에게 청소·분리배출 의무를 일방적으로 전가하지 않는다.

### 매출

전기·수도 비용 변화와 회원 매출 변화를 분리한다. 절감액은 같은 지점·같은 계절·같은 운영시간 등 비교 가능성이 확인될 때만 계산한다.

## 7. 채널별 공개 기준

### 네이버·Google 지역 프로필

브랜드·지점 공식 운영 주체가 승인한 사실만 게시한다.

필수 요소:

- 적용 지점
- 시작일
- 실제 행동
- 이용자에게 필요한 안내
- 측정 또는 확인 방법
- 문의 목적지

인증을 받지 않았다면 인증 마크·기관명·등급을 사용하지 않는다.

### 당근

지역 주민에게 직접 영향을 주는 행동만 짧게 안내한다. 분리배출 참여나 다회용 물병 권장처럼 이용자가 준비할 사항은 선택사항과 예외를 명확히 쓴다.

### Instagram `@ant.toe.98`

이 계정은 코치 개인 계정이다. 시설 정책의 공식 발표 주체로 사용하지 않는다.

적합한 소재는 실제로 확인된 코치의 작은 실천이나 수련 후 정리 습관이다. 코치의 경험·발언·당일 행동은 자료가 있을 때만 1인칭으로 쓴다.

현재 승인 대기 적체가 있으므로 이 주제의 새 게시 패키지는 만들지 않는다. 실제 행동과 촬영 근거가 생겨도 별도 완성본 승인 전 업로드·예약·발행하지 않는다.

## 8. 파일럿 설계

### EXP-454 — 한 지점 환경 행동·증거·전환 분리 검증

1. 대표가 지점 하나와 행동 하나를 승인한다.
2. 최소 4주 기준선을 수집한다.
3. 비용·시설 변경이 없는 행동부터 시작한다.
4. 실행일·담당자·예외 상황을 기록한다.
5. 최소 4주 운영 후 같은 단위로 비교한다.
6. 채널 반응과 문의·체험·복귀·재등록·실수납을 별도 원장에서 대조한다.

### 성공 기준

다음 운영 품질 조건을 모두 충족해야 한다.

- 승인 없는 비용·시설·계정 변경 0건
- 확인되지 않은 인증·절감·효과 주장 0건
- 공용 계량의 지점 단독 귀속 0건
- 데이터 없음의 0 변환 0건
- 참여를 문의·체험·등록으로 승격한 사례 0건
- 개인정보 공개 0건
- 측정 이벤트 연결률 95% 이상

사업 성과 기준은 기준선·비교기간·최소 표본·목표 차이를 대표가 승인한 뒤 확정한다. 기준선이 없으면 전환율·절감률·ROI를 만들지 않는다.

### 중단 기준

- 안전·위생·환기 기준과 충돌
- 임대인 또는 건물 관리 승인 필요성이 뒤늦게 확인됨
- 측정 범위를 분리할 수 없음
- 회원·보호자에게 과도한 부담 또는 불편 발생
- 인증·친환경 표현이 실제 상태보다 앞서감
- 비용 대비 운영 책임자를 지정할 수 없음

## 10. 감사 규칙

- 해외 인증 사례를 국내 수요·매출 효과로 확대하지 않는다.
- 한 지점의 행동을 8개 지점 전체 운영으로 표현하지 않는다.
- 인증 신청과 인증 취득을 구분한다.
- 절감 행동과 실제 절감량을 구분한다.
- 캠페인 참여와 회원 전환을 구분한다.
- 공개 사진에 회원·보호자 식별정보가 포함되지 않도록 한다.
- 미확정 FINAL ROAD, 내부 예산·손익, 승인 대기 Instagram 미디어·캡션은 공개하지 않는다.
