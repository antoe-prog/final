# 수업시간·운영일 확대 수요·정원·비용·유지율 검증 기준 v1

- 실험 ID: EXP-461
- 작성일: 2026-09-29
- 대상: 파이널유도멀티짐 지점별 운영 검토
- 상태: 대표 승인 전 설계안
- 목적: 신규 체험, 휴면 복귀, 기존회원 만족·재등록, 매출을 함께 보면서 수업시간 또는 운영일 확대 여부를 판단한다.

## 오늘 확인한 외부 사례

연합뉴스는 2026-09-29 서울 중구가 2026-10-01부터 7개 구립 체육시설의 정기 휴관일을 월 2회에서 월 1회로 줄이고, 충무스포츠센터와 회현체육센터의 일요일 개관 시간을 오전 9시 30분에서 오전 9시로 앞당긴다고 보도했다. 기사에는 전체 등록의 약 78%가 두 센터에 집중됐다는 설명도 포함됐다.

이 사례는 공공체육시설의 운영시간 확대 사례일 뿐, 파이널유도멀티짐의 수요나 수익성을 증명하지 않는다. 따라서 동일 조치를 복제하지 않고 지점·시간대별 실제 요청량, 정원, 인력, 안전, 비용, 유지율을 먼저 검증한다.

## 우선 판단

운영시간 확대는 “문의가 많다”는 인상만으로 결정하지 않는다. 한 지점의 한 후보 시간대를 대상으로 수요 신호와 운영 여력을 연결한 뒤 승인 여부를 판단한다.

1. 신규 체험: 기존 시간표 때문에 체험하지 못한 문의 건수
2. 휴면 복귀: 후보 시간대가 열리면 복귀 의향이 있는 휴면회원 수
3. 기존회원: 혼잡도, 대기 명단, 시간대 만족도, 재등록률 변화
4. 매출: 추가 수납액에서 코치·보조 인력·청소·공과금·환불을 뺀 증분 기여이익

## 비공개로 연결할 데이터

개인 식별정보를 제외하고 아래 항목을 지점·주차·후보 시간대 단위로 집계한다.

- 지점, 집계기간, 후보 요일·시간
- 해당 시간대를 요청한 신규 문의 수
- 체험 예약, 실제 방문, 신규 등록
- 휴면 대상 수, 복귀 제안 대상 수, 복귀 의향, 실제 복귀
- 기존 정원, 실제 출석, 대기 인원, 취소·노쇼
- 만족 응답, 만료예정, 재등록
- 코치·보조 인력 시간과 비용
- 청소·공과금 등 추가 비용
- 추가 수납액, 환불액, 순수납액

현재 위 내부 값은 모두 **데이터 미연결**이다. 회원·보호자 연락처, 개인별 출석·건강·결제 원장은 공개 저장소에 기록하지 않는다.

## 파일럿 설계

- 범위: 대표가 승인한 1개 지점·1개 후보 시간대
- 기간: 기준선 기간과 파일럿 기간을 동일한 길이로 설정
- 유입 표식: 네이버, 인스타그램, 당근, 현장 문의에 동일한 후보 시간대 코드를 부여
- CRM 분리: 신규 체험, 체험후미등록, 휴면, 만료예정, 기존회원의 반응을 각각 기록
- 비교: 같은 지점·같은 요일·같은 시간대의 기준선과 비교
- 공개 문구: 시간표·가격·체험 혜택이 실제 확정되기 전에는 게시하지 않음

## 승인 조건

다음 조건을 모두 충족할 때만 파일럿 개시를 검토한다.

- 필수 이벤트 필드 완성률 95% 이상
- 지점·시간대·유입경로 연결 가능
- 코치 배치와 시설 정원·안전 기준 100% 충족
- 추가 비용과 실제 수납·환불을 같은 기간으로 계산 가능
- 증분 기여이익이 음수가 아니며 재등록·만족·수업 품질이 악화되지 않음

구체적 매출·전환·재등록 목표치는 기준선 데이터가 연결된 후 대표가 확정한다. 현재는 수치 목표를 임의로 만들지 않는다.

## 중단 조건

아래 중 하나가 발생하면 확대하지 않고 원인을 검토한다.

- 후보 시간대 수요가 적거나 출처를 확인할 수 없음
- 필수 이벤트 연결률이 95% 미만
- 안전 인력 또는 시설 정원을 충족하지 못함
- 비용·수납·환불 자료가 빠져 기여이익 계산 불가
- 취소·노쇼가 증가하거나 기존회원 만족·재등록이 의미 있게 악화
- 지점 운영 방식과 맞지 않아 수업 품질 유지가 어려움

## 채널별 실행안

- 네이버: 승인 후에만 실제 운영 시간과 예약 가능 여부를 정확히 갱신
- 인스타그램: @ant.toe.98의 승인 대기 콘텐츠와 분리하며, 확정 전 시간표나 혜택을 게시하지 않음
- 당근: 지점 반경 수요 확인용 문구를 준비하되 대표 승인 전 게시·광고 집행하지 않음
- CRM: 휴면·체험후미등록·만료예정·기존회원에게 실제 메시지를 보내기 전 대상 기준과 문구를 승인받음

## 감사 체크

- 외부 공공시설 사례를 내부 수요 증거로 과장하지 않았는가
- 가격, 시간표, 무료 체험, 혜택을 확인 없이 만들지 않았는가
- 개인정보나 민감 경영자료를 공개 문서에 포함하지 않았는가
- 지표의 분자·분모·기간·출처를 기록했는가
- 광고 집행·고객 발송·계정 변경을 승인 없이 실행하지 않았는가
