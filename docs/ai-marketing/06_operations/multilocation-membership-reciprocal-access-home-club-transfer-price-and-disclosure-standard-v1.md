# 다지점 회원권·상호 이용·소속 이전·요금 변경 공개 기준 v1

- 문서 상태: 공개 운영 기준
- 작성일: 2026-09-26
- 적용 대상: 파이널유도멀티짐의 다지점 이용권, 교차 지점 수련, 소속 지점 변경, 지점별 가격·혜택 안내
- 적용 채널: 웹사이트, 앱, 네이버 플레이스·블로그, 당근, Instagram, 상담 스크립트, 약관·결제 화면
- 실험 ID: EXP-455

## 1. 목적

다지점 체육시설에서 “모든 지점 이용 가능”, “어느 지점에서나 자유롭게” 같은 문구는 강한 획득 메시지가 될 수 있다. 그러나 실제 이용 횟수, 소속 지점, 예약 우선권, 수업 종류, 추가 비용, 회원권 이전 조건이 다르면 소비자가 핵심 조건을 잘못 이해할 수 있다.

이 기준은 신규 체험회원 확보, 휴면회원 복귀, 기존회원 만족·재등록, 실수납·순수납 증대의 네 목표를 함께 관리한다. 광고 노출·클릭·문의와 실제 방문·등록·재등록·수납은 서로 다른 사건으로 기록한다.

## 2. 외부 사례와 적용 한계

2026-09-18 보도된 호주 NSW Civil and Administrative Tribunal 사례에서는 “다른 지점 이용 가능”이 주요 판매 포인트였지만, 주 이용 지점이 바뀌면 회원권 이전과 더 높은 요금이 발생할 수 있다는 점이 충분히 공개되지 않은 것이 문제로 지적됐다.

이 사례는 호주 특정 사건이다.

- 대한민국 법률의 직접 적용 사례가 아니다.
- 파이널유도멀티짐의 현재 약관·상품·지점 운영이 동일하다는 의미가 아니다.
- 해외 판정만으로 국내 위법 여부를 단정하지 않는다.
- 실제 공개 전 국내 약관·표시광고·체육시설 관련 검토가 별도로 필요하다.

운영상 핵심 교훈은 “혜택 문구보다 결과를 바꿀 조건을 먼저 명확히 공개한다”는 것이다.

## 3. 금지되는 단정

다음 문구는 근거와 조건이 확정되지 않으면 사용하지 않는다.

- 전 지점 무제한 이용
- 어디서나 동일한 수업
- 어느 지점에서든 같은 가격
- 추가 비용 없음
- 자동으로 자유롭게 지점 이동
- 모든 시간대 예약 가능
- 지점 변경 시 불이익 없음
- 회원권 하나로 모든 프로그램 이용
- 8개 지점 자유 이용
- 평생 동일 요금

FINAL ROAD 추진안의 8개 지점 순회·미션·스탬프는 승인·개최·참여 지점·비용·보상이 확인되지 않았으므로 모집 문구나 회원권 혜택으로 사용하지 않는다.

한 항목이라도 미확정이면 광고 문구보다 먼저 운영 결정을 완료한다.

## 5. 주장 상태

각 지점·상품·채널별 상태를 기록한다.

1. NOT_DEFINED: 상품·조건 미정
2. INTERNAL_DRAFT: 내부 초안만 존재
3. OPERATIONS_VERIFIED: 지점·시간·예약·가격·책임자 확인
4. TERMS_REVIEWED: 약관·결제·환불·동의 절차 검토
5. PUBLICATION_APPROVED: 대표가 정확한 문구와 적용 범위 승인
6. LIVE_VERIFIED: 실제 채널 공개본과 결제·운영 화면 일치 확인
7. SUSPENDED: 조건 불일치·오안내·운영 장애로 공개 중단

PUBLICATION_APPROVED 전에는 광고 집행, 고객 메시지 발송, 앱·웹·계정 변경을 하지 않는다.

## 9. KPI 정의

다음 지표는 분자·분모·기간·출처를 함께 표시한다.

- 상세 조건 조회율 = 상세 조건 조회 고유 사용자 / 다지점 안내 노출 고유 사용자
- 문의율 = 유효 문의 / 다지점 안내 노출 고유 사용자
- 체험 예약률 = 체험 예약 / 유효 문의
- 실제 방문률 = 실제 방문 / 체험 예약
- 신규 등록률 = 신규 등록 / 실제 방문
- 휴면 복귀율 = 복귀한 휴면회원 / 연락 동의가 있는 휴면회원
- 재등록률 = 재등록 / 기간 내 만료 대상
- 교차 지점 이용률 = 교차 지점 이용 회원 / 적용 회원
- 소속 변경률 = 소속 변경 회원 / 교차 지점 이용 회원
- 가격 변경 이탈률 = 가격 변경 후 해지 / 가격 변경 대상
- 순수납 = 실수납 - 환불
- 증분 순수납 = 실험군 순수납 - 비교기준 순수납

분모가 0이거나 원장이 연결되지 않으면 데이터 미연결·계산 불가로 남긴다. 플랫폼 조회·도달·클릭·좋아요·저장은 문의·방문·등록·재등록·매출이 아니다.

## 10. EXP-455 — 다지점 혜택 조건 이해·전환·불만 분리 검증

### 가설

핵심 제한을 결제 전에 명확히 공개하면 단기 문의량은 줄 수 있지만, 잘못된 기대에서 발생하는 취소·환불·불만·이탈을 줄이고 실제 적합 고객의 방문·등록·재등록 품질을 높일 수 있다.

### 사전 조건

- 한 지점 또는 합성 데이터로 제한
- 적용 상품·지점·시간·예약·가격·환불 조건 확정
- 대표 승인
- 법률 자문이 필요한 표현은 별도 검토
- 광고비·할인·시스템 변경은 별도 승인
- 개인정보 공개 0건

### 비교안

- A안: 혜택과 제한을 같은 화면에서 요약
- B안: 혜택 요약 후 상세 조건 링크 제공

두 안 모두 중요한 조건을 숨기지 않는다. 기만적 축약을 실험 변수로 사용하지 않는다.

### 성공 기준

최소 표본과 관찰기간은 내부 기준선 확인 후 승인한다. 운영 정확도 기준은 즉시 적용한다.

- 잘못된 지점·가격·수업 안내 0건
- 승인 없는 상품·가격·계정 변경 0건
- 동의 없는 소속 지점 변경 0건
- 플랫폼 반응의 실제 전환 오분류 0건
- 지점·채널 중복 귀속 0건
- 개인정보 공개 0건
- 이벤트 연결률 95% 이상

### 중단 기준

- 실제 약관과 공개 문구 불일치
- 가격 또는 소속 변경 사전 안내 누락
- 지점별 운영자가 조건을 동일하게 설명하지 못함
- 예약·출석·수납 원장 연결 불가
- 해지·환불·불만 급증
- 안전·수업 품질·정원 운영과 충돌

## 11. 역할별 책임

- CMO: 신규 문의량보다 약속의 정확성, 실제 방문, 재등록, 순수납을 우선한다.
- Growth Analyst: 채널→문의→예약→방문→등록→교차 이용→소속 변경→재등록→실수납을 연결한다.
- Acquisition Marketer: “전 지점” 같은 넓은 문구 대신 확인된 지점·대상·수업을 구체적으로 제시한다.
- CRM Marketer: 회원 상태별로 다른 조건을 안내하고, 실제 메시지 발송 전 승인과 수신 동의를 확인한다.
- Content Strategist: 채널별 발표 주체와 정보량을 맞추되 중요한 제한을 생략하지 않는다.
- Experiment Manager: 문의 증가만으로 성공을 선언하지 않고 취소·환불·불만·재등록·순수납을 함께 본다.
- Auditor: 공개 문구, 약관, 결제 화면, 상담 스크립트, 실제 운영이 일치하는지 확인한다.
