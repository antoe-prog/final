# 체험 신청·참여동의·보호자 권한·전자서명·비상연락·체크인 완결성 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-18
- 적용 조직: 파이널유도멀티짐
- 적용 범위: 온라인·현장 체험 신청, 참여동의, 보호자 권한, 전자서명, 안전 확인, 비상연락, 체크인, 출석·전환 귀속
- 공개 제외: 신청자·회원·보호자 식별정보, 연락처, 생년월일, 건강·부상 내용, 서명 원본, 접속기록, 개인별 출석·결제 원장, 내부 가격·손익
- 내부 신청·동의·출석·전환 데이터: **데이터 미연결**
- 법률 주의: 이 문서는 운영 통제안이며 개별 동의서·면책문구·보유기간의 법적 적정성을 확정하는 법률 자문이 아니다.

## 1. 핵심 판단

체험 전환의 목표는 신청서를 많이 여는 것이 아니라 **필요한 정보를 최소한으로 받고, 올바른 주체가 현재 버전에 동의하고, 현장에서 안전하게 확인한 뒤, 실제 참여 결과를 정확히 기록하는 것**이다.

다음 사건을 하나로 합치지 않는다.

`링크 열람 → 입력 시작 → 제출 → 동의 항목 선택 → 전자서명 → 서명 검증 → 보호자 권한 확인 → 운영 검토 → 예약 확정 → 현장 체크인 → 실제 참여 → 등록 → 실수납`

- 신청서 열람은 제출이 아니다.
- 체크박스 선택은 서명 검증이 아니다.
- 전자서명 완료는 보호자 권한 확인이 아니다.
- 동의 완료는 예약 확정이 아니다.
- 체크인은 실제 수업 참여가 아니다.
- 실제 참여는 등록·결제 완료가 아니다.

서명 완료 수를 체험 참석이나 신규회원으로 계산하면 전환율과 안전 준비 상태가 동시에 왜곡된다.

## 2. 기존 기준과 경계

이 문서는 다음 기존 문서를 대체하지 않는다.

- 회원·미성년자 촬영물 동의 기준: 촬영·공개·재사용·철회
- 가족·가구·보호자·결제자 기준: 사람·가구·권한·결제 역할
- 체험 참석 준비·노쇼·재예약 기준: 예약 확정 이후 참석 결과
- 수업 정원·대기명단 기준: 좌석 배정과 기존회원 보호
- 체험 후 미등록 기준: 참석 이후 등록·실수납
- 건강·부상·복귀 안전 기준: 개인 건강 판단과 수련 복귀

이번 문서는 그 사이의 공백만 다룬다.

1. 신청서가 실제로 완성됐는지
2. 어떤 버전의 어떤 목적에 누가 동의했는지
3. 미성년자의 보호자 권한이 확인됐는지
4. 필요한 안전정보가 최소한으로 수집·검토됐는지
5. 현장 체크인 전에 미완료 항목이 남았는지
6. 서명·체크인 사건이 퍼널에 중복 집계되지 않는지

## 3. 역할을 분리한다

| 역할 | 정의 | 자동 해석 금지 |
|---|---|---|
| PARTICIPANT | 실제 체험 수련자 | 신청서 작성자 |
| APPLICANT | 신청 정보를 입력한 사람 | 참가자·보호자 |
| SIGNER | 특정 문서에 전자서명한 사람 | 법정대리인 |

| EMERGENCY_CONTACT | 긴급 상황 연락 대상으로 지정된 사람 | 보호자·마케팅 수신자 |
| REVIEWER | 신청·동의 완결성을 확인하는 승인된 담당자 | 지도자·법무책임자 |
| CHECKIN_OPERATOR | 현장 도착·체크인을 기록하는 담당자 | 건강정보 전체 열람자 |

한 사람이 여러 역할을 가질 수 있지만 역할별 근거와 유효범위를 별도로 기록한다.

## 4. 동의 목적을 묶지 않는다

다음 항목은 화면과 원장에서 분리한다.

1. 체험 신청 처리에 필요한 개인정보
2. 수업 운영과 안전 확인에 필요한 정보
3. 참여 조건·주의사항 확인
4. 비상 연락
5. 결제·취소·환불 관련 동의가 필요한 경우의 별도 항목
6. 광고성 정보 수신
7. 사진·영상 촬영
8. 공개 게시·광고·재사용

운영에 필요한 필수 항목과 선택 항목을 구분한다.

- 광고성 정보 수신 거부를 이유로 체험 신청을 거절하지 않는다.
- 촬영·공개 거부를 이유로 체험 참여를 거절하지 않는다.
- 코치 개인 Instagram 계정 공개 동의를 도장 공식 계정·네이버·당근·광고 동의로 확장하지 않는다.
- 신청서 제출을 후기 작성이나 촬영 동의로 해석하지 않는다.
- 한 번의 포괄 체크박스로 목적·채널·기간이 다른 동의를 받지 않는다.

### 5.1 예약 전 최소 필드

운영상 필요한 범위에서만 수집한다.

- 비공개 참가자 식별자
- 성인·미성년 구분에 필요한 최소 상태
- 희망 지점·수업·일정
- 승인된 운영 연락 경로
- 필요한 경우 보호자 연결 상태
- 동의 문서 버전
- 신청 상태
- 중복 확인 키
- 생성·갱신 시각

### 5.2 별도 보호가 필요한 정보

다음 정보는 일반 마케팅 CRM 메모나 공개 저장소에 복사하지 않는다.

- 건강상태, 병력, 부상, 장애 관련 상세정보
- 응급처치·복약 관련 상세정보

- 비상연락처
- 접속기록·기기정보
- 개인별 출석·결제·상담 원문

필요성·접근권한·보유기간·파기 절차가 확정되지 않은 민감정보 필드는 만들지 않는다.

### 5.3 현장 노출 최소화

체크인 화면에는 업무에 필요한 상태만 표시한다.

- `READY`: 필수 절차 확인 완료
- `ACTION_REQUIRED`: 현장 확인 필요
- `HUMAN_REVIEW`: 승인된 책임자 검토 필요
- `NOT_ELIGIBLE_YET`: 현재 참여 조건 미충족
- `UNKNOWN`: 원천 확인 불가

프런트 화면에 건강·부상 상세 내용이나 보호자 증빙 원본을 기본 노출하지 않는다.

## 7. 전자서명 증거

전자서명은 전자적 형태라는 이유만으로 효력이 부인되지는 않지만, 어떤 문서에 누가 어떤 방식으로 서명했는지와 당사자 약정·다른 법령 요건은 별도 검토 대상이다.

비공개 원장에는 최소한 다음을 연결한다.

- `document_id`
- `document_version`
- 제시한 전문의 해시
- 목적·지점·프로그램·유효기간
- signer의 비공개 식별자와 역할
- 서명 요청·제시·입력·검증 시각
- 사용한 전자서명 방식
- 동의 선택값
- 검증 상태와 검토자
- 철회·대체·만료 상태
- 원본 증거의 승인된 보관 위치

서명 이미지 하나만 따로 저장해 여러 문서에 재사용하지 않는다.

문서가 바뀌면 과거 동의 기록을 덮어쓰지 않는다. 실질적 변경의 재동의 필요 여부는 승인된 법무·운영 기준으로 판단한다.

## 8. 미성년자와 보호자 권한

- 미성년 참가자 본인의 서명을 법정대리인 서명으로 바꾸지 않는다.
- 신청자가 보호자라고 입력한 사실만으로 권한을 확정하지 않는다.
- 한 자녀에 대한 권한을 형제자매에게 자동 적용하지 않는다.
- 결제자·비상연락처·운영 연락 수신자를 보호자로 자동 승격하지 않는다.
- 권한 범위와 유효기간을 기록한다.
- 복수 보호자 요청이 충돌하면 현장 직원이 임의 결정하지 않고 지정 책임자에게 인계한다.
- 만 14세 미만 아동 개인정보 동의가 필요한 처리에는 최신 법령과 내부 법무기준에 맞는 법정대리인 동의·확인 절차를 적용한다.
- 긴급 상황 대응과 일반 마케팅을 같은 권한으로 처리하지 않는다.

## 9. 비상연락과 안전 확인

비상연락처는 긴급 대응 목적에 한정한다.

- 광고성 메시지 발송 대상에 자동 추가하지 않는다.
- 비상연락처의 체험·회원 전환을 만들지 않는다.
- 참가자와 동일한 전화번호라는 이유로 사람 레코드를 병합하지 않는다.
- 연락 실패·변경·철회 이력을 보존한다.
- 공개 문서·URL·UTM·분석 로그에 넣지 않는다.

건강·부상 질문은 진단이나 참여 적합성 판정을 자동화하지 않는다.

- 위험 신호는 승인된 책임자에게 인계한다.
- 마케팅 담당자가 의료적 결론을 내리지 않는다.
- 건강정보 미제공을 임의로 ‘문제 없음’으로 채우지 않는다.
- 수집한 세부정보를 콘텐츠 주제·후기·세분화 광고에 재사용하지 않는다.
- 실제 참여 여부는 현장 안전 판단과 별도 출석 원천으로 확정한다.

## 10. 체크인 완결성 게이트

현장 체크인 전 다음 항목을 확인한다.

1. 올바른 참가자와 올바른 수업인지
2. 예약이 실제로 확정됐는지
3. 취소·휴강·지점 변경이 없는지
4. 현재 문서 버전의 필수 절차가 완료됐는지
5. 미성년자에게 필요한 보호자 권한이 확인됐는지
6. 사람 검토가 필요한 안전 플래그가 처리됐는지
7. 중복 체크인이 아닌지
8. 좌석·정원 기준을 위반하지 않는지

`PRECHECK_READY`가 없다고 자동으로 거절하지도, 무시하고 참여시키지도 않는다. 현장 예외 절차와 책임자가 있어야 한다.

오프라인·현장 작성이 필요하면 다음을 보존한다.

- 제시한 문서 버전
- 실제 작성·서명 시각
- 확인자
- 원본 보관 위치
- 후속 전산 입력 시각
- 원본과 전산 기록의 관계

나중에 전산 입력했다는 이유로 작성 시각을 덮어쓰지 않는다.

## 11. 다지점 운영

- 동의의 지점·프로그램·활동 범위를 명시한다.
- 한 지점의 신청을 모든 지점·모든 프로그램의 동의로 확장하지 않는다.
- 홈 지점과 방문 지점을 분리한다.
