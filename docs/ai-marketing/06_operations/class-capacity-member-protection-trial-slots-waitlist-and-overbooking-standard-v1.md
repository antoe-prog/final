# 수업 정원·기존회원 보호·체험석·대기자·초과예약 기준 v1

- 적용 조직: 파이널유도멀티짐 공개 마케팅·운영 실무
- 작성일: 2026-09-17
- 문서 상태: 공개 가능한 운영 기준
- 적용 범위: 일반 수업, 신규 체험, 휴면 복귀, 재등록 상담 방문과 다지점 예약
- 공개 제외: 회원·보호자 식별정보, 연락처, 건강정보, 개인별 예약·출석·계약·결제 기록, 내부 가격·원가·손익, 비밀키
- 내부 성과 상태: 데이터 미연결

## 1. 핵심 판단

예약이 가득 찼거나 대기자가 있다는 사실만으로 추가 매출 기회가 확정된 것은 아니다. 다음 사건을 분리해야 한다.

`안전 정원 승인 → 판매·예약 가능 정원 → 기존회원 보호석 → 체험 가능석 → 예약 확정 → 대기 등록 → 빈자리 발생 → 자리 제안 → 수락 → 예약 승격 → 체크인 → 실제 참여`

대기자 수는 특정 지점·요일·시간·수업에 대한 미충족 수요 신호다. 다른 시간대나 다른 지점의 수요로 자동 확대하지 않는다. 초과예약은 안전·지도 품질·기존회원 경험을 해칠 수 있으므로 실제 운영 데이터와 대표 승인 없이 사용하지 않는다.

## 2. 네 목표와의 연결

| 목표 | 관리할 사건 | 잘못된 대체 지표 |
|---|---|---|
| 신규 체험회원 확보 | 체험 가능석·예약 승격·실제 체험 | 대기 등록·자리 알림 |
| 휴면회원 복귀 | 복귀 가능석·실제 복귀 참여 | 일반 신규 체험 |
| 기존회원 재등록·만족 | 기존회원 접근권·예약 성공·실제 참여 | 총 예약수·만석 횟수 |
| 매출 증대 | 계약·실수납·환불·직접비용 반영 순수납 | 대기자·정가 총액·예약 |

## 3. 정원 계층

### 3.1 필수 정원

| 정원 | 의미 | 승인 원천 |
|---|---|---|
| SAFETY_CAPACITY | 공간·지도·연령·수업 내용상 안전하게 받을 수 있는 최대 인원 | 지점 책임자·코치·안전 기준 |
| OPERATIONAL_CAPACITY | 실제 코치·보조인력·매트·장비로 운영 가능한 인원 | 시간표·인력·시설 원천 |
| BOOKABLE_CAPACITY | 시스템에서 예약을 받을 수 있는 인원 | 예약 설정 |
| MEMBER_PROTECTED_CAPACITY | 기존회원 이용권 보호를 위해 확보한 인원 | 대표 승인 정책 |
| TRIAL_CAPACITY | 신규 체험에 배정 가능한 인원 | 수업별 승인 정책 |
| RETURN_CAPACITY | 휴면 복귀·재개 회원에게 배정 가능한 인원 | CRM·수업 정책 |
| WALK_IN_CAPACITY | 현장 방문을 받을 수 있는 인원 | 지점 운영 정책 |

다음 관계를 기본 검수한다.

`BOOKABLE_CAPACITY ≤ OPERATIONAL_CAPACITY ≤ SAFETY_CAPACITY`

각 보호석과 체험석의 합이 예약 가능 정원을 넘지 않아야 한다. 정원은 지점 전체가 아니라 수업 회차 단위로 관리한다.

### 3.2 정원을 숫자 하나로 통합하지 않는 이유

- 같은 공간도 연령·수련 수준·수업 내용에 따라 지도 가능 인원이 달라질 수 있다.
- 코치 1명과 보조코치가 있는 수업의 운영 정원은 다를 수 있다.
- 네와자·란도리·입문 설명 수업은 필요한 공간과 감독 수준이 다를 수 있다.
- 시설 수용인원과 안전하게 지도할 수 있는 인원은 같지 않다.
- 기존회원 이용권이 보장하는 접근성과 신규 체험석은 별도 정책이 필요하다.

### 4.2 버전 관리

- 정원 변경은 이전 값을 덮어쓰지 않고 버전·승인자·적용 시각을 남긴다.
- 코치 변경, 휴강, 시설 구역 축소와 장비 부족은 새 정원 버전의 사유가 될 수 있다.
- 이미 확정된 예약보다 정원이 낮아지면 자동 취소하지 않고 사람 검토 대기열로 보낸다.
- 임시 증원은 해당 회차에만 적용하고 반복 시간표에 자동 복제하지 않는다.
- 다른 지점의 정원을 복사할 때 공간·코치·수업 조건을 다시 확인한다.

## 6. 기존회원 보호

### 6.1 기본 원칙

- 신규 체험 확보가 기존회원의 계약상 이용 기회를 지속적으로 밀어내면 안 된다.
- 기존회원 보호석은 실제 계약·이용권 구조와 수업 수요를 본 뒤 승인한다.
- 보호석은 빈자리처럼 보여도 체험석으로 자동 전환하지 않는다.
- 전환 가능 시각·조건·권한을 대표가 승인한다.
- 지점 이동 회원은 신규 체험으로 계산하지 않는다.

### 6.2 확인할 위험

- 인기 시간대가 체험 예약으로 채워져 기존회원이 반복적으로 대기함
- 무제한 이용권의 실제 예약 접근성이 현저히 낮아짐
- 기존회원 보호석이 사용되지 않았다는 이유로 사전 고지 없이 삭제됨
- 지점별 정책 차이가 공개 안내와 충돌함
- 체험석이 계약 후 자동으로 동일 시간대 정규석을 보장한다고 오해시킴

### 6.3 보호 KPI

- 기존회원 예약 성공률
- 기존회원 대기 등록률
- 기존회원 평균 대기시간
- 기존회원 대기 후 실제 참여율
- 체험석 전환으로 인한 기존회원 예약 거절 수
- 인기 회차 반복 대기 회원 수

내부 예약·계약 데이터가 없으면 계산하지 않는다.

## 7. 체험석 운영

### 7.1 체험석 생성 조건

- 해당 회차의 안전·운영 정원이 승인됨
- 기존회원 보호석과 충돌하지 않음
- 입문자 지도에 필요한 코치·보조인력이 있음
- 실제 수업 내용이 체험 대상에게 적합함
- 복장·준비물·도착·취소 안내가 확인됨
- 가격·혜택이 있으면 최신 승인 원천이 있음

### 7.2 체험석 상태

- TRIAL_SLOT_DRAFT: 내부 검토 중
- TRIAL_SLOT_APPROVED: 승인 완료
- TRIAL_SLOT_PUBLISHED: 예약 채널에 공개 반영
- TRIAL_SLOT_BOOKED: 체험 예약 확정
- TRIAL_SLOT_ATTENDED: 실제 체험 참여
- TRIAL_SLOT_UNUSED: 승인됐으나 예약 없음
- TRIAL_SLOT_RELEASED: 정책에 따라 다른 대상에게 전환
- TRIAL_SLOT_CANCELED: 운영·안전 사유로 폐기

초안·승인·공개·예약·참여를 구분한다.

### 7.3 채널별 표현

#### 네이버

- 실제 예약 가능 회차와 공개 상태를 대조한다.
- 신청과 확정을 구분한다.
- 지점·수업·대상·시간을 명확히 표시한다.
- ‘마감 임박’은 실제 좌석 원천과 승인 없이는 사용하지 않는다.

#### Instagram 코치 개인 계정

- 코치 개인 설명 콘텐츠와 공식 체험 모집을 구분한다.
- 코치 계정의 DM 답변을 전 지점 좌석 확정으로 표현하지 않는다.
- 미확정 시간표·무료 체험·잔여석·혜택을 넣지 않는다.
- 확인된 문의 경로가 있을 때만 수업 문의 CTA를 사용한다.

#### 당근

- 실제 지점 생활권과 예약 가능한 회차가 확인될 때만 지역 표현을 쓴다.
- 광고 클릭·채팅 시작을 체험 예약으로 계산하지 않는다.
- 여러 지점을 하나의 정원처럼 합치지 않는다.

## 8. 대기열 규칙

### 8.1 공정성 원칙

- 선착순, 추첨, 회원 등급, 이용권 우선 등 실제 규칙을 사전에 승인한다.
- 직원이 임의로 순서를 바꾸면 이유와 승인자를 기록한다.
- 보호자와 수련자의 중복 대기 등록을 검토한다.
- 같은 사람이 여러 채널에 등록해도 한 자리 수요로 중복 제거한다.
- 대기 순번이 실제 예약권을 보장한다고 표현하지 않는다.

### 8.2 자리 제안

자리 제안에는 다음을 포함한다.

- 정확한 지점·수업·시각
- 수락 방법
- 승인된 응답 기한
- 수락하지 않을 때의 처리
- 취소·변경 경로

자리 제안 발송은 예약 확정이 아니다. 자동 승격 여부는 고객이 사전에 이해하고 동의한 규칙이 있을 때만 사용한다.

### 8.3 응답 기한

- 외부 업체의 20~30분 응답 기한을 내부 기본값으로 복사하지 않는다.
- 수업까지 남은 시간, 채널 전달 속도, 이동시간과 운영 인력을 보고 승인한다.
- 전달 실패를 고객 거절로 처리하지 않는다.
- 만료 시각과 다음 대기자 제안 시각을 기록한다.
- 기한 정책이 없으면 WAITLIST_WINDOW_UNSET으로 유지한다.

### 8.4 대기열 종료

다음 때 해당 회차의 대기 상태를 종료한다.

- 예약으로 실제 승격
- 본인의 대기 취소
- 수업 시작 또는 승인된 마감 시각 경과
- 수업 취소
- 대상 자격 변경
- 연락 중단·수신거부 요청

다른 날짜의 대기열로 자동 이동하지 않는다.

## 9. 초과예약

### 9.1 기본 금지

실제 예약 수가 BOOKABLE_CAPACITY를 넘는 상태를 초과예약으로 정의한다. 다음 조건이 모두 충족되기 전에는 사용하지 않는다.

- 안전 정원과 운영 정원이 별도로 확인됨
- 수업·시간대별 취소·노쇼 데이터가 충분함
- 기존회원 이용권과 소비자 안내가 검토됨
- 초과 도착 시 대체 수업·보상·현장 대응이 승인됨
- 지점 책임자와 대표의 명시적 승인 존재

현재 내부 데이터가 연결되지 않았으므로 초과예약은 승인되지 않은 가설이다.

### 9.2 외부 비율 사용 금지

외부 자료가 제안하는 10~15% 등의 초과예약 비율을 적용하지 않는다. 다음 차이가 있기 때문이다.

- 유도 수업은 매트 공간과 파트너 구성에 제약이 있음
- 입문자·아동·성인의 감독 요구가 다름
- 란도리·네와자·기술 설명의 공간 요구가 다름
- 지점별 코치·시설·시간표 조건이 다름
- 초과 도착 시 안전과 지도 품질 저하가 발생할 수 있음

### 9.3 우선 대안

1. 대기열 운영
2. 취소 자리의 명확한 제안
3. 수요가 집중된 시간대의 원인 확인
4. 실제 코치·공간이 있을 때 추가 회차 검토
5. 이용 가능한 인접 시간·지점의 선택적 안내

다른 시간대나 지점을 강제로 대체하지 않는다.

## 10. 다지점 운영

- 지점별 정원은 합산하지 않는다.
- 대기자를 다른 지점으로 보내기 전 거리·시간·대상·수업 적합성을 확인한다.
- 타 지점 제안은 원래 예약의 자동 변경이 아니다.
- 한 사람이 여러 지점에서 동일 시간대 예약을 확정하지 않도록 중복 검토한다.
- 지점 이동은 신규 획득으로 집계하지 않는다.
- 계약·수납 귀속과 실제 참여 지점을 분리 기록한다.

## 11. 수요 판정

### 11.1 대기자가 의미하는 것

대기자는 다음 조건이 붙은 수요 신호다.

- 특정 지점
- 특정 날짜·시간
- 특정 수업 유형
- 특정 대상·이용권
- 특정 대기 정책

월요일 저녁 대기자를 화요일 낮 수업 수요로 확정하지 않는다.

### 11.2 추가 회차 검토 조건

- 반복 기간 동안 같은 회차의 유효 대기자가 발생
- 대기 후 실제 참여 의사가 확인됨
- 취소·중복·봇·잘못된 지점이 제거됨
- 코치·공간·장비·안전 정원을 확보할 수 있음
- 기존 시간표와 회원 만족에 미치는 영향 검토
- 예상 수요를 실제 계약·수납으로 과대 해석하지 않음

대기자 수만으로 지점 확장·인력 채용·광고 증액을 결정하지 않는다.

## 12. KPI

### 12.1 정원·예약

- 예약 점유율 = 유효 예약 수 / BOOKABLE_CAPACITY
- 실제 이용률 = 실제 참여 수 / OPERATIONAL_CAPACITY
- 체험석 예약률 = 체험 예약 확정 수 / 승인된 체험석 수
- 체험석 참석률 = 실제 체험 참여 수 / 유효 체험 예약 수
- 기존회원 예약 성공률 = 기존회원 예약 확정 수 / 기존회원 유효 예약 요청 수

### 12.2 대기열

- 대기 등록률 = WAITLIST_JOINED 수 / 만석 도달 후 유효 예약 시도 수
- 자리 제안률 = SLOT_OFFERED 수 / 유효 대기 등록 수
- 자리 수락률 = SLOT_ACCEPTED 수 / 전달된 자리 제안 수
- 승격률 = WAITLIST_PROMOTED 수 / 유효 대기 등록 수
- 승격 후 참석률 = 승격 후 실제 참여 수 / WAITLIST_PROMOTED 수
- 대기 만료율 = SLOT_OFFER_EXPIRED 수 / 전달된 자리 제안 수

### 12.3 보호·품질

- 기존회원 대기율
- 체험석 전환으로 인한 기존회원 거절 수
- 정원 감소 후 영향을 받은 예약 수
- 초과 도착 수
- 현장 안전·지도 품질 사건 수
- 수업별 불만·서비스 회복 사건 수

### 12.4 매출

- 대기 승격 후 신규 계약 수
- 대기 승격 후 복귀·재등록 수
- 관련 실수납
- 환불·보상·직접비용 반영 순수납

분자·분모·기간·원천을 함께 표시한다. 분모가 0이거나 데이터가 없으면 계산하지 않는다. 대기자 수, 예약 수와 정가 총액을 매출로 사용하지 않는다.

## 13. 대기열 감사

매 운영일 다음을 확인한다.

1. 안전 정원보다 예약 가능 정원이 큰가
2. 보호석과 체험석의 합이 예약 가능 정원을 넘는가
3. 대기 순서가 근거 없이 변경됐는가
4. 자리 제안이 예약 확정으로 표시됐는가
5. 전달 실패가 고객 거절로 처리됐는가
6. 승격 후 이전 대기 알림이 계속되는가
7. 수업 취소 뒤 대기자가 남아 있는가
8. 지점 이동이 신규 획득으로 집계됐는가
9. 체험석 때문에 기존회원 예약이 반복적으로 거절되는가
10. 초과예약이 승인 없이 적용됐는가
11. 대기자와 예약을 매출로 계산했는가
12. 개인정보가 공개 문서에 들어갔는가
