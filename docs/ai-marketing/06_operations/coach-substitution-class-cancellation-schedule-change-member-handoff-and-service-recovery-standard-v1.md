# 코치 대체·휴강·시간표 변경·회원 인계·서비스 회복 기준 v1

- 적용 조직: 파이널유도멀티짐 공개 마케팅·운영 실무
- 작성일: 2026-09-17
- 문서 상태: 공개 가능한 운영 기준
- 적용 범위: 일반 수업, 체험 수업, 복귀 수업, 승급·대회 준비 수업과 다지점 대체 안내
- 공개 제외: 회원·보호자 식별정보, 연락처, 건강정보, 코치 개인사유, 개인별 예약·출석·계약·결제·환불 기록, 내부 인사·징계자료, 비밀키
- 내부 성과 상태: 데이터 미연결

## 1. 핵심 판단

코치 부재나 수업 변경이 발생했을 때 가장 먼저 해야 할 일은 홍보가 아니라 다음 사건을 분리하는 것이다.

`부재 신호 → 영향 수업 확인 → 대체 코치 자격 검토 → 배정 제안 → 대체 코치 수락 → 수업 유지·변경·휴강 결정 → 공개 정보 수정 → 대상 회원 안내 → 전달 확인 → 실제 수업 이행 → 참석 확인 → 서비스 회복 결정 → 실제 이행 → 회원 확인`

코치가 배정됐다는 사실만으로 대체 수업이 확정된 것은 아니다. 안내를 발송했다는 사실만으로 회원이 변경 내용을 확인한 것도 아니다. 보강·이월·환불을 제안했다는 사실만으로 실제 이행된 것도 아니다.

수업이 예정대로 이행되지 않았는데도 예약수·월회비·정가 총액을 그대로 성과로 계산하면 회원 만족과 매출이 동시에 과대평가된다.

## 2. 네 목표와의 연결

| 목표 | 관리할 사건 | 잘못된 대체 지표 |
|---|---|---|
| 신규 체험회원 확보 | 변경 안내 확인·재예약·실제 체험 | 체험 신청·안내 발송 |
| 휴면회원 복귀 | 복귀 수업 유지·대체 선택·실제 복귀 | 복귀 의사·대체 제안 |
| 기존회원 재등록·만족 | 수업 연속성·변경 수용·서비스 회복 이행 | 공지 게시·보상 약속 |
| 매출 증대 | 계약·실수납·환불·보상비용 반영 순수납 | 예약·청구액·보강 제안 |

- 같은 지점 내 공간 변경과 타 지점 이동
- 같은 대상의 대체 수업과 연령·수준이 다른 합반
- 대체 수업 제안과 예약 확정
- 안내 발송과 확인
- 보강 약속과 보강 이행
- 환불 신청과 환불 완료

### 4.2 변경 버전

- 원래 시간표를 덮어쓰지 않고 이전 값과 변경 버전을 남긴다.
- 변경 결정 시각과 공개 반영 시각을 분리한다.
- 재변경이 발생하면 최신 버전만 알리는 것이 아니라 이전 안내를 정정했음을 표시한다.
- 다른 지점의 시간표를 복사할 때 대상·정원·코치·공간을 다시 검증한다.
- 변경 후 원래 회차가 살아 있는 것처럼 중복 예약되지 않게 한다.

## 5. 대체 코치 검토

### 5.1 필수 확인

- 해당 연령·수준·수업 유형을 지도할 내부 권한
- 필요한 자격·경력의 내부 확인 상태
- 아동·청소년 지도 시 보호·인계 기준
- 수업 목표·안전 주의·진도에 대한 인수인계
- 해당 회차의 시간·지점·정원 수락
- 이해충돌·중복 배정 여부
- 응급 상황과 사고 보고 경로

자격이나 권한이 확인되지 않은 사람을 단순히 도복을 입을 수 있다는 이유로 대체 지도자로 배정하지 않는다.

### 5.2 인계 최소 항목

- 수업 목표와 예정 진도
- 입문자·복귀자 존재 여부의 비식별 요약
- 안전상 제한이 필요한 활동의 비식별 운영 지침
- 정원·보조 인력·매트 구역
- 출석·보호자 인계 절차
- 다음 수업과의 연결 포인트
- 사고·불만·일정 변경 보고 책임자

개인별 건강정보는 필요 최소한의 권한자에게만 제공하며 공개 일정표·마케팅 문서에 기록하지 않는다.

## 6. 수업 유지·변경·휴강 결정

### 6.1 판단 순서

1. 안전하게 수업을 운영할 수 있는가
2. 승인된 대체 코치가 실제로 수락했는가
3. 원래 대상·시간·장소·정원을 유지할 수 있는가
4. 변경이 계약·공개 안내와 충돌하는가
5. 회원이 현실적으로 이동·참여할 수 있는 대안인가
6. 변경 통지가 수업 전에 전달될 수 있는가
7. 보강·이월·환불 등 회복 조치가 필요한가

안전 또는 지도 책임이 불명확하면 수업 유지보다 사람 검토와 휴강 판단을 우선한다.

### 6.2 합반 제한

- 아동·성인, 입문·상급, 일반·선수반을 자동 합반하지 않는다.
- 합반 후 안전·지도 가능 정원을 다시 계산한다.
- 기존 수업 목표와 크게 달라지면 CLASS_SCOPE_CHANGED로 기록한다.
- 합반을 정상 이행과 동일하게 처리하려면 사전 정책과 대상 적합성이 확인되어야 한다.
- 합반 때문에 실제 수업 시간이 줄거나 개별 지도가 현저히 달라진 경우 회복 검토 대상으로 보낸다.

## 7. 안내 기준

### 7.1 필수 안내 항목

- 영향을 받는 정확한 지점·날짜·수업 시각
- 코치 변경, 시간 변경, 장소 변경, 합반, 휴강 중 해당 유형
- 변경된 시작·종료 시각과 장소
- 참여 가능한 대상과 준비물 변화
- 기존 예약의 유지·취소 여부
- 대체 회차 또는 재예약 방법
- 문의·취소 경로
- 추가 정정이 있을 때 확인할 공식 원천

코치의 건강·가족·징계 등 상세 개인사유는 공개하지 않는다. 필요한 경우 ‘운영상 사유’처럼 최소한으로 안내한다.

### 7.2 안내 상태

`작성 → 사실 검수 → 승인 → 공개 반영 → 개별 발송 → 전달 → 확인 → 정정 필요 여부`

- 초안을 공개 공지로 계산하지 않는다.
- 공개 게시만으로 모든 예약자가 확인했다고 보지 않는다.
- 발송 실패·수신거부·연락처 오류를 회원의 동의 또는 거절로 해석하지 않는다.
- 수업 직전 변경은 공개 게시와 대상자 안내를 병행하되 실제 발송은 승인된 운영 절차로만 한다.
- 미성년자 수업은 승인된 보호자 연락·인계 원천을 사용한다.

### 7.3 채널별 역할

#### 네이버·웹사이트

- 반복 시간표와 임시 변경 공지를 구분한다.
- 임시 변경 종료일을 표시한다.
- 예약 가능 화면과 공개 시간표가 일치하는지 확인한다.
- 수정 신청과 실제 공개 반영을 별도 상태로 둔다.

#### Instagram 코치 개인 계정

- @ant.toe.98은 코치 개인 계정이며 전체 지점 공식 공지의 유일한 원천으로 사용하지 않는다.
- 본인 담당 수업 변경도 공식 운영 원천과 대조한 뒤 보조 안내로만 사용한다.
- 미확정 대체 코치·시간표·보상·환불을 게시하지 않는다.
- 수업 변경 안내와 개인 수련 기록을 같은 게시물에서 혼합하지 않는다.

#### 당근

- 지역 게시물과 실제 영향을 받는 지점을 일치시킨다.
- 장기 운영시간 변경과 단일 회차 휴강을 구분한다.
- 채팅 시작을 변경 확인이나 재예약으로 계산하지 않는다.

## 8. 서비스 회복

### 8.1 가능한 조치 상태

| 상태 | 의미 |
|---|---|
| RECOVERY_REVIEW_PENDING | 계약·원인·영향 검토 중 |
| MAKEUP_OFFERED | 보강 수업 제안 |
| EXTENSION_OFFERED | 이용기간 이월·연장 제안 |
| CREDIT_OFFERED | 승인된 크레딧 제안 |
| REFUND_REVIEW_PENDING | 환불 기준 검토 중 |
| REFUND_APPROVED | 환불 승인 |
| REFUND_SETTLED | 실제 환불 완료 |
| RECOVERY_DECLINED | 회원이 제안을 거절 |
| RECOVERY_FULFILLED | 선택한 조치 이행 완료 |
| CASE_REOPENED | 해결되지 않아 재개방 |

### 8.2 기본 원칙

- 변경·휴강 사유가 누구의 책임인지 검토하기 전에 자동으로 회원 귀책을 적용하지 않는다.
- 보강, 연장, 크레딧과 환불은 서로 다른 조치다.
- 동일 사건에 복수 조치가 적용되면 중복 비용과 상태를 기록한다.
- ‘다른 수업에 오면 된다’는 제안만으로 원래 계약이 이행됐다고 보지 않는다.
- 법정·계약상 환급 기준을 마케팅 문구로 축소하거나 대체하지 않는다.
- 외부 무도장의 포괄적 무환불 약관을 내부 기준으로 복사하지 않는다.

## 9. 회원 경험과 재등록

- 반복 변경 횟수와 변경 직후 출석 저하를 별도 관찰한다.
- 코치 변경 후 회원 만족 미응답을 긍정으로 처리하지 않는다.
- 변경 수용 여부와 재등록 의사를 분리한다.
- 재등록 의향을 계약으로, 계약을 실수납으로 계산하지 않는다.
- 불만·안전 사건이 열려 있으면 일반 재등록 자동화를 중지하고 담당자에게 인계한다.
- 서비스 회복 직후 리뷰·추천을 요구하지 않는다.

## 10. 다지점 운영

- 한 지점의 휴강을 전 지점 휴강으로 확대하지 않는다.
- 타 지점 대체는 거리·시간·대상·정원·코치 적합성을 확인한다.
- 타 지점 수업 제안은 자동 예약 변경이 아니다.
- 실제 수업 지점과 계약·수납 귀속 지점을 분리한다.
- 지점 이동을 신규회원이나 복귀회원으로 중복 집계하지 않는다.
- 각 지점의 공개 시간표와 예약 원천이 동일 버전을 가리키는지 확인한다.

- 코치 변경·시간 변경·장소 변경·합반·휴강 수
- 결정부터 공개 반영까지 시간
- 결정부터 대상자 전달까지 시간
- 전달 실패와 정정 공지 수

### 11.2 회원 경험

- 변경 안내 확인률 = 확인 대상자 수 / 전달된 대상자 수
- 대안 선택률 = 대안 수락 수 / 전달된 대안 제안 수
- 대체 예약 확정률 = 대체 예약 확정 수 / 대안 수락 수
- 변경 후 실제 참여율 = 실제 참여 수 / 변경 후 유효 예약 수
- 회복 이행률 = 실제 이행된 조치 수 / 승인된 회복 조치 수
- 해결 확인률 = 해결 확인 수 / 회복 이행 수

### 11.3 사업 성과

- 변경 영향 회원의 재등록 계약 수
- 관련 실수납
- 환불·크레딧·보강 직접비용
- 변경 사건 관련 순수납
- 변경 없는 비교 회차와의 출석·재등록 차이

분자·분모·기간·원천을 함께 표시한다. 데이터가 없거나 분모가 0이면 계산하지 않는다. 안내 발송, 보강 제안과 청구액을 성과로 계산하지 않는다.
