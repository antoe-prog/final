# 수업 예약·대기명단·당일취소·노쇼·정원 회수·출석 귀속 기준 v1

- 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-18
- 적용 범위: 파이널유도멀티짐의 신규 체험, 기존회원 수업 예약, 휴면회원 복귀, 재등록 및 매출 귀속
- 제외 범위: 개인 식별정보, 연락처, 건강정보, 개별 출석·결제 원장, 내부 가격·원가, 미확정 행사, 승인 대기 Instagram 미디어·캡션
- 운영 원칙: 예약 신청·예약 확정·체크인·실제 참여·실수납을 서로 다른 사건으로 기록한다.

## 1. 목적

이 기준은 다음 오류를 막기 위한 것이다.

1. 예약 신청을 예약 확정으로 계산하는 오류
2. 대기명단 등록을 수업 예약으로 계산하는 오류
3. 체크인을 실제 참여로 계산하는 오류
4. 결석 검토 중 상태를 노쇼 확정으로 계산하는 오류
5. 취소 수수료 부과를 실수납 매출로 계산하는 오류
6. 여러 지점·채널의 동일 회원과 동일 예약을 중복 집계하는 오류
7. 정원 회수를 이유로 안전 정원을 초과하는 오류
8. 운영 알림을 광고성 메시지 동의로 간주하는 오류

## 2. 가장 중요한 판단

정원 손실의 원인은 노쇼 한 가지가 아니다.

- 예약 확정 후 미참여
- 늦은 취소
- 대기 승격 알림 미도달
- 승격 수락 기한 부족
- 지점·수업 간 중복 예약
- 체크인과 출석 확정의 불일치
- 수업 취소 또는 운영 변경
- 안전 정원과 판매 가능 정원의 혼동

따라서 수수료나 제재를 먼저 적용하지 않는다. 먼저 사건 상태와 원천을 연결하고, 실제로 회수 가능한 좌석이 어디에서 사라지는지 측정한다.

## 3. 용어

### 3.1 정원

- **안전 정원**: 매트 공간, 연령·수준, 지도 인력과 수업 형식을 고려해 대표와 현장 책임자가 승인한 최대 인원
- **판매 가능 정원**: 안전 정원 안에서 실제 예약을 받을 수 있도록 열어 둔 인원
- **예약 확정 인원**: 유효한 예약 확정 상태의 고유 참여자 수
- **대기 인원**: 만석 수업의 대기명단에 있는 고유 참여자 수
- **회수 가능 좌석**: 취소·변경으로 다시 배정할 수 있고 안전 정원을 넘지 않는 좌석
- **회수 완료 좌석**: 대기 승격 또는 신규 예약 후 실제 참여까지 확인된 좌석

판매 가능 정원은 안전 정원을 넘을 수 없다. 통계적 초과예약은 별도 승인과 안전 검토 없이 사용하지 않는다.

### 3.2 예약과 참여

- **예약 신청**: 사용자가 수업 참여를 요청한 상태
- **예약 확정**: 기준 시스템이 좌석을 확정한 상태
- **대기 등록**: 만석 수업의 순번 또는 대기 자격이 생성된 상태
- **대기 승격 제안**: 빈 좌석을 대기자에게 제안한 상태
- **대기 승격 수락**: 대기자가 제안된 좌석을 수락한 상태
- **체크인**: 도착 또는 입장 절차가 기록된 상태
- **출석 확인**: 코치나 승인된 현장 담당자가 실제 참여를 확인한 상태
- **노쇼**: 예약이 유효했고, 수업 종료 후에도 취소·체크인·출석 또는 승인된 예외가 없는 것으로 확인된 상태

체크인은 출석의 보조 증거이며, 자동으로 실제 참여를 증명하지 않는다.

## 4. 표준 상태 모델

예약 사건은 아래 상태 중 하나와 변경 이력을 가져야 한다.

| 코드 | 상태 | 성과 계산 |
|---|---|---|
| DRAFT | 입력 중 | 제외 |
| BOOKING_REQUESTED | 예약 신청 | 신청만 집계 |
| BOOKING_CONFIRMED | 좌석 확정 | 예약 확정 집계 |
| WAITLISTED | 대기 등록 | 대기 집계 |
| SEAT_RELEASED | 좌석 반환 | 회수 가능 좌석 |
| PROMOTION_OFFERED | 대기 승격 제안 | 제안 집계 |
| PROMOTION_ACCEPTED | 승격 수락·예약 확정 | 예약 확정 집계 |
| CANCELLED_EARLY | 승인 기준 전 취소 | 조기 취소 |
| CANCELLED_LATE | 승인 기준 후 취소 | 늦은 취소 |
| CHECKED_IN | 도착·입장 기록 | 출석으로 계산하지 않음 |
| ATTENDANCE_VERIFIED | 실제 참여 확인 | 실참여 집계 |
| NO_SHOW_REVIEW | 노쇼 검토 | 노쇼로 계산하지 않음 |
| NO_SHOW_CONFIRMED | 노쇼 확정 | 노쇼 집계 |
| FEE_ASSESSED | 비용 부과 | 매출로 계산하지 않음 |
| FEE_WAIVED | 비용 면제·취소 | 순수납 제외 |
| PAYMENT_CAPTURED | 실제 수납 확인 | 실수납 후보 |
| REFUNDED | 환불 완료 | 순수납 차감 |
| CLASS_CANCELLED | 운영자 수업 취소 | 회원 노쇼 제외 |
| EXCEPTION_REVIEW | 예외 검토 | 최종 분류 보류 |

모든 상태 변경에는 사건 ID, 예약 ID, 지점 ID, 수업 ID, 발생 시각, 원천 시스템, 변경 주체, 사유 코드가 필요하다. 공개 저장소에는 실제 값이나 개인 식별자를 저장하지 않는다.

## 5. 상태 전이 원칙

### 5.1 예약 확정

예약 신청만으로 좌석을 확정하지 않는다. 기준 시스템의 확정 ID와 확정 시각이 있어야 한다.

### 5.2 대기명단

대기 등록은 예약 확정이 아니다. 승격 제안도 예약 확정이 아니다. 승격 수락 또는 승인된 자동 승격 규칙이 충족되어야 예약 확정으로 전환한다.

### 5.3 취소

조기 취소와 늦은 취소의 기준 시점은 대표가 승인한 공개 정책을 사용한다. 기준이 없으면 임의로 시간을 만들지 않고 모두 미분류로 둔다.

### 5.4 체크인과 출석

셀프 체크인, QR 스캔, 프런트 체크인은 도착 신호다. 실제 수업 참여는 코치 또는 승인된 현장 담당자의 출석 확인으로 확정한다.

### 5.5 노쇼

수업 시작 전이나 진행 중에는 노쇼를 확정하지 않는다. 수업 종료 후 다음을 확인한다.

- 유효한 예약 확정
- 수업 정상 개최
- 취소 기록 없음
- 체크인·출석 기록 없음
- 시스템 지연 여부 확인
- 승인된 예외 없음

확인 전 상태는 NO_SHOW_REVIEW로 유지한다.

## 6. 대기명단 운영 기준

### 6.1 순번

대기 순번은 등록 시각 또는 대표가 승인한 명시적 우선순위 규칙에 따른다. 코치나 직원이 임의로 긍정 고객·고액 회원을 우선하지 않는다.

### 6.2 승격 제안

승격 제안에는 다음이 포함되어야 한다.

- 대상 수업과 지점
- 수업 시작 시각
- 수락 기한
- 수락 방법
- 수락하지 않았을 때의 처리
- 취소·노쇼 정책이 적용되는 시점

실제 메시지 발송은 대표 승인과 채널 동의 확인 후에만 한다.

### 6.3 수락 기한

수락 기한은 수업까지 남은 시간과 알림 수신 가능성을 고려한다. 심야 또는 지나치게 촉박한 승격으로 실질적인 응답 기회를 주지 못했다면 자동 노쇼·제재 대상으로 만들지 않는다.

### 6.4 연쇄 승격

한 사람이 거절하거나 기한이 지나면 다음 대기자에게 좌석을 제안한다. 동일 좌석을 동시에 여러 사람에게 확정하지 않는다. 승격 사건마다 멱등성 키를 사용한다.

### 6.5 대기 중복

동일인이 같은 시각에 여러 지점 또는 여러 수업을 대기·예약한 경우 자동 삭제하지 않고 충돌 검토 대상으로 보낸다.

## 7. 정원 회수 기준

좌석 회수는 아래 순서로 계산한다.

1. 취소 또는 좌석 반환 발생
2. 회수 가능한 좌석 확인
3. 대기 승격 제안
4. 승격 수락 또는 신규 예약 확정
5. 체크인
6. 실제 참여 확인

좌석 반환만으로 회수 완료로 계산하지 않는다. 예약 확정만으로도 회수 완료로 계산하지 않는다. 최종 실참여가 확인되어야 회수 완료다.

## 8. 신규 체험 운영

신규 체험의 노쇼는 일반 회원 노쇼와 분리한다.

- 문의
- 체험 신청
- 예약 확정
- 사전 안내 확인
- 실제 참여
- 등록
- 실수납

체험 노쇼를 자동으로 실패 리드 또는 거절 의사로 해석하지 않는다. 후속 연락은 마케팅 동의, 채널, 횟수와 중단 기준이 승인된 경우에만 한다.

체험 예약 취소와 일반 회원 수업 취소를 같은 분모에 섞지 않는다.

## 9. 기존회원·휴면회원·만료예정회원

- 기존회원: 수업 예약·출석·취소 데이터를 만족도와 재등록의 보조 신호로만 사용한다.
- 휴면회원: 복귀 수업 예약과 실제 참여를 분리한다.
- 만료예정회원: 예약·출석만으로 재등록을 확정하지 않는다.
- 재등록: 계약 또는 회원권 생성과 실제 수납을 구분한다.
- 장기 미출석: 건강·불만·이사 등 원인을 추정하지 않는다.

## 10. 미성년자와 보호자

미성년자 예약은 참여자와 보호자 권한을 분리한다.

- 보호자 연락처를 참여자 마케팅 동의로 자동 승격하지 않는다.
- 비상연락 동의를 광고성 메시지 동의로 사용하지 않는다.
- 취소·노쇼·비용 정책은 보호자에게도 사전에 확인 가능한 형태로 제공해야 한다.
- 형제자매 예약과 동일 가구 예약을 동일인으로 합치지 않는다.

## 11. 알림과 동의

운영 알림과 마케팅 메시지는 목적을 분리한다.

### 운영 알림 예시

- 예약 확정
- 수업 변경·취소
- 대기 승격 제안
- 취소 접수
- 출석 오류 확인 요청

### 마케팅 메시지 예시

- 신규 혜택
- 재등록 제안
- 휴면 복귀 캠페인
- 친구 추천
- 이벤트 홍보

운영 알림 수신을 광고성 메시지 동의로 간주하지 않는다. 연락 중단 요청 이후에는 승인된 필수 운영 범위를 넘어 발송하지 않는다.

## 12. 비용·수납·환불

늦은 취소 또는 노쇼 비용을 적용하려면 다음이 선행되어야 한다.

- 계약·약관·고지 문구 확인
- 최신 법령·소비자분쟁 기준 검토
- 적용 대상과 예외 정의
- 보호자 안내
- 면제·이의제기·환불 절차
- 실제 결제사와 원장 연결
- 대표 승인

다음 상태를 분리한다.

- 비용 부과 결정
- 청구 생성
- 결제 시도
- 결제 성공
- 결제 실패
- 면제
- 취소
- 환불
- 순수납

FEE_ASSESSED를 매출로 계산하지 않는다. PAYMENT_CAPTURED에서 환불과 취소를 차감한 값만 순수납 후보다.

## 13. 예외 처리

다음은 자동 제재 대신 검토 대상으로 보낸다.

- 시설 또는 코치 사정으로 수업이 취소·변경된 경우
- 시스템 장애 또는 알림 미도달 가능성
- 대기 승격이 지나치게 촉박했던 경우
- 중복 예약 병합 오류
- 보호자 권한 확인이 필요한 경우
- 의료·안전 사건이 신고된 경우
- 체크인과 코치 출석 기록이 충돌하는 경우
- 결제·회원권 상태가 동기화되지 않은 경우

건강 사유의 상세 내용은 운영 기준 문서나 공개 저장소에 기록하지 않는다.

## 14. 다지점 중복 방지

각 사건에는 location_id와 class_id를 둔다. 동일 참여자가 여러 지점에서 같은 시간대에 예약된 경우 별도 검토한다.

- 한 실제 참여를 두 지점 출석으로 계산하지 않는다.
- 한 취소를 두 번 좌석 반환으로 계산하지 않는다.
- 한 수납을 여러 지점 매출로 중복 귀속하지 않는다.
- 지점 이동은 신규회원으로 다시 계산하지 않는다.
- 신규·복귀·재등록은 서로 배타적인 분류 규칙을 둔다.

## 15. 기준 원천 우선순위

1. 현장 코치가 확정한 실제 출석 기록
2. 기준 예약 시스템의 예약·취소 사건
3. 승인된 체크인 시스템 기록
4. 결제사의 실제 수납·환불 사건
5. CRM의 연락·후속 상태
6. 채널 클릭·열람·알림 기록

하위 원천의 신호가 상위 원천의 실제 사건을 대신하지 않는다.

## 16. KPI 정의

모든 지표는 기간, 지점, 수업 유형, 참여자 분류, 분자, 분모와 원천을 표시한다.

## 17. 네 목표와 연결

### 신규 체험회원 확보

### 휴면회원 복귀

복귀 메시지 발송이 아니라 복귀 수업의 실제 참여를 성과로 본다. 기존회원 예약과 중복 귀속하지 않는다.

### 기존회원 재등록·만족

정원 부족, 잦은 대기, 촉박한 승격, 오류 제재를 만족도 위험으로 본다. 재등록은 계약·실수납으로 별도 확인한다.

### 매출 증대

회수된 좌석의 실제 참여와 실수납을 연결한다. 노쇼 비용 부과액을 매출로 과장하지 않는다.
