# Google Business Profile–Gemini 연결 앱 자격·변경 통제·전환 귀속 기준 v1

- 상태: 공개 가능한 지역 마케팅 운영 기준
- 기준일: 2026-09-26
- 적용 범위: 다지점 유도장·체육시설의 Google Business Profile을 Gemini 웹 앱에서 조회·관리하는 기능의 도입 검토
- 공개 제외: Google 계정·프로필 식별자, 관리자 이름·이메일, 회원·보호자 식별정보, 개인별 문의·출석·건강·결제 원장, 비밀키·토큰, 승인 대기 콘텐츠, 미확정 가격·시간표·행사
- 실행 상태: **연결·프로필 변경·게시·리뷰 답글 미실행**
- 현재 판정: **다지점 운영 구조와 공식 자격 조건이 충돌하므로 기본값은 미연결 유지**

## 1. 오늘의 판단

Gemini 웹 앱은 Google Business Profile의 정보 조회에 그치지 않고 영업시간·연락처·웹사이트·소셜 링크·예약 링크를 변경하고, 프로필 게시물을 생성·예약·발행·삭제하며, 리뷰 답글 초안을 만들거나 삭제할 수 있다.

파이널유도멀티짐처럼 여러 지점을 관리하는 운영에서는 편의성보다 변경 통제가 우선이다. Google의 현재 공식 조건은 한 개의 인증된 Business Profile만 소유·관리하는 계정을 요구하며, 두 개 이상 프로필에 접근하는 소유자·관리자는 대상에서 제외한다. 따라서 8개 지점 운영 구조에 바로 적용할 수 있다고 가정하지 않는다.

## 2. 공식 확인 기능

Google 공식 도움말에서 다음 기능을 확인했다.

### 프로필 정보

- 정규 영업시간과 특별 영업시간 조회·변경
- 웹사이트 URL과 소셜 미디어 링크 조회·변경
- 예약·주문·약속 등 행동 링크 관리
- 카테고리에 따라 제공되는 비즈니스 속성 조회·변경
- 프로필 상태와 내부 기술 정보 조회
- 공개 URL을 이용한 사진 업로드
- 사업 설명 등 누락 정보 보완 제안

### 고객 접점

- 별점·리뷰·연결 미디어 조회
- 리뷰 답글 초안 작성 또는 기존 답글 삭제
- Update·Offer·Event 유형 프로필 게시물 생성·예약·발행·삭제
- 리뷰 주제 요약과 피드백 패턴 분석

### 성과 정보

- 노출·웹사이트 클릭·길찾기 요청·예약 등 성과 지표 분석
- 고객이 프로필을 찾을 때 사용한 검색어 조회
- 비즈니스 노트북의 선제 제안과 맞춤 프롬프트

위 기능의 존재는 파이널유도 계정에서의 실제 제공·성공·정확성을 의미하지 않는다.

| R1 초안 | 설명·게시물·리뷰 답글 초안 생성 | 외부 저장·발행 전 사실·주체 검수 |
| R2 저위험 변경 | 사진 추가, 비필수 속성 수정 | 대표 승인과 전후 화면 보관 |

R2~R5는 자동화의 일반 실행 권한으로 처리하지 않는다.

## 5. 다지점 변경 원장

다지점에서 동일 변경을 일괄 적용하지 않는다. 각 변경은 다음 비식별 필드로 기록한다.

| 필드 | 설명 |
|---|---|
| change_id | 변경 작업 고유값 |
| location_code | 공개 불가 지점명 대신 승인된 비식별 코드 |
| profile_scope | 단일 프로필·다중 프로필·미확인 |
| requested_action | 조회·초안·수정·예약·발행·삭제·연결·해제 |
| target_field | 영업시간·연락처·링크·사진·게시물·리뷰 답글 |
| source_of_truth | 승인된 시간표·웹사이트·계약·운영 공지 |
| before_value_hash | 변경 전 값의 비가역 확인값 |
| approved_value_hash | 승인된 최종 값의 비가역 확인값 |
| approver_role | 대표·지점 책임자·보안 담당 |
| approval_state | 미요청·대기·승인·반려·철회 |
| executed_at | 실제 실행 시각 |
| public_verified_at | Search·Maps 공개 확인 시각 |
| rollback_state | 불필요·준비·실행·실패 |
| source_checked_at | Google 공식 문서 확인 시각 |

개인 계정 이메일·리뷰 작성자 정보·회원정보·원문 결제자료는 공개 저장소에 기록하지 않는다.

## 6. 게시물·리뷰 답글 검수 기준

### 게시물

- Update·Offer·Event의 유형을 실제 내용과 일치시킨다.
- 지점·기간·가격·참여조건·취소·환불·예약 링크를 승인 원장과 대조한다.
- 미확정 FINAL ROAD, 무료 체험, 할인, 보상, 대회 실적을 창작하지 않는다.
- Gemini가 만든 문구를 사실 검증 없이 예약·발행하지 않는다.
- 한 지점 승인 문구를 다른 지점에 복제하지 않는다.

### 리뷰 답글

- 리뷰 작성자의 신원·수련·건강·결제 사실을 답글에 노출하지 않는다.
- 개인별 사건의 사실관계가 확인되지 않으면 공개 답변에서 인정·부인하지 않는다.
- 보상·환불·법적 책임·안전 보장을 즉석에서 약속하지 않는다.
- 초안 생성과 실제 게시를 분리한다.
- 삭제는 복구 가능성·증거 보존·대표 승인을 확인한 뒤 진행한다.

## 7. 네 목표별 활용과 금지선

| 목표 | 허용되는 선행 활용 | 내부 원장으로만 판정할 결과 |
|---|---|---|
| 신규 체험 | 검색어·노출·웹 클릭·길찾기·예약 신호 분석, 승인된 입문 안내 초안 | 유효 문의·예약 확정·체험 실참여·신규 등록 |
| 휴면 복귀 | 계절·시간대 관련 집계 검색어와 승인된 복귀 안내 초안 | 휴면 대상·복귀 문의·복귀 실참여 |
| 재등록·만족 | 리뷰 주제의 집계 분석, 반복 불편 코드 | 만료예정 분모·재등록 완료·만족도 |
| 매출 | Offer·예약 링크의 승인된 운영 가능성 검토 | 실수납·환불·차지백·순수납 |

다음 등식은 사용하지 않는다.

- Gemini 제안 = 고객 수요
- 노출 = 문의
- 웹 클릭·길찾기 = 방문
- 예약 신호 = 체험 실참여
- 리뷰 별점 = 재등록
- 게시물 발행 = 매출
- 검색어 증가 = 신규 등록
- 여러 지점 합계 = 개별 지점 성과

내부 데이터가 연결되지 않으면 **데이터 미연결·계산 불가**로 둔다.

## 9. EXP-456 — Gemini–Business Profile 자격·변경 통제 검증

### 목적

기능을 도입하는 실험이 아니라, 계정 자격과 변경 통제가 안전하게 검증 가능한지 판정한다.

### 단계

1. 대표가 지정한 시험 담당자의 계정 유형·프로필 수·언어·지역·Keep Activity 상태를 읽기 전용으로 확인한다.
2. 다지점 관리자 계정은 연결을 시도하지 않고 공식 제외 조건과 대조한다.
3. 조건을 충족하는 별도 시험 계정이 있더라도 첫 단계는 R0 조회만 허용한다.
4. 합성 영업시간·가상 링크·가상 게시물로 초안 결과를 검수하되 외부 저장·예약·발행하지 않는다.
5. R2 이상은 작업별 정확한 최종 값과 대표 승인을 받은 뒤 한 지점에서만 실행한다.
6. 변경 후 Search·Maps 공개 화면과 내부 원장을 대조하고, 불일치 시 즉시 중단한다.

### 성공 기준

- 공식 자격 조건 오판정 0건
- 승인 없는 연결·Keep Activity·권한 변경 0건
- 승인 없는 영업시간·연락처·링크 변경 0건
- 승인 없는 게시·예약·삭제·리뷰 답글 0건
- 지점 오귀속·채널 중복 귀속 0건
- 생성문구의 미확정 가격·혜택·시간표·실적 주장 0건
- 개인정보·비밀정보·승인 대기 콘텐츠 공개 0건
- 변경 전후 값과 공개 확인 누락 0건

### 즉시 중단 조건

- 담당 계정이 두 개 이상 인증 프로필에 접근
- 한국어 또는 해당 계정에서 기능이 실제 제공되지 않음
- 개인 계정 사용·Keep Activity 활성화가 내부 보안·개인정보 정책과 충돌
- 승인된 최종 값과 Gemini 실행 값 불일치
- 지점별 공개 상태를 분리 검증할 수 없음
- 삭제·되돌리기 절차를 확보하지 못함

사업 성과 기준은 실제 문의·체험·복귀·재등록·수납 원장이 연결된 뒤 별도로 정한다.

## 10. 필요한 대표 승인·입력
