## 읽는 순서

신규 획득 파일럿은 기존회원의 친구 연락처를 운영자가 먼저 수집하는 방식이 아니라 친구가 직접 신청·동의하는 Self-Opt-In 구조를 기본안으로 한다. Open Dojo Week는 모든 반을 무조건 모집하지 않고 실제 안전정원·실출석·체험 허용석이 확인된 시간대에만 신규 체험을 배치하는 Capacity-First 원칙을 사용한다. Hyperlocal DOOH Pilot은 이 여석이 확인된 슬롯에 한해 로컬 옥외광고를 연결하며, 재생 수가 아니라 문의·예약·실방문·등록·30일 활성까지 연결해 판단한다. Women First-Step Judo Pilot은 여성 초보가 표준 혼합 성인반에 바로 진입하기 전 별도의 첫 1~2회 경험이 실제로 방문·2회차·30일 활성의 마찰을 낮추는지 검증하며, 여성 전용 상설반 수요를 사전 가정하지 않는다. Skill-First Ukemi Gateway는 아직 정규회원이 아닌 성인에게 `유도 가입`보다 `낙법·균형·기본 움직임`이라는 구체적인 기술을 짧은 입문상품으로 제시했을 때 자발적 신청·실방문·정규 유도 연결이 개선되는지 검증한다. 이는 유료등록 이후를 다루는 First Six Weeks Activation Window와 구분한다. Fixed Beginner Intake Window는 완전 초보를 아무 날짜에나 혼합수업에 투입하는 방식과 정해진 시작창을 비교해 `첫 실방문→2회차→14일 등록→30일 활성`과 코치 온보딩 부담을 함께 본다. Grappling Crossover Acquisition은 완전 초보가 아니라 주짓수·레슬링 등 인접 그래플링 경험·관심을 자발적으로 표시한 성인에게 유도의 스탠딩·그립·메치기 진입경로를 별도로 제시했을 때 실제 실방문·등록·30일 활성로 이어지는지 검증한다. 경쟁 체육관 회원 명단을 수집하거나 지역 대회와 제휴한 것처럼 표현하지 않는다. Capacity-Aware Waitlist & Alternate-Slot Routing은 인기 시간대가 만석일 때 모집을 계속 밀어 넣지 않고 실제 여석이 있는 대체시간 → 동의 기반 대기목록 → 다음 입문기수 사전알림 순으로 수요를 안전하게 보존하며, 과예약이나 가짜 희소성을 허용하지 않는다. Local Presence Consistency Audit은 광고나 지역행사 콘텐츠를 더 늘리기 전에 본관의 지점명·주소·층·영업시간·문의경로를 내부 기준값으로 확정하고 네이버·Google·서울특별시유도회·당근·공식 채널의 차이를 `MATCH / STALE / MISSING / UNKNOWN / CANNOT_EDIT`로 분류한다. 실제 운영값을 확인하기 전에는 제3자 디렉터리만 보고 공식 프로필을 수정하지 않는다. 강서사랑상품권 결제 준비안은 2026-09-16 예정된 지역상품권 발행을 가격할인이 아니라 결제수단 가시화 기회로 다루며, 본관의 실제 가맹·회원권 결제 가능성·정산을 확인하기 전에는 `강서사랑상품권 사용 가능` 문구를 공개하지 않는다. Naver SmartPlace Coupon — Margin-Protected Pilot은 2026-09-09 공개된 스마트플레이스 첫 쿠폰 이벤트를 단순 할인 경쟁으로 해석하지 않고, 쿠폰 노출·다운로드·사용완료를 실제 예약·체험 출석·유료등록·30일 활성까지 연결해 마진 훼손 없이 검증한다. 쿠폰 발행 가능 업종·과거 발행 이력·이벤트 자격은 관리자 확인 전 `데이터 미연결`로 둔다. 당근 다지점 로컬 라우팅 준비안은 2026-09-03 출시된 `브랜드 지점 방문 늘리기`의 최소 10개 지점 요건을 현재 충족한다고 가정하지 않고, 지점별 비즈프로필·여석·로컬문의·실방문·등록·30일 활성 데이터를 같은 구조로 쌓아 향후 다지점 광고 검토 자격을 판단하도록 한다. 또한 토스페이먼츠 PG와 토스플레이스 POS를 별도 운영요소로 구분한다. Parent-to-Member Household Expansion은 이미 유소년 회원으로 도장을 경험하는 가구 안에서 보호자가 자발적으로 성인 입문 체험을 선택할 수 있는지 검증하되, 보호자 전환이 유소년 재등록이나 매출을 높인다고 사전 가정하지 않는다. Second-Visit Trial Bridge는 첫 체험 참석을 즉시 가입판정으로 끝내지 않고, 실제 체험정책이 허용하는 경우 두 번째 방문을 별도 전환단계로 관리해 `첫 체험→2회차 예약·참석→14일 등록→30일 활성`을 측정한다. 기존 체험 후속관리 문안을 중복 발송하지 않고, 두 번째 방문이 늘어도 등록·활성 개선이 없으면 확대하지 않는다. First Six Weeks Activation Window는 유입 이후 신규·복귀회원의 첫 6주를 별도 관리구간으로 두고 출석계획·코치 접점·진도 가시화·다음 목표가 이후 30일 활성과 재등록에 연결되는지 검증한다. Review Trust Loop는 네이버의 별점·리뷰답글 변화에 맞춰 검색 단계의 신뢰 증거와 FAQ 콘텐츠를 관리하지만, 리뷰 수와 예약 간의 외부 상관관계를 파이널유도 예상 성과로 환산하지 않는다. 체험 문안의 실제 운영정보를 확인하고, 예약·현장 출석·등록을 구분하는 계측 규격을 적용한 뒤 각 실험의 실행 승인과 비교조건을 정한다. 내부 회원수·매출·전환율은 **데이터 미연결**이다.

2026-09-10 작성된 계측·실험 문서는 기존 준비본을 게시한 것이다. 문서의 원래 출처 확인일과 실제 게시일은 다르며, 오늘의 신규 시장조사나 검증된 성과로 해석하지 않는다. 2026-09-11 Buddy Referral, Capacity-First Open Dojo Week, Hyperlocal DOOH Pilot, Review Trust Loop, Parent-to-Member Household Expansion, First Six Weeks Activation Window, Local Presence Consistency Audit, Women First-Step Judo Pilot, 당근 다지점 로컬 라우팅 준비안, Skill-First Ukemi Gateway, Second-Visit Trial Bridge, 강서사랑상품권 결제 준비안, Capacity-Aware Waitlist & Alternate-Slot Routing 문서는 당일 확인한 공개 자료를 기반으로 작성했다. 2026-09-12 Naver SmartPlace Coupon — Margin-Protected Pilot, Fixed Beginner Intake Window, Grappling Crossover Acquisition은 9월 9~12일 공개된 플랫폼·유도·그래플링 운영 사례를 기준으로 작성했다.

## 공개 범위

이 경로에는 개인별 회원·보호자 식별정보, 연락처, 건강·출석·결제 원장, 비밀키·토큰, 개인 컴퓨터 절대경로, 옵시디언 설정을 넣지 않는다.

GitHub 게시, 옵시디언 반영, 예약 설정 적용, 예약 호출, 실제 고객 대상 실행은 서로 다른 확인 항목이다. 현재 확인 결과는 연결 검증 문서를 참고한다.
