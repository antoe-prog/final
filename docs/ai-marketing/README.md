## 읽는 순서

신규 획득 파일럿은 기존회원의 친구 연락처를 운영자가 먼저 수집하는 방식이 아니라 친구가 직접 신청·동의하는 Self-Opt-In 구조를 기본안으로 한다. Open Dojo Week는 모든 반을 무조건 모집하지 않고 실제 안전정원·실출석·체험 허용석이 확인된 시간대에만 신규 체험을 배치하는 Capacity-First 원칙을 사용한다. 체험 문안의 실제 운영정보를 확인하고, 예약·현장 출석·등록을 구분하는 계측 규격을 적용한 뒤 각 실험의 실행 승인과 비교조건을 정한다. 내부 회원수·매출·전환율은 **데이터 미연결**이다.

2026-09-10 작성된 계측·실험 문서는 기존 준비본을 게시한 것이다. 문서의 원래 출처 확인일과 실제 게시일은 다르며, 오늘의 신규 시장조사나 검증된 성과로 해석하지 않는다. 2026-09-11 Buddy Referral 및 Capacity-First Open Dojo Week 문서는 당일 확인한 공개 자료를 기반으로 작성했다.

## 공개 범위

이 경로에는 개인별 회원·보호자 식별정보, 연락처, 건강·출석·결제 원장, 비밀키·토큰, 개인 컴퓨터 절대경로, 옵시디언 설정을 넣지 않는다.

GitHub 게시, 옵시디언 반영, 예약 설정 적용, 예약 호출, 실제 고객 대상 실행은 서로 다른 확인 항목이다. 현재 확인 결과는 연결 검증 문서를 참고한다.
