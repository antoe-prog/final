# Naver ADVoost Place Preflight & Holdout v1

- 기준일: 2026-09-12
- 상태: 공개 웹 조사 및 실험 설계 완료 / 광고 미집행 / 비용 미발생 / 계정 변경 미실행
- 내부 회원수·매출·전환율·네이버 광고계정 상태: **데이터 미연결**
- 목표: 신규 체험회원 확보를 위한 네이버 플레이스광고 자동화 기능을 안전하게 검증하되, 스마트플레이스 정보 오류·자동소재 과장·플랫폼 지면 변경에 따른 성과 오판을 방지한다.

## 오늘의 판단

2026-09-16 예정된 `ADVoost 플레이스(Beta)`를 바로 켜는 것보다 먼저 **SmartPlace Source-of-Truth 점검 + 2026-09-12~15 사전 기준선 확보 + 자동/수동 비교용 Holdout 설계**가 우선이다.

네이버 공식 운영팁에 따르면 ADVoost 플레이스는 기존 플레이스검색광고 내부의 자동 운영 기능이며, 광고주가 하루 예산과 요일/시간대만 설정하면 입찰가, 지역·성별·연령대 타겟팅, 노출 매체, 광고 소재를 시스템이 자동으로 결정한다. 광고 소재는 스마트플레이스의 사진·업체명·업체 소개·일부 혜택 정보를 재료로 생성된다.

따라서 파이널유도멀티짐은 `광고 소재를 먼저 만드는 것`보다 `광고가 가져갈 원천정보가 사실인지`를 먼저 확인해야 한다. 특히 본관의 정확한 위치·층·체험 가능시간·대상·도복/준비물·비용·예약경로가 확인되지 않은 상태에서 자동 운영을 켜면 잘못된 정보가 자동 소재에 반영될 수 있다.

또한 네이버는 2026-09-10부터 플레이스광고 노출 위치를 변경했다. 모바일 통합검색에서는 첫 화면 광고가 1개 늘고 더보기 이후 광고가 3개에서 2개로 조정됐으며, PC도 1페이지 마지막 슬롯 광고가 1개 늘고 2페이지 광고가 3개에서 2개로 조정됐다. 전체 최대 광고 개수와 과금 기준은 유지된다. 이 지면 변화가 이미 적용된 상태이므로 9/10 이전 성과와 9/16 이후 ADVoost 성과를 단순 비교하면 자동화 효과와 지면 재배치 효과가 섞일 수 있다.

## 발견한 변화

### 1. 9월 16일 ADVoost 플레이스 광고주센터 우선 오픈 예정

네이버 광고주센터 공식 운영팁(2026-09-09)은 ADVoost 플레이스를 `새 광고상품`이 아니라 기존 플레이스검색광고 광고그룹별 자동 운영 기능이라고 설명한다.

자동 운영이 맡는 항목:
- 입찰가
- 지역 타겟팅
- 성별·연령대 타겟팅
- 노출 매체
- 스마트플레이스 정보 기반 광고 소재

광고주가 직접 설정하는 핵심 항목:
- 하루 예산
- 요일/시간대

기존 수동 광고그룹에 자동 운영을 적용해도 기존 입찰가·타겟팅 값은 저장되며 다시 수동 운영으로 돌리면 이전 값이 복원된다고 네이버가 안내한다.

### 2. 스마트플레이스가 자동 소재의 원천 데이터가 됨

네이버 공식 안내에서 업체 이미지 최소 1장은 광고그룹 생성·저장을 위한 필수 조건이다. 등록된 사진은 자동 광고 이미지의 재료가 되고, 업체명·업체 소개는 자동 광고 문구 생성에 쓰인다. 예약 혜택·쿠폰 등 부가정보도 조건에 따라 광고에 함께 표시될 수 있다.

파이널유도 적용 시 특히 점검할 항목:
- 지점 공식명
- 실제 고객 출입 주소·층·입구
- 실제 체험 가능한 대상과 시간
- 체험비·등록비 등 공개 가능한 가격정보
- 도복 필요 여부·대여 여부
- 주차·대중교통 안내
- 공식 예약/문의 경로
- 실제 승인된 사진과 설명문

확인되지 않은 `무료체험`, `마감임박`, `마지막 N자리`, `도복 무료`, `승급 가능`, `기업 제휴`, `10% 혜택` 등의 표현은 원천정보에 넣지 않는다.

### 3. 9월 10일 플레이스광고 지면 재배치가 이미 적용됨

네이버 공식 공지(2026-09-03, 적용일 2026-09-10)에 따르면:

- 모바일 통합검색: 첫 화면 광고 1개 추가 / 더보기 이후 3개 → 2개
- PC 통합검색: 1페이지 마지막 슬롯 광고 1개 추가 / 2페이지 3개 → 2개
- 모바일 최대 6개, PC 최대 12개라는 전체 광고 개수는 유지
- 광고 등록·랭킹·과금 기준은 기존과 동일

따라서 9/16 이후 클릭 변화가 발생해도 ADVoost 자동화만의 효과라고 단정하지 않는다.

### 4. 현재 유도장 사례에서도 `시간표 + 반 구분 + 체험 가능 여부`가 핵심 공개정보로 쓰임

Singapore Judo Club은 2026년 8월부터 적용되는 시간표를 Kids / Adult Beginners / Adult Intermediate / Adult Advance로 분리하고 `Check Class Availability`를 별도 행동으로 제시한다.

Judo Ryu Western Australia는 현재 2026 Term 3 수업기간과 주니어 수업요일·시간을 구체적으로 공개하고 Free Trial 등록 경로를 제공한다.

이 사례는 파이널유도도 무료체험을 해야 한다는 근거가 아니다. 시사점은 자동광고가 읽어갈 공개정보에 `대상·시간·실제 가능 여부`가 명확해야 한다는 점이다.

## 실험 1 — EXP-228 ADVoost Auto vs Manual Holdout

### 가설
동일한 실제 체험 가능 조건에서 ADVoost 자동 운영이 수동 운영 대비 `실방문 1명당 획득비용` 또는 `30일 활성 신규회원 1명당 획득비용`을 개선할 수 있다.

### 비교 원칙
- 동일한 지점
- 동일한 승인 체험정책
- 유사한 요일/시간대
- 동일한 귀속 기준
- 자동/수동 광고그룹을 성과 리포트에서 구분

같은 검색 트래픽을 완전히 무작위 분할할 수 없다면 정식 A/B 테스트라고 표현하지 않고 `controlled holdout comparison`으로 기록한다.

### 핵심 KPI
- CPC
- 유효문의율
- 문의→예약
- 예약→실방문
- 실방문→14일 등록
- 등록→30일 활성
- 광고비 / 실방문
- 광고비 / 30일 활성 신규회원
- 기존회원 과밀·불편 건수

### 성공 기준
대표가 사전에 승인한 `실방문당 허용 획득비용` 또는 `30일 활성 신규회원당 허용 획득비용` 안에서 자동 운영이 수동 기준선을 악화시키지 않고, 잘못된 소재·과예약·기존회원 수업품질 악화가 없을 때 확대를 검토한다.

기준 금액과 최소 개선폭은 현재 **데이터 미연결**이다.

### 중단 기준
- 스마트플레이스의 오래된 정보가 자동 소재에 반영됨
- 실제 체험 불가능 시간·대상으로 문의가 집중됨
- 예산 소진 속도가 승인 범위를 벗어남
- 실방문 없이 클릭만 증가
- 안전정원 초과 또는 기존회원 수업품질 악화

## 실험 2 — EXP-229 SmartPlace Source QA Impact

### 가설
정확한 위치·시간·대상·첫 방문 정보를 원천 프로필에 정리하면 광고 방식과 무관하게 반복문의와 잘못된 예약을 줄일 수 있다.

- 시간 재확인 문의
- 잘못된 반 예약
- 예약→실방문
- 고객 오인/정정 건수

성과 기준선과 최소 개선폭은 **데이터 미연결**이다.
