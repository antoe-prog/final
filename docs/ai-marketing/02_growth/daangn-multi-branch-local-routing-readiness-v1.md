# 당근 다지점 로컬 라우팅 준비안 v1

- 작성 기준일: 2026-09-11
- 상태: 전략·계측 설계 완료 / 광고 미집행 / 계정·프로필 변경 없음
- 목표: 신규 체험회원 확보, 지점별 로컬 수요 계측, 향후 다지점 광고 운영 준비
- 내부 회원수·매출·전환율·지점별 여석: **데이터 미연결**

## 오늘의 판단

당근은 2026-09-03 전문가모드에 `브랜드 지점 방문 늘리기` 광고 목표를 출시했다. 공식 설명상 최소 10개 이상의 지점을 보유한 프랜차이즈·다점포 브랜드를 대상으로, 본사 단일 캠페인에서 여러 지점을 운영하고 광고 클릭 사용자를 위치 기준으로 인근 지점의 비즈프로필에 자동 연결한다. 행정구역뿐 아니라 도보시간·차도거리 기준의 지역 범위 타겟팅을 지원하고 지점별 성과를 본사 계정에서 볼 수 있다.

파이널유도멀티짐이 현재 이 상품의 `최소 10개 지점` 요건을 충족하는지는 **데이터 미연결**이다. 따라서 이번 문서는 광고 집행안이 아니라, 지금부터 지점별 로컬 수요·여석·전환 데이터를 같은 구조로 쌓아 향후 요건 충족 시 바로 비교 가능한 상태를 만드는 준비안이다.

## 발견한 변화

### 1. 다지점 광고가 `행정구역`이 아니라 실제 방문거리 기준으로 이동

당근은 광고 클릭 사용자를 방문 가능한 인근 지점으로 연결하고, 도보 20분·차량 3km와 같은 실제 이동거리 기준 설정을 예시로 든다. 파이널유도는 임의의 반경을 그대로 복제하지 않고, 각 지점의 실제 유입지역과 통학·통근 패턴을 내부 데이터로 확인한 뒤 범위를 정해야 한다.

### 2. 본사 공통 메시지와 지점별 성과를 동시에 관리할 수 있는 구조 등장

공식 안내에 따르면 본사 브랜드프로필에 공통 소식을 올려 연결된 지점에 동일하게 반영하고, 전체·지점별 예산 및 성과를 관리할 수 있다. 파이널유도에도 `본사 공통 브랜드 메시지`와 `지점별 여석·시간표·현장정보`를 분리하는 콘텐츠 구조가 필요하다.

### 3. 당근 비즈프로필 자체도 데이터 기반 관리 기능을 강화

2026-05-29 당근은 비즈프로필 관리자 홈에 방문자 수, 단골 현황, 소식 반응률, 고객 문의와 함께 검색어·방문경로를 활용한 지능형 가이드를 강화했다고 발표했다. 유료 광고 집행 전에도 각 지점의 비즈프로필 데이터를 같은 방식으로 수집하는 것이 우선이다.

### 4. 당근-토스플레이스 연동은 `토스페이먼츠 PG`와 같은 개념이 아님

2026-08-13 발표된 연동은 토스플레이스 가맹점·POS·토스 프론트 단말기와 당근 비즈프로필·주문·결제를 연결하는 계획이다. 토스페이먼츠 PG를 사용한다는 사실만으로 이 연동 대상이라고 볼 수 없다. 파이널유도의 `PG사`, `POS`, `당근 비즈프로필`, `지점 정산계정`은 별도 필드로 관리해야 한다.

## 즉시 실행 3개

### 1. Branch Local Demand Schema

각 지점 내부 시스템에 아래 필드를 분리한다.

- `branch_id`
- `branch_name_public`
- `daangn_bizprofile_id`
- `naver_place_id`
- `local_service_area_observed`
- `safe_capacity_by_class`
- `trial_seats_available`
- `local_profile_visits`
- `local_inquiries`
- `trial_reservations`
- `verified_trial_attendance`
- `first_paid_14d`
- `active_30d`
- `renewal`
- `attributable_revenue`
- `ad_spend`
- `toss_place_connected`
- `payment_pg_provider`

회원·보호자 식별정보와 개인별 출석·결제 원장은 공개 저장소에 넣지 않는다.

### 2. 본사 공통 / 지점 로컬 콘텐츠를 분리

본사 공통: 브랜드 철학, 초보 안내 원칙, 안전·예절, 공통 행사 설명.

지점 로컬: 실제 주소·층·입구, 지점별 시간표, 실제 체험 가능석, 담당코치, 지역 FAQ, 지점별 문의경로.

실제 여석이 다른데 모든 지점에 같은 `마감 임박`, `체험 가능`, `무료` 문구를 일괄 배포하지 않는다.

### 3. 광고 자격 전 `Organic Branch Benchmark` 확보

유료 다지점 광고를 검토하기 전에 최소한 동일 기간 기준으로 지점별 `비즈프로필 방문 → 문의 → 예약 → 실제 방문 → 등록 → 30일 활성`을 기록한다. 지점 수 요건을 충족하더라도 기준선 없이 유료 캠페인을 시작하면 지점별 증분효과를 구분하기 어렵다.

## 실험

### EXP-199 Branch-Level Local Content Benchmark

가설: 본사 공통 소개만 사용하는 것보다 실제 지점 시간표·위치·대상·체험가능정보를 확인해 제공한 지점 콘텐츠가 로컬 문의의 질을 높일 수 있다.

- 주 KPI: `비즈프로필 방문 → 유효문의 → 예약 → 실방문`
- 하단 KPI: `실방문 → 14일 내 등록 → 30일 활성`
- 안전지표: 위치·시간 오안내, 과밀, 중복문의, 기존회원 불편
- 성공: 사전 정의한 최소개선폭 충족 + 하단 퍼널 악화 없음
- 중단: 실제와 다른 여석·시간·혜택 게시 또는 과밀 발생

기준선·최소개선폭·표본수는 **데이터 미연결**이다.

### EXP-200 Multi-Branch Routing Readiness Gate

`최소 10개 지점`, 지점별 비즈프로필, 실제 여석, 전환계측, 광고비 상한, 지점별 예산 책임이 모두 확인되었을 때만 당근의 다지점 광고 상품 검토 상태를 `READY_FOR_REVIEW`로 전환한다. 하나라도 미확인인 경우 광고 집행 상태는 `NOT_READY`다.

이는 실제 광고 실험이 아니라 집행 전 자격·데이터 게이트다.

## Auditor

- 당근의 바른치킨 사례는 당근이 공개한 광고주 성공사례이며 파이널유도의 예상 성과로 환산하지 않는다.
- `총 주문 500% 증가` 같은 F&B 결과를 체육시설의 체험·등록 전환율 예측에 사용하지 않는다.
- 최소 10개 지점 요건을 충족한다고 확인되기 전에는 상품 사용 가능하다고 표현하지 않는다.
- 토스페이먼츠 PG와 토스플레이스 POS를 같은 서비스로 취급하지 않는다.
- 광고비 지원·캐시백이 존재하더라도 대표 승인 전 비용 집행을 하지 않는다.
