# 당근 Local Audience Intent Routing v1

- 작성 기준일: 2026-09-13
- 상태: 전략·계측 설계 완료 / 게시·쿠폰·광고·고객발송 미실행
- 목표: 신규 체험회원 확보, 휴면회원 복귀, 기존회원 재등록·만족, 매출 증대
- 내부 회원수·매출·전환율·당근 채널 성과: **데이터 미연결**

## 오늘의 판단

파이널유도멀티짐의 당근 운영에서 다음 우선순위는 `단골 수` 자체를 늘리는 것이 아니라, 비즈프로필에 들어온 지역 관심을 `첫 체험 / 다시 시작 / 기존회원 문의`로 자발적으로 분기시켜 실제 예약·실방문·30일 활성까지 연결하는 것이다.

당근은 2026-05-29 비즈프로필 관리자 홈을 전면 개편해 방문자 수, 단골 현황, 소식 반응률, 고객 문의, 방문 경로와 검색어를 한 화면에서 볼 수 있도록 했다. 공식 페이지에서도 비즈프로필이 소식, 채팅, 쿠폰, 단골 관리 기능을 제공한다고 안내한다. 따라서 유료 광고 이전에도 로컬 관심층의 `프로필 방문 → 소식 반응 → 문의 → 예약 → 실방문`을 계측할 수 있는 기반이 있다.

다만 `당근 단골 = 기존회원`, `당근 단골 = 휴면회원`, `프로필 방문자 = 신규리드`로 취급하면 안 된다. 플랫폼의 단골·방문자는 로컬 관심층일 뿐이며, 회원상태는 본인이 문의·예약 과정에서 스스로 목적을 선택한 경우에만 분류한다.

## 발견한 변화

### 1. 당근 비즈프로필이 단순 가게 페이지에서 데이터 기반 로컬 CRM 보조도구로 확장

당근 공식 발표 기준으로 2026-05-29 개편된 관리자 홈은 방문자 수, 단골 현황, 소식 반응률, 고객 문의, 방문 경로, 검색어를 제공한다. 또한 비즈프로필 데이터에 따라 소식 발행·쿠폰 등의 운영 가이드를 제안한다.

이 변화는 파이널유도가 당근에서 `단골 숫자`만 볼 것이 아니라 `어떤 로컬 정보가 문의와 실제 방문을 만드는지`를 채널 내부 데이터와 자체 퍼널 데이터로 연결해야 한다는 의미다.

### 2. 당근 비즈프로필 단골 규모 자체가 커졌지만, 이를 파이널유도 성과로 전용할 수는 없음

당근은 2026-06-04 비즈프로필을 통해 지역 가게와 연결된 누적 단골 수가 1,000만 규모에 도달했다고 발표했다. 이는 로컬 비즈프로필 생태계가 커졌다는 플랫폼 신호이지, 파이널유도의 예상 단골 수·전환율 근거가 아니다.

### 3. 강서구 운동시설의 당근 오퍼 경쟁은 이미 강함

2026-09-13 확인 기준, 강서구 마곡의 F45마곡 당근 비즈프로필은 강서구 주민 대상 1회 무료체험 공지와 5회 체험권 할인 정보를 노출하고 있다.

강서구 방화동의 무지개유도관은 당근에서 유도복·띠 증정 쿠폰과 회비 할인, 입관 혜택을 함께 노출하며 마지막 수정일이 2026-09-04로 표시된다.

강서구 화곡동의 용인대강서유도관도 가격·시설·후기·문의정보를 비즈프로필에 공개하고 있다.

따라서 파이널유도가 당근에서 신규 고객을 확보하기 위해 반드시 더 큰 할인·증정을 해야 한다는 결론은 성립하지 않는다. 오히려 `초보 가능 시간`, `실제 체험 가능석`, `준비물`, `첫 수업에서 배우는 내용`, `다시 시작 가능한 반` 같은 이용확실성 정보를 통해 차별화할 수 있는지 먼저 검증한다.

## 역할별 실행 원칙

### CMO

- 당근의 목표를 `단골 수 최대화`가 아니라 `지역 관심 → 의도분류 → 실제 방문 → 30일 활성`으로 정의한다.
- 할인전쟁에 바로 참여하지 않는다.
- 유료 광고는 유기적 프로필·소식·문의 기준선이 확보된 뒤 별도 승인 대상으로 둔다.

### Growth Analyst

기본 퍼널을 다음처럼 정의한다.

`profile_visit → content_engagement → inquiry → intent_self_selected → slot_offered → booking_confirmed → verified_attendance → paid_14d → active_30d → renewal`

의도 분류는 고객이 직접 선택한 경우만 기록한다.

- `NEW_TRIAL`: 처음 체험
- `RETURNER`: 과거 이용 후 다시 시작하고 싶다고 본인이 표시
- `EXISTING_MEMBER`: 현재 회원 문의라고 본인이 표시
- `UNKNOWN`: 분류되지 않음

당근 `단골` 상태만으로 위 값을 추정하지 않는다.

### Acquisition Marketer

신규 체험용 콘텐츠는 할인보다 다음 정보를 우선 테스트한다.

- 초보자가 가능한 실제 시간
- 체험 가능 대상
- 첫 수업에서 배우는 내용
- 준비물
- 주차·입구·샤워 등 실제 이용정보
- 체험 후 다음 선택지

`무료`, `마감임박`, `잔여 1석`은 실제 정책·여석 확인 전 사용하지 않는다.

### CRM Marketer

당근의 단골·프로필 방문자를 내부 휴면회원 명단과 임의 매칭하지 않는다.

다시 시작하려는 사용자가 스스로 `RETURNER`를 선택했을 때만 복귀 퍼널로 이동한다.

기존회원 문의도 플랫폼 공개지표에서 개인 회원상태를 추정하지 않고, 본인의 자발적 식별 이후 내부 채널로 안전하게 전환한다.

### Content Strategist

당근 소식 콘텐츠는 다음 세 축으로 분리한다.

1. **처음 시작**: 초보 첫 수업, 낙법·기본동작, 체험 가능한 실제 시간
2. **다시 시작**: 오랜만에 복귀할 때 준비사항, 수준 재적응 방식, 가능한 시간
3. **현재 회원 정보**: 휴관·행사·시간표 등 공개 가능한 운영정보

하나의 소식에서 세 집단을 모두 가격혜택으로 묶지 않는다.

- `profile_visitors`
- `followers_or_regulars`
- `post_views`
- `post_engagement`
- `inquiries`
- `search_terms_available`
- `visit_sources_available`
- `trial_reservations`
- `verified_trial_attendance`
- `paid_14d`
- `active_30d`
- `renewal`
- `attributable_revenue`

개별 이용자 이름·닉네임·전화번호·개인별 출석·결제 원장은 공개 저장소에 기록하지 않는다.

### 2. Intent Self-Selection Entry

당근 문의 후 고객이 스스로 선택할 수 있는 최소 분기를 준비한다.

- 처음 체험
- 다시 시작
- 기존회원 문의
- 기타

실제 메시지·자동응답·폼 변경은 대표 승인 전 실행하지 않는다.

### 3. Utility-First Content Queue

첫 파일럿 콘텐츠 후보는 다음 순서로 준비한다.

1. `처음 유도 체험할 때 필요한 준비물과 첫 수업 흐름`
2. `강서구에서 퇴근 후 가능한 성인 초보 시간 — 실제 시간표 확인 후 게시`
3. `오랜만에 유도를 다시 시작할 때 강도를 어떻게 맞추는가`

각 게시물은 실제 지점·시간·체험석 확인 후에만 게시한다.

## 실험

### EXP-265 Utility Post vs Incentive-Led Post

**가설**: 큰 할인보다 실제 이용정보를 제공하는 소식이 질 높은 문의·실방문을 만들 수 있다.

- A: 초보 수업·준비물·시간 중심 정보형
- B: 승인된 혜택이 있을 경우 혜택 중심형
- 1차 KPI: `post_view → inquiry`
- 2차 KPI: `inquiry → booking → verified_attendance`
- 하단 KPI: `paid_14d → active_30d`
- 안전지표: 가격 혼선, 허위 희소성, 과밀, 반복문의
- 중단: 정보형/혜택형 어느 쪽이든 실방문·30일 활성 개선 없이 할인비용이나 운영부담만 증가

할인금액·최소개선폭·필요 표본수는 **데이터 미연결**이다.

### EXP-266 Intent Self-Selection Routing

**가설**: 문의자가 `처음 체험 / 다시 시작 / 기존회원 문의`를 스스로 선택하면 상담 분류시간과 잘못된 안내를 줄일 수 있다.

- KPI: 분류완료율, 첫 유효응답시간, 슬롯 제안률, 예약률, 실방문률
- 성공: 분류 정확성 개선 + 하단 퍼널 악화 없음
- 중단: 질문 증가로 문의 포기율이 높아지거나 민감정보 과수집이 발생

### EXP-267 Follower Quality, Not Follower Count

`단골 증가`를 단독 성공지표로 사용하지 않는다.

- 관찰: 단골 증감, 소식 반응, 문의, 예약, 실방문
- 성공: 단골/반응 변화가 실제 문의·실방문·30일 활성의 개선과 함께 나타남
- 중단: 단골 숫자만 증가하고 하단 퍼널 변화가 없음

## 필요한 대표 승인·입력

- 본관 및 각 지점의 공식 당근 비즈프로필 URL 또는 관리자 접근 여부
- 지점별 당근 관리자 홈의 비식별 집계값
- 실제 체험 가능 시간과 `trial_capacity`
- 현재 당근 쿠폰·체험혜택 존재 여부
- 신규/복귀/기존회원 문의를 어느 내부 채널로 넘길지
- 업무시간 내 당근 채팅 응답 담당자
- 혜택형 실험을 할 경우 할인·증정 비용 상한

모든 값이 확인되기 전까지 관련 KPI는 **데이터 미연결**이다.

## Auditor

- `당근 단골 = 실제 회원`으로 해석하지 않는다.
- `프로필 방문 = 신규 리드`로 계산하지 않는다.
- 당근 사용자와 내부 회원 DB를 전화번호·이름 등으로 임의 매칭하지 않는다.
- 경쟁 도장의 할인·유도복 증정을 그대로 복제하지 않는다.
- F45마곡, 무지개유도관, 용인대강서유도관의 공개 프로필은 시장 관찰 사례이며 성과 비교의 근거가 아니다.
- 공개 소식에는 실제 지점·시간·정원과 다른 정보를 사용하지 않는다.
- 회원·보호자의 개인별 출석·건강·결제·연락처를 공개 저장소에 기록하지 않는다.
- 광고, 할인, 쿠폰, 고객발송, 계정변경은 대표 승인 없이는 실행하지 않는다.
