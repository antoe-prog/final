# Local Presence Consistency Audit v1

- 기준일: 2026-09-11
- 상태: 공개 웹 감사 완료 / 실제 플랫폼 수정 전 / 내부 성과 데이터 미연결
- 목표: 신규 체험 유입의 길찾기·영업시간·도착정보 마찰을 줄이고, 지역 캠페인 집행 전에 공개 업체정보의 기준점을 확정한다.

## 오늘의 판단

신규 광고·이벤트 노출을 더 늘리기 전에 본관의 공개 업체정보를 하나의 `Canonical Location Card`로 맞추는 것이 우선이다. 현재 공개 웹에서는 본관의 도로명 주소 자체는 대체로 일치하지만 층 표기와 영업시간 표현이 채널별로 다르게 관찰된다. 이것이 실제 예약 취소·노쇼·매출 손실을 일으켰다는 내부 증거는 없으므로 효과는 **데이터 미연결**로 둔다.

## 공개 웹에서 확인한 차이

### 1. Google 공개 업체정보
- 파이널유도멀티짐 본관: 서울 강서구 화곡동 등촌로 17, 3층으로 표시됨.
- 구조화 결과에서 평일 10:30~23:00과 일요일 11:00~13:00 등이 표시되며, 토요일은 같은 결과에 명시되지 않았다. 명시되지 않은 요일을 임의로 휴무라고 해석하지 않는다.
- 확인일: 2026-09-11.

### 2. 서울특별시유도회
- `파이널유도멀티짐`을 강서구 등촌로 17(화곡동)으로 등록하고 있다.
- 해당 공개 상세에는 층 정보가 표시되지 않는다.
- 확인일: 2026-09-11.

### 3. 제3자 체육시설 디렉터리
- 일부 공개 디렉터리는 같은 브랜드·주소를 `등촌로 17 지층, 3층`으로 표기하고 평일 10:30~23:00 영업시간을 표시한다.
- 제3자 데이터는 최신성·정확성이 보장되지 않으므로 실제 운영정보의 기준으로 사용하지 않는다.

### 감사 결론

현재 공개 웹만으로 `정확한 고객 진입층`, `주말 운영시간`, `대표 문의경로`를 확정하지 않는다. 운영자가 확인한 실제 값이 기준이어야 하며, 그 값과 다른 공개 채널만 수정 대상으로 분류한다.

## 발견한 외부 변화

네이버 스마트플레이스는 영업시간·휴무일·홈페이지 같은 일부 부가정보는 수정 후 바로 반영될 수 있고 검색 반영에는 최대 1일이 걸릴 수 있다고 안내한다. 업체명·전화번호·주소·대표키워드 같은 기본정보는 운영자 검토가 필요하며 최대 영업일 5일이 걸릴 수 있다. 네이버 지도 내비게이션은 스마트플레이스에 입력된 영업시간·주차정보를 목적지 안내에 활용한다고 안내한다.

Google Business Profile API 문서도 위치에는 정밀하고 정확한 주소를 사용하고, 카테고리는 핵심 사업을 정확히 설명하는 최소한의 범위로 유지하도록 안내한다.

지역 수요 측면에서는 강서구가 2026-09-12 허준근린공원에서 가족·이웃 대상 체험부스가 포함된 `허준 인트로축제`를 열고, 2026-09-19에는 마곡미술길에서 가족 단위 참여가 가능한 `누구나 아티스트 페스티벌`이 예정돼 있다. 이 일정이 본관 방문이나 검색량을 증가시킨다는 데이터는 없다. 다만 지역 콘텐츠를 집행한다면 잘못된 길찾기·영업시간 정보가 없는 상태가 선행조건이다.

## 즉시 실행 3개

### 1. Canonical Location Card 확정
내부 기준값을 다음 8개 필드로 고정한다.

- 지점 공식명
- 실제 고객 출입 주소
- 건물명·층·출입구 설명
- 대표 전화/문의 경로
- 요일별 실제 수업·상담 가능시간
- 정기휴무·공휴일 정책
- 주차 가능 여부와 실제 안내
- 신규 체험 예약 링크 또는 문의 경로

값이 확인되기 전에는 공개 채널을 수정하지 않는다.

### 2. 채널별 일치성 매트릭스
`네이버 / Google / 서울특별시유도회 / 당근 비즈프로필 / 공식 사이트·블로그 / 주요 제3자 디렉터리`를 행으로 두고 위 8개 필드를 비교한다.

분류는 `MATCH / STALE / MISSING / UNKNOWN / CANNOT_EDIT` 다섯 상태로 통일한다. 제3자 사이트는 수정권한이 없을 수 있으므로 무리하게 정정 완료로 기록하지 않는다.

### 3. 지역 캠페인 전 Location Gate
네이버·인스타그램·당근에서 지역 행사와 연계한 콘텐츠나 체험 모집을 승인하기 전에 최소한 다음 항목이 일치하는지 확인한다.

`지점명 / 주소 / 층·입구 / 운영시간 / 문의경로 / 체험 가능시간`

허준 인트로축제나 마곡미술길 행사와 공식 제휴·후원 관계가 확인되지 않은 상태에서 행사명·로고를 사용해 공식 파트너처럼 표현하지 않는다.

## 실험 — EXP-196 Route-Ready Profile

### 가설
정확한 층·입구·운영시간·문의경로가 주요 프로필에 일치하면 첫 방문 단계의 길찾기 질문과 도착 실패를 줄일 수 있다.

### 사전 관찰기간
수정 전 동일 기간 동안 다음을 집계한다.
- 위치·층·입구 관련 문의 수
- 운영시간 재확인 문의 수
- 예약 후 `장소를 못 찾음`으로 확인된 불참 수
- 지도/플레이스 유입 → 예약 → 현장 확인 실방문

현재 기준값은 **데이터 미연결**이다.

### 개입
대표가 실제 기준정보를 승인한 뒤 수정 가능한 공식·주요 채널만 일치시킨다. 제3자 목록의 수정 불가 항목은 별도로 기록한다.

### 성공 판단
같은 길이의 후속 관찰기간에서 위치·시간 관련 고객 마찰이 감소하고 예약→실방문이 악화되지 않을 때 운영 표준으로 유지한다. 계절성·광고·행사 영향이 동시에 발생하면 인과효과로 단정하지 않는다.

### 즉시 중단·롤백 조건
- 실제 주소·층·운영시간과 다른 정보 게시
- 지도 핀 오류 또는 기존 정상 프로필 훼손
- 신규 체험이 불가능한 시간대를 영업·체험 가능시간처럼 표시
- 제3자 데이터만 보고 공식 프로필을 변경

## KPI 상태

- 공개 채널별 불일치 수: 데이터 미연결
- 위치·층·입구 문의 수: 데이터 미연결
- 운영시간 재확인 문의 수: 데이터 미연결
- 장소 찾기 실패 확인 노쇼: 데이터 미연결
- 플레이스/지도 → 예약: 데이터 미연결
- 예약 → 현장 실방문: 데이터 미연결
- 실방문 → 유료등록: 데이터 미연결
- 30일 활성·재등록·매출: 데이터 미연결

## 필요한 대표 승인·입력

- 본관의 실제 고객 출입층과 입구 설명
- 현재 주말·공휴일 실제 운영시간
- 대표 문의 번호 또는 채널
- 주차 안내
- 체험 예약의 공식 경로
- 네이버·Google·당근 등 각 프로필의 수정 권한과 현재 관리자 화면 값

실제 플랫폼 정보 수정, 계정 변경, 콘텐츠 게시, 고객 연락, 광고 집행은 별도 승인 없이 수행하지 않는다.

## Auditor

1. `공개 정보가 다르다`와 `한쪽이 틀렸다`를 구분한다. 실제 운영값을 확인하기 전에는 잘못된 채널을 확정하지 않는다.
2. 주소·전화번호·영업시간 일치가 검색순위를 높인다고 보장하지 않는다. 이번 목적은 고객 도착정보의 신뢰성과 마찰 감소다.
3. 지역 축제 일정과 본관 방문 증가 사이의 인과관계를 주장하지 않는다.
4. 개인 연락처·회원정보·예약 원장을 공개 저장소에 넣지 않는다.
