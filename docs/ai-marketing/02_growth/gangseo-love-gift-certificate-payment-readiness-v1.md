# 강서사랑상품권 결제 준비안 v1

- 작성일: 2026-09-11
- 상태: **설계 완료 / 가맹 상태·실제 결제 가능 여부 미확인 / 외부 홍보·고객 발송·가격 변경 미실행**
- 목적: 파이널유도멀티짐 본관의 신규 체험→등록, 휴면 복귀, 기존회원 재등록 과정에서 결제 마찰을 줄일 수 있는 지역화폐 수용 가능성을 검증한다.

## 1. 시장 변화

2026-09-09 연합뉴스 보도에 따르면 서울 강서구는 추석을 앞두고 **2026-09-16 13:00부터 강서사랑상품권 100억원을 발행**할 예정이다. 보도상 구매 시 5% 할인과 결제액 5% 환급이 적용된다. 월 구매한도는 50만원, 보유한도는 150만원이다.

강서구청의 강서사랑상품권 안내 페이지는 강서구 관내 서울강서사랑상품권 가맹점에서 사용할 수 있고, 구매 시 5% 할인, 연말정산 소득공제 30%, 가맹점 결제 수수료 0%를 안내한다.

서울시는 2026-03-12 기준 서울사랑상품권 가맹점 가입 대상을 서울 소재 사업자등록 사업장으로 안내하고, 제한 업종을 별도로 열거한다. 체육시설이 자동 허용된다고 단정할 수 없으므로 **파이널유도멀티짐의 실제 가맹 승인·결제 가능 상태는 별도 확인**한다.

## 2. CMO 판단

이번 기회는 `할인행사`가 아니라 **결제수단 가시화(payment-option visibility)** 로 접근한다.

파이널유도가 자체 할인율을 낮추거나 쿠폰 비용을 부담하지 않으면서, 실제 가맹점이고 결제가 정상 동작하는 경우 고객에게 지역상품권 사용 가능성을 명확히 안내할 수 있다. 단, 가맹점 등록이 되지 않았거나 결제 테스트가 끝나지 않았다면 어떤 채널에서도 `강서사랑상품권 사용 가능`이라고 홍보하지 않는다.

## 3. 필요한 데이터 및 게이트

공개 저장소에는 아래 상태값만 기록하고 개인별 결제정보는 기록하지 않는다.

- `merchant_registered`: 강서사랑상품권 가맹 여부
- `merchant_status_verified_at`: 관리자/서울Pay+에서 상태를 확인한 시점
- `test_payment_verified`: 실제 소액 테스트 또는 공식 상태 확인 여부
- `settlement_account_verified`: 정산계좌 확인 여부
- `payment_method_exposed`: 네이버/당근/인스타/상담문구 등에 사용 가능 결제수단을 공개했는지
- `payment_method_inquiry_count`: 결제수단 관련 문의 건수(집계값)
- `registration_paid_by_local_currency_count`: 지역상품권 결제 등록 건수(집계값)
- `renewal_paid_by_local_currency_count`: 지역상품권 결제 재등록 건수(집계값)

현재 값은 모두 **데이터 미연결**이다.

## 4. 즉시 실행안

1. 대표 또는 승인된 관리자가 서울Pay+에서 본관 사업자의 강서사랑상품권 가맹 상태를 확인한다.
2. 가맹 상태가 유효한 경우 실제 결제 가능 범위, 정산계좌, 정산주기, 회원권/수강료 결제 가능 여부를 확인한다.
3. 결제 가능성이 검증된 뒤에만 `강서사랑상품권 결제 가능`을 네이버 플레이스, 상담 FAQ, 당근 비즈프로필, 체험 후속 안내의 **결제수단 정보**로 추가하는 안을 검토한다.

## 5. 실험

### EXP-205 Payment-Option Visibility

**가설:** 실제 결제 가능한 지역상품권을 상담 단계에서 명확히 안내하면 가격 할인 없이도 일부 신규·복귀·재등록 고객의 결제 마찰을 줄일 수 있다.

측정:
- 유효문의 → 예약
- 실방문 → 유료등록
- 만료예정 → 재등록
- 결제수단 문의 빈도
- 지역상품권 결제 건수/금액(집계)
- 자체 할인비용 변화

성공판정은 사전에 연결된 내부 기준선을 사용한다. 현재 기준선·최소개선폭·전환율은 **데이터 미연결**이다.

중단조건:
- 가맹 승인 미확인
- 회원권/서비스 결제 가능 여부 불명확
- 실제 결제 실패 또는 정산 오류
- 공공 환급·할인 혜택을 파이널유도 자체 할인으로 오인시키는 문구 발생

### EXP-206 Local-Currency Renewal Window

강서사랑상품권 발행 직후의 결제수단 안내가 만료예정 회원의 재등록에 영향을 주는지 관찰한다. 고객에게 불필요한 추가 영업메시지를 보내는 실험이 아니라, **기존 재등록 안내 안에서 결제수단 정보를 제공하는 방식**을 기본안으로 한다.

## 6. 채널 콘텐츠 방향

- 네이버: `파이널유도멀티짐 결제수단 안내` 형태의 정보성 FAQ. 실제 검증 전 게시 금지.
- 인스타그램: 상품권 구매를 부추기는 콘텐츠보다 `사용 가능한 결제수단` 정보만 사실대로 제공.
- 당근: 지역 주민 대상 게시물에서 실제 결제 가능 시에만 결제수단 태그 또는 안내 문구 사용.
- 상담/CRM: 신규·휴면·만료예정 대상에게 가격할인 대신 `현재 사용 가능한 결제수단`을 정확히 안내.

## 7. Auditor 가드레일

- `총 10% 할인`을 파이널유도 자체 할인처럼 표현하지 않는다.
- 2026-09-16 발행분의 할인·환급 조건은 정책 변경 가능성이 있으므로 실제 고객 안내 시점에 다시 확인한다.
- 상품권 구매를 강요하거나 재등록을 압박하는 방식으로 사용하지 않는다.
- 지역상품권 사용 가능 여부를 확인하기 전에는 광고·게시물·고객 메시지에 사용 가능 문구를 넣지 않는다.
- 회원·보호자 식별정보, 개인별 결제원장, 연락처, 정산계좌번호는 공개 저장소에 기록하지 않는다.
