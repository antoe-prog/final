# Second-Visit Trial Bridge v1

작성일: 2026-09-11 (KST)

## 목적

파이널유도멀티짐의 신규 체험 퍼널에서 `첫 체험 참석`을 곧바로 `가입 여부 결정`으로 처리하지 않고, 운영정책이 허용하는 경우 `두 번째 방문`을 별도의 전환 단계로 관리한다. 이 문서는 공개 가능한 전략·계측 문서이며 실제 무료체험 횟수, 가격, 고객 발송, 예약 변경, 광고 집행을 확정하거나 실행하지 않는다.

## 이번 판단의 근거

- Gymdesk의 2026 Benchmark는 4,594개 활성 체육관(대다수 무도·격투기 시설)의 운영데이터를 분석했다. 175,000건의 실제 무료체험 중 73%가 유료회원으로 전환됐고, 전환의 상당 부분이 초반 2주에 집중됐다. 이는 파이널유도의 예상 전환율이 아니라 외부 운영 벤치마크다.
- 2026-27 시즌에 Victoria Judo Club과 Burnaby Judo Club은 신규자에게 2주 체험을 제공하고, Judo Club Bellevillois는 가입 전에 2회의 체험수업 참여를 권장한다. UC Berkeley의 2026 가을 성인 무도 프로그램도 지정된 체험기간에 최대 2회 방문을 허용한다.
- 위 사례는 `2회가 최적`임을 증명하지 않는다. 다만 여러 유도·무도시설이 첫 방문만으로 가입을 결정시키기보다 짧은 다회 체험구간을 운영하고 있다는 최신 패턴을 보여준다.

## 핵심 퍼널

`lead → trial_1_reserved → trial_1_attended → trial_2_offered → trial_2_reserved → trial_2_attended → paid_within_14d → active_30d → renewal`

필수 집계 필드:

- `trial_1_attended_at`
- `trial_2_offered_at`
- `trial_2_reserved_at`
- `trial_2_attended_at`
- `paid_at`
- `paid_after_visit_number`
- `active_30d`
- `source_channel`
- `class_slot`

개인별 이름·연락처·보호자정보·건강정보·결제원장은 공개 저장소에 저장하지 않는다.

## 운영 설계

### 1. 첫 방문의 목표

첫 방문의 목표를 `즉시 결제` 하나로 두지 않는다. 실제 수업 운영이 허용하는 범위에서 도장 이용방법, 기초 움직임, 낙법 또는 초보자가 참여 가능한 내용, 질문 확인을 제공하고 다음 방문 선택지를 명확히 안내한다.

### 2. 두 번째 방문의 목표

첫날과 동일한 설명을 반복하기보다 실제 수업 흐름을 조금 더 이해할 수 있게 한다. 구체적인 기술·대련·메치기 여부는 실제 코치 정책과 안전기준 확인 후 결정한다. 두 번째 방문 후에도 강압적 결제 유도보다 다음 단계와 비용·시간표를 사실대로 안내한다.

### 3. 체험 후 CRM

기존 `trial-followup-review-v1.md`의 D0/D1/D3 후보를 그대로 중복 발송하지 않는다. 첫 방문 후 이미 두 번째 일정이 예약돼 있으면 추가 영업성 연락을 줄이고 예약 안내에 집중한다. 두 번째 방문을 원하지 않거나 수신거부 의사를 밝힌 경우 후속 연락을 중단한다.

## 채널 콘텐츠

- 네이버: `유도 첫 체험 한 번으로 결정하기 어려운 이유`, `첫 방문과 두 번째 방문에서 확인할 것` 같은 정보형 콘텐츠 후보
- 인스타그램: 첫 방문의 낯섦과 두 번째 방문에서 익숙해지는 과정을 과장 없이 보여주는 짧은 시퀀스 후보
- 당근: 실제 체험정책과 여석이 확정된 경우에만 지역·대상·시간을 포함해 공지. `2회 무료` 여부는 대표 승인 전 사용 금지

## 실험

### EXP-203 Second-Visit Bridge

**가설:** 첫 체험 직후 선택 가능한 두 번째 방문 경로를 제공하면 `첫 체험 → 유료등록 → 30일 활성` 과정의 마찰을 줄일 수 있다.

**주 KPI:**
- trial_1_attended → trial_2_reserved
- trial_2_reserved → trial_2_attended
- trial_1_attended → paid_within_14d
- paid → active_30d

**판정:** 기준선·최소개선폭·표본수는 내부 데이터 연결 후 사전 확정한다. 두 번째 방문이 늘어도 유료등록·30일 활성은 개선되지 않고 코치 부담이나 과밀만 증가하면 확대하지 않는다.

### EXP-204 Book-Next-Visit Timing

첫 체험 종료 시점에 다음 가능시간을 안내하는 방식과, 기존 후속관리 과정에서 다음날 안내하는 방식을 비교할 수 있다. 단, 실제 연락횟수와 채널은 별도 승인한다. 성공은 단순 예약률이 아니라 실제 2회차 참석과 14일 내 등록까지 함께 본다.

## 필요한 대표 승인·입력

- 현재 신규 체험이 1회인지 다회인지, 무료·유료 여부
- 체험 가능한 반과 시간대별 안전정원
- 첫 방문·두 번째 방문에서 허용할 수업범위
- 도복·복장·준비물 정책
- 두 번째 방문 안내를 현장에서 할지 후속 메시지로 할지
- 기준선: 첫 체험 참석, 등록, 30일 활성의 비식별 집계

## KPI 상태

첫 체험 예약 수 **데이터 미연결** / 첫 체험 실방문률 **데이터 미연결** / 2회차 제안률 **데이터 미연결** / 2회차 예약률 **데이터 미연결** / 2회차 실방문률 **데이터 미연결** / 14일 내 유료등록률 **데이터 미연결** / 30일 활성률 **데이터 미연결** / 재등록률 **데이터 미연결** / 코치 추가 처리시간 **데이터 미연결** / 귀속매출 **데이터 미연결**.

## Auditor 기준

- 외부 체육관의 73% 전환율을 파이널유도 예상치로 사용하지 않는다.
- `2회 체험이 1회보다 무조건 효과적`이라고 주장하지 않는다.
- 무료체험, 할인, 도복대여, 대련 제외 등 실제 확정되지 않은 혜택을 콘텐츠에 넣지 않는다.
- 기존 체험 후속관리 문안과 중복 연락하지 않는다.
- 미성년자는 보호자 동의·연락정책을 별도로 따른다.
