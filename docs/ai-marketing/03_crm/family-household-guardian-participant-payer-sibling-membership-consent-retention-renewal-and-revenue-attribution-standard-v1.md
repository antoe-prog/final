# 가족·가구·보호자·참여자·결제자·형제자매 회원권·동의·유지·재등록·매출 귀속 기준 v1

- 문서 상태: 공개 운영 기준
- 작성일: 2026-09-20
- 적용 대상: 파이널유도멀티짐의 가족 문의, 유소년·성인 가족 등록, 형제자매 등록, 가족 공유 회원권, 개인 회원권, 체험, 출석, 결제, CRM, 채널 성과
- 제외 대상: 실제 회원·보호자 이름, 연락처, 생년월일, 가족관계 자료, 출석·건강·결제 원장, 내부 가격·예산, 미확정 행사
- 핵심 원칙: **사람, 가족관계, 연락 권한, 계약, 이용권한, 출석, 결제, 매출을 서로 다른 사실로 기록한다.**

## 1. 목적

가족 단위 등록에서는 다음 항목이 한 화면이나 한 결제에 함께 나타날 수 있다.

- 수련에 참여하는 사람
- 법정대리인 또는 승인된 보호자
- 서비스 안내를 받을 연락 담당자
- 실제 결제자
- 같은 가구의 형제자매
- 가족 공유 회원권
- 개인별 회원권과 수업 이용권한
- 한 번의 청구·결제·환불

이를 한 사람 또는 한 성과로 합치면 다음 오류가 생긴다.

- 한 가구 문의를 여러 신규 문의로 중복 계산
- 한 번의 가족 결제를 형제자매 각자의 매출로 중복 계산
- 결제자를 실제 수련 참여자로 계산
- 보호자 또는 비상연락처를 광고 수신 동의자로 간주
- 형제자매 추가를 신규 가구 획득과 추천 성과에 동시에 귀속
- 가족 공유 회원권만 보고 모든 가족에게 출석·예약 권한 부여
- 보호자 변경·권한 철회 뒤에도 이전 연락처에 안내 발송
- 미성년자에게 승인되지 않은 직접 마케팅 후보 생성

이 문서는 신규 체험, 휴면 복귀, 기존회원 만족·재등록, 순수납 매출을 정확히 연결하기 위한 최소 기준이다.

## 2. 역할을 분리한다

한 사람이 여러 역할을 가질 수 있지만 역할별 근거와 유효기간은 따로 관리한다.

| 역할 | 의미 | 그 역할만으로 증명되지 않는 것 |
|---|---|---|
| 참여자 | 체험·수업·행사에 실제 참여할 사람 | 보호자 권한, 결제 책임, 마케팅 동의 |
| 법정대리인 | 관계와 권한이 확인된 대리인 | 결제 완료, 광고 수신 동의 |
| 승인 보호자 | 내부 기준에 따라 특정 안내·인계 권한이 확인된 사람 | 법정대리인 지위, 모든 계약 권한 |
| 서비스 연락 담당자 | 일정·준비물·계약 이행 안내 수신자 | 광고 수신 동의, 결제 책임 |
| 결제자 | 청구 또는 결제를 담당하는 사람 | 실제 참여, 보호자 권한, 재등록 의사 |
| 가구 관리자 | 가족 계정 관리 권한이 있는 사람 | 모든 가족 구성원의 개별 동의 |
| 비상연락 대상 | 사고·응급 시 연락할 사람 | 일상 서비스 연락·광고 수신 동의 |
| 마케팅 수신자 | 채널·목적·기간별 광고성 정보 동의가 유효한 사람 | 보호자 권한, 계약·결제 완료 |

### 2.1 관계 상태

각 관계는 최소 다음 상태를 가진다.

- 요청됨
- 근거 확인 대기
- 유효
- 변경 요청
- 철회 또는 종료
- 분쟁·확인 보류

이름이 가족 계정에 있다는 이유만으로 권한이 유효하다고 판단하지 않는다.

## 4. 가족 공유 회원권과 개인 회원권

Gymdesk는 한 사람에게 부여하는 회원권과 가족 계정 전체에 배정하는 가족 공유 회원권을 구분한다. 가족 공유 회원권은 가족 전체의 접근을 설정하고 한 번의 결제를 받을 수 있지만, 개인 회원권은 가족 구성원별 이용권한을 더 세밀하게 통제할 수 있다.

따라서 내부 운영에서는 다음을 구분한다.

### 4.1 가족 공유 회원권

- 계약 수: 가족 계약 기준
- 결제 수: 실제 거래 기준
- 활성 참여자 수: 권한이 부여된 개인 기준
- 실제 참여: 개인별 출석 확인 기준
- 매출: 한 결제를 한 번만 순수납에 반영
- 가족 구성원 추가·제거: 계약 변경과 개인 권한 변경을 분리

### 4.2 개인 회원권

- 가족 계정 안에서도 개인별 계약·권한·기간을 따로 관리
- 가족 할인은 가격 규칙이며 실제 참여나 유지의 증거가 아님
- 형제자매 할인 적용은 신규 가구 획득과 별도
- 한 결제자가 여러 개인 회원권을 납부해도 매출은 거래·청구 기준으로 합산

### 4.3 접근권한

회원권이 존재해도 다음을 별도로 확인한다.

- 어느 참여자에게 권한이 부여됐는가
- 어느 지점·프로그램·회차를 이용할 수 있는가
- 시작일·종료일·휴회·제한이 무엇인가
- 가족 구성원 변경이 권한 명단에 반영됐는가

가족관계만으로 자동 출석·예약 권한을 만들지 않는다.

## 5. 동의와 연락 권한

### 5.1 동의 목적을 분리한다

- 개인정보 수집·이용
- 계약 체결 또는 변경
- 체험·수업 참여
- 서비스 안내
- 광고성 정보
- 촬영·공개
- 비상연락·안전 인계
- 결제·환불 연락

하나의 동의를 다른 목적으로 재사용하지 않는다.

### 5.2 미성년자 기본 통제

개인정보보호위원회는 아동·청소년 개인정보 처리에 관한 별도 가이드라인을 제공한다. 실제 적용 전 최신 법령과 내부 법률 검토를 우선한다.

운영 기본값은 다음과 같다.

- 연령과 법정대리인 확인 기준이 정해지지 않으면 자동 마케팅 대상에서 제외
- 법정대리인 또는 승인 보호자 관계가 확인되지 않으면 계약·촬영·공개 후보를 만들지 않음
- 비상연락처를 광고 수신자로 전환하지 않음
- 결제자라는 이유로 보호자 권한을 자동 부여하지 않음
- 보호자 권한 변경·철회 시 발송 후보와 계정 접근을 다시 검토
- 미성년자 직접 연락은 승인된 연령·목적·법적 근거·내부 책임자 확인 전 중단

### 5.3 발송 상태

다음을 구분한다.

- 대상 후보
- 권한·동의 확인
- 사람 검토
- 발송 승인
- 발송
- 전달
- 사람 응답
- 후속 완료

대상 추출이나 발송을 사람의 동의·응답·문제 해결로 계산하지 않는다.

## 6. 신규 체험 퍼널

가족 문의는 가구와 개인을 동시에 보되 중복시키지 않는다.

1. 유입 접점
2. 문의 사건
3. 가구 후보
4. 참여 희망자 식별
5. 보호자·연락 담당자 확인
6. 참여자별 체험 예약
7. 참여자별 실제 체험
8. 계약 단위 결정
9. 참여자별 이용권한 활성
10. 거래별 실정산
11. 참여자별 첫 실제 수업
12. 계약·참여자별 유지 관찰

### 6.1 계수 예시

한 보호자가 형제자매 두 명의 체험을 문의하고 둘 다 참여했으며 가족 공유 회원권 하나를 결제한 경우:

- 문의 가구: 1
- 문의자: 1
- 체험 참여자: 2
- 실제 체험: 2
- 활성 계약: 1
- 활성 참여자: 2
- 실정산 거래: 1
- 순수납: 실제 실정산 금액 1회
- 신규 가구: 내부 정의 충족 시 1
- 신규 회원: 내부 회원 정의가 참여자 기준이면 2, 계약 기준이면 1 — 보고서에 분모와 정의를 명시

정의가 확정되지 않으면 둘 중 하나를 선택하지 않고 **데이터 미연결·정의 미확정**으로 둔다.

## 7. 형제자매 추가·삭제·이동

형제자매 추가는 다음 사건으로 나눈다.

- 같은 가구 관계 추가
- 참여자 후보 생성
- 체험 예약·실제 참여
- 기존 가족 계약 변경 또는 개인 계약 신규
- 이용권한 추가
- 추가 청구·실정산
- 첫 실제 수업

### 7.1 신규 성과 판정

- 기존 가구에 참여자가 추가된 사실을 신규 가구 획득으로 계산하지 않음
- 추천 코드가 있어도 동일 가구·기존 관계 여부를 먼저 확인
- 새 참여자를 신규 참여자로 볼지는 내부 회원 정의에 따름
- 계약 변경과 새 계약을 구분
- 추가 청구가 없으면 추가 매출 0으로 보지 말고 거래 상태를 확인
- 다른 지점으로 이동한 참여자를 신규·복귀·재등록에 중복 귀속하지 않음

### 7.2 삭제·분리

- 가족 계정에서 제거됨
- 이용권한 종료
- 계약 종료
- 결제 중단
- 실제 참여 종료

위 상태는 서로 다르다. 계정 제거만으로 이탈·환불·계약 종료를 확정하지 않는다.

## 8. 휴면·만료·재등록 CRM

다음 작업 큐를 분리한다.

| 큐 | 기준 | 연락 대상 |
|---|---|---|
| 참여 공백 검토 | 개인별 실제 출석 공백 | 승인된 서비스 연락 담당자 |
| 가족 계약 만료예정 | 계약 종료일 | 계약 연락 담당자 |
| 결제 실패 | 거래 실패·재시도 상태 | 결제 담당자 |
| 보호자 권한 확인 | 관계 만료·변경·분쟁 | 내부 승인된 확인 경로 |
| 이용권한 불일치 | 계약은 활성이나 개인 권한 오류 | 운영 담당자 |
| 형제자매 추가 문의 | 새 참여 후보 | 문의자·승인 연락 담당자 |
| 휴면 복귀 | 내부 휴면 정의 충족 | 유효한 광고·서비스 연락 기준에 맞는 대상 |
| 재등록 검토 | 계약 종료 후 새 계약 후보 | 계약 연락 담당자 |

한 가족 구성원의 공백을 가구 전체의 휴면으로 자동 확장하지 않는다.

## 9. 매출·비용 귀속

### 9.1 기본 산식

- 총수납 = 실제 실정산 거래 합계
- 순수납 = 총수납 - 환불 - 차지백
- 순매출 기여 = 순수납 - 실제 사용 할인·크레딧·보상비 - 승인된 직접 변동비

내부 회계 정의가 확정되기 전에는 공식 재무 수치로 사용하지 않는다.

### 9.2 가족 매출 통제

- 한 가족 결제를 각 참여자에게 전액 복제하지 않음
- 사람별 배분이 필요하면 사전에 승인된 배분 규칙 사용
- 할인 약속·쿠폰 발급과 실제 사용을 구분
- 결제 승인과 실정산을 구분
- 환불 요청과 환불 완료를 구분
- 지점 간 이동·공동 수업은 전체 매출 1회, 지점 배분은 별도
- 결제자 변경이 신규 계약이나 신규 매출을 의미하지 않음

## 13. 실험 EXP-428

### 가족·보호자·참여자·결제자·계약·권한·매출 판정 정확도

합성 데이터:

- 가구 480개
- 성인·보호자·결제자 후보 720명
- 참여자 960명
- 관계·권한 사건 2,400건
- 동의 사건 1,800건
- 회원권·이용권한 2,400건
- 출석 사건 2,400건
- 청구·결제·환불 사건 2,400건

### 성공 기준

다음 오류가 모두 0건이어야 한다.

- 가구를 개인 수로 계산
- 보호자·결제자를 실제 참여자로 계산
- 한 결제를 형제자매에게 전액 중복 귀속
- 가족 회원권을 명단에 없는 사람의 권한으로 확장
- 형제자매 추가를 신규 가구와 추천 성과에 중복 귀속
- 체크인을 실제 참여로 자동 승격
- 결제 승인을 실정산으로 계산
- 비상연락처를 광고 수신 동의자로 계산
- 확인 대기·철회된 보호자 권한으로 연락 후보 생성
- 미성년자 직접 마케팅 후보를 승인 기준 없이 생성
- 환불·차지백을 순수납에서 누락
- 지점 이동을 신규·복귀·재등록으로 중복 계산

하나라도 실패하면 자동 대상 확정, 고객 메시지, 이용권한 변경 및 신규·복귀·재등록·매출 보고를 중단한다.

## 14. 대표 승인·입력 체크리스트

- 회원의 공식 단위: 사람, 계약, 가구 중 무엇을 어떤 보고서에 쓰는가
- 가족 공유 회원권과 개인 회원권의 판매·권한 기준
- 가족관계·법정대리인·승인 보호자 확인 방법
- 보호자 권한의 범위·만료·변경·분쟁 처리
- 결제자·계약자·서비스 연락 담당자 구분
- 미성년자 직접 연락 허용 연령·목적·법적 근거·승인자
- 서비스 안내와 광고성 정보의 구분
- 형제자매 추가·삭제·지점 이동의 신규·복귀·재등록 정의
- 가족 할인·추천·보상 자격과 중복 방지
- 한 결제의 사람·지점별 배분 규칙
- 실정산·환불·차지백·순수납 기준 원장
- 실제 출석·참여와 정정 권한
- 데이터 보유기간·접근권한·삭제 절차

승인 전에는 실제 고객 대상 자동 발송·권한 변경·결제 조정·성과 확정을 하지 않는다.

## 15. 감사 규칙

- 공개 문서에는 개인 식별정보와 실제 원장을 넣지 않는다.
- 가족이라는 이유로 관계·권한·동의를 추정하지 않는다.
- 결제자를 보호자 또는 참여자로 추정하지 않는다.
- 가족 공유 회원권을 개인별 실제 참여 증거로 사용하지 않는다.
- 외부 시스템의 기능 설명을 내부 정책 확정으로 바꾸지 않는다.
- 법령·가이드라인은 최신 원문과 내부 책임자 검토 후 적용한다.
- 승인되지 않은 가격·혜택·행사·성과를 공개하지 않는다.
