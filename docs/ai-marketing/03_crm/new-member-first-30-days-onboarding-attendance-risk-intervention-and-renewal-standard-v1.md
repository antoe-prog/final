# 신규회원 첫 30일 온보딩·출석·위험 신호·개입·재등록 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 작성·검토일: 2026-09-17
- 적용 범위: 체험 후 신규 등록자, 휴면 후 복귀자, 지점 이동자를 포함한 초기 적응 구간
- 기준 시간대: Asia/Seoul
- 공개 제외: 회원·보호자 식별정보, 연락처, 개인별 출석·건강·상담·결제 원장, 실제 가격·혜택, 승인 대기 Instagram 콘텐츠, 미확정 FINAL ROAD

## 1. 오늘의 판단

신규 등록은 퍼널의 끝이 아니라 초기 유지의 시작이다. 다음 사건을 하나의 `등록 완료` 상태로 합치지 않는다.

1. 계약 체결
2. 실수납 확인
3. 이용 시작일 도래
4. 첫 수업 예약
5. 첫 실제 참여
6. 첫 안내 완료
7. 초기 출석 리듬 형성
8. 불편·질문 확인
9. 다음 수업 또는 다음 목표 확정
10. 30일 검토 완료
11. 재등록 대상 도래
12. 실제 재등록과 실수납

첫 30일은 비교 가능한 운영 관찰 창으로 사용한다. 모든 회원의 습관이 30일에 형성되거나 첫 달 출석만으로 장기 유지가 결정된다고 단정하지 않는다.

## 2. 공개 자료에서 확인한 변화

- 2026년 체육시설 운영 자료는 가입 서류보다 첫 방문·예약·시설 안내·초기 출석 확인을 포함하는 온보딩을 강조한다.
- 2026년 무도장 운영 자료는 신규 수련생에게 첫 수업 준비, 도장 규칙, 일정, 담당자와 다음 행동을 일관되게 안내하는 체크리스트를 제안한다.
- Health & Fitness Association은 2026-09-10 공개한 미국 시설 방문 자료에서 8월 방문 증가를 보고했다. 이는 미국 1만여 시설의 익명 집계이며 파이널유도의 지역 수요·회원 유지 성과로 전용하지 않는다.
- 공급업체가 제시하는 방문 횟수·연락 시점·유지율은 내부 기준이나 목표가 아니다. 파이널유도 데이터로 임계값을 검증하기 전에는 `THRESHOLD_UNSET`으로 둔다.

## 3. 적용 대상과 제외 대상

### 3.1 적용 대상

- 처음 계약하고 이용을 시작한 신규회원
- 장기 휴면 후 새로운 이용 기간을 시작한 복귀회원
- 다른 지점에서 이동해 새 환경에 적응하는 회원
- 미성년 회원의 보호자 운영 안내

### 3.2 같은 집계에 섞지 않는 대상

- 체험만 예약한 사람
- 계약했지만 시작일이 미래인 사람
- 계약했지만 결제가 실패·취소된 사람
- 기존 이용 기간을 단순 연장한 회원
- 지점 이동자
- 휴회·부상·공식 장기 결석 처리 중인 회원

신규·복귀·지점 이동·단순 재등록을 별도 코호트로 유지한다.

## 4. 기준 시각 정의

| 시각 | 정의 | 주의 |
|---|---|---|
| `contract_signed_at` | 계약이 체결된 시각 | 매출·이용 시작이 아님 |
| `payment_settled_at` | 실제 수납이 확인된 시각 | 환불·차지백 반영 필요 |
| `service_start_at` | 승인된 이용 시작 시각 | 첫 참여와 다를 수 있음 |
| `first_booking_at` | 첫 수업 예약 확정 시각 | 실제 참여가 아님 |
| `first_attendance_at` | 첫 실제 참여 확인 시각 | 체크인 오류 검토 필요 |
| `onboarding_started_at` | 온보딩 책임자가 여정을 개시한 시각 | 자동 메시지 발송과 다름 |
| `day_30_review_due_at` | 승인된 기준 시각으로부터 30일 검토 예정 | 자동 성공·실패 판정 금지 |

기본 관찰 기준점은 대표 승인 전 `ONBOARDING_ANCHOR_UNSET`으로 둔다. 계약일·결제일·이용 시작일·첫 참여일 중 어떤 시각을 사용할지 확정해야 한다.

## 6. 첫 30일 운영 단계

정확한 날짜·발송 시점·횟수는 대표 승인과 내부 데이터 검증 전까지 고정하지 않는다.

### 단계 A — 시작 준비

확인 항목:

- 지점·수업·대상 연령·담당 코치
- 승인된 이용 시작일
- 첫 방문 또는 첫 수업 예약
- 복장·준비물·도착 방법
- 체크인·예약·취소 방법
- 미성년자의 보호자 권한과 인계 기준
- 문의·안전·결제 문제의 공식 경로

### 단계 B — 첫 실제 참여

확인 항목:

- 실제 참석 여부
- 오리엔테이션 실제 완료 여부
- 수업 담당자와 다음 행동
- 회원이 질문을 남길 수 있는 경로
- 공개 촬영·후기·성과 공유 동의와 운영 동의의 분리

### 단계 C — 초기 출석 관찰

관찰 항목:

- 이용 가능 회차
- 예약 확정 회차
- 사업자 취소 회차
- 회원 취소 회차
- 실제 참석 회차
- 체크인 누락 검토 상태
- 다음 예약 여부

수업 제공 기회가 없었던 기간을 회원 미출석으로 계산하지 않는다.

### 단계 D — 불편·위험 신호 검토

위험 신호는 자동 이탈 판정이 아니라 검토 후보 생성에만 사용한다.

- 이용 시작 후 첫 예약 미확정
- 예약 후 실제 참여 미확인
- 확인된 참석 뒤 다음 행동 미확정
- 반복된 예약 변경 또는 전달 실패
- 수업 수준·시간·준비물·시설 질문 미해결
- 보호자·회원이 명시한 불편 또는 중단 의사
- 결제 실패·계약 상태 불일치

건강·부상·동기 부족·경제사정·불만을 데이터 없이 추정하지 않는다.

### 단계 E — 30일 검토

검토 항목:

- 시작 기준 시각과 관찰 가능 일수
- 제공 가능한 수업 수와 실제 참석 수
- 첫 참여까지 걸린 시간
- 문의와 해결 상태
- 다음 예약·목표·진도 검토 상태
- 계약·결제·휴회·환불 상태
- 공개 인정 선호와 동의 상태

30일 검토 완료를 만족·재등록·장기 유지 완료로 집계하지 않는다.

## 7. 출석 지표 정의

| 지표 | 계산 | 조건 |
|---|---|---|
| 첫 참여 전환율 | 첫 실제 참여자 / 이용 시작 적격자 | 미래 시작일·취소 계약 제외 |
| 첫 참여 소요일 | 첫 실제 참여 시각 - 이용 시작 기준 시각 | 기준점 확정 필요 |
| 제공 기회 대비 참석률 | 실제 참석 회차 / 회원이 참여 가능했던 제공 회차 | 휴강·만석·대상 불일치 제외 |
| 예약 대비 참석률 | 실제 참석 회차 / 확정 예약 회차 | 체크인 누락 검토 후 계산 |
| 다음 행동 확정률 | 다음 예약·상담·목표 확정자 / 첫 참여자 | 자동 제안만으로 확정 금지 |
| 30일 활성률 | 승인된 활성 조건 충족자 / 30일 관찰 완료자 | 활성 조건 미확정 시 계산 금지 |

분자·분모·기간·출처가 없거나 분모가 0이면 계산하지 않는다.

## 8. 위험 등급과 개입 제한

### 8.1 위험 등급

- `RISK_UNASSESSED` — 데이터 부족 또는 관찰 미성숙
- `REVIEW_CANDIDATE` — 검토 조건 충족
- `CONTACT_CANDIDATE` — 연락 적격성 확인 필요
- `OWNER_REVIEWED` — 담당자가 근거 검토
- `INTERVENTION_APPROVED` — 개입 내용 승인
- `INTERVENTION_COMPLETED` — 실제 개입 완료
- `RESOLVED` — 문제 해결 근거 확인
- `UNRESOLVED` — 미해결 또는 관찰 계속

### 8.2 자동화 금지

- 출석 부족만으로 이탈 확정
- 근거 없는 건강·동기·경제사정 추정
- 미성년자에게 보호자 권한 없이 직접 광고 연락
- 수신거부 이후 광고 후속
- 미확정 가격·무료 체험·할인·좌석 제공
- 회원의 공개 축하·후기·사진을 기본값으로 설정

| 수업 운영 | 예약, 준비물, 휴강·변경 | 별도 목적 |

| 광고·재등록 | 혜택·새 상품·재등록 제안 | 동의·수신거부 별도 관리 |

자동 접수 확인을 실질 답변이나 문제 해결로 처리하지 않는다.

## 10. 성인·미성년 회원 분리

### 성인회원

- 회원 본인의 연락 동의와 선호 채널을 사용한다.
- 목표·불편·공개 인정 선호를 본인 확인 없이 만들지 않는다.

### 미성년 회원

- 계약·결제·광고·촬영·안전 연락의 보호자 권한을 구분한다.
- 아동의 기술·행동·건강 메모를 공개 콘텐츠나 일반 마케팅 데이터로 옮기지 않는다.
- 보호자에게 보낸 메시지를 아동 본인의 이해·동의 완료로 간주하지 않는다.

## 11. 지점·수업 인계

멀티짐에서는 다음을 분리한다.

- 계약 지점
- 실제 이용 지점
- 담당 코치
- 첫 수업 담당자
- 상담·불편 처리 책임자
- 수납·환불 귀속 지점
- 지점 이동 승인 상태

지점 이동자는 신규회원으로 중복 집계하지 않는다. 다른 지점에서 첫 방문했다는 이유로 전체 첫 참여를 새로 생성하지 않는다.

## 12. 콘텐츠 연결 원칙

### 네이버·당근·브랜드 채널

- 일반적인 첫 수업 준비 안내는 공개 가능하다.
- 실제 시간표·가격·좌석·혜택은 승인 버전만 사용한다.
- 회원의 출석·변화·후기는 별도 공개 동의 없이는 사용하지 않는다.

### 코치 개인 Instagram `@ant.toe.98`

- 코치가 설명하는 일반적인 입문 준비·낙법·예절·도복·기초 질문 콘텐츠에 적합하다.
- 확인되지 않은 당일 지도 경험이나 개인 회원 성과를 1인칭 사실로 만들지 않는다.
- 코치 개인 계정을 본관·멀티짐의 공식 공지 주체로 표현하지 않는다.
- 저장·질문·팔로우·수업 문의 중 하나의 CTA만 사용한다.
