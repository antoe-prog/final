- 문서 상태: 공개 가능한 운영 기준
- 작성·검토일: 2026-09-16
- 적용 범위: 신규회원 활성, 기존회원 만족·재등록, 휴면회원 복귀 후 재활성
- 기준 시간대: Asia/Seoul
- 공개 제외: 회원·보호자 식별정보, 개인별 출석·기술·건강·상담·승급·결제 원장, 연락처, 승인 대기 콘텐츠, 미확정 행사·가격·혜택

## 1. 오늘의 판단

마일스톤 인정은 단순한 축하 게시물이 아니라 다음 사건을 정확히 분리하는 운영 체계여야 한다.

1. 진도 근거 발생
2. 코치 검토
3. 승급 자격 확인
4. 평가 일정 확정
5. 실제 평가
6. 결과 확정
7. 인정 방식 선호 확인
8. 비공개 또는 공개 축하 실행
9. 만족·재등록 결과 관찰

출석 횟수만으로 기술 숙련, 승급 자격, 평가 합격, 재등록 의사를 자동 판정하지 않는다.

## 2. 공개 사례에서 확인한 변화

British Judo가 2026년 5월 27일 공개한 Melbourn Judo Club 사례는 작은 규모의 잦은 승급 평가 기회를 운영하고, 출석·노력·발달에 맞춘 진도를 강조한다. 해당 클럽이 제시한 유지율은 단일 클럽의 자체 보고이며 파이널유도의 목표치나 인과효과로 적용하지 않는다.

2026년 체육시설·무도장 운영 자료는 기술·띠 추적, 출석, 회원관리, 커뮤니티 인정을 같은 운영 영역에서 다룬다. 공급업체 기능과 성과 주장은 제품 설명이므로 도입 효과로 간주하지 않는다.

2026년 부티크 피트니스 보도는 공개 축하를 기대하는 회원과 공개 주목을 원하지 않는 회원이 함께 있음을 보여준다. 따라서 공개 인정은 기본값이 아니라 확인된 선호와 공개 동의를 전제로 한다.

## 3. 적용 원칙

- 승급 기준은 대한유도회·도장 내부의 현재 승인 기준을 기준으로 한다. 외국 단체·타 도장의 평가 주기를 복사하지 않는다.
- 출석, 수련 노력, 기술 진도, 공식 승급은 서로 다른 마일스톤으로 저장한다.
- 코치의 관찰 메모는 승급 합격 기록이 아니다.
- 승급 비용 납부는 자격·응시·합격·재등록을 증명하지 않는다.
- 공개 축하 동의는 마케팅 수신동의나 회원가입 동의와 분리한다.
- 미성년자 또는 보호가 필요한 회원의 공개 사용은 승인된 보호자·법정대리인 확인 절차를 거치기 전까지 보류한다.
- 공개를 원하지 않는 회원에게도 비공개 인정 선택지를 제공한다.
- 축하 누락을 보상·혜택·자동 무료 제공으로 처리하지 않는다. 비용·혜택은 별도 승인 대상이다.
- 마일스톤 도달을 재등록 압박이나 공개 후기 요청의 조건으로 사용하지 않는다.
- 실제 연락·게시·촬영·혜택·계정 변경은 대표 승인과 대상별 적격성 확인 후에만 실행한다.

## 6. 공개 인정 선택지

### 비공개 기본안

- 수업 전후 짧은 코치 피드백
- 개인 앱·카드의 진도 확인
- 개인 메시지 초안 후 승인된 전달
- 다음 학습 목표 안내

### 공개 선택안

공개 축하는 다음이 모두 확인될 때만 후보가 된다.

- 공개 대상 본인과 필요한 보호자 동의
- 공개 채널과 사용 범위
- 이름·얼굴·도복 표식·배경의 식별 위험
- 정확한 마일스톤과 결과 원천
- 최종 문구·이미지·게시 계정
- 게시 후 삭제·정정 담당 역할

동의가 없거나 선호가 불명확하면 얼굴·이름·개인 진도를 공개하지 않는다.

## 7. 코치 개인 Instagram 적용

`@ant.toe.98`은 코치 개인 계정이다. 지점 전체의 공식 승급 발표 계정으로 표현하지 않는다.

회원 마일스톤 콘텐츠는 다음 중 하나일 때만 후보로 둔다.

- 코치 본인의 확인된 수련·지도 관점
- 식별정보 없는 일반적인 진도 설명
- 별도 공개 동의를 받은 실제 사례
- 얼굴·이름·시설을 특정하지 않는 개념 일러스트

회원 사례가 없으면 가상의 성공담을 만들지 않는다. “회원들이 모두”, “한 달 만에 승급”, “재등록이 늘었다” 같은 확인되지 않은 표현을 사용하지 않는다.

현재 승인 대기 게시물은 별도 승인 절차를 유지하며, 이 기준을 이유로 업로드·예약·발행하지 않는다.

## 10. KPI 정의

- 마일스톤 판정 완전성 = 필수 원천이 있는 판정 / 전체 판정 후보
- 코치 검토 완료율 = 검토 완료 / 검토 필요 후보
- 승급 자격 오분류율 = 사후 정정된 자격 판정 / 자격 판정
- 인정 선호 확인률 = 선호 확인 / 인정 후보
- 공개 동의 완전성 = 범위가 확인된 동의 / 공개 후보
- 인정 누락률 = 승인 기한 내 미완료 / 승인된 인정
- 만족 확인률 = 후속 확인 완료 / 인정 완료
- 재등록률 = 검증 재등록 / 성숙한 만료예정 코호트

모든 비율은 분자·분모·기간·원천·기준 버전을 표시한다. 분모가 0이면 계산하지 않고, 원천이 없으면 `데이터 미연결`, 결과창이 끝나지 않으면 `미성숙`으로 둔다.

마일스톤 인정 후 재등록이 발생해도 직접 인과로 단정하지 않는다.

## 11. EXP-330 — 진도·인정·재등록 판정 완전성

- 목적: 회원의 실제 진도와 선호를 존중하면서 누락·오분류 없이 운영할 수 있는지 검증
- 1단계: 합성 레코드 12건으로 상태 전환 건식 검증
- 2단계: 대표 승인 후 비식별 실제 후보 20건 또는 30일
- 성공 기준:
  - 진도·출석·승급 자격·평가·결과 분리율 100%
  - 코치 검토 없는 승급 자격 확정 0건
  - 인정 방식 선호 확인률 100%
  - 공개 동의 없는 게시 후보 0건
  - 예정·승인·실행·완료 혼합 0건
  - 승인본과 실행본 불일치 0건
  - 재등록의 검증 계약 대사율 100%
- 중단 기준:
  - 출석만으로 승급·기술 숙련 확정
  - 비용 납부를 합격·재등록으로 처리
  - 무동의 회원·보호자 식별정보 공개
  - 축하를 공개 후기·재등록·혜택 수령의 조건으로 사용
  - 외부 클럽 유지율을 내부 목표로 적용
- 만족·재등록 개선 목표: 데이터 미연결
