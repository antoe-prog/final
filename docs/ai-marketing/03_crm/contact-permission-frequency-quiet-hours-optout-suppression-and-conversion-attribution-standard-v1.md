# 연락 자격·빈도·야간·수신거부·전 채널 억제·전환 귀속 기준 v1

- 문서 상태: 공개 가능한 운영 기준 초안
- 적용 대상: 신규 문의, 체험 후 미등록, 휴면, 만료예정, 기존회원 대상 CRM 기획
- 적용 채널: 문자, 카카오톡, 전화, 이메일, 앱푸시, Instagram DM 등
- 기준일: 2026-09-19
- 목적: 고객 여정 단계와 연락 가능 여부를 분리하고, 수신거부·중복·야간·연락 피로를 방지한다.

## 1. 핵심 원칙

1. 연락처가 있다는 사실은 광고성 연락 자격이 있다는 뜻이 아니다.
2. 과거 회원, 체험 신청자, 보호자, 휴면회원이라는 이유만으로 현재 모든 채널 연락을 허용하지 않는다.
3. 계약·예약 이행 정보와 재등록·복귀·혜택 제안은 목적과 전체 문맥을 기준으로 구분한다.
4. 수신거부는 캠페인 하나가 아니라 해당 목적·채널의 후속 대기열 전체에 우선 적용한다.
5. 자동응답, 발송 요청, 발송 성공, 전달, 열람, 답변, 예약, 실참여, 등록, 실수납을 각각 다른 사건으로 기록한다.
6. 법적 최소 기준을 지켰더라도 반복 연락이 고객 경험을 해칠 수 있으므로 별도의 빈도 상한과 중단 기준이 필요하다.

## 2. 이번 기준이 해결하는 문제

- 같은 사람이 신규·휴면·만료예정 캠페인에 동시에 포함됨
- 문자 수신거부 후 카카오톡·DM·전화로 자동 전환됨
- 보호자와 미성년자를 별도 고객으로 보고 중복 연락함
- 자동응답이나 발송 성공을 사람 응답으로 계산함
- 안부·정보 안내 형식을 사용하지만 실제 목적은 재등록 권유임
- 야간 별도 동의와 일반 수신동의를 혼동함
- 일방적으로 지급한 쿠폰·포인트의 안내를 정보성으로 간주함
- 수신거부 처리 요청과 실제 억제 완료를 동일하게 봄
- 열람·클릭·답장을 복귀·재등록·매출로 계산함

## 3. 연락 목적 분류

| 분류 | 예시 | 기본 처리 |
|---|---|---|
| `SERVICE_NOTICE` | 확정 예약 변경, 결제·계약 이행에 필요한 사실 안내 | 목적·필요성·대상 확인 |
| `SAFETY_NOTICE` | 운영 중단, 긴급 안전 공지 | 실제 긴급성과 대상 확인 |
| `SUPPORT_REPLY` | 고객이 먼저 보낸 문의에 필요한 답변 | 문의 범위 안에서 응답 |
| `FEEDBACK_REQUEST` | 수업·체험 의견 요청 | 연락 자격·빈도·중립성 확인 |
| `REACTIVATION` | 휴면회원 복귀 권유 | 광고성 연락 자격 확인 |
| `RENEWAL_PROMOTION` | 만료예정 회원의 재등록 권유·혜택 | 광고성 연락 자격 확인 |
| `ACQUISITION_PROMOTION` | 체험·등록·친구추천 제안 | 광고성 연락 자격 확인 |
| `CONSENT_CONFIRMATION` | 기존 광고 수신동의 사실 정기 확인 | 법령·안내서 기준 별도 운영 |

메시지 제목이 `안내`, `정보`, `안부`여도 실제 목적과 내용이 판매·등록·혜택 유도라면 광고성 가능성을 별도로 검토한다.

## 4. 연락 자격 상태 모델

| 상태 | 의미 | 허용 범위 |
|---|---|---|
| `IDENTITY_UNRESOLVED` | 동일인·가구·보호자 관계 미확인 | 발송 보류 |
| `PURPOSE_UNCLASSIFIED` | 연락 목적 미분류 | 발송 보류 |
| `CONSENT_UNKNOWN` | 동의 증거 없음 | 광고성 발송 보류 |
| `CONSENT_REQUESTED` | 동의 요청만 완료 | 동의로 취급 금지 |
| `CONSENT_VALID` | 목적·채널·시각·근거 확인 | 승인된 범위만 가능 |
| `NIGHT_CONSENT_UNKNOWN` | 야간 별도 동의 미확인 | 야간 광고성 발송 보류 |
| `NIGHT_CONSENT_VALID` | 야간 별도 동의 확인 | 승인된 범위만 가능 |
| `CONSENT_EXPIRED_OR_REVIEW_DUE` | 재확인 또는 유효성 검토 필요 | 광고성 발송 보류 |
| `OPTOUT_REQUESTED` | 수신거부 접수 | 즉시 대기열 차단 |
| `SUPPRESSION_PENDING` | 시스템 간 억제 반영 중 | 모든 자동 발송 차단 |
| `SUPPRESSED` | 해당 목적·채널 억제 완료 | 발송 금지 |
| `LEGAL_HOLD` | 민원·분쟁·법적 검토 | 자동 발송 금지 |
| `ELIGIBLE` | 자격·빈도·시간·중복 검사를 통과 | 승인된 캠페인만 가능 |

`CONSENT_UNKNOWN`, `CONSENT_REQUESTED`, `OPTOUT_REQUESTED`, `SUPPRESSION_PENDING`, `SUPPRESSED`는 광고 발송 대상이 아니다.

## 6. 발송 전 자격 게이트

다음 조건을 모두 통과해야 광고성 발송 후보가 된다.

1. 실제 연락 목적이 분류됐는가
2. 본인·보호자·가구·지점 관계가 확인됐는가
3. 해당 목적과 채널의 동의 증거가 있는가
4. 수신거부·민원·법적 보류가 없는가
5. 야간에 해당하면 별도 야간 동의가 확인됐는가
6. 빈도 상한과 냉각기간을 넘지 않았는가
7. 다른 캠페인·지점·담당자의 중복 대기열이 없는가
8. 미확정 가격·시간표·혜택·정원을 포함하지 않는가
9. 발신자·광고성 표시·수신거부 방법 등 필요한 표시가 검수됐는가
10. 최종 발송본과 승인본이 동일한가

하나라도 실패하면 `ELIGIBLE`로 전환하지 않는다.

## 7. 빈도·냉각기간·우선순위

구체적인 횟수와 기간은 대표 승인 후 설정한다. 데이터가 없는데 임의의 숫자를 법정 기준이나 최적값으로 공개하지 않는다.

### 기본 우선순위

1. 수신거부·민원·법적 보류
2. 안전·필수 서비스 안내
3. 고객이 먼저 시작한 문의 응답
4. 이미 확정된 예약·결제 후속
5. 체험 후 미등록 후속
6. 만료예정 재등록
7. 휴면회원 복귀
8. 일반 프로모션

낮은 우선순위 캠페인은 높은 우선순위 캠페인과 충돌하면 연기하거나 제외한다.

### 채널 전환 금지

- 문자 수신거부를 카카오톡·전화·DM 자동 전환 사유로 사용하지 않는다.
- 전달 실패를 다른 채널 동의로 해석하지 않는다.
- 읽지 않음·무응답을 추가 연락 동의로 해석하지 않는다.
- 지점이 다르다는 이유로 같은 사람에게 중복 캠페인을 발송하지 않는다.

## 8. 야간과 예약 발송

- 시스템 시간대는 `Asia/Seoul`로 고정하고 발송 요청 시각과 실제 수신 시각을 구분한다.
- 야간 광고성 전송은 별도 사전 동의 증거가 없으면 보류한다.
- 예약 시각이 낮 시간이어도 지연 발송으로 야간 수신 가능성이 있으면 안전한 시간대로 이동한다.
- 해외 체류 가능성이 있는 수신자에게 한국시간만으로 안전하다고 단정하지 않는다.
- 긴급 안전 공지를 마케팅 문구와 결합하지 않는다.

## 9. 수신거부와 전 채널 억제

### 처리 순서

`OPTOUT_REQUESTED → QUEUE_BLOCKED → CHANNEL_SUPPRESSED → CAMPAIGN_SUPPRESSED → CROSS_SYSTEM_VERIFIED → SUPPRESSED`

- 수신거부 접수 즉시 새 예약·재시도·리타기팅 대상 생성을 차단한다.
- 발송 도구, CRM, 스프레드시트, 담당자 개인 목록에 각각 남아 있는 대기열을 확인한다.
- 처리 요청을 완료로 표시하지 않고 실제 발송 억제를 시험한다.
- 앱푸시 수신거부에 불필요한 로그인이나 복잡한 절차를 요구하지 않는다.
- 동의 철회 후 서비스 이용에 불필요한 불이익을 부과하지 않는다.

### 예외 처리

필수 계약·예약 이행 안내가 필요한 경우에도 광고 문구를 섞지 않고 목적·근거·범위를 별도로 기록한다.

## 10. 보호자·미성년자·가구·다지점

- 보호자 연락처와 미성년자 회원을 별도 광고 대상으로 중복 생성하지 않는다.
- 보호자 권한이 확인되지 않으면 개인별 수업·결제 내용을 발송하지 않는다.
- 형제·가족·부부 관계는 자동 병합하지 않고 확인된 관계만 사용한다.
- 한 지점의 수신동의가 모든 지점·브랜드·목적으로 확장되는지 추정하지 않는다.
- 지점 이동·회원 상태 변경이 과거 수신거부를 초기화하지 않는다.

## 11. 캠페인별 운영

### 체험 후 미등록

- 예약, 체크인, 실참여를 구분한다.
- 무응답을 가격·시간·흥미 부족으로 자동 분류하지 않는다.
- 다음 단계는 `재체험 제안`, `질문 응답`, `중단` 중 승인된 경로만 사용한다.

### 휴면회원 복귀

- 휴면 정의와 기준일이 연결되지 않으면 대상 생성을 중단한다.
- 과거 친분·코치 기억을 광고 동의로 취급하지 않는다.
- 복귀 의사와 복귀 완료·재등록·실수납을 구분한다.

### 만료예정·기존회원 재등록

- 계약상 필요한 만료 안내와 혜택·판매 제안을 분리한다.
- 만료예정일·잔여횟수·가격의 기준 원장을 확인한다.
- 만족도 응답을 재등록 동의나 후기 동의로 자동 승격하지 않는다.

## 12. 채널별 콘텐츠 원칙

### 네이버·당근 공개 콘텐츠

- 공개 게시물과 개인 발송을 구분한다.
- 댓글·채팅 시작을 광고 수신동의로 확대하지 않는다.
- 지역·가격·혜택·마감 주장은 승인된 공개값만 사용한다.

### Instagram 코치 개인 계정

- 코치 개인의 설명·수련 기록과 브랜드의 공식 영업 메시지를 구분한다.
- 댓글·저장·팔로우를 DM·전화·재등록 연락 동의로 보지 않는다.
- 게시물 CTA는 저장·질문·팔로우·수업 문의 중 하나만 사용한다.
- 승인 대기 미디어·캡션은 대표 승인 전 업로드·외부 저장·예약·발행하지 않는다.

## 13. 퍼널과 매출 귀속

`AUDIENCE_ELIGIBLE → SEND_REQUESTED → SENT → DELIVERED → OPENED → HUMAN_RESPONSE → BOOKING_CONFIRMED → TRIAL_ATTENDED → REGISTRATION_COMPLETED → CASH_COLLECTED → REFUND_OR_CHARGEBACK → NET_CASH`

- 발송 요청은 실제 발송이 아니다.
- 실제 발송은 전달이나 열람이 아니다.
- 자동응답은 사람 응답이 아니다.
- 답변·링크 클릭은 예약 확정이 아니다.
- 예약 확정은 실참여가 아니다.
- 복귀 의사·등록 의사는 등록 완료 또는 실수납이 아니다.
- 환불·차지백을 차감하지 않은 금액을 순수납으로 보고하지 않는다.
- 지점·가구·채널·캠페인·결제 중복 귀속을 제거한다.
