# Q4 Schedule-Fit & Renewal Protection v1

- 작성일: 2026-09-12
- 상태: 전략·계측·실험 설계 / 고객 발송·가격 변경·시간표 변경·광고 집행 전
- 목표: 10~12월 일정 재편 시기에 `시간이 안 맞아서 그만두는 문제`를 할인보다 먼저 발견하고, 신규 체험의 반 적합성·기존회원의 시간대 이동·휴면회원의 복귀 가능시간을 연결해 신규 체험 실방문, 재등록, 복귀, 순기여를 함께 보호하는지 검증
- 내부 회원수·매출·전환율: **데이터 미연결**

## 오늘의 판단

이번 회차의 우선순위는 신규 프로모션을 하나 더 만드는 것이 아니라 **Q4 일정이 굳기 전에 회원·보호자·잠재회원의 `시간대 적합성`을 별도 전환요인으로 관리하는 것**이다.

2026년 9월 9일 강서구 자치회관에는 10~12월 4분기 프로그램 모집 공지가 올라왔고, 방화3동 프로그램들은 9월 21~30일 접수예정으로 공개되고 있다. 강서구 생활체육도 청소년 농구를 9~12월, 러닝·슬로우조깅·인라인스케이트 등을 9~11월 단위로 운영한다.

이 사실만으로 파이널유도 고객이 다른 프로그램 때문에 이탈한다고 주장할 수는 없다. 다만 **지역 주민이 9월 중에 4분기 활동시간을 선택하는 공개 일정 신호가 존재한다**. 따라서 10월 이후 결석·만료를 기다렸다가 복귀 메시지를 보내기보다, 지금 `현재 수업시간 유지 가능 / 다른 시간 필요 / 잠시 중단 예정 / 복귀 가능시간`을 운영데이터로 분리하는 편이 검증 가치가 높다.

이번 문서는 기존 `attendance-drift-early-warning-v1.md`와 다르다. Attendance Drift는 실제 출석패턴 약화를 사후 신호로 감지한다. 이번 전략은 **출석이 떨어지기 전의 일정충돌을 사전 신호로 수집하고, 가능하면 반 이동·대체시간·복귀 슬롯으로 연결하는 것**이 범위다.

## Acquisition Marketer — 신규 체험 캠페인 방향

Q4 신규획득에서는 `무료체험` 한 줄보다 **가능한 시간을 빠르게 확인할 수 있는 구조**를 우선 검증한다.

### 네이버

- 실제 운영시간을 기준으로 `성인 / 초등 저학년 / 초등 고학년 / 중등` 등 필요한 최소 분류만 표시
- `가장 가능한 시간`과 `두 번째 가능한 시간`을 선택하게 하는 예약 흐름 검토
- FULL 또는 체험 불가 시간은 문의를 받은 뒤 거절하지 말고 처음부터 비노출 또는 대체시간 제시

### 인스타그램

- `10~12월에도 이어갈 수 있는 시간대가 중요합니다`처럼 시간 적합성을 교육하되 조급함을 만들지 않는다.
- 실제 수업시간이 확정된 경우에만 카드/릴스로 시간표를 공개한다.
- `마감임박`, `잔여 1석`은 실재 재고가 없으면 사용하지 않는다.

### 당근

- 지역형 게시물에는 `대상 + 요일 + 시간 + 체험 가능 여부`를 한 화면에서 확인할 수 있게 한다.
- 실제 체험석이 없는 시간은 신규획득 CTA에 사용하지 않는다.

## CRM Marketer — Q4 일정충돌을 이탈로 오인하지 않는 구조

### 1. `시간 변경 필요`와 `그만둘 의사`를 분리한다

수업시간이 맞지 않는 회원에게 첫 선택지를 해지/재등록으로 두지 않는다. 운영상 가능하다면 아래 순서로 검토한다.

1. 현재 시간 유지 가능
2. 다른 기존 반으로 이동 가능
3. 일정기간 휴회 가능 — 실제 정책이 있는 경우만
4. 복귀 가능한 미래 슬롯 기록
5. 해지/만료 처리

### 2. 보호자·성인회원의 개인사유를 과수집하지 않는다

필요한 것은 `현재 시간 유지 가능 여부`와 `가능한 대체시간`이다. 학교명, 학원명, 회사명, 가족상황 같은 상세사유는 마케팅 세그먼트에 필요하지 않다.

### 3. 휴면회원은 `언제 올 수 있나요?`보다 선택 가능한 슬롯을 먼저 준비한다

복귀 연락을 승인해 실행하는 경우, 실제 여석이 없는 시간대를 제안하지 않는다. 휴면 복귀 캠페인은 `preferred_return_window → capacity_check → verified_return`로 연결한다.

## Experiment Manager

### EXP-245 Q4 Schedule-Fit Checkpoint

**가설:** 10월 이후 출석저하를 기다리는 것보다 9월 중 `현재시간 유지 / 변경 필요 / 일시 중단 예정` 상태를 미리 확인하면 일정충돌 회원에게 필요한 운영경로를 더 일찍 제공할 수 있고 이후 30일 활성·재등록이 개선될 수 있다.

**Treatment:** 승인된 대상에게 최소 문항으로 일정적합성 확인 → 필요한 경우 사람 검토 → 실제 가능한 반 이동/휴회/복귀안내

**Control:** 기존 운영

**KPI:**
- schedule-fit 응답률
- `SWITCH_NEEDED → switch_completed`
- 10월 실제출석
- 이후 30일 활성
- 재등록
- 불편·수신거부·민원
- 직원 처리시간

**중단 기준:** 개인정보 과수집, 이동 가능한 반이 없는데 설문만 증가, 동일회원 반복접촉, 기존반 과밀, 30일 활성·재등록 개선 없이 운영업무만 증가.

현재 기준선·최소개선폭·표본수는 **데이터 미연결**이다.

### EXP-246 Class-Switch Save Path

**가설:** 일정충돌이 확인된 기존회원에게 실제 여석이 있는 대체반을 제시하면 `그대로 결석 → 만료`보다 활성상태 유지 가능성이 높을 수 있다.

**KPI:**
- switch offer → accepted
- accepted → first attendance in new slot
- 30일 활성
- 재등록
- 이동 전/후 반별 과밀도
- 코치 업무량

**중단 기준:** 대체반 수업품질 악화, 안전정원 초과, 연령·수준 부적합 배치, 회원에게 이동을 강요하는 운영.

### EXP-247 Primary + Fallback Trial Slot

**가설:** 신규문의 시 하나의 희망시간만 받는 것보다 `1순위 + 2순위`를 받아 실제 체험석과 매칭하면 문의→예약과 예약→실방문 과정의 시간불일치를 줄일 수 있다.

**KPI:**
- qualified inquiry → matched slot
- matched slot → reservation
- reservation → verified attendance
- 실방문 → 14일 등록
- 등록 → 30일 활성
- 잘못된 반 배치율

**중단 기준:** 사용자가 원하지 않는 시간으로 자동배정, 지점·연령·수준 조건 무시, 실제 여석보다 많은 예약 허용.

## 필요한 대표 승인·입력

실제 실행 전에 아래가 필요하다.

1. 본관·지점별 10~12월 확정 또는 예정 시간표
2. 반별 `member_capacity`와 `trial_capacity`
3. 반 이동 허용정책과 코치 승인 필요 여부
4. 회원권 기간 중 반 변경 가능 여부와 비용정책
5. 휴회·복귀 정책
6. 신규 체험 가능한 요일·시간
7. 네이버·인스타·당근에 공개 가능한 확정 운영시간
8. 일정적합성 확인 메시지를 보낼 대상·채널·동의범위

값이 연결되기 전에는 임의 시간표, 여석, `마감임박`, 자동 반 이동을 만들지 않는다.

## Auditor — 근거·중복·과장·브랜드 리스크

1. 강서구 4분기 프로그램 모집이 파이널유도 이탈의 원인이라고 주장하지 않는다.
2. `시간이 맞으면 재등록한다`는 인과를 데이터 없이 단정하지 않는다.
3. 외부 유도장의 학기제·가격·정원을 파이널유도 정책으로 복제하지 않는다.
4. 회원의 학교·학원·회사·가족일정 상세를 마케팅 목적으로 수집하지 않는다.
5. 반 이동은 단순 빈자리뿐 아니라 연령·수준·안전·코치 판단을 함께 확인한다.
6. 신규 체험 확보를 위해 기존회원 수업밀도를 악화시키지 않는다.
7. 실제 여석이 없는 반에 `예약 가능`, `마감임박` 같은 표현을 쓰지 않는다.
8. 가격할인·무료보강·회원권 연장·메시지 발송·프로필 변경은 대표 승인 전 실행하지 않는다.

## 이번 회차의 결론

2026년 9월 현재 강서구에서는 Q4 프로그램 모집이 시작됐고, 해외 유도장에서도 가을 학기 시간표·반·체험가능 여부를 명확히 공개하는 운영이 확인된다. 파이널유도에서 검증해야 할 핵심은 `할인을 더 하면 남는가`가 아니라 **회원에게 맞는 시간대가 실제로 존재하고, 일정이 바뀌었을 때 이동 가능한 경로가 있는가**이다.

우선 측정 체인은 아래로 둔다.

`q4_schedule_fit → keep_or_switch → verified_attendance → active_30d → renewal`

신규는 아래로 분리한다.

`preferred_slot_1 + preferred_slot_2 → matched_trial_slot → verified_attendance → paid_14d → active_30d`

내부 기준선이 연결되기 전에는 효과 크기나 예상 매출을 추정하지 않는다.
