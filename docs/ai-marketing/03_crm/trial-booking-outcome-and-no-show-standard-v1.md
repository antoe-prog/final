# 체험 예약 결과·노쇼·재예약 판정 기준 v1

- 작성일: 2026-09-14
- 목적: 체험 예약 이후 실제 결과를 참석·취소·재예약·확정 노쇼로 분리해 신규 체험 퍼널과 후속관리를 과장 없이 측정
- 적용 전제: 실제 체험 예약·출석·등록·수납 데이터 미연결
- 외부 행동: 알림·고객 메시지·페널티·수수료·할인·광고·계정 변경 미실행

## 오늘의 판단

체험 예약 수만 늘리기 전에 예약 결과의 기준을 고정한다. 체크인이 없다는 이유만으로 즉시 노쇼로 처리하지 않고, 수업 개최 여부·취소·재예약·기술 오류·승인된 유예시간을 확인한 뒤 확정한다. 재예약 후 방문은 원래 노쇼를 삭제하지 않고 별도의 회복 결과로 기록한다.

## 예약 결과 상태

한 예약에는 아래 최종 결과 하나만 둔다.

| 상태 | 정의 | 참석·노쇼 계산 |
|---|---|---|
| `BOOKED_FUTURE` | 시작 시각 전 유효 예약 | 판정 대상 아님 |
| `OUTCOME_PENDING` | 시작 시각은 지났으나 출석 동기화·유예시간·운영 확인 미완료 | 계산 보류 |
| `ATTENDED` | 승인된 원천에서 실제 출석 확인 | 참석 |
| `CUSTOMER_CANCELLED` | 고객이 시작 전 취소 의사를 확인 가능한 기록으로 전달 | 노쇼 아님 |
| `RESCHEDULED_BEFORE_START` | 시작 전 다른 확정 일정으로 변경 | 노쇼 아님, 새 예약과 연결 |
| `DOJO_CANCELLED` | 지점·코치·시설 사유로 수업이 열리지 않음 | 고객 성과 분모 제외 |
| `NO_SHOW_CONFIRMED` | 개최된 수업에 유예시간 이후 출석·사전취소·사전재예약이 없음이 검증됨 | 노쇼 |
| `CHECKIN_ERROR` | 실제 참석 정황은 있으나 체크인 또는 데이터 동기화 오류 | 수정 전 계산 보류 |
| `DUPLICATE_VOID` | 중복·테스트·잘못 생성된 예약 | 모든 성과 분모 제외 |

당일 늦은 취소는 `CUSTOMER_CANCELLED`로 보존하되 `late_cancel_flag`를 별도 기록한다. 늦은 취소와 노쇼를 합치지 않는다.

## 노쇼 확정 게이트

다음 조건을 모두 만족할 때만 `NO_SHOW_CONFIRMED`로 바꾼다.

1. 예약된 지점·수업·시작 시각이 유효하다.
2. 해당 수업이 실제 개최됐다.
3. 대표가 승인한 출석 유예시간이 지났다.
4. 승인된 출석 원천에 체크인이 없다.
5. 사전 취소·사전 재예약 기록이 없다.
6. 시스템 지연·체크인 오류·중복 예약 가능성을 확인했다.
7. 판정 담당 역할과 판정 시각이 기록됐다.

유예시간과 체크인 기준원천이 승인되지 않았으면 `OUTCOME_PENDING`으로 둔다. 무응답이나 연락 부재만으로 노쇼를 확정하지 않는다.

## 최소 내부 필드

실제 개인값은 공개 저장소에 기록하지 않는다.

## 상태 전환 규칙

1. `BOOKED_FUTURE`는 예정 시각 전에는 성과 판정하지 않는다.
2. 예정 시각이 지나면 먼저 `OUTCOME_PENDING`으로 두고 수업 개최·출석 동기화를 확인한다.
3. 사전 재예약은 기존 예약을 `RESCHEDULED_BEFORE_START`로 닫고 새 예약 키를 연결한다.
4. 도장 취소는 고객 취소나 노쇼로 바꾸지 않는다.
5. 체크인 오류가 해결되면 근거와 수정 시각을 남기고 `ATTENDED`로 정정할 수 있다.
6. 확정 노쇼 뒤 재예약하더라도 원래 결과를 덮어쓰지 않고 `recovered_attendance_at`을 별도 기록한다.
7. 실제 출석 후에만 체험 후속 단계로 이동한다.
8. 실제 등록 사건이 확인되기 전에는 등록으로 기록하지 않는다.
9. 수신거부·연락중단 요청은 모든 마케팅 후속보다 우선한다.
10. 알림·재예약 권유·자동화·페널티·수수료는 각각 별도 승인 후 실행한다.

## 지표 정의

| KPI | 계산 |
|---|---|
| 결과 완전성 | 최종 결과가 기록된 도래 예약 ÷ 판정 가능한 도래 예약 |
| 체험 참석률 | `ATTENDED ÷ (ATTENDED + NO_SHOW_CONFIRMED)` |
| 고객 취소율 | `CUSTOMER_CANCELLED ÷ 판정 가능한 도래 예약` |
| 사전 재예약률 | `RESCHEDULED_BEFORE_START ÷ 판정 가능한 도래 예약` |
| 확정 노쇼율 | `NO_SHOW_CONFIRMED ÷ (ATTENDED + NO_SHOW_CONFIRMED)` |
| 노쇼 회복 방문률 | 확정 노쇼 뒤 승인된 기간 안 실제 방문 ÷ 회복 판정기한이 지난 확정 노쇼 |
| 체험 14일 등록률 | 14일 내 실제 등록 ÷ `ATTENDED` |
| 등록 수납 확인률 | 검증 결제가 연결된 등록 ÷ 실제 등록 |

모든 비율에 기간·지점·채널·분자·분모·데이터 원천을 함께 표시한다. 분모가 0이거나 데이터가 없으면 계산하지 않는다. 같은 사람의 중복 예약은 승인된 중복 규칙으로 병합하며, 예약 기준과 사람 기준 지표를 혼합하지 않는다.

## 운영 진단

- 예약 수는 많지만 결과 완전성이 낮으면 캠페인보다 출석 판정 연결을 먼저 수정한다.
- 확정 노쇼가 늘어도 원인을 일정·교통·불안·가격·건강 문제로 추정하지 않는다.
- 고객 취소와 도장 취소를 합치면 고객 행동과 운영 문제를 구분할 수 없다.
- 참석률이 높아도 14일 등록률이 낮다면 체험 적합성·질문 해소·등록 설명을 별도로 점검한다.
- 등록이 있어도 검증 수납이 없으면 매출 기여로 계산하지 않는다.

## EXP-295 — 체험 예약 결과 완전성 기준선

- 기간: 대표 승인 후 데이터가 연결된 최초 14일
- 가설: 예약 결과를 분리하면 후속 누락과 실제 체험 회복을 과장 없이 판정할 수 있다.
- 성공:
  - 판정 가능한 도래 예약의 결과 기록률 100%
  - `DOJO_CANCELLED`의 고객 노쇼 포함 0건
  - `OUTCOME_PENDING`의 확정 노쇼 포함 0건
  - 재예약의 대체 예약 키 연결률 100%
  - 수신거부 이후 연락 0건
  - 동일 예약 중복 후속 0건
  - 공개 개인정보 0건
- 보류:
  - 출석 원천·유예시간·수업 개최 확인·중복 정의 미승인
  - 예약·출석·등록 데이터 미연결
- 중단:
  - 무응답만으로 노쇼 확정
  - 도장 취소를 고객 노쇼로 기록
  - 승인 없는 메시지·자동화·페널티·수수료·혜택 실행
  - 개인정보 공개
- 참석률·회복 방문률·등록률·매출 개선폭: 데이터 미연결

## 대표 승인·입력

- 체험 예약과 실제 출석의 기준 시스템
- 지점별 수업 개최 확인 원천
- 출석 유예시간과 늦은 도착 처리
- 고객 취소·늦은 취소·재예약의 확정 정의
- 중복·테스트 예약 제외 기준
- 회복 방문 판정기간
- 연락 동의·수신거부·허용 횟수
- 알림·재예약 안내 문구와 실행 채널
- 페널티·수수료 정책의 적용 여부와 별도 승인
- 개인정보 없는 지점·채널별 14일 집계
