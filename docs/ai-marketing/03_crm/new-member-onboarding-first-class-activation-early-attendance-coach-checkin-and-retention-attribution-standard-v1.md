# 신규회원 온보딩·첫 수업·초기 활성화·지속출석·재등록 귀속 기준 v1

- 문서 버전: v1
- 검토일: 2026-09-18
- 적용 대상: 파이널유도멀티짐의 공개 가능한 운영·측정 기준 초안
- 상태: 대표 승인 전 기준안
- 포함하지 않는 정보: 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제 원장, 내부 가격·원가·손익, 미확정 행사, 승인 대기 Instagram 미디어·캡션

## 1. 목적

신규회원 확보를 등록 건수에서 끝내지 않고 다음 여정을 분리해 관리한다.

`체험 실참여 → 등록·회원권 활성화 → 첫 수업 예약 → 첫 실참여 → 초기 적응 → 지속 출석 → 재등록·실수납`

이 기준의 목적은 다음 네 가지다.

1. 체험회원과 활성회원을 혼동하지 않는다.
2. 예약·체크인·실제 수업 참여를 서로 다른 사건으로 기록한다.
3. 결제나 계약만으로 온보딩 완료·활성화·유지를 선언하지 않는다.
4. 신규회원이 초기에 필요한 안내와 지원을 받았는지 운영 책임을 분명히 한다.

## 2. 핵심 원칙

### 2.1 온보딩은 단일 사건이 아니다

- 가입서 작성은 온보딩 완료가 아니다.
- 계약·전자서명 완료는 온보딩 완료가 아니다.
- 결제 승인 또는 수납은 온보딩 완료가 아니다.
- 첫 수업 예약은 첫 참여가 아니다.
- 체크인은 실제 수업 참여가 아니다.
- 첫 참여는 지속 출석이나 재등록이 아니다.

### 2.2 측정은 실제 사건을 기준으로 한다

- 신청·예약·체크인·출석·결제의 기준 시스템을 각각 지정한다.
- 화면 열람이나 메시지 전달을 행동 완료로 승격하지 않는다.
- 자동 생성된 상태보다 담당자가 확인한 실제 사건을 우선한다.
- 출처·발생 시각·지점·프로그램·담당자·정정 이력을 남긴다.

### 2.3 외부 사례의 기간과 목표를 그대로 채택하지 않는다

- 외부 플랫폼이 제시한 가입 다음 날, 7일, 30일 등의 시점은 참고 사례다.
- 자체 회원권·수업주기·연령·지점 운영에 맞는 기준은 내부 데이터로 정한다.
- 내부 기준선이 없으면 전환율·유지율·활성화율 목표를 만들지 않고 `데이터 미연결`로 표시한다.

## 3. 적용 범위와 제외 범위

### 3.1 적용 범위

- 체험 후 신규 등록자
- 신규 등록 후 첫 수업 전 회원
- 첫 수업 참여 후 초기 적응 구간의 회원
- 신규회원의 보호자 또는 법정대리인 확인이 필요한 경우
- 지점 이동·가족 등록·복수 프로그램 참여로 중복 가능성이 있는 경우

### 3.2 제외 또는 별도 처리

- 단순 문의자
- 신청서를 열었으나 제출하지 않은 사람
- 예약만 하고 실제 참석하지 않은 체험자
- 활성 회원권이 없는 체험 방문자
- 휴면·일시정지·재개 회원: 별도 복귀 기준 적용
- 환불·해지·분쟁: 별도 계약·결제 기준 적용
- 미확정 행사·프로그램 참여자: 외부 모집·온보딩 대상으로 사용하지 않음

## 5. 첫 수업의 정의

### 5.1 유효한 첫 수업

다음 조건을 모두 충족한 최초의 수업을 `FIRST_ATTENDED`로 본다.

- 회원권 또는 승인된 참여 자격이 유효하다.
- 실제 운영된 수업이다.
- 지점·프로그램·수업 ID가 확인된다.
- 예약 여부와 무관하게 실제 참여가 확인된다.
- 취소·휴강·테스트 체크인·중복 기록이 아니다.
- 수업 종료 후 출석이 확정됐다.

### 5.2 첫 수업으로 계산하지 않는 사건

- 예약 신청
- 대기명단 등록 또는 승격 제안
- 예약 확정만 된 상태
- 시설 입장 또는 바코드 체크인만 있는 상태
- 오리엔테이션만 받고 수업에 참여하지 않은 경우
- 휴강·취소된 수업
- 중복·테스트·동기화 오류 기록

## 6. 첫 수업 전 준비 기준

### 6.1 운영 안내

- 지점과 수업을 혼동하지 않도록 정확한 장소를 확인한다.
- 날짜·도착 권장 시각·수업 시작 시각을 구분한다.
- 복장·도복·준비물은 해당 지점의 확인된 정책만 안내한다.
- 가격·무료 체험·혜택·취소 기준은 승인된 정보만 안내한다.
- 주차·출입·탈의·보관 등 시설 정보는 실제 지점 자료가 있을 때만 제공한다.

### 6.2 안전·참여 안내

- 참여 동의와 마케팅 동의를 분리한다.
- 촬영 동의는 수업 참여 동의와 분리한다.
- 미성년자 본인의 서명과 보호자 권한 확인을 동일하게 취급하지 않는다.
- 건강·부상 정보는 안전에 필요한 최소 범위만 수집한다.
- 건강 상태를 근거 없이 추정하거나 공개 콘텐츠에 옮기지 않는다.
- 안내 완료는 기술 이해·숙련 또는 무사고 보장을 뜻하지 않는다.

## 7. 현장 온보딩 체크리스트

프로그램·연령별로 승인된 항목만 사용한다.

1. 담당 코치 또는 현장 책임자 확인
2. 공간·출입·비상 안내
3. 수업 진행 방식의 간단한 안내
4. 확인된 복장·도복·준비물 점검
5. 안전·중단 요청·질문 방법 안내
6. 첫 수업의 실제 참여 확인
7. 수업 후 질문 또는 불편사항 확인
8. 다음 예약 방법 또는 담당 연락 경로 안내

모든 항목을 같은 사람이 처리할 필요는 없지만, 최종 책임자는 한 명이어야 한다.

## 8. 담당자·업무 인계

### 8.1 필수 필드

- 온보딩 작업 ID
- 익명화된 회원 키
- 지점·프로그램
- 담당자 역할과 백업 역할
- 생성 시각·기한·완료 시각
- 현재 상태와 다음 조치
- 누락·예외·인계 사유
- 원장 링크 또는 사건 ID

### 8.2 중복 방지

- 동일 회원권·프로그램에 활성 온보딩 작업을 하나만 둔다.
- 지점 이동은 신규 등록으로 다시 집계하지 않는다.
- 가족·동일 연락처는 자동으로 한 사람으로 합치지 않는다.
- 체험 전환과 신규회원 온보딩 성과를 같은 전환으로 중복 집계하지 않는다.
- 코치·지점·채널은 기여 차원으로 남기되 실수납을 중복 배분하지 않는다.

## 9. 연락 기준

### 9.1 운영 알림과 마케팅의 분리

- 예약 확정·변경·준비물·안전 안내는 운영 목적이다.
- 행사·혜택·상품·재등록 권유는 마케팅 또는 판매 목적일 수 있다.
- 운영 연락에 동의했다는 이유로 마케팅 연락 자격을 만들지 않는다.
- 전달·열람·링크 클릭을 답장·예약·출석으로 승격하지 않는다.

### 9.2 외부 발송 전 승인

다음 항목이 승인되지 않으면 실제 발송하지 않는다.

- 대상 자격
- 목적과 법적 근거
- 채널과 발신 주체
- 문구
- 발송 시점·빈도·야간 제한
- 수신거부·중단 처리
- 미성년자 보호자 권한
- 담당자와 예외 인계

### 9.3 이벤트 기반 초안

외부 사례의 고정 시점을 그대로 복사하지 않고 사건으로 시작한다.

- `MEMBERSHIP_ACTIVE` 후 첫 수업 미예약: 예약 방법 안내 검토
- `FIRST_CLASS_BOOKED` 후: 확인된 준비 정보 안내 검토
- `FIRST_ATTENDED` 후: 질문·불편사항 확인 검토
- `SECOND_CLASS_BOOKED` 미발생: 운영 누락과 참여 장애 검토
- 반복 취소·미참여: 제재보다 원장 오류·휴회·수업 변경 여부 우선 검토

실제 메시지 발송은 대표 승인과 연락 자격 확인 후에만 한다.

## 10. 초기 활성화 정의

### 10.1 권장 구성요소

초기 활성화는 하나의 사건이 아니라 다음 요소의 조합으로 정의한다.

- 활성 회원권 확인
- 첫 유효 수업 실참여
- 필수 안전·운영 안내 완료
- 질문 또는 불편사항을 전달할 경로 인지
- 다음 수업 예약 또는 실제 후속 참여
- 승인된 관찰 구간의 출석 확인

### 10.2 자동 판정 금지

- 결제 1회만으로 활성화 완료로 판정하지 않는다.
- 첫 수업 1회만으로 습관 형성·유지를 선언하지 않는다.
- 외부 연구의 방문 횟수나 기간을 내부 합격선으로 복사하지 않는다.
- 출석 공백으로 건강·경제·동기·불만 원인을 추정하지 않는다.
- 코치의 개인 경험·철학을 자료 없이 회원 안내에 삽입하지 않는다.

- 개인 연락처나 회원 사례를 공개 글에 옮기지 않는다.

## 13. 귀속 기준

### 13.1 획득과 활성화의 분리

- 최초 유효 유입 채널은 획득 귀속으로 남긴다.
- 온보딩 담당 코치와 지점은 운영 기여로 남긴다.
- 첫 참여·두 번째 참여·재등록은 각각 별도 결과다.
- 하나의 회원·결제·출석 사건을 여러 채널의 성과로 중복 계산하지 않는다.

### 13.2 매출 귀속

- 청구 예정·결제 시도·승인·실수납을 구분한다.
- 회원권 활성화와 실수납을 구분한다.
- 환불 가능 기간과 취소·부분환불을 반영한다.
- 등록·첫 참여·온보딩 완료를 매출로 계산하지 않는다.
- 재등록 의향·예약·계약서 작성은 실수납이 아니다.

## 15. 실험 설계

### EXP-395 — 신규회원 온보딩·첫 수업·초기 활성화 귀속 정확도

#### 대상

- 합성 신규회원 여정 360건
- 등록·회원권·예약·출석 사건 1,080건
- 온보딩 작업·안내·연락 사건 720건

실제 고객 연락·계정 변경·결제·예약 변경 없이 합성 데이터로만 검증한다.

#### 성공 기준

다음 오류가 모두 0건이어야 한다.

- 체험 방문자의 활성회원 오분류
- 등록 시작·서명·결제의 온보딩 완료 오분류
- 예약·대기·체크인의 첫 실참여 오분류
- 휴강·취소 수업의 노쇼 또는 실참여 오분류
- 첫 참여의 지속 출석·재등록 자동 승격
- 보호자 권한 미확인 상태의 완료 처리
- 운영 알림 자격의 마케팅 동의 자동 승격
- 연락 자격 미확인 발송
- 지점·가구·프로그램 간 중복 온보딩
- 채널·코치·지점의 실수납 중복 귀속
- 개인정보·건강정보·승인 대기 콘텐츠의 공개 노출

#### 중단 기준

- 위 오류가 한 건이라도 발생하면 실제 자동화 적용을 중단한다.
- 기준 원장이나 담당자가 없는 상태에서는 고객 대상 자동 발송을 시작하지 않는다.
- 안전·보호자·결제 예외를 자동으로 종료하지 않는다.

## 17. 역할별 실행

- 체험·등록·결제·예약·체크인·출석·재등록을 사건 단위로 분리한다.
- 분자·분모·기간·원천이 없는 지표는 계산하지 않는다.

### Acquisition Marketer

- 광고·검색·지역 콘텐츠의 성과를 문의에서 끝내지 않고 첫 실참여까지 연결한다.
- 미확정 시간표·가격·무료·혜택을 소재로 사용하지 않는다.

### CRM Marketer

- 운영 안내와 마케팅 연락을 분리한다.
- 발송 전 연락 자격과 수신거부를 확인한다.

### Content Strategist

- 입문 교육과 실제 지점의 운영 약속을 구분한다.
- 코치 개인 계정에 확인되지 않은 1인칭 경험·지도 철학을 만들지 않는다.

### Experiment Manager

- 먼저 합성 데이터로 상태 전이와 중복 귀속을 검증한다.
- 외부 발송·결제·회원권 변경 없이 성공·중단 기준을 판정한다.

### Auditor

- 개인정보·민감정보·승인 대기 콘텐츠·미확정 행사의 공개 여부를 점검한다.
- 과장된 효과·안전 보장·근거 없는 가격·성과 수치를 차단한다.
