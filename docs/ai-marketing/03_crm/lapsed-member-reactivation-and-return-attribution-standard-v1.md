- 선행 기준: member-attendance-risk-and-retention-triage-standard-v1.md

## 1. 목적

휴면회원 복귀를 단순 메시지 발송 수나 답장 수로 계산하지 않는다. 다음 사건을 구분해 실제 복귀와 수익기여를 과장 없이 판단한다.

1. 휴면 후보 추출
2. 계약·출석·휴회·지점이동 확인
3. 휴면 상태 검증
4. 연락 목적과 광고성 여부 판정
5. 매체별 수신동의·수신거부 확인
6. 연락 대상 승인
7. 실제 발송과 전달 결과
8. 회원 응답과 복귀 의사
9. 복귀 예약
10. 실제 복귀 출석
11. 계약 재시작 또는 재등록
12. 결제와 순수납
13. 재활성 관찰창 성숙
14. 캠페인 기여 판정

이 기준의 목적은 연락량을 늘리는 것이 아니라, 연락할 수 있는 대상에게 적법하고 검증 가능한 방식으로 접근하고 실제 복귀를 측정하는 것이다.

## 2. 용어와 경계

### 2.1 휴면은 하나의 계약 상태가 아니다

휴면 후보에는 서로 다른 상태가 섞일 수 있다.

- 유효 계약이 있으나 승인된 기간 동안 검증 출석이 없는 회원
- 승인된 휴회 상태인 회원
- 계약이 만료된 이전회원
- 해지 효력이 발생한 이전회원
- 미래 시작 계약자
- 지점 이동 회원
- 다른 지점에서 출석 중인 회원
- 예약·체크인 데이터가 지연된 회원
- 도장 휴강·정원 제한으로 출석하지 못한 회원

따라서 휴면 후보 목록을 곧바로 연락 대상이나 복귀 캠페인 분모로 사용하지 않는다.

### 2.2 출석위험과 휴면 검증

출석 감소 신호와 휴면 상태는 member-attendance-risk-and-retention-triage-standard-v1.md에서 구분한다.

이 문서는 승인된 휴면 또는 이전회원 상태가 검증된 뒤 재활성 경로를 다룬다.

### 2.3 복귀와 재등록

- 복귀 의사: 돌아오겠다는 표현
- 복귀 예약: 수업 또는 상담 예약
- 복귀 출석: 실제 수업 참석
- 계약 재시작: 승인된 계약 원천에서 효력 확인
- 재등록: 승인된 재등록 정의 충족
- 재활성: 승인된 관찰기간과 활동 조건 충족

이 상태들은 서로 대체하지 않는다.

## 3. 핵심 원칙

1. 휴면 후보는 휴면 확정이 아니다.
2. 휴회회원은 승인된 종료일과 복귀 규칙을 확인하기 전 일반 마케팅 대상에 넣지 않는다.
3. 다른 지점의 검증 출석은 원지점의 휴면으로 계산하지 않는다.
4. 예약·상담·답장은 실제 복귀 출석이 아니다.
5. 계약 생성·결제 시도는 재등록·순수납이 아니다.
6. 메시지 생성·예약·플랫폼 수락은 실제 전달·열람·응답과 다르다.
7. 무응답은 거절, 불만, 경제 사정, 타 도장 이동을 의미하지 않는다.
8. 복귀 사유는 회원이 직접 확인한 범주만 사용한다.
9. 광고성 정보는 운영 안내로 위장하지 않는다.
10. 매체별 수신동의와 수신거부 상태를 확인한다.
11. 수신거부나 동의 철회가 확인되면 광고성 연락을 중단한다.
12. 혜택·쿠폰·무료 기간은 대표 승인과 광고성 정보 준수 없이 제안하지 않는다.
13. 외부 업체의 복귀율·빈도·기간·ROI 수치를 내부 목표로 복사하지 않는다.
14. 성숙 코호트와 비교 기준이 없으면 증분 효과를 주장하지 않는다.
15. 공개 저장소에는 개인 연락 이력이나 대상 명단을 저장하지 않는다.

## 4. 법적·운영 분류

이 문서는 법률 자문이 아니라 운영 통제 기준이다. 실제 캠페인 시행 전 최신 법령과 공식 안내, 내부 개인정보 처리 근거를 다시 확인한다.

### 4.1 운영 안내

계약 이행, 예약 변경, 휴강, 결제 오류 등 현재 거래의 필수 안내인지 검토한다.

운영 안내에 복귀 혜택·판매 권유·재등록 촉진을 섞으면 광고성 정보로 분류될 수 있으므로 목적과 문구를 분리한다.

### 4.2 광고성 정보

재등록 권유, 복귀 혜택, 쿠폰, 무료 체험, 상품 판매 등 영리 목적의 촉진 내용은 광고성 여부를 검토한다.

다음은 승인 전 필수 확인 항목이다.

- 전송 목적
- 전송 매체
- 명시적 사전 동의 또는 적용 가능한 예외 근거
- 동의 일자와 증거
- 수신거부·동의 철회 상태
- 야간 전송 여부와 별도 동의 필요성
- 전송자 표시
- 쉽게 이용 가능한 수신거부 방법
- 처리 결과 기록
- 문구 승인자

### 4.3 금지

- 혜택 알림·정보 제공처럼 모호한 표현으로 광고 동의를 받기
- 수신거부 절차를 어렵게 만들기
- 수신거부 후 광고성 메시지를 계속 보내기
- 고객 명단을 공개 저장소나 승인되지 않은 외부 도구에 올리기
- 동의가 확인되지 않은 연락처를 임의로 보완·생성하기
- 운영 안내를 광고성 메시지의 우회 경로로 사용하기

## 10. 귀속 규칙

### 10.1 기본 귀속

다음 항목이 모두 있어야 캠페인 연결을 검토한다.

- 동일한 내부 대상 식별자
- 승인된 캠페인 ID
- 적격·승인·실제 발송 증거
- 복귀 예약 또는 실제 출석 사건
- 승인된 귀속 관찰기간
- 캠페인 이전 상태
- 다른 동시 캠페인과 자연 복귀 검토
- 지점·프로그램 일치 또는 승인된 이동 규칙

### 10.2 귀속 상태

| 상태 | 의미 |
|---|---|
| ATTRIBUTION_UNCONNECTED | 캠페인과 결과 연결 불가 |
| ATTRIBUTION_PENDING | 관찰창 미성숙 |
| CONTACTED_BEFORE_RETURN | 복귀 전 승인 연락 확인 |
| ORGANIC_RETURN | 승인 연락 없이 복귀 |
| MULTI_TOUCH_REVIEW | 여러 캠페인 접촉 |
| CAMPAIGN_ASSOCIATED_RETURN | 규칙상 연결 가능 |
| INCREMENTALITY_UNPROVEN | 연결은 있으나 증분 효과 미검증 |
| INCREMENTAL_LIFT_VERIFIED | 승인 비교 설계에서 증분 확인 |
| REVENUE_ATTRIBUTION_UNCONNECTED | 순수납·비용 연결 불가 |

연락 후 복귀했다는 시간 순서만으로 인과를 확정하지 않는다.

### 10.3 비교 설계

가능하면 동일 지점·프로그램·휴면 상태의 성숙 대상 중 승인된 비교군을 둔다.

다음을 기록한다.

- 배정 기준
- 제외 기준
- 발송 정책
- 오염 여부
- 비교 기간
- 실제 복귀 출석
- 계약 재시작
- 환불 반영 순수납
- 직접비

비교군 운영이 부적절하거나 표본이 부족하면 증분 효과를 계산하지 않는다.

## 11. 연락 빈도와 종료

빈도와 기간은 대표 승인 없이 정하지 않는다. 외부 업체의 월별·연간 접촉 횟수를 복사하지 않는다.

다음 조건에서는 일반 재활성 연락을 종료한다.

- 수신거부 또는 동의 철회
- 명시적 연락 중단 요청
- 분쟁·민원·안전·개인정보 이관
- 보호자 경로 미확인
- 중복 대상
- 계약·출석 상태 오류
- 승인된 최대 접촉 횟수 도달
- 캠페인 종료
- 실제 복귀 후 일반 온보딩·유지관리로 인계

## 12. 채널별 실행 연결

### 12.1 네이버

복귀 대상에게 개별 연락하는 대신 공개 가능한 최신 시간표·문의 경로의 정확성을 먼저 확인한다. 클릭·길찾기는 복귀 출석이 아니다.

### 12.2 Instagram 코치 개인 계정

코치의 유도 상식·입문 질문·수련 관점을 중심으로 한다. 휴면회원에게 직접 보내는 캠페인 문구나 공식 혜택 공지로 사용하려면 별도 승인과 사실 확인이 필요하다.

공개 게시물 도달·저장·프로필 방문은 실제 복귀 출석과 분리한다.

### 12.3 당근

실제 운영 지점과 지역 범위가 확인된 경우에만 공개 소식을 사용할 수 있다. 채팅 시작·쿠폰 조회·예약 의사는 실제 복귀 출석이나 재등록이 아니다.

## 13. KPI 정의

모든 KPI는 기간, 지점, 프로그램, 규칙 버전, 분자, 분모, 성숙일, 원천을 표시한다.

### 13.1 휴면 판정 완전율

분자: 계약·출석·휴회·교차지점·도장 예외 검증이 완료된 휴면 후보 수

분모: 판정 기한이 지난 유효 휴면 후보 수

### 13.2 연락 적격률

분자: 목적·동의·수신거부·채널·정책 검증을 통과한 대상 수

분모: 연락 검토 기한이 지난 검증 휴면 대상 수

### 13.3 실제 발송률

분자: 발송 증거가 확인된 대상 수

분모: 승인된 발송 대상 수

발송률은 전달률·응답률이 아니다.

### 13.4 응답률

분자: 승인 관찰창 안에 응답이 확인된 대상 수

분모: 전달 여부 기준이 동일한 성숙 발송 대상 수

전달 상태를 확인할 수 없으면 그 한계를 표시한다.

### 13.5 복귀 예약률

분자: 복귀 예약이 검증된 대상 수

분모: 예약 관찰창이 성숙한 유효 발송 대상 수

### 13.6 복귀 출석률

분자: 실제 복귀 출석이 검증된 대상 수

분모: 출석 관찰창이 성숙한 유효 발송 대상 수

예약을 분자에 포함하지 않는다.

### 13.7 계약 재시작률

분자: 계약 효력 재시작이 검증된 대상 수

분모: 계약 관찰창이 성숙한 유효 발송 대상 수

### 13.8 재활성률

분자: REACTIVATION_MATURED 대상 수

분모: 동일한 규칙과 관찰창이 성숙한 복귀 출석 대상 수

### 13.9 순수납과 증분 기여

순수납 = 확인 결제 - 환불 - 차지백

증분 순수납 = 캠페인군 순수납 - 승인 비교 기준 순수납

증분 기여 = 증분 순수납 - 승인된 직접비

분모가 0이거나 비교 설계·비용 데이터가 없으면 계산하지 않는다.

## 14. 네 목표와의 연결

| 목표 | 직접 신호 | 과대계상 방지 |
|---|---|---|
| 신규 체험회원 확보 | 복귀회원과 신규 체험 분리 | 복귀를 신규 등록으로 계산 금지 |
| 휴면회원 복귀 | 실제 복귀 출석·재활성 | 답장·예약을 복귀로 계산 금지 |
| 기존회원 재등록·만족 | 계약 재시작·후속 유지 | 혜택 수락을 만족으로 계산 금지 |
| 매출 증대 | 환불 반영 순수납·증분 기여 | 정가·결제 시도·총액 과대계상 금지 |

## 15. 실험 설계: EXP-311

### 가설

휴면 판정과 연락 적격을 먼저 검증하고, 답장·예약·출석·계약·순수납을 분리하면 복귀 캠페인의 실제 병목과 기여를 측정할 수 있다.

### 대상

대표가 승인한 지점·프로그램의 성숙한 검증 휴면 코호트

### 기간

승인·데이터 연결 후 최초 30일 또는 대표가 승인한 관찰기간

### 성공 기준

- 휴면 후보의 계약·출석·휴회·교차지점 검증률 100%
- 연락 대상의 목적·매체·수신동의·수신거부 검증률 100%
- 승인 대상과 실제 발송 혼합 0건
- 답장·예약·출석·계약 재시작 혼합 0건
- 자연 복귀의 캠페인 귀속 0건
- 미성숙 관찰창의 실패 처리 0건
- 수신거부 후 광고성 연락 0건
- 공개 개인정보·개인 원장 0건

### 보류 기준

- 휴면·복귀·재활성 정의 미확정
- 계약·출석·동의 기준 시스템 미연결
- 연락 문구·채널·빈도·시간 미승인
- 성숙 코호트 없음
- 비교 기준과 비용 원천 미확정

### 중단 기준

- 휴면 후보 명단에 즉시 일괄 발송
- 운영 안내로 위장한 광고성 정보
- 수신거부·동의 철회 무시
- 승인 없는 혜택·쿠폰·무료 기간 제안
- 예약이나 답장을 실제 복귀로 계산
- 건강·가족·경제 사유 추정
- 개인별 원장 또는 연락처 공개

### 현재 기준선

데이터 미연결

## 16. 역할별 책임

### CMO

복귀 메시지 수보다 실제 복귀 출석과 재활성 성숙을 우선 KPI로 둔다.

### Growth Analyst

휴면 후보, 검증 휴면, 연락 적격, 발송, 응답, 예약, 출석, 계약, 순수납을 같은 코호트로 연결한다.

### Acquisition Marketer

복귀회원과 신규 체험회원을 분리하고 공개 채널 반응을 복귀 성과로 과대계상하지 않는다.

### CRM Marketer

목적·동의·수신거부·채널·빈도·종료 조건을 검증한 뒤 승인 대상만 관리한다.

### Content Strategist

공개 콘텐츠는 최신 지점·수업·문의 정보와 일치시킨다. 개인 계정의 콘텐츠를 공식 복귀 공지로 오인시키지 않는다.

### Experiment Manager

동일한 규칙과 성숙 관찰창의 비교군에서만 증분 복귀와 순기여를 계산한다.

### Auditor

광고성 정보 규정, 개인정보 최소화, 자연 복귀 오귀속, 미확정 혜택, 수익 과장을 검토한다.
