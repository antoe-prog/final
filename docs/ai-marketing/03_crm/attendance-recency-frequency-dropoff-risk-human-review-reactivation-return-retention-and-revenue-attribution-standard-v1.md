# 출석 최근성·빈도 감소 신호, 사람 검토, 복귀·재등록·순수납 귀속 기준 v1

- 적용 대상: 파이널유도멀티짐의 신규 체험, 기존회원 유지, 휴면 복귀, 재등록, 매출 분석
- 문서 성격: 공개 가능한 운영·측정 기준
- 기준일: 2026-09-20
- 실험 ID: `EXP-437`

## 1. 목적

출석 감소를 조기에 발견하되 한두 번의 결석이나 데이터 누락을 휴면으로 단정하지 않는다. 출석 신호, 사람 검토, 연락 가능 여부, 실제 복귀, 재등록, 실정산을 각각 다른 사건으로 기록한다.

이 기준은 자동 고객 발송을 허가하지 않는다. 실제 대상자 선정, 연락, 계정 변경, 혜택 제공은 대표 승인과 적법한 연락 근거가 있을 때만 수행한다.

## 2. 핵심 원칙

1. **출석 감소는 검토 신호이지 휴면 확정이 아니다.**
2. 예상 수업을 알 수 없으면 결석률을 계산하지 않는다.
3. 체크인과 실제 수련 완료는 분리한다.
4. 동결·해지·프로그램 변경·타 지점 이용은 서로 다른 상태다.
5. 서비스 안내와 광고성 복귀 제안의 연락 근거를 분리한다.
6. 예약은 복귀가 아니며, 실제 복귀는 재등록이 아니다.
7. 계약 활성과 청구, 승인, 입금, 환불·차지백을 분리한다.
8. 휴면 복귀와 재등록을 신규회원으로 중복 집계하지 않는다.

## 3. 판정 상태

### 3.1 출석 관찰

`EXPECTED_SESSION_DEFINED → ELIGIBLE → BOOKED_OR_OPEN_ACCESS → CHECKED_IN → ATTENDANCE_CONFIRMED`

- `EXPECTED_SESSION_DEFINED`: 회원별로 관찰기간에 참여가 기대되는 수업 또는 허용 이용 방식이 정의됨
- `ELIGIBLE`: 멤버십·프로그램·지점 기준으로 해당 수업에 참여 가능
- `BOOKED_OR_OPEN_ACCESS`: 예약 수업은 예약 상태, 자유 이용은 예약 불필요 상태
- `CHECKED_IN`: 키오스크·앱·직원 처리 등으로 입장 기록 생성
- `ATTENDANCE_CONFIRMED`: 중복·오수업·오입력을 제거한 실제 출석 근거 확정

예상 수업이 없거나 자유 이용 빈도의 기준이 승인되지 않으면 결석률은 `계산 불가`다.

### 3.2 위험 신호와 검토

`OBSERVATION_WINDOW_CLOSED → SIGNAL_GENERATED → HUMAN_REVIEWED → CLASSIFIED`

`CLASSIFIED`는 다음 중 하나다.

- `NO_ACTION`: 정상 변동 또는 데이터 오류
- `SERVICE_FOLLOW_UP`: 일정·등록·운영상 확인 필요
- `REACTIVATION_CANDIDATE`: 승인된 기준에 맞는 복귀 검토 대상
- `HOLD_OR_EXCLUDED`: 동결·해지·타 프로그램·타 지점 등 제외 상태
- `INSUFFICIENT_DATA`: 최근성·빈도·기대 수업·신분 중 핵심값 부족

단일 결석, 최근성 하나, 시스템의 `inactive` 알림만으로 자동 분류하지 않는다.

### 3.3 연락과 복귀

`CONTACT_ELIGIBLE → OUTREACH_APPROVED → MESSAGE_SCHEDULED → MESSAGE_SENT → DELIVERED → REPLIED → RETURN_BOOKED → RETURN_ATTENDED`

- 동의·수신거부·채널·보호자 관계가 확인되지 않으면 `CONTACT_ELIGIBLE`로 올리지 않는다.
- 예약 또는 자리 제안을 `RETURN_ATTENDED`로 계산하지 않는다.
- 무응답은 거절이 아니며, 전송 성공은 도달·열람·회신이 아니다.

### 3.4 회원·매출 결과

`RETURN_ATTENDED → MEMBERSHIP_REACTIVATED_OR_RENEWED → CHARGE_CREATED → SETTLED → NET_REVENUE_CONFIRMED`

- 복귀 참석과 재활성·재등록을 분리한다.
- 청구 생성과 실정산을 분리한다.
- 순수납은 실정산에서 해당 환불·차지백을 뺀 값이다.
- 하나의 결제를 신규·복귀·재등록 또는 여러 채널에 중복 귀속하지 않는다.

## 4. 사람 검토 제외 항목

다음은 자동 복귀 대상에서 제외하고 상태를 확인한다.

- 멤버십 동결 또는 공식 휴회
- 계약 종료·해지
- 프로그램·시간대·지점 변경
- 출석 추적을 사용하지 않는 수업 또는 자유 이용
- 체크인 누락·중복·잘못 선택된 세션
- 보호자와 실제 참여자 불일치
- 승인된 연락 채널 또는 광고성 연락 동의 없음
- 건강·부상 등 민감 사유: 공개 분석과 공개 저장소에 저장하지 않음

## 5. 최소 데이터

### 5.1 출석 신호

- 가명 회원 키
- 지점·프로그램·세션 키
- 관찰기간 시작·종료
- 예상 참여 횟수와 근거
- 확인된 출석 횟수
- 마지막 확인 출석일
- 체크인 원천과 중복 제거 상태
- 멤버십·동결·해지 상태 및 효력일

### 5.2 검토·연락

- 신호 생성일과 규칙 버전
- 사람 검토자·검토일·분류 결과
- 연락 근거·허용 채널·수신거부 상태
- 승인자·승인일
- 예약·전송·도달·회신 사건의 별도 시각

### 5.3 결과·매출

- 복귀 예약·실제 복귀 출석
- 재활성 또는 재등록 효력일
- 계약·청구·승인·실정산 사건
- 환불·차지백
- 중복 방지용 단일 귀속 키

데이터가 연결되지 않은 지점·기간은 `데이터 미연결`로 표시한다. 빈 값은 0으로 바꾸지 않는다.

## 8. EXP-437

합성 지점 8개, 가명 회원 2,400명, 수업·체크인·동결·해지·연락·예약·출석·결제 사건으로 판정 정확도를 검증한다.

### 성공 기준

다음 오류가 모두 0건이어야 한다.

1. 예상 수업 미정인데 결석률 계산
2. 한 번 결석한 회원을 휴면으로 자동 확정
3. 동결·해지·지점 이동 대상을 복귀 캠페인에 포함
4. 누락 또는 중복 체크인으로 빈도 왜곡
5. 시스템 알림을 사람 검토 완료로 계산
6. 연락 동의 미확인 또는 수신거부 대상을 발송 후보로 생성
7. 예약·전송·도달을 회신 또는 실제 복귀로 계산
8. 복귀 출석을 재활성·재등록으로 계산
9. 휴면 복귀·재등록을 신규회원으로 중복 집계
10. 청구·승인을 실정산으로 계산
11. 환불·차지백 누락
12. 동일 매출을 복수 채널·지점·목표에 중복 귀속

하나라도 실패하면 자동 고객 발송, 자동 휴면 분류, 복귀 성과·매출 보고를 중단한다.
