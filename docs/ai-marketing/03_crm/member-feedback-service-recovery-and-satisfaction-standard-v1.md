# 회원 의견·서비스회복·만족도 판정 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 작성·검토일: 2026-09-14
- 적용 범위: 파이널유도멀티짐의 비식별 회원 의견·서비스 문제·만족도 집계
- 제외 범위: 회원·보호자 식별정보, 연락처, 개인별 건강·출석·결제 원장, 실제 발송 문구, 미확정 보상·혜택
- 관련 목표: 기존회원 만족·재등록, 휴면회원 복귀, 신규 체험 품질, 검증 수납 유지

## 1. 목적

설문 발송, 응답, 의견 접수, 문제 확인, 담당 배정, 조치 약속, 실제 조치, 회원 확인, 재등록을 각각 다른 사건으로 관리한다.

응답이 없다고 만족 또는 불만으로 해석하지 않는다.
의견을 받았다는 사실만으로 문제를 해결했다고 표시하지 않는다.
조치 완료만으로 만족·재등록·매출 개선을 주장하지 않는다.

## 2. 핵심 원칙

1. 만족도는 응답한 사람의 의견이며 전체 회원의 상태가 아니다.
2. 무응답은 중립점수나 만족으로 대체하지 않는다.
3. 칭찬, 제안, 문의, 서비스 문제, 안전 문제, 결제 분쟁을 구분한다.
4. 접수·담당 배정·조치 약속·실제 조치·회원 확인·종결을 분리한다.
5. 민감한 건강·가족·경제 사유는 공개 집계에 포함하지 않는다.
6. 여러 채널에서 들어온 같은 문제는 하나의 내부 사건으로 연결한다.
7. 지점별 문제를 전체 지점의 문제나 성과로 확대하지 않는다.
8. 후기 공개·사례 활용 동의는 운영 의견 수집 동의와 별도로 받는다.
9. 보상·할인·계약 변경·고객 연락은 별도 승인 없이 실행하지 않는다.
10. 데이터가 없거나 분모가 0이면 비율을 계산하지 않는다.

## 3. 범주 정의

### 3.1 칭찬

서비스나 수업에 대한 긍정적 의견이다.
칭찬 접수를 만족도 전체 점수나 재등록 의사로 계산하지 않는다.
공개 후기나 콘텐츠로 전환하려면 별도의 공개 사용 동의가 필요하다.

### 3.2 제안

시간표, 수업 구성, 시설, 예약, 안내 등에 대한 개선 아이디어다.
제안 수용 여부와 실제 실행 여부를 별도로 기록한다.

### 3.3 문의

답변이 필요한 정보 요청이다.
문의 해결과 서비스 문제 해결을 혼합하지 않는다.

### 3.4 서비스 문제

회원이 기대한 수업·예약·시설·안내·응대와 실제 경험 사이의 확인된 차이다.
문제의 원인은 확인 전 UNKNOWN으로 둔다.

### 3.5 안전·민감 이슈

부상, 괴롭힘, 차별, 아동·청소년 보호, 개인정보, 결제 분쟁은 일반 만족도 흐름에서 분리해 승인된 담당 절차로 이관한다.

- 중복 사건 연결 규칙

## 7. 설문 설계 원칙

### 7.1 분모

응답률의 분모는 실제 발송 대상이 아니라, 중복·발송 실패·수신중단을 제외한 유효 초대 수로 사전 정의한다.

응답률 =
유효 응답 수 ÷ 유효 초대 수

유효 초대 수가 0이면 계산하지 않는다.

### 7.2 만족도

평균 만족도는 실제 응답자만 대상으로 계산하고 다음을 함께 표시한다.

- 문항과 척도 버전
- 조사기간
- 유효 응답 수
- 유효 초대 수
- 응답률
- 지점·회원군 범위
- 무응답 처리 방식

응답률 없이 평균 점수만 보고하지 않는다.

### 7.3 비교

기간 간 비교에는 같은 문항·척도·대상 규칙을 사용한다.
문항이나 모집 방식이 바뀌면 연속 추세로 연결하지 않는다.
응답자 구성이 크게 다르면 개선 또는 악화로 단정하지 않는다.

## 8. 서비스회복 흐름

1. 의견을 접수한다.
2. 중복 사건 여부를 확인한다.
3. 일반 의견과 안전·개인정보·결제 분쟁을 분리한다.
4. 접수 확인 여부를 기록한다.
5. 담당 역할과 조치 기한을 지정한다.
6. 원인을 추정하지 않고 사실관계를 확인한다.
7. 승인된 조치를 계획한다.
8. 실제 조치 시각과 증거를 기록한다.
9. 회원 확인 상태를 기록한다.
10. 종결 또는 재개를 판정한다.
11. 재등록·출석·결제 결과는 별도 기준으로 성숙시킨다.

## 9. 상황별 처리

### 9.1 수업 관련 의견

수업 난이도, 설명, 상대 배정, 진행속도 의견은 실제 수업·담당·날짜를 내부에서 확인한다.
개별 기술평가나 건강정보를 공개 집계에 옮기지 않는다.

### 9.2 시간표·예약

게시된 시간표, 실제 개최, 예약 가능 상태를 대조한다.
대기등록·예약실패·도장 취소를 회원 불만 또는 노쇼로 자동 분류하지 않는다.

### 9.3 시설·환경

접수, 현장 확인, 임시조치, 최종조치, 회원 확인을 분리한다.
사진이나 영상에 회원이 식별되면 공개 저장하지 않는다.

### 9.4 응대·안내

누가 잘못했는지 추정하기 전에 접수 시각, 담당, 전달 내용, 답변 시각을 확인한다.
직원 개인 평가를 공개 문서에 포함하지 않는다.

### 9.5 공개 후기와 콘텐츠

의견 수집 동의는 Instagram·네이버·웹사이트 공개 동의가 아니다.
공개 사용에는 매체, 문구, 이미지, 기간, 익명화 범위를 확인한다.
미성년자·보호자·회원 식별정보는 승인 없는 홍보에 사용하지 않는다.

## 10. KPI 정의

### 10.1 접수 확인률

분자: ACKNOWLEDGED_VERIFIED 건
분모: 확인 목표시간이 지난 유효 접수 건

자동 수신 화면만 있고 사람이 확인하지 않은 경우 별도 표시한다.

### 10.2 담당 배정 완전성

분자: 담당 역할과 조치 기한이 모두 기록된 열린 건
분모: 열린 유효 서비스 문제 건

### 10.3 확인된 해결률

분자: RESOLVED_CONFIRMED 건
분모: 결과 관찰기간이 끝난 유효 서비스 문제 건

내부 조치 완료만 있는 건은 분자에서 제외한다.

### 10.4 재개율

분자: REOPENED 건
분모: 같은 기간의 RESOLVED_CONFIRMED 건

분모가 0이면 계산하지 않는다.

### 10.5 만족도 응답률

분자: 유효 응답 수
분모: 유효 초대 수

수신중단·중복·발송 실패 처리 기준을 함께 표시한다.

### 10.6 재등록 연계

문제 해결 후 재등록은 동일 내부 계약 사건이 연결되고 관찰기간이 끝난 경우에만 별도 분석한다.
해결 사실만으로 재등록이나 매출 기여를 주장하지 않는다.

## 11. 실험 EXP-305

### 가설

의견 접수부터 회원 확인까지 상태를 분리하면 미처리 건, 조치 약속만 있는 건, 반복 문제를 명확히 발견하고 만족도 과장을 줄일 수 있다.

### 기간

대표 승인 및 데이터 연결 후 최초 14일.
재등록 영향은 승인된 관찰기간이 끝난 성숙 코호트에서 별도 평가한다.

### 성공 기준

- 유효 접수의 접수시각·채널·지점 기록률 100%
- 열린 문제의 담당 역할·조치 기한 기록률 100%
- 조치 약속과 실제 완료의 혼합 0건
- 회원 확인 없는 해결 완료 판정 0건
- 중복 사건의 중복 성과 계산 0건
- 무응답의 만족 처리 0건
- 안전·개인정보·결제 분쟁의 일반 흐름 오분류 0건
- 공개 활용 동의 없는 후기 게시 0건
- 수신중단 후 연락 0건
- 공개 개인정보 0건

### 보류 기준

- 공식 접수 채널·담당 역할 미확정
- 문항·척도·설문 대상 미확정
- 심각도·이관·조치 기한 미확정
- 회원 확인과 종결 증거 미확정
- 재등록 관찰기간 미확정

### 중단 기준

- 승인 없는 메시지·보상·계약 변경 실행
- 무응답을 만족 또는 해결로 처리
- 민감 사유를 추정하거나 공개
- 공개 동의 없는 후기·이미지 활용
- 해결 전 문제를 홍보 성과로 전환
