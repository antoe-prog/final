- 탈의·보관·화장실·매트 진입 동선을 설명한다.

- 회원의 건강·부상 정보를 다른 회원 앞에서 묻거나 노출하지 않는다.

첫 수업에서 모든 규칙과 기술을 한꺼번에 설명하지 않는다. 승인된 최소 안내를 제공하고 이해 여부를 확인한다.

- 인사와 매트 출입 예절
- 수업의 큰 순서
- 중단·도움 요청 방법
- 파트너 연습의 기본 안전

- 수업 후 다음 행동

### 7.3 기술·성과 표현

- 첫 수업에서 특정 기술 습득을 보장하지 않는다.
- 체력·체중·통증·자신감의 변화를 약속하지 않는다.
- 코치의 실제 관찰과 시스템 기록을 구분한다.
- 다른 회원과 비교하거나 공개 평가하지 않는다.

### 8.1 목적

- 참여 사실과 안전 이상 여부 확인

- 다음 수업 또는 이용 방법 안내

- 불편·오류 접수

## 10. 만족·질문·불편 측정

### 10.1 만족도와 행동 분리

- 만족 응답은 실제 출석을 증명하지 않는다.
- 출석은 만족을 증명하지 않는다.
- 질문은 불만을 증명하지 않는다.
- 불만 접수는 해지 의사를 증명하지 않는다.
- 문제 해결은 재등록을 보장하지 않는다.
- 추천·후기 작성은 장기 유지를 증명하지 않는다.

### 10.2 최소 질문 영역

실제 설문 문구와 발송은 대표 승인 후 진행한다. 측정 영역은 다음처럼 분리한다.

- 수업 진행을 따라가기 어려운 지점이 있었는가
- 질문하거나 도움을 요청하기 쉬웠는가
- 다음 수업을 어떻게 이용하는지 알고 있는가
- 해결되지 않은 문의나 불편이 있는가
- 연락 중단 또는 채널 변경 요청이 있는가

건강·장애·심리·가족·재정 상황을 마케팅 설문에서 불필요하게 수집하지 않는다.

### 11.2 유지 정의

DAY_30_RETAINED는 대표가 승인한 정의를 충족하고 기준 출석·회원권 원장으로 검증될 때만 부여한다.

후보 정의 예시:

- 30일 종료일에 유효 회원권이 존재
- 승인된 최소 참여 조건 충족
- 해지·환불 완료 상태가 아님
- 데이터 누락 검토 완료

예시는 승인된 정책이 아니므로 실제 집계에 바로 적용하지 않는다.

### 11.3 장기 유지와 구분

첫 30일 유지, 다음 결제, 재등록, 60일·90일 유지, 장기 유지율은 각각 다른 지표다. DAY_30_RETAINED를 재등록이나 장기 유지로 표현하지 않는다.

## 15. KPI와 계산식

### 15.1 기본 수치

- 온보딩 적격 회원 수
- 담당자 배정·수락 수
- 첫 수업 예약·체크인·실제 참여 수

- 다음 행동 확인 수

- 불편 접수·조치 완료 수
- 30일 검토 완료 수
- 30일 유지 확인 수
- 휴회·해지·환불 수

### 15.2 계산식

- 첫 수업 참여율 = 첫 수업 실제 참여 신규회원 / 온보딩 적격 신규회원
- 질문 해결률 = 해결 확인 질문 / 유효 질문 접수
- 서비스 회복 완료율 = 고객 확인이 끝난 조치 / 유효 불편 접수
- 30일 검토 완료율 = 검토 완료 신규회원 / 30일 검토 도래 신규회원
- 30일 유지율 = 승인된 유지 정의 충족 신규회원 / 동일 시작기간 온보딩 적격 신규회원

모든 계산에는 분자·분모·기간·지점·출처를 표시한다. 분모가 0이거나 데이터가 없으면 계산 불가로 둔다.

### 15.3 금지되는 KPI 해석

- 안내 발송을 온보딩 완료로 계산
