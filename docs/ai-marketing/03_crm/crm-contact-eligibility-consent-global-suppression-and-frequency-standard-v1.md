# CRM 연락 적격성·수신동의·통합 차단·발송 빈도 기준 v1

- 문서 상태: 공개 운영 기준 초안
- 기준일: 2026-09-16
- 적용 대상: 휴면회원, 체험 후 미등록자, 만료예정자, 기존회원 대상 문자·카카오·이메일·앱푸시 연락
- 소유 역할: CMO / Growth Analyst / CRM / Auditor
- 현재 상태: 실제 고객 명단·동의·연락 이력 미연결, 발송 전
- 내부 회원·연락·복귀·재등록·매출: **데이터 미연결**
- 주의: 본 문서는 운영 통제안이며 개별 발송의 법률 적합성을 확정하지 않는다. 실제 적용 전 최신 법령·플랫폼 정책과 담당자 검토가 필요하다.

## 1. 목적

CRM 후보를 곧바로 발송 대상으로 사용하지 않고 다음을 분리한다.

`회원 상태 → 연락 목적 → 광고성 여부 → 동의·예외 검토 → 수신거부·차단 대조 → 채널·시간 적격성 → 대표 승인 → 발송 → 전달·반응 → 복귀·재등록·순수납`

다음 오류를 방지한다.

1. 휴면 또는 미등록 상태만으로 광고 연락이 가능하다고 판단
2. 서비스 안내에 혜택·수업 홍보를 섞고 비광고성으로 처리
3. 한 지점의 수신거부를 다른 지점 발송에서 무시
4. 동의 범위를 다른 브랜드·서비스·채널로 확대
5. 앱 알림 허용을 광고성 정보 수신동의로 간주
6. 발송 성공을 복귀·재등록·매출로 계산
7. 같은 사람에게 지점·채널별 메시지를 중복 발송
8. 미성년 회원 연락처와 보호자 연락 권한을 추정

## 2. 최신 공개 변화 감시

2026-09-15 언론 보도는 정부의 스팸 수신량 조사 범위에 메신저를 추가하는 계획을 전했다. 이는 메신저 기반 CRM도 문자와 별개인 비규제 영역으로 보아서는 안 된다는 운영 신호다.

다만 확인 시점에 해당 보도의 내용을 확정하는 공식 공표문을 찾지 못했다. 따라서 다음 상태로 관리한다.

- `MESSENGER_SPAM_MEASUREMENT_REPORTED`: 언론 보도 확인
- `OFFICIAL_SCOPE_CHANGE_UNVERIFIED`: 공식 공표 미확인
- 정책·법률 변경으로 단정하지 않음
- 현재의 정보통신망법·KISA 안내서·플랫폼 정책을 계속 기준으로 사용

## 3. 대상 상태와 연락 적격성의 분리

| 대상 상태 | 의미 | 연락 가능성 |
|---|---|---|
| TRIAL_NOT_ENROLLED | 체험 후 등록 사건 미확인 | 자동 발송 불가 |
| INACTIVE_CANDIDATE | 승인 기간 동안 출석 사건 미확인 | 자동 발송 불가 |
| MEMBERSHIP_EXPIRING | 회원권 만료 예정 | 목적별 분류 필요 |
| MEMBERSHIP_EXPIRED | 회원권 만료 확인 | 자동 발송 불가 |
| ACTIVE_MEMBER | 현재 회원 | 광고 동의와 별개 |
| RETURNED_VERIFIED | 복귀 후 실제 출석 확인 | 성과 후보 |
| RENEWED_VERIFIED | 유효 재계약 확인 | 성과 후보 |

‘휴면’은 내부 출석·계약 상태일 뿐 광고성 연락의 동의나 기존 거래관계 예외를 증명하지 않는다.

## 4. 연락 목적 분류

### 4.1 계약·서비스 이행 정보 후보

다음은 계약 또는 이용 요청의 이행과 직접 관련될 수 있다.

- 고객이 요청한 상담·견적에 대한 답변
- 확정 예약의 일시·장소·준비물 안내
- 수업 휴강·변경·안전·결제 사실 안내
- 회원권 상태나 청구 결과의 사실 통지
- 고객이 요청한 취소·환불 처리결과

그러나 다른 수업, 할인, 신규 상품, 이벤트, 복귀 혜택, 재등록 권유를 함께 넣으면 광고성 정보로 재분류될 수 있다.

### 4.2 광고성 정보 후보

다음 목적은 광고 검토 대상으로 둔다.

- 복귀 권유
- 체험 후 등록 권유
- 회원권 재등록·연장 권유
- 할인·쿠폰·선물·무료 혜택
- 신규 수업·지점·행사 홍보
- 친구 추천·리뷰 요청에 혜택 연결
- 정보 안내에 섞인 서비스 홍보

광고성이 조금이라도 혼재하면 `PROMOTIONAL_REVIEW_REQUIRED`로 분류한다.

### 4.3 만족·운영 조사

순수 만족 조사도 답변 뒤 혜택·등록·리뷰·추천을 유도하면 광고 또는 리뷰 정책 검토가 필요하다. 조사 응답을 후속 광고 동의로 사용하지 않는다.

## 6. 통합 차단명단

KISA 안내서는 본사와 지사가 고객정보를 공유하는 경우 수신거부 의사도 공유되는 것으로 설명한다. 파이널유도 다지점 운영에서는 지점별 발송 목록보다 통합 차단명단을 먼저 대조한다.

### 최소 차단 필드

실제 값은 비공개 시스템에만 저장한다.

- pseudonymous_contact_key
- suppression_scope
- source_branch
- source_channel
- opt_out_requested_at
- opt_out_processed_at
- processing_result_notified_at
- consent_withdrawal_scope
- last_consent_at
- consent_source_version
- channel_scope
- brand_scope
- reviewer_role
- correction_history
- deletion_or_retention_status

### 금지

- 공개 저장소에 이름·전화번호·이메일·카카오 ID 저장
- 지점별 파일에 차단명단 복사 후 수동 병합
- 수신거부자를 ‘휴면’ 또는 ‘미등록’ 세그먼트로 다시 활성화
- 다른 채널 동의를 근거로 문자·이메일·앱푸시 범위 확대
- 직원 개인 연락처나 개인 카카오 계정으로 우회 발송
- 연락처 형식을 조금 바꿔 차단 대조를 회피

## 7. 채널별 통제

### 7.1 문자

- 광고성 여부를 먼저 판정한다.
- 전송자, 연락처, 수신거부 방법 등 최신 법령·안내서상 표시 요건을 검토한다.
- 야간 전송은 별도 동의 요건을 확인한다.
- 고객에게 도달하는 시각을 기준으로 예약 발송 시간을 검토한다.
- 문자 수신동의를 카카오·이메일·앱푸시 동의로 확장하지 않는다.

### 7.2 카카오톡 채널

카카오 채널 운영정책은 광고성 메시지 앞의 광고 표시, 전송자 정보와 쉽게 실행되는 수신거부·철회 방법을 요구한다.

- 채널 메시지는 카카오 채널 정책과 법령을 함께 대조한다.
- 할인·프로모션·서비스 홍보가 혼재하면 광고성으로 처리한다.
- 개인 코치 계정의 친분 또는 과거 대화를 채널 광고 동의로 간주하지 않는다.
- `@ant.toe.98` Instagram 코치 개인 계정의 댓글·DM 관계를 CRM 연락 동의로 사용하지 않는다.
- 개인 카카오톡 발송은 별도 적법성·권한 검토 없이 대체 경로로 사용하지 않는다.

### 7.3 이메일

- 광고성 제목·전송자·연락처·수신거부 방법을 검토한다.
- 수신거부를 위해 로그인을 요구하지 않는다.
- 이메일 동의 범위와 실제 발송 서비스를 일치시킨다.

### 7.4 앱푸시

KISA 안내서는 운영체제의 알림 허용이 광고성 정보 수신동의를 대체하지 않는다고 설명한다.

- 기기 알림 허용과 광고 동의를 분리 저장한다.
- 로그인 상태와 대상 식별 가능성을 확인한다.
- 앱 설정에서 철회가 실제로 적용되는지 검증한다.
- 앱 미출시·미연결 상태에서는 발송 가능하다고 주장하지 않는다.

## 8. 발송 빈도와 중복 통제

법적 최소요건 충족 여부와 고객 피로도 관리는 별개다. 내부 빈도 상한은 대표 승인 전 **데이터 미연결**로 둔다.

### 발송 키

`pseudonymous_contact_key + purpose_family + campaign_id + channel + observation_window`

### 차단 순서

1. 통합 수신거부·철회
2. 연락처 수집 원천·보유 적격성
3. 전송자·브랜드·지점 범위
4. 채널 동의 범위
5. 고객 요청·계약 이행 여부
6. 동일 목적 최근 발송
7. 다른 지점·채널 중복
8. 응답 대기·진행 중 예약·등록
9. 해지·분쟁·민원·사고 검토
10. 승인된 빈도 상한
11. 승인된 시간대
12. 최종 문구·대상 승인

같은 사람이 여러 지점 기록에 있어도 하나의 고객 접점으로 대조한다.

## 9. 세그먼트별 실행 게이트

### 9.1 체험 후 미등록

- 실제 체험 방문 확인
- 등록 미확인과 거절·보류 구분
- 후속 연락 요청 또는 광고 연락 적격성 확인
- 진행 중 상담·예약 여부 대조
- 동일 목적 연락 이력 확인
- 대표 승인 후 발송

체험 참여 사실만으로 광고 연락 가능성을 확정하지 않는다.

### 9.2 휴면 후보

- 휴면 기준 버전 확인
- 휴회·부상·이사·해지·연락거부와 구분
- 최근 출석·결제·예약 지연 반영 확인
- 통합 차단명단 대조
- 복귀 권유의 광고성 검토
- 승인 전 발송 금지

### 9.3 만료예정

- 만료 사실 안내와 연장 권유를 별도 문구로 분리한다.
- 할인·혜택·등록 링크가 있으면 광고성 검토 대상으로 둔다.
- 자동갱신·청구 여부를 추정하지 않는다.
- 회원권 효력과 결제 상태를 대조한다.

### 9.4 기존회원

- 운영·안전 공지와 행사·상품 홍보를 분리한다.
- 출석·진도·승급 정보를 공개 축하나 재등록 압박에 자동 사용하지 않는다.
- 만족 조사 결과로 긍정 후기 요청 대상을 선별하지 않는다.

## 10. 퍼널과 KPI

`적격 후보 → 승인 대상 → 실제 전송 → 전달 → 회신 → 예약 → 실제 방문 → 복귀·재등록 → 순수납`

| KPI | 분자 | 분모 | 현재 |
|---|---|---|---|
| 연락 적격률 | 승인 가능한 후보 | 전체 세그먼트 후보 | 데이터 미연결 |
| 차단 대조율 | 차단 대조 완료 후보 | 전체 후보 | 데이터 미연결 |
| 중복 방지율 | 중복 제거 후보 | 중복 발견 후보 | 데이터 미연결 |
| 전달률 | 전달 확인 | 실제 전송 | 데이터 미연결 |
| 회신률 | 유효 회신 | 성숙한 전달 | 데이터 미연결 |
| 회신→예약 | 예약 확인 | 유효 회신 | 데이터 미연결 |
| 예약→실방문 | 실제 방문 | 성숙한 예약 | 데이터 미연결 |
| 휴면 복귀율 | 복귀 후 실제 출석 | 적격 휴면 연락 코호트 | 데이터 미연결 |
| 재등록률 | 유효 재등록 | 적격 만료예정 연락 코호트 | 데이터 미연결 |
| 순수납 기여 | 환불·차지백 반영 수납 | 귀속 코호트 | 데이터 미연결 |

전달 실패, 수신거부, 사업자 취소와 데이터 누락을 무응답으로 합치지 않는다. 분모가 0이거나 관찰기간·원천이 연결되지 않으면 계산하지 않는다.

## 11. 실험 EXP-336

### 0단계

합성 레코드 20건으로 다음을 검증한다.

- 서비스 안내와 광고성 혼재
- 채널 동의 불일치
- 본사·지점 수신거부
- 체험 후 미등록과 명시적 거절
- 휴면과 휴회·부상
- 만료 사실 안내와 재등록 권유
- 보호자 권한 미확인
- 동일인 다지점·다채널 중복
- 앱 알림 허용만 존재
- 동의 원천·범위 미확인

### 1단계

대표 승인 후 비식별 후보 20건 또는 14일을 발송 없이 감사한다.

### 성공 기준

- 연락 목적 분류율 100%
- 광고성 여부 검토율 100%
- 동의·전송자·채널 범위 확인률 100%
- 통합 차단명단 대조율 100%
- 수신거부자 발송 후보 0건
- 보호자 권한 미확인 후보 0건
- 지점·채널 중복 후보 0건
- 승인 없는 실제 메시지 발송 0건
- 발송·회신·예약·방문·등록 혼합 판정 0건

### 보류 기준

- 광고 동의 원천·버전·범위 미연결
- 본사·지점 통합 차단명단 미구축
- 메시지 목적·문구·채널 미승인
- 고객 기준 시스템과 비식별 연결키 미지정

### 중단 기준

- 휴면·미등록 상태만으로 연락 가능 판정
- 수신거부·철회 후 발송
- 다른 지점·브랜드·채널 동의로 범위 확대
- 개인 계정으로 우회 발송
- 서비스 안내에 광고를 섞고 비광고로 처리
- 승인 없는 혜택·광고·고객 연락 실행

현재 발송률·회신률·복귀율·재등록률·순수납 목표는 **데이터 미연결**이다.

## 13. 감사 메모

- 파이널유도의 실제 수신동의, 연락 가능 회원 수, 발송·회신·복귀·재등록·매출을 추정하지 않았다.
- 기존 회원, 체험자 또는 보호자라는 사실만으로 광고 연락 가능성을 인정하지 않았다.
- 언론 보도의 메신저 스팸 조사 확대를 확정 정책이나 법 개정으로 단정하지 않았다.
- 법률상 예외의 적용 여부는 실제 거래·수집·동의 사실 검토가 필요하므로 자동 승인하지 않았다.
- 고객 메시지, 광고, 계정 변경, 혜택 제공을 실행하지 않았다.
- 개인정보, 개인별 연락·출석·결제 원장, 승인 대기 Instagram 미디어·캡션과 미확정 FINAL ROAD 정보는 공개하지 않았다.
