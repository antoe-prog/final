# CRM 연락 동의·운영안내·광고성 정보·수신거부 적격성 기준 v1

- 문서 상태: 공개 가능한 운영·측정 기준
- 작성·검토일: 2026-09-15
- 적용 범위: 신규 문의, 체험후미등록, 휴면, 만료예정, 기존회원 대상 CRM 연락의 발송 전 판정
- 기준 시간대: Asia/Seoul
- 관련 목표: 신규 체험 확보, 휴면 복귀, 기존회원 재등록·만족, 검증 수납 기여
- 제외 범위: 실제 연락처·회원 ID·동의 원문·메시지 원문·개인별 출석·건강·계약·결제 원장, 비밀키·토큰, 미확정 가격·혜택·행사, 승인 대기 Instagram 콘텐츠

## 1. 목적

연락할 수 있는 데이터가 있다는 사실과 연락해도 된다는 사실을 분리한다.

다음 사건을 서로 다른 상태로 관리한다.

1. 연락처가 내부 시스템에 존재함
2. 연락 목적과 채널이 정해짐
3. 운영안내인지 광고성 정보인지 분류됨
4. 필요한 동의와 증거가 확인됨
5. 수신거부·연락중단·분쟁 제외가 반영됨
6. 문구·대상·채널·시점이 승인됨
7. 실제 발송이 실행됨
8. 전달·응답·문의·예약·참석·계약·정산이 각각 확인됨

회원가입, 문의, 체험 참석, 과거 결제, Instagram 팔로우를 포괄적인 광고 수신동의로 해석하지 않는다.

이 기준은 법률 자문을 대체하지 않는다. 실제 전송 전에는 현행 법령, KISA 안내서, 계약·동의 화면과 담당 법무 검토를 기준으로 세부 규칙을 확정한다.

## 2. 기존 문서와의 경계

- `inquiry-response-clock-and-aging-standard-v1.md`는 문의 접수부터 사람의 유효 답변까지의 시계를 다룬다.
- `dormant-member-return-eligibility-and-outcome-standard-v1.md`는 휴면 자격과 복귀 결과를 다룬다.
- `membership-expiry-renewal-readiness-outcome-standard-v1.md`는 만료예정과 재등록 결과를 다룬다.
- `member-feedback-service-recovery-satisfaction-and-renewal-signal-standard-v1.md`는 의견 접수와 해결 확인을 다룬다.
- 이 문서는 위 흐름에서 **누구에게, 어떤 채널로, 어떤 목적의 연락을 검토할 수 있는지**를 판정하는 공통 발송 전 게이트다.

## 3. 핵심 원칙

1. 연락처 보유를 동의로 바꾸지 않는다.
2. 동의는 채널·목적·범위·문구 버전·획득시각·증거가 확인돼야 한다.
3. 운영상 필요한 안내와 광고성 제안을 한 메시지에 섞지 않는다.
4. 혼합 메시지는 분리할 수 없으면 광고성 정보로 검토한다.
5. 수신거부와 연락중단은 캠페인 성과보다 우선한다.
6. 최신의 유효한 철회·중단 상태가 과거 동의보다 우선한다.
7. 한 채널의 동의를 다른 채널로 확대하지 않는다.
8. 공개 SNS 반응을 개인 메시지 동의로 해석하지 않는다.
9. 미성년자·보호자 관계와 연락 권한이 불명확하면 자동 발송하지 않는다.
10. 안전·건강·민원·결제 분쟁은 일반 마케팅 흐름에서 제외하고 사람에게 이관한다.
11. 메시지 발송량을 문의·복귀·재등록·매출로 계산하지 않는다.
12. 승인 없는 발송, 자동화 활성화, 할인·혜택 제공, 계정 변경을 하지 않는다.

## 4. 메시지 목적 분류

실제 문구 전체와 수신 맥락을 기준으로 분류한다. 제목이나 첫 문장만으로 판단하지 않는다.

| 분류 | 설명 | 예시 범주 | 기본 처리 |
|---|---|---|---|
| `ACTIVE_INQUIRY_REPLY` | 당사자가 현재 요청한 질문에 필요한 범위로 답변 | 방문 가능 여부, 준비물, 확인된 수업 안내 | 문의 범위와 종료시점 확인 |
| `SERVICE_OPERATIONAL` | 이미 합의되거나 이용 중인 서비스 수행에 필요한 안내 | 예약 확인·변경·취소, 휴강, 결제 결과, 계약상 필요한 안내 | 광고 문구 분리 후 검토 |
| `SAFETY_URGENT` | 안전 또는 긴급 운영 변경 | 시설 이용 중단, 긴급 일정 변경 | 최소 정보·담당 검토 |
| `MARKETING_PROMOTIONAL` | 구매·등록·복귀·추천·이벤트 참여를 권유 | 체험 제안, 할인, 혜택, 재등록 보너스, 휴면 복귀 캠페인 | 광고 수신 적격성 필수 |
| `MIXED_UNSPLIT` | 운영안내와 판촉이 한 메시지에 혼재 | 예약 변경 안내에 할인 제안 포함 | 분리 전 발송 보류 |
| `UNCLASSIFIED` | 목적 또는 문구가 불완전 | 빈 템플릿, 임시 메모 | 발송 금지 |

운영상 안내라는 이름을 붙여 판촉 내용을 우회하지 않는다. 반대로 실제 문의 답변을 마케팅 캠페인 성과로 부풀리지 않는다.

## 5. 연락 적격성 상태 코드

| 코드 | 의미 | 발송 판정 |
|---|---|---|
| `CONTACT_DATA_UNVERIFIED` | 연락처의 현재성·소유·원천 불명 | 금지 |
| `PURPOSE_UNCLASSIFIED` | 연락 목적 미분류 | 금지 |
| `ACTIVE_REPLY_SCOPE_CONFIRMED` | 현재 문의에 필요한 답변 범위 확인 | 승인된 답변만 검토 가능 |
| `OPERATIONAL_NOTICE_REVIEWED` | 운영안내 필요성과 비광고 문구 검토 | 승인 후 검토 가능 |
| `MARKETING_CONSENT_UNVERIFIED` | 광고 목적 동의 증거 불완전 | 금지 |
| `MARKETING_CONSENT_CONFIRMED` | 해당 채널·목적의 동의 증거 확인 | 다른 게이트 통과 후 가능 |
| `EXCEPTION_REVIEW_REQUIRED` | 법령상 예외를 주장하지만 조건 검증 전 | 자동 발송 금지 |
| `OPT_OUT_RECORDED` | 해당 채널 또는 목적 수신거부 확인 | 즉시 금지 |
| `STOP_ALL_NONMANDATORY` | 모든 비필수 연락 중단 요청 | 즉시 금지 |
| `DISPUTE_OR_SAFETY_HOLD` | 민원·안전·결제·개인정보 이슈 | 일반 흐름 제외 |
| `MINOR_AUTHORITY_REVIEW` | 미성년자·보호자 권한 불명 | 사람 검토 전 금지 |
| `DUPLICATE_CONFLICT_REVIEW` | 지점·채널·원천 간 상태 충돌 | 금지 |
| `APPROVED_TO_SEND` | 목적·동의·중단·문구·대상·시점 승인 완료 | 지정된 1회 실행만 가능 |
| `SENT_VERIFIED` | 승인본의 실제 발송 확인 | 전달·응답과 분리 |
| `DELIVERY_FAILED` | 전송 실패 확인 | 자동 재시도 금지 |

`MARKETING_CONSENT_CONFIRMED`만으로 발송할 수 없다. 대상 규칙, 문구, 채널, 발송시점, 빈도, 담당 승인과 중복 검사가 모두 필요하다.

## 6. 최소 비공개 입력 필드

실제 값은 접근 통제된 내부 시스템에만 둔다. 공개 저장소에는 필드 정의만 둔다.

| 구분 | 최소 필드 |
|---|---|
| 대상 | `internal_subject_id`, `lifecycle_stage`, `branch_code`, `program_code` |
| 채널 | `channel_code`, `contact_point_status`, `contact_point_verified_at` |
| 목적 | `purpose_code`, `message_class`, `campaign_or_case_id` |
| 동의 | `consent_status`, `consent_scope`, `consent_obtained_at`, `consent_source`, `consent_wording_version`, `consent_evidence_ref` |
| 철회 | `opt_out_scope`, `opt_out_at`, `stop_reason_code`, `suppression_status` |
| 문의 | `inquiry_received_at`, `inquiry_scope`, `reply_window_status` |
| 검토 | `legal_rule_version`, `policy_version`, `reviewed_by_role`, `reviewed_at` |
| 승인 | `audience_version`, `message_version`, `approved_by_role`, `approved_at`, `approval_expires_at` |
| 실행 | `send_attempt_at`, `send_status`, `delivery_status`, `provider_event_id` |
| 감사 | `source_system`, `loaded_at`, `conflict_status`, `correction_reason` |

전화번호, 전자우편, 메신저 ID, IP 주소, 기기 식별자, 동의 화면 원문은 공개 문서에 넣지 않는다.

## 7. 동의 증거 판정

다음 항목을 확인할 수 있어야 `MARKETING_CONSENT_CONFIRMED`로 판정한다.

- 누가 동의했는지 내부적으로 확인 가능
- 어떤 채널에 동의했는지 확인 가능
- 어떤 목적과 범위인지 확인 가능
- 동의 요청 문구와 화면 버전 확인 가능
- 동의 시각과 획득 원천 확인 가능
- 선택 동의가 필수 동의처럼 강제되지 않았는지 확인 가능
- 최신 철회·수신거부가 없는지 확인 가능
- 중복 레코드의 더 최근 상태와 충돌하지 않는지 확인 가능

다음은 단독 증거로 사용하지 않는다.

- 회원권 계약이 존재함
- 과거에 한 번 체험함
- 명함·문의서에 연락처를 적음
- Instagram을 팔로우하거나 게시물에 반응함
- 공개 프로필에 연락처가 보임
- 직원이 과거 대화했다고 기억함
- 발송 도구에서 `subscribed`로 표시되지만 원천 증거가 없음

## 8. 수신거부·연락중단 우선순위

수신거부 요청이 들어오면 다음 순서로 처리한다.

1. 요청 시각·채널·범위를 내부적으로 보존한다.
2. 활성 발송 대기열에서 해당 범위를 즉시 억제한다.
3. 예약된 캠페인과 재시도 대기열을 함께 검사한다.
4. 지점별 중복 레코드와 외부 발송 도구에 중단 상태를 전파한다.
5. 전파 완료 여부를 검증한다.
6. 법적으로 필요한 최소 기록 외에는 추가 판촉 연락을 하지 않는다.

철회 확인을 이유로 새로운 광고 문구를 보내지 않는다. 철회 후 재동의는 별도의 명시적 행동과 증거가 있을 때만 기록한다.

## 9. 혼합 메시지 분리 규칙

### 분리 대상

- 예약 변경 + 재등록 할인
- 휴강 안내 + 친구 추천 혜택
- 결제 실패 안내 + 상위 상품 권유
- 체험 준비물 답변 + 기간 한정 등록 제안
- 개인정보 정책 변경 + 휴면 복귀 이벤트

### 처리

1. 운영상 필요한 문장만 독립 메시지로 만든다.
2. 판촉 문장은 별도 캠페인과 별도 적격성으로 분리한다.
3. 분리할 수 없으면 전체를 `MIXED_UNSPLIT`로 보류한다.
4. 운영안내의 도달·응답을 마케팅 전환으로 귀속하지 않는다.

## 10. 생애주기별 적용

### 신규 문의

- 당사자가 물은 질문에 필요한 답변 범위를 기록한다.
- 자동 접수와 사람의 답변을 구분한다.
- 문의 답변에 할인·후기 요청·친구 추천을 끼워 넣지 않는다.
- 문의가 종료된 뒤 별도 판촉을 하려면 해당 채널의 광고 수신 적격성을 다시 확인한다.

### 체험후미등록

- 체험 결과와 다음 단계 합의 여부를 먼저 확인한다.
- 합의된 정보 전달과 새로운 등록 권유를 구분한다.
- 광고 동의가 불명확하면 자동 후속 캠페인에 넣지 않는다.
- 무응답을 동의, 거절, 가격 불만으로 해석하지 않는다.

### 휴면회원

- 오래된 연락처나 과거 동의를 현재 유효하다고 가정하지 않는다.
- 휴면정책 안내를 복귀 판촉에 이용하지 않는다.
- 연락 가능성과 휴면 자격을 각각 확인한다.
- 수신거부·분쟁·건강·휴회 상태는 일반 자동화에서 제외한다.

### 만료예정회원

- 실제 계약 만료 사실 안내와 재등록 혜택 제안을 분리한다.
- 계약 만료일·자동결제·가격이 검증되지 않으면 발송하지 않는다.
- 재등록 의향, 계약 시작, 성공 결제, 정산을 별도 사건으로 기록한다.

### 기존회원

- 예약·휴강·결제 결과·계약상 필요한 안내와 이벤트·추천·상품 제안을 분리한다.
- 만족도 조사도 목적·문구·채널의 적격성과 대표 승인을 확인한다.
- 긍정 리뷰나 별점을 혜택 조건으로 요구하지 않는다.

## 11. 채널별 통제

### 문자·메신저

- 발신 주체, 광고성 표시, 수신거부 방법 등 세부 형식은 현행 법령과 KISA 제7차 안내서 기준으로 법무 검토 후 고정한다.
- 야간 광고 전송은 별도 요건을 검증하지 못하면 기본 차단한다.
- 전달 실패를 동의 철회나 회원 이탈로 해석하지 않는다.

### 전자우편

- 운영안내와 뉴스레터·프로모션을 분리한다.
- 수신거부가 실제 억제 목록에 반영됐는지 검증한다.
- 열람·클릭을 문의·예약·등록으로 계산하지 않는다.

### Instagram DM

- 공개 팔로우·좋아요·댓글은 DM 광고 동의가 아니다.
- 당사자가 보낸 현재 질문에 대한 답변과 선제 판촉 DM을 구분한다.
- 코치 개인 계정의 답변을 파이널유도 공식 계약·가격 보증처럼 표현하지 않는다.
- 승인된 완성본 게시 절차와 개인별 DM 연락 절차를 혼합하지 않는다.

### 네이버·당근 채팅

- 사용자가 시작한 현재 문의의 범위를 기록한다.
- 채팅 기능 노출을 광고 수신동의로 해석하지 않는다.
- 지점 정보와 수업·가격은 검증된 원본만 사용한다.

### 앱 푸시

- 광고 동의 요청을 모호한 `혜택 알림`, `정보 제공` 같은 표현으로 숨기지 않는다.
- 광고 수신거부 절차를 로그인 등 불필요하게 복잡한 과정으로 만들지 않는다.
- 서비스 필수 알림과 광고 알림 설정을 분리한다.

## 12. 발송 전 8단계 게이트

| 단계 | 질문 | 미통과 상태 |
|---|---|---|
| G1 목적 | 왜 연락하는가 | `PURPOSE_UNCLASSIFIED` |
| G2 분류 | 운영·답변·광고·혼합 중 무엇인가 | `UNCLASSIFIED` 또는 `MIXED_UNSPLIT` |
| G3 원천 | 연락처와 생애주기 상태가 현재 유효한가 | `CONTACT_DATA_UNVERIFIED` |
| G4 동의 | 해당 채널·목적의 필요한 증거가 있는가 | `MARKETING_CONSENT_UNVERIFIED` |
| G5 억제 | 수신거부·중단·분쟁·중복이 없는가 | `OPT_OUT_RECORDED` 등 |
| G6 사실 | 가격·시간표·혜택·계약 정보가 검증됐는가 | `FACT_REVIEW_REQUIRED` |
| G7 승인 | 대상·문구·채널·시점·빈도가 승인됐는가 | `APPROVAL_REQUIRED` |
| G8 실행 | 승인본과 실제 발송본이 일치하는가 | `EXECUTION_REVIEW_REQUIRED` |

한 단계라도 통과하지 못하면 발송하지 않는다.

## 13. 발송 후 사건 분리

| 사건 | 의미 | 다음 사건으로 자동 승격 금지 |
|---|---|---|
| `SEND_ATTEMPTED` | 발송 시도 | 실제 발송 |
| `SENT_VERIFIED` | 제공자 시스템상 발송 | 전달 |
| `DELIVERED_VERIFIED` | 전달 확인 | 읽음·응답 |
| `RESPONSE_RECEIVED` | 응답 수신 | 유효 문의 |
| `VALID_INQUIRY_CONFIRMED` | 스팸·테스트·중복 제외 문의 | 예약 |
| `BOOKING_CONFIRMED` | 일시·좌석 합의 | 참석 |
| `ATTENDED_VERIFIED` | 출석 원천의 실제 참석 | 계약 |
| `CONTRACT_VERIFIED` | 효력 있는 계약 | 수납 |
| `NET_COLLECTION_VERIFIED` | 환불·차지백 반영 수납 | 순이익 |

수신거부는 캠페인 실패가 아니라 준수해야 할 이용자 선택이다. 수신거부율을 낮추기 위해 철회 경로를 숨기거나 복잡하게 만들지 않는다.

## 14. KPI 정의

모든 수치에는 기간, 채널, 목적, 규칙 버전, 분자, 분모, 원천을 표시한다.

| KPI | 분자 | 분모 |
|---|---|---|
| 연락처 원천 확인률 | 원천·현재성 확인 수 | 연락 검토 후보 수 |
| 메시지 분류 완료율 | 목적·분류 완료 수 | 연락 검토 후보 수 |
| 광고 동의 증거 확인률 | 해당 채널·목적 증거 확인 수 | 광고 연락 검토 수 |
| 억제 반영 완전율 | 모든 발송 도구에 중단 반영 수 | 수신거부·중단 요청 수 |
| 승인본 일치율 | 승인 대상·문구·채널·시점과 일치한 발송 수 | 실제 발송 수 |
| 유효 응답률 | 검증된 유효 응답 수 | 전달이 확인되고 관찰창이 끝난 발송 수 |
| 문의→예약률 | 같은 성숙 코호트의 확정 예약 | 검증 유효 문의 |
| 예약→참석률 | 검증 실제 참석 | 결과가 확정된 예약 |
| 참석→계약률 | 검증 계약 | 결과창이 성숙한 참석 |
| 검증 순수납 | 성공 수납 - 환불 - 차지백 | 금액 합계, 비율 아님 |

분모가 0이면 계산하지 않는다. 원천이 없으면 `데이터 미연결`, 관찰창이 끝나지 않으면 `미성숙`, 원천이 충돌하면 `판정 보류`로 표시한다.

## 19. 공개 근거와 적용 한계

### KISA·방송미디어통신위원회, 2026-03-04

KISA는 `불법스팸 방지를 위한 정보통신망법 안내서` 제7차 개정본에서 광고 동의 요청을 `혜택 알림`, `정보제공`처럼 광고가 아닌 것으로 오인할 수 있는 표현으로 숨기지 않도록 안내했다. 앱 푸시 광고 수신거부에 로그인 등 복잡한 절차를 요구하지 않는 방향도 명확히 했다.

- 보도자료: https://www.kisa.or.kr/
- 제7차 개정본 자료실: https://spam.kisa.or.kr/spam/na/ntt/selectNttList.do?mi=10207&bbsId=1005

사이트 검색 결과와 자료실 게시일은 2026-03-04로 확인했다. 실제 발송 서식·표시·시간대 요건은 원문 안내서와 현행 법령을 법무 담당자가 다시 확인해야 한다.

### 국가법령정보센터, 2026-09-15 확인

정보통신망법 제50조는 전자적 전송매체를 이용한 영리목적 광고성 정보의 전송 제한과 수신자의 명시적 사전 동의를 규정한다. 본 문서는 법령상 예외를 자동 적용하지 않고 `EXCEPTION_REVIEW_REQUIRED`로 보류한다.

- 정보통신망 이용촉진 및 정보보호 등에 관한 법률: https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률

### 개인정보보호위원회, 2023-12-01

개인정보위는 휴면정책 변경 안내를 마케팅에 이용하지 말고, 휴면회원 대상 광고성 정보는 마케팅 활용 동의와 정보통신망법상 수신동의 절차를 확인해야 한다고 안내했다.

- https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=C020010000&nttId=9573

### ABC Fitness, 2026년 자료

체육시설 SMS 운영 자료는 동의, 세분화, 자동화, 성과측정을 한 흐름으로 다룬다. 해외 법제와 공급업체 자료이므로 구체적인 발송 빈도·전환율·성과 수치를 파이널유도 기준으로 적용하지 않았다.

- https://abcfitness.com/

## 20. Auditor 확인

- 기존 휴면·문의·재등록·만족도 문서와 중복되는 결과 기준을 새로 만들지 않았다.
- 공통 발송 전 적격성, 메시지 분류, 수신중단 전파에 범위를 한정했다.
