# 신규회원 첫 30일 온보딩·활성 판정 기준 v1

- 문서 목적: 체험 후 등록이 검증된 신규회원이 첫 수업부터 30일 관찰창까지 어떤 상태인지 일관되게 기록하고, 초기 지원 누락과 성과 과장을 방지한다.
- 적용 범위: `REGISTERED_VERIFIED` 상태로 전환된 신규회원
- 제외 범위: 체험 전 문의, 체험 예약·노쇼, 체험 후 미등록, 장기 휴면·만료 예정 회원, 결제 독촉
- 공개 원칙: 본 문서는 공개 가능한 운영 규격만 포함한다. 개인별 이름, 연락처, 출석·건강·결제 원장과 상담 원문은 공개하지 않는다.
- 작성 기준일: 2026-09-14

## 1. 핵심 원칙

1. 등록, 수납, 첫 수업 예약, 첫 출석, 30일 활성은 서로 다른 사건이다.
2. 등록만으로 활성회원이라고 판정하지 않는다.
3. 첫 30일의 출석 횟수가 적다는 사실만으로 불만, 이탈, 의지 부족을 추정하지 않는다.
4. 외부 업계 자료의 출석 횟수나 유지율을 파이널유도멀티짐의 목표로 그대로 사용하지 않는다.
5. 회원별 이용권, 권장 빈도, 휴회, 부상, 도장 취소 등 확인된 운영 맥락을 반영한다.
6. 자동 알림과 사람의 확인·지원 기록을 분리한다.
7. 실제 메시지, 혜택, 이용권 변경, 결제 조치에는 별도 승인과 적법한 처리 근거가 필요하다.
8. 30일 성과는 관찰창이 끝난 코호트만 계산한다.

## 2. 진입 조건

다음 조건이 모두 충족되어야 첫 30일 온보딩 흐름에 진입한다.

- 등록 기준 시스템에서 `REGISTERED_VERIFIED` 확인
- 등록일과 적용 지점 확인
- 상품·이용권 상태 확인
- 중복·테스트·오류 레코드가 아님
- 연락이 필요한 경우 수신 근거와 중단 상태 확인
- 담당 역할 지정

결제는 별도 사건이다. 등록이 확인되어도 결제 원장과 연결되지 않으면 수납 또는 매출로 계산하지 않는다.

## 6. 활성 기준 설계 규칙

활성 기준은 대표 승인 전 확정하지 않는다. 후보 구성요소는 다음과 같다.

- 첫 정규 수업 참석 검증
- 이용권 조건에 맞는 관찰 가능한 출석
- 다음 수업 또는 참여 계획의 확인
- 해결되지 않은 운영 문제 없음
- 계약 상태 유효
- 수신 여부와 무관하게 실제 서비스 이용 사건 존재

다음 항목은 단독 활성 근거가 아니다.

- 앱 로그인
- 메시지 열람
- Instagram 좋아요·조회
- 결제만 완료
- 코치의 주관적 인상
- 외부 벤치마크 출석 횟수

활성 기준이 변경되면 과거 코호트에 소급해 섞지 않고 `activation_rule_version`별로 분리한다.

## 7. 지원 신호와 인계

### 확인이 필요한 신호

- 첫 수업 예약이 없음
- 예약은 있으나 결과가 누락됨
- 도장 취소로 참여 기회가 줄어듦
- 회원 또는 보호자가 직접 어려움을 알림
- 수업·지점·이용권 정보가 충돌함
- 담당자가 다음 행동을 기록하지 않음

이 신호는 불만 또는 이탈 사유가 아니다.

### 사람 인계가 필요한 경우

- 부상·건강·안전 우려
- 미성년자 보호자 의사결정
- 환불·계약·가격 분쟁
- 좋지 않은 수업 경험 또는 민원
- 수업·코치·지점 변경 판단
- 개인별 훈련 강도 조정

민감한 상세 내용은 마케팅 메모에 복제하지 않고 승인된 담당 체계로 전달한다.

## 8. 관찰창과 예외

- 기본 관찰창 후보: 등록 효력 시작일부터 30일
- 최종 시작점은 대표 승인 필요
- 미래 시작 계약은 효력 시작 전까지 코호트에 포함하지 않음
- 승인된 휴회 기간은 별도 표시하고 임의로 출석 부족에 포함하지 않음
- 도장 취소 수업은 고객 미참석으로 계산하지 않음
- 데이터 동기화 오류는 `DATA_REVIEW_REQUIRED`로 둠
- 관찰창이 끝나지 않은 회원은 30일 활성률 분모에서 제외

## 9. KPI 정의

모든 비율은 기간, 분자, 분모, 데이터 원천, 규칙 버전을 함께 표시한다. 분모가 0이면 계산하지 않는다.

- 온보딩 진입 완전성 = 필수 진입 필드가 모두 있는 검증 등록 / 검증 등록
- 첫 수업 예약률 = 첫 정규 수업 예약이 검증된 등록 / 예약 관찰 대상 등록
- 첫 수업 참석률 = 첫 정규 수업 참석이 검증된 등록 / 첫 수업 결과가 성숙한 예약
- 담당·다음 행동 완전성 = 담당과 다음 행동 또는 종결이 있는 열린 레코드 / 열린 레코드
- 14일 검토 완전성 = 14일 검토가 기록된 성숙 레코드 / 14일 관찰창이 끝난 등록
- 30일 활성률 = `ACTIVATED_CONFIRMED` / 동일 규칙 버전의 30일 성숙 등록
- 30일 비활성률 = `NOT_ACTIVATED_CONFIRMED` / 동일 규칙 버전의 30일 성숙 등록
- 판정 보류율 = `DATA_REVIEW_REQUIRED` / 30일 판정 대상
- 30일 내 검증 종료율 = 30일 안에 `CANCELLED_VERIFIED` / 30일 결과가 성숙한 등록
- 검증 수납 연결률 = 검증 결제 사건과 연결된 등록 / 검증 등록
- 수신 중단 후 연락 건수 = `CONTACT_STOPPED` 이후 발송된 연락

실제 출석, 활성, 유지, 재등록, 수납 수치는 데이터 미연결이다.
