# 휴강·수업변경·보강·크레딧·환불·서비스회복·유지·매출 귀속 기준 v1

- 문서 상태: 공개 운영 기준
- 기준일: 2026-09-18
- 적용 목적: 기존회원 만족·재등록, 휴면 예방·복귀, 신규회원 신뢰, 매출 귀속 정확도
- 적용 범위: 다지점 유도장의 날짜별 수업 변경·휴강·대체수업·보강·크레딧·환불·서비스 회복
- 공개 제외: 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제·민원 기록, 실제 지점 시간표·가격·혜택, 내부 손익, 미확정 행사
- 법률 주의: 실제 계약 해지·환급액은 최신 법령·소비자분쟁해결기준·개별 계약·이용 이력을 함께 대조한다.

## 1. 핵심 판단

수업표의 편집, 휴관 표시, 안내 발송은 회원이 변경을 인지했거나 보강을 받았다는 증거가 아니다.

다음 사건을 분리한다.

1. 변경 필요 발생
2. 변경안 작성
3. 운영·안전 검토
4. 변경 승인
5. 특정 수업 회차 변경
6. 기존 예약 영향 산출
7. 안내 대상 확정
8. 안내 발송
9. 전달 확인
10. 고객 선택
11. 예약 취소 또는 이동
12. 보강권·크레딧 승인
13. 보강 예약
14. 보강 실제 참여
15. 환불 요청
16. 환불 승인
17. 환불 완료
18. 불편 접수
19. 조치 완료
20. 고객 확인
21. 출석·유지·재등록 관찰

어느 단계도 다음 단계의 자동 증거가 아니다.

## 2. 기존 기준과의 경계

이 문서는 다음 공개 기준을 대체하지 않는다.

- 정원·체험 슬롯·대기명단 기준: 수업 회차의 자리, 예약, 대기, 취소, 노쇼, 실참석
- 신규회원 첫 30일 기준: 회원권 활성 후 온보딩, 첫 수업, 초기 만족과 유지
- 비활성 위험·휴면·복귀 기준: 출석 감소 검증, 휴회·휴면, 실제 복귀와 유지
- 회원권·재등록·결제·환불 기준: 계약, 가격 버전, 결제 승인, 실수납, 환불 원장
- 지역검색·플레이스 기준: 주소, 운영시간, 특별시간, 공개 반영 검증
- 다채널 문의 기준: 동일인, 지점, 담당자, 응답시간과 성과 귀속

이 문서는 도장 사유의 일정 변화가 실제 회원 이용권, 참석, 만족, 재등록과 매출에 미치는 영향을 연결한다.

## 3. 기준 객체

### 3.1 반복 수업 템플릿

요일·시간·프로그램을 정의하는 반복 규칙이다. 템플릿을 바꿔도 이미 생성된 날짜별 회차가 자동으로 같은 상태가 되었다고 간주하지 않는다.

필수 필드:

- 지점 ID
- 프로그램 ID
- 기본 요일·시작·종료 시각
- 담당 코치 역할
- 적용 시작일과 종료일
- 공개 여부
- 승인자
- 버전

### 3.2 수업 인스턴스

특정 날짜·시간에 실제 열리는 회차다.

필수 필드:

- 수업 인스턴스 ID
- 지점·프로그램
- 원래 시작·종료 시각
- 현재 시작·종료 시각
- 원래 담당자·현재 담당자
- 상태
- 변경 사유 범주
- 기존 예약 수
- 변경 승인 시각
- 공개 반영 시각
- 마지막 검증 시각

### 3.3 영향 회원

변경 승인 시점에 다음 중 하나에 해당하는 사람이다.

- 예약 확정
- 대기명단
- 체험 예약 확정
- 복귀 예약 확정
- 해당 회차에 배정된 개인수업
- 프로그램 이용권은 있으나 예약 없이 참여 가능한 운영에서 별도 검증된 대상

단순 팔로워, 게시물 조회자, 과거 문의자는 영향 회원으로 자동 포함하지 않는다.

### 3.4 회복 수단

보강, 대체수업, 이용기한 연장, 크레딧, 환불 등 승인된 조치다. 제안·승인·발급·사용·정산 상태를 각각 기록한다.

## 5. 변경 유형

| 유형 | 정의 | 기본 후속 |
|---|---|---|
| TIME_SHIFT | 같은 날짜의 시작·종료 시각 변경 | 예약자 재확인 |
| DATE_SHIFT | 다른 날짜로 이동 | 원예약 취소와 신규 회차 연결 |
| INSTRUCTOR_CHANGE | 담당 코치 변경 | 계약·프로그램 조건 검토 |
| ROOM_CHANGE | 같은 지점 내 공간 변경 | 동선·접근 안내 검토 |
| LOCATION_CHANGE | 다른 지점 이동 | 고객 명시 동의와 지점 귀속 |
| PROGRAM_CHANGE | 수업 내용·대상 범주 변경 | 적격성 재검증 |
| SHORTENED | 수업 시간 단축 | 이용권·보상 기준 검토 |
| CANCELLED_BY_BUSINESS | 도장 사유로 회차 취소 | 대안·보상·환불 검토 |
| EMERGENCY_CLOSURE | 안전·시설·재난 등 긴급 휴관 | 우선 안전 안내·사후 정산 |
| PARTIAL_CLOSURE | 일부 프로그램·시간대만 중단 | 영향을 받은 회차만 처리 |

'휴강'이라는 한 단어로 모든 유형을 합치지 않는다.

## 6. 변경 승인과 버전 잠금

변경은 다음 순서로 처리한다.

1. 원래 회차 스냅샷 보존
2. 변경 사유 범주 기록
3. 정원·안전·인력·시설 검토
4. 승인자와 승인 시각 기록
5. 변경 버전 생성
6. 예약·대기·체험·복귀 대상 영향 산출
7. 예약 시스템 반영
8. 공개 시간표 반영
9. 안내 대상 스냅샷 생성
10. 채널별 안내
11. 고객 선택 처리
12. 보강·크레딧·환불 처리
13. 공개 상태와 원장 대조
14. 예외·민원 종료

변경 후 다시 수정하면 새 버전을 생성한다. 이전 안내를 덮어쓰지 않는다.

## 7. 채널별 역할

### 7.1 예약·회원 시스템

다음의 기준 원천이어야 한다.

- 회차 상태
- 예약·대기 상태
- 고객 선택
- 보강권·크레딧 상태
- 실제 참여
- 환불·수납 연결

### 7.2 네이버·Google 등 지역정보

시설 전체 운영시간과 날짜별 특별시간을 관리한다. 개별 수업 시간표와 시설 운영시간을 혼동하지 않는다.

Google Business Profile의 특별시간은 짧은 기간의 운영시간 변경에 사용하고, 7일 이상 또는 종료일 미정의 폐쇄는 임시 휴업 기준을 별도로 검토한다. 편집 저장 후 실제 공개 화면을 확인한다.

### 7.3 당근·지역 커뮤니티

공개 공지는 승인된 지점·날짜·범위만 사용한다. 특정 회원에게 필요한 예약 변경을 공개 게시 하나로 대체하지 않는다.

### 7.4 공식 지점 채널

지점의 확정 일정 공지를 담당한다. 발행 주체, 적용 지점, 날짜, 변경 전후 정보를 명확히 한다.

### 7.5 코치 개인 Instagram

코치 개인 계정은 공식 일정의 기준 원천이 아니다.

- 확정 전 휴강·보강·시간 변경 공지 금지
- 브랜드 전체의 발표 주체로 표현 금지
- 실제 자리·마감·무료·가격·보상 임의 주장 금지
- 공식 안내로 연결할 때 승인된 링크와 지점 범위만 사용
- 일반 유도 설명 콘텐츠를 일정 변경 안내로 오인시키지 않는다

## 8. 안내 계약

### 8.1 필수 정보

승인된 안내에는 필요한 범위에서 다음을 포함한다.

- 적용 지점
- 적용 수업·날짜·시간
- 변경 전 정보
- 변경 후 정보 또는 취소 상태
- 영향 범위
- 고객이 해야 할 선택
- 선택 기한이 있다면 승인된 기한
- 문의 경로
- 보강·크레딧·환불은 확정된 항목만 표시
- 기준 버전과 발송 시각

### 8.2 금지 표현

- '모두 자동 보강 처리됐습니다' — 실제 발급 검증 전
- '전액 환불됩니다' — 계약·기준·원장 검증 전
- '다음 수업 아무 때나 오시면 됩니다' — 정원·적격성 확인 전
- '문자 받으셨으니 확인 완료입니다' — 전달·인지 미확인
- '한 번 쉬어도 이용기간은 그대로입니다' — 승인된 보상 규칙 미확인
- '휴강으로 인한 이탈' — 회원 선택·사유 미확인
- '보강 제공 완료' — 제안 또는 발급만 된 상태

### 8.3 전달과 응답

다음 상태를 분리한다.

- 생성
- 발송
- 전달
- 열람 또는 확인 가능 상태
- 고객 인지 응답
- 고객 선택
- 담당자 처리
- 실제 결과

광고성 정보 동의와 계약 이행·운영 안내의 법적 근거를 혼합하지 않는다. 연락 중단·채널 제한·미성년자 보호자 절차를 적용한다.

## 10. 크레딧·환불·매출 기준

### 10.1 크레딧

크레딧은 매출이나 환불과 동일하지 않다.

필수 필드:

- 크레딧 ID
- 발급 근거 회차
- 승인자
- 발급액 또는 이용 단위
- 유효기간
- 사용 가능 상품·지점
- 발급·사용·만료 상태
- 회계 처리 기준
- 중복 보상 방지 키

### 10.2 환불

다음 사건을 분리한다.

1. 요청
2. 적격성 검토
3. 산식 검토
4. 승인
5. 결제 취소 또는 송금 지시
6. 실제 환불 완료
7. 회원권·크레딧 조정
8. 순수납 반영
9. 분쟁 종료

환불 승인이나 카드 취소 요청을 환불 완료로 집계하지 않는다.

### 10.3 매출

- 계약금액
- 결제 승인액
- 실수납액
- 크레딧 발급액
- 실제 사용액
- 환불액
- 차지백
- 순수납

을 분리한다. 휴강 후 재등록 의향, 보강 선택, 회원권 연장은 매출이 아니다.

## 11. 서비스 회복

### 11.1 불편 상태

| 상태 | 정의 |
|---|---|
| ISSUE_REPORTED | 고객이 불편·오류를 전달 |
| ISSUE_TRIAGED | 담당 지점·책임자·우선순위 배정 |
| ROOT_CAUSE_UNVERIFIED | 원인 확인 전 |
| ROOT_CAUSE_VERIFIED | 시스템·운영 근거로 원인 확인 |
| ACTION_PROPOSED | 조치 제안 |
| ACTION_APPROVED | 조치 승인 |
| ACTION_COMPLETED | 조치 실행 증거 존재 |
| CUSTOMER_CONFIRMATION_PENDING | 고객 결과 확인 대기 |
| RECOVERY_CONFIRMED | 고객이 결과를 확인 |
| ISSUE_CLOSED | 원장·예외·후속까지 종료 |

불편 접수를 불만 회원, 이탈 위험, 환불 요구로 자동 분류하지 않는다.

### 11.2 원인 범주

- 운영시간 오표시
- 수업표 오표시
- 예약 시스템 미반영
- 예약자 통지 누락
- 다른 지점 정보 혼입
- 코치·공간 변경
- 정원·대기 처리 오류
- 보강권·크레딧 미반영
- 중복 차감·청구
- 환불 지연
- 원인 미확인

담당자 추정과 고객이 확인한 사유를 구분한다.

## 12. 유지·재등록 귀속

다음은 유지·재등록 성과가 아니다.

- 공지 발송
- 고객의 '확인했습니다' 응답
- 보강권 발급
- 보강 예약
- 첫 보강 출석
- 재등록 문의
- 결제 링크 클릭
- 결제 승인

유지는 승인된 관찰기간의 회원권 유효 상태와 실제 참여 기준으로, 재등록은 계약·실수납·회원권 연장 검증으로 판정한다.

휴강과 이후 해지·휴면 사이의 시간적 선후만으로 인과관계를 단정하지 않는다.

→ 대안 예약
→ 실제 참여

### 13.2 KPI 정의

| KPI | 분자 | 분모 | 비고 |
|---|---|---|---|
| 영향대상 정확도 | 검증된 실제 영향 회원 | 산출된 영향 대상 | 개인정보 비공개 |
| 전달률 | 전달 확인 안내 | 발송 안내 | 채널 정의 필요 |
| 인지율 | 인지 응답 회원 | 전달 확인 회원 | 열람과 구분 |
| 선택완료율 | 대안을 선택한 회원 | 선택 필요 회원 | 자동 선택 제외 |
| 보강예약률 | 보강 예약 확정 회원 | 보강 적격 회원 | 제안과 구분 |
| 보강참여율 | 실제 보강 참여 회원 | 보강 예약 확정 회원 | 체크인과 구분 |
| 회복완료율 | 고객 확인까지 완료 | 이슈 접수 | 단순 조치 제외 |
| 휴강 후 유지율 | 관찰기간 유지 회원 | 검증된 영향 회원 | 비교군·기간 명시 |
| 재등록률 | 재등록 검증 회원 | 만료 대상 영향 회원 | 실수납 기준 별도 |
| 순수납 | 실수납-환불-차지백 | 해당 기간 | 회계 기준 필요 |

분모가 0이거나 데이터가 없으면 계산하지 않는다.

## 15. 채널 공개 전 체크리스트

- [ ] 지점·수업·날짜·시간이 승인된 기준 원천과 일치한다.
- [ ] 시설 운영시간과 개별 수업 시간이 구분된다.
- [ ] 변경 전후 정보가 명확하다.
- [ ] 기존 예약자에게 별도 안내가 필요한지 확인했다.
- [ ] 보강·크레딧·환불은 승인·원장 상태와 일치한다.
- [ ] 실제 잔여 자리나 정원을 추정하지 않는다.
- [ ] 코치 개인 계정을 브랜드 공식 발표 주체로 표현하지 않는다.
- [ ] 미성년자·보호자·수신동의 절차를 확인한다.
- [ ] 편집 저장이 아니라 공개 상태를 다시 확인한다.
- [ ] 개인정보·결제·건강·민원 원장을 공개하지 않는다.

## 16. 합성 데이터 검증 실험

실제 회원을 사용하지 않고 합성 수업 변경 여정 192건으로 점검한다.

성공 기준:

- 반복 템플릿 변경을 날짜별 회차 반영으로 오분류 0건
- 휴관 표시 후 기존 회차·예약 잔존 누락 0건
- 안내 발송을 전달·인지로 오분류 0건
- 보강 제안을 예약·참여로 오분류 0건
- 크레딧 승인을 발급·사용으로 오분류 0건
- 환불 승인을 환불 완료로 오분류 0건
- 체크인을 실제 참여로 오분류 0건
- 휴강 영향의 휴면·이탈 원인 단정 0건
- 복귀·재등록·지점 이동의 신규회원 오분류 0건
- 승인 없는 실제 연락·보상·환불·계정 변경 0건

하나라도 발생하면 실제 대상 적용을 중단하고 상태 정의·원장 연결을 수정한다.

## 18. 공개 자료에서 확인한 운영 시사점

1. Google Business Profile은 짧은 기간의 운영시간 변경을 특별시간으로 따로 관리하며, 7일 이상 또는 종료일 미정의 폐쇄는 임시 휴업 기준을 사용하도록 안내한다.
2. Gymdesk의 현재 일정 관리 문서는 수업 날짜·시간 변경 시 참석자가 자동 통지되지 않을 수 있다고 명시한다.
3. Gymdesk는 하루 휴관 표시가 신규 예약을 막더라도 기존 수업이 남을 수 있으므로 기존 회차의 취소와 참석자 안내를 별도로 처리해야 한다고 안내한다.
4. 일정 시스템의 기능은 파이널유도멀티짐의 실제 계약·보강·환불·회원권 원장이 연결됐다는 증거가 아니다.
5. 한국의 실제 환급 처리는 최신 소비자분쟁해결기준과 개별 계약·이용 이력을 대조해야 한다.
