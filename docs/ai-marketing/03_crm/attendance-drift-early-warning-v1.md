# Attendance-Drift Early Warning & Human Check-In v1

- 작성일: 2026-09-12
- 상태: 전략·계측·실험 설계 / 고객 발송·운영DB 적용·광고 집행 전
- 목표: 기존회원의 출석 이탈 신호를 조기에 발견해 재등록·만족·순기여를 보호하고, 휴면 전환 이후의 복귀비용을 줄일 수 있는지 검증
- 내부 회원수·매출·전환율: **데이터 미연결**

## 오늘의 판단

이번 회차의 우선순위는 신규 문의를 하나 더 늘리는 것보다 **기존회원이 정식 해지·만료 전에 출석 빈도가 떨어지는 구간을 별도 CRM 상태로 관리하는 것**이다.

이미 First Six Weeks Activation Window가 신규·복귀회원의 등록 후 첫 6주를 다룬다. 이번 문서는 그 기간을 지난 기존회원까지 포함해, 개인별 사전 계획 또는 최근 정상 패턴과 비교했을 때 출석이 약해지는 `attendance drift`를 내부 신호로 사용한다.

핵심 원칙은 `결석 = 이탈`로 자동 판정하지 않는 것이다. 질병·출장·시험·가족일정·대회준비·휴식 등 정상적인 이유가 있을 수 있으므로, 시스템은 연락대상 후보를 만들 뿐 최종 판단은 운영정책과 사람의 확인을 거친다.

## 발견한 변화

### 1. Gymdesk 2026 Benchmark는 무도장 데이터에서 출석 빈도와 이탈 사이의 강한 관찰상관을 제시한다

Gymdesk의 2026 Benchmark는 4,594개 활성 체육관을 분석했고, 출석을 추적하는 시설의 801,000개 멤버십에서 드물게 방문하는 회원의 취소 비율이 주 3회 이상 방문하는 회원보다 높게 나타났다고 보고한다. 공개 수치는 `<1회/2주` 44.2%, `약 주1회` 34.1%, `약 주2회` 26.5%, `주3회 이상` 23.2%다.

이 수치를 파이널유도의 목표 이탈률이나 위험기준으로 복사하지 않는다. 관찰데이터이며 회원권 구조·연령·종목·지역이 다르다. 참고할 핵심은 **정식 해지보다 먼저 출석패턴의 약화가 관측될 수 있다는 점**이다.

출처: https://gymdesk.com/gym-benchmark-report

### 2. 2026년 피트니스 소비자 조사에서도 ‘조용한 이탈’과 선제 연락 부재가 별도 문제로 다뤄지고 있다

Zenoti가 2026년 공개한 미국 헬스·피트니스 회원 1,393명 조사에서는 53%가 정식 취소 의사표현 없이 한동안 출석을 멈춘 경험이 있다고 답했고, 휴면 경험자 가운데 상당수가 시설의 선제 연락을 받지 못했다고 보고한다.

미국 일반 피트니스 조사이므로 파이널유도 회원의 행동비율로 환산하지 않는다. 다만 `결제만 유지되거나 만료될 때까지 아무 행동도 하지 않는 회원`을 해지 이후에만 CRM 대상으로 잡는 방식의 한계를 보여주는 최신 신호로 참고한다.

출처: https://www.zenoti.com/thecheckin/silent-churn-crisis-2026-gym-membership-data

### 3. Judo BC는 2026/27 시즌 등록에서 New Member와 Returning Member를 운영상 분리한다

Judo Canada가 2026-07-01 새 등록 플랫폼으로 전환한 뒤 Judo BC의 2026/27 등록안내는 `New Member`와 `Returning Member`를 분리하고, 복귀회원에게 기존 멤버십 찾기·계약 동의·클럽 연결·시즌 갱신 절차를 별도로 제시한다.

이는 파이널유도에 같은 연간 갱신제를 적용하라는 근거가 아니다. 참고점은 **신규·복귀·현재 활성회원의 상태를 하나의 CRM 단계로 뭉개지 않는 운영 구조**다.

출처: https://www.judobc.ca/membership/registration/

### 4. 강서구 생활체육 운영도 참여자 만족을 다음 운영에 반영하는 피드백 루프를 사용한다

강서구는 2026년 하반기 생활체육교실을 10개 종목·35개 교실, 822명 규모로 모집했고, 수강생 만족도 조사를 다음 연도 운영에 반영한다고 공개했다. 파이널유도의 재등록률 근거로 사용할 수는 없지만, 지역 생활체육 운영에서도 단순 모집 이후 **참여경험을 수집해 다음 운영을 조정하는 구조**가 사용되고 있다는 지역 참고사례다.

출처: https://sports.gangseo.seoul.kr/fmcs/1

## Growth Analyst — 관리 퍼널과 병목

기존회원 유지 퍼널을 아래처럼 분리한다.

`active_member → expected_attendance → attendance_drift_candidate → human_review → check_in_if_appropriate → schedule_recovery_or_no_action → active_30d → renewal → revenue`

만료 전 CRM은 별도로 연결한다.

`renewal_window → attendance_status → renewal_offer_or_information → renewed / expired → returner_lane_if_opted_in`

필수 내부 필드 후보:

- `member_id` — 운영DB 내부 전용
- `branch_id`
- `class_id`
- `membership_status`
- `expected_weekly_frequency` — 회원 본인 계획 또는 상품·반 기준을 구분
- `visits_last_7d`
- `visits_last_14d`
- `baseline_visit_frequency`
- `attendance_drift_state` — NORMAL / REVIEW / CONTACTED / PAUSED / EXEMPT
- `known_pause_until` — 휴회·출장 등 사전 확인된 경우
- `last_coach_touchpoint_at`
- `renewal_due_at`
- `active_30d_after_checkin`
- `renewed_after_checkin`

개인별 출석·사유·연락처·건강정보는 공개 GitHub에 기록하지 않는다.

## Acquisition Marketer — 신규획득 우선순위 조정

이번 전략이 필요한 동안에는 `리드 수 증가`만으로 마케팅 성공을 판단하지 않는다. 기존회원의 실제 활성과 재등록 기준선이 보이지 않으면 신규획득비를 늘려도 순회원 증가 여부를 판단하기 어렵다.

획득 캠페인은 계속 설계할 수 있으나, 비교표에는 최소한 아래를 함께 둔다.

- 신규 체험 실방문
- 신규 유료등록
- 신규 30일 활성
- 기존회원 30일 활성
- 재등록
- 순회원 증감
- 획득비용과 유지비용

현재 값은 모두 **데이터 미연결**이다.

## CRM Marketer — 연락 원칙

### 1. 자동 메시지보다 내부 Review Queue가 먼저다

출석이 줄었다고 시스템이 즉시 카카오톡·문자를 보내지 않는다. 먼저 아래 예외를 제거한다.

- 승인된 휴회
- 출장·시험·학교행사 등 이미 공유된 일정
- 부상·건강 관련 휴식 — 상세 건강정보를 마케팅 세그먼트로 사용하지 않는다
- 대회 후 회복 또는 코치와 합의한 일정
- 회원권 자체가 저빈도 상품인 경우

### 2. 연락 목적은 판매보다 상태확인이다

연락이 필요한 경우에도 `왜 안 나오세요?`, `곧 만료됩니다`, `지금 재등록하세요`를 첫 메시지로 자동 발송하지 않는다. 실제 운영정책이 승인되면 최근 일정에 변화가 있는지, 가능한 다른 시간대가 필요한지, 휴회·복귀 경로 안내가 필요한지 확인하는 짧은 체크인을 검토한다.

### 3. 만료예정과 출석저하를 구분한다

`만료예정이지만 정상 출석`인 회원과 `아직 만료가 멀지만 출석이 급감한 회원`을 같은 CRM 캠페인으로 묶지 않는다. 재등록 메시지는 계약기간 기준, 출석 체크인은 참여상태 기준으로 별도 관리한다.

## Content Strategist — 채널별 실행 방향

이번 전략의 핵심은 개인 CRM이므로 공개채널 콘텐츠를 직접적인 `이탈자 호출` 형태로 만들지 않는다.

- **네이버:** `바쁜 달에도 유도 루틴을 유지하는 방법`, `주 1회·2회 등 본인 일정에 맞춰 수업 계획을 세울 때 확인할 것`처럼 일정관리형 정보 콘텐츠를 검토한다. 특정 출석횟수가 효과를 보장한다고 주장하지 않는다.
- **Instagram:** 실제 회원 개인 출석기록을 공개하지 않고 `이번 주 가능한 수업시간 확인 → 본인 일정에 맞는 다음 수업 선택` 같은 루틴 콘텐츠를 만든다.
- **당근:** 휴면회원 추적 광고가 아니라 실제 여석이 있는 시간대와 복귀 진입경로가 확정된 경우에만 지역 복귀·성인수업 정보를 노출한다.

## Experiment Manager

### EXP-217 Attendance-Drift Review Queue

**가설:** 출석패턴이 약해진 기존회원 후보를 자동 발송이 아닌 내부 Review Queue로 먼저 확인하면, 기존의 `만료 후 복귀관리`보다 이른 시점에 일정조정·휴회·복귀경로를 안내할 수 있고 이후 30일 활성·재등록이 개선될 수 있다.

**비교:**
- Control: 기존 운영
- Treatment: 승인된 drift rule → 예외검토 → 필요 시 사람의 체크인

**핵심 KPI:**
- `reviewed_candidate → active_next_30d`
- `reviewed_candidate → renewal`
- 체크인 후 수업시간 변경·휴회·복귀 선택률
- 불편·수신거부·민원 건수
- 코치/직원 처리시간

**성공 기준:** 사전에 내부 기준선을 연결하고 최소개선폭을 고정한 뒤 판정한다. 현재 기준선·최소개선폭·표본수는 **데이터 미연결**이다.

**중단 기준:** 반복연락 증가, 정상 휴회자 오분류, 건강·가족사 등 민감사유의 마케팅 이용, 코치 업무량 초과, 30일 활성·재등록 개선 없이 연락량만 증가하는 경우 중단한다.

### EXP-218 Personal Baseline vs Fixed Absence Threshold

**가설:** 모든 회원에게 동일한 `N일 미출석` 기준을 적용하는 것보다 본인이 계획한 빈도 또는 최근 정상패턴 대비 변화로 후보를 만드는 편이 오탐을 줄일 수 있다.

예: 주 1회 회원과 주 4회 회원에게 동일한 7일 기준을 적용하지 않는다. 단, 실제 임계값은 내부 데이터를 연결하기 전 확정하지 않는다.

**KPI:**
- Review Queue 오탐률
- 실제 체크인 필요비율
- 다음 30일 활성
- 재등록
- 직원 처리시간

## 필요한 대표 승인·입력

1. 회원권·반별 정상적인 이용빈도와 회원 본인 계획빈도를 어떤 방식으로 기록할지
2. 승인된 휴회·대회·출장 등 `연락 제외 상태` 정의
3. 최근 3~6개월 비식별 집계: 주별 출석분포, 만료, 재등록, 휴면 전환
4. 기존회원에게 운영상 체크인을 할 수 있는 연락범위와 수신동의 기준
5. 코치가 하루·주간 처리 가능한 Review Queue 최대량
6. 현재 만료예정 CRM·콜리스트와의 중복 방지 규칙
7. 체크인 이후 다른 시간대·휴회·복귀 경로를 실제 제공할 수 있는 운영정책

## Auditor

- Gymdesk의 출석 빈도와 취소율은 관찰상관이며 파이널유도에 동일 임계값·효과크기를 적용하지 않는다.
- Zenoti 조사는 미국 일반 피트니스 소비자 조사다. `53%`를 파이널유도 휴면률로 사용하지 않는다.
- 한 번 또는 며칠의 결석을 `이탈위험`, `의지 부족`, `불만족`으로 자동 분류하지 않는다.
- 질병·부상·가족사·학교생활 같은 민감하거나 사적인 이유를 마케팅 세그먼트로 사용하지 않는다.
- 체크인의 목적은 할인판매가 아니라 상태 확인과 실제 가능한 선택지 안내다.
- 직원이 고객의 개인 출석현황을 공개채널 콘텐츠·공개 GitHub에 기록하지 않는다.
- 광고·고객 메시지 발송·계정변경·운영DB 적용은 대표 승인 없이 실행하지 않는다.

## 결론

이번 전략의 핵심은 `해지한 회원을 다시 데려오기`보다 한 단계 앞선 **`정상 출석에서 멀어지는 신호를 조기에 보고, 자동 영업이 아닌 사람의 검토로 필요한 경우에만 돕는 것`**이다.

파이널유도에 적합한 출석위험 임계값은 아직 존재하지 않는다. 먼저 내부 비식별 기준선을 연결하고 EXP-217/218로 오탐·활성·재등록·운영부담을 함께 검증한다.
