# 회원권 만료·재등록·휴회·해지·환불·복귀·매출 귀속 기준 v1

- 문서 버전: v1
- 검토일: 2026-09-19
- 적용 대상: 파이널유도멀티짐의 기존회원 유지, 만료예정 재등록, 휴면회원 복귀, 해지·환불 및 순수납 성과 측정
- 공개 범위: 공개 가능한 운영 기준만 포함
- 제외: 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제 원장, 내부 가격·손익, 미확정 행사와 승인 대기 Instagram 콘텐츠

## 1. 목적

회원권 만료 알림, 재등록 의사, 결제 승인, 실제 수납, 새 이용기간 활성화를 하나의 `재등록`으로 뭉치지 않는다. 휴회와 이탈, 해지 요청과 해지 완료, 환불 요청과 환불 완료도 구분한다.

이 기준의 목표는 다음 네 가지다.

1. 만료예정 회원의 재등록 기회를 놓치지 않는다.
2. 휴회 회원을 이탈 회원으로 잘못 분류하지 않는다.
3. 해지·환불 과정에서 사실과 다른 약속이나 매출 과대계상을 막는다.
4. 신규등록·재등록·복귀등록을 중복 없이 구분한다.

## 2. 핵심 원칙

1. `연락 발송`, `열람`, `답장`, `재등록 의사`, `결제 승인`, `실수납`, `새 이용기간 활성화`는 별개 사건이다.
2. 재등록 성과는 승인된 기준에 따라 결제가 실제 반영되고 새 이용기간이 활성화된 뒤 확정한다.
3. 휴회는 계약 종료나 이탈과 동일하지 않다.
4. 만료는 자동으로 이탈을 뜻하지 않으며, 만료예정은 재등록 완료가 아니다.
5. 결제 예정·카드 승인 시도·승인 성공은 정산된 순수납과 동일하지 않다.
6. 환불·부분환불·차지백·결제취소는 매출과 회원권 상태에 각각 반영한다.
7. 자동갱신·휴회기간 연장·일할 계산·수수료는 실제 승인된 약관과 시스템 설정이 확인된 경우에만 안내한다.
8. 지점 이동은 신규회원이나 이탈 후 복귀로 중복 계산하지 않는다.

## 4. 재등록 확정 규칙

### 4.1 필수 조건

재등록 완료는 아래가 모두 충족된 경우에만 집계한다.

1. 동일 회원·지점·상품·이용기간을 식별할 수 있다.
2. 이전 회원권과 새 회원권의 관계가 `renewal`로 기록된다.
3. 결제가 기준 원장에 실제 수납으로 반영된다.
4. 새 이용기간과 이용권한이 활성화된다.
5. 취소·환불·차지백이 반영된다.
6. 같은 거래를 신규등록·복귀등록·지점 이동과 중복 귀속하지 않는다.

### 4.2 재등록으로 보지 않는 사건

- 만료 알림 발송 또는 열람
- 전화 연결, DM 답장, 상담 완료
- 재등록 희망·검토·약속
- 견적·결제 링크 발송
- 결제 예정 또는 승인 시도
- 카드 승인 성공만 있고 정산·이용기간 활성 확인이 없는 경우
- 휴회 종료일 도래
- 체크인·예약만 있고 회원권 상태가 확인되지 않은 경우

## 5. 휴회 운영 기준

1. 휴회 사유는 운영에 필요한 최소 범위만 수집한다.
2. 부상·질환 등 건강 상세정보는 필수로 요구하지 않는다. 별도 처리가 필요하면 권한·목적·보유기간을 검토한다.
3. 휴회 시작일·종료일·이용권한·결제·남은 기간·복귀 방식의 영향을 분리 기록한다.
4. `결제 정지`, `이용 정지`, `회원권 만료일 연장`은 서로 다른 설정이다.
5. 휴회 승인 전에 일할 계산, 크레딧, 만료일 연장을 보장하지 않는다.
6. 자동 복귀가 설정돼도 통지 전달과 실제 권한·결제 재개를 확인한다.
7. 휴회 중 방문·콘텐츠 반응을 복귀 완료로 집계하지 않는다.

## 6. 해지·환불 운영 기준

1. 해지 요청 접수 시점, 이용 종료 시점, 결제 중단 시점, 환불 완료 시점을 분리한다.
2. 소비자분쟁해결기준은 당사자 간 별도 의사표시가 없는 경우의 합의·권고 기준이다. 실제 계약과 이용내역을 함께 확인한다.
3. 환불 금액·공제·수수료·처리기한을 추정하지 않는다.
4. 해지 요청이 접수되면 미래 자동결제·예약된 청구·이용권한에 미치는 영향을 검토한다.
5. 환불이 완료되면 총수납, 환불, 차지백, 순수납을 별도 원장으로 남긴다.
6. 고객의 취소 사유 자유서술은 접근권한을 제한하고 보유기간을 정한다.
7. 공개 답글·후기·콘텐츠에 해지 사유나 개인별 결제정보를 노출하지 않는다.

## 7. 회원 분류 기준

| 분류 | 기준 |
|---|---|
| 신규등록 | 이전 활성 회원권 관계가 없는 첫 유효 등록 |
| 재등록 | 이전 회원권의 연속 또는 후속 기간으로 승인된 등록 |
| 휴회 복귀 | `FROZEN`에서 승인된 이용권한·결제 재개 |
| 휴면 복귀 | 승인된 휴면 정의를 충족한 뒤 다시 유효 등록 |
| 지점 이동 | 동일 조직 내 홈지점 또는 서비스지점 변경 |
| 해지 | 승인 절차를 거쳐 회원권 이용권한이 종료 |
| 이탈 | 승인된 관찰기간과 정의를 충족한 분석 분류 |

`EXPIRED`, `PAST_DUE`, `FROZEN`, `CANCEL_REQUESTED`를 자동으로 이탈 처리하지 않는다.

## 8. 퍼널과 지표 정의

### 8.1 재등록 퍼널

`만료예정 적격 → 연락 가능 → 안내 발송 → 전달 → 사람 응답 → 조건 수락 → 결제 대기 → 실수납 → 새 기간 활성 → 환불 조정`

### 8.2 휴회 복귀 퍼널

`휴회 승인 → 휴회 적용 → 복귀 예정 → 통지 전달 → 복귀 수락 → 권한 재개 → 결제 재개 → 실제 참여`

### 8.3 해지·환불 퍼널

`해지 요청 → 검토 → 승인 → 이용 종료 → 청구 중단 → 환불 대기 → 환불 완료 → 순수납 조정`

### 8.4 KPI 산식

| KPI | 산식 | 현재 상태 |
|---|---|---|
| 재등록률 | `NEW_TERM_ACTIVE 고유 회원 / 재등록 적격 만료예정 고유 회원` | 데이터 미연결 |
| 수락→재등록률 | `NEW_TERM_ACTIVE / RENEWAL_ACCEPTED` | 데이터 미연결 |
| 결제실패 복구율 | `실패 후 CASH_COLLECTED / PAYMENT_FAILED` | 데이터 미연결 |
| 휴회 복귀율 | `RESUMED / 복귀기한 도래 FROZEN` | 데이터 미연결 |
| 해지 완료율 | `TERMINATED / CANCEL_REQUESTED` | 데이터 미연결 |
| 순수납 | `실수납 - 환불 - 차지백` | 데이터 미연결 |

분자·분모·기간·기준 원장을 함께 표시한다. 분모가 0이거나 원장이 없으면 계산하지 않는다.

## 9. 채널 운영

### 네이버·당근·공식 브랜드 채널

- 승인된 회원권 기간·가격·자동갱신·휴회·해지·환불 조건만 공개한다.
- `자동 연장`, `언제든 환불`, `수수료 없음` 같은 조건은 근거가 없으면 사용하지 않는다.
- 지점별 조건이 다르면 해당 지점과 적용기간을 표시한다.

### Instagram @ant.toe.98

- 코치 개인 계정에서 브랜드 공식 약관·가격·환불 공지의 발표 주체로 말하지 않는다.
- 개인의 확인되지 않은 수련 경험이나 회원 사례를 재등록 근거로 만들지 않는다.
- 자연스러운 수업 문의 연결은 가능하지만 실제 시간표·가격·혜택은 확인된 공식 안내로 연결한다.

### CRM

- 채널·목적별 동의, 수신거부, 빈도, 야간 전송 기준을 먼저 통과한 대상만 후보가 된다.
- 무응답을 추가 연락 동의로 보지 않는다.
- 수신거부 뒤 다른 채널로 자동 전환하지 않는다.

## 10. 다지점·가구·보호자 기준

1. `person_id`, `household_id`, `membership_id`, `location_id`, `payment_id`를 분리한다.
2. 보호자 결제와 수련자 회원권을 같은 사람으로 병합하지 않는다.
3. 가족 공유 회원권은 사람별 이용권한과 가구 단위 결제를 분리한다.
4. 지점 이동을 신규등록·복귀·재등록으로 중복 계산하지 않는다.
5. 환불과 매출은 승인된 회계 지점에 한 번만 귀속한다.
6. 미성년자 연락·계약·환불은 보호자 권한 확인 절차를 거친다.

## 12. 실험 EXP-409

### 가설

상태 전이를 분리하면 휴회·만료·결제승인을 이탈·재등록·매출로 잘못 계산하는 오류를 막을 수 있다.

### 대상

- 합성 회원 480명
- 회원권 상태 사건 1,440건
- 결제·환불·차지백 사건 720건
- 지점·가구·보호자 관계 360건

### 성공 기준

- `RENEWAL_ACCEPTED`를 재등록 완료로 오분류 0건
- `PAYMENT_AUTHORIZED`를 실수납으로 오분류 0건
- `FROZEN`을 이탈로 오분류 0건
- `CANCEL_REQUESTED`를 해지 완료로 오분류 0건
- `REFUND_PENDING`을 환불 완료로 오분류 0건
- 환불·차지백 미차감 0건
- 보호자 결제를 수련자 신규등록으로 중복 귀속 0건
- 지점 이동을 신규·복귀·재등록으로 중복 귀속 0건

### 중단 기준

위 항목 중 하나라도 실패하면 실제 자동 연락, 자동 갱신·휴회·해지 처리, 재등록·순수납 성과 보고를 중단한다.

## 13. 대표 승인·입력 필요사항
