## 1. 핵심 판단

출석 감소는 위험 신호이지 휴면·불만·해지의 확정 증거가 아니다.

2. 실제 출석

연락 발송이나 복귀 의사만으로 복귀 성과를 집계하지 않는다.

## 2. 기존 기준과의 경계

이 문서는 다음 기존 기준을 대체하지 않는다.

- 회원권 만료·재등록·결제·환불 기준: 계약, 가격, 결제, 회원권 기간의 기준 원천
- 체험 후 미등록 기준: 체험 참석 이후 신규 등록 여정
- 다채널 문의 기준: 채널·지점·담당자·동일인 귀속
- 예약·노쇼 기준: 개별 수업 회차의 예약·출석·취소 판정

이 문서는 활성 회원의 출석 변화부터 휴면 판정, 복귀 실행, 실제 재출석과 복귀 후 유지까지를 다룬다.

## 4. 출석 데이터 검증

출석 감소를 위험 신호로 사용하기 전에 다음을 검증한다.

- 출석 원장의 기준 시스템
- 체크인 누락 또는 중복 여부
- 지점 간 이동 출석 반영 여부
- 휴강·공휴일·대회·행사로 인한 일정 변화
- 회원권 시작일·만료일·휴회기간
- 수업 예약 없이 참여 가능한 운영 방식
- 코치 수기 출석의 반영 지연
- 가족계정·보호자계정의 회원 매핑
- 수업권 변경 또는 반 변경
- 환불·해지·결제 실패 상태

데이터 누락 가능성이 있으면 ATTENDANCE_RISK_UNVERIFIED로 유지한다.

## 5. 개인 기준선과 공통 임계값

모든 회원에게 동일한 7일·14일·30일 임계값을 자동 적용하지 않는다.

회원의 기존 패턴은 다음과 같이 다를 수 있다.

- 주 1회 수련
- 주 2~3회 수련
- 불규칙 교대근무
- 시험·대회·학기 일정
- 보호자 일정에 따른 아동 수련
- 승인된 장기 휴회
- 다른 지점 병행
- 시즌별 참여

따라서 위험 신호는 우선 개인 기준선 대비 변화로 본다.

### 5.1 권장 데이터 필드

- 최근 관찰기간 출석 횟수
- 직전 비교기간 출석 횟수
- 개인 기준 출석 빈도
- 마지막 검증 출석일
- 연속 예약취소·미방문 횟수
- 승인된 휴회 시작·종료일
- 회원권 상태
- 지점 이동 여부
- 출석 데이터 완전성
- 담당자 검토 상태

### 5.2 대표 승인 전 금지

- 외부 업체가 제시한 7일·30일 기준의 자동 적용
- 평균 출석만으로 개인 이탈 판정
- 소수 지점의 기준을 전 지점에 적용
- 데이터 미연결 상태에서 위험 회원 수 발표
- 출석 감소를 건강·경제·불만 사유로 추정

## 6. 휴회·휴면·해지 구분

### 6.1 휴회

휴회는 요청, 승인, 적용, 종료를 분리한다.

- PAUSE_REQUESTED: 요청만 접수
- PAUSED: 승인 조건과 기간이 회원권에 반영됨
- PAUSE_END_PENDING: 종료 예정이나 복귀 여부 미확인
- PAUSE_ENDED: 실제 종료와 회원권 상태 확인

승인된 휴회자를 휴면 캠페인에 넣지 않는다.

### 6.2 휴면

휴면은 대표가 승인한 정의와 기준 시스템으로 판정한다.

필수 확인:

- 회원권 상태
- 마지막 출석
- 휴회·해지·결제 실패 여부
- 지점 이동
- 연락 중단
- 미성년자 보호자 권한
- 분쟁·환불·안전 사건

휴면은 마케팅 편의를 위한 임의 태그가 아니라 검증된 운영 상태여야 한다.

### 6.3 해지

해지 요청, 회원권 효력 종료, 환불, 정산을 분리한다.

해지한 사람의 재접촉 가능 여부는 계약 종료와 별개로 동의·중단 상태를 확인한다.

## 7. 복귀 연락 적격성

다음 조건을 모두 충족할 때만 REACTIVATION_ELIGIBLE로 분류한다.

- 동일인·회원 상태가 검증됨
- 휴회·해지·미납·분쟁 상태가 확인됨
- 적법한 연락 근거와 채널이 확인됨
- 연락 중단 요청이 없음
- 미성년자는 보호자 권한과 수신 주체가 확인됨
- 최신 지점·수업·가격 정보를 검증할 수 있음
- 담당자와 종료 기준이 배정됨

다음은 자동 제외한다.

- DO_NOT_CONTACT
- 민원·분쟁 처리 중
- 환불 미완료
- 안전사고 조사 중
- 개인 건강정보 확인이 필요한 상태
- 담당 지점이 불명확
- 중복 회원 또는 다른 지점 활성회원
- 연락 적격성 데이터 미연결

## 8. 복귀 메시지 원칙

복귀 메시지는 죄책감, 압박, 건강 추정, 허위 희소성을 사용하지 않는다.

### 8.1 허용되는 목적

- 안부 확인
- 고객이 요청한 정보 제공
- 현재 참여 가능 여부 확인
- 최신 수업·예약 경로 안내
- 고객 지정 시점의 재접촉
- 연락 종료 의사 확인

### 8.2 금지 표현 유형

- 왜 안 나오느냐는 추궁
- 곧 회원권이 사라진다는 허위 긴급성
- 건강이 나빠졌을 것이라는 추정
- 체중·외모·부상에 대한 압박
- 미확정 할인·무료 혜택
- 승인되지 않은 가격·시간표
- 다른 회원과의 비교
- 미성년자에게 직접 결제 요구
- 수신거부 이후 다른 채널 연락

### 8.3 운영 연락과 광고성 연락

회원권 상태 확인, 요청한 정보 전달과 할인·재등록 권유를 구분한다.

광고성 정보가 포함되면 해당 채널의 동의 원장과 표시·수신거부 요건을 확인한다.

## 10. 복귀 성과 정의

### 10.1 복귀 의사

고객이 수련 재개 의사를 표현한 상태다. 실제 출석이나 결제가 아니다.

### 10.2 복귀 예약

수업 또는 상담 예약이 확정된 상태다. 실제 방문이 아니다.

### 10.3 실제 복귀

복귀 이후 첫 출석이 기준 원장에서 검증된 상태다.

### 10.4 회원권 복귀

유효한 회원권 상품·지점·기간이 활성화된 상태다.

### 10.5 매출 복귀

실수납이 확인되고 환불·차지백과 연결 가능한 상태다.

### 10.6 복귀 후 유지

대표가 승인한 관찰기간 동안 출석 또는 유효 회원권 조건을 충족한 상태다.

첫 재출석 1회만으로 지속 복귀를 확정하지 않는다.

## 11. 신규·복귀·재등록·지점 이동 분리

| 구분 | 기준 |
|---|---|
| 신규 | 과거 활성 회원권이 없고 신규 계약·실수납·회원권 활성화 확인 |
| 휴면 복귀 | 승인된 휴면 상태 이후 실제 재출석 또는 회원권 재활성화 |
| 재등록 | 기존 또는 만료 회원이 승인된 정의에 따라 회원권을 갱신 |
| 지점 이동 | 동일 회원이 운영 지점을 변경 |
| 프로그램 변경 | 동일 지점 내 수업·상품 변경 |
| 재방문 | 출석은 했으나 회원권·수납 변화 없음 |

한 사건을 둘 이상의 성과로 중복 집계하지 않는다.

## 13. 코호트 설계

다음 코호트를 섞지 않는다.

- 신규 가입 첫 30일
- 신규 가입 31~90일
- 장기 활성 회원
- 출석 감소 위험 회원
- 승인된 휴회 종료 예정
- 회원권 만료
- 결제 실패
- 해지 완료
- 휴면
- 첫 복귀 출석
- 복귀 후 관찰기간

각 코호트의 성과는 동일한 관찰기간으로 비교한다.

## 14. 역할별 실행

### CMO

- 신규 획득과 회원 손실을 별도 관리
- 할인보다 상태·원천·연락 적격성 연결을 우선
- 지점별 기준 없는 복귀 목표를 임의 설정하지 않음

### Growth Analyst

- 개인 기준선과 공통 기준을 분리
- 누락·휴강·휴회·지점 이동을 위험 신호에서 제거
- 코호트별 분자·분모·관찰기간을 고정

### Acquisition Marketer

- 복귀 회원을 신규 성과로 집계하지 않음
- 신규 캠페인 성과에서 기존회원·지점 이동 제외
- 공개 콘텐츠 반응을 복귀 성과로 오분류하지 않음

### CRM Marketer

- 적격성·빈도·중단 조건 준수
- 추정 사유 대신 고객 확인 상태 기록
- 첫 재출석 이후 유지 체크를 별도 관리

### Content Strategist

- 개인 출석·건강·결제 사유를 콘텐츠에 사용하지 않음
- 코치 개인 계정에서 특정 회원의 복귀를 암시하지 않음
- 일반적인 입문·복습·안전 콘텐츠로만 연결

### Experiment Manager

- 실제 연락 전 합성 데이터로 상태 분류 검증
- 메시지 발송 수를 복귀율로 보고하지 않음
- 외부 벤치마크를 내부 성공 기준으로 사용하지 않음

### Auditor

- 개인정보·미성년자·민감정보·연락 중단 검토
- 중복 집계와 매출 과대 계상 탐지
- 승인 없는 연락·혜택·계정 변경 차단
