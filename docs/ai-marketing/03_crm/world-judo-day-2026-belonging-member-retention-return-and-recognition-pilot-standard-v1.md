## 1. 판단

이번 공식 주제는 단순한 ‘환영’ 메시지보다 **회원이 인정받고, 연결되고, 계속 머물 수 있는 경험**을 점검할 계기다.

현재 내부 회원·매출·전환 데이터는 연결되지 않았다. 따라서 공개 홍보를 먼저 확대하지 않고, 한 지점 또는 한 수업 단위에서 다음 네 여정을 식별·측정할 수 있게 만드는 것을 우선한다.

1. 신규 문의 → 체험 예약 → 실제 방문 → 등록
2. 체험 후 미등록 → 사유 확인 → 적합한 후속 안내
3. 휴면·복귀 → 복귀 장벽 확인 → 첫 방문 → 2주 유지
4. 만료 예정·기존 회원 → 코치 확인 → 재등록 또는 이탈 사유 기록

## 2. IJF 발표에서 가져온 원칙

IJF는 inclusion을 ‘문을 여는 것’, belonging을 ‘구성원으로 인정받고 지원받으며 계속 함께할 수 있는 것’으로 구분한다.

파일럿에서는 이 원칙을 다음처럼 번역한다.

- 참여 가능하다는 말보다 실제 안내 동선이 명확한가
- 첫 방문자가 누구에게 무엇을 물어볼지 아는가
- 체험 후 미등록 사유를 압박 없이 기록할 수 있는가
- 복귀 회원이 쉬었던 이유를 공개하도록 강요받지 않는가
- 기존 회원의 도움·참여가 구체적으로 인정되는가
- 운영 능력을 넘는 접근성·의료·적응형 수업을 홍보하지 않는가

## 3. 네 목표별 적용

| 목표 | 회원 경험 설계 | 최소 측정 이벤트 | 현재 상태 |
|---|---|---|---|
| 신규 체험 확보 | 첫 문의 답변에 수업 흐름·복장·방문 절차를 일관되게 안내 | 문의, 체험 예약, 실제 방문, 등록 | 데이터 미연결 |
| 휴면회원 복귀 | 복귀 장벽을 선택형으로 확인하고 가능한 복귀 경로만 안내 | 동의된 연락, 답변, 복귀 예약, 실제 복귀, 2주 유지 | 데이터 미연결 |
| 재등록·만족 | 만료 전 코치 확인과 기여·참여 인정 기록 | 만료 예정, 확인 완료, 재등록, 이탈 사유 | 데이터 미연결 |
| 매출 증대 | 허위 혜택 없이 등록·재등록 전환을 정확히 연결 | 등록·재등록 건수와 결제일, 유입 경로 | 데이터 미연결 |

## 4. 코호트별 최소 운영안

### A. 신규 체험

- 첫 방문 전: 수업 흐름, 복장, 도착 시간, 문의 담당을 확인한다.
- 도착 시: 운영 가능한 경우 이름 확인, 공간 안내, 질문 창구를 제공한다.
- 수업 후: 다음 단계와 문의 방법을 한 번만 명확히 안내한다.
- 기록: 체험 예약일, 방문 여부, 등록 여부, 유입 경로를 분리한다.

### B. 체험 후 미등록

- 연락 동의가 있는 경우에만 후속 안내한다.
- 가격·시간·거리·수업 적합성·보류·연락 원치 않음 등 사유를 선택형으로 기록한다.
- 혜택을 임의로 만들거나 마감 압박을 사용하지 않는다.
- ‘연락 원치 않음’은 즉시 제외한다.

### C. 휴면·복귀

- 연락 동의와 휴면 기준을 먼저 확정한다.
- 복귀 이유나 건강 상태를 공개하도록 요구하지 않는다.
- 실제 제공 가능한 수업·강도·상담 범위만 안내한다.
- 복귀 방문과 2주 내 재방문을 별도 이벤트로 기록한다.

### D. 만료 예정·기존 회원

- 만료일 전 일관된 시점에 코치 확인을 실시한다.
- 불편·수업 적합성·목표 변화·시간 문제를 선택형으로 기록한다.
- 대회 실적이나 변화 후기를 동의 없이 홍보 소재로 전환하지 않는다.
- 재등록 여부와 만족 응답을 분리한다.

## 6. EXP-460 측정 설계

### 가설

환영 문구를 늘리는 것보다 회원 여정의 다음 단계와 담당자를 명확히 하고, 체험·복귀·재등록 사유를 일관되게 기록하면 병목을 확인할 수 있다.

### 범위

- 대표가 지정한 1개 지점 또는 1개 수업
- 대표가 승인한 코호트만 적용
- 기간은 승인일로부터 World Judo Day인 2026-10-28 전후 비교가 가능하도록 설정
- 실제 시작일·종료일은 승인 후 기록

### 필수 필드

- 지점 또는 수업 코드
- 코호트
- 유입 경로
- 최초 접점일
- 다음 단계 예정일
- 다음 단계 완료 여부
- 중단·보류 사유 코드
- 연락 동의 상태
- 담당자
- 데이터 출처와 기록 시각

개인 식별정보는 승인된 내부 시스템에만 보관하고 공개 저장소에는 집계값만 남긴다.

### 성공 기준

운영 품질 기준:

- 이벤트 연결률 95% 이상
- 필수 필드 완성률 95% 이상
- 승인 없는 고객 메시지·비용·계정 변경 0건
- 공개 저장소 민감정보 노출 0건
- 실제 운영과 홍보 문구 불일치 0건

사업 성과 기준:

- 신규 등록률, 복귀율, 2주 유지율, 재등록률은 기준 데이터와 최소 표본이 연결된 뒤 대표 승인으로 확정한다.
- 현재는 분자·분모가 없어 계산하지 않는다.

### 중단 기준

다음 중 하나라도 발생하면 신규 홍보·발송을 중단하고 운영을 재검토한다.

- 이벤트 연결률 또는 필수 필드 완성률이 95% 미만
- 수신 동의 또는 촬영·공개 동의가 확인되지 않음
- 실제 제공할 수 없는 접근성·의료·적응형 수업을 암시함
- 회원에게 민감한 사유 공개를 압박함
- 공개 저장소에 개인 식별정보나 내부 원장이 포함됨
