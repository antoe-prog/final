# 체험 후 미등록·결정 보류·거절 사유·재접촉·등록 귀속 기준 v1

- 문서 상태: 공개 운영 기준
- 적용 목적: 신규 체험회원 확보, 체험 후 미등록 회수, 휴면 복귀 구분, 재등록·매출 귀속 정확도
- 적용 범위: 파이널유도멀티짐의 체험 수업 이후 후속 관리 설계
- 제외 범위: 개인 식별정보, 연락처, 개인별 출석·건강·결제 내역, 비공개 가격·혜택, 미확정 행사
- 기준일: 2026-09-17

## 1. 핵심 원칙

체험을 신청했거나 예약했다고 해서 체험에 참석한 것은 아니다. 체험에 참석했다고 해서 등록 의사가 있는 것도 아니며, 등록 의사가 있다고 해서 계약·결제·회원권 활성화가 완료된 것도 아니다.

따라서 다음 사건을 각각 분리해 기록한다.

1. 체험 문의
2. 체험 예약 요청
3. 체험 예약 확정
4. 체험 참석 확인
5. 후속 연락 적격성 확인
6. 후속 연락 시도
7. 메시지 전달 또는 통화 연결
8. 고객 응답
9. 결정 보류
10. 등록 의사
11. 계약 완료
12. 결제 승인
13. 실수납
14. 회원권 활성화
15. 거절
16. 연락 중단 요청
17. 재접촉 예정
18. 장기 미결정 또는 소실

어느 한 단계도 다음 단계의 자동 증거로 사용하지 않는다.

## 2. 우선 관리 대상

### 2.1 포함

다음 조건을 모두 충족할 때 체험 후 후속 후보로 분류한다.

- 실제 체험 참석이 출석 원장 또는 담당자 검증으로 확인됨
- 아직 활성 회원권과 실수납이 확인되지 않음
- 후속 연락을 허용하는 법적·내부 운영 근거가 있음
- 연락 중단 요청 또는 채널 차단 상태가 아님
- 중복 고객·지점 이동·기존 회원 여부가 검토됨

### 2.2 별도 큐

다음 대상은 체험 후 미등록 큐와 합치지 않는다.

- 예약했으나 참석 여부가 확인되지 않은 사람
- 사업자 휴강·일정 변경으로 체험하지 못한 사람
- 기존 회원의 다른 지점 체험
- 휴면회원의 복귀 체험
- 기존 회원의 프로그램 변경 체험
- 보호자 결정이 필요한 미성년 체험
- 이미 계약했으나 결제 또는 회원권 반영만 지연된 사람
- 환불·해지·분쟁 처리 중인 사람

## 5. 미등록 사유 체계

사유는 고객이 직접 말했거나 담당자가 확인 가능한 근거가 있을 때만 기록한다. 담당자의 추정은 확정 사유와 분리한다.

| 사유 코드 | 의미 | 기록 규칙 |
|---|---|---|
| SCHEDULE | 수업 시간·생활 일정 불일치 | 고객이 말한 범위만 기록 |
| LOCATION | 거리·교통·지점 접근 문제 | 주소 등 불필요한 상세정보 제외 |
| PROGRAM_FIT | 수업 내용·강도·형식의 적합성 | 가치 판단 없이 요약 |
| PRICE_BUDGET | 가격·예산 문제 | 임의 할인 제안 금지 |
| GUARDIAN_FAMILY | 보호자·가족 결정 필요 | 미성년자 권한 확인 |
| TIMING | 지금은 시작 시점이 아님 | 가능하면 고객 지정 시점 기록 |
| COMPARING | 다른 선택지 비교 중 | 경쟁사 추정·비방 금지 |
| HEALTH_SAFETY | 건강·안전 우려를 고객이 언급 | 최소한으로 기록하고 민감정보 접근 제한 |
| NOT_INTERESTED | 명시적으로 관심 없음 | 재접촉 의사 별도 확인 |
| UNREACHABLE | 승인된 시도 후 연결되지 않음 | 거절로 변환 금지 |
| DUPLICATE_INVALID | 중복·오입력·스팸 확인 | 검증 근거 보존 |
| OTHER_VERIFIED | 위 분류 외 확인된 사유 | 짧고 중립적으로 기록 |
| UNKNOWN | 이유가 확인되지 않음 | 추정하지 않음 |

사유마다 다음 메타데이터를 둔다.

- 확인일
- 확인 채널
- 고객 직접 발언 여부
- 담당자 추정 여부
- 재접촉 허용 여부
- 고객 지정 재접촉일
- 민감정보 포함 여부
- 검토 책임자

## 6. 후속 연락 원칙

### 6.1 운영 연락과 광고성 연락 분리

체험 참석 확인, 분실물 안내, 요청한 정보 전달 등 운영 목적 연락과 할인·등록 권유·행사 홍보 등 광고성 연락을 분리한다.

- 운영 연락에 판촉 문구를 끼워 넣지 않는다.
- 광고성 연락은 적용 법령과 수신 동의 원장에 따라 적격성을 확인한다.
- 수신거부·연락 중단 요청은 채널별 캠페인보다 우선한다.
- 미성년자에게 직접 결제·계약을 압박하지 않는다.

### 6.2 메시지 목적은 한 번에 하나

후속 연락은 다음 중 하나의 목적만 선택한다.

- 체험 경험에 대한 짧은 확인
- 고객이 요청한 정보 제공
- 등록 절차 설명
- 재방문 또는 상담 가능 여부 확인
- 고객 지정 시점의 재접촉
- 연락 종료 확인

후기 요청, 추천 요청, 리뷰 인센티브, 추가 상품 판매를 체험 후속에 동시에 묶지 않는다.

### 6.3 빈도와 시점

보편적인 최적 횟수나 간격을 임의로 확정하지 않는다. 대표가 승인한 정책과 고객의 요청을 우선한다.

각 시도에는 다음을 남긴다.

- 예정 시각
- 실제 시도 시각
- 채널
- 발신 주체
- 전달·연결 상태
- 고객 응답
- 다음 조치
- 중단 사유

## 7. 결정 보류와 재접촉

### 7.1 결정 보류

고객이 생각할 시간이 필요하다고 말하면 DECISION_PENDING으로 둔다.

- 보류를 긍정 또는 부정으로 해석하지 않는다.
- 고객이 원하는 추가 정보만 확인한다.
- 재접촉 허용 여부와 시점을 분리해 확인한다.
- 특정 날짜가 없으면 담당자가 임의의 약속일을 만들지 않는다.

### 7.2 냉각 상태

고객이 특정 시점 이후 연락을 요청한 경우 COOLING으로 둔다.

- 요청한 날짜 전 광고성 재접촉 금지
- 만료된 가격·행사·혜택을 재사용하지 않음
- 재접촉 시 최신 시간표·가격·운영 조건을 다시 확인
- 고객이 중단을 요청하면 즉시 DO_NOT_CONTACT로 변경

## 8. 등록과 매출 귀속

### 8.1 등록 성공

신규 등록은 다음 조건을 모두 확인했을 때만 성과로 집계한다.

- 고객·회원 식별이 검증됨
- 계약 상태가 유효함
- 실수납이 확인됨
- 회원권 상품·지점·기간이 활성화됨
- 신규·복귀·재등록·지점 이동 구분이 완료됨

등록 의사, 결제 링크 클릭, 계약서 작성 시작, 카드 승인만으로 성공 처리하지 않는다.

### 8.2 매출

다음 값을 구분한다.

- 표시 가격
- 계약 금액
- 할인 금액
- 결제 승인액
- 실수납
- 환불
- 차지백
- 순수납

순수납은 승인된 회계 기준과 동일 기간의 실수납·환불·차지백을 연결할 수 있을 때만 계산한다.

## 9. 채널 귀속

Instagram, 네이버, 당근, Google Business Profile, 전화, 지인 추천 등 최초 접점과 체험 예약 채널, 실제 등록 채널을 각각 보존한다.

- 최초 접점과 최종 전환 채널을 하나로 덮어쓰지 않는다.
- DM·댓글·전화 버튼 클릭을 문의 완료로 간주하지 않는다.
- 체험 참석과 등록 사이의 담당자 변경을 신규 문의로 중복 집계하지 않는다.
- 귀속기간과 기여 규칙은 대표 승인 전 적용하지 않는다.

## 12. 역할별 운영

### CMO

- 체험 후 미등록 손실을 신규 유입 부족과 분리
- 추정 사유를 근거로 할인·캠페인을 승인하지 않음
- 네 목표의 중복 집계를 방지

### Growth Analyst

- 상태 전이를 검증하고 분자·분모·기간을 고정
- 무응답·거절·보류·연락 중단을 분리
- 채널과 지점의 중복 귀속을 탐지

### Acquisition Marketer

- 체험 전 약속과 실제 수업 경험의 불일치 여부 확인
- 허위 긴급성·미확정 혜택·성과 보장 사용 금지
- 체험 참석 이후의 다음 단계를 명확히 설명

### CRM Marketer

- 후속 적격성, 채널, 빈도, 중단 조건을 준수
- 고객이 직접 말한 사유와 담당자 추정을 분리
- 재접촉일과 종료 상태를 명확히 관리

### Content Strategist

- 자주 확인되는 질문을 비식별 교육 콘텐츠로 환류
- 개인 후기·건강·결제 사유를 콘텐츠 소재로 전환하지 않음
- 가격·시간표·혜택은 승인된 최신 정보만 사용

### Experiment Manager

- 실험 시작 전 상태·분모·성공·중단 기준 등록
- 메시지 발송 수를 전환 성과로 보고하지 않음
- 작은 표본과 미연결 데이터를 승자로 판정하지 않음

### Auditor

- 동의·미성년자·민감정보·과장·중복 집계 검토
- 연락 중단 요청의 누락 탐지
- 실제 고객 연락은 대표 승인 범위 내에서만 허용

## 13. 실험 설계

### EXP-370: 체험 후 상태·사유·재접촉·등록 귀속 정확도

- 대상: 실제 고객 없이 만든 합성 체험 여정 120건
- 목적: 체험 참석 이후 상태 분류와 매출 귀속 오류 제거

성공 기준:

- 예약을 참석으로 오분류 0건
- 무응답을 거절로 오분류 0건
- 담당자 추정을 고객 확인 사유로 기록한 사례 0건
- 결정 보류를 등록 의사로 오분류 0건
- 등록 의사를 계약·실수납으로 오분류 0건
- 휴면 복귀·재등록·지점 이동을 신규로 오분류 0건
- 연락 중단 이후 후속 적격 처리 0건
- 민감 건강정보의 불필요한 수집·공개 0건
- 승인 없는 실제 연락·할인·계정 변경 0건

중단 기준:

- 연락 중단 요청 누락 1건 이상
- 미성년자 권한 미확인 연락 승인 1건 이상
- 개인정보 또는 결제정보의 공개 저장 1건 이상
- 상태 오분류로 등록·매출이 과대 집계된 사례 1건 이상
