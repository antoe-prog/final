# Parent-to-Member Household Expansion v1

- 작성 기준일: 2026-09-11
- 상태: 전략·실험 설계 완료 / 고객 연락·가격변경·유료집행 전
- 목표: 기존 유소년 회원 가구를 기반으로 성인 신규 체험, 가족 단위 만족·재등록, 추가 매출 기회 검증
- 내부 회원수·가구수·체험수·매출·전환율: **데이터 미연결**

## 오늘의 판단

신규 광고 채널을 하나 더 늘리기보다, 이미 도장을 경험하고 있는 유소년 회원의 보호자를 `관찰자 → 자발적 체험자 → 성인 입문회원`으로 전환할 수 있는지 검증한다.

핵심 퍼널은 다음과 같다.

`youth_active → parent_observation → parent_opt_in → adult_trial → adult_paid → adult_active_30d → youth_renewal → household_revenue`

이는 `부모가 아이와 함께 운동하면 반드시 오래 다닌다`는 가정이 아니다. 성인 체험 전환, 30일 활성, 유소년 재등록과 가구당 수납의 실제 변화가 연결되기 전까지 효과는 미검증 상태로 둔다.

## 발견한 변화

### 1. 기존 유소년 회원의 부모를 별도 성인 입문 잠재고객으로 보는 사례

ZKS Martial Arts의 2026년 9월 뉴스레터는 기존 유소년 회원 부모에게 별도의 완전초보 BJJ 12주 과정을 직접 제안한다. 메시지의 핵심은 `아이에게 매주 요구하는 훈련을 부모도 직접 경험해보라`는 것이다. 최대 12명으로 인원을 제한하고 정해진 시작일·시간·과정으로 운영한다. 파이널유도에 해당 가격·할인·BJJ 구성을 복제하지 않고, **기존 회원 가구 안에 별도의 성인 입문 수요가 있을 수 있다는 운영 사례**로만 사용한다.

### 2. 부모가 자녀 수업을 직접 보는 관찰 접점

CFMWS Ottawa-Gatineau의 2026/27 유소년 유도 프로그램은 부모가 아이의 수업에 머물러 관찰하는 것을 적극 권장한다. 이 구조는 보호자가 수업의 안전·지도 방식·난이도를 직접 이해할 수 있는 접점을 만든다. 관찰 자체가 성인 등록을 만든다는 성과 데이터는 공개돼 있지 않으므로 인과효과로 해석하지 않는다.

### 3. 가족 단위 훈련을 별도 상품 가치로 제시하는 무도시설

Fudoshin Karate는 성인과 어린이가 함께 시작할 수 있는 구조와 가족이 함께 훈련할 수 있다는 점을 공개적으로 안내한다. Sampa Jiu Jitsu도 2026년 6월 Fathers & Kids 이벤트에서 부모가 자녀와 같은 매트에서 훈련하도록 했다. 이는 `아이만 등록하는 시설`과 별도로, 가족 경험 자체를 회원 가치로 설계하는 사례다. 성과 수치는 공개 마케팅 문구이므로 파이널유도의 예상 재등록률·매출로 환산하지 않는다.

## Growth Analyst — 필요한 데이터

공개 저장소에는 실제 개인·가족 식별정보를 저장하지 않는다. 내부 운영시스템에서만 다음 집계를 연결한다.

- 현재 유소년 활성회원 수
- 보호자 연락·마케팅 동의 상태
- 보호자의 성인반 체험 이력 여부
- 보호자 체험 제안 대상 수
- 보호자 자발적 관심표시 수
- 성인 체험 예약 / 현장 실방문 / 유료등록 / 30일 활성
- 유소년 회원의 해당 기간 재등록 여부
- 성인회원 추가 수납 및 환불
- 같은 가구 내 복수회원 여부를 판정할 내부 household key

`household key`는 공개 GitHub 문서에 실제 값을 남기지 않는다. 가족관계를 추정하지 않고 운영시스템에 이미 확인된 관계만 사용한다.

## Acquisition Marketer — 신규 체험 구조

### Parent Taster

실제 성인반 여석이 확인될 때만 기존 보호자가 자발적으로 신청할 수 있는 1회 체험 또는 짧은 입문 세션을 검토한다.

- 체험 가능 일시·정원은 Capacity-First 원칙으로 결정한다.
- 부모의 체력·유도 경험을 미리 단정하지 않는다.
- 아이 수업의 대기시간을 이용한다는 이유만으로 보호자에게 자동 참가를 요구하지 않는다.
- 무료 여부·도복 대여·할인·가족요금은 현재 **데이터 미연결**이며 대표 승인 전 약속하지 않는다.

## CRM Marketer — 대상별 후속 액션

1. **유소년 기존회원 보호자**: 수업 관찰 또는 기존 상담 접점에서 성인반 관심 여부를 자발적으로 표시할 수 있게 한다.
2. **관심표시 후 미예약 보호자**: 실제 성인 초보 가능시간과 준비물만 안내하고 반복 추적은 하지 않는다.
3. **보호자 체험 후 미등록**: 시간대·난이도·비용 중 결정에 필요한 정보가 무엇인지 확인한다.
4. **보호자 등록 가구**: 유소년과 성인의 출석·재등록은 각각 측정하고, 가구 단위 유지효과는 별도로 관찰한다.

실제 고객 메시지 발송은 대표 승인과 연락 권한 확인 전에는 수행하지 않는다.

## Content Strategist — 채널별 기획

### 네이버

- `아이 유도 수업을 보다가 부모도 시작할 수 있을까요?`
- `성인 유도 초보가 첫날 배우는 것`
- `부모·아이 각각 어떤 반에서 시작하는지`

실제 시간표·비용·준비물만 사용한다.

### 인스타그램

- 보호자가 자녀 수업의 준비운동이나 기본 낙법을 직접 체험하는 짧은 과정형 콘텐츠
- `아이에게 해보라고 했던 동작, 부모가 직접 해보면?` 같은 관찰→체험 서사
- 촬영·게시 동의가 없는 회원·보호자는 노출하지 않는다.

### 당근

- 실제 성인 초보석이 있을 때만 `강서구 성인 유도 입문 / 자녀가 다니는 부모도 신청 가능`처럼 지역·대상·시간을 명확히 한다.
- 가족 할인·무료체험·마감임박은 실제 정책과 수용석이 확인될 때만 표시한다.

## Experiment Manager

### EXP-192 Parent Observation → Voluntary Trial

- 가설: 아이 수업을 이미 이해하고 있는 보호자에게 자발적 성인 체험 선택지를 제공하면 새로운 성인 실방문을 만들 수 있다.
- 핵심 KPI: `eligible_parent → opt_in → reservation → verified_attendance → paid_14d → active_30d`
- 보조 KPI: 보호자 문의 처리시간, 유소년 수업 방해·혼잡, 기존회원 불편.
- 성공 기준: 사전 정의한 최소 전환개선 및 운영부담 기준을 충족할 때 확대 검토.
- 중단 기준: 체험 때문에 기존 수업 정원·안전·코치 집중도가 악화되거나, 동의 없는 반복 연락이 발생하면 중단.
- 현재 기준선·최소개선폭·필요 표본: **데이터 미연결**.

### EXP-193 Household Retention Observation

- 가설: 보호자가 실제 성인 회원으로 활성화된 가구는 유소년 단독 가구와 다른 재등록 패턴을 보일 수 있다.
- 측정: `adult_active_30d`, `youth_renewal`, `household_active_members`, `household_net_receipts`.
- 이 실험은 무작위로 부모에게 가입을 강요하는 실험이 아니다. 자연 발생한 가구 코호트를 관찰한다.
- 성공 기준: 충분한 관찰기간과 표본 확보 후 사전에 정의한 유지·수익 기준을 만족할 때 가족 확장 프로그램을 검토한다.
- 중단/판정보류: 표본 부족, 가구 연결 데이터 누락, 가입시점·회원권 차이 등 교란요인이 큰 경우 인과효과를 주장하지 않는다.

## Auditor

- `가족이 함께하면 재등록률이 높다`는 문구를 내부 데이터 없이 사용하지 않는다.
- 보호자의 이름·연락처·가족관계·개인별 출석·결제정보를 공개 GitHub에 저장하지 않는다.
- 유소년 회원의 등록을 이유로 보호자를 자동 마케팅 대상이라고 가정하지 않는다. 현재 연락 권한과 승인 범위를 확인한다.
- 기존 유소년 수업의 안전정원과 코치 집중도가 우선이다. 성인 체험을 끼워 넣기 위해 수업 구조를 무리하게 변경하지 않는다.
- 해외 시설의 할인율·무료체험·성과 표현을 파이널유도의 보장 결과로 복제하지 않는다.

## 필요한 대표 승인·입력

- 현재 성인 초보 수용 가능한 시간대와 안전정원
- 유소년 회원 보호자의 연락·마케팅 동의 확인 방식
- 성인 체험비 / 도복 / 준비물 / 첫날 참여범위
- 가족 할인 또는 복수회원 정책의 현재 존재 여부
- 실제 체험 후 등록·30일 활성·재등록 데이터를 연결할 내부 집계 방식

비용 발생, 할인, 무료체험 확정, 고객 연락, 공개 게시, 계정·운영DB 변경은 이번 문서 작성으로 승인된 것으로 보지 않는다.

- 가구당 순수납 변화: **데이터 미연결**
