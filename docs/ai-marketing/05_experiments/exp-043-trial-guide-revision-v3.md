## 개정 이유

2026년 8~9월 복수의 유도 클럽이 첫 체험 전에 복장, 준비물, 도착시각, 첫 수업 흐름, 도복 필요 여부를 구체적으로 안내하고 있음을 확인했다. 따라서 EXP-043은 `정보를 더 주면 효과가 있는가`가 아니라 **동일한 필수 사실을 더 구조적으로 보여주면 예약 후 실제 방문이 개선되는가**로 좁힌다.

## 가설

확인된 필수정보를 카드/체크리스트처럼 빠르게 읽을 수 있는 구조로 제공하면 현재 텍스트형 안내보다 `예약 확정 → 현장 확인 방문` 전환이 개선될 수 있다. 미검증 가설이다.

## 비교설계

### 공통 필수정보

A와 B 모두 동일하게 제공한다.

1. 확정 지점·날짜·시간
2. 실제 도착경로
3. 실제 권장 도착시각
4. 복장·준비물
5. 첫 수업의 확인된 범위
6. 안전·취소·일정변경 경로
7. 체험비·등록비·도복 등 추가비용 또는 구매 필요 여부

확인되지 않은 값은 작성하지 않는다. 필수정보를 한 군에만 숨기는 실험은 금지한다.

### A

현재 승인된 텍스트 순서로 필수정보를 제공한다.

### B

A와 동일한 사실을 `일정 / 위치 / 준비 / 첫 수업 / 변경` 중심의 7블록 체크리스트로 구조화한다. 링크 수와 연락 횟수는 가능한 한 A와 동일하게 유지한다.

## 대상

- 확정 예약이 있는 신규 체험자
- 휴면 복귀·기존회원은 별도 분석
- 이미 다른 자동알림을 받고 있다면 중복 발송 여부를 먼저 확인

## 주지표

`현장 확인 방문률 = verified_attendance / 종료된 확정예약`

고객취소·노쇼·방문여부 미확인을 분리한다. 방문 여부 미확인을 자동 노쇼로 처리하지 않는다.

## 보조지표

- 일정변경 요청 및 성공률
- 안내 후 반복문의량
- 첫 체험 후 14일 내 유료등록률
- 등록 후 30일 활성률
- 불편·오안내·중복연락 건수
- 담당자 처리시간

14일·30일은 분석창 설계값이며 내부 운영승인 전에 확정한다.

## 성공·보류·중단

### 성공 검토

사전에 고정한 최소 개선폭과 불확실성 기준을 충족하고, 등록·활성·불편·처리시간 지표가 허용범위 안에 있을 때만 확대한다.

### 판정보류

기준선 부재, 표본 부족, 데이터 누락, 관찰기간 미도래, 비교조건 불일치, A/B 간 수업시간·가격·여석 차이가 큰 경우.

### 즉시 중단 또는 수정

- 잘못된 시간·위치·비용·복장 안내
- 수용 불가능한 반으로 예약 유도
- 필수 안전정보 누락
- 명시적 수신 거부 이후 연락
- 플랫폼 기본 알림과 중복되어 과도한 연락이 발생
- 외부 도장의 무료·대여 정책을 파이널유도 정책처럼 표기
