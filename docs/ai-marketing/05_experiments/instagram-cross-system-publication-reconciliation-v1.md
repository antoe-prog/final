- 내부 회원·문의·예약·등록·매출: **데이터 미연결**

## 오늘의 판단

Instagram의 실제 공개 여부와 게시 도구의 `Published` 기록은 같은 의미가 아니다. 활성 게시물은 Instagram 공개 URL과 프로필 노출을 우선 기준으로 판정하고, Metricool은 게시 이력과 보조 분석 원천으로 사용한다.

이번 확인에서 Instagram 프로필에는 3개 게시물이 보였고, Metricool 게시 이력 응답에는 `Published` 4건이 있었다. 차이는 승인본 JUDO-003 v3 한 건이다. 이 게시물은 Metricool에 `Published`로 남아 있지만 Instagram URL은 사용할 수 없고 프로필에도 보이지 않으며 분석 행에도 나타나지 않았다. 원인은 확인되지 않았으므로 재게시·삭제·수정하지 않는다.

### 주의

- Instagram의 `--`는 0이 아니라 미집계·미제공이다.
- Metricool 분석의 0을 Instagram 원본의 `--`로 덮어쓰지 않는다.
- 조회수는 노출 횟수이며 고유 인원으로 해석하지 않는다.
- 서로 다른 URL과 목적의 게시물 수치를 합산하지 않는다.
- Metricool 게시 이력에 있다는 사실만으로 Instagram 공개를 주장하지 않는다.
- 승인 대기 패키지의 미디어·캡션은 확인 요청 범위의 Metricool 이력에 나타나지 않았으며, 업로드·외부 초안 저장·예약·발행을 실행하지 않았다.

## 상태 원천 우선순위

1. **공개 상태:** Instagram 공개 URL과 프로필 표시
2. **원본 성과:** 접근 가능한 Instagram 개별 인사이트
3. **보조 성과:** Metricool 분석 — 반드시 원천과 확인 시각 표기
4. **게시 작업 이력:** Metricool 게시 이력
5. **사업 성과:** 문의·예약·실방문·등록·복귀·재등록·매출의 비식별 내부 집계

두 원천이 충돌하면 값을 억지로 합치지 않고 `상태 불일치`로 보류한다.

## 실험

### EXP-289 Cross-System Publication Reconciliation

**가설**

게시 전후에 Instagram 공개면과 게시 도구 이력을 URL 단위로 대조하면 중복 게시와 잘못된 성과 귀속을 줄일 수 있다.

**체크포인트**

- 발행 직전: 동일 작업 ID·주제의 공개·예약·대기 항목 존재 여부
- 발행 직후: 성공 응답과 공개 URL
- T+15분: Instagram 프로필 표시·URL 접근
- T+24시간·T+72시간: 원본 인사이트와 보조 분석

**성공 기준**

- 승인 패키지당 활성 공개 URL 1개
- URL·버전·게시 시각·원천 기록률 100%
- Instagram 공개면과 게시 도구 상태 일치
- `--`와 0 혼동 0건
- 승인 없는 재게시·삭제·수정 0건

**보류 기준**

- 공개면과 게시 도구 상태 불일치
- 원본 인사이트 미집계 또는 접근 불가
- 게시 작업 ID·버전·승인 경로 미확인
- 사업 퍼널 데이터 미연결

**중단 기준**

- 확인 전 재게시
- 서로 다른 URL의 지표 합산
- Metricool 상태만으로 공개 완료 주장
- 개인정보 또는 승인 대기 미디어·캡션의 공개 저장
