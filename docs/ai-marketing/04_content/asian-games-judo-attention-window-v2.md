# Asian Games Judo Attention Window v2 — 이벤트 운영 모드 전환

- 기준일: 2026-09-13
- 상태: 공개 콘텐츠·계측·브랜드 안전 설계 / 실제 게시·광고·고객 발송 전
- 내부 회원수·매출·전환율: **데이터 미연결**
- 이전 문서: `asian-games-judo-attention-window-v1.md`

## v2에서 바뀐 점

v1은 대회 전반의 관심창을 `교육형 콘텐츠 → 체험 전환`으로 정의했다. v2는 개막이 가까워진 시점에서 실행 단위를 더 작게 나눈다.

1. 공식 일정과 공식 결과 페이지를 Source of Truth로 고정한다.
2. 방송 화면·선수 사진 재사용 없이 `공식 결과 확인 → 코치 자체 설명 → 지역 체험 CTA`로 반응한다.
3. 선수·메달 뉴스는 조회수용 소재가 아니라 `유도 이해 → 실제 방문` 퍼널의 상단 신호로만 쓴다.
4. 신규, 휴면·복귀, 기존회원의 목적을 분리해 같은 메시지를 일괄 발송하지 않는다.
5. 경기 당일 운영이 수업·코치 업무를 침해하지 않도록 제작 시간 상한과 중단 기준을 둔다.

## 오늘의 판단

2026 아이치·나고야 아시안게임은 9월 19일 개막한다. 공식 경기장 페이지 기준 유도는 Aichi International Arena에서 9월 30일~10월 3일 진행되며 매일 오전·오후 세션이 나뉜다. 공식 유도 페이지에는 경기 일정, Live Results, Medal Table 진입점이 별도로 마련되어 있다.

따라서 파이널유도멀티짐의 우선순위는 `아시안게임 응원 게시물 수`가 아니라 다음 체인을 검증하는 것이다.

`official_event_signal → original_explainer → local_profile_visit → qualified_inquiry → slot_offered → booking → verified_attendance → paid_14d → active_30d → renewal`

조회수, 좋아요, 저장, 응원댓글은 보조지표다. 실제 성공은 실방문·등록·30일 활성·재등록까지 연결해 판정한다.

현재 파이널유도의 네이버·인스타·당근 유입, 문의, 예약, 실방문, 14일 등록, 30일 활성, 재등록, 귀속매출은 전부 **데이터 미연결**이다.

## 발견한 변화

### 1. 아시안게임이 준비 단계에서 실제 이벤트 운영 단계로 진입했다

Aichi-Nagoya 2026 공식 사이트는 9월 16~18일 Team Welcome Ceremony를 진행한다고 9월 8일 공지했다. 대회 개막은 9월 19일이다.

유도 경기장은 Aichi International Arena이며 공식 Venue Opening Schedule 기준 세션은 다음과 같다.

- 9월 30일: JUD01 11:00~14:00 / JUD02 17:00~19:30
- 10월 1일: JUD03 11:00~14:00 / JUD04 17:00~19:30
- 10월 2일: JUD05 11:00~14:00 / JUD06 17:00~19:30
- 10월 3일: JUD07 11:00~14:00 / JUD08 17:00~19:30

공식 사이트는 일정이 변경될 수 있음을 명시하므로 게시 당일 재확인이 필요하다.

공식 출처:

### 2. 한국 유도대표팀 관련 관심 신호가 구체화됐다

2026년 9월 9일 연합뉴스 보도에서 한국 대표팀은 아시안게임에서 남자 2개, 여자 2개 이상 금메달을 목표로 제시했고, 허미미(-57kg), 이현지(+78kg) 등 주요 우승 후보가 언급됐다.

이 뉴스는 파이널유도 신규회원 증가를 뜻하지 않는다. 다만 한국어권에서 선수·체급·경기전망 관련 검색과 콘텐츠 소비가 커질 가능성을 탐색할 수 있는 시의성 신호다.

출처:
- https://en.yna.co.kr/view/AEN20260909006200315
- https://www.yna.co.kr/view/AKR20260909098200007

### 3. 공식 사이트가 Live Results와 Medal Table을 제공한다

경기 기간 중 결과 확인은 기사·SNS 재전달보다 공식 결과 페이지를 우선한다. 파이널유도 콘텐츠는 공식 결과를 확인한 뒤 경기 장면을 재사용하지 않고 자체 기술 데모·텍스트 도식으로 설명한다.

이 구조는 다음 리스크를 낮춘다.

- 방송화면·선수사진 무단 재사용
- 잘못된 경기결과 또는 체급정보 전파
- 공식 파트너로 오인되는 브랜딩
- 승패 중심 과장 콘텐츠

## 역할별 실행 기준

### 1) CMO

이번 관심창의 목표 우선순위는 다음이다.

1. 신규 체험회원: 이벤트 관심을 실제 체험으로 연결
2. 기존회원 만족·재등록: 경기 이해 콘텐츠를 학습동기로 활용
3. 휴면회원 복귀: 자발적 반응 또는 기존 동의 범위 내에서만 복귀 경로 제공
4. 매출: 체험·복귀·재등록에서 발생한 증분 순기여로 판단

`메달 소식 → 할인`처럼 즉시 가격 프로모션으로 연결하지 않는다.

### 2) Growth Analyst

신규 퍼널:

`event_content_view → profile_visit → inquiry → slot_offered → booking → verified_attendance → paid_14d → active_30d`

휴면·복귀 퍼널:

`event_content_view → self_declared_return_interest → return_slot_offered → verified_return_visit → active_30d → renewal`

기존회원 퍼널:

`member_content_exposure → class_learning_use → active_30d → renewal`

필요 데이터는 모두 비식별 집계로 관리한다.

### 3) Acquisition Marketer

신규획득 메시지는 `선수처럼 훈련`이 아니라 `경기에서 보이는 기술을 초보자가 어떻게 배우는지`로 둔다.

예시 주제:

- 유도 경기에서 왜 먼저 균형을 무너뜨리는가
- 한판과 절반을 볼 때 무엇을 봐야 하는가
- 메치기 전에 그립 싸움이 중요한 이유
- 굳히기 상황에서 20초가 왜 중요한가
- 초보자는 왜 낙법부터 배우는가

CTA는 실제 여석이 확인된 경우에만 체험 시간으로 연결한다.

### 4) CRM Marketer

- 휴면회원 전체 대상 아시안게임 일괄 메시지 금지
- 기존회원에게 `대회 보세요`만 보내는 홍보성 메시지보다 수업과 연결된 학습 포인트 우선
- 체험후미등록자는 기존 후속관리 정책과 중복 발송하지 않음
- 복귀 의향을 본인이 표시한 사람만 RETURNER로 구분

### 5) Content Strategist

#### 네이버

검색의도형 장문을 중심으로 한다.

- `2026 아시안게임 유도 경기 일정과 보는 법`
- `유도 한판·절반·지도 쉽게 이해하기`
- `유도 경기에서 보이는 그립과 균형의 원리`
- `유도 처음 배우면 왜 낙법부터 하나`

모든 일정·결과 콘텐츠는 공식 사이트를 먼저 확인한다.

#### 인스타그램

15~30초 자체 촬영 원본을 사용한다.

구조:
1. 오늘 경기에서 볼 포인트 1개
2. 코치 자체 기술 데모 1개
3. 초보자 수업에서의 적용 1개
4. CTA 1개

방송 캡처와 선수 경기영상은 기본적으로 사용하지 않는다.

#### 당근

지역 정보형으로 제한한다.

- 강서구에서 유도 경기 보고 직접 배워보고 싶은 사람에게 필요한 준비물
- 성인 초보가 첫 수업에서 배우는 것
- 실제 체험 가능 요일·시간

여석 확인 전 `마감임박`, `오늘 가능`, `잔여 1석`을 쓰지 않는다.

### 6) Experiment Manager

실험은 최대 3개만 동시에 운영한다.

### 7) Auditor

매 게시 전 다음을 체크한다.

- 일정·결과가 공식 Source of Truth와 일치하는가
- 방송화면·선수사진·공식 로고 사용권이 확인됐는가
- `공식 파트너`, `국가대표식`, `메달리스트 훈련법` 등 오인 표현이 없는가
- 실제 체험시간·대상·여석과 CTA가 일치하는가
- 회원·미성년자 촬영 동의가 확인됐는가
- 성과를 조회수만으로 평가하고 있지 않은가

## 즉시 실행 3개

### A. Event-Day Source of Truth 보드 준비

경기 당일 운영자가 확인할 링크를 3개로 제한한다.

1. 공식 유도 일정
2. 공식 Live Results
3. 공식 Medal Table

기사와 SNS는 맥락 확인용 보조출처로만 사용한다.

### B. Rights-Safe Same-Day Explainer 템플릿 준비

경기 후 같은 날 제작할 콘텐츠는 아래 형식으로 통일한다.

- 공식 결과 한 줄
- 오늘 경기에서 이해할 기술/규칙 1개
- 코치 자체 촬영 또는 자체 도식 1개
- 초보자 수업에서의 연결 1개
- 실제 체험 가능 슬롯 CTA 1개

제작시간 상한은 대표 승인 전 **데이터 미연결**이다.

### C. 이벤트 유입 태깅 준비

최소 태그:

- `ASIAN_GAMES_NAVER`
- `ASIAN_GAMES_INSTAGRAM`
- `ASIAN_GAMES_DAANGN`
- `ASIAN_GAMES_DIRECT`
- `UNKNOWN`

동일 사람이 여러 채널에서 문의하면 중복리드로 추정하되 불필요한 개인정보를 수집하지 않는다.

## 실험 1~3개

### EXP-274 Event-Day Explainer vs Generic Technique Content

가설: 대회 당일 공식 결과와 연결한 자체 설명 콘텐츠가 일반 기술 콘텐츠보다 유효문의·실방문을 늘릴 수 있다.

A: 일반 자체 기술 콘텐츠
B: 공식 경기결과 확인 후 제작한 자체 기술 설명 + 동일 CTA

주지표:
- `verified_attendance / qualified_inquiries`

보조지표:
- 프로필 방문
- 문의
- 예약
- 14일 등록
- 30일 활성
- 제작시간

성공 기준:
- 사전에 승인한 최소개선폭 충족
- 저작권·사실오류 0건
- 수업운영 부담 상한 이내

중단 기준:
- 조회수만 상승하고 실방문·활성 개선 없음
- 일정/결과 오정보
- 방송화면 무단사용
- 코치 제작부담이 수업운영을 침해

기준선·최소개선폭·표본수: **데이터 미연결**

### EXP-275 Search Intent Article → Local Trial

가설: `경기 보는 법` 검색형 네이버 콘텐츠가 일반 도장 홍보글보다 더 적합한 체험문의로 이어질 수 있다.

A: 일반 도장 소개
B: 경기 규칙·기술 해설 + 실제 체험 CTA

핵심 KPI:
`article_visit → inquiry → booking → verified_attendance → paid_14d → active_30d`

중단 기준:
- 검색유입은 증가하지만 체험 실방문 개선 없음
- 경기정보 업데이트 부담이 과도함
- 오래된 경기결과가 최신 정보처럼 남음

### EXP-276 Member Learning Layer

가설: 기존회원에게 경기 관전포인트를 실제 수업 기술과 연결해 주면 학습 만족·출석 지속에 도움이 될 수 있다.

측정:
`content_exposed_members → next_30d_attendance → renewal`

주의:
- 인과관계 사전 가정 금지
- 선수 성과를 회원의 승급·경기성과와 연결해 과장 금지
- 기존회원에게 외부 게시물 열람을 강제하지 않음

## Auditor 최종 체크

다음 문구·행동은 기본 금지한다.

- `아시안게임 공식 파트너 도장`
- `국가대표식 훈련`
- `금메달 기술 그대로 배운다`
- 선수 얼굴·방송화면·공식 엠블럼의 무단 광고 활용
- 공식 결과 확인 전 승패 속보 게시
- 실제 여석 확인 전 `마감 임박`, `잔여 1석`
- 신규/휴면/기존회원에 동일 메시지 일괄 발송
- 이벤트 조회수를 회원 증가로 해석

이번 전략의 성공은 `아시안게임 때문에 콘텐츠 조회수가 늘었는가`가 아니라 **이벤트 관심이 안전하고 정확한 교육 콘텐츠를 거쳐 실제 체험·활성·재등록으로 이어졌는가**로 판정한다.
