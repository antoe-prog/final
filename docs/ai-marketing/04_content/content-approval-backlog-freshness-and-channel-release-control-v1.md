# 콘텐츠 승인 적체·최신성·채널 배포 통제 기준 v1.1

- 적용 범위: 파이널유도멀티짐 관련 공개 마케팅 콘텐츠
- 문서 성격: 공개 가능한 운영 기준
- 기준일: 2026-09-20
- 개인정보: 수집·기록·공개하지 않음
- 승인 대기 미디어·캡션: 포함하지 않음

## 1. 운영 판단

콘텐츠가 이미 승인 대기 중이면 새 제작량을 늘리기보다 기존 완성본의 `승인·수정·폐기·보류` 결정을 먼저 받아야 한다.

제작 완료는 배포 완료가 아니며, 배포 완료는 성과 발생이 아니다. 승인 대기본이 쌓인 상태에서 새 콘텐츠만 추가하면 다음 문제가 생긴다.

- 사실과 규정의 최신성이 떨어짐
- 비슷한 주제가 중복 제작됨
- 폐기본 또는 이전 버전이 게시될 위험이 커짐
- 게시 간격과 채널 목적이 무너짐
- 게시 후 측정할 대상을 식별하기 어려워짐
- 대표의 실제 결정이 필요한 병목이 가려짐

## 2. 승인 큐의 최소 기록 단위

승인 대기 콘텐츠마다 아래 필드를 가진 한 행을 만든다.

| 필드 | 필수 | 공개 저장소 기록 |
|---|---:|---|
| 작업 ID | 예 | 개별 승인 대기본은 제외 |
| 버전 | 예 | 개별 승인 대기본은 제외 |
| 채널 | 예 | 일반 운영 기준만 공개 가능 |
| 대상 계정·프로필 | 예 | 승인 대상에서 명시 |
| 사업 목적 | 예 | 신규·복귀·재등록·만족·매출 중 선택 |
| 단일 CTA | 예 | 저장·질문·팔로우·수업 문의 등 하나 |
| 현재 상태 | 예 | 정의된 상태만 사용 |
| 근거 확인일 | 사실 주장 시 | 일반 원칙만 공개 가능 |
| 권리·동의 상태 | 예 | 식별정보 없이 상태만 기록 |
| 다음 결정 | 예 | 승인·수정·폐기·보류 |
| 결정 담당 | 예 | 공개 문서에는 역할명만 사용 |
| 다음 검토일 | 예 | 내부 운영표에서 관리 |

회원·보호자 식별정보, 개인 연락처, 개인별 출석·결제·건강 정보는 승인 큐에 넣지 않는다.

## 4. 우선순위

### P0 — 즉시 중지·교정

- 이미 공개된 오탈자 또는 사실 오류
- 잘못된 계정·지점·가격·시간표·행사 정보
- 공개 동의가 확인되지 않은 촬영물
- 폐기본 또는 중복 게시

### P1 — 승인 완료·미게시

- 승인된 미디어와 캡션의 동일성 확인
- 계정·형식·순서·공개 여부 확인
- 게시 전 최신 사실 재검증

### P2 — 완성·승인 대기

- 대표가 실제 완성본을 볼 수 있게 제공
- 승인·수정·폐기·보류 중 하나를 결정
- 승인 전 외부 업로드 금지

### P3 — 사실·권리 미확인

- 규정·시간표·가격·혜택·행사·지점 정보 재확인
- 촬영물 공개 동의 확인
- 확인 전 공개 문구로 완성하지 않음

### P4 — 미래 아이디어

- 기존 큐와 주제·목적·CTA 중복 확인
- 승인 적체가 해소되기 전 제작량을 자동으로 늘리지 않음

## 5. 최신성 등급

### A. 당일 확인이 필요한 정보

- 운영시간·수업시간·휴무
- 가격·무료 체험·혜택·쿠폰
- 행사 개최·모집·참가비·보상
- 예약 가능 여부·정원
- 지점 주소·문의 경로

게시 당일 기준 원천을 확인할 수 없으면 보류한다.

### B. 버전 확인이 필요한 정보

- 경기 규정
- 도복 규정
- 플랫폼 기능·정책
- 법령·광고성 정보 전송 기준

문서명, 버전 또는 시행일, 확인일, URL을 기록한다. 이전 버전의 표현을 최신 규정처럼 쓰지 않는다.

### C. 사실 제공이 필요한 개인 콘텐츠

- 코치의 당일 수련
- 지도 경험
- 지도 철학
- 대회 경험과 실적

사용자 자료가 없으면 실제 경험처럼 1인칭으로 쓰지 않는다.

### D. 권리 확인이 필요한 콘텐츠

- 회원 후기
- 회원·보호자 식별 가능 촬영물
- 실제 수련 변화
- 제3자 이미지·영상·음원

공개 사용 동의와 범위를 확인하지 못하면 제외한다.

## 6. 한국시간 하루 기준 제작량 통제

Instagram 새 게시 패키지는 한국시간 하루에 1개를 기본값으로 한다.

같은 날의 추가 작업은 다음 순서로 진행한다.

1. 승인 대기본의 사실·오탈자·접근성 재검수
2. 수정본과 이전 버전 분리
3. 공개 게시물 성과 확인
4. 다음 소재의 근거만 준비
5. 대표 결정이 필요한 항목 정리

새 패키지 추가가 필요한 예외는 대표가 긴급 공지 또는 우선 캠페인을 승인한 경우다. 이 경우에도 시간표·가격·혜택·행사 사실을 당일 확인한다.

## 7. 채널별 배포 기준

### Instagram 코치 개인 계정

- 코치 개인의 설명·수련·지도 맥락을 유지한다.
- 본관 또는 브랜드 공식 발표처럼 쓰지 않는다.
- 한 게시물에 CTA 하나를 사용한다.
- 완성 이미지·순서·캡션을 보여준 뒤 게시 승인을 받는다.
- 승인 전 미디어 업로드·외부 초안 저장·예약·발행을 하지 않는다.

### 네이버

- 검색자가 필요한 실제 지점·방문·준비 정보를 확인한 뒤 작성한다.
- Instagram 캡션을 그대로 복사하지 않는다.
- 상호명·주소·운영시간·수업시간·문의 경로를 각각 검증한다.

### 당근

- 지역 이웃에게 필요한 소식, 채팅, 쿠폰, 예약 기능을 구분한다.
- 쿠폰 또는 혜택은 대표 승인 없이 만들지 않는다.
- 채팅 시작·단골 추가를 실제 방문·등록·매출로 계산하지 않는다.

### Google 비즈니스 프로필

- 업데이트, 혜택, 이벤트의 필수 정보를 구분한다.
- 변경된 상세정보는 게시 후에도 수정한다.
- 날짜 범위가 없는 6개월 초과 게시물은 보관 처리될 수 있으므로 장기 안내는 게시물 하나에 의존하지 않는다.
- 프로필 행동을 체험 참석이나 등록으로 확정하지 않는다.

## 8. 한 콘텐츠의 채널별 변환

같은 주제를 여러 채널에 사용할 수 있지만 문구와 목적을 그대로 복제하지 않는다.

| 원천 주제 | Instagram | 네이버 | 당근 | Google |
|---|---|---|---|---|
| 유도 입문 상식 | 저장·질문 중심 캐러셀 | 검색형 상세 설명 | 근거리 방문 준비 안내 | 최신 공지와 확인 링크 |
| 코치 수련 기록 | 개인 관점·회고 | 확인된 맥락의 장문 | 지역성과 관련 있을 때만 | 원칙적으로 제외 |
| 수업 준비 | 시각 설명 | 지점별 준비물·절차 | 방문 전 핵심정보 | 최신 운영정보 연결 |
| 복귀 안내 | 개인 계정에 맞는 부담 완화 | 복귀 절차 상세 | 지역별 문의 경로 | 운영정보 최신화 |

각 채널의 공개 주체가 다르면 어조와 책임 범위도 다르게 설정한다.

## 9. 결정 기한과 WIP 제한

승인 처리 기한과 최대 승인 대기 수는 대표가 정해야 한다. 외부 벤치마크 숫자를 내부 기준으로 자동 적용하지 않는다.

대표 승인 전 기본 안전 규칙은 다음과 같다.

- 같은 날 새 Instagram 패키지 기본 1개
- 승인 대기본이 있으면 추가 제작보다 검수 우선
- 동일 주제·CTA·대상 중복 시 새 제작 보류
- 규정·행사·가격 정보가 바뀌면 게시 직전 재검증
- 폐기 또는 대체된 버전은 게시 후보에서 제외

## 10. 성과 인계

승인 큐의 목표는 게시물 수가 아니라 측정 가능한 사업 학습이다.

### 플랫폼 지표

- 조회
- 도달
- 좋아요
- 댓글
- 저장
- 공유
- 프로필 방문
- 신규 팔로우

### 사업 지표

- 유효 문의
- 체험 예약
- 실제 체험 참석
- 신규 등록
- 휴면회원 복귀 출석
- 기존회원 재등록
- 확인된 순수납

플랫폼 반응을 사업 지표로 대체하지 않는다. 분자·분모·관찰기간·원천이 없으면 전환율을 계산하지 않는다.

## 11. 실험

### EXP-313 — 승인 적체·최신성 통제 완전성

- 대상: 대표 승인 후 다음 10개 콘텐츠 결정
- 관찰기간: 승인된 운영기간
- 성공 조건:
  - 상태·채널·목적·CTA 기록률 100%
  - 승인 대기 항목의 다음 결정·담당·검토일 기록률 100%
  - 사실 주장 항목의 근거 확인일 기록률 100%
  - 대체된 이전 버전 게시 0건
  - 승인 전 업로드·예약·발행 0건
  - 동일 콘텐츠 중복 게시 0건
  - 공개 검증 없는 게시 완료 처리 0건
- 보류 조건:
  - 최대 승인 대기 수와 처리 기한 미승인
  - 게시 당일 확인이 필요한 정보의 기준 원천 미지정
  - 채널별 계정·프로필 소유권 미확인
- 중단 조건:
  - 미확정 가격·혜택·행사 공개
  - 공개 동의 없는 촬영물 사용
  - 승인본과 다른 미디어·캡션 게시
  - 개인정보 또는 민감 경영자료 공개
- 현재 적체시간·처리율·사업 개선폭: 데이터 미연결

## 15. Auditor 결론

- 개별 승인 대기본의 미디어·캡션을 공개하지 않았다.
- 제작 완료, 승인, 게시, 공개 검증, 성과를 분리했다.
- Instagram 코치 개인 계정과 브랜드 공식 발표 주체를 구분했다.
- 당근의 소식·채팅·쿠폰·예약 기능을 실제 방문·등록과 구분했다.
- Google 게시물의 최신성 특성을 장기 운영정보의 대체물로 과장하지 않았다.
- 외부 수치로 내부 승인 기한이나 최대 적체 수를 만들지 않았다.
- 확인되지 않은 회원수·전환율·매출은 데이터 미연결로 남겼다.


## 16. 외부 승인 도구와 대표 게시 승인 분리

대표의 게시 승인은 완성 미디어·순서·캡션·대상 계정·형식을 확인한 뒤 내려지는 사업상 승인이다. Metricool 등 외부 도구의 검토 상태는 이 승인을 기록하거나 보조할 수 있지만 대신하지 않는다.

- 대표의 정확한 완성본 승인이 없으면 외부 도구에 미디어를 업로드하거나 검토 요청·예약·발행하지 않는다.
- 외부 검토 요청과 검토자 이메일 발송도 외부 저장·알림이므로 별도 권한 없이 실행하지 않는다.
- Metricool의 승인 기능은 Advanced 또는 Custom 요금제 기능이므로 현재 계정에서 사용할 수 있다고 추정하지 않는다.
- 도구의 `Pending review`, `Approved`, `Rejected`는 내부 상태인 `승인 대기`, `승인 완료` 및 플랫폼 공개 상태와 분리한다.
- 어떤 검토자가 거절하면 해당 콘텐츠는 발행하지 않는다.
- 검토 뒤 콘텐츠가 수정되면 기존 승인은 초기화되는 것으로 처리하고, 정확한 새 버전으로 다시 승인받는다.
- 예약 시각까지 검토 대기인 게시물에 제공되는 3시간 유예는 도구 동작일 뿐 내부 승인 기한이나 발행 보장이 아니다.
- 승인 전 예약을 금지하므로 유예시간에 의존한 운영을 설계하지 않는다.

## 17. 승인·예약·공개 상태 대조표

| 단계 | 확인해야 할 증거 | 다음 단계로 자동 승격 금지 |
|---|---|---|
| 대표 승인 대기 | 정확한 버전·미디어·순서·캡션·계정·형식 | 검토 요청·외부 저장·예약 |
| 대표 승인 완료 | 승인 문구·대상 버전·승인 시점 | 업로드 성공·예약 완료 |
| 외부 도구 검토 | 검토 기준·검토자·승인 또는 거절 상태 | 대표 승인 완료 |
| 예약 완료 | 계정·시간대·예약시각·동일 파일 | 발행 완료 |
| 플랫폼 처리 | 플랫폼 수신·처리 상태 | 공개 완료 |
| 공개 검증 완료 | 실제 공개 URL·계정·장수·순서·캡션 | 성과 발생 |
| 성과 관찰 | 게시물별 조회·도달·저장·문의 등 | 등록·매출 |

Google 비즈니스 프로필의 `Live`, `Pending`, `Not approved`도 내부 승인 상태와 분리한다. `Pending`과 `Not approved`는 공개되지 않은 상태이며, 예약·전송 성공이나 플랫폼 수신을 `Live`로 계산하지 않는다.

## 18. 실험 추가

### EXP-431 — 승인 상태·수정·예약·공개 검증 판정 정확도

- 대상: 합성 콘텐츠 480개, 버전 1,920개, 검토 결정 2,400건, 예약·발행 사건 1,440건, 공개 검증 사건 960건
- 성공 조건: 아래 오류가 모두 0건
  - 대표 승인 대기를 외부 도구 검토 대기로 대체
  - 도구 승인을 대표 승인으로 계산
  - 거절이 하나라도 있는 콘텐츠를 게시 후보에 포함
  - 승인 후 수정된 버전을 재승인 없이 게시 후보로 유지
  - 3시간 유예를 발행 완료로 계산
  - Google의 `Pending` 또는 `Not approved`를 `Live`로 계산
  - 예약 완료를 발행 완료로 계산
  - 발행 성공 알림을 공개 URL 검증으로 계산
  - 승인 전 미디어·캡션을 외부 도구에 저장
  - 코치 개인 계정을 지점 공식 계정으로 분류
  - 조회·도달을 문의·등록·매출로 계산
- 중단 조건: 오류가 하나라도 발생하면 자동 검토 요청, 외부 저장, 예약, 발행 및 콘텐츠별 매출 보고를 중단
- 현재 승인 처리시간·공개 검증률·사업 전환율: 데이터 미연결
