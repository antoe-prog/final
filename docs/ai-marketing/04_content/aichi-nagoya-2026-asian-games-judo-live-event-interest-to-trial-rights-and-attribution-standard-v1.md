#### 진행 중 기록과 확정 결과의 분리 규칙

1. 공개 상태를 `경기 진행 기록 / 부분 결과 / 최종 결과`로 구분하고 확인 시각을 함께 표시한다.
2. `Results`에 일부 순위가 보이더라도 해당 체급의 1위·2위·공동 3위가 모두 표시됐는지 확인하기 전에는 해당 체급의 최종 결과로 부르지 않는다.
3. `체급별 최종 결과`와 `경기일 전체 최종 결과`를 분리한다. 1일 차 전체 확정은 당일 네 체급이 모두 체급별 최종 결과 조건을 충족한 뒤에만 사용한다.
4. 선수명·점수·승패를 장기 사용 마케팅 문구에 고정하지 않고 공식 페이지로 안내한다.
5. 메달·최종 순위는 IJF `Results` 또는 조직위원회 최종 결과가 게시된 뒤 두 번째 확인을 거쳐 사용한다.
6. 확인 전 결과 예상, 중계 화면 캡처, 선수 사진 재사용, 승패를 체험 혜택과 결합한 판촉 문구는 사용하지 않는다.
7. 이미 공개한 결과가 공식 정정되면 정정 시각·출처와 함께 공개 문구를 갱신한다.

### 네이버

- 대회 일정과 공식 링크를 명시한 검색형 해설 글을 준비한다.
- 실제 수업 시간·가격·무료 체험·혜택은 내부 확인 전 포함하지 않는다.
- 경기 결과가 들어가면 공식 출처의 확인 시각을 함께 기록한다.
- 중계 안내는 공식 권리 보유처가 확인된 경우에만 링크하고, IJF의 TV 정보 미등록 상태를 전체 중계 부재로 단정하지 않는다.

### 당근

- 지점 반경 이용자에게 “대회 관전 뒤 생긴 입문 질문”을 받는 지역형 게시안을 준비한다.
- 체험 제공 조건과 위치·시간표가 확정되기 전에는 모집·할인 문구를 게시하지 않는다.
- 유료 광고는 대표 승인 전 집행하지 않는다.

### CRM

- 기존회원에게 대회 응원·관전 메시지를 보내는 것과 휴면 복귀 제안을 분리한다.
- 수신 동의, 대상 기준, 문구, 발송 시각을 대표가 승인하기 전 실제 발송하지 않는다.
- 개인별 선수 선호, 건강, 출석, 결제정보는 공개 문서에 기록하지 않는다.

## EXP-462 — 대회 관심의 교육형 콘텐츠→체험 전환 검증

### 비교안

- A안: 일정·관전 포인트 중심 교육형 콘텐츠
- B안: 경기 후 입문 질문 중심 교육형 콘텐츠
- 두 안 모두 동일한 채널, 기간, 행동 유도, 유입코드 체계를 사용한다.

### 최소 이벤트

- 콘텐츠 식별자
- 채널과 지점
- 노출·도달·저장·공유
- 프로필 방문 또는 링크 클릭
- 문의
- 체험 예약
- 실제 방문
- 신규 등록
- 휴면 복귀
- 만료예정 재등록
- 수납·환불·순수납

현재 내부 문의·체험·복귀·재등록·수납 데이터는 모두 **데이터 미연결**이다. 공개 저장소에는 집계 정의만 기록하고 개인 식별정보와 원장은 올리지 않는다.

### 성공 기준

- 일정·결과 출처 표시율 100%
- 진행 중 경기 기록·부분 결과·체급별 최종 결과를 상위 범위의 최종 결과로 확대 표시한 사례 0건
- 권리 미확인 영상·이미지·로고 사용 0건
- 공식 후원·제휴·대표팀 관계 오인 0건
- 승인 없는 게시·메시지·광고·계정 변경 0건
- 문의 이후 필수 이벤트 연결률 95% 이상
- 중복 전환 귀속 0건

콘텐츠별 저장률·문의율·방문율·등록률 목표치는 기준선과 최소 표본이 연결된 후 확정한다.

### 중단 기준

- 공식 일정·결과와 공개 문구 불일치
- 권리 또는 초상 사용 근거 미확인
- 지점·콘텐츠 식별자 누락
- 필수 이벤트 연결률 95% 미만
- 실제 제공하지 않는 수업·시간표·가격·혜택 암시
- 민감정보 또는 승인 대기 Instagram 산출물의 공개 저장소 노출

## 대표 승인·입력 필요

- 대회 연계 콘텐츠 추진 여부와 사용할 채널
- 실제 적용 지점
- 자체 촬영 가능 범위와 공개 사용 동의 기준
- 실제 시간표·정원·가격·체험 조건
- 유입코드 기록 담당자
- 문의·예약·방문·등록·복귀·재등록·수납 원장 연결
- 현재 Instagram 승인 대기 5건의 처리 결정

## Auditor 체크

- 대회 개최를 내부 전환 성과로 과장하지 않았는가
- 선수 실적·출전·결과를 공식 확인 없이 작성하지 않았는가
- `Contests`의 진행 중 기록과 `Results`의 확정 결과를 구분했는가
- 중계 화면·로고·선수 사진의 권리를 확인했는가
- 코치 개인 계정과 브랜드 공식 발표를 구분했는가
- 행동 유도와 전환 귀속 기준이 하나로 연결되는가
- 비용·광고·고객 발송·계정 변경을 승인 없이 실행하지 않았는가
