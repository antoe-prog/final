# 아이치·나고야 2026 아시안게임 유도 관심→체험 전환·권리·귀속 기준 v1

- 실험 ID: EXP-462
- 작성일: 2026-09-30
- 대상: 파이널유도멀티짐 공개 채널·CRM 운영 검토
- 상태: 대표 승인 전 설계안
- 목적: 대회 기간의 유도 관심을 교육형 콘텐츠와 실제 체험 문의로 연결하되, 중계권·선수 초상·공식 후원 오인·확인 전 결과 게시 위험을 통제한다.

## 확인된 외부 변화

국제유도연맹(IJF) 공식 대회 페이지 기준, 제20회 아이치·나고야 아시안게임 유도 개인전은 2026-09-30부터 2026-10-02까지 진행되며 혼성단체전은 2026-10-03에 열린다. 개인전 페이지에는 32개국 199명 참가로 표시된다.

이 일정은 유도 관심이 높아질 수 있는 계기지만 파이널유도멀티짐의 문의·체험·등록 증가를 증명하지 않는다. 실제 전환은 채널별 유입코드와 문의·예약·방문·등록 사건을 연결해 확인한다.

### 2026-09-30 경기일 운영 확인

2026-09-30 10:19 KST에 IJF 개인전 페이지를 다시 확인했다.

- DAY 1 예선 시작: 11:00
- DAY 1 결승 블록 시작: 17:00
- DAY 1 체급: 남자 -60kg·-66kg, 여자 -48kg·-52kg
- IJF 페이지의 TV Info: `This competition does not have any TV info yet`

마지막 항목은 IJF 대회 페이지에 TV 정보가 아직 등록되지 않았다는 뜻이다. 국내외 모든 중계가 없다는 뜻으로 확대하지 않는다. 공개 관전 안내를 만들기 전에는 공식 조직위원회·권리 보유 방송사·IJF 페이지를 다시 확인하고, 확인 시각과 링크를 함께 기록한다.

## 오늘의 우선 판단

1. 실시간 결과·선수 중심 속보 경쟁보다 입문자가 경기를 이해하도록 돕는 교육형 해설을 우선한다.
2. 중계 화면, 방송사 캡처, 대회 로고, 선수 사진을 권리 확인 없이 재사용하지 않는다.
3. 경기 결과와 출전 여부는 IJF·대회 조직위원회 등 공식 출처 확인 후 날짜·출처와 함께 기록한다.
4. 공개 콘텐츠의 행동 유도는 한 번에 하나만 사용하고, 문의 이후 실제 방문·등록과 분리 측정한다.
5. @ant.toe.98은 코치 개인 계정이므로 본관 또는 전체 브랜드의 공식 발표 주체처럼 표현하지 않는다.

## 채널별 실행안

### Instagram

- 현재 승인 대기 패키지 5건·40장 해소 전 새 승인 패키지를 추가하지 않는다.
- 향후 제작 시 경기 영상 대신 자체 제작 도식·도복·매트·코치 단독 손발 촬영으로 기술 관전 포인트를 설명한다.
- 허용 주제 예시: 점수 용어 확인법, 초보자가 볼 세 가지 장면, 경기 후 궁금한 기술을 질문하는 법.
- 금지: 권리 미확인 중계 캡처, 공식 계정처럼 보이는 로고 조합, 확인 전 결과, 선수·대표팀과의 관계 암시.
- 승인된 완성본만 업로드·예약·발행한다.

### 네이버

- 대회 일정과 공식 링크를 명시한 검색형 해설 글을 준비한다.
- 실제 수업 시간·가격·무료 체험·혜택은 내부 확인 전 포함하지 않는다.
- 경기 결과가 들어가면 공식 출처의 확인 시각을 함께 기록한다.
- 중계 안내는 공식 권리 보유처가 확인된 경우에만 링크하고, IJF의 TV 정보 미등록 상태를 전체 중계 부재로 단정하지 않는다.

### 당근

- 지점 반경 이용자에게 “대회 관전 뒤 생긴 입문 질문”을 받는 지역형 게시안을 준비한다.
- 체험 제공 조건과 위치·시간표가 확정되기 전에는 모집·할인 문구를 게시하지 않는다.
- 유료 광고는 대표 승인 전 집행하지 않는다.

### CRM

- 기존회원에게 대회 응원·관전 메시지를 보내는 것과 휴면 복귀 제안을 분리한다.
- 수신 동의, 대상 기준, 문구, 발송 시각을 대표가 승인하기 전 실제 발송하지 않는다.
- 개인별 선수 선호, 건강, 출석, 결제정보는 공개 문서에 기록하지 않는다.

## EXP-462 — 대회 관심의 교육형 콘텐츠→체험 전환 검증

### 비교안

- A안: 일정·관전 포인트 중심 교육형 콘텐츠
- B안: 경기 후 입문 질문 중심 교육형 콘텐츠
- 두 안 모두 동일한 채널, 기간, 행동 유도, 유입코드 체계를 사용한다.

### 최소 이벤트

- 콘텐츠 식별자
- 채널과 지점
- 노출·도달·저장·공유
- 프로필 방문 또는 링크 클릭
- 문의
- 체험 예약
- 실제 방문
- 신규 등록
- 휴면 복귀
- 만료예정 재등록
- 수납·환불·순수납

현재 내부 문의·체험·복귀·재등록·수납 데이터는 모두 **데이터 미연결**이다. 공개 저장소에는 집계 정의만 기록하고 개인 식별정보와 원장은 올리지 않는다.

### 성공 기준

- 일정·결과 출처 표시율 100%
- 권리 미확인 영상·이미지·로고 사용 0건
- 공식 후원·제휴·대표팀 관계 오인 0건
- 승인 없는 게시·메시지·광고·계정 변경 0건
- 문의 이후 필수 이벤트 연결률 95% 이상
- 중복 전환 귀속 0건

콘텐츠별 저장률·문의율·방문율·등록률 목표치는 기준선과 최소 표본이 연결된 후 확정한다.

### 중단 기준

- 공식 일정·결과와 공개 문구 불일치
- 권리 또는 초상 사용 근거 미확인
- 지점·콘텐츠 식별자 누락
- 필수 이벤트 연결률 95% 미만
- 실제 제공하지 않는 수업·시간표·가격·혜택 암시
- 민감정보 또는 승인 대기 Instagram 산출물의 공개 저장소 노출

## 대표 승인·입력 필요

- 대회 연계 콘텐츠 추진 여부와 사용할 채널
- 실제 적용 지점
- 자체 촬영 가능 범위와 공개 사용 동의 기준
- 실제 시간표·정원·가격·체험 조건
- 유입코드 기록 담당자
- 문의·예약·방문·등록·복귀·재등록·수납 원장 연결
- 현재 Instagram 승인 대기 5건의 처리 결정

## Auditor 체크

- 대회 개최를 내부 전환 성과로 과장하지 않았는가
- 선수 실적·출전·결과를 공식 확인 없이 작성하지 않았는가
- 중계 화면·로고·선수 사진의 권리를 확인했는가
- 코치 개인 계정과 브랜드 공식 발표를 구분했는가
- 행동 유도와 전환 귀속 기준이 하나로 연결되는가
- 비용·광고·고객 발송·계정 변경을 승인 없이 실행하지 않았는가
