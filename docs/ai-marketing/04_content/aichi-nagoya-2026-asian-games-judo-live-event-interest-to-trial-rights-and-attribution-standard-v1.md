- 개인별 선수 선호, 건강, 출석, 결제정보는 공개 문서에 기록하지 않는다.

## EXP-462 — 대회 관심의 교육형 콘텐츠→체험 전환 검증

### 비교안

- A안: 일정·관전 포인트 중심 교육형 콘텐츠
- B안: 경기 후 입문 질문 중심 교육형 콘텐츠
- 두 안 모두 동일한 채널, 기간, 행동 유도, 유입코드 체계를 사용한다.

### 최소 이벤트

- 콘텐츠 식별자
- 채널과 지점
- 노출·도달·저장·공유
- 프로필 방문 또는 링크 클릭
- 문의
- 체험 예약
- 실제 방문
- 신규 등록
- 휴면 복귀
- 만료예정 재등록
- 수납·환불·순수납

현재 내부 문의·체험·복귀·재등록·수납 데이터는 모두 **데이터 미연결**이다. 공개 저장소에는 집계 정의만 기록하고 개인 식별정보와 원장은 올리지 않는다.

### 성공 기준

- 일정·결과 출처 표시율 100%
- 진행 중 경기 기록·부분 결과·체급별 최종 결과를 상위 범위의 최종 결과로 확대 표시한 사례 0건
- 권리 미확인 영상·이미지·로고 사용 0건
- 공식 후원·제휴·대표팀 관계 오인 0건
- 승인 없는 게시·메시지·광고·계정 변경 0건
- 문의 이후 필수 이벤트 연결률 95% 이상
- 중복 전환 귀속 0건

콘텐츠별 저장률·문의율·방문율·등록률 목표치는 기준선과 최소 표본이 연결된 후 확정한다.

### 중단 기준

- 공식 일정·결과와 공개 문구 불일치
- 권리 또는 초상 사용 근거 미확인
- 지점·콘텐츠 식별자 누락
- 필수 이벤트 연결률 95% 미만
- 실제 제공하지 않는 수업·시간표·가격·혜택 암시
- 민감정보 또는 승인 대기 Instagram 산출물의 공개 저장소 노출

## 대표 승인·입력 필요

- 대회 연계 콘텐츠 추진 여부와 사용할 채널
- 실제 적용 지점
- 자체 촬영 가능 범위와 공개 사용 동의 기준
- 실제 시간표·정원·가격·체험 조건
- 유입코드 기록 담당자
- 문의·예약·방문·등록·복귀·재등록·수납 원장 연결
- 현재 Instagram 승인 대기 5건의 처리 결정

## Auditor 체크

- 대회 개최를 내부 전환 성과로 과장하지 않았는가
- 선수 실적·출전·결과를 공식 확인 없이 작성하지 않았는가
- `Contests`의 진행 중 기록과 `Results`의 확정 결과를 구분했는가
- 중계 화면·로고·선수 사진의 권리를 확인했는가
- 코치 개인 계정과 브랜드 공식 발표를 구분했는가
- 행동 유도와 전환 귀속 기준이 하나로 연결되는가
- 비용·광고·고객 발송·계정 변경을 승인 없이 실행하지 않았는가
