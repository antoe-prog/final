# 래스터 캐러셀 기술 프리플라이트 기준 v1

- 문서 상태: 공개 운영 기준
- 적용 대상: Instagram·네이버·당근용 PNG/JPEG 캐러셀
- 목적: 승인 전에 파일 규격, 대비, 여백, 문구, 순서와 승인 패키지 일치를 검증한다.
- 적용 제외: 개별 승인 대기 이미지·캡션·대체 텍스트, 회원 식별자료, 비공개 성과자료

## 1. 완료 상태를 분리한다

| 상태 | 의미 |
|---|---|
| `MEDIA_RENDERED` | 이미지 파일이 생성됨 |
| `MEDIA_INTEGRITY_VERIFIED` | 장수·규격·모드·해시를 확인함 |
| `VISUAL_PREFLIGHT_PASSED` | 대비·잘림·계층·문구를 검수함 |
| `PACKAGE_LOCKED` | 이미지·순서·캡션·대체 텍스트·해시를 한 버전으로 고정함 |
| `READY_FOR_APPROVAL` | 완성본을 대표가 검토할 수 있음 |
| `APPROVED` | 특정 버전의 명시적 게시 승인이 있음 |
| `PUBLISHED_VERIFIED` | 공개 게시와 최종 일치를 확인함 |

렌더링 완료를 승인 완료나 게시 완료로 계산하지 않는다.

## 2. 파일 무결성 검사

각 장에서 다음을 기록한다.

- 파일명과 업로드 순서
- 가로·세로 픽셀
- RGB/RGBA 등 색상 모드
- 투명도 유무
- 파일 크기
- SHA-256
- 파일 열기 성공 여부

캐러셀 장수, 검토 PDF 페이지 수, 원본 ZIP 파일 수가 서로 다르면 패키지를 잠그지 않는다.

## 3. 대비 검사

WCAG 2.2 수치는 정적 소셜 이미지의 내부 가드레일로만 사용한다.

- 일반 텍스트 참고 기준: `4.5:1`
- 큰 텍스트 참고 기준: `3:1`
- 계산값을 반올림하여 통과시키지 않는다.
- 최종 합성 이미지에서 전경과 실제 인접 배경을 측정한다.
- 사진·질감·그림 위 글자는 단일 평균 배경색만으로 통과시키지 않는다.
- 작은 계정명·출처·장 번호도 별도 확인한다.
- 색상만으로 강조하지 않고 굵기, 크기, 위치, 선 또는 아이콘을 함께 사용한다.

자동 표본 추출은 후보 색상 쌍을 찾는 보조 수단이다. 모든 안티앨리어싱 픽셀이나 기기 표시 환경을 대표하지 않으므로 시각 검수를 함께 기록한다.

## 4. 안전 여백과 잘림

- 제목·본문·계정 표기·장 번호가 파일 가장자리에 닿지 않게 한다.
- 텍스트 경계 상자를 자동 계산할 수 있으면 픽셀 여백을 기록한다.
- 일러스트가 문자 탐지에 섞이면 자동 결과를 확정값으로 사용하지 않는다.
- 접촉 시트에서 8장 전체 흐름과 가장자리 접촉을 확인한다.
- 검토 PDF에서 페이지별 잘림을 다시 확인한다.
- 플랫폼 업로드 후 미리보기 크롭이 있다면 승인 후 별도 확인한다.

## 5. OCR과 한글 검수

- OCR 언어 모델이 없거나 대상 언어를 지원하지 않으면 `OCR_UNAVAILABLE`로 기록한다.
- 영어 OCR만으로 한글 무오류를 주장하지 않는다.
- OCR 결과는 원문 대조와 확대 시각 검수를 대체하지 않는다.
- 음절 누락, 받침 오류, 띄어쓰기, 숫자, 계정명, 장 번호를 우선 확인한다.
- 최종 이미지가 바뀌면 이전 OCR·시각 검수 결과를 재사용하지 않는다.

## 6. 승인 패키지 잠금

패키지에는 다음을 포함한다.

1. 고유 작업 ID와 버전
2. 대상 계정과 게시 형식
3. 최종 미디어와 업로드 순서
4. 미디어별 SHA-256
5. 최종 캡션과 해시태그
6. 장별 대체 텍스트
7. AI 생성 또는 편집 상태
8. 기술 프리플라이트 결과
9. 현재 승인·업로드·예약·게시 상태

승인 이후 미디어, 문구, 순서, 캡션 또는 대상 계정이 실질적으로 바뀌면 새 버전으로 다시 잠그고 승인받는다.

## 7. 게시 전·후 통제

### 승인 전

- Instagram·연결 게시 도구에 미디어를 업로드하지 않는다.
- 외부 초안, 예약, 발행을 만들지 않는다.
- 승인 대기 패키지를 공개 저장소에 올리지 않는다.

### 승인 후

- 해시와 순서를 대조한 뒤 한 번만 업로드한다.
- AI 생성 콘텐츠 표시와 장별 대체 텍스트 경로를 확인한다.
- 게시 실패 재시도 전 공개 여부를 확인한다.
- 공개 URL에서 계정, 장수, 순서, 캡션을 재검증한다.
- 입력 기능이나 공개 결과를 확인할 수 없는 항목은 `미확인`으로 남긴다.

## 8. KPI 분리

기술 프리플라이트는 운영 품질 지표다. 다음 사업 KPI와 분리한다.

- 조회·도달
- 저장·공유·댓글
- 프로필 방문·문의
- 체험 예약·실제 참여
- 신규 등록·휴면 복귀·재등록
- 실수납·환불·차지백 반영 순수납

연결된 분자·분모·기간·원천이 없으면 비율을 계산하지 않는다.

## 9. EXP-446 — 프리플라이트 판정 정확도

합성 캐러셀 20건, 이미지 160장, 오류 사건 240건으로 검증한다.

성공 기준은 다음 오류가 모두 0건인 것이다.

- 장수·PDF 페이지·ZIP 파일 수 불일치 통과
- 서로 다른 규격·색상 모드·투명도 누락
- 변경된 이미지의 이전 SHA 재사용
- 4.499:1을 4.5:1로 반올림해 통과
- 사진 평균색만으로 모든 글자의 대비 통과
- 일러스트 픽셀을 텍스트 여백으로 확정
- 한국어 OCR 미지원 상태에서 자동 철자 검수 완료 보고
- 접촉 시트만 보고 개별 원본 잘림 검수 생략
- 렌더링 완료를 승인·게시 완료로 계산
- 승인 대기 패키지를 공개 저장소에 노출
- 기술 검수 완료를 문의·체험·매출로 귀속

하나라도 발생하면 `READY_FOR_APPROVAL` 판정을 중단한다.

## 11. Auditor 공개 안전 기준

- 승인 대기 개별 이미지·캡션·대체 텍스트는 공개 저장소에서 제외한다.
- 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제자료를 포함하지 않는다.
- 비밀키·토큰·로그인 정보와 미확정 행사·가격·혜택을 포함하지 않는다.
- 내부 회원수·전환율·매출이 연결되지 않으면 `데이터 미연결`로 기록한다.
