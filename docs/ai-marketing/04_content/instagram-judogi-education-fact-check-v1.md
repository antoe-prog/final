# Instagram 유도복 교육 콘텐츠 사실검증 기준 v1

- 기준일: 2026-09-13 (KST)
- 적용 범위: 코치 개인 계정의 유도복 상식 콘텐츠 및 네이버·당근 확장본
- 공개 범위: 재사용 가능한 근거·표현·검수 기준만 포함
- 제외 범위: 승인 대기 중인 개별 게시물의 이미지, 최종 캡션, 미확정 행사 정보, 회원 정보, 내부 예산·매출·전환 자료

## 목적

유도복을 소재로 입문자와 비수련자의 호기심을 만들되, 특정 제조사의 구조를 모든 유도복의 공통 규격으로 일반화하거나 최신 경기 규정을 확인하지 않은 채 숫자를 제시하는 오류를 막는다. 콘텐츠 성과는 도달·반응과 실제 문의·체험·등록을 분리해 측정한다.

| 두꺼운 도복이 항상 더 좋다 | 사용 금지 | 용도, 규정, 착용감과 제품 설계가 다르므로 단순 우열로 일반화할 근거가 없다 |
| 최신 IJF 경기용 도복의 정확한 숫자 규격 | 게시 직전 재검증 전 사용 금지 | 규정은 갱신될 수 있으므로 게시 시점의 IJF 공식 SOR 및 Judogi Rules 원문을 다시 확인해야 한다 |

## 표현 가드레일

### 사용할 수 있는 표현

- “유도는 상대의 도복을 잡고 기술을 거는 종목입니다.”
- “잡고 당기는 상황을 고려해 원단과 봉제가 설계됩니다.”
- “쌀알처럼 보이는 사시코 짜임을 사용하는 도복이 있습니다.”
- “상의 위아래의 짜임이 다른 제품도 있습니다.”
- “제품마다 소재, 구조와 원단 중량이 다릅니다.”
- “경기에서는 해당 대회의 도복 규정을 확인합니다.”

### 사용하지 않는 표현

- “모든 유도복은 같은 구조다.”
- “두꺼울수록 안전하고 좋은 도복이다.”
- “사시코는 부상을 방지한다.”
- “항균·탈취·충격 흡수 효과가 입증됐다.”
- “이 숫자가 현재 모든 IJF 경기의 절대 규격이다.”
- “공식 IJF 인증 제품”이라는 문구나 라벨을 권한·제품 확인 없이 사용
- 코치가 실제로 소유하거나 매일 입는 도복이라는 근거 없는 1인칭 표현
- 특정 브랜드 추천, 가격, 구매 혜택 또는 성능 순위

제조사 페이지의 항균·탈취·건조·충격 흡수 주장은 제조사 설명이며 이번 교육 콘텐츠의 핵심에 필요하지 않으므로 제외한다.

## 이미지 제작 검수 기준

1. 원단 확대 이미지는 사시코의 쌀알형 조직을 참고하되 실제 제품 사진을 복제하지 않고 자체 일러스트로 제작한다.
2. 상의 위아래 짜임 비교에는 “제품에 따라 다름” 또는 “구성 예시”를 표시한다.
3. 그립 장면은 손가락 수, 관절 방향, 소매·깃의 위치가 자연스러운지 확인한다.
4. 최신 공식 원문에서 확인하지 않은 두께·중량·소매 길이 숫자를 삽입하지 않는다.
5. IJF 로고, 인증 라벨, 제조사 상표, 제품 사진을 무단 사용하지 않는다.
6. 실제 코치·회원·시설 촬영으로 오인되지 않도록 일러스트임을 유지한다.
7. 제목, 핵심 문장, 설명, 보조 표기의 크기와 굵기를 구분하고 한 장당 색상 강조는 한 곳만 둔다.
8. 게시 전 한글 철자, 띄어쓰기, 페이지 순서, 계정 표기, 잘림을 장별 전체 화면과 확대 화면에서 모두 검수한다.

## 채널별 적용

### Instagram

- 역할: 원단과 봉제의 시각적 호기심을 만드는 7~10장 교육형 캐러셀
- CTA: 도복에 관한 질문 1개
- 금지: 승인 전 미디어 업로드·외부 초안 저장·예약·발행
- 측정: 도달, 조회한 계정, 저장, 공유, 댓글 질문, 프로필 방문을 각각 기록

### 네이버

- 역할: 공식·제조사 근거를 링크한 확장 FAQ
- 구성: 잡기와 규격 → 사시코와 원단 구조 → 제품 차이 → 초보자의 확인 질문
- 금지: 제품 판매글처럼 보이는 브랜드 순위와 확인되지 않은 체험 정책

### 당근

- 역할: 지역 회원 모집 공지보다는 “도복에서 볼 수 있는 유도 상식”의 짧은 생활체육 설명
- 조건: 실제 지점·시간표·체험 가능 여부가 확인될 때만 지역 방문 CTA 추가
- 금지: 여석, 마감, 무료 체험, 할인 혜택을 근거 없이 제시

## 퍼널과 CRM 연결

- 신규: 콘텐츠 질문 → 프로필 방문 → 유효 문의 → 체험 예약 → 실방문 → 신규 등록
- 체험 후 미등록: 연락 동의와 후속 연락 기준이 확인된 경우에만 별도 관리
- 휴면: 게시물 관심을 복귀 의향으로 간주하지 않는다
- 기존: 댓글·저장을 재등록 성과로 간주하지 않고 실제 활성·재등록 데이터와 분리한다
- 매출: 귀속 기간, 결제 상태, 취소·환불, 콘텐츠 유입 근거가 연결되기 전에는 데이터 미연결

## 실험 정의

### EXP-280 Judogi Curiosity-to-Question Baseline

- 가설: 제품 추천이나 기술 시범 없이도 “왜 두꺼운가”라는 물성 질문이 유도 입문자의 유효 질문을 만들 수 있다
- 형식: 근거가 확인된 설명 1개 + 구조 비교 1개 + 질문 CTA 1개
- 측정 시점: 게시 후 24시간, 72시간
- 콘텐츠 지표: 도달, 조회한 계정, 저장, 공유, 댓글 중 유도복 관련 질문, 프로필 방문
- 사업 지표: 신규·휴면복귀·기존회원 문의, 체험 예약, 실방문, 14일 등록, 30일 활성, 재등록
- 성공 기준: 사실 오류·권리 문제 0건, 동일 정의의 24시간·72시간 지표 확보, 유도복 관련 질문의 존재 여부 확인
- 보류 기준: 분모 미제공, 표본 부족, 댓글 작성자의 의도 구분 불가
- 중단 기준: 규정·원단 구조의 사실 오류, 제조사별 차이의 과도한 일반화, 상표·사진 권리 문제, 승인본 불일치
- 최소 개선폭과 기준선: 데이터 미연결

## 데이터 기록 규칙

- 조회수와 조회한 계정은 서로 다른 단위로 기록한다.
- 저장률 = 저장 ÷ 도달 × 100. 도달이 0이거나 미제공이면 계산 불가.
- 공유율 = 공유 ÷ 도달 × 100. 도달이 0이거나 미제공이면 계산 불가.
- 프로필 방문률 = 프로필 방문 ÷ 도달 × 100. 도달이 0이거나 미제공이면 계산 불가.
- 댓글 수와 “유도복 관련 질문” 수를 분리한다.
- 문의·예약·실방문·등록·활성·재등록은 내부 비식별 집계가 연결되기 전까지 데이터 미연결로 둔다.

## 감사 결론

IJF 자료는 경기 공정성과 도복 통제의 근거로 사용하고, KuSakura 자료는 원단·봉제·제품 차이의 제조사 사례로만 사용한다. 제조사 설명을 독립적 의학·안전 효능으로 확대하지 않는다. 개별 승인 대기 콘텐츠의 이미지와 최종 캡션은 이 공개 문서에 포함하지 않는다.
