# 회원·미성년자 사진·영상 동의·게시·재사용·철회·삭제·전환 귀속 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 작성 기준일: 2026-09-19
- 적용 대상: 파이널유도멀티짐의 Instagram·네이버·Google·당근 등 공개 콘텐츠
- 목적: 사람을 식별할 수 있는 사진·영상·음성·이름을 안전하게 관리하면서 콘텐츠 성과를 실제 문의·체험·등록·실수납과 분리한다.
- 제외: 실제 회원 명단, 보호자 연락처, 원본 동의서, 개인별 촬영물, 출석·건강·결제·민원 기록

> 이 문서는 공개 가능한 운영 설계다. 개별 촬영물의 적법성이나 실제 계약을 대신하지 않는다. 적용 전 실제 처리 목적, 대상 연령, 동의 문구, 보유기간, 위탁·국외 이전 여부를 확인한다.

## 1. 오늘의 우선순위

콘텐츠 제작량보다 먼저 `촬영 가능 → 공개 가능 → 채널별 게시 가능 → 재사용 가능 → 철회 요청 → 공개 제거 확인`을 분리한다.

다음은 동의로 보지 않는다.

- 수업에 참석했다.
- 도복을 입고 촬영 구역에 있었다.
- 카메라를 피하지 않았다.
- 단체사진에 섰다.
- 보호자 또는 회원이 답장을 하지 않았다.
- 과거에 다른 게시물 공개에 동의했다.
- 내부 보관용 촬영에 동의했다.

## 2. 운영 원칙

1. **목적 한정**: 촬영, 내부 보관, 유기적 게시, 유료 광고, 다른 채널 재사용을 한 상태로 합치지 않는다.
2. **사람별 확인**: 단체사진도 식별 가능한 사람마다 근거를 확인한다.
3. **미성년자 강화**: 보호자 권한을 확인하고, 이해 가능한 방식으로 당사자의 의사도 확인한다. 법적 판단이 필요한 경우 별도 검토한다.
4. **최소 공개**: 얼굴·이름·음성·소속·시간·장소를 모두 공개할 필요가 없으면 줄인다.
5. **거절 불이익 금지**: 촬영·게시를 거절해도 수업·평가·회원권 이용에 불이익을 주지 않는다.
6. **철회 가능성 반영**: 철회 요청 접수와 실제 제거 완료를 구분하고, 재게시·광고 집행을 즉시 잠근다.
7. **완전 삭제 과장 금지**: 원 게시물 제거와 검색 캐시·공유본·제3자 재게시물 제거는 다르다.
8. **성과 분리**: 게시·조회·클릭을 문의·체험·등록·수납으로 승격하지 않는다.

## 3. 상태 모델

| 상태 | 의미 | 완료 증거 | 다음 허용 작업 |
|---|---|---|---|
| `CONCEPT_PLANNED` | 소재와 목적만 정함 | 작업 ID·목적·채널 | 촬영 대상 검토 |
| `SUBJECT_SCOPE_REVIEWED` | 식별 가능한 대상과 위험을 검토 | 대상 유형·미성년 여부·노출 항목 | 동의 요청 설계 |
| `CONSENT_REQUESTED` | 동의를 요청함 | 요청 시각·버전 | 답변 대기 |
| `CONSENT_DECLINED` | 공개 또는 촬영을 거절함 | 거절 범위 | 비식별 대체안만 사용 |
| `CONSENT_PARTIAL` | 일부 목적·채널만 허용 | 허용·금지 범위 | 범위 내 제작 |
| `CONSENT_VERIFIED` | 필요한 범위의 동의 근거를 확인 | 버전·권한·채널·기간 | 촬영 또는 편집 |
| `CAPTURED` | 원본 촬영 완료 | 원본 ID·촬영일 | 비공개 편집 |
| `EDITED` | 공개 후보 편집 완료 | 후보 파일 해시 | 사람별 최종 범위 검수 |
| `CREATIVE_APPROVED` | 미디어·문구·순서 승인 | 승인자·버전·시각 | 승인된 채널 게시 |
| `UPLOADED_DRAFT` | 채널 비공개 초안 업로드 | 채널 초안 ID | 게시 승인 확인 |
| `SCHEDULED` | 게시 예약 완료 | 채널·예약 시각·게시물 ID | 예약 유지 또는 취소 |
| `PUBLISHED` | 공개 게시 확인 | 공개 URL·검증 시각 | 성과 관찰 |
| `REUSE_REQUESTED` | 새 채널·광고·편집 재사용 검토 | 새 목적·채널 | 범위 확인 |
| `REUSE_APPROVED` | 재사용 범위 확인 | 근거 버전 | 해당 범위 재사용 |
| `REVOCATION_REQUESTED` | 철회 또는 공개 중단 요청 접수 | 요청 시각·범위 | 신규 사용 잠금 |
| `REMOVAL_PENDING` | 원 게시물 제거 진행 중 | 대상 URL·담당자 | 제거 확인 |
| `REMOVED_FROM_OWNED_CHANNEL` | 운영 계정의 공개본 제거 확인 | 제거 시각·검증 화면 | 캐시·공유본 검토 |
| `CACHE_OR_REPOST_PENDING` | 캐시·제3자 공유본이 남을 수 있음 | 대상 목록 | 가능한 신고·요청 |
| `REMOVAL_VERIFIED` | 정의된 범위의 제거를 검증 | 채널별 검증 기록 | 보관·삭제 결정 |
| `ARCHIVED_RESTRICTED` | 증빙 목적 제한 보관 | 접근권한·보유기한 | 기한 후 삭제 검토 |
| `SOURCE_DELETED` | 정해진 원본 삭제 완료 | 삭제 기록 | 종료 |
| `INCIDENT_ESCALATED` | 무단 공개·잘못된 대상·민감정보 사고 | 사건 ID·책임자 | 법무·개인정보·안전 대응 |

`CONSENT_REQUESTED`는 `CONSENT_VERIFIED`가 아니다. `CREATIVE_APPROVED`는 게시 완료가 아니다. `REMOVED_FROM_OWNED_CHANNEL`은 인터넷 전체에서의 삭제를 의미하지 않는다.

## 4. 동의 범위 원장

공개 저장소가 아닌 제한된 시스템에서 촬영물 단위로 다음 항목을 관리한다.

| 필드 | 설명 |
|---|---|
| `asset_id` | 촬영물·편집본의 내부 비식별 ID |
| `subject_id` | 인물별 비식별 ID |
| `age_role` | 성인·미성년자·코치·직원·방문자 등 |
| `guardian_authority_status` | 보호자 권한 확인 상태 |
| `capture_allowed` | 촬영 가능 여부 |
| `internal_storage_allowed` | 내부 보관 가능 여부 |
| `organic_publish_channels` | Instagram·네이버·Google·당근 등 허용 채널 |
| `paid_media_allowed` | 유료 광고 사용 가능 여부 |
| `face_name_voice_scope` | 얼굴·이름·음성·도복 표식 노출 범위 |
| `editing_scope` | 크롭·자막·합성·AI 편집 등 허용 범위 |
| `reuse_scope` | 재게시·리컷·보도자료·인쇄물 허용 범위 |
| `valid_from` / `valid_until` | 허용 기간 |
| `consent_version` | 확인한 문구 버전 |
| `revocation_route` | 철회 접수 경로 |
| `evidence_location` | 제한 저장된 증빙 위치; 원문은 공개 저장소 금지 |
| `reviewer` / `reviewed_at` | 최종 검수 책임자와 시각 |

## 5. 게시 전 게이트

다음 중 하나라도 실패하면 게시·예약·재사용을 중단한다.

- 식별 가능한 모든 인물이 원장과 연결되는가?
- 미성년자의 보호자 권한 확인이 완료됐는가?
- 게시 채널과 계정 주체가 허용 범위에 포함되는가?
- 코치 개인 계정과 브랜드 공식 계정을 혼동하지 않는가?
- 얼굴·이름·음성·도복 소속 표식이 허용 범위를 넘지 않는가?
- 수업 시간·지점·학교·거주지 등 조합으로 미성년자를 과도하게 식별할 수 없는가?
- 건강·부상·진단·결제·민원 등 민감한 맥락이 드러나지 않는가?
- 후기·변화·실적이 실제 당사자 진술과 확인 자료에 근거하는가?
- 동의하지 않은 주변 인물과 화면·거울·유리 반사 속 인물이 제거됐는가?
- 대체 텍스트가 실제 이미지와 일치하며 불필요한 개인정보를 추가하지 않는가?
- 승인된 미디어 해시·순서·캡션과 업로드 대상이 같은가?

## 6. 미성년자·단체 촬영 추가 통제

### 미성년자

- 보호자 권한이 불명확하면 공개하지 않는다.
- 이름, 학교, 수업시간, 지점, 얼굴을 불필요하게 함께 노출하지 않는다.
- 성취·신체 변화·건강·부상 내용을 홍보 문구로 확대하지 않는다.
- 거절하거나 촬영에서 빠질 수 있는 동선을 마련한다.
- 수업 중 촬영 안내와 공개 게시 동의를 같은 것으로 취급하지 않는다.

### 단체 촬영

- 한 사람의 동의로 다른 사람을 포함하지 않는다.
- 멀리 있는 인물도 확대했을 때 식별 가능한지 확인한다.
- 동의가 불명확한 사람은 크롭·가림·대체 컷으로 제외한다.
- 얼굴 가림만으로 도복 이름표·음성·특이 표식까지 자동 비식별화됐다고 판단하지 않는다.

## 7. 안전한 대체 소재

사람 동의가 준비되지 않았을 때도 다음 소재로 채널을 운영할 수 있다.

- 코치 단독 촬영: 얼굴·음성·복장 공개 범위를 코치 본인에게 확인
- 손·발·도복·띠·매트 중심 클로즈업
- 빈 도장·수업 전 준비물·정리 장면
- 실제 시설로 오인되지 않는 개념 일러스트
- 기술명·준비물·예절·첫 수업 질문 등 정보형 카드
- 식별정보가 없는 합성 예시와 체크리스트

AI 생성 이미지는 실제 회원 후기나 실제 수업 장면처럼 표현하지 않는다. 실제 인물의 얼굴을 닮게 만들거나 승인되지 않은 후기·성과를 합성하지 않는다.

## 9. 철회·삭제 처리

1. 요청 범위와 요청자 권한을 확인한다.
2. 해당 자산의 신규 업로드·예약·광고·재사용을 즉시 잠근다.
3. 운영 계정의 게시물·스토리·릴스·광고 소재·예약본을 찾는다.
4. 원 게시물 제거와 공개 URL 비노출을 각각 확인한다.
5. 검색 캐시·리포스트·공유 링크 등 운영자가 직접 통제하지 못하는 범위를 구분한다.
6. 가능한 신고·삭제 요청과 그 결과를 기록한다.
7. 증빙 보관 필요성과 원본 삭제 기한을 실제 정책에 따라 결정한다.
8. 제거 완료 시각과 미해결 범위를 당사자에게 과장 없이 안내한다.

## 10. 퍼널과 귀속

```
콘텐츠 승인
→ 게시 완료
→ 노출·도달·조회
→ 저장·공유·프로필 방문
→ 링크·전화·채팅 시작
→ 유효 문의
→ 체험 신청
→ 예약 확정
→ 체험 실참여
→ 신규 등록·복귀·재등록
→ 실수납
→ 환불·차지백 반영
→ 순수납
```

### 금지되는 자동 승격

- 얼굴 동의 완료 → 게시 승인
- 게시 승인 → 게시 완료
- 조회·저장 → 문의
- 통화 버튼 클릭 → 통화 연결·상담
- 채팅 시작·자동답장 → 유효 문의
- 예약 신청·체크인 → 체험 실참여
- 등록 의사 → 등록 완료·실수납

| 미성년자 보호자 권한 확인율 | 권한 확인 완료 대상 | 공개 후보 미성년자 | 데이터 미연결 |

| 순수납 ROI | 순기여 | 승인된 비용 | 데이터 미연결·계산 불가 |

분모가 0이거나 연결되지 않으면 비율을 계산하지 않는다.

## 12. 역할별 실행

### CMO

- 사람 중심 홍보보다 동의 범위와 철회 처리 가능성을 선행 조건으로 둔다.
- 인물 촬영이 없어도 운영 가능한 콘텐츠 비중을 확보한다.

### Growth Analyst

- 게시 성과와 문의·체험·등록·실수납을 별도 사건으로 연결한다.
- 삭제된 콘텐츠의 과거 성과를 현재 활성 콘텐츠 성과로 재사용하지 않는다.

### Acquisition Marketer

- 공개 근거가 확인된 자산만 랜딩·광고·지역 프로필에 사용한다.
- 동의 미연결 기간에는 도복·매트·코치 단독·개념 일러스트 소재를 사용한다.

### CRM Marketer

- 촬영 동의 요청을 마케팅 수신 동의나 회원권 계약 동의로 대체하지 않는다.
- 철회·거절 정보를 불이익이나 이탈 사유로 사용하지 않는다.

### Content Strategist

- 자산마다 실제 촬영, 개념 일러스트, 재현 장면을 명확히 구분한다.
- 코치 개인 경험은 확인 자료가 있을 때만 1인칭으로 쓴다.

### Experiment Manager

- 합성 데이터로 상태 오분류·채널 범위·철회 차단·삭제 검증을 먼저 시험한다.

### Auditor

- 공개 저장소에는 원본 촬영물, 동의서, 이름, 연락처, 식별 가능한 기록을 올리지 않는다.
- 외부 채널에서 삭제됐다고 내부 원본까지 삭제된 것으로 처리하지 않는다.

## 13. 실험 EXP-401

**가설:** 사람·자산·채널·목적·철회 상태를 분리하면 무단 게시와 잘못된 성과 귀속을 예방할 수 있다.

### 시험 데이터

- 합성 촬영 자산 240건
- 합성 인물·동의 범위 720건
- 게시·재사용·철회·삭제 사건 720건
- 성인·미성년자·코치·회원·방문자·단체 촬영 조합 포함

### 성공 기준

- `CONSENT_REQUESTED`의 `CONSENT_VERIFIED` 오분류 0건
- 수업 참석·침묵·단체사진 참여의 공개 동의 오분류 0건
- 보호자 권한 미확인 미성년자 공개 0건
- 유기적 게시 동의의 유료 광고 동의 자동 승격 0건
- 한 채널 동의의 다른 채널 재사용 자동 승격 0건
- 철회 요청 후 신규 업로드·예약·광고 집행 0건
- 운영 채널 제거의 인터넷 전체 삭제 오분류 0건
- 조회·클릭의 문의·체험·수납 오분류 0건
- 개인정보·원본 동의서의 공개 저장소 기록 0건

### 중단 기준

성공 기준 중 하나라도 실패하면 실제 인물 촬영물의 자동 게시·재사용·삭제 완료 처리와 ROI 보고를 중단한다.
