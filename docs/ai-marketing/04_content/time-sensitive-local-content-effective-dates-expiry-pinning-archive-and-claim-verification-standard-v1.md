# 기간성 지역 콘텐츠·효력일·만료·고정·보관·주장 검증 기준 v1

- 적용 조직: 파이널유도멀티짐 공개 마케팅 실무
- 적용 채널: 네이버 스마트플레이스·블로그, Google 비즈니스 프로필, 당근 비즈프로필, 웹사이트, 브랜드 SNS, 코치 개인 Instagram
- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-17
- 공개 제외: 실제 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제 기록, 비밀키, 내부 예산·손익, 승인 대기 Instagram 미디어·캡션, 미확정 행사·가격·혜택

## 1. 핵심 판단

콘텐츠를 게시했다는 사실만 관리하면 기간이 끝난 행사·가격·시간표·좌석·혜택이 현재 안내처럼 남을 수 있다. 지역 기반 마케팅에서는 다음 상태를 분리한다.

1. 사실 원천이 확정됨
2. 콘텐츠가 승인됨
3. 효력이 시작됨
4. 채널에 게시됨
5. 공개 화면에서 관찰됨
6. 승인 원천과 일치함
7. 효력이 종료됨
8. 수정·고정 해제·보관·삭제가 필요함
9. 공개 화면에서 종료 처리가 검증됨

과거 게시물의 조회·검색 노출이 남아 있다는 이유로 현재 모집·혜택·좌석이 유효하다고 보지 않는다. 게시물 만료는 고객 여정의 종료가 아니며, 문의·예약·실방문·계약·실수납을 별도 사건으로 관리한다.

## 2. 네 목표와의 연결

### 2.1 신규 체험회원 확보

- 검색·프로필·소식에서 현재 유효한 지점·수업·문의 경로를 찾게 한다.
- 종료된 행사·체험 조건·마감 문구가 신규 문의를 잘못 유도하지 않게 한다.
- 게시물 클릭을 체험 예약이나 실제 방문으로 집계하지 않는다.

### 2.2 휴면회원 복귀

- 과거 복귀 안내의 혜택·기간을 현재 조건으로 오인하지 않게 한다.
- 휴면회원의 기존 관계를 신규 리드로 중복 집계하지 않는다.
- 과거 콘텐츠를 보고 들어온 문의에는 현재 기준 원천을 다시 확인한다.

### 2.3 기존회원 재등록·만족

- 종료된 시간표·휴강·행사 공지가 고정 게시물이나 하이라이트에 남지 않게 한다.
- 기존회원 운영 안내와 광고성 모집 콘텐츠를 구분한다.
- 잘못된 공개 안내로 발생한 문의·방문 실패를 회원 책임으로 처리하지 않는다.

### 2.4 매출 증대

- 기간성 콘텐츠의 도달과 계약·결제·환불 반영 순수납을 분리한다.
- 만료된 가격·혜택의 잘못된 적용을 방지한다.
- 실제 비용·수납·환불이 연결되지 않으면 ROAS·ROI를 계산하지 않는다.

## 3. 콘텐츠 유형 분류

| 유형 | 예시 | 기본 처리 |
|---|---|---|
| EVERGREEN | 유도 용어·도복·입문 상식 | 정기 사실 재검토 |
| TIME_BOUND_OPERATION | 임시휴무·수업 변경·공사 | 종료 시 수정·보관·원복 검증 |
| EVENT | 세미나·대회·오픈 클래스 | 신청·행사·후속 단계를 분리 |
| OFFER | 할인·쿠폰·혜택 | 시작·종료·조건·승인 필수 |
| CAPACITY | 잔여석·대기·마감 | 좌석 원천과 짧은 유효기간 필수 |
| PRICE | 이용요금·추가비용·환불기준 | 공식 가격 버전과 일치 필수 |

| INCIDENT | 오류·휴강·시설 문제·정정 | 사실 확인·영향 범위·회복 상태 관리 |

EVERGREEN도 영구 불변을 뜻하지 않는다. 기술·규정·플랫폼 기능·지점 정보가 바뀔 수 있으므로 검토일과 근거를 남긴다.

## 4. 콘텐츠 주장 원장

게시물 단위뿐 아니라 고객 행동에 영향을 주는 주장 단위로 기록한다.

### 4.1 필수 필드

| content_id | 콘텐츠 고유 ID |
| version | 승인 대상 버전 |
| channel | 게시 채널 |

| claim_type | 시간·가격·혜택·좌석·행사·문의 경로·일반 지식 등 |
| source_system | 사실의 기준 시스템 |
| source_version | 승인 원천의 버전 |

### 4.2 금지 원칙

- `effective_to`가 필요한 주장에 종료 시각 없이 `오늘`, `이번 주`, `마감 임박`만 쓰지 않는다.
- 게시 도구의 예약 종료를 사실 효력 종료로 대신하지 않는다.
- 원본이 바뀌었다는 이유만으로 기존 공개 콘텐츠가 자동 수정됐다고 보지 않는다.
- 고정 게시물을 최신 정보라고 자동 판정하지 않는다.
- 삭제·보관 요청을 공개 종료 처리 완료로 표시하지 않는다.

## 6. 효력 시작과 종료

### 6.1 절대 시각

- 날짜·시간·시간대를 함께 기록한다.
- 한국 대상 콘텐츠의 기준 시간대는 승인 원천과 채널 설정을 확인한다.
- `오늘`, `내일`, `이번 주말`을 쓸 때도 원장에는 절대 날짜를 기록한다.
- 자정 종료인지 영업 종료인지 명확히 한다.

### 6.2 시작 전

- 승인 완료와 공개 가능 시각을 분리한다.
- 가격·혜택·행사·좌석은 효력 시작 전 공개 여부를 별도로 승인받는다.
- 사전 안내라면 `예정`, `승인 완료`, `신청 시작`을 혼동하지 않는다.

### 6.3 종료 후

콘텐츠 성격에 따라 다음 중 하나를 선택한다.

- 수정: 현행 정보로 바꿔도 과거 기록이 왜곡되지 않을 때
- 고정 해제: 프로필 상단·홈·하이라이트의 우선 노출만 종료할 때
- 보관: 공개 프로필에서 숨기되 내부 계보를 보존할 때
- 삭제: 안전·개인정보·중대한 허위 위험이 있고 보관만으로 부족할 때
- 유지: 과거 기록으로 가치가 있으며 종료 사실이 명확할 때
- 정정: 기존 정보가 틀려 영향을 받은 사람에게 현재 사실을 알려야 할 때

조회가 높다는 이유로 만료된 모집·가격·혜택을 고정 상태로 유지하지 않는다.

## 7. 고정·하이라이트·프로필 링크

고정 영역은 일반 피드보다 최신 공식 안내로 오인될 위험이 크다.

### 7.1 고정 전 확인

- 발표 주체가 해당 주장을 할 권한이 있는가
- 지점·대상·기간이 명시됐는가
- 가격·혜택·좌석의 기준 원천이 있는가
- 종료 시각과 고정 해제 책임자가 지정됐는가
- 링크가 승인된 현재 목적지로 연결되는가

### 7.2 고정 해제 검증

- 해제 버튼 실행과 공개 프로필 변화 확인을 분리한다.
- 모바일·비로그인 환경에서 상단 노출이 사라졌는지 확인한다.
- 하이라이트·링크 인 바이오·예약 버튼·스토리 링크의 잔존 여부도 확인한다.
- 캐시·검색 미리보기 잔존은 채널별 별도 상태로 기록한다.

## 8. 채널별 적용

### 8.1 Instagram 코치 개인 계정

- 코치 개인의 수련·지도 설명·일상 맥락을 우선한다.
- 브랜드 전체의 가격·시간표·행사·좌석을 공식 확정 발표처럼 말하지 않는다.
- 게시물의 날짜가 과거라는 사실만으로 현재 조건이 아님이 충분히 전달된다고 가정하지 않는다.
- 기간성 지점 안내를 고정·하이라이트로 쓸 경우 발표 주체와 종료 처리 계획을 별도 승인한다.
- 보관 기능을 실행했다는 사실과 공개 프로필에서 사라진 사실을 분리한다.
- 승인 대기 미디어·캡션은 Instagram 또는 외부 게시 도구에 업로드·초안 저장·예약하지 않는다.

### 8.2 네이버 스마트플레이스·블로그

- 업체 영업시간과 예약·주문 운영시간을 분리한다.
- 새소식·공지·쿠폰과 업체 기본정보의 원천을 구분한다.
- 수정 신청·심사·검색 반영·공개 일치 검증을 분리한다.
- 쿠폰 혜택 변경은 이미 받은 쿠폰에 미치는 영향까지 확인한다.
- 과거 블로그 글이 검색될 수 있으므로 가격·시간표·행사 글에는 기준일과 확인 경로를 둔다.

### 8.3 Google 비즈니스 프로필

- 업데이트·혜택·이벤트 유형을 구분한다.
- 혜택과 이벤트는 시작·종료 날짜와 시간을 정확히 입력한다.
- 날짜 범위를 지정하지 않은 게시물은 6개월이 지나면 보관될 수 있다는 플랫폼 규칙을 고려한다.
- 반복 게시 기능을 사용할 때는 원천 정보가 바뀐 뒤 오래된 문구가 다시 게시되지 않도록 반복 일정과 원본을 함께 종료한다.
- 일반 운영시간과 특별시간·장기 휴업을 분리한다.
- 게시 후 수정·삭제가 가능하다는 사실을 자동 종료나 정확성 보장으로 해석하지 않는다.
- 게시물 CTA 링크의 최종 목적지를 직접 확인한다.

### 8.4 당근 비즈프로필

- 홈에 노출되는 소식·쿠폰 수가 제한될 수 있으므로 오래된 항목의 잔존을 검수한다.
- 소식 수정과 공개 반영 확인을 분리한다.
- 단골 알림 발송은 단골의 알림 설정에 따라 전달 방식이 다를 수 있으므로 발송을 열람으로 보지 않는다.
- 비즈프로필 소식을 광고 소재로 사용할 경우 원본 소식의 효력 종료와 광고 집행 종료를 함께 관리한다.
- 채팅 시작을 예약·방문·실수납으로 처리하지 않는다.

### 8.5 웹사이트

- 가격·시간표·혜택·행사 페이지에 `last_verified_at`과 담당 원천을 둔다.
- 종료된 페이지는 무조건 삭제하지 말고 적절한 현행 안내로 연결한다.
- 검색 결과 제목·설명·구조화 데이터와 화면 본문이 충돌하지 않는지 확인한다.
- 외부 채널이 복사해 간 오래된 링크를 찾을 수 있도록 원본 URL 계보를 보존한다.

## 9. 현행 정보와 과거 기록의 표현

### 9.1 현행 표현

- `2026년 9월 17일 확인`
- `적용 기간: YYYY-MM-DD HH:MM ~ YYYY-MM-DD HH:MM KST`
- `지점별 일정은 공식 안내에서 다시 확인`

### 9.2 과거 기록 표현

- `종료된 행사 기록`
- `당시 안내 기준`
- `현재 가격·일정과 다를 수 있음`
- `현재 문의 경로`와 과거 신청 링크를 분리

### 9.3 금지 표현

- 근거 없는 `마지막 기회`, `오늘만`, `곧 마감`
- 좌석 원천 없이 `잔여 1석`, `마감 임박`
- 가격 버전 없이 `현재 최저가`, `전 지점 동일`
- 승인되지 않은 `무료 체험`, `전원 지급`, `무조건 연장`
- 효력 종료 후에도 현재형으로 남은 `신청하세요`, `예약 가능합니다`

## 10. 만료 전 점검 창

모든 기간성 콘텐츠에는 내부 점검 시각을 둔다. 점검 간격은 콘텐츠 위험과 채널 기능에 맞춰 대표가 승인한다.

### P0

- 잘못된 주소·시간·가격·결제·환불·안전 정보
- 승인 없는 개인정보·회원 촬영물
- 종료된 혜택이 현재 사용 가능하다고 표시됨

처리: 즉시 노출 축소·정정 검토, 책임자 인계, 영향 범위 확인

### P1

- 지난 행사·휴강·마감 공지가 고정·하이라이트에 남음
- 만료된 좌석·쿠폰·신청 링크가 작동함
- 코치 개인 계정이 브랜드 공식 발표처럼 보임

처리: 당일 상태 확인과 종료 처리

### P2

- 오래된 일반 소개·대표 이미지·해시태그
- 현행 사실과 충돌하지 않지만 재검토일이 지난 EVERGREEN 콘텐츠

처리: 계획된 콘텐츠 감사에서 갱신

## 11. 수정과 정정

### 11.1 수정

오탈자·링크·현행 정보 변경으로 과거 의미를 왜곡하지 않을 때 사용한다.

### 11.2 정정

다음 경우에는 조용한 수정만으로 충분하다고 가정하지 않는다.

- 잘못된 가격·혜택·환불 조건이 공개됨
- 잘못된 시간·주소·지점으로 방문을 유도함
- 잘못된 좌석·예약 상태로 행동을 유도함
- 회원·코치·기관에 관한 사실 오류가 있음
- 안전 행동에 영향을 줄 수 있는 오류가 있음

정정에는 잘못된 주장, 올바른 현행 사실, 적용 시각, 확인 경로를 포함한다. 실제 영향 대상자 연락은 동의·권한·대표 승인 후 별도 실행한다.

## 12. 채널 간 복제 기준

- Instagram 캡션을 네이버·당근 공지로 자동 복제하지 않는다.
- 코치 개인의 1인칭 표현을 브랜드 공식 사실로 바꾸지 않는다.
- 각 채널의 링크·날짜·버튼·고정 기능을 다시 확인한다.
- 한 채널의 삭제를 전체 채널 종료로 처리하지 않는다.
- 소스 콘텐츠가 만료되면 파생 콘텐츠·광고·프로필 링크를 함께 조회한다.
- 이미지 안의 날짜·가격·혜택은 캡션 수정만으로 고쳐지지 않는다.

## 13. 성과와 귀속

### 13.1 콘텐츠 상태 지표

- 검수 대상 기간성 콘텐츠 수
- 종료 예정 콘텐츠 수
- 기한 내 종료 처리 수
- 만료 후 잔존 콘텐츠 수
- 고정·하이라이트 잔존 오류 수
- 잘못된 링크 수
- 정정 필요·완료 수

기한 내 종료 처리율 = `EXPIRED_VERIFIED 건수 / 종료 처리 대상 건수`

- 분자·분모·기간·채널을 함께 표시한다.
- 미검수 항목을 성공으로 처리하지 않는다.
- 분모가 0이면 비율을 계산하지 않는다.

### 13.2 플랫폼 반응

- 노출·조회
- 도달
- 클릭
- 좋아요·댓글·저장·공유
- 프로필 활동
- 게시물 귀속 팔로우

### 13.3 사업 성과

- 직접 문의
- 적격 문의
- 체험 예약
- 실제 방문
- 신규 계약·실수납
- 휴면 복귀
- 재등록·실수납
- 환불 반영 순수납

과거 콘텐츠의 조회·클릭을 현재 캠페인의 신규회원이나 매출로 자동 귀속하지 않는다. 현재 내부 실적은 데이터 미연결이다.

## 15. EXP-360 — 기간성 콘텐츠 효력·만료·고정·정정 완전성

### 포함 사례

- 종료일 없는 `이번 주` 행사
- 이미 끝난 혜택이 프로필 상단에 고정됨
- 고정 해제 버튼은 눌렀으나 공개 화면에 남음
- 캡션만 수정되고 이미지 속 날짜는 과거 상태
- 네이버 업체 영업시간과 예약 운영시간 불일치
- Google 이벤트 종료일 누락
- 원천이 바뀌었지만 Google 반복 게시 일정이 과거 문구를 다시 게시함
- 당근 소식은 수정됐으나 광고 소재는 과거 문구 유지
- 코치 개인 계정이 브랜드 공식 모집 주체처럼 표현됨
- 과거 게시물 경유 문의가 신규 캠페인 성과로 중복 귀속됨
- 삭제 요청을 삭제 완료로 오분류함

- 소스 만료 후 파생 콘텐츠·광고 잔존 미탐지 0건
