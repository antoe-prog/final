# Naver AI Search Landing Readiness — 검색·AI 광고용 랜딩 구조 v1

- 작성일: 2026-09-13
- 상태: 공개자료 기반 전략 설계 / 광고 미집행 / 사이트·계정 변경 없음
- 목표: 신규 체험회원 확보 + 검색 유입 품질 개선 + 체험·복귀·재등록 경로의 정보 정합성 확보
- 내부 회원수·매출·전환율·검색광고 성과·웹분석: **데이터 미연결**

## 오늘의 판단

이번 우선순위는 **광고비 확대 전, 파이널유도멀티짐의 공개 랜딩페이지를 사람과 검색·AI 시스템이 모두 이해할 수 있는 구조로 만드는 것**이다.

네이버 광고주센터는 2026년 8월부터 네이버 AI 광고가 정식 출시됐고, AI 브리핑에도 광고가 노출되기 시작했다고 안내하고 있다. 동시에 ADVoost 검색은 검색로봇이 광고 랜딩페이지를 수집·색인하고 검색어와의 연관도를 평가해 노출에 활용한다고 설명한다. 네이버는 이미지 한 장 중심의 페이지는 검색로봇에게 내용이 거의 없는 페이지처럼 보일 수 있다고 명시하고, 제목·설명·URL·ALT·본문 텍스트와 Q&A·서비스 설명 같은 구체적인 정보를 권장한다.

따라서 파이널유도는 `광고 키워드 추가 → 클릭 수 증가`보다 먼저 `검색 의도 → 정확한 프로그램 페이지 → 실제 시간·대상·체험 경로 → 실방문`이 연결되는 공개 정보 구조를 갖춰야 한다.

현재 파이널유도의 공개 홈페이지가 네이버 검색로봇에 어느 수준으로 수집·색인되고 있는지, 각 지점·프로그램 페이지가 별도 URL로 존재하는지, Title/Description/OG/ALT/본문 텍스트/FAQ가 어떻게 구성돼 있는지는 **데이터 미연결**이다. 공개 검색 결과만으로 비색인 상태라고 단정하지 않는다.

## 발견한 변화

### 1. 검색광고에서도 랜딩페이지 자체가 광고 노출의 입력값이 됨

네이버는 ADVoost 검색이 랜딩페이지 내용을 읽고 검색어와의 연관도를 평가한다고 안내한다. 따라서 `강서구 유도`, `마곡 성인 유도`, `초등 유도 체험`, `유도 다시 시작`처럼 의도가 다른 검색어를 하나의 포괄적 홈페이지에 모두 연결하는 방식보다, 실제 제공 서비스와 일치하는 상세페이지를 분리하는 것이 검증 가치가 있다.

이는 SEO만의 문제가 아니다. 네이버 공식 안내상 검색광고의 확장검색·ADVoost 검색도 랜딩페이지의 내용과 연관도를 활용한다.

### 2. AI·검색 로봇은 이미지 중심 디자인보다 구조화된 텍스트를 필요로 함

네이버는 사람이 이미지를 보고 이해하더라도 검색로봇은 페이지 내 텍스트와 구조를 중심으로 이해한다고 설명한다. 따라서 시간표, 초보자 안내, 준비물, 체험 절차를 포스터 이미지 한 장으로만 제공하면 로봇에게 충분한 내용이 전달되지 않을 수 있다.

파이널유도 공개 페이지는 최소한 아래를 텍스트로 제공하는 방향을 검토한다.

- 지점명과 실제 지역
- 대상 연령·수준
- 실제 운영하는 프로그램명
- 초보자 가능 여부
- 확인된 수업 요일·시간
- 첫 체험 흐름
- 준비물
- 위치·입구·주차 등 방문 정보
- 자주 묻는 질문
- 실제 예약 또는 문의 CTA

시간·가격·정원처럼 자주 바뀌는 항목은 내부 Source of Truth와 불일치하지 않도록 별도 검수한다.

### 3. 최신 무도장 공개페이지도 `프로그램 + 시간 + 초보 설명 + CTA`를 함께 제공하는 패턴이 확인됨

Mike's Judo Club의 2026년 9월 시간표는 초보반별 연령·시간·훈련내용과 Free Trial/FULL 상태를 같은 페이지에서 보여준다.

Japan Arts Centre Police Sport UK Judo는 2026년 9월 신규 초보과정, 코치진 자격, 수업시간, 무료 체험 CTA를 함께 공개하고 있다.

SenoSen School의 현행 일정 페이지는 시간표뿐 아니라 체험 예약 후 무엇이 일어나는지, 무엇을 준비하는지까지 FAQ로 설명한다.

이 사례는 페이지 구조 참고용이며, 외부 도장의 무료체험 조건·시간·가격·성과를 파이널유도에 복제하지 않는다.

## CMO — 우선순위

1. 광고 예산 확대보다 **검색 의도별 랜딩 구조의 정확성**을 먼저 확보한다.
2. 신규획득과 복귀·기존회원 정보를 한 페이지에서 혼합하지 않는다.
3. 지점별 실제 시간표와 다른 공통 문구를 배포하지 않는다.
4. `검색 노출`보다 `유효문의 → 예약 → 실방문 → 14일 등록 → 30일 활성`을 최종 판단 기준으로 둔다.

`returner_search_or_content → returner_info_view → self_opt_in → suitable_slot_offered → verified_return → active_30d → renewal`

### 핵심 병목 후보

- 포스터 이미지에만 중요한 정보가 존재

- 네이버·인스타·당근과 공식 웹의 정보 불일치

현재 발생 건수와 전환 영향은 모두 **데이터 미연결**이다.

## Acquisition Marketer — 검색 의도별 공개페이지 후보

실제 제공 가능 여부가 확인된 항목만 페이지화한다.

### 후보 A. 지역 + 브랜드

- 파이널유도멀티짐 본관
- 강서구 유도
- 마곡·등촌 등 실제 서비스 생활권

### 후보 B. 대상별

- 성인 유도 입문
- 중·고등부 유도
- 초등 유도 입문

### 후보 C. 행동 의도별

- 유도 체험
- 처음 시작하는 유도
- 오랜만에 다시 시작하는 유도

각 페이지는 `누구에게 적합한가 → 무엇을 배우는가 → 실제 가능한 시간 → 첫 방문 흐름 → CTA` 순으로 단순하게 구성한다.

검색량이 확인되지 않은 키워드를 `인기 키워드`라고 표현하지 않는다.

## CRM Marketer — 공개 복귀 경로 분리

휴면·복귀 회원에게 신규회원 전용 혜택 페이지를 기본 경로로 사용하지 않는다.

공개 `다시 시작하는 분` 정보 영역에는 아래 정도만 제공한다.

- 쉬었던 기간과 관계없이 문의 가능한지
- 기존 띠·경력 확인 방식
- 첫 복귀 수업 강도는 어떻게 조정하는지
- 복귀 가능한 실제 시간 확인 방법
- Self-Opt-In 문의 CTA

개인별 과거 출석·결제·건강정보는 공개페이지에 노출하지 않는다.

체험후미등록자에게도 개인추적 URL이나 식별 가능한 공개 링크를 사용하지 않는다.

## Content Strategist — 채널 연결 원칙

### 네이버

검색어와 가장 가까운 상세페이지를 랜딩 후보로 사용한다. 검색광고를 실제 집행하려면 대표 승인 후 진행한다.

### Instagram

Reel·게시물에서 설명한 프로그램과 동일한 공개페이지로 연결한다. `성인 초보` 콘텐츠가 어린이 통합 홈페이지로 연결되지 않도록 한다.

### 당근

지역형 소식은 해당 지점의 실제 시간·체험가능정보와 일치하는 페이지 또는 승인된 문의 경로로 연결한다.

### 공통

모든 채널에서 동일한 `프로그램명 / 대상 / 시간 / 체험조건`을 유지한다. 변경 시 외부 채널을 함께 검수한다.

## 즉시 실행 3개

### 1. Public Landing Inventory

외부 변경 없이 먼저 공개페이지 목록을 만든다.

각 페이지를 다음 상태로 분류한다.

- `INDEXABLE_CONFIRMED`
- `INDEXABLE_UNKNOWN`
- `CONTENT_INCOMPLETE`
- `STALE_INFO_RISK`
- `AUTH_REQUIRED`
- `NOT_FOR_ACQUISITION`

현재 상태값은 **데이터 미연결**이다.

### 2. Search-Intent Page Template 정의

신규 페이지를 실제 배포하기 전, 공통 템플릿을 문서 수준에서 확정한다.

필수 구성:

1. 고유 Title
2. 고유 Description
3. 명확한 H1
4. 실제 대상·지역·프로그램 설명 본문
5. 실제 시간 또는 최신 시간 확인 경로
6. 첫 방문 FAQ
7. 준비물·위치 정보
8. CTA
9. 이미지 ALT
10. 마지막 검수일

### 3. Schedule Truth Gate

시간표가 내부에서 변경되면 검색·광고·SNS 페이지가 자동으로 맞춰진다고 가정하지 않는다.

`internal_schedule_changed → public_page_review_required → naver_review_required → instagram_review_required → daangn_review_required`

외부 페이지 변경은 대표 승인과 운영 절차 확인 후 수행한다.

## Experiment Manager — 실험

### EXP-268 Intent-Specific Landing vs Generic Landing

**가설:** 실제 제공 서비스와 검색 의도가 일치하는 상세 랜딩이 포괄적 홈페이지보다 하단 퍼널의 유효문의 품질을 높일 수 있다.

비교:

- A: 포괄 홈페이지
- B: 실제 프로그램·대상·지점이 일치하는 상세페이지

핵심 KPI:

- 랜딩 조회 → 유효문의
- 유효문의 → 슬롯 제안
- 슬롯 제안 → 예약
- 예약 → 실방문
- 실방문 → 14일 등록
- 등록 → 30일 활성

성공 기준:

- 대표가 사전에 정한 최소 개선폭을 충족하고,
- 오안내·잘못된 반 배정·과밀이 증가하지 않으며,
- 하단 퍼널이 악화되지 않을 때만 확대한다.

기준선·최소개선폭·필요 표본수는 **데이터 미연결**이다.

### EXP-269 Crawlability & Content Completeness Gate

광고 집행 실험이 아니라 공개페이지 준비상태 검증이다.

각 후보 랜딩에서 아래를 확인한다.

- 검색로봇 접근 가능 여부
- 고유 Title·Description
- 본문 텍스트 존재
- 핵심 이미지 ALT
- 명확한 URL
- 프로그램·대상·지역·CTA 일치
- Q&A 또는 초보자 안내 존재

하나의 페이지에 핵심정보가 모두 이미지로만 존재하거나 인증이 필요한 페이지라면 검색 획득용 랜딩에서 제외한다.

### EXP-270 Public Schedule Integrity Check

**목표:** 신규획득 확대 전에 외부 공개정보의 오안내 위험을 줄인다.

확인 항목:

- 실제 운영 시간 vs 웹
- 실제 체험가능 여부 vs 웹
- 네이버 vs 웹
- 인스타 vs 웹
- 당근 vs 웹

성공 기준:

- 사전 정의한 검수기간 내 운영정보 불일치 0건을 목표로 하되, 현재 기준선은 **데이터 미연결**이다.

중단 기준:

- 잘못된 시간·가격·체험조건 노출
- 실제 없는 반·프로그램 노출
- 검색광고 랜딩이 로그인 뒤에 위치
- 개인 회원정보가 공개 URL에 포함

## 필요한 대표 승인·입력

실제 사이트 변경 또는 광고 집행 전 아래가 필요하다.

1. 공식 공개 도메인과 운영 중인 공개페이지 목록
2. 각 지점의 실제 공개 가능 주소·시간표·대상·체험정책
3. 현재 웹분석 도구 및 이벤트 계측 여부
4. 네이버 검색광고 사용 여부와 광고주 계정 상태
5. 네이버 URL 진단도구·Search Advisor 사용 여부
6. 공개 가능한 회비·가격 범위
7. 신규·복귀용 CTA의 실제 담당자와 응답 가능 시간
8. 사이트 코드 변경 승인권자

이 값들은 현재 **데이터 미연결**이다.
