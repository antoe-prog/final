## 즉시 적용하는 게시 안전장치

1. 게시 실행 전 Instagram 프로필과 Metricool List에서 동일 주제·동일 작업 ID의 공개·Pending 항목을 모두 확인한다.
2. 이미 열린 작성창은 새 승인 실행에 재사용하지 않는다. 새 작성창에서 승인본 해시와 캡션을 다시 대조한다.
3. `Publish now` 실행은 한 번만 하고 Pending 상태에서는 재실행하지 않는다.
4. 공개 전환 후 계정·URL·첫 장·마지막 장·캡션을 확인한다.
5. 예상하지 않은 구버전 또는 중복 게시 발견 시 삭제·수정하지 않고 별도 상태로 기록한다.

## 실험

### EXP-284 Single-Package Publication Integrity

**가설**

작업 ID·버전·미디어 해시·캡션 해시·게시 전 중복 조회를 하나의 체크리스트로 고정하면 구버전 또는 중복 게시 위험을 먼저 발견할 수 있다.

**성공 기준**

- 승인 작업 ID·버전과 공개 게시물 일치 100%
- 한 승인 패키지당 새 공개 URL 1개
- 게시 전 동일 주제 공개·Pending 항목 확인 100%
- 공개 후 8장·캡션 검증 100%
- 개인정보·권리 문제 0건

**중단 기준**

- 승인본과 미디어·문구 불일치
- 동일 패키지의 두 번째 게시 시도
- Pending 상태에서 재발행
- 별도 승인 없는 삭제·수정
- 원인 미확인 상태에서 특정 도구·사람에게 책임 귀속

게시 무결성은 확인 가능하지만 도달·문의·등록·매출 개선폭은 **데이터 미연결**이다.
