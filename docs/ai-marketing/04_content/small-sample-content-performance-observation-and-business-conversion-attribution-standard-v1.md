# 소표본 콘텐츠 성과 관찰·사업 전환 귀속 기준 v1

- 적용 범위: 파이널유도멀티짐의 Instagram·네이버·당근·Google 비즈니스 프로필 등 공개 마케팅 콘텐츠
- 문서 성격: 공개 가능한 측정·판정 운영 기준
- 기준일: 2026-09-20
- 개인정보: 수집·기록·공개하지 않음
- 개별 승인 대기 미디어·캡션: 포함하지 않음

## 1. 운영 판단

조회·도달·반응의 분모가 매우 작을 때 비율은 한 건의 행동에도 크게 변한다. 이 단계에서는 콘텐츠의 승자·패자, 채널 효율, 문의율, 등록률 또는 매출 기여를 확정하지 않는다.

각 콘텐츠는 다음 세 층으로 분리한다.

1. 플랫폼 노출: 조회·도달
2. 플랫폼 반응: 좋아요·댓글·저장·공유·팔로우
3. 사업 결과: 유효 문의·체험 예약·실제 참여·신규 등록·복귀·재등록·순수납

상위 층의 숫자를 하위 층의 결과로 자동 승격하지 않는다.

## 2. 최소 기록 단위

콘텐츠 한 건마다 아래 필드를 기록한다.

| 필드 | 설명 |
|---|---|
| 콘텐츠 ID·버전 | 대체본과 이전 버전 분리 |
| 계정·채널 | 코치 개인 계정과 지점 공식 채널 분리 |
| 공개 URL | 실제 공개 확인의 증거 |
| 공개 시각 | 시간대 포함 |
| 관찰 시작·종료 | 모든 비교에 동일 기준 적용 |
| 조회·도달 | 플랫폼이 제공한 정의와 원천 기록 |
| 좋아요·댓글·저장·공유 | 각 사건을 독립 기록 |
| 게시물 귀속 팔로우 | 계정 전체 증감과 분리 |
| 유효 문의 | 사람의 실제 질문·응답 여부 확인 |
| 체험 예약·실제 참여 | 예약과 출석 분리 |
| 등록·복귀·재등록 | 공식 정의에 따라 상호 배타적으로 분류 |
| 순수납 | 환불·차지백·할인·보상 비용 반영 |
| 데이터 원천 | 플랫폼·CRM·예약·출석·계약·정산 원장 구분 |

## 3. 지표 정의와 금지 해석

### 조회

콘텐츠가 표시된 횟수다. 동일인이 여러 번 포함될 수 있다.

금지:

- 조회를 고유 인원으로 계산
- 조회를 관심·문의·방문으로 계산
- 여러 게시물의 조회 합계를 신규 고객 수로 계산

### 도달

플랫폼 정의상 콘텐츠를 본 사람 또는 계정 수다. 게시물별 도달을 더해 계정 전체 고유 도달로 만들지 않는다. 같은 사람이 여러 게시물에 포함될 수 있다.

### 반응

좋아요·댓글·저장·공유는 서로 다른 행동이다. 하나의 합산 점수로만 보지 않고 원시값을 함께 보존한다.

### 프로필·지역검색 상호작용

프로필 조회·전화 버튼·길찾기·웹사이트 클릭은 플랫폼 상호작용이다. 전화 연결, 상담, 실제 방문, 실제 체험을 증명하지 않는다.

### 사업 결과

문의·예약·출석·계약·결제·정산은 각각 별도 사건과 원천이 있어야 한다. 확인되지 않은 단계는 데이터 미연결로 남긴다.

## 4. 비율 표시 규칙

모든 비율은 다음 네 항목을 함께 표시한다.

- 분자
- 분모
- 관찰기간
- 데이터 원천

예시:

`저장률 = 저장 2건 / 도달 40명 = 5.0%, 공개 후 72시간, 플랫폼 원천`

금지:

- 분모 없는 퍼센트
- 분모가 0인 비율 계산
- 서로 다른 관찰기간의 직접 비교
- 조회 기반 비율과 도달 기반 비율 혼합
- 유기적 성과와 유료 성과 혼합
- 반올림된 비율만 보존하고 원시 건수 삭제

## 5. 소표본 판정 규칙

최소 분모·최소 비교 콘텐츠 수·최소 관찰기간은 대표가 사전에 승인한다. 승인되지 않은 임계값을 외부 벤치마크에서 가져와 내부 성공 기준으로 사용하지 않는다.

임계값이 연결되기 전에는 다음 규칙을 적용한다.

- 원시값만 확정하고 우열 판정은 보류
- 0건을 실패로 자동 분류하지 않음
- 1건의 반응으로 콘텐츠 방향을 변경하지 않음
- 가장 높은 비율을 승자로 선언하지 않음
- 광고 확대·예산 이동 근거로 사용하지 않음
- 다음 콘텐츠의 사실·형식·CTA를 한꺼번에 변경하지 않음
- 관찰 중인 게시물을 삭제·재게시해 기간을 초기화하지 않음

## 6. 결측값·0·미지원 구분

| 상태 | 의미 |
|---|---|
| 0 | 해당 기간에 플랫폼이 0건으로 반환 |
| 데이터 미연결 | 원천 시스템 또는 식별키가 연결되지 않음 |
| 미지원 | 플랫폼·요금제·계정 유형에서 제공하지 않음 |
| 조회 실패 | 일시적 오류·권한·로그인 문제 |
| 계산 불가 | 분모 0, 기간 불일치 또는 원천 불일치 |
| 미성숙 | 사전 승인된 관찰기간이 끝나지 않음 |

빈 값이나 `-`를 0으로 바꾸지 않는다.

## 7. 비교 가능한 콘텐츠 묶음

다음 항목이 맞지 않으면 같은 실험군으로 직접 비교하지 않는다.

- 채널과 계정
- 게시 형식
- 목적과 대상
- CTA
- 유기적·유료 여부
- 관찰기간
- 지표 정의
- 공개 상태
- 데이터 원천

주제 탐색 콘텐츠와 체험 문의 콘텐츠를 같은 전환 목표로 평가하지 않는다. 코치 개인 Instagram과 지점 공식 채널도 합치지 않는다.

## 8. 콘텐츠에서 사업 결과까지

`공개 검증 → 조회·도달 → 반응 → 프로필 행동 → 유효 문의 → 체험 예약 → 실제 체험 → 등록·복귀·재등록 → 실정산`

필수 통제:

- 공개 URL이 없는 콘텐츠는 게시 완료로 계산하지 않음
- 문의 원천은 자기신고·링크·대화 맥락과 함께 기록
- 예약을 실제 체험으로 계산하지 않음
- 체크인을 실제 참여로 자동 확정하지 않음
- 계약 동의를 실정산으로 계산하지 않음
- 한 실정산을 여러 게시물·채널·지점에 중복 귀속하지 않음
- 환불·차지백을 순수납에서 차감
- 직접·보조 접점은 별도로 표시

## 9. 채널별 측정 역할

### Instagram 코치 개인 계정

- 전문성·친근함·질문·저장 행동을 관찰
- 지점 공식 발표나 전체 도장의 운영 성과로 확대하지 않음
- 게시물별 URL·형식·CTA를 보존

### 네이버

- 검색 유입, 콘텐츠 조회, 공식 문의 경로를 분리
- 블로그·플레이스·예약의 식별자를 구분
- 검색 노출을 방문·등록으로 계산하지 않음

### 당근

- 노출·조회·채팅·단골·쿠폰·예약을 구분
- 채팅 시작을 유효 문의나 실방문으로 자동 계산하지 않음

### Google 비즈니스 프로필

- 조회·검색·전화 클릭·길찾기·웹사이트 클릭·예약을 분리
- 지점별 프로필과 기간을 구분
- 전화 클릭은 통화 연결이 아니며 길찾기는 방문이 아님

## 10. UTM·콘텐츠 식별

웹 링크가 연결된 콘텐츠는 사전 승인된 소문자 명명 규칙을 사용한다.

- `utm_source`: 플랫폼
- `utm_medium`: 채널 유형
- `utm_campaign`: 캠페인
- `utm_content`: 콘텐츠 ID·버전·CTA 구분

대소문자·띄어쓰기·철자 차이로 같은 캠페인이 여러 행으로 갈라지지 않도록 한다. UTM 클릭은 문의·예약·등록이 아니라 유입 증거다.

## 11. 실험

### EXP-432 — 소표본 콘텐츠 성과·사업 전환 판정 정확도

- 대상: 합성 콘텐츠 600건, 플랫폼 사건 24,000건, 문의·예약·출석·계약·정산 사건 6,000건
- 성공 조건: 아래 오류가 모두 0건
  - 조회를 고유 도달로 계산
  - 게시물별 도달을 계정 고유 인원으로 단순 합산
  - 분자·분모·기간·원천 없는 비율 생성
  - 빈 값·`-`·미지원을 0으로 변환
  - 최소 분모 미연결 상태에서 승자 판정
  - 1건의 반응으로 콘텐츠 방향·광고 확대 결정
  - 프로필 행동을 문의·방문으로 계산
  - 예약·체크인을 실제 체험으로 계산
  - 계약 동의를 실정산으로 계산
  - 신규·복귀·재등록을 중복 계산
  - 한 매출을 여러 콘텐츠·채널·지점에 중복 귀속
  - 환불·차지백을 순수납에서 누락
- 중단 조건: 오류가 하나라도 발생하면 자동 승자 선정, 광고 확대, 고객 발송 및 콘텐츠별 매출 보고를 중단
- 현재 최소 분모·관찰기간·사업 전환 원장: 데이터 미연결

## 14. Auditor 결론

- 공개 플랫폼 지표와 내부 사업 성과를 분리했다.
- 외부 벤치마크를 내부 최소 표본 기준으로 자동 적용하지 않았다.
- 0·결측·미지원·조회 실패·계산 불가를 구분했다.
- 승인 대기 콘텐츠, 개인정보, 연락처, 출석·건강·결제 원장을 포함하지 않았다.
- 조회·도달·반응을 문의·등록·매출로 과장하지 않았다.
