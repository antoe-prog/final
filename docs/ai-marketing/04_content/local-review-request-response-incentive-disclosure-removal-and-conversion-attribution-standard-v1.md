# 지역 후기 요청·응답·인센티브·신고·삭제·전환 귀속 기준 v1

- 문서 상태: 공개 가능한 마케팅·운영 기준
- 기준일: 2026-09-18
- 적용 조직: 파이널유도멀티짐
- 적용 채널: 네이버 플레이스, Google 비즈니스 프로필·지도, 당근, Instagram, 자체 만족도 조사
- 적용 목표: 신규 체험 신뢰, 휴면 복귀, 기존회원 만족·재등록, 매출 귀속 정확도
- 공개 제외: 리뷰어·회원·보호자 식별정보, 연락처, 개인별 수업·상담·건강·결제 원장, 계정 권한, 내부 손익자료
- 내부 후기 요청·게시·문의·등록·매출 데이터: **데이터 미연결**
- 원칙: 후기 수와 별점을 체험·등록·재등록·매출로 자동 해석하지 않는다.

## 1. 핵심 판단

지역 후기 운영의 목적은 높은 별점을 인위적으로 만드는 것이 아니라 **실제 경험에 기반한 자발적 의견을 편향 없이 받을 수 있게 하고, 공개 응답과 내부 개선을 연결하는 것**이다.

다음 사건을 분리한다.

`후기 요청 대상 판정 → 요청 승인 → 요청 발송 → 링크 열람 → 후기 작성 시작 → 플랫폼 게시 → 공개 노출 확인 → 사업자 응답 → 문제 해결 → 문의 → 체험 예약 → 실제 참여 → 등록 → 실수납`

- 후기 요청 대상은 실제 발송이 아니다.
- 발송은 링크 열람이 아니다.
- 링크 열람은 후기 작성이 아니다.
- 후기 작성은 플랫폼 공개 노출이 아니다.
- 공개 후기는 긍정 후기나 추천 의사가 아니다.
- 후기 게시자는 신규 문의자가 아니다.
- 별점 상승은 신규 등록이나 매출 증가가 아니다.
- 후기 삭제 요청은 삭제 완료가 아니다.

## 2. 기존 기준과 경계

이 문서는 다음 기존 기준을 대체하지 않는다.

- 다채널 문의 기준: 문의 수신·중복·응답·예약
- 지역 프로필·UTM 기준: 지점 링크·클릭·길찾기·전화·예약 귀속
- 촬영물 동의 기준: 회원 사진·영상의 촬영·공개·철회
- 체험 후 미등록 기준: 참석 이후 후속과 등록
- 추천 프로그램 기준이 있는 경우: 추천인·피추천인·혜택·매출
- 불만·안전사건 기준: 안전·건강·아동보호·환불·분쟁 인계

이번 기준은 공개 후기의 요청·응답·인센티브·신고·성과 귀속만 다룬다.

## 4. 플랫폼 정책 게이트

### 4.1 Google

Google 지도 후기에는 다음 원칙을 적용한다.

- 실제 경험에 기반하지 않은 후기를 요청하지 않는다.
- 현금·할인·무료 상품·무료 서비스 등 대가와 후기를 교환하지 않는다.
- 부정 후기의 수정·삭제와 보상을 교환하지 않는다.
- 긍정 후기를 쓸 가능성이 높은 사람만 골라 요청하지 않는다.
- 특정 별점이나 특정 문구를 요구하지 않는다.
- 현장에서 압박하거나 직원별 후기 할당량을 두지 않는다.
- 직원·가족·계약관계자·경쟁업체 등 이해충돌 가능성이 있는 리뷰를 일반 고객 후기처럼 만들지 않는다.

실제 경험자가 대가 없이 자발적으로 후기와 별점을 결정하도록 요청하는 것은 가능하다.

### 4.2 네이버

네이버 후기에는 실제 방문·이용과 연결된 플랫폼 절차를 우선한다.

- 플랫폼의 최신 작성·노출·신고 절차를 임의로 우회하지 않는다.
- 영수증·예약·방문 인증을 직원이 대신 생성하지 않는다.
- 회원 계정을 빌리거나 여러 계정으로 동일 후기를 반복 작성하지 않는다.
- 회원에게 특정 문구·별점·사진을 강요하지 않는다.
- 사업주가 불편한 후기라는 이유만으로 정책 위반이라고 단정하지 않는다.
- 권리침해·개인정보·욕설·스팸 등 신고 사유와 단순한 의견 불일치를 분리한다.

네이버의 구체적 작성 자격·인증 방식·신고 UI는 실행 시점의 공식 도움말과 실제 계정 화면을 다시 확인한다.

### 4.3 당근

당근의 지역 후기·채팅·게시물 반응은 서로 분리한다.

- 이웃의 게시물 반응이나 채팅을 후기 게시로 계산하지 않는다.
- 지역 인증 상태를 실제 방문이나 회원 등록으로 해석하지 않는다.
- 지역 게시물에 허위 후기·후기 대가·대리 작성을 요청하지 않는다.
- 채팅에서 민감한 회원정보나 분쟁 세부내용을 공개하지 않는다.
- 최신 서비스별 후기·광고 정책은 실행 전 공식 안내에서 재확인한다.

### 4.4 Instagram @ant.toe.98

@ant.toe.98는 코치 개인 계정으로 운영한다.

- 도장 공식 고객센터나 후기 분쟁 창구로 표현하지 않는다.
- 댓글·DM의 칭찬을 공식 회원 후기처럼 재게시하지 않는다.
- 회원 경험을 캡처·공개하려면 별도의 공개 사용 동의를 확인한다.
- 댓글·저장·공유를 네이버·Google 후기로 계산하지 않는다.
- 승인 전 패키지에 확인되지 않은 회원 변화·성과·추천 발언을 넣지 않는다.

## 5. 후기 요청 자격

### 5.1 기본 자격

후기 요청 후보는 다음을 모두 충족해야 한다.

- 실제 체험 또는 회원 이용이 승인된 원천에서 확인됨
- 본인 또는 권한이 확인된 보호자
- 올바른 지점·서비스와 연결됨
- 중복 요청 방지 기간을 충족
- 연락 목적·채널·동의 상태가 유효
- 수신거부·연락중단·분쟁 보류 상태가 아님
- 안전·건강·아동보호·환불 사건이 우선 인계 상태가 아님

후보 판정은 발송 승인이 아니다.

### 5.2 금지되는 선별

다음 기준으로 요청 대상을 고르지 않는다.

- 높은 만족도 점수를 준 사람만 선택
- 칭찬한 사람만 선택
- 불만을 제기하지 않은 사람만 선택
- 특정 코치와 친한 회원만 선택
- 재등록한 회원만 선택
- 할인·선물 수락 의사가 있는 사람만 선택
- 부정 후기 작성 가능성을 이유로 제외
- 별점 변경 의사를 먼저 확인한 뒤 요청

이와 같은 방식은 후기 게이팅 또는 편향된 요청이 될 수 있다.

### 5.3 요청 빈도

- 요청 횟수·간격·채널 상한을 대표가 승인한다.
- 같은 이용 사건에 여러 지점·코치·채널이 중복 요청하지 않는다.
- 발송 실패를 무제한 재시도하지 않는다.
- 후기 미작성자를 부정적 고객으로 분류하지 않는다.
- 후기 작성 여부를 수업·승급·재등록 혜택과 연결하지 않는다.

## 6. 인센티브와 이해관계

### 6.1 내부 기본 원칙

파이널유도멀티짐은 플랫폼별 차이를 좁게 해석하지 않고, 공개 후기의 신뢰를 보호하기 위해 다음을 내부 기본값으로 둔다.

- 공개 후기 작성의 대가로 현금·할인·무료 수업·상품·포인트·추첨권을 제공하지 않는다.
- 긍정 후기의 대가를 제공하지 않는다.
- 부정 후기 수정·삭제의 대가를 제공하지 않는다.
- 후기 수 또는 별점과 직원 보상을 직접 연결하지 않는다.
- 직원·가족·대행사·협력사의 이해관계 후기를 일반 고객 후기처럼 운영하지 않는다.

### 6.2 만족도 조사와 보상

비공개 만족도 조사에 보상을 제공하려면 다음을 분리한다.

- 보상은 응답 완료 자체에 대해 제공
- 긍정·부정 답변과 보상액이 무관
- 공개 후기 작성은 선택사항
- 공개 후기 링크를 보상 조건으로 사용하지 않음
- 개인정보·세금·경품 규정 검토
- 실제 지급과 비용 원장을 별도 기록

비공개 설문 보상을 공개 후기 보상으로 확장하지 않는다.

### 6.3 추천 프로그램과 구분

회원 추천 혜택은 공개 후기 작성과 묶지 않는다.

- 추천 코드 사용
- 피추천인의 체험
- 실제 등록
- 실수납
- 혜택 승인
- 혜택 지급

위 사건은 공개 후기와 별도 원장으로 관리한다.

## 7. 후기 요청 문구 원칙

요청 문구에는 다음을 포함한다.

- 실제 이용 경험에 대한 자발적 의견 요청
- 긍정·부정 여부와 무관함
- 작성 여부가 서비스·혜택에 영향을 주지 않음
- 특정 별점·문구·사진을 요구하지 않음
- 올바른 지점 링크
- 문의·불편 해결 경로가 필요한 경우 별도 안내

피해야 할 문구:

- “별점 5점 부탁드립니다”
- “좋은 후기만 남겨주세요”
- “후기 인증하면 할인”
- “사진 3장과 특정 키워드를 넣어주세요”
- “낮은 별점이면 먼저 연락 주세요”
- “후기를 삭제하면 환불해 드립니다”
- “코치 이름을 꼭 써 주세요”

실제 발송 문구와 시점은 대표 승인 후 확정한다. 이 문서는 발송 승인이 아니다.

## 8. 공개 답글 기준

### 8.1 모든 답글

- 짧고 구체적으로 작성한다.
- 확인되지 않은 사실을 단정하지 않는다.
- 회원 여부·수업일·결제·출석·건강정보를 공개하지 않는다.
- 미성년자 이름·학교·나이·보호자 관계를 공개하지 않는다.
- 같은 답글을 대량 복사하지 않는다.
- 할인·쿠폰·재등록 압박을 넣지 않는다.
- 코치 개인 계정과 공식 사업자 계정의 말하는 주체를 구분한다.

### 8.2 긍정 후기

- 감사 표현과 구체적 피드백 수용을 중심으로 한다.
- 회원의 실력 향상·체중 변화·대회 성과를 추가로 만들어내지 않는다.
- 재등록·추천·지인 초대를 압박하지 않는다.
- 후기를 광고 소재로 재사용하려면 별도 권리·동의를 확인한다.

### 8.3 부정 후기

- 감정적 반박이나 공개 논쟁을 하지 않는다.
- 상대방의 신원·이용기록을 공개하지 않는다.
- 확인 가능한 사실과 현재 확인 중인 사항을 구분한다.
- 사과가 필요한 경우 범위를 명확히 한다.
- 복잡한 사안은 승인된 비공개 경로로 전환한다.
- 안전·아동보호·차별·폭력·건강·결제 분쟁은 지정 책임자에게 즉시 인계한다.
- 후기 수정·삭제를 문제 해결의 조건으로 요구하지 않는다.

| UNKNOWN | 원천·상태 확인 불가 | 0건 |

단순히 마음에 들지 않거나 의견이 다르다는 이유로 신고하지 않는다.

삭제 후에도 캡처·검색 캐시·제3자 공유가 남을 수 있으므로 “인터넷에서 완전 삭제”라고 주장하지 않는다.

## 10. 비공개 운영 원장

- 지점·이용 사건
- 요청 자격 근거
- 연락 동의·수신거부 상태
- 승인자·승인일
- 요청 채널·문구 버전
- 발송·실패·열람 상태
- 플랫폼·프로필
- 후기 URL 또는 플랫폼 식별자
- 공개 확인 시각
- 별점·텍스트 수집 여부와 허용 근거
- 답글 상태·승인자
- 신고·이의제기·결정 상태
- 문의·체험·등록·수납 연결 근거
- 보유기간·파기 상태

후기 원문과 개인정보를 공개 GitHub에 복사하지 않는다.

별점 평균은 분포·기간·후기 수·플랫폼을 함께 표시한다. 표본이 작으면 지점·코치 순위를 만들지 않는다.

현재 파이널유도의 후기 요청·게시·공개·응답·신고·후기 귀속 문의·체험·등록·매출은 **데이터 미연결**이다.

## 12. 네 가지 목표별 활용

### 신규 체험회원 확보

- 지점별 실제 후기 링크와 랜딩을 구분한다.
- 후기 요청보다 먼저 지점 정보·시간표·문의 경로의 최신성을 확인한다.
- 공개 후기를 신뢰 보조 신호로만 사용하고 체험 전환을 별도 측정한다.
- 리뷰어 신원이나 후기 원문을 광고 타기팅에 사용하지 않는다.

### 휴면회원 복귀

- 과거 회원에게 복귀 메시지와 후기 요청을 한 번에 보내지 않는다.
- 휴면회원의 과거 후기를 현재 만족도로 간주하지 않는다.
- 복귀 후 실제 이용 사건 없이 새 후기를 요청하지 않는다.
- 복귀를 신규회원으로 중복 집계하지 않는다.

### 기존회원 만족·재등록

- 공개 후기보다 비공개 문제 해결을 우선한다.
- 후기 미작성과 재등록 의사를 연결하지 않는다.
- 부정 후기를 재등록 실패의 단일 원인으로 단정하지 않는다.
- 반복 불만 주제를 비식별 집계해 운영 개선에 사용한다.

### 매출 증대

- 별점·후기 수를 매출로 환산하지 않는다.
- 후기 링크·문의·예약·출석·등록·실수납을 단계별로 연결한다.
- 리뷰 대행비·경품·광고비가 있으면 직접비용을 별도 기록한다.
- 환불·혜택·대행 수수료를 반영하지 않은 총수납을 순매출로 표시하지 않는다.

## 13. 채널별 콘텐츠 실행

### 네이버

- 지점별 최신 운영정보와 실제 이용자가 궁금해하는 준비물·수업방식 FAQ를 우선한다.
- 후기 원문을 허락 없이 블로그 콘텐츠로 복제하지 않는다.
- 지점별 후기 수·별점을 수동으로 합산해 전체 브랜드 평점처럼 표현하지 않는다.
- 권리침해 신고와 일반 의견 불일치를 분리한다.

### Google

- 실제 경험자에게 대가 없이 동일한 원칙으로 요청한다.
- Google이 제공하는 리뷰 링크·QR 경로를 사용할 수 있으나, 링크 생성과 실제 배포는 계정 권한·대표 승인 후 진행한다.
- 공개 답글은 개인정보 없이 짧고 관련성 있게 작성한다.
- 정책 위반 가능성이 있는 후기만 신고한다.

### 당근

- 동네 후기·채팅 반응·광고 클릭을 분리한다.
- 지역 회원 후기처럼 보이는 운영자 작성물을 만들지 않는다.
- 가격·혜택·무료 체험이 미확정이면 후기 답글이나 홍보글에 넣지 않는다.

### Instagram

- 코치 개인의 설명 콘텐츠와 회원 후기를 구분한다.
- 실제 회원 발언·변화·실적은 근거와 공개동의 없이는 만들지 않는다.
- 후기 캡처를 캐러셀에 넣을 경우 별도 승인 패키지로 제작하고 게시 승인을 받는다.
- 현재 승인 대기 콘텐츠를 후기 캠페인으로 변경하지 않는다.

## 17. 근거 출처

- Google 지도 사용자 생성 콘텐츠 정책은 실제 경험에 기반하지 않은 후기, 금전·할인·무료 상품·서비스와 교환한 후기, 부정 후기 수정·삭제와 대가를 교환하는 행위, 긍정 후기의 선택적 요청과 특정 문구·별점 압박을 금지한다. [Google Maps 금지·제한 콘텐츠](https://support.google.com/contributionpolicy/answer/7400114?hl=en)
- Google은 실제 고객에게 리뷰 링크나 QR 코드를 안내할 수 있지만 대가 제공은 금지하며, 긍정·부정 후기를 함께 가치 있게 다루고 개인정보 없이 전문적으로 답글을 작성하라고 안내한다. [Google 리뷰 요청·응답 도움말](https://support.google.com/business/answer/3474122?hl=en)
- Google은 정책을 위반한 후기만 삭제 대상이 될 수 있으며, 단순히 동의하지 않거나 마음에 들지 않는다는 이유로 신고해서는 안 된다고 안내한다. [Google 부적절한 후기 신고](https://support.google.com/business/answer/4596773?hl=en)
- 네이버 스마트플레이스 사업주 고객센터는 방문자 리뷰 권리침해 신고와 플레이스 문의 경로를 제공한다. 실제 신고 자격과 절차는 실행 시 최신 화면에서 재확인한다. [네이버 스마트플레이스 사업주 고객센터](https://help.naver.com/alias/smartplace/smartplace_2.naver)

## 18. Auditor 결론

후기는 마케팅 자산이기 전에 실제 이용자의 공개 의견이다.

1. 실제 경험자에게만 요청한다.
2. 긍정·부정 여부와 무관한 동일 기준을 적용한다.
3. 후기와 보상을 교환하지 않는다.
4. 특정 별점·문구·삭제를 요구하지 않는다.
5. 공개 답글에서 개인정보를 밝히지 않는다.
6. 신고·삭제·문제 해결을 서로 다른 상태로 기록한다.
7. 후기·별점·문의·체험·등록·실수납을 분리한다.
8. 플랫폼 기능 제공을 내부 연결 완료나 성과로 간주하지 않는다.
