# Instagram AI 생성 미디어 표시·출처·코치 진정성 기준 v1

- 적용 조직: 파이널유도멀티짐 공개 마케팅 실무
- 우선 적용 계정: 코치 개인 Instagram
- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-15
- 포함하지 않는 정보: 회원 식별정보, 연락처, 출석·건강·결제 원장, 비밀키, 미확정 행사·가격·혜택, 승인 대기 게시물의 미디어·캡션

## 1. 목적

AI 생성 이미지와 실제 촬영물을 명확히 구분하면서도 코치 개인 계정의 전문성과 친근함을 지키는 기준이다.

핵심 목표는 다음 네 가지다.

1. 생성 이미지가 실제 코치·회원·시설·수업처럼 오인되는 일을 막는다.
2. 게시 전 미디어 출처와 변경 이력을 재현할 수 있게 한다.
3. 플랫폼의 AI 표시 기능과 자체 캡션 고지를 구분해 판단한다.
4. 콘텐츠 반응을 문의·체험·등록·재등록 성과와 혼합하지 않는다.

이 기준은 AI 이미지 사용을 일괄 금지하거나 권장하지 않는다. 정보 전달에 필요한 일러스트와 실제 경험을 증명해야 하는 촬영물의 역할을 구분한다.

## 2. 적용 원칙

### 2.1 계정 주체

- 코치 개인 계정은 코치의 수련 기록, 지도 경험, 유도에 대한 관점과 일상을 중심으로 운영한다.
- 도장 공식 발표, 전 지점 공통 정책, 확정되지 않은 가격·시간표·행사를 코치 개인의 확정 사실처럼 말하지 않는다.
- 실제 코치의 경험이나 발언은 제공된 원자료가 있을 때만 1인칭으로 쓴다.
- 생성 이미지 속 인물이나 공간을 실제 코치·회원·도장이라고 부르지 않는다.

### 2.2 투명성

- 플랫폼이 자동으로 표시할 것이라고 가정하지 않는다.
- 플랫폼 표시가 없다고 실제 촬영물로 간주하지 않는다.
- 생성형 AI를 사용했다는 사실과 콘텐츠의 사실 정확성은 별도 검토한다.
- “AI Info” 등 플랫폼 표시는 면책이나 사실 인증이 아니다.

### 2.3 최소 오인

- 필요한 정보는 가장 낮은 오인 위험의 표현 방식으로 제작한다.
- 실제 수업 분위기, 시설 상태, 코치 얼굴, 회원 변화처럼 현실 증명이 필요한 주제는 실제 원본을 우선한다.
- 개념 설명, 도복 구조, 입문 질문처럼 실제 장면을 주장할 필요가 없는 주제는 명시적인 일러스트를 사용할 수 있다.
- 존재하지 않는 후기, 대회 실적, 신체 변화, 치료 효과, 수업 장면을 합성하지 않는다.

## 3. 미디어 유형 분류

모든 게시 후보는 아래 유형 중 하나를 지정한다.

| 코드 | 유형 | 정의 | 기본 오인 위험 | 기본 처리 |
|---|---|---|---|---|
| M0 | 원본 실사 | 카메라로 촬영했고 생성·합성 변경이 없음 | 중간 | 촬영 주체·동의·장소 확인 |
| M1 | 경미 편집 실사 | 밝기, 색, 자르기, 노출, 단순 잡티 등 내용 의미를 바꾸지 않는 편집 | 중간 | 원본 보존·편집 범위 기록 |
| M2 | 내용 변경 편집 | 배경 교체, 인물·사물 추가·삭제, 동작·표정·도복·시설 상태 변경 | 높음 | 변경 부위·목적 공개 검토 |
| M3 | 비사실적 AI 일러스트 | 실제 사진처럼 보이지 않는 도식·그림·질감·캐릭터 | 낮음~중간 | 일러스트 표기와 사실 검수 |
| M4 | 사실적 AI 합성 | 실제 촬영처럼 보이는 인물·공간·수업·제품 이미지 | 매우 높음 | 원칙적 보류, 예외 승인 필요 |
| M5 | 혼합 | 실사와 생성 요소가 한 미디어에 함께 존재 | 높음 | 각 요소의 출처·경계 기록 |
| M6 | 출처 불명 | 원본·권리·생성 여부를 확인할 수 없음 | 매우 높음 | 게시 금지 |

### 3.1 영상·음성

영상과 음성에도 같은 분류를 적용한다.

- 실제 코치의 음성처럼 들리는 합성 음성은 M4로 본다.
- 실제 코치가 하지 않은 말을 한 것처럼 만드는 합성은 게시하지 않는다.
- 속도 조절, 자막, 무음 구간 제거는 의미를 바꾸지 않으면 M1로 기록할 수 있다.
- 동작 궤적이나 자세를 바꾸는 생성 편집은 M2 또는 M5다.

| 코치 수련 기록 | M0·M1 | 실제 날짜·장소·맥락 원자료 | 합성 수련 장면 |

| 시설 소개 | 최신 M0·M1 | 촬영 지점·검증일 기록 | 합성 시설을 실제처럼 표현 |

| 안전·건강 안내 | 검증된 M0·M1·M3 | 교육 범위·출처·한계 표시 | 진단·치료 효과 암시 |
| 행사·가격·혜택 | 승인된 실제 자료 | 확정 원천과 유효기간 확인 | 미확정 정보를 시각화해 공개 |

## 5. 플랫폼 표시와 자체 고지

### 5.1 Meta 정책에서 확인할 점

Meta는 다음 두 경로를 통해 AI 관련 표시를 적용할 수 있다고 설명한다.

1. 업로드 파일에서 업계 공통 AI 신호를 탐지하는 경우
2. 게시자가 AI 생성 콘텐츠임을 직접 공개하는 경우

또한 Meta는 AI로 생성된 콘텐츠와 AI 도구로 단순 수정·편집된 콘텐츠의 표시 위치를 다르게 운영한다고 설명한다. 따라서 운영자는 다음을 지킨다.

- 파일의 메타데이터가 항상 유지되거나 탐지될 것이라고 가정하지 않는다.
- 편집 정도가 작다는 이유만으로 원본·편집 기록을 생략하지 않는다.
- 작성 도구에 AI 관련 선택 항목이 보인다는 사실을 실제 게시 표시 성공으로 기록하지 않는다.
- 게시 전 최신 작성 화면에서 선택 항목과 설명을 다시 확인한다.
- 게시 후 공개 화면에서 실제 표시 여부를 별도로 검증한다.

### 5.2 자체 고지 수준

플랫폼 표시와 별개로 다음 원칙을 사용한다.

| 상황 | 캡션 또는 이미지 자체 고지 |
|---|---|
| M3이며 누구나 그림으로 인식 가능 | “개념 일러스트” 등 짧은 표현을 패키지 메모·대체 텍스트에 포함 |
| M3이지만 실제 도복·시설로 오인 가능 | 캡션에 “설명을 위한 일러스트” 명시 |
| M2·M5 | 어떤 요소가 변경·생성됐는지 이해 가능한 말로 명시 |
| M4 | 예외 승인 없이는 게시하지 않음. 승인 시 사실적 생성물임을 눈에 띄게 명시 |
| M6 | 고지로 보완하지 않고 게시 금지 |

자체 고지는 해시태그 뒤에 숨기거나 모호한 약어만 쓰지 않는다.

## 6. 출처·변경 이력 기록

공개 게시 전 비공개 작업 기록에 다음 필드를 남긴다.

| 필드 | 내용 |
|---|---|
| WORK_ID | 게시물 고유 ID |
| VERSION | 승인 대상 버전 |
| ACCOUNT | 대상 계정 |
| MEDIA_ORDER | 업로드 순서 |
| MEDIA_TYPE | M0~M6 |
| SOURCE_OWNER | 촬영자·제작자 또는 사용 도구 |
| SOURCE_DATE | 촬영·생성·수령일 |
| SOURCE_PATH | 원본을 찾을 수 있는 비공개 위치 |
| SOURCE_HASH | 게시 원본의 SHA-256 |
| EDIT_HISTORY | 자르기·색·합성·생성 등 변경 내역 |
| REALITY_CLAIM | 실제 인물·장소·날짜·수업 주장 여부 |
| CONSENT_STATUS | 등장 인물의 공개 동의 상태 |
| RIGHTS_STATUS | 사용 권리 확인 상태 |
| DISCLOSURE_DECISION | 플랫폼 선택·자체 고지 판단과 이유 |
| FACT_SOURCE | 규칙·건강·상품·행사 주장의 근거 |
| APPROVAL_STATUS | 제작 중·승인 대기·승인 완료·게시 완료 |
| PUBLISHED_URL | 게시 후 실제 공개 URL |

회원·보호자 식별정보와 동의서 원문은 공개 저장소에 넣지 않는다. 공개 문서에는 절차와 비식별 상태만 남긴다.

## 7. 승인 전 10단계 게이트

1. 계정 주체를 코치 개인으로 확인한다.
2. 게시 목적과 CTA 한 가지를 정한다.
3. 각 미디어를 M0~M6로 분류한다.
4. 원본·권리·SHA-256을 기록한다.
5. 실제 인물·시설·경험 주장 여부를 표시한다.
6. 인물 공개 동의와 민감정보 노출을 확인한다.
7. 기술·규정·건강·상품·운영 주장의 근거를 확인한다.
8. 플랫폼 표시와 자체 고지 결정을 각각 기록한다.
9. 최종 이미지 순서·캡션·대체 텍스트를 한 버전으로 잠근다.
10. 대표에게 완성본을 보여주고 해당 버전의 게시 승인을 받는다.

승인 전에는 Instagram 또는 외부 게시 도구로 파일을 업로드하거나 초안 저장·예약·발행하지 않는다.

## 8. 게시 후 검증

게시 완료는 버튼 클릭이나 예약 등록으로 판정하지 않는다.

다음을 확인한다.

- 정확한 대상 계정
- 실제 공개 URL
- 캐러셀 장수와 순서
- 이미지·영상의 승인본 일치
- 캡션과 해시태그의 승인본 일치
- 플랫폼의 AI 관련 표시 노출 여부
- 자체 고지의 공개 노출 여부
- 중복 게시 부재

플랫폼이 예상과 다른 표시를 적용한 경우 원본을 삭제하거나 다시 게시하기 전에 영향과 중복 위험을 먼저 검토한다.

## 9. 코치 진정성 포트폴리오

생성 일러스트만으로 계정을 채우지 않는다. 실제 코치 맥락이 확인될 때 다음 포트폴리오를 순환한다.

1. 코치 단독 수련 또는 준비 장면
2. 손·발·도복·매트 중심의 기술 포인트
3. 실제 지도 장면과 설명 포인트
4. 입문자의 질문을 푸는 일러스트
5. 도복·규칙·예절 등 유도 상식
6. 확인된 코치 경험과 관점
7. 동의가 확인된 커뮤니티 장면

원자료가 없는 코치 경험은 촬영 제안이나 작성 질문으로 남기고 실제 경험처럼 만들지 않는다.

### 9.1 건강한 표현

- 몸의 크기·외형을 실력·성실성·가치의 증거로 단정하지 않는다.
- 통증 무시, 과도한 훈련, 극단적 식단을 의지나 남성성의 기준으로 미화하지 않는다.
- 생성된 이상적 체형을 실제 훈련 결과처럼 보여주지 않는다.
- 기술 학습, 안전한 참여, 이해, 과정과 관계를 중심으로 설명한다.

2026년 6월 공개된 #GymTok 연구는 TikTok의 근육 지향 콘텐츠 2,210건을 분석했으며, 더 극단적인 근육 표현과 전문가가 더 유해하다고 평가한 콘텐츠가 높은 참여와 연관됐다고 보고했다. 이 연구는 TikTok 자료이며 유도나 Instagram의 직접 성과 근거가 아니다. 여기서는 외형 중심 콘텐츠의 브랜드·건강 위험을 검토하는 보조 근거로만 사용한다.

## 10. 채널별 재사용 규칙

### Instagram

- 코치 개인의 말투와 주체를 유지한다.
- M3 일러스트는 설명 콘텐츠에 사용하고 실제 현장 증명용으로 쓰지 않는다.
- 게시별 승인 잠금을 지킨다.

### 네이버

- 실제 시설·시간표·지도·가격은 최신 승인 원천과 대조한다.
- 일러스트로 실제 지점 사진을 대체하지 않는다.
- AI가 작성한 문구라도 사실 원천과 검증일을 남긴다.

### 당근

- 지역 주민이 실제 장소·운영 조건으로 이해할 수 있는 정보는 실사와 승인 정보를 우선한다.
- 생성된 이벤트 장면이나 회원 모습을 실제 개최 사례처럼 쓰지 않는다.
- 채팅·쿠폰·예약 기능의 실제 활성 여부를 추정하지 않는다.

## 11. KPI와 퍼널

미디어 투명성 지표와 사업 성과 지표를 분리한다.

### 11.1 운영 품질

- 미디어 유형 분류율 = 분류 완료 미디어 수 / 게시 후보 미디어 수
- 원본·해시 기록률 = 원본과 해시가 있는 미디어 수 / 게시 후보 미디어 수
- 표시 결정 기록률 = 플랫폼·자체 고지 결정 완료 게시물 수 / 게시 후보 수
- 승인본 일치율 = 승인본과 공개본이 일치한 게시물 수 / 게시 완료 수
- 현실 오인 사고 수 = 실제가 아닌 인물·시설·경험을 실제로 오인하게 한 확인 사고 수

분모가 0이거나 데이터가 연결되지 않으면 계산하지 않는다.

### 11.2 콘텐츠 성과

- 저장
- 공유
- 댓글
- 프로필 방문

## 12. 실험 설계

### EXP-325 — AI 미디어 출처·표시·진정성 판정 완전성

- 목적: 생성·편집·실사 미디어가 승인과 게시 과정에서 정확히 구분되는지 검증
- 1단계 대상: 합성 작업 레코드로 만든 건식 게시 후보 6건
- 2단계 대상: 대표 승인 후 실제 게시 후보 최대 6건
- 대조 단위: 게시물과 각 미디어 파일
- 변경 변수: 미디어 유형과 고지 판단 기록 방식

#### 성공 기준

- 미디어 유형 분류율 100%
- 원본·권리·해시 기록률 100%
- 플랫폼 표시와 자체 고지 판단 분리율 100%
- 승인본과 실행 후보본 일치율 100%
- 생성 인물·시설·경험의 실사 오인 0건
- 무동의 회원 미디어 사용 0건
- 미확정 가격·행사·성과 노출 0건

#### 보류 조건

- 원본 또는 권리 확인 불가
- 동의 상태 미확인
- 플랫폼 작성 화면의 최신 선택 항목 미확인
- 승인 대상 미디어·캡션 버전 불일치

#### 중단 조건

- M6 미디어가 게시 후보에 포함됨
- 합성 코치 발언·수련·시설을 실제로 표현함
- AI 표시가 곧 사실 인증이라고 보고함
- 승인 전 외부 업로드·예약·발행이 발생함

## 17. 감사 결론

AI 생성 일러스트는 설명 효율을 높일 수 있지만, 코치 개인 계정의 핵심 증거인 실제 수련·지도·사람·공간을 대신할 수 없다. 가장 중요한 통제는 “AI를 썼는가” 하나가 아니라, 무엇이 실제이고 무엇이 생성·변경됐는지, 그 판단 근거와 승인 버전을 다시 확인할 수 있게 만드는 것이다.
