# 소셜 콘텐츠 접근성·대체 텍스트·자막·가독성·대비·포용 표현 기준 v1.4

- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-20
- 적용 범위: Instagram, 네이버, 당근, 웹사이트 및 파생 소셜 콘텐츠
- 사업 성과 상태: 신규 체험·휴면 복귀·재등록·실수납·순수납 데이터 미연결

## 1. 목적

콘텐츠의 접근성 준비와 실제 플랫폼 설정을 구분하고, 이미지·영상·캡션이 핵심 의미를 놓치지 않도록 한다. 접근성 품질을 조회·문의·예약·등록·매출 성과로 오인하지 않는다.

## 2. 핵심 판단

1. 대체 텍스트를 문서에 작성한 상태와 플랫폼에 입력한 상태, 공개 게시물에서 확인한 상태는 서로 다르다.
2. 캐러셀은 각 장의 역할과 읽는 순서가 다르므로 장별 대체 텍스트를 준비한다.
3. 정적 이미지 안의 작은 글자도 내부 시각 품질 검수 대상으로 본다.
4. 색상은 의미 전달의 유일한 수단으로 사용하지 않는다.
5. 자동 자막과 자동 대체 텍스트는 초안 또는 보조 기능일 수 있으므로 정확성 검수가 필요하다.
6. 접근성 기준 충족을 의료 효과, 안전 보장, 법적 적합성 인증 또는 사업 성과로 표현하지 않는다.

## 3. 상태 모델

| 상태 | 의미 | 허용 표현 |
|---|---|---|
| `ALT_NOT_PREPARED` | 대체 텍스트가 아직 없음 | 준비 전 |
| `ALT_PREPARED` | 장별 대체 텍스트 문안만 완성 | 대체 텍스트 준비 완료 |
| `ALT_PLATFORM_SET` | 플랫폼 편집 화면에 입력하고 저장 결과를 확인 | 플랫폼 설정 완료 |
| `ALT_PUBLISHED_VERIFIED` | 공개 게시물에서 설정 결과를 다시 확인 | 공개 검증 완료 |
| `ALT_UNSUPPORTED` | 해당 게시 경로가 기능을 제공하지 않음을 확인 | 기능 미지원 확인 |
| `ALT_UNVERIFIED` | 기능 또는 저장 결과를 확인하지 못함 | 설정 여부 미확인 |
| `ALT_REMEDIATION_IDENTIFIED` | 공개 후 자동 설명 오류 또는 수동 입력 누락을 확인하고 보정 문안을 준비 | 보정 필요·문안 준비 |
| `ALT_REMEDIATION_APPROVED` | 계정 소유자가 특정 게시물·장별 문안·변경 범위를 승인 | 보정 승인 완료 |
| `ALT_REMEDIATION_APPLIED_UNVERIFIED` | 승인 문안을 저장했으나 재진입 또는 공개 결과 확인이 끝나지 않음 | 적용 후 검증 대기 |
| `ALT_REMEDIATION_VERIFIED` | 저장 성공과 장별 값 유지, 비대상 항목 무변경을 확인 | 게시 후 보정 검증 완료 |

다음 전환은 금지한다.

- 문안 작성만으로 `ALT_PLATFORM_SET` 처리
- 업로드 성공만으로 `ALT_PUBLISHED_VERIFIED` 처리
- 플랫폼 자동 설명을 사람이 검수한 대체 텍스트로 처리
- 기능 위치를 찾지 못한 상태를 `ALT_UNSUPPORTED`로 처리
- 편집 화면 진입만으로 `ALT_REMEDIATION_APPLIED_UNVERIFIED` 처리
- 일부 장 입력만으로 캐러셀 전체를 `ALT_REMEDIATION_VERIFIED` 처리

### 3.1 대체 텍스트 출처 필드

상태와 별도로 `alt_source`를 기록한다.

| 값 | 의미 |
|---|---|
| `MANUAL` | 사람이 최종 이미지에 맞춰 작성하고 플랫폼에 입력한 문안 |
| `PLATFORM_AUTO` | 플랫폼이 자동 생성한 이미지 설명 |
| `AUTO_LIKE_UNVERIFIED` | 공개 화면에 자동 설명 형태의 문구가 보이지만 생성 주체를 확인하지 못함 |
| `UNKNOWN` | 출처를 확인하지 못함 |

`PLATFORM_AUTO`와 `AUTO_LIKE_UNVERIFIED`는 `ALT_PLATFORM_SET` 또는 `ALT_PUBLISHED_VERIFIED`의 증거가 아니다. 연결 게시 도구가 대체 텍스트 필드를 제공하지 않거나 결과를 반환하지 않으면 직접 플랫폼에서 확인하기 전까지 `ALT_UNVERIFIED`를 유지한다.

### 3.2 게시물별 감사 상태

공개 계정 전체를 한꺼번에 완료·미완료로 판정하지 않고 게시물마다 다음 상태를 기록한다.

| 상태 | 의미 |
|---|---|
| `POST_NOT_AUDITED` | 편집 화면의 장수와 장별 입력값을 확인하지 않음 |
| `POST_AUDITED_ALL_EMPTY` | 모든 장의 입력란을 확인했고 전부 비어 있음 |
| `POST_AUDITED_PARTIAL` | 일부 장만 확인했거나 빈 값과 설정값이 섞여 있음 |
| `POST_AUDITED_SET` | 모든 장에 수동 값이 있음을 확인했으나 보정 승인·저장 검증과는 별개 |
| `POST_REMEDIATION_PENDING` | 장별 보정 문안은 준비됐으나 입력·저장 전 |
| `POST_REMEDIATION_VERIFIED` | 승인된 문안을 저장하고 재진입 검증까지 완료 |

확인하지 않은 게시물은 `0`으로 기록하지 않는다. 정확한 편집 화면, 장수, 입력값을 모두 확인한 게시물만 감사 분모에 포함한다.

### 3.3 감사 스냅샷 유효기간

계정 단위의 감사 범위는 관찰 시점의 공개 게시물 목록과 장수에만 유효한 스냅샷으로 기록한다.

- 새 캐러셀 공개, 기존 게시물의 미디어·장수 변경, 보관·삭제·복원 중 하나가 확인되면 계정 단위 감사 상태를 `STALE`로 전환한다.
- 예약·초안 콘텐츠는 아직 공개되지 않았으므로 공개 게시물 감사 분모에 포함하지 않는다.
- 보관·삭제된 게시물은 과거 감사 이력에서 조용히 제거하지 않고 별도 변경 사건으로 기록한다.
- 게시물 편집 후 장수 또는 미디어가 바뀌면 이전 장별 입력 감사 결과를 재사용하지 않는다.
- `3/3 게시물 감사 완료`와 `3/3 게시물 보정 완료`는 서로 다른 지표다.

## 4. 이미지 대체 텍스트 기준

### 4.1 의미 중심 작성

- 이미지가 전달하는 목적과 핵심 정보를 먼저 쓴다.
- 장식 요소를 모두 나열하지 않는다.
- 이미지 속 핵심 문구가 의미 전달에 필요하면 포함한다.
- 캡션 전체를 장마다 반복하지 않는다.
- 검색어·해시태그를 억지로 삽입하지 않는다.
- 실제 코치·회원·시설 촬영물이 아닌 이미지를 실제 장면처럼 설명하지 않는다.
- 확인되지 않은 가격·시간표·혜택·후기·대회 실적을 추가하지 않는다.
- 사람을 설명할 때 성별·연령·장애·건강·숙련도 등을 외형만으로 추정하지 않는다.
- 회원·보호자 식별정보와 개인별 출석·건강·결제정보를 포함하지 않는다.

### 4.2 캐러셀 읽기 순서

각 장은 다음 순서로 작성한다.

1. 장의 역할: 표지, 질문, 설명, 비교, 예시, 정리, 행동 유도
2. 화면의 핵심 문구 또는 메시지
3. 의미 이해에 필요한 주요 시각 요소
4. 필요할 때만 장 순서 또는 앞뒤 장과의 관계

장수 표기는 탐색에 도움이 될 때만 넣는다. 모든 장에 동일한 계정명·배경색·장식 설명을 반복하지 않는다.

### 4.3 자동 이미지 설명 감사

공개 화면 또는 접근성 트리에서 자동 설명 형태의 문구가 보이면 다음 오류를 장별로 점검한다.

- 이미지 속 한글의 음절·단어 중복, 누락, 다른 문자 삽입
- 유도복·띠·매트·기술 동작을 일반 의류나 다른 물체로 잘못 분류
- 표지 썸네일 설명을 캐러셀 전 장의 설명으로 오인
- 화면 문구만 길게 복사하고 장의 목적·관계·행동 유도를 누락
- 실제 촬영물과 개념 일러스트를 혼동
- 자동 설명이 보인다는 이유만으로 사람 검수·수동 입력 완료로 판정

오류가 하나라도 있으면 자동 설명은 참고값으로만 남기고, 최종 이미지에 맞춘 장별 수동 대체 텍스트를 승인 패키지에 포함한다.

## 5. 텍스트 대비와 색상

이 문서는 WCAG 2.2의 수치를 정적 소셜 이미지의 **내부 시각 품질 가드레일**로 적용한다. 이것만으로 법적 적합성 또는 전체 접근성 준수를 인증하지 않는다.

- 일반 크기 텍스트와 이미지 속 텍스트: 최소 `4.5:1`
- 큰 텍스트: 최소 `3:1`
- 계산 결과를 반올림하여 기준을 통과시키지 않는다.
- 핵심어 강조는 색상과 함께 굵기, 밑줄, 아이콘, 위치, 레이블 중 하나 이상을 사용한다.
- 브랜드 색상이 기준에 못 미치면 더 어두운 대체색, 밝은 배경 또는 별도 텍스트 영역을 사용한다.
- 배경 사진·질감 위 글자는 실제 최종 합성본에서 다시 측정한다.

## 6. 타이포그래피와 모바일 가독성

- 제목, 핵심 문장, 설명, 보조 표기의 크기와 굵기를 분리한다.
- 모든 문장을 크고 굵게 처리하지 않는다.
- 제목은 가능하면 두 줄 이내로 유지한다.
- 긴 설명은 이미지 위에 겹치지 않고 별도 여백에 배치한다.
- 계정명·장수·출처 같은 작은 표기도 내부 대비 기준을 적용한다.
- 최종 PNG와 검토 PDF를 휴대전화 크기 미리보기로 확인한다.
- 자간·행간·줄바꿈 때문에 한글 음절이나 단어가 잘못 읽히지 않는지 확대 검수한다.

## 7. 영상·릴스 자막

- 말한 내용과 의미 있는 비언어 음향을 동기화해 제공한다.
- 자동 자막은 고유명사, 유도 용어, 숫자, 부정 표현, 시간·가격을 사람이 검수한다.
- 화면 글자만으로 음성 정보를 대신했다고 단정하지 않는다.
- 자막이 얼굴·손동작·기술의 핵심 지점을 가리지 않게 배치한다.
- 배경음만 있는 영상은 그 사실을 필요에 따라 설명하고, 제작하지 않은 자막을 설정했다고 주장하지 않는다.
- 회원 식별이 가능한 영상은 공개 사용 동의와 철회 처리 기준을 별도로 확인한다.

## 8. 캡션과 포용 표현

- 운동 경험, 체력, 몸 상태, 성별, 나이, 장애, 경제 사정, 동기를 추정하지 않는다.
- `누구나 가능`, `부상 걱정 없음`, `반드시 좋아짐` 같은 절대 표현을 피한다.
- 초보자가 질문하거나 속도를 조절할 수 있다는 정보를 제공하되 실제 운영 방식은 확인된 범위에서만 쓴다.
- 의학적 진단·치료·재활·부상 예방 효과를 근거 없이 주장하지 않는다.
- 코치 개인 계정의 경험과 의견은 실제 제공된 사실에 근거할 때만 1인칭으로 쓴다.
- 행동 유도는 저장·질문·팔로우·수업 문의 중 한 가지를 우선한다.

## 9. 채널별 적용

| 채널 | 실행 기준 | 완료 증거 |
|---|---|---|
| Instagram | 장별 대체 텍스트, 출처, 캡션, 캐러셀 순서, 공개 화면 검수 | 장별 입력·저장 결과와 공개 게시물 확인 |
| 네이버 | 대표 이미지 문구와 본문 의미 일치, 이미지 의존 정보의 본문 병기 | 공개 페이지 확인 |
| 당근 | 소식·쿠폰·프로필 이미지의 핵심 조건을 본문에도 표기 | 공개 프로필·소식 확인 |
| 웹사이트 | 의미 있는 이미지 대체 텍스트, 장식 이미지 제외, 자막·텍스트 대안 | 실제 페이지와 보조기술 점검 |

플랫폼 기능이 다르면 동일 문안을 기계적으로 복사하지 않고 핵심 의미를 유지해 조정한다.

## 10. 승인·버전·게시 통제

1. 콘텐츠 ID와 버전을 부여한다.
2. 최종 이미지 순서, 캡션, 해시태그, 장별 대체 텍스트를 한 패키지로 잠근다.
3. 오탈자·대비·읽기 순서·과장 표현·개인정보를 검수한다.
4. 승인 대기 상태에서는 Instagram 업로드·외부 초안 저장·예약·발행을 하지 않는다.
5. 승인 후 색상·문구·장 순서·캡션이 실질적으로 바뀌면 새 버전을 다시 승인받는다.
6. 게시 후 URL, 계정, 장수, 순서, 캡션, 가능한 경우 대체 텍스트를 공개 화면에서 확인한다.
7. 플랫폼이 대체 텍스트 확인 경로를 제공하지 않으면 `ALT_UNVERIFIED`로 남긴다.
8. 공개 프로필의 대표 썸네일 설명만 확인한 경우 캐러셀 전 장의 대체 텍스트를 확인했다고 처리하지 않는다.
9. 게시 도구에서 대체 텍스트 입력란이 없으면 캡션이나 자동 설명으로 대체 완료 처리하지 않는다.

### 10.1 게시 후 수동 대체 텍스트 보정

1. 공개 화면의 자동 설명 오류 또는 수동 입력 누락을 증거와 함께 기록한다.
2. 실제 게시된 최종 자산의 순서·버전·해시를 확인한다.
3. 장별 의미 중심 문안을 작성하고 계정 변경 범위를 별도 승인받는다.
