# Asian Games Judo Attention Window v1 — 교육형 콘텐츠 → 체험 전환

- 기준일: 2026-09-12
- 상태: 공개 콘텐츠·계측 설계 / 게시·광고·고객 발송 전
- 내부 회원수·매출·전환율: **데이터 미연결**

## 오늘의 판단

2026 아이치·나고야 아시안게임이 9월 19일 개막하고, 유도 개인전은 9월 30일~10월 2일, 혼성단체전은 10월 3일 예정되어 있다. 파이널유도멀티짐은 이 시기를 단순한 `응원 게시물`이 아니라 **유도를 잘 모르는 사람이 경기 규칙과 기술을 이해하고, 이후 실제 체험으로 넘어갈 수 있는 교육형 관심창**으로 활용할 수 있다.

이번 전략의 핵심 체인은 다음과 같다.

`event_interest → educational_content_view → profile/place_visit → inquiry → reservation → verified_attendance → visit_2 → paid_within_14d → active_30d → renewal`

조회수·좋아요·응원댓글은 보조지표일 뿐이다. 실제 성공 여부는 문의·예약·실방문·등록·30일 활성까지 연결해 판단한다.

파이널유도의 현재 네이버·인스타·당근 도달, 문의, 예약, 실방문, 등록, 30일 활성, 재등록, 귀속매출은 모두 **데이터 미연결**이다.

## 즉시 실행 3개

### A. 3단계 콘텐츠 캘린더를 준비한다

#### 1단계 — 9/12~9/18: `관전 준비`
- 네이버: `아시안게임 유도 보기 전 알아두면 좋은 5가지`
- 인스타: `한판 / 절반 / 지도 / 굳히기`를 코치가 직접 설명하는 짧은 원본 영상
- 당근: 실제 체험 가능석이 확인될 때만 `유도 경기 보고 직접 배워보고 싶은 분` 형태의 지역형 정보 게시

#### 2단계 — 9/19~9/29: `기술 이해`
- 체급과 경기방식 설명
- 손기술·발기술·허리기술의 차이
- 왜 낙법을 먼저 배우는지
- 경기에서 보이는 그립·균형·메치기의 관계

#### 3단계 — 9/30~10/3: `경기 후 직접 해보기`
- 경기 결과 자체를 재전송하기보다 그날 화제가 된 기술·상황을 **도장 코치의 자체 촬영 데모**로 설명
- 실제 체험 가능시간·여석이 확인된 경우에만 체험 CTA 연결

### B. 방송화면·선수사진을 광고소재로 재사용하지 않는다

공식 경기 영상, 방송 캡처, 선수 사진, 아시안게임 엠블럼·공식 그래픽은 사용권을 확인하지 않은 상태에서 홍보소재로 사용하지 않는다.

기본 콘텐츠는 다음으로 제한한다.

- 코치가 직접 촬영한 기술 데모
- 파이널유도 자체 제작 도식
- 텍스트 기반 경기규칙·관전포인트
- 사용 허가가 확인된 공식 링크의 공유

`공식 파트너`, `공식 응원 도장`, `국가대표 훈련 방식`처럼 실제 관계를 오인하게 하는 표현도 사용하지 않는다.

### C. 기존회원·휴면회원은 별도 목적로 관리한다

- 기존회원: 수업 전후 `오늘 경기에서 볼 기술 포인트` 정도의 교육 요소로 만족·학습동기 확인
- 휴면회원: 아시안게임을 이유로 일괄 연락하지 않는다. 기존 연락 가능 범위와 opt-in 정책 안에서만 복귀 콘텐츠를 사용할 수 있다.
- 신규고객: 콘텐츠에서 바로 결제 유도보다 `경기 이해 → 체험 예약 → 실제 방문` 순으로 연결한다.

## 실험

### EXP-230 Event-Led Education CTA vs Generic Trial CTA

가설: `성인 유도 체험` 같은 일반 CTA보다, 아시안게임 시기의 교육형 콘텐츠 뒤에 체험 CTA를 연결했을 때 더 적합한 신규 문의와 실제 방문이 발생할 수 있다.

- A: 일반 성인/유소년 체험 소개 콘텐츠
- B: 유도 관전·기술 설명 콘텐츠 + 동일한 체험 CTA
- 주지표: `verified_attendance / completed_reservations`
- 보조지표: 콘텐츠→문의, 문의→예약, 첫 방문→2회차, 14일 등록, 30일 활성
- 성공 기준: 사전에 확정한 최소개선폭을 충족하고 오안내·수업혼잡·브랜드 리스크가 증가하지 않을 때 확대
- 중단 기준: 조회수만 늘고 실방문·30일 활성 개선이 없거나, 저작권·상표·공식제휴 오인 문제가 발생할 때 중단

기준 전환율, 최소개선폭, 표본수는 **데이터 미연결**이다.

### EXP-231 Original Coach Demo vs Event-Clip Reliance

가설: 방송·경기 클립에 의존하지 않고 코치가 직접 촬영한 짧은 기술 설명도 충분히 저장·공유·문의 행동을 만들 수 있다.

- A: 일반 자체 촬영 수업/기술 영상
- B: 아시안게임 관전 포인트와 연결한 자체 촬영 기술 데모
- 핵심 KPI: 저장/공유보다 `프로필 방문 → 문의 → 예약 → 실방문`
- 보조 KPI: 제작시간, 반복질문 감소, 저작권 이슈 0건
- 중단 기준: 사실오류, 선수 경기내용 오해, 방송영상 무단사용, 실방문 개선 없는 과도한 제작부담

## 채널별 실행안

### 네이버
검색의도형 장문을 우선한다.

- `2026 아시안게임 유도 경기 보는 법`
- `유도 한판과 절반은 어떻게 다른가`
- `유도 경기에서 지도는 언제 받나`
- `유도 처음 배우면 왜 낙법부터 하나`

게시 전 공식 규칙·대회일정을 재확인한다. 선수의 결과 예측이나 메달 보장은 콘텐츠 중심으로 삼지 않는다.

### 인스타그램
15~30초 자체촬영 데모를 중심으로 한다.

- 관전포인트 1개
- 코치 데모 1개
- 초보자가 실제 수업에서 어떻게 배우는지 1개
- 마지막 CTA는 1개만 사용

### 당근
지역형 정보성 문구로 제한한다.

- `강서구에서 유도 경기 보고 직접 배워보고 싶다면`
- 실제 체험 가능 슬롯과 대상이 확인된 경우에만 시간 표시
- 가짜 `마감임박`, `국가대표식 훈련`, `아시안게임 특별할인` 금지

## 필요한 대표 승인·입력

실제 게시 전 확인이 필요한 내부값:

- 본관/지점별 실제 체험 가능 시간과 여석
- 성인·유소년 중 어느 세그먼트를 우선할지
- 체험비·도복·준비물·도착시간 정책
- 코치 자체 촬영 가능 여부 및 얼굴 노출 동의 범위
- 회원 촬영이 포함될 경우 별도 초상권·보호자 동의 절차
- 네이버·인스타·당근 게시 승인 범위
- 콘텐츠 제작에 허용할 주당 운영시간

## Auditor

1. 아시안게임 관심이 파이널유도 체험수요 증가를 보장한다고 표현하지 않는다.
2. 공식 엠블럼·방송화면·선수사진·경기클립은 사용권 확인 없이 마케팅 소재로 전용하지 않는다.
3. 국가대표 또는 대회와 제휴한 것처럼 표현하지 않는다.
4. 선수의 특정 경기결과·부상·출전상태는 게시 시점의 공식 출처로 다시 확인한다.
5. 경기 기술을 설명할 때 실제 경기장면을 과도하게 단순화하거나 특정 선수를 평가·비하하지 않는다.
6. 미성년 회원의 얼굴·이름·학교·등급을 결합한 콘텐츠를 만들지 않는다.
7. 이벤트 콘텐츠의 성공은 조회수·좋아요가 아니라 실방문·등록·30일 활성까지 확인한다.
8. 고객 메시지 발송, 광고집행, 가격할인, 프로필 변경은 대표 승인 없이 실행하지 않는다.
