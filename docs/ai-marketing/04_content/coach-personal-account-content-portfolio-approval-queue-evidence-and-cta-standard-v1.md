# 코치 개인 계정 콘텐츠 포트폴리오·승인 대기·근거·CTA 운영 기준 v1

- 적용 조직: 파이널유도멀티짐 공개 마케팅 실무
- 우선 적용 계정: 코치 개인 Instagram
- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-16
- 공개 제외: 승인 대기 미디어·캡션, 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제 기록, 비밀키, 미확정 행사·가격·혜택

## 1. 목적

콘텐츠를 많이 만드는 것보다 검증된 한 게시물을 제작, 승인, 게시, 측정까지 끊김 없이 통과시키는 운영 기준이다.

핵심 목적은 다음과 같다.

1. 코치 개인 계정을 도장 공식 발표 계정처럼 운영하지 않는다.
2. 같은 주제·시각·CTA의 반복 제작을 줄인다.
3. 승인 대기물이 쌓인 상태에서 새 초안만 계속 늘어나는 일을 막는다.
4. 기술·규정·코치 경험·상업적 약속의 근거 수준을 구분한다.
5. 게시 반응과 문의·체험·등록·재등록·실수납을 분리한다.

## 2. 계정과 콘텐츠 주체

- 코치 개인 계정은 코치의 전문성, 친근함, 수련과 지도 맥락을 보여주는 채널이다.
- 계정의 운영 성격과 Instagram 설정상의 개인·크리에이터·비즈니스 유형은 구분한다.
- 전 지점 공통 정책, 가격, 시간표, 행사, 모집, 혜택을 코치 개인의 확정 발표처럼 말하지 않는다.
- 코치의 실제 경험, 당일 수련, 지도 철학과 발언은 사용자 제공 원자료가 있을 때만 1인칭으로 쓴다.
- 원자료가 없으면 촬영 제안 또는 확인 질문으로 남기고 실제 경험처럼 만들지 않는다.

## 3. 단일 콘텐츠 계보

모든 게시 후보는 하나의 고유 작업 ID와 버전을 가진다.

### 3.1 필수 필드

| 필드 | 의미 |
|---|---|
| WORK_ID | 게시물 고유 ID |
| VERSION | 승인 대상 버전 |
| ACCOUNT | 대상 계정 |
| SUBJECT | 주제 |
| PURPOSE | 신규·복귀·만족·재등록·매출 중 주목적 |
| PILLAR | 콘텐츠 축 |
| FORMAT | 캐러셀·릴스·스토리 등 |
| CTA | 저장·질문·팔로우·수업 문의 중 한 가지 |
| CLAIM_CLASS | 기술·규정·경험·운영·상업적 약속 분류 |
| EVIDENCE | 근거 URL·원자료·검증일 |
| MEDIA_ORIGIN | 실사·편집·AI 일러스트 등 |
| CONSENT_STATUS | 인물 공개 동의 상태 |
| ALT_TEXT_STATUS | 장별 대체 텍스트 준비·설정 상태 |
| APPROVAL_STATUS | 승인 상태 |
| UPLOAD_STATUS | 업로드·예약·게시 상태 |
| SOURCE_HASH | 승인 미디어의 SHA-256 |
| PUBLISHED_URL | 게시 후 공개 URL |
| MEASUREMENT_WINDOW | 성과 조회 시작·종료 시각 |

### 3.2 분리 원칙

- 제작 완료는 승인 완료가 아니다.
- 승인 완료는 업로드 완료가 아니다.
- 예약 등록은 게시 완료가 아니다.
- 게시 도구의 성공 메시지는 공개 게시 검증이 아니다.
- 조회와 도달은 문의가 아니다.
- 문의와 체험 예약은 실제 방문이 아니다.
- 계약과 청구는 실수납이 아니다.

## 4. 콘텐츠 포트폴리오

### 4.1 기본 콘텐츠 축

| 코드 | 콘텐츠 축 | 사용 조건 | 대표 위험 |
|---|---|---|---|
| P1 | 유도 기술 개념 | 공신력 있는 기술 근거 | 성공 보장·과도한 단순화 |
| P2 | 입문자 질문 | 일반 정보와 도장별 차이 구분 | 미확정 수업·가격 단정 |
| P3 | 예절·문화·용어 | 공식 용어·절차 확인 | 규칙과 관습 혼합 |
| P4 | 도복·장비·준비물 | 제품별 차이와 일반 원리 구분 | 상품 추천·기능 과장 |
| P5 | 코치 수련 기록 | 실제 원본과 날짜·맥락 확인 | 허구의 1인칭 경험 |
| P6 | 지도 설명 포인트 | 실제 지도 자료 또는 일반 설명 | 회원 식별·효과 보장 |
| P7 | 수업 준비·코치 일상 | 실제 촬영 자료 확인 | 합성 장면의 실사 오인 |
| P8 | 지점·행사·복귀 안내 | 대표 승인·확정 원천 | 코치 계정의 공식 발표 오인 |

### 4.2 순환 원칙

- 최근 준비·게시 목록에서 같은 콘텐츠 축만 연속 선택하지 않는다.
- 같은 주제라도 질문, 설명 구조, 시각, CTA가 실질적으로 같으면 새 게시물로 만들지 않는다.
- 실제 코치 자료가 없는 기간에는 일반 유도 설명을 만들 수 있지만, 계정 전체가 익명 일러스트만으로 채워지지 않게 촬영 후보를 별도 관리한다.
- 하루 제작 목표는 실제 게시 빈도나 최적 게시 시각을 의미하지 않는다.

## 5. 중복 판정

새 제작 전에 최근 12개 게시·준비 패키지를 다음 다섯 축으로 비교한다.

1. 주제: 같은 질문이나 지식을 다시 설명하는가
2. 도입: 표지 문장과 첫 장의 문제 제기가 유사한가
3. 구조: 표지, 정의, 예시, 정리의 배열이 반복되는가
4. 시각: 같은 도복·매트·두 인물·추상 도식이 반복되는가
5. CTA: 같은 행동 요청이 연속되는가

### 5.1 중복 등급

| 등급 | 판정 | 처리 |
|---|---|---|
| D0 | 주제·구조·시각이 충분히 다름 | 제작 가능 |
| D1 | 한 축만 유사 | 차이를 기록하고 제작 가능 |
| D2 | 두세 축이 유사 | 기존 패키지 개선을 우선 |
| D3 | 네 축 이상 유사 | 신규 제작 중단·통합 또는 폐기 |

해시가 다르다는 사실만으로 새로운 콘텐츠라고 판정하지 않는다.

## 6. CTA 기준

한 패키지에는 다음 중 한 가지 CTA만 둔다.

| CTA | 적합한 목적 | 측정 항목 |
|---|---|---|
| 저장 | 나중에 다시 볼 체크리스트·입문 정보 | 저장 수 |
| 질문·댓글 | 독자의 궁금증 수집 | 실제 댓글·질문 수 |
| 팔로우 | 연속 설명 시리즈 예고 | 게시물 귀속 팔로우 |
| 수업 문의 | 확인된 문의 경로로 연결 | 직접 문의·적격 문의 |

- 저장과 댓글과 문의를 한 게시물에 동시에 요구하지 않는다.
- CTA가 이미지와 캡션에서 서로 다르면 승인 대기로 보내지 않는다.
- CTA 순환은 기계적인 균등 배분이 아니라 목적과 정보량에 맞춰 결정한다.
- 미확정 가격·무료 체험·혜택·좌석·마감 표현으로 문의를 유도하지 않는다.

## 7. 근거 등급

| 등급 | 근거 | 사용 가능 범위 |
|---|---|---|
| E1 | IJF·국가협회·법령·플랫폼 공식 문서 | 규정·용어·플랫폼 기능 |
| E2 | 제조사 공식 기술 자료 | 도복·장비 구조와 제품 정보 |
| E3 | 대표가 제공한 내부 확정 원천 | 시간표·가격·행사·혜택 |
| E4 | 코치가 제공한 원본·메모·촬영물 | 코치 개인 경험·당일 수련·지도 맥락 |
| E5 | 업계 사례·벤더 자료 | 아이디어·가설 보조 근거 |
| E0 | 출처 없음·기억·추정 | 공개 주장에 사용 금지 |

### 7.1 주장별 최소 근거

- 기술 원리·경기 절차: E1 우선
- 도복 구조: E1 또는 E2
- 코치의 경험·철학: E4
- 가격·시간표·모집·혜택: E3
- 마케팅 사례: E5로 실험 가설만 만들고 내부 성과로 단정하지 않는다.
- 회원 후기·변화·대회 실적: 당사자 동의와 검증 원천이 모두 없으면 사용하지 않는다.

## 8. 상태 흐름

게시물은 다음 순서로 이동한다.

IDEA → EVIDENCE_READY → MEDIA_COMPLETE → QA_PASSED → APPROVAL_PENDING → APPROVED → UPLOAD_IN_PROGRESS → PUBLISHED → VERIFIED → MEASUREMENT_OPEN → MEASUREMENT_CLOSED

예외 상태는 다음과 같다.

- REWORK: 수정 후 새 버전 필요
- REJECTED: 승인 거절
- DISCARDED: 폐기, 다시 게시 후보로 사용하지 않음
- PUBLISH_BLOCKED: 로그인·권한·도구·플랫폼 오류로 게시 불가
- PUBLISH_PARTIAL: 일부 단계만 완료돼 공개 검증이 끝나지 않음

상태를 건너뛰지 않는다. 승인 대기 미디어를 Instagram이나 외부 게시 도구에 업로드·초안 저장·예약하지 않는다.

## 9. 승인 대기 WIP 기준

### 9.1 기본 한도

- 승인 대기 패키지는 최대 3개를 기본 운영 한도로 둔다.
- 한도는 외부 벤치마크가 아니라 현재 운영의 검토 누적을 막기 위한 내부 제안값이다.
- 한도에 도달하면 새 제작보다 기존 패키지의 사실 검수, 우선순위 결정, 승인·수정·폐기 처리를 우선한다.
- 긴급한 안전 교정이나 승인본 오류 수정은 예외로 하되 기존 작업의 새 버전으로 기록한다.

### 9.2 승인 우선순위

1. 사실 근거와 안전 검수가 끝났는가
2. 최근 게시물과 주제·시각·CTA가 겹치지 않는가
3. 코치 개인 계정의 주체가 명확한가
4. 한 가지 학습 질문을 검증할 수 있는가
5. 게시 후 성과를 조회할 수 있는가

오래 기다렸다는 이유만으로 위험하거나 중복된 패키지를 우선하지 않는다.

## 10. 승인 패키지 완전성

승인 요청에는 다음을 한 번에 제시한다.

- 고유 작업 ID와 버전
- 대상 계정
- 주제와 목적
- 게시 형식과 장수
- 최종 미디어 전부와 업로드 순서
- 최종 캡션
- 해시태그 3~5개
- 장별 대체 텍스트
- CTA 한 가지
- 근거와 한계
- 미디어 출처·동의 상태
- 현재 상태: 승인 대기·미업로드·미예약·미게시

미디어가 보이지 않았던 이력이 있으면 PDF 검토본과 원본 묶음을 함께 제공한다. 파일 링크 제공을 영구 보관 완료로 표현하지 않는다.

## 11. 승인 후 버전 잠금

- 승인받은 이미지, 순서, 캡션, 계정과 형식을 그대로 사용한다.
- 승인 후 실질적인 문구·미디어·순서 변경이 필요하면 버전을 올리고 다시 승인받는다.
- 오탈자 수정도 공개 의미나 이미지 픽셀을 바꾸면 새 버전으로 기록한다.
- 승인본의 파일별 SHA-256을 업로드 전에 다시 대조한다.
- 같은 작업 ID와 승인 버전은 한 번만 게시한다.
- 재시도 전 계정 게시물과 게시 도구 상태에서 이미 공개됐는지 확인한다.

## 12. 게시 완료 검증

다음 조건이 모두 충족돼야 게시 완료다.

1. 정확한 계정에서 공개 URL이 열림
2. 캐러셀 장수와 순서가 승인본과 일치
3. 이미지·영상 해시 또는 시각 검수가 승인본과 일치
4. 캡션·해시태그가 승인본과 일치
5. 마지막 장까지 이동 가능하고 중복 게시가 없음
6. 대체 텍스트는 실제 설정 여부를 별도 확인

예약, Pending, PUBLISHING, 버튼 클릭 성공을 게시 완료로 사용하지 않는다.

## 13. 성과 측정

### 13.1 플랫폼 지표

- 조회
- 도달
- 좋아요
- 댓글
- 저장
- 공유
- 프로필 활동
- 게시물 귀속 팔로우

Instagram의 추천 자격은 비팔로워 추천 가능성을 뜻할 수 있지만 실제 노출을 보장하지 않는다. 계정 상태나 추천 자격은 최신 공식 화면에서 확인하고, 확인하지 않은 상태를 추정하지 않는다.

### 13.2 사업 지표

- 직접 문의
- 적격 문의
- 체험 예약
- 실제 방문
- 신규 계약
- 실수납
- 휴면 복귀
- 재등록
- 환불 반영 순수납

플랫폼 지표와 사업 지표를 단순 합산하지 않는다. 계산할 때 분자, 분모, 기간과 원천을 표시한다. 분모가 0이거나 연결되지 않았으면 계산하지 않는다.

## 14. 채널별 변환

### Instagram

- 코치 개인의 설명과 시각 중심으로 구성한다.
- 승인본 잠금과 게시물별 성과를 유지한다.

### 네이버

- 검색 의도가 분명한 제목과 실제 지점 정보를 사용한다.
- Instagram의 개인 경험 표현을 도장 공식 사실로 바꾸지 않는다.
- 가격·시간표·예약은 최신 승인 원천과 대조한다.

### 당근

- 지역과 실제 지점을 확인할 수 있을 때만 생활권 표현을 사용한다.
- 미확정 행사·혜택·마감·좌석을 공개하지 않는다.
- 코치 개인 계정의 게시물을 지점 공지로 자동 복제하지 않는다.

## 15. 실험 설계

### EXP-348 — 콘텐츠 계보·승인 대기·CTA·게시 멱등성 검증

- 대상: 실제 계정이나 고객을 사용하지 않는 합성 패키지 24개
- 목적: 중복 제작과 무승인 게시를 차단하면서 한 패키지의 전체 계보를 보존하는지 검증
- 사전조건: 가격·혜택·회원정보·실제 게시 계정 미사용

성공 기준:

- 작업 ID와 버전 누락 0건
- 근거 없는 기술·경험·운영 주장 0건
- 패키지당 CTA 두 개 이상 0건
- D3 중복 후보의 신규 제작 진행 0건
- 승인 대기 한도 초과 0건
- 승인 전 외부 업로드·예약·게시 0건
- 승인 후 파일·순서·캡션 불일치 0건
- 동일 작업 ID·버전의 중복 게시 판정 오류 0건
- 플랫폼 반응의 문의·계약·수납 오분류 0건

중단 기준:

- 개인정보·동의 원문 공개
- 미확정 가격·시간표·행사·혜택 공개
- 코치 경험 또는 회원 후기를 생성해 사실처럼 사용
- 실제 고객 연락·광고 집행·계정 변경·게시 실행

## 16. 대표 승인·입력 체크리스트

- 코치 개인 계정의 콘텐츠 축 우선순위
- 승인 대기 기본 한도와 예외 승인자
- 게시물 승인·수정·폐기 결정권자
- 코치 경험·수련·지도 원자료 제공 방식
- 실제 촬영물의 사용 권리와 회원·보호자 동의 원장
- 가격·시간표·행사·혜택의 기준 시스템
- 공식 문의 경로와 지점 귀속 방식
- CTA별 귀속기간
- 게시 후 조회 시점과 성과 판정 책임자
- 원본·해시·게시 URL의 비공개 보관 위치

## 17. 공개 전 감사 체크리스트

- [ ] 코치 개인 계정의 주체가 명확하다.
- [ ] 플랫폼 계정 유형을 추정하지 않았다.
- [ ] 최근 12개 후보와 중복 비교를 했다.
- [ ] CTA가 한 가지다.
- [ ] 주장별 근거 등급을 기록했다.
- [ ] 1인칭 경험은 코치 원자료가 있다.
- [ ] 회원·보호자 공개 동의를 확인했다.
- [ ] 미확정 가격·시간표·행사·혜택이 없다.
- [ ] 장수·순서·캡션·대체 텍스트가 완성됐다.
- [ ] 승인 대기 상태에서 외부 업로드를 하지 않았다.
- [ ] 승인 후 버전과 해시를 잠갔다.
- [ ] 공개 URL·장수·캡션·중복 부재를 검증했다.
- [ ] 조회·도달과 문의·체험·등록·수납을 분리했다.
