# Multi-Branch Visual Proof Standard v1

- 기준일: 2026-09-12
- 상태: 공개 콘텐츠·계측 표준 설계 / 촬영·게시·광고·계정 변경 전
- 적용 대상: 파이널유도멀티짐 본관 및 지점의 공개 마케팅 자산
- 내부 회원수·매출·전환율·채널별 성과: **데이터 미연결**

## 오늘의 판단

이번 회차의 우선순위는 광고·쿠폰·체험가격을 추가하는 것이 아니라, **검색과 프로필에서 잠재고객이 처음 보는 사진·짧은 영상·수업 장면을 다지점 공통의 `Visual Proof` 체계로 표준화할 준비를 하는 것**이다.

핵심 체인은 다음과 같다.

`local_search_impression → visual_asset_view → profile_detail_view → qualified_inquiry → booking → verified_attendance → paid_14d → active_30d → renewal`

네이버는 2026-05-28부터 일부 업종 검색 결과를 `범용 특화` 컬렉션으로 개편해 헬스장·필라테스·요가 등을 예시로 여러 업체 이미지를 한 화면에서 보여주고 방문자 리뷰 이미지·문장도 함께 노출한다고 안내했다. 파이널유도멀티짐의 등록 업종이 이 컬렉션에 실제 적용되는지는 **데이터 미연결**이다. 따라서 적용 여부를 확인하기 전 `검색 노출이 개선된다`고 주장하지 않는다.

또한 네이버는 2026-06-04 플레이스 상단 이미지 영역의 네이버TV 연동을 종료하면서, 사업주가 직접 등록 가능한 네이버 Clip 또는 새소식을 통한 영상 업로드·노출을 안내했다. 즉 사진과 짧은 영상은 플레이스 상세 내부의 부가 콘텐츠가 아니라 검색·플레이스 첫인상 후보 자산으로 관리할 가치가 있다.

이번 표준은 특정 지점의 공개 콘텐츠를 `잘못됐다`고 판단하는 문서가 아니라, 다지점 운영에서 자산 제작과 계측 기준을 통일하기 위한 설계다.

## CMO — 우선순위

1. 광고비 증액보다 기존 검색·프로필에서 보여주는 `실제 수업 증거`의 품질과 최신성을 먼저 계측한다.
2. 모든 지점에 같은 포스터를 배포하는 방식보다 `공통 촬영 프레임 + 지점별 실제 장면` 구조를 우선한다.
3. 조회수·좋아요를 최종 KPI로 두지 않고 `유효문의 → 예약 → 실방문 → 14일 등록 → 30일 활성`까지 연결한다.
4. 사진·영상 제작을 위해 미성년자·회원의 촬영동의를 추정하지 않는다.

## Growth Analyst — 퍼널과 데이터 구조

### 핵심 퍼널

`asset_published → asset_view_or_profile_view → inquiry → booking → verified_attendance → paid_14d → active_30d → renewal`

플랫폼이 자산별 조회를 제공하지 않으면 `profile_view`부터 시작한다. 추적이 불가능한 단계를 임의 숫자로 채우지 않는다.

### 최소 집계 필드

- `branch_code` — 공개 저장소에는 실제 회원정보와 연결하지 않는 지점 코드만 사용
- `channel` — NAVER / INSTAGRAM / DAANGN / OTHER
- `asset_type` — PHOTO / SHORT_VIDEO / CAROUSEL / FACILITY / COACH / CLASS / BEGINNER_GUIDE
- `asset_published_at`
- `asset_status` — CURRENT / STALE / REVIEW / UNKNOWN
- `profile_views`
- `qualified_inquiries`
- `bookings`
- `verified_attendance`
- `paid_14d`
- `active_30d`
- `renewals`

현재 값은 모두 **데이터 미연결**이다.

## Acquisition Marketer — 신규 체험 확보용 Visual Proof 8종

다음 8종은 `있어야 한다`는 확정 기준이 아니라 파일럿용 촬영체크리스트다.

1. **외부 접근 장면** — 건물 입구·층·도장 진입 동선. 실제 위치와 다른 연출 금지.
2. **매트 전체 장면** — 수업 공간의 규모감과 정돈상태를 보여준다.
3. **초보자 기본수업 장면** — 낙법·기본 움직임처럼 첫 체험자가 실제 접할 수 있는 장면.
4. **기술 지도 장면** — 코치가 설명·시범하는 모습. `방치되지 않는다`는 운영 증거 역할 후보.
5. **파트너 연습 장면** — 통제된 연습 상황. 위험하거나 과격해 보이는 장면만 대표 이미지로 사용하지 않는다.
6. **굳히기·란도리 장면** — 실제 정규수업의 다양성을 보여주되 초보자에게 첫날 강제된다고 오인시키지 않는다.
7. **시설·편의 장면** — 탈의·샤워·대기공간 등 실제 제공시설만 노출한다.
8. **코치·수업정보 카드** — 실제 담당코치·대상·시간이 확인된 경우에만 사용한다.

`국가대표식`, `선수급 보장`, `단기간 다이어트`, `학교폭력 완전예방` 등 과도한 성과보장 문구는 비주얼 카드에 넣지 않는다.

## CRM Marketer — 기존회원·휴면회원 적용

Visual Proof는 신규획득 전용으로만 보지 않는다.

- **기존회원:** 자신의 수업이 브랜드 콘텐츠로 소비되는 것이 아니라 실제 훈련과 성장경험을 존중받고 있다고 느끼는지 확인한다.
- **휴면회원:** 과거 회원에게 현재 도장의 변화나 수업분위기를 보여주는 콘텐츠 후보로 사용할 수 있으나, 연락동의 없이 메시지를 발송하지 않는다.
- **체험후미등록:** 기존 체험후속관리 문안과 중복 발송하지 않는다. 필요하면 공개 콘텐츠 링크를 한 번 제공하는 정도부터 검증한다.
- **만료예정:** 콘텐츠 열람을 재등록 의도로 자동 해석하지 않는다.

## Content Strategist — 채널별 실행안

### 네이버

목표: `검색·플레이스에서 첫 클릭 전에 실제 도장 모습을 이해시키기`

- 대표이미지 후보: 매트 전체 + 실제 수업 분위기가 한 번에 보이는 장면
- 보조이미지: 초보 기본수업 / 기술지도 / 시설 / 코치 / 연령대별 실제 수업장면
- Clip 후보: 15~30초 `낙법 → 기술시범 → 파트너 연습 → 마무리` 같은 짧은 수업 흐름
- 새소식: 촬영일과 실제 해당 클래스 정보를 확인한 뒤 게시

네이버의 `범용 특화` 컬렉션에 유도장이 포함되는지는 먼저 실제 검색에서 확인한다.

### Instagram

목표: `정적인 도장 소개가 아니라 실제 움직임·지도방식을 보여주기`

- Reel 1: `처음 오면 무엇부터 배우는가`
- Reel 2: `코치 시범 → 회원 연습 → 피드백`
- Carousel: `시설 / 수업 / 코치 / 준비물 / 체험 가능 시간`

조회수보다 프로필 방문, 유효문의, 예약, 실방문을 본다.

### 당근

목표: `동네 사용자가 이 도장이 실제로 어떤 곳인지 빠르게 판단하게 하기`

- 지점별 실제 사진을 우선 사용한다.
- 주소·영업시간·체험 가능 여부가 다른 지점의 사진·문구를 섞지 않는다.
- `오늘 마감`, `잔여 1석`은 실제 `trial_capacity`가 확인되는 경우에만 사용한다.

## 즉시 실행 3개

### 1. Visual Asset Inventory

본관·지점별 공개 채널에서 현재 노출 중인 사진·영상의 존재 여부만 집계한다.

상태 예시:
- `CURRENT`: 최근 운영과 일치
- `STALE`: 시간표·시설·코치·브랜딩과 불일치 가능
- `REVIEW`: 초상권·민감정보·과장표현 검토 필요
- `MISSING`: 필수 후보 장면 없음
- `UNKNOWN`: 확인 불가

실제 수정은 대표 승인 전 수행하지 않는다.

### 2. 8-Frame Shot List Pilot

본관 1개 지점 또는 대표 승인 지점에서 위 8종 중 실제 필요한 항목만 촬영하는 최소 파일럿을 설계한다.

촬영 전 확인:
- 성인 회원 촬영·활용 동의
- 미성년자 보호자 동의
- 도복 이름표·학교명·휴대전화 화면 등 식별정보 노출 여부
- 부상·건강상태가 드러나는 장면 여부
- 실제 수업 방해 여부

### 3. Channel-to-Visit Attribution

게시 전 기간과 게시 후 기간을 단순 비교해 인과를 주장하지 않는다. 가능한 경우 채널별 문의경로 또는 캠페인 코드를 사용해 `콘텐츠 → 문의 → 예약 → 실방문`을 연결한다.

## Experiment Manager

### EXP-256 Search-Card Visual Completeness

**가설:** 실제 시설·수업·코치·초보경험을 균형 있게 보여주는 프로필이 단일 포스터·로고 중심 프로필보다 유효문의와 예약 단계의 불확실성을 줄일 수 있다.

- A: 현행 프로필
- B: 대표 승인된 Visual Proof 자산 세트
- 핵심 KPI: `profile_view → qualified_inquiry → booking → verified_attendance`
- 보조 KPI: 위치·준비물·수업방식 반복문의, 콘텐츠 제작·관리시간
- 성공 기준: 집행 전 최소개선폭과 관찰기간을 확정한 뒤 하단 퍼널 개선과 운영부담을 함께 충족
- 중단 기준: 잘못된 운영정보, 초상권 문제, 민감정보 노출, 과밀·허위 체험가능 표현

기준선·최소개선폭·표본수는 **데이터 미연결**이다.

### EXP-257 Short Video vs Static Proof

**가설:** 같은 사실정보를 정적 이미지와 15~30초 수업영상으로 각각 제공할 때 어느 형식이 실제 문의·예약·실방문 연결에 더 유리한지 지점별로 다를 수 있다.

- 비교 콘텐츠의 CTA·가격·체험조건은 동일하게 유지한다.
- Reel/Clip 조회수만으로 승자를 정하지 않는다.
- 핵심 KPI: 유효문의, 예약, 실방문, 14일 등록
- 중단 기준: 제작시간이 사전 허용범위를 넘거나 개인정보·수업방해 문제가 발생할 때

### EXP-258 Multi-Branch Asset Consistency Audit

**가설:** 지점별 실제 정보는 유지하면서 공통 촬영프레임과 품질검수 기준을 적용하면 브랜드 혼선을 줄일 수 있다.

측정 후보:
- 지점 프로필의 오래된 사진 비율
- 실제 운영과 불일치한 자산 건수
- 채널별 반복문의
- 지점별 문의→예약→실방문

브랜드 일관성을 위해 모든 지점에 동일 사진을 강제하지 않는다. 목표는 `같은 품질 기준 + 다른 실제 현장`이다.

## 필요한 대표 승인·입력

1. 본관 및 각 지점의 공식 네이버·인스타·당근 계정 목록
2. 각 지점의 현재 대표이미지·사진·영상 마지막 갱신일
3. 실제 수업시간·대상·코치·편의시설의 공개 가능 기준값
4. 촬영 가능 시간과 수업 방해 허용범위
5. 성인 촬영동의 및 미성년자 보호자 동의 절차
6. 기존 사진·영상의 사용권 확인 여부
7. 채널별 프로필 방문·문의·예약·실방문 비식별 집계
8. 네이버 검색에서 해당 지점이 `범용 특화` 형태로 실제 노출되는지 여부

비용이 드는 촬영외주, 광고, 고객 연락, 계정 변경, 콘텐츠 게시·삭제는 대표 승인 없이 수행하지 않는다.
