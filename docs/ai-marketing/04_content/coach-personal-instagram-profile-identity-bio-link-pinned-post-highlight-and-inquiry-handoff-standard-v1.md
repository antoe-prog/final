# 코치 개인 Instagram 프로필·정체성·소개·링크·고정 게시물·하이라이트·문의 인계 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-17
- 적용 대상: 코치 개인 Instagram 계정과 연결되는 공개 문의 경로
- 적용 목표: 신규 체험 문의, 휴면 복귀, 기존회원 만족·재등록, 매출 귀속의 정확성
- 데이터 상태: 내부 문의·예약·방문·등록·수납 데이터 미연결

## 1. 목적

프로필 방문자가 계정의 주체와 콘텐츠 목적을 이해하고, 필요할 때 검증된 공식 문의 경로로 이동할 수 있도록 한다. 프로필 노출, 링크 탭, DM, 예약, 실제 방문, 계약과 실수납을 서로 다른 사건으로 관리한다.

## 2. 핵심 판단

1. 코치 개인 계정은 코치의 설명·수련·지도 맥락을 보여주는 채널이며 브랜드 공식 발표 계정으로 표현하지 않는다.
2. 계정의 운영 성격과 Instagram 설정상의 개인·크리에이터·비즈니스 유형은 구분한다.
3. 프로필 소개, 외부 링크, 고정 게시물, 하이라이트와 행동 버튼은 각각 별도 승인·검증 대상이다.
4. 프로필 편집 저장, 공개 노출 관찰과 최종 목적지 검증을 분리한다.
5. 프로필 방문·링크 탭·DM을 문의·예약·방문·등록·매출로 자동 집계하지 않는다.
6. 게시물이 늘어나도 공식 문의 경로가 없거나 잘못 연결되면 전환 확대를 주장하지 않는다.

## 3. 프로필 상태 모델

| 상태 | 의미 |
|---|---|
| `PROFILE_OBSERVED` | 현재 화면을 읽기 전용으로 관찰 |
| `PROFILE_PROPOSED` | 소개·링크·고정·하이라이트 변경안 작성 |
| `PROFILE_APPROVED` | 변경할 정확한 값과 범위 승인 |
| `PROFILE_UPDATE_SUBMITTED` | Instagram에서 변경 저장 실행 |
| `PROFILE_LIVE_OBSERVED` | 변경값이 화면에 표시되는 것을 관찰 |
| `PROFILE_DESTINATION_VERIFIED` | 링크·버튼의 최종 목적지와 담당 범위 확인 |
| `PROFILE_MATCH_VERIFIED` | 승인안과 공개 화면·목적지가 모두 일치 |
| `PROFILE_DISCREPANCY` | 승인안·공개 화면·목적지 중 하나 이상 불일치 |
| `PROFILE_ROLLBACK_REQUIRED` | 잘못된 변경을 복구해야 함 |

`PROFILE_UPDATE_SUBMITTED`를 공개 반영 완료로 사용하지 않는다. 링크가 보인다는 사실만으로 올바른 지점·예약·문의 경로라고 판정하지 않는다.

## 5. 소개 문구 기준

소개 문구는 다음 순서로 설계한다.

1. 누가 말하는가: 코치 개인
2. 무엇을 다루는가: 수련 기록, 지도 설명, 유도 입문 정보 등 확인된 범위
3. 독자가 무엇을 기대할 수 있는가: 질문·학습·팔로우 등 한 가지 주된 가치
4. 문의가 필요한 경우 어디로 가는가: 검증된 공식 경로가 있을 때만 표기

### 금지·주의 표현

- 전 지점의 공식 발표 주체처럼 보이는 표현
- 확인되지 않은 지점명·주소·시간표·가격·무료 체험·혜택·잔여석
- 제공 자료가 없는 1인칭 수련 경험·지도 철학·대회 실적
- `누구나 가능`, `부상 걱정 없음`, `무조건 효과` 같은 절대 표현
- 개인 전화번호나 임시 담당자 정보를 검증 없이 공개

## 6. 외부 링크와 행동 버튼

### 6.1 외부 링크

- URL을 추가하기 전에 공식 문의·예약·지점 안내 중 목적을 하나로 정의한다.
- 표시 제목과 최종 페이지의 기능이 일치해야 한다.
- 지점 선택이 필요한 경우 특정 지점으로 잘못 귀속되지 않게 한다.
- 단축 URL은 원본 목적지와 관리자 권한을 기록한다.
- 로그인 요구, 만료, 오류, 다른 상품·지점 연결 여부를 모바일·비로그인 환경에서 검수한다.
- 추적 파라미터에는 이름·전화번호·회원번호 등 개인정보를 넣지 않는다.

### 6.2 연락처·행동 버튼

- 버튼 제공 여부와 종류는 현재 계정 유형·지역·연결 파트너 화면에서 직접 확인한다.
- 기능이 공식 도움말에 존재한다는 사실만으로 해당 계정에 설정 가능하다고 단정하지 않는다.
- 버튼 클릭을 예약·방문·수납으로 집계하지 않는다.
- 개인 이메일·전화번호 공개는 별도 승인을 받는다.

## 7. 고정 게시물

Instagram은 게시물을 프로필 상단에 고정하는 기능을 제공한다. 고정은 새 게시나 재게시가 아니지만 프로필의 우선 노출을 바꾸는 계정 변경이므로 승인 후 실행한다.

### 7.1 역할 제안

| 슬롯 | 역할 | 선택 기준 |
|---|---|---|
| 1 | 처음 온 사람을 위한 시작점 | 계정 주체와 입문자가 얻을 정보가 명확함 |
| 2 | 코치 설명 역량 | 근거가 검수된 기술·도복·예절 설명 |
| 3 | 코치 개인성 | 확인된 수련 기록·지도 관점·일상 |

- 최신 게시물이라는 이유만으로 고정하지 않는다.
- 조회수가 높다는 이유만으로 고정하지 않는다.
- 승인 대기, 만료된 행사, 오래된 가격·시간표 게시물을 고정하지 않는다.
- 고정·해제 요청과 공개 화면 결과를 별도로 기록한다.

## 8. 스토리 하이라이트

하이라이트는 게시물의 대체물이 아니라, 공개된 스토리를 주제별로 묶어 프로필에 남기는 기능이다.

### 8.1 추천 정보 구조

- `처음이라면`: 입문자가 먼저 볼 일반 정보
- `유도 상식`: 검수된 용어·도복·예절·기술 개념
- `코치 기록`: 실제 자료가 있는 수련·지도·일상
- `문의 안내`: 공식 경로·담당 범위가 승인된 경우에만 운영

### 8.2 운영 기준

- 이름·표지·포함 스토리 목록을 함께 승인한다.
- 가격·시간표·행사·혜택이 포함되면 효력 종료일을 둔다.
- 삭제·수정 요청과 실제 공개 결과를 분리한다.
- 회원 식별 촬영물은 공개 동의와 철회 상태를 확인한다.
- 빈 하이라이트나 생성 버튼 노출을 운영 완료로 처리하지 않는다.

## 9. 코치 개인 계정과 공식 문의 인계

프로필과 게시물은 다음 퍼널을 구분한다.

`프로필 방문 → 링크 탭 또는 DM → 공식 문의 생성 → 담당자 수락 → 적격 문의 → 체험 예약 → 실제 방문 → 계약 → 실수납`

- 공개 댓글과 DM 원문을 공개 저장소에 넣지 않는다.
- DM이 도착했다는 사실만으로 적격 문의로 분류하지 않는다.
- 코치 개인 계정이 가격·환불·좌석·운영시간의 최종 기준 시스템이 되지 않게 한다.
- 운영 문의는 확인된 공식 경로로 인계하고 담당자 수락을 기록한다.
- 기존회원·휴면회원·지점 이동 문의를 신규 리드로 중복 생성하지 않는다.
- 안전·아동보호·개인정보 사건은 일반 마케팅 큐에서 분리한다.

## 10. 변경 승인과 검증

### 10.1 승인 패키지

- 대상 계정
- 변경 전 관찰 시각과 화면 증거
- 변경할 정확한 소개 문구
- 추가·수정·삭제할 링크와 최종 목적지
- 고정·해제할 게시물 URL과 순서
- 하이라이트 이름·표지·포함 스토리
- 계정 유형을 바꾸는지 여부
- 변경 후 검증 책임자
- 롤백 값

### 10.2 실행 순서

1. 현재 프로필 읽기 전용 관찰
2. 공개 사실·링크 목적지·담당 범위 확인
3. 변경안과 롤백 값 승인
4. 승인된 필드만 변경
5. 저장 결과 확인
6. 공개 화면에서 재확인
7. 링크·버튼 최종 목적지 시험
8. 승인안과 공개값 대조
9. 불일치 시 수정 또는 롤백

소개·링크·고정·하이라이트·계정 유형을 한 번에 바꾸지 않고 필드별 결과를 기록한다.

## 11. KPI

### 11.1 프로필 품질

- 필수 필드 검증률 = `검증 완료 필드 수 / 검수 대상 필드 수`
- 링크 정상률 = `최종 목적지까지 검증된 링크 수 / 공개 링크 수`
- 고정 일치율 = `승인 순서와 일치한 고정 게시물 수 / 승인 고정 게시물 수`
- 하이라이트 현행률 = `유효한 하이라이트 수 / 검수한 하이라이트 수`

### 11.2 행동·사업 성과

- 프로필 방문
- 외부 링크 탭
- 연락처·행동 버튼 탭
- DM 시작
- 공식 문의 생성
- 적격 문의
- 체험 예약
- 실제 방문
- 신규 계약·실수납
- 휴면 복귀
- 재등록
- 환불 반영 순수납

각 수치를 기간·원천과 함께 기록한다. 연결되지 않은 비율과 매출은 계산하지 않는다.
