# 코치 개인 Instagram 프로필·문의 전환 준비 기준 v1

## 1. 목적

코치 개인 Instagram 계정의 프로필을 콘텐츠 소비 이후의 명확한 다음 단계로 설계하되, 개인 화자와 공식 브랜드 채널을 혼동하지 않고 프로필 행동을 실제 문의·체험·등록·매출로 과장하지 않는다.

## 2. 핵심 원칙

1. `코치 개인 계정`은 콘텐츠의 화자·운영 역할이고, `개인·크리에이터·비즈니스 계정`은 플랫폼 설정이다. 서로 자동 추론하지 않는다.
2. 프로필에는 계정 주체, 다루는 주제, 확인된 소속, 하나의 우선 행동을 짧게 표시한다.
3. 가격·시간표·무료 체험·지점·성과·자격은 승인된 최신 사실만 표시한다.
4. 프로필 변경은 초안, 대표 승인, 적용, 공개 검증을 분리한다.
5. 프로필 방문·링크 클릭·연락 버튼 클릭은 문의나 매출이 아니다.

## 3. 프로필 필드 검수

| 필드 | 확인할 내용 | 금지되는 단정 |
|---|---|---|
| 사용자명 | 지정 계정과 일치 | 유사 계정을 공식 계정으로 처리 |
| 표시 이름 | 사람·역할을 명확히 표현 | 확인되지 않은 직함·자격 |
| 소개 문구 | 화자·콘텐츠 범위·행동 유도 | 공식 발표 주체처럼 표현 |
| 카테고리 | 공개 화면 또는 설정에서 직접 확인 | 카테고리로 세부 계정 유형 추정 |
| 링크 | 승인된 목적지·모바일 작동·소유자 | 제3자 링크를 공식 링크로 간주 |
| 연락 버튼 | 실제 연결 정보와 승인 상태 | 버튼 노출을 유효 문의로 계산 |
| 프로필 사진 | 계정 주체와 일치 | 회원·미성년자 사진의 동의 추정 |

## 4. 소개 문구 구조

권장 순서는 다음과 같다.

1. 코치 개인의 짧은 정체성
2. 게시할 콘텐츠 범위 2~3개
3. 확인된 소속 또는 활동 맥락
4. 한 가지 행동 유도

공식 지점 계정이 아닌 경우 `공식`, `본관 공지`, `대표 안내` 같은 표현을 사용하지 않는다. 개인 경험·지도 철학·당일 수련은 근거가 있을 때만 1인칭으로 쓴다.

## 5. 링크와 연락 경로

- 대표가 승인한 공식 문의·예약 목적지만 사용한다.
- 링크가 여러 개여도 프로필의 우선 행동은 하나로 정한다.
- 링크 단축 또는 제3자 랜딩 페이지는 소유자·개인정보 처리·최종 목적지를 검증한다.
- UTM에는 개인 이름·전화번호·회원번호 등 식별정보를 넣지 않는다.
- 변경 전과 후에 모바일 열림, 리디렉션, 대상 지점, 오류 화면을 확인한다.
- 연락 버튼의 노출·클릭·앱 열림·발신·연결·유효 문의를 별도 사건으로 기록한다.

## 6. 상태 모델

`PROFILE_DRAFT → REPRESENTATIVE_APPROVED → APPLIED → PUBLIC_VERIFIED → DESTINATION_VERIFIED → INQUIRY_OBSERVED`

- 초안 작성은 프로필 변경이 아니다.
- 승인만으로 적용 완료가 되지 않는다.
- 저장 성공만으로 공개 화면 검증이 되지 않는다.
- 링크가 열려도 문의가 발생한 것은 아니다.
- DM 알림이나 전화 클릭은 유효 문의가 아니다.
- 예약은 실제 체험이 아니며 체험은 계약·실정산이 아니다.

## 7. 이벤트와 KPI 정의

| 단계 | 최소 증거 | 다음 단계로 자동 승격 금지 |
|---|---|---|
| 프로필 방문 | 플랫폼 프로필 활동 지표 | 링크 클릭 |
| 링크 클릭 | 링크 또는 랜딩 분석 사건 | 문의 |
| 연락 버튼 클릭 | 플랫폼 버튼 지표 | 통화 연결 |
| 문의 접수 | 채널 수신 사건 | 유효 문의 |
| 사람 응답 | 담당자의 실제 응답 | 고객 회신 |
| 예약 확정 | 예약 상태·시각·지점 | 실제 방문 |
| 실제 체험 | 출석 또는 담당 확인 | 등록 |
| 계약 활성 | 승인된 계약 사건 | 실정산 |
| 순수납 | 정산에서 환불·차지백 반영 | 콘텐츠 단독 매출 |

분자·분모·기간·원천이 없으면 전환율을 계산하지 않는다. 동일 인물의 복수 채널 접점을 중복 문의·등록·매출로 합산하지 않는다.

## 8. 채널별 역할

- Instagram: 코치의 수련·지도 맥락과 입문자의 질문을 설명하고 한 가지 문의 경로로 연결한다.
- 네이버·Google 비즈니스 프로필: 실제 지점의 주소·영업정보·전화·공식 링크를 관리한다.
- 당근 등 지역 채널: 지역 게시물 또는 채팅을 독립 원천으로 기록한다.
- 개인 Instagram을 지점 공식 프로필이나 대표 공지 채널로 자동 분류하지 않는다.

## 9. 실험 EXP-433 — 프로필부터 순수납까지 판정 정확도

합성 계정 120개, 프로필·링크·연락·문의·예약·출석·계약·정산 사건으로 다음 오류가 모두 0건인지 검증한다.

- 코치 개인 계정을 브랜드 공식 계정으로 분류
- 공개 카테고리로 크리에이터·비즈니스 세부 유형을 추정
- 승인되지 않은 소개 문구·링크·연락처 적용
- 프로필 방문이나 링크 클릭을 문의로 계산
- 연락 버튼 클릭을 연결 통화로 계산
- DM 알림을 유효 문의로 계산
- 예약을 실제 체험으로 계산
- 체험을 계약·실정산으로 계산
- 한 실정산을 여러 채널·지점에 중복 귀속
- UTM에 개인 식별정보 포함
- 동의 미확인 회원 촬영물·후기 사용

하나라도 실패하면 자동 프로필 변경, 링크 교체, 고객 발송, 전환·매출 보고를 중단한다.

## 10. 대표 승인·입력

- 계정의 공개 역할과 사용 가능한 소속 표기
- 표시 이름·소개 문구·프로필 사진
- 승인된 공식 문의 또는 예약 링크
- 링크 대상 지점과 담당자
- 서비스 문의와 광고성 후속 연락의 동의 기준
- 유효 문의·예약·실제 체험·등록·실정산 정의
- 최초·마지막·보조 접점 귀속기간
- 프로필 변경 승인자와 공개 검증 담당자

## 11. 근거

- Instagram 프로필은 표시 이름, 소개 문구, 카테고리, 링크, 연락 기능을 서로 다른 요소로 노출할 수 있으므로 각 필드를 개별 검증해야 한다: https://help.instagram.com/
- Instagram의 프로페셔널 대시보드는 프로페셔널 계정용 관리 진입점이지만, 공개 노출만으로 크리에이터와 비즈니스 중 세부 유형을 단정하지 않는다: https://about.instagram.com/
- Google Analytics 캠페인 URL은 source·medium·campaign·content 값을 구분하며 대소문자를 구분하므로 일관된 명명 규칙이 필요하다: https://support.google.com/analytics/answer/10917952?hl=ko

## 12. 감사 기준

- 승인 대기 프로필 문구와 실제 링크는 공개 저장소에 올리지 않는다.
- 회원·보호자 식별정보, 연락처, 출석·건강·결제자료를 프로필·UTM·공개 문서에 넣지 않는다.
- 미확정 행사, 가격, 혜택, 지점, 시간표를 공개 사실처럼 쓰지 않는다.
- 적용·공개 검증·문의·체험·정산의 증거가 없으면 `데이터 미연결` 또는 `계산 불가`로 남긴다.
