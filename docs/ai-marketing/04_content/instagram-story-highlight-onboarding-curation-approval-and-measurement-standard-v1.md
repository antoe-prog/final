# Instagram 스토리 하이라이트 온보딩·승인·측정 기준 v1

## 1. 목적

코치 개인 Instagram 계정의 하이라이트를 신규 방문자의 온보딩 경로로 설계한다. 기존 공개 콘텐츠를 재사용하되 스토리 재게시와 하이라이트 생성은 별도 외부 공개 행위로 관리하고, 조회를 문의·체험·매출로 과장하지 않는다.

## 2. 적용 원칙

1. 하이라이트가 실제로 없거나 비어 있는지는 로그인된 계정 소유자 화면과 공개 화면을 구분해 확인한다.
2. 하이라이트는 계정의 화자·주제·입문 정보·기존 콘텐츠 탐색을 돕는다.
3. 코치 개인 계정을 본관·브랜드 공식 발표 채널로 표현하지 않는다.
4. 기존 피드 게시물의 재사용도 새로운 스토리 공개이므로 별도 승인한다.
5. 가격·시간표·혜택·행사·문의 링크는 최신 승인 정보가 있을 때만 포함한다.

## 3. 권장 정보 구조

초기 계정은 3~5개의 짧은 하이라이트로 시작한다.

| 유형 | 역할 | 사용할 수 있는 근거 |
|---|---|---|
| 처음 | 입문자가 묻는 기본 질문 | 공개 완료 입문 콘텐츠 |
| 준비 | 방문 전 확인할 항목 | 승인된 일반 안내 |
| 상식 | 도복·규칙·기초 개념 | 공식 자료로 검증된 콘텐츠 |
| 수련 | 수련을 돌아보는 관점 | 공개 완료 코치 콘텐츠 |
| 문의 | 공식 문의 경로 | 대표 승인 링크·담당·지점 |

문의 경로가 미승인 상태라면 문의 하이라이트를 공개하지 않는다.

## 4. 제작 기준

- 제목은 모바일 프로필에서 식별할 수 있도록 짧게 쓴다.
- 표지는 동일한 색상·선 굵기·중앙 안전영역을 사용한다.
- 각 하이라이트 첫 장은 주제, 중간 장은 독립 정보, 마지막 장은 행동 유도 한 가지로 구성한다.
- 다른 하이라이트의 문장을 반복해 장수만 늘리지 않는다.
- 실제 코치 경험·회원 후기·대회 실적은 근거가 있을 때만 사용한다.
- 회원이 식별되는 촬영물은 공개 사용 동의를 확인한다.

## 5. 상태 모델

HIGHLIGHT_CONCEPT → COVER_READY → STORY_MEDIA_READY → REPRESENTATIVE_APPROVED → STORY_PUBLISHED → HIGHLIGHT_CREATED → PUBLIC_VERIFIED

- 표지 완성은 스토리 완성이 아니다.
- 스토리 게시 성공은 하이라이트 생성 완료가 아니다.
- 하이라이트 이름·표지·순서가 공개 화면에서 확인되어야 공개 완료다.
- 기존 스토리 보관함에 있다는 사실만으로 재공개 승인이 생기지 않는다.

## 6. 변경·삭제 통제

- 이름·표지·포함 스토리 변경은 변경 전후 버전을 기록한다.
- 삭제 전 해당 스토리가 다른 하이라이트에 사용되는지 확인한다.
- 만료된 가격·혜택·시간표는 즉시 검토 대상으로 표시한다.
- 수정 또는 삭제 성공을 공개 화면에서 다시 확인한다.
- 플랫폼의 편집·삭제 가능 여부와 내부 승인 권한을 구분한다.

## 7. 측정 기준

| 사건 | 의미 | 자동 승격 금지 |
|---|---|---|
| 스토리 노출 | 화면 표시 | 완독 |
| 다음 장 이동 | 탐색 행동 | 관심 |
| 프로필 이동 | 프로필 열기 | 문의 |
| 링크 클릭 | 목적지 열기 | 예약 |
| DM 알림 | 수신 사건 | 유효 문의 |
| 예약 확정 | 예약 사건 | 실제 체험 |
| 실제 체험 | 출석 확인 | 계약 |
| 실정산 | 환불·차지백 반영 수납 | 하이라이트 단독 매출 |

하이라이트별 조회를 사람 수로 단순 합산하지 않는다. 분자·분모·관찰기간·원천이 없으면 완독률과 전환율을 계산하지 않는다.

## 8. EXP-434 — 하이라이트 승인·공개·전환 판정 정확도

합성 하이라이트 240개와 스토리·프로필·링크·문의·예약·출석·정산 사건으로 다음 오류가 모두 0건인지 검증한다.

- 하이라이트 초안을 공개 완료로 계산
- 표지 완성을 스토리 미디어 완성으로 계산
- 기존 공개 게시물 승인을 스토리 재게시 승인으로 확대
- 스토리 게시를 하이라이트 생성으로 계산
- 보관함 저장을 공개 상태로 계산
- 만료 가격·시간표·혜택 유지
- 스토리 노출·프로필 이동을 문의로 계산
- 예약을 실제 체험으로 계산
- 동일 결제를 여러 하이라이트·채널에 중복 귀속
- 동의 미확인 회원 촬영물 사용

하나라도 실패하면 자동 스토리 게시, 하이라이트 생성·수정·삭제와 전환·매출 보고를 중단한다.

## 9. 대표 승인·입력

- 공개할 하이라이트명과 순서
- 표지 디자인
- 각 스토리의 최종 미디어·문구
- 공식 문의 링크·지점·담당자
- 가격·시간표·혜택의 유효기간과 승인자
- 스토리 재사용 허용 범위
- 게시 후 공개 검증 담당자
- 노출·프로필 이동·문의·체험의 관찰기간

## 11. 감사 기준

- 승인 대기 표지·스토리 문구는 공개 저장소에 포함하지 않는다.
- 회원·보호자 식별정보, 연락처, 출석·건강·결제자료를 포함하지 않는다.
- 미확정 행사·가격·시간표·무료 체험·혜택을 공개 사실처럼 쓰지 않는다.
- 실제 업로드·생성·수정·삭제·고객 연락을 실행하지 않았다면 실행했다고 보고하지 않는다.
