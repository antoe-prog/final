# 회원·미성년자 촬영물 동의·보호·철회·공개 통제 기준 v1

- 적용 조직: 파이널유도멀티짐 공개 마케팅 실무
- 적용 채널: Instagram, 네이버, 당근, 웹, 인쇄물, 광고 소재
- 문서 상태: 공개 가능한 운영 기준 / 실제 촬영·게시·삭제·연락 전
- 기준일: 2026-09-15
- 내부 회원수·전환율·매출 및 동의 현황: **데이터 미연결**

## 1. 오늘의 판단

회원이 등장하는 사진·영상은 `촬영 동의 있음` 하나로 게시 가능 여부를 판단하지 않는다. **촬영 → 저장 → 편집 → 채널별 공개 → 재사용 → 철회 → 통제 가능한 공개본 처리**를 하나의 수명주기로 관리해야 한다.

특히 미성년자가 포함될 수 있는 유도장 콘텐츠는 신규 체험 유입에 도움이 될 수 있어도 보호 원칙이 우선이다. 동의를 받지 못한 사람을 피해서 촬영하는 운영안, 공개 범위와 기간, 철회 시 기존 게시물·파생본을 찾는 절차가 없으면 실제 촬영을 시작하지 않는다.

핵심 게이트는 다음과 같다.

`목적 확정 → 촬영 적격성 → 동의·의사 확인 → 안전한 촬영 → 승인된 편집 → 채널별 공개 승인 → URL·파생본 기록 → 철회·만료 전파`

## 2. 기존 기준과 이번 문서의 범위

기존 `Multi-Branch Visual Proof Standard v1`은 회원·보호자 동의 확인과 식별정보 노출 방지를 요구한다. 기존 `Instagram AI 생성 미디어 표시·출처·코치 진정성 기준 v1`은 미디어별 출처·해시·동의 상태를 기록한다.

이번 기준은 그 다음 공백을 채운다.

- 동의를 목적·채널·기간·재사용 범위별로 분리
- 미성년자 촬영 전 보호자 확인과 당사자의 현재 의사 확인을 분리
- 촬영하지 않는 회원을 안전하게 제외하는 운영 방법 정의
- 원본·편집본·썸네일·인쇄물·광고 등 파생본 추적
- 동의 철회·기간 만료 시 새 사용 중단과 기존 통제본 처리
- 삭제 완료와 제3자 복제 회수 불가를 구분

이 문서는 법률 자문을 대체하지 않는다. 구체적인 동의서, 보유기간, 예외 적용과 분쟁은 대표가 지정한 개인정보·법무 검토자가 확정한다.

## 3. 법적 기준과 내부 보호 기준의 구분

### 3.1 대한민국 개인정보 보호법에서 확인한 최소 기준

2026년 9월 11일 시행 개인정보 보호법을 기준으로 다음을 확인했다.

- 제22조의2: 만 14세 미만 아동의 개인정보를 처리하기 위해 법에 따른 동의를 받아야 할 때에는 법정대리인의 동의를 받고 그 동의 여부를 확인해야 한다.
- 제22조: 동의 사항을 구분해 정보주체가 명확히 인지할 수 있게 알려야 하며, 홍보·판매 권유 목적 동의를 거부했다는 이유만으로 서비스 제공을 거부해서는 안 된다.
- 제37조: 정보주체는 개인정보 처리정지 또는 동의 철회를 요구할 수 있다. 처리자는 법정 예외가 없는 범위에서 필요한 조치를 해야 한다.
- 제21조: 보유기간 경과나 처리 목적 달성 등으로 개인정보가 불필요해지면 법정 보존 예외가 없는 범위에서 지체 없이 파기해야 한다.

식별 가능한 회원 촬영물이 개인정보에 해당하는지, 특정 이용 방식에 어떤 처리 근거가 필요한지는 실제 자산·계약·이용 맥락을 법무 검토한다. `도장 안에서 찍었다`거나 `수업에 참여했다`는 사실만으로 홍보 공개 동의가 생겼다고 보지 않는다.

### 3.2 내부 보호 기준

다음은 한국 법령의 연령 기준을 바꾸는 주장이 아니라, 스포츠 현장의 안전을 높이기 위한 내부 통제다.

- 보호자 동의가 있더라도 촬영 시점에 당사자가 싫다고 하면 촬영·사용을 중단한다.
- 어린 회원에게도 이해할 수 있는 말로 촬영 목적과 공개 범위를 설명한다.
- 가입·수업 참여·승급·혜택을 홍보 촬영 동의의 대가나 조건으로 만들지 않는다.
- 미성년자 촬영에는 조직 소유 또는 대표가 승인한 장비와 담당자만 사용한다.
- 탈의실·화장실·샤워실·응급처치 공간은 촬영 금지 구역으로 둔다.

## 4. 동의 단위를 분리한다

한 번의 포괄 동의로 아래 항목을 모두 묶지 않는다.

| 동의 단위 | 확인할 내용 | 미확인 시 처리 |
|---|---|---|
| 촬영 | 사진·영상·음성 중 무엇을 촬영하는가 | 촬영 제외 |
| 저장 | 원본과 편집본을 어디에 얼마나 보관하는가 | 저장 금지 |
| 내부 이용 | 수업 피드백·내부 교육에 쓰는가 | 내부 이용 보류 |
| 공개 게시 | 어떤 채널과 계정에 공개하는가 | 해당 채널 게시 보류 |
| 인쇄 | 포스터·배너·리플릿에 쓰는가 | 인쇄 보류 |
| 광고 | 유료 광고 소재로 쓰는가 | 광고 보류 |
| 재편집 | 자르기·자막·리믹스·합성 허용 범위 | 재편집 보류 |
| 재사용 | 다른 캠페인·지점·기간에 다시 쓰는가 | 신규 승인 검토 |
| 식별 정보 | 이름·학교·연령·지점·태그를 함께 공개하는가 | 함께 공개 금지 |

`Instagram 게시 동의`를 네이버·당근·유료 광고·인쇄물 동의로 자동 확장하지 않는다. 코치 개인 계정의 게시 동의를 도장 공식 계정이나 지점 광고의 동의로 자동 확장하지 않는다.

## 5. 비공개 동의 원장

회원·보호자 식별정보와 동의 증거는 공개 GitHub가 아닌 승인된 비공개 시스템에 저장한다.

### 5.1 최소 필드

- `subject_id`: 비공개 내부 식별자
- `guardian_verification_status`: 해당 시 법정대리인 확인 상태
- `consent_version`: 제시한 동의 문구 버전
- `purpose_scope`: 촬영·내부 이용·공개·광고 등 목적
- `channel_scope`: 승인된 채널·계정
- `asset_scope`: 특정 촬영 또는 자산 범위
- `valid_from`, `valid_until`: 유효기간
- `storage_location`: 승인된 원본 보관 위치
- `consent_evidence`: 동의와 확인 증거 위치
- `current_willingness_checked_at`: 촬영 당일 의사 확인 시각
- `withdrawal_method`: 철회 접수 경로
- `status`: 현재 상태
- `reviewer`, `reviewed_at`: 검토자와 시각

### 5.2 상태값

| 상태 | 의미 |
|---|---|
| DRAFT | 문구만 준비, 동의 미획득 |
| RECEIVED | 동의 입력 수신, 신원·범위 미검증 |
| VERIFIED | 주체와 범위 검증 완료 |
| ACTIVE | 기간·목적·채널 내에서 사용 가능 |
| EXPIRED | 유효기간 만료, 새 사용 금지 |
| WITHDRAWN | 동의 철회, 새 처리·사용 보류 |
| TAKEDOWN_PENDING | 통제 가능한 공개본 처리 중 |
| REMOVED | 지정된 통제본 처리 완료 |
| LEGAL_HOLD | 법정 보존·분쟁 등 사람 검토 필요 |
| UNKNOWN | 증거 불명, 사용 금지 |

`RECEIVED`를 `ACTIVE`로 간주하지 않는다. 계약이 유지 중이거나 과거 게시물이 남아 있다는 이유로 동의가 계속 유효하다고 판단하지 않는다.

## 6. 자산·공개본 등록부

철회가 들어왔을 때 어디에 무엇이 공개됐는지 찾을 수 있도록 비공개 등록부를 유지한다.

### 6.1 자산 필드

- `asset_id`
- 원본·편집본 SHA-256
- 촬영일·촬영 목적·촬영 담당
- 등장 인물의 비공개 동의 상태 참조
- 편집 이력과 생성형 AI 사용 여부
- 승인된 채널·계정·기간
- 승인 버전과 승인자

### 6.2 공개본 필드

- `publication_id`
- `asset_id`와 파생본 관계
- 채널·계정
- 공개 URL 또는 인쇄 배포 식별자
- 게시·배포 시각
- 썸네일·리사이즈·자막본·광고본 목록
- 공개 상태
- 제거 요청·완료·거절·실패 시각과 사유

한 게시물의 표지, 캐러셀 일부, Reel 커버, Story 재공유, 네이버 썸네일을 각각 파생본으로 연결한다.

## 7. 촬영 당일 운영

### 7.1 구역 설계

- **GREEN:** 승인된 담당자가 동의 확인된 사람만 촬영하는 구역·시간
- **YELLOW:** 배경 인물·거울·창문 반사·이름표를 추가 확인하는 구역
- **RED:** 탈의실·화장실·샤워실·응급처치·건강상담 등 촬영 금지 구역

촬영 비동의자를 특정 색 팔찌 등으로 공개 표시해 낙인·추측을 만들지 않는다. 담당자가 비공개 명단 또는 촬영 배치표로 확인하고, 카메라 각도·그룹 배치·별도 촬영 시간을 조정한다.

### 7.2 촬영 전 체크

1. 오늘 촬영 목적과 공개 후보 채널을 알린다.
2. 동의 원장의 상태·범위·기간을 확인한다.
3. 미성년자는 필요한 보호자 확인 상태를 검증한다.
4. 당사자에게 촬영 의사를 다시 묻는다.
5. 비동의자의 안전한 제외 동선을 정한다.
6. 도복 이름표, 학교명, 전화 화면, 차량번호, 건강 정보 노출을 점검한다.
7. 촬영 담당·장비·원본 저장 위치를 확인한다.
8. 수업 안전과 흐름을 해치면 촬영을 중단한다.

### 7.3 이미지 선택 기준

- 활동과 기술 설명이 중심인 장면을 우선한다.
- 불필요한 얼굴 클로즈업과 식별정보 결합을 줄인다.
- 넘어짐·고통·응급처치·신체 노출을 홍보 장면으로 사용하지 않는다.
- 굴욕적·희화화될 수 있는 표정이나 각도를 제외한다.
- 실제 수업 강도·진행과 다른 장면을 연출해 초보자에게 오해를 주지 않는다.
- 안전한 대안이 필요하면 코치 단독, 손·발·도복·매트, 비식별 후면, 명확한 일러스트를 사용한다.

### 당근

- 동네·학교·생활권 정보와 미성년자 얼굴을 결합하지 않는다.

### 유료 광고·인쇄물

- 일반 게시 동의와 별도 범위가 확인될 때만 사용한다.
- 광고 대행사·인쇄업체에 전달되는 파일과 보유기간을 기록한다.
- 집행 종료가 곧 파일 삭제를 의미하지 않으므로 회수·파기 결과를 별도로 확인한다.

## 9. 동의 철회·기간 만료 처리

### 9.1 철회 접수 즉시

1. 접수 주체와 대상 범위를 안전하게 확인한다.
2. 상태를 `WITHDRAWN` 또는 `TAKEDOWN_PENDING`으로 바꾼다.
3. 예약 게시·광고·재편집·새 배포 후보에서 제외한다.
4. 자산 해시로 원본·편집본·공개 URL·파생본을 조회한다.
5. 법정 보존·분쟁 등 예외 가능성이 있으면 자동 삭제하지 않고 검토한다.

### 9.2 통제 가능한 공개본

- 자사 계정 게시물·썸네일·하이라이트·예약본
- 자사 웹·네이버·당근 게시물
- 운영 중인 유료 광고 소재
- 보유 중인 인쇄물과 대행사 전달본

승인된 담당자가 삭제·교체·집행중단을 수행하고, 각 결과를 `REMOVED`, `FAILED`, `LEGAL_HOLD` 등으로 기록한다. 공개 게시물 삭제나 광고 중단도 외부 행동이므로 대표 권한과 사고 대응 규칙에 따라 실행한다.

### 9.3 통제 불가능하거나 회수가 어려운 복제본

온라인 공개 이후 제3자가 저장·공유·캡처한 사본까지 모두 회수할 수 있다고 약속하지 않는다. 가능한 신고·삭제 요청을 검토하되 `원본 게시물 삭제 완료`와 `인터넷상의 모든 사본 삭제`를 혼합하지 않는다.

철회 접수자에게는 다음을 구분해 알린다.

- 새 사용 중단 여부
- 자사 통제본 처리 범위와 결과
- 법정 예외 또는 처리 불가 사유
- 제3자 복제본의 현실적 한계
- 추가 문의 경로

### 9.4 기간 만료

만료 자산은 자동으로 재승인되지 않는다. 새 게시·재업로드·캠페인 재사용 전에 목적·채널·기간을 다시 검토한다. 단지 오래된 회원 사진이라는 이유로 아카이브 가치가 우선한다고 판단하지 않는다.

## 10. 사고 대응

다음은 일반 마케팅 검수보다 빠른 보호 경로로 이관한다.

- 미성년자 또는 보호자가 즉시 공개 중단을 요청한 경우
- 촬영 금지 구역이나 부상·건강 정보가 노출된 경우
- 이름·학교·위치·연락 정보가 결합된 경우
- 무동의 인물이 식별 가능한 경우
- 이미지가 조롱·합성·도용·성적 오용에 사용된 정황이 있는 경우
- 담당자 개인기기에 원본이 남아 있거나 외부 전송이 확인된 경우

사고 기록에는 공개 URL, 발견 시각, 임시 조치, 담당자, 다음 기한을 남긴다. 공개 보고서나 GitHub에는 피해자 식별정보를 남기지 않는다.

## 12. KPI

### 12.1 보호·운영 품질

- 동의 범위 완전율 = 목적·채널·기간·철회 경로가 모두 있는 활성 동의 / 활성 동의
- 촬영 당일 의사 확인율 = 당일 확인 완료 인원 / 촬영 대상 인원
- 자산 추적 완전율 = 해시·동의 참조·파생본·공개 URL이 연결된 자산 / 공개 자산
- 철회 억제 반영률 = 새 사용이 차단된 철회 자산 / 철회 대상 자산
- 통제본 처리 완전율 = 결과가 기록된 통제본 / 확인된 통제본
- 무동의 식별 가능 공개 사고 수
- 촬영 금지 구역 공개 사고 수

### 12.2 콘텐츠 성과

- 조회·도달·저장·공유·댓글
- 프로필 방문·귀속 팔로우

### 12.3 사업 성과

- 유효 문의
- 체험 예약
- 실제 체험 참석
- 신규 등록
- 휴면 복귀
- 재등록
- 순수납

보호 KPI가 충족되지 않으면 조회·문의가 늘어도 실험 성공으로 판정하지 않는다. 분모가 0이거나 데이터가 연결되지 않으면 비율을 계산하지 않는다.

현재 모든 동의·촬영·철회·사업 KPI는 **데이터 미연결**이다.

## 13. 실험

### EXP-326 — 촬영물 동의·철회 전파 완전성

- 1단계: 실제 회원정보가 없는 합성 동의·자산·공개본 레코드 10건
- 2단계: 대표 승인과 법무 검토 후 실제 신규 촬영 후보의 비식별 상태값만 검증
- 변경 변수: 기존 단일 동의 확인 대 목적·채널·기간·파생본 등록부

#### 성공 기준

- 목적·채널·기간·철회 경로 기록률 100%
- 촬영 당일 당사자 의사 확인률 100%
- 원본·편집본·공개 URL·파생본 연결률 100%
- 철회 자산의 예약·광고·재사용 억제 반영률 100%
- 통제본별 처리 결과 기록률 100%
- 무동의 미성년자·회원 공개 0건
- 촬영 금지 구역·민감정보 공개 0건
- 모든 인터넷 사본 삭제와 같은 과장 보고 0건
- 승인 없는 촬영·게시·삭제·광고 변경 0건

#### 보류 조건

- 현재 동의서 버전과 법적 검토 상태 미확인
- 촬영 장비·보관 위치·담당 권한 미확인
- 기존 공개 자산과 동의 원장 연결 불가
- 지점·계정별 삭제·광고 중단 권한 미확인

#### 중단 조건

- 회원가입이나 혜택을 동의 조건으로 요구
- 보호자 동의만으로 당사자의 현재 거부를 무시
- 포괄 동의를 모든 채널·기간·광고에 확장
- 철회 후 새 게시·재업로드·광고 집행 지속
- 공개 저장소에 회원·보호자 식별정보 또는 동의서 원문 저장

## 14. 필요한 대표 승인·입력

1. 현재 촬영·초상·홍보 동의서와 문구 버전
2. 프로그램별 연령 확인 방법과 만 14세 미만 법정대리인 확인 절차
3. 개인정보·법무 검토 책임자
4. 허용할 촬영 목적·채널·계정·재사용 범위·보유기간
5. 조직 승인 장비·촬영 담당·원본 보관 위치
6. 비동의자를 안전하게 제외하는 수업·촬영 운영안
7. 철회 접수 채널과 긴급 공개중단 책임자·처리기한
8. 기존 게시물·광고·인쇄물·대행사 파일의 비공개 목록
9. 촬영물 동의와 광고 수신동의를 분리하는 운영 원칙

실제 회원 촬영, 동의 요청, 게시·삭제, 광고 중단, 고객 연락, 계정 변경은 대표 승인 없이 실행하지 않는다.

## 15. 근거 출처와 적용 한계

### 대한민국 공식 법령

- 국가법령정보센터, `개인정보 보호법`, 2026-09-11 시행, 법률 제21445호. 제21조, 제22조, 제22조의2, 제37조를 확인했다.  
  https://law.go.kr/LSW/lsInfoP.do?lsId=011357

이 기준은 공식 법령의 원칙을 운영 절차로 옮긴 것이다. 특정 촬영물의 개인정보 해당성, 동의 외 처리 근거, 법정 보존 예외와 삭제 범위는 실제 사안별 검토가 필요하다.

### 스포츠 보호 보조 기준

- NSPCC Child Protection in Sport Unit, `Photography and filming in sports and activities`, 2025-11-25 갱신. 촬영 목적·향후 사용·보유기간·저장·철회 방법을 사전에 알리고 기록할 것, 조직 장비와 승인 담당자를 사용할 것, 탈의·화장실·응급처치 구역을 제외할 것, 온라인 공개 후 회수가 어려울 수 있음을 설명한다.  
  https://sport.nspcc.org.uk/help-advice/topics/photography-and-filming-in-sports-and-activities/

NSPCC의 보호자 동의 연령 기준은 영국 맥락이므로 한국 법률 기준으로 채택하지 않는다. 이 문서에서는 촬영구역·장비·당사자 의사·온라인 회수 한계 등 스포츠 보호 운영 원칙만 참고했다.

## 16. Auditor 결론

촬영 동의는 영구적이고 무제한인 콘텐츠 사용권이 아니다. 파이널유도멀티짐은 회원과 미성년자의 이미지를 신규 획득 수단으로 사용하기 전에 목적·채널·기간·철회 경로를 분리하고, 자산 해시에서 실제 공개 URL과 파생본까지 추적해야 한다.

이 공개 문서에는 회원·보호자 이름, 연락처, 동의서 원문, 실제 촬영물, 출석·건강·결제정보, 승인 대기 Instagram 미디어·캡션, 미확정 FINAL ROAD·가격·혜택을 포함하지 않는다.
