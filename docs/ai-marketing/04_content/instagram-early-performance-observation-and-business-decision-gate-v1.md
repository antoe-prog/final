# Instagram 게시 초기 성과 관찰·사업판단 게이트 v1

- 적용 대상: 파이널유도멀티짐 관련 코치 개인 Instagram 게시물
- 문서 성격: 공개 가능한 측정·판정 기준
- 기준일: 2026-09-15
- 기준 시간대: Asia/Seoul
- 내부 문의·회원·매출 데이터: 데이터 미연결
- 승인 대기 미디어·캡션: 포함하지 않음

## 1. 오늘의 판단

조회나 도달이 처음 나타난 것은 `데이터 수집 시작`이지 `콘텐츠 성공`이 아니다.

게시 직후의 작은 수치로 다음 게시물의 주제·형식·CTA를 바꾸면 자연 변동과 실제 차이를 구분할 수 없다. 게시물마다 공개 확인, 데이터 가용성, 관찰기간 성숙, CTA 결과, 사업 결과를 순서대로 통과한 뒤 판단한다.

## 2. 이 기준이 막는 오류

- 조회가 0인 게시물을 즉시 실패로 판정
- `-`, 미제공, 미집계를 숫자 0으로 변환
- 도달 1과 조회 3을 중복 사용자 4명으로 합산
- 좋아요 1건을 문의 또는 등록으로 처리
- 관찰시간이 다른 게시물을 같은 조건으로 비교
- 저장 CTA 게시물과 댓글 CTA 게시물을 좋아요만으로 비교
- 플랫폼 수치를 신규회원·복귀·재등록·매출로 확대 해석
- 이미 게시한 콘텐츠를 성과 확인 전에 중복 발행

## 3. 지표의 최소 해석

### 조회

- 콘텐츠가 조회된 횟수로 기록한다.
- 동일 사용자의 반복 노출이 포함될 수 있으므로 사람 수로 해석하지 않는다.
- 도달과 더해 총사용자 수를 만들지 않는다.

### 도달

- 콘텐츠를 한 번 이상 본 고유 계정의 추정치로 다룬다.
- Meta는 도달을 추정 지표로 설명하므로 확정 인원으로 표현하지 않는다.

### 좋아요·댓글·저장·공유·팔로우

- 각 행동을 별도 사건으로 기록한다.
- 합계가 필요하면 `상호작용 합계`라고 명시하되 구성 항목을 함께 남긴다.
- CTA와 직접 연결되는 행동을 1차 지표로 사용한다.

### 프로필 방문·문의

- 프로필 방문은 플랫폼 행동이다.
- DM·전화·채팅 등 실제 문의는 별도 사업 사건이다.
- 문의 경로와 게시물 귀속이 확인되지 않으면 콘텐츠 성과로 연결하지 않는다.

## 4. 값 상태 코드

| 코드 | 의미 | 계산 사용 |
|---|---|---|
| OBSERVED_ZERO | 원천이 명시적으로 0을 반환 | 분모 조건을 충족할 때만 사용 |
| OBSERVED_VALUE | 원천이 1 이상의 값을 반환 | 사용 가능 |
| NOT_AVAILABLE | 원천에 항목이 없음 또는 `-` | 사용 금지 |
| NOT_COLLECTED | 기능·요금제·권한상 미수집 | 사용 금지 |
| NOT_MATURE | 승인된 관찰기간이 지나지 않음 | 최종판정 금지 |
| NOT_LINKED | 사업 데이터가 연결되지 않음 | 사업성과 계산 금지 |
| SOURCE_CONFLICT | 플랫폼·도구 간 값 불일치 | 해소 전 판정 보류 |

`NOT_AVAILABLE`, `NOT_COLLECTED`, `NOT_MATURE`, `NOT_LINKED`는 모두 0이 아니다.

## 5. 다섯 단계 판단 게이트

### G0 — 공개 게시 검증

필수 증거:

- 승인된 계정
- 공개 URL
- 미디어 수와 순서
- 승인 캡션 일치
- 실제 공개 상태

통과 전에는 성과 관찰을 시작하지 않는다.

### G1 — 지표 가용성

필수 기록:

- 원천
- 조회시각
- 게시시각
- 지표별 값 상태 코드
- 게시물 URL

조회·도달 중 하나가 나타나도 다른 항목의 미제공 상태를 0으로 바꾸지 않는다.

### G2 — 관찰기간 성숙

대표가 승인할 기본 관찰 지점을 게시시각 기준으로 기록한다.

- 초기 확인: 공개 검증 직후
- 1차 관찰: 제안 T+24시간
- 2차 관찰: 제안 T+72시간
- 성숙 관찰: 제안 T+7일

위 시간은 업계 성과 기준이 아니라 비교 조건을 맞추기 위한 내부 제안이다. 대표 승인 전에는 임의의 성공 임계값으로 사용하지 않는다.

### G3 — CTA 결과

| CTA | 1차 관찰지표 | 보조지표 | 성공으로 계산하지 않는 값 |
|---|---|---|---|
| 저장 | 저장 | 도달·조회 | 좋아요만 발생 |
| 질문 | 댓글 또는 확인 가능한 질문 | 저장·공유 | 조회만 발생 |
| 팔로우 | 게시물 귀속 신규 팔로우 | 프로필 방문 | 전체 팔로워 수 변화만 있음 |
| 수업 문의 | 귀속 가능한 유효 문의 | 프로필 방문 | 링크 클릭 또는 DM 열기만 있음 |

CTA 결과가 0이어도 관찰기간이 성숙하지 않았으면 실패로 확정하지 않는다.

### G4 — 사업 결과

콘텐츠 성과와 아래 사건을 분리해 연결한다.

1. 유효 문의
2. 체험 예약
3. 실제 체험 참석
4. 신규 등록
5. 복귀 문의·예약·실제 출석
6. 재등록
7. 환불·차지백 반영 순수납

귀속키·관찰기간·기준 시스템이 없으면 `데이터 미연결`로 남긴다.

## 6. 비교 가능 조건

게시물 비교는 아래가 모두 같거나 차이를 명시할 때만 한다.

- 계정
- 형식
- CTA
- 관찰 경과시간
- 지표 원천
- 지표 정의
- 유료 노출 포함 여부
- 게시 상태

표본이 매우 작을 때는 순위보다 `데이터 가용`, `CTA 행동 발생`, `사업 연결 가능` 여부만 판단한다.

## 7. 비율 계산 규칙

### 도달 대비 행동률

`해당 행동 수 / 도달 × 100`

계산 조건:

- 도달이 1 이상
- 행동 지표가 명시적으로 수집됨
- 같은 게시물·같은 조회시점
- 관찰기간 상태가 표시됨

도달이 0이거나 미제공이면 계산하지 않는다.

### 조회 대비 행동률

`해당 행동 수 / 조회 × 100`

반복 조회가 포함될 수 있으므로 사람 기준 전환율이라고 부르지 않는다.

### 사업 전환율

각 단계의 동일 코호트만 계산한다.

- 체험예약률 = 체험 예약 / 유효 문의
- 체험참석률 = 실제 참석 / 체험 예약
- 신규등록률 = 신규 등록 / 성숙한 체험 참석 코호트
- 복귀율 = 실제 복귀 출석 / 적격 휴면 연락 코호트
- 재등록률 = 검증 재등록 / 성숙한 만료예정 코호트

분자·분모·기간·원천이 없으면 계산하지 않는다.

## 8. 현재 공개 게시물 적용 원칙

- 게시물별 조회·도달·반응은 각각 기록한다.
- 새로 1 이상의 조회·도달이 나타나면 `OBSERVED_VALUE`로 바꾼다.
- 반응 0은 해당 지표가 실제로 0을 반환했을 때만 `OBSERVED_ZERO`로 기록한다.
- 게시물별 관찰 경과시간과 CTA가 다르면 단순 우열을 정하지 않는다.
- 현재 내부 문의·예약·등록·복귀·재등록·순수납은 `NOT_LINKED`다.

## 9. 네 사업 목표별 판단

### 신규 체험회원 확보

- 콘텐츠: 도달, 저장, 프로필 방문, 귀속 문의
- 사업: 유효 문의, 예약, 실제 참석, 신규 등록
- 게시물 조회만으로 신규 확보를 주장하지 않는다.

### 휴면회원 복귀

- 콘텐츠: 복귀 관련 질문, 저장, 귀속 문의
- 사업: 적격 연락, 복귀 예약, 실제 복귀 출석, 재활성
- 자연 복귀를 콘텐츠 또는 캠페인 성과로 자동 귀속하지 않는다.

### 기존회원 만족·재등록

- 콘텐츠: 질문, 저장, 확인된 피드백
- 사업: 출석 유지, 문제 해결 확인, 재등록
- 무응답을 만족으로 처리하지 않는다.

### 매출 증대

- 계약·결제·환불·차지백을 구분한다.
- 좋아요·조회·예약을 매출로 처리하지 않는다.
- 순수납 원천이 연결되지 않으면 `데이터 미연결`이다.

## 10. 채널별 보조 역할

### Instagram

- 코치 개인의 실제 수련·지도 근거와 콘텐츠 CTA를 측정한다.

### 네이버

- 검색 유입과 실제 문의 경로를 분리한다.
- 블로그 조회를 체험 예약으로 계산하지 않는다.

### 당근

- 소식 조회·채팅·쿠폰·예약을 서로 다른 사건으로 기록한다.

### Google 비즈니스 프로필

- 조회·경로·전화 행동과 실제 문의·방문을 분리한다.

## 12. 실험

### EXP-315 — 게시 초기 관찰·판정 완전성

- 대상: 다음 5개 공개 게시물
- 가설: 값 상태와 관찰 게이트를 적용하면 작은 초기 수치의 과대해석과 조기 콘텐츠 변경을 줄일 수 있다.
- 성공 조건:
  - 게시 URL·게시시각·조회시각·원천 기록률 100%
  - 모든 지표의 값 상태 코드 기록률 100%
  - 관찰기간 미성숙 상태의 최종 성공·실패 판정 0건
  - 조회와 도달의 합산 사용자 수 계산 0건
  - CTA 불일치 지표로 성공 판정 0건
  - 사업 데이터 미연결 상태의 회원·매출 성과 주장 0건
  - 승인 전 업로드·예약·발행 0건
- 보류 조건:
  - 게시시각·공개 URL·지표 원천 확인 불가
  - 관찰 지점 미승인
  - 도구 간 지표 충돌
- 중단 조건:
  - 미제공 값을 0으로 변환
  - 분모 0 또는 미제공 상태에서 비율 계산
  - 고객 연락·광고·혜택을 무승인 실행
- 현재 성과 개선폭: 데이터 미연결

## 16. Auditor 결론

- 조회·도달·사람 수를 혼동하지 않았다.
- Meta가 추정 지표로 설명하는 도달을 확정 인원으로 사용하지 않았다.
- 소수 표본에 임의의 업계 성공 임계값을 적용하지 않았다.
- T+24·72시간·7일은 내부 비교 지점 제안이며 플랫폼 공식 기준으로 표현하지 않았다.
- 공급업체의 고객 성과·자동화 수치를 내부 기준선으로 적용하지 않았다.
- 플랫폼 반응을 문의·등록·복귀·재등록·매출로 확대 해석하지 않았다.
- 승인 대기 콘텐츠와 민감정보를 공개하지 않았다.
