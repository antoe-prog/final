# 운동·건강·수련효과 주장 근거·후기·안전·전환 귀속 기준 v1

- 문서 상태: 공개 가능한 운영 기준 초안
- 적용 대상: 파이널유도멀티짐의 네이버·Instagram·당근·웹·오프라인 홍보 기획
- 기준일: 2026-09-19
- 목적: 운동·건강·수련효과를 과장하지 않고, 주장 검증과 문의·체험·등록·실수납을 분리한다.

## 1. 핵심 원칙

1. 일반적인 신체활동의 집단 수준 이점은 특정 유도 수업이 개인에게 같은 결과를 보장한다는 근거가 아니다.
2. 명시적 문장뿐 아니라 이미지, 전후 비교, 자막, 해시태그, 코치 복장, 그래프가 만드는 암시적 인상도 주장으로 검토한다.
3. 객관적으로 확인 가능한 주장은 공개 전에 근거·적용 대상·한계·기준일을 기록한다.
4. 회원 경험담과 코치 의견은 사실 확인 대상이며, 전형적 결과나 인과관계의 증거로 자동 승격하지 않는다.
5. 진단·치료·완치·재활·통증 감소·질환 예방을 약속하는 표현은 일반 마케팅 승인 범위에서 제외한다.
6. 조회·저장·문의·등록은 건강 또는 수련효과가 발생했다는 증거가 아니다.

## 2. 범위와 비범위

### 포함

- 체력·근력·유연성·균형·협응·기술 향상 표현
- 다이어트·체중·체지방·외모 변화 표현
- 자세 교정·통증 완화·부상 예방·재활 표현
- 우울·불안·ADHD·집중력·자신감 등 정신건강·발달 표현
- 면역력·성장·수면·질환 위험 등 건강 표현
- 안전성, 무부상, 누구나 가능하다는 표현
- 회원 후기, 전후 이미지, 수치, 그래프, 연구 인용

### 포함하지 않는 것

- 개인별 진료·운동처방·의학적 판단
- 실제 응급 대응과 시설 안전관리 절차
- 회원의 건강정보·상담 원문·부상기록 공개
- 미확정 가격·혜택·시간표·행사 정보

## 3. 주장 분류

| 등급 | 예시 | 기본 처리 |
|---|---|---|
| A 운영 사실 | 수업 형식, 준비물, 공개된 운영 절차 | 기준 원장과 공개값 대조 |
| B 일반 교육 | 유도의 규칙·도복·기초 용어 | 공식 규칙·신뢰 가능한 출처 확인 |
| C 기술·수행 | 균형, 낙법, 특정 기술 이해 향상 | 대상·기간·평가 방법과 한계 필요 |
| D 외모·체중 | 체중 감량, 체지방 감소, 자세 변화 | 개인차·조건·측정 근거 필요; 보장 금지 |
| E 안전·부상 | 안전하다, 부상을 막는다, 무부상 | 위험·조건·예외를 포함한 엄격 검토 |
| F 의료·재활 | 통증 치료, 재활, 질환 예방·개선 | 일반 마케팅 승인 범위에서 제외 |
| G 정신건강·발달 | 우울·불안·ADHD 개선, 키 성장 | 일반 마케팅 승인 범위에서 제외 또는 전문 검토 필수 |

한 콘텐츠에 여러 등급이 있으면 가장 높은 위험 등급으로 처리한다.

## 6. 근거 판단

### 근거 계층

1. 최신 공공기관·전문학회 지침과 체계적 검토
2. 연구 설계와 대상이 명확한 동료평가 연구
3. 측정 정의와 원장이 연결된 자체 집계 데이터
4. 코치 관찰과 회원 경험담

하위 근거를 상위 근거처럼 표현하지 않는다. 단일 연구나 다른 종목 연구는 유도장 전체 고객에게 자동 적용하지 않는다.

### 적용 가능성 확인

- 연구의 운동 종류가 실제 수업과 같은가
- 대상 연령·건강 상태가 홍보 대상과 같은가
- 빈도·강도·기간이 실제 이용 조건과 같은가
- 결과가 자기보고인지 객관 측정인지
- 평균 변화인지 모든 참여자의 변화인지
- 비교군·중도탈락·부작용·한계가 공개됐는지
- 상관관계를 인과관계로 바꾸지 않았는지

하나라도 확인되지 않으면 단정형 결과 문구를 승인하지 않는다.

## 7. 표현 기준

### 승인 전 보류하는 문구

- `유도만 하면 무조건 살이 빠집니다`
- `자세를 완벽하게 교정합니다`
- `허리·무릎 통증을 치료합니다`
- `부상을 예방합니다`, `절대 다치지 않습니다`
- `우울증·불안·ADHD를 개선합니다`
- `키가 큽니다`, `면역력이 강화됩니다`
- `재활에 확실히 효과가 있습니다`
- `몇 주 안에 실력이 보장됩니다`

면책 문구를 작게 붙여도 본문의 확정적 인상을 자동으로 해소하지 않는다.

### 상대적으로 낮은 위험의 작성 방향

- 결과 보장 대신 수업에서 실제로 하는 활동을 설명한다.
- `개인에 따라 다릅니다`만 쓰지 말고 대상·조건·측정 범위를 함께 밝힌다.
- `도움이 될 수 있습니다`도 객관적 효과 주장이라면 근거 검토를 생략하지 않는다.
- 통증·질환·재활 문의는 마케팅 답변에서 진단하지 않고 적절한 전문 상담 경로 확인을 안내한다.
- 안전 표현은 위험이 없다는 뜻이 아니라 준비·지도·진행 절차를 사실대로 설명한다.

## 8. 후기·전후 이미지·숫자

### 후기

- 실제 경험자와 서비스 이용 사실을 확인한다.
- 대가·할인·무료 제공 등 중요한 관계를 명확히 표시한다.
- 만족도가 높은 사람만 선택해 전형적 결과처럼 제시하지 않는다.
- 회원의 말을 치료·예방·보장 주장으로 확대 편집하지 않는다.
- 공개·재사용·유료 광고 범위를 별도 동의로 관리한다.

### 전후 이미지

- 촬영 조건·기간·의상·조명·자세 차이를 숨기지 않는다.
- 신체 형태를 과장하는 합성·왜곡·리터칭을 하지 않는다.
- 개인 결과를 모든 수련자의 예상 결과로 표현하지 않는다.
- 미성년자 신체 변화 소재는 일반 홍보 후보에서 제외한다.

### 숫자·그래프

- 분자·분모·기간·대상·측정 방법·누락값을 표시한다.
- 문의율·등록률을 체력·통증·체중 개선률로 바꾸지 않는다.
- 분모가 0이거나 연결되지 않으면 `계산 불가`로 남긴다.

## 9. 채널별 적용

### Instagram

- 표지·본문·캡션·해시태그·일러스트가 만드는 전체 인상을 함께 검수한다.
- 저장·댓글 CTA는 하나만 사용하고 효과 체험담을 유도하지 않는다.
- 승인 대기 미디어·캡션은 승인 전 Instagram·외부 초안·공개 GitHub에 올리지 않는다.

### 네이버

- 블로그 본문과 플레이스 설명의 효과 표현을 같은 주장 원장에 연결한다.
- 지역 키워드와 건강효과 문구를 결합해 실제보다 넓은 효능을 암시하지 않는다.
- 후기 원문을 재사용할 때 별도 동의와 중요한 관계 표시를 확인한다.

### 당근

- 동네 후기·사례를 대표 결과로 일반화하지 않는다.
- `누구나`, `안전`, `교정`, `재활` 등 표현은 이미지 안 글자까지 검수한다.
- 채팅 시작을 효과 확인이나 체험 예약으로 계산하지 않는다.

## 10. 퍼널과 귀속

`CLAIM_EXPOSURE → CONTENT_INTERACTION → VALID_INQUIRY → BOOKING_CONFIRMED → TRIAL_ATTENDED → REGISTRATION_COMPLETED → CASH_COLLECTED → REFUND_OR_CHARGEBACK → NET_CASH`

- 노출·조회·저장·공유는 효과가 발생했다는 증거가 아니다.
- 문의는 예약이 아니며 예약은 실참여가 아니다.
- 등록 의사는 등록 완료 또는 실수납이 아니다.
- 동일 가구·지점·채널·결제를 중복 귀속하지 않는다.
- 건강 결과를 측정할 경우 마케팅 퍼널과 별도이며, 목적·권한·민감정보 보호를 먼저 검토한다.

## 11. 정정·철회

다음 조건이면 `CORRECTION_REQUIRED`로 전환한다.

- 근거 원문이 철회·수정됨
- 실제 서비스 조건과 근거 조건이 다름
- 후기 동의 철회 또는 중요한 관계 누락
- 전후 이미지 가공·측정 오류 발견
- 소비자가 치료·보장 주장으로 오해할 합리적 가능성 확인
- 승인 버전과 공개 버전이 다름

운영 채널에서 삭제한 것과 검색 캐시·공유본·제3자 재게시물까지 사라진 것은 구분한다.

## 12. 실험 EXP-405

### 목적

운동·건강·수련효과 주장과 후기의 검증·승인·전환 귀속 정확도를 확인한다.

### 합성 테스트 데이터

- 주장 360건: A~G 각 등급, 명시·암시 주장 혼합
- 근거·후기·전후 이미지 720건
- 노출·문의·예약·출석·등록·결제·환불 사건 720건
- 실제 회원·연락처·건강정보를 사용하지 않는다.

### 성공 기준

- 근거 미확인 건강·의료 주장 공개 승인 0건
- 집단 수준 근거의 개인 결과 보장 오분류 0건
- 후기·코치 의견의 과학적 증거 자동 승격 0건
- 동의·대가 표시 미확인 후기 공개 0건
- 조작 또는 조건 미표시 전후 이미지 승인 0건
- `안전`·`부상 예방`·`무부상` 암시 누락 0건
- 조회·저장·문의의 건강 결과 오분류 0건
- 지점·가구·채널·결제 중복 귀속 0건

한 항목이라도 실패하면 자동 공개, 후기 재사용, 건강효과 성과 보고를 중단한다.

## 13. 필요한 대표 승인·입력

- 허용할 운동·기술·건강효과 표현 범위
- 의료·재활·안전 고위험 주장 검토 책임자
- 내부 측정 데이터의 기준 원장·측정법·재검토 주기
- 후기·전후 이미지의 동의·대가 표시·재사용 범위
- 미성년자 소재의 제외·승인 기준
- 정정·철회 담당자와 처리기한
- 네이버·Instagram·당근별 승인자
- 문의·예약·출석·회원권·결제 기준 원장 연결 범위

## 15. 근거와 한계

- 대한민국 표시·광고의 공정화에 관한 법률: 부당한 표시·광고 판단은 실제 표현과 사실관계에 따라 검토해야 한다. <https://www.law.go.kr/법령/표시ㆍ광고의공정화에관한법률>
- 추천·보증 등에 관한 표시·광고 심사지침: 후기·추천과 경제적 이해관계의 공개 기준을 실제 최신 문서로 확인한다. <https://www.law.go.kr/행정규칙/추천·보증등에관한표시·광고심사지침>
- WHO Physical activity fact sheet, 2024-06-26: 신체활동의 집단 수준 건강 이점을 설명하지만 특정 유도장·개인의 결과 보장 근거로 사용하지 않는다. <https://www.who.int/news-room/fact-sheets/detail/physical-activity>
