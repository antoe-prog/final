# Instagram 콘텐츠 포트폴리오 커버리지·근거 사다리 기준 v1

- 적용 대상: 파이널유도멀티짐 관련 코치 개인 Instagram 콘텐츠
- 운영 성격: 코치 개인의 전문성·친근함을 보여주는 계정
- 문서 성격: 공개 가능한 운영 기준
- 기준일: 2026-09-15
- 내부 회원·전환·매출 데이터: 데이터 미연결
- 개별 승인 대기 미디어·캡션: 포함하지 않음

## 1. 판단

게시물 수보다 먼저 관리할 것은 **콘텐츠 포트폴리오의 역할 분담**이다.

입문 상식과 규정 설명만 계속 발행하면 정보성은 쌓이지만 코치 개인 계정의 실제 전문성·친근함을 충분히 보여주지 못할 수 있다. 반대로 근거 없는 수련 경험이나 지도 철학을 1인칭으로 만들면 신뢰를 해친다.

따라서 다음 게시물은 최근 콘텐츠에서 부족한 역할과 현재 확보 가능한 근거를 함께 보고 정한다.

## 2. 포트폴리오의 일곱 기둥

| 기둥 | 독자 질문 | 적합한 소재 | 우선 목표 | 가능한 단일 CTA |
|---|---|---|---|---|
| P1 입문 불안 해소 | 처음 가도 괜찮을까? | 첫 방문 질문, 복장, 준비 과정 | 신규 체험 준비 | 저장 또는 수업 문의 |
| P2 유도 상식 | 유도는 왜 이렇게 할까? | 도복, 예절, 규정, 용어 | 발견·신뢰 | 질문 또는 저장 |
| P3 기술 이해 | 동작의 핵심은 무엇일까? | 균형, 잡기, 메치기·굳히기 개념 | 전문성 | 저장 또는 질문 |
| P4 코치 수련 | 코치는 무엇을 연습할까? | 실제 수련 장면과 확인된 회고 | 친근함·전문성 | 질문 또는 팔로우 |
| P5 지도 준비 | 수업 전에 무엇을 준비할까? | 수업안, 매트 준비, 설명 포인트 | 신뢰·기존회원 만족 | 질문 또는 저장 |
| P6 관계·복귀 | 다시 시작해도 될까? | 확인된 복귀 준비, 수련 리듬 | 휴면 복귀·유지 | 수업 문의 |
| P7 지역 방문 확신 | 어디로 어떻게 가면 될까? | 검증된 지점·시간·문의 절차 | 체험 예약·방문 | 수업 문의 |

한 게시물은 주기둥 하나와 보조기둥 하나까지만 가진다. 목표와 CTA를 여러 개 넣어 성과 해석을 어렵게 만들지 않는다.

## 3. 근거 사다리

콘텐츠의 공개 가능 수준은 확보된 근거 단계보다 높을 수 없다.

### E0 — 아이디어만 있음

- 주제만 있고 공식 근거나 실제 자료가 없음
- 공개 문구·캡션 완성 금지
- 다음 행동: 근거 또는 촬영 계획 확보

### E1 — 공식 공개 근거

- 국제·국내 유도단체의 최신 규정·용어
- 플랫폼 공식 도움말·정책
- 확인 가능한 제품 또는 시설 운영 원천

가능한 콘텐츠:

- 일반 유도 상식
- 규정·용어 설명
- 플랫폼 사용 안내

불가능한 확장:

- 코치가 실제로 그렇게 지도한다는 주장
- 특정 수업·회원·지점의 실제 상태

### E2 — 코치가 제공한 사실

- 날짜가 있는 수련 기록
- 실제 지도 포인트
- 확인된 수업 준비 내용
- 코치가 직접 승인한 발언

가능한 콘텐츠:

- 제한된 1인칭 회고
- 코치 개인의 설명과 관점

자료에 없는 감정·성과·철학을 덧붙이지 않는다.

### E3 — 비식별 원본 미디어

- 코치 단독 촬영
- 손·발·도복·매트·수업 준비물 중심 촬영
- 회원이 식별되지 않는 공간 기록

가능한 콘텐츠:

- 실제 수련·준비 과정의 시각 증거
- 코치 개인 계정의 일상성

촬영일·촬영 주체·실제 상황을 확인한 뒤 사용한다.

### E4 — 동의가 확인된 회원 자료

- 회원 또는 보호자의 공개 사용 동의
- 공개 범위와 철회 상태가 확인된 후기·사진·영상
- 원문과 전후 맥락이 보존된 수련 변화

가능한 콘텐츠:

- 회원 경험과 공동체 문화
- 확인된 변화와 후기

동의 없는 자료, 건강·결제·개인 출석 정보는 사용하지 않는다.

### E5 — 검증된 사업 정보

- 대표가 확정한 지점·시간표·가격·체험 조건
- 실제 문의·예약 경로
- 승인된 행사·혜택·모집 조건

가능한 콘텐츠:

- 방문·예약·등록 전환 콘텐츠

게시 당일 기준 원천을 재확인한다.

## 4. 기둥별 최소 근거

| 콘텐츠 기둥 | 최소 근거 | 공개 금지 조건 |
|---|---|---|
| P1 입문 불안 해소 | E1 또는 검증된 일반 안내 | 실제 가격·시간표 추정 |
| P2 유도 상식 | E1 | 오래된 규정의 최신화 주장 |
| P3 기술 이해 | E1, 코치 관점이면 E2 | 개인별 효과·부상 예방 단정 |
| P4 코치 수련 | E2, 시각 주장 시 E3 | 자료 없는 1인칭 경험 |
| P5 지도 준비 | E2, 시각 주장 시 E3 | 실제 수업 운영으로 위장한 생성 이미지 |
| P6 관계·복귀 | 일반 심리 설명은 E1, 실제 사례는 E4 | 휴면 사유·효과 추정 |
| P7 지역 방문 확신 | E5 | 주소·시간·혜택 미확인 |

## 5. 다음 주제 선택 절차

1. 최근 공개 게시물의 주기둥을 기록한다.
2. 승인 대기와 폐기본은 공개 성과 포트폴리오에서 분리한다.
3. 최근 반복된 기둥과 비어 있는 기둥을 확인한다.
4. 네 사업 목표 중 현재 우선순위를 하나 고른다.
5. 사용할 수 있는 근거 단계를 확인한다.
6. 근거가 부족하면 다른 기둥으로 바꾸거나 촬영·사실 수집안을 준비한다.
7. CTA 하나와 해당 KPI를 정한다.
8. 완성본 승인 후에만 업로드한다.

## 6. 반복·편중 판정

다음 중 하나라도 해당하면 새 제작 전에 포트폴리오 검토를 한다.

- 같은 주기둥이 연속으로 두 번 이상 선택됨
- 최근 콘텐츠의 대부분이 공식 정보 요약임
- 코치 개인 계정인데 E2·E3 근거 콘텐츠가 없음
- 서로 다른 게시물이 같은 질문과 CTA를 반복함
- 저장·질문·팔로우·문의 CTA가 한 게시물에 섞임
- 신규 확보 소재만 있고 복귀·유지 소재가 전혀 없음
- 가격·행사·지역정보가 검증되지 않아 전환 콘텐츠가 멈춤

이는 자동 폐기 기준이 아니다. 반복이 전략적으로 필요한 경우 목적과 근거를 기록한 뒤 승인받는다.

## 7. 코치 개인 계정의 우선 증거

코치 개인 계정에서 전문성과 친근함을 함께 보여주는 우선순위는 다음과 같다.

1. 확인된 코치 수련 장면과 짧은 학습 포인트
2. 실제 수업 준비 장면과 설명할 항목
3. 코치 단독 기술 연습 또는 비식별 도복·손발 촬영
4. 제공된 사실에 근거한 수련 후 질문
5. 공식 근거를 코치가 쉽게 풀어주는 설명

실제 자료가 없을 때는 1~4를 경험처럼 만들지 않고 E1 정보 콘텐츠로 낮추거나 원본 확보 브리프를 만든다.

## 8. 사업 목표 연결

### 신규 체험회원 확보

- P1·P7 중심
- 콘텐츠 KPI: 저장, 프로필 방문, 수업 문의
- 사업 KPI: 유효 문의, 체험 예약, 실제 참석, 신규 등록

### 휴면회원 복귀

- P4·P6 중심
- 콘텐츠 KPI: 저장, 프로필 방문, 수업 문의
- 사업 KPI: 복귀 문의, 복귀 예약, 실제 복귀 출석, 재활성

### 기존회원 재등록·만족

- P4·P5·P6 중심
- 콘텐츠 KPI: 질문, 저장
- 사업 KPI: 만족 신호, 출석 유지, 재등록

### 매출 증대

- P7과 검증된 E5 정보만 직접 전환에 사용
- 사업 KPI: 계약, 결제, 환불·차지백 반영 순수납
- 조회·좋아요·댓글을 매출로 계산하지 않음

## 9. 채널 변환

### Instagram

- 코치 개인의 시점과 실제 증거가 중심이다.
- 7~10장 캐러셀은 장마다 다른 역할을 갖는다.
- CTA는 하나로 제한한다.

### 네이버

- 검색 의도에 맞춰 제목과 상세 설명을 확장한다.
- 실제 지점·시간표·준비물·문의 경로는 E5 확인 후 쓴다.

### 당근

- 지역 이웃이 행동하는 데 필요한 짧은 사실을 우선한다.
- 소식·채팅·쿠폰·예약을 서로 다른 사건으로 측정한다.

### Google 비즈니스 프로필

- 주소·전화·웹사이트·사진의 일관성을 먼저 확인한다.
- 실제 공간 경험을 보여주는 사진은 공개 권리와 지점 일치를 확인한다.

## 10. 성과 판정

게시물별로 다음을 분리한다.

- 게시 URL
- 주기둥·보조기둥
- 근거 단계
- CTA
- 게시시각
- 조회시각
- 조회·도달·좋아요·댓글·저장·공유·프로필 방문·팔로우
- 문의·예약·실제 참석·신규 등록·복귀·재등록·순수납

0, 미집계, 미제공, 미성숙을 구분한다. 분모가 없으면 행동률과 전환율을 계산하지 않는다.

## 11. 실험

### EXP-314 — 콘텐츠 기둥 커버리지·근거 적합성

- 대상: 승인 후 공개되는 다음 6개 콘텐츠
- 가설: 기둥과 근거 단계를 먼저 기록하면 교육 콘텐츠 편중과 근거 없는 개인 서사를 줄이고 사업 목표별 학습을 분리할 수 있다.
- 성공 조건:
  - 주기둥·근거 단계·목적·CTA 기록률 100%
  - 최소 3개 서로 다른 주기둥 포함
  - 최소 2개 서로 다른 사업 목표 포함
  - 같은 주기둥 3회 연속 0건
  - 요구 근거보다 강한 주장 0건
  - 승인 전 업로드·예약·발행 0건
  - 게시물별 플랫폼 지표 원천 기록률 100%
- 보류 조건:
  - 코치 개인 사실·원본 미디어 부재
  - 지점·시간표·가격·문의 경로 미확정
  - 핵심 플랫폼 지표 미제공
- 중단 조건:
  - 가공한 경험을 실제 코치 경험으로 표현
  - 동의 없는 회원 자료 사용
  - 조회·반응을 문의·등록·매출로 계산
  - 미확정 혜택·행사·가격 공개
- 현재 사업 개선폭: 데이터 미연결

## 15. Auditor 결론

- 개인 계정의 운영 성격과 플랫폼 계정 유형을 혼동하지 않았다.
- 코치 개인 콘텐츠를 공식 브랜드 발표로 만들지 않았다.
- 공급업체의 성과 주장과 수치를 내부 기준선으로 사용하지 않았다.
- 공식 정보, 코치 제공 사실, 원본 미디어, 회원 동의, 사업 정보를 서로 다른 근거 단계로 분리했다.
- 교육형 편중을 줄이되 실제 자료가 없는 코치 경험을 만들지 않도록 했다.
- 확인되지 않은 회원수·전환율·매출은 데이터 미연결로 남겼다.
