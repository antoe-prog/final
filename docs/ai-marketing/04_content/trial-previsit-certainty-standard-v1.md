- 작성 기준일: 2026-09-12 (KST)
- 상태: 공개 검토 문서 / 고객 발송·운영DB 적용 전
- 목적: 신규 체험 예약자가 첫 방문 전에 알아야 할 정보를 표준화해 `예약 → 실제 방문` 구간의 불확실성을 줄일 수 있는지 검증한다.

## 이번 회차의 새 근거

2026년 8~9월에 확인한 복수의 유도 클럽은 체험·입문 페이지에서 단순히 `체험 예약`만 제시하지 않고 첫 방문 전에 필요한 정보를 매우 구체적으로 공개한다.

- Ishikawa Judo Club은 2026-08-20 게시물에서 첫 수업에 도복이 없어도 되며 편한 운동복, 장신구 제거, 손발톱 정리 등 첫 방문 준비를 설명한다.
  - https://ishikawajudoclub.ca/what-to-expect-at-your-first-judo-class-in-burnaby/
- SC Gröbenzell은 2026년 9월 체험일정과 함께 지퍼 없는 운동복, 슬리퍼, 물병을 명시하고 정식 초보과정 전에는 도복 구매가 필요하지 않다고 안내한다.
  - https://www.sc-groebenzell.de/de/aktuelles/meldungen/2026-Judo-Schnuppertraining.php
- Abingdon Judo Club은 첫 세션에서 무엇을 배우는지, 무엇을 입고 가져올지, 몇 분 일찍 도착할지까지 한 페이지에서 안내한다.
  - https://abingdonjudo.com/try-judo/
- Dragon Judo Academy도 첫 수업 전 복장·물·도착시간·수업흐름·도복 필요 여부를 FAQ와 Beginner Guide에 묶어 제공한다.
  - https://www.dragonjudoacademy.com/beginner-guide

이 사례들은 파이널유도에서 같은 결과가 난다는 증거가 아니다. 다만 최신 유도 입문 페이지가 `예약 CTA`만 두는 대신 **첫 방문의 미지 요소를 제거하는 정보설계**를 실제로 사용하고 있다는 근거다.

## 기존 문서와의 역할 분리

이 문서는 `체험 후속관리 검토본`의 발송 횟수를 늘리는 문서가 아니다. 또한 `EXP-043 체험 안내`의 실험가설을 대체하지 않는다.

- `trial-followup-review-v1.md`: 신청 직후·전날·체험 후 등 연락 시점과 후속관리 검토
- `exp-043-trial-guide-revision-v2.md`: 구조화된 체험 안내가 실제 방문률을 개선하는지 검증하는 실험 설계
- **이 문서**: 비교군 모두에 반드시 제공해야 할 `사실 기반 최소 안내정보`와 실험 가능한 표현 계층을 정의

필수 안전·위치·비용·취소정보를 한쪽 실험군에만 숨기는 방식은 허용하지 않는다.

## 7블록 최소 표준

체험 예약이 확정된 사람에게 아래 정보는 실제 운영값이 확인된 경우에만 제공한다.

1. **확정 일정** — 지점, 날짜, 시작·종료시각
2. **도착 경로** — 건물명·층·출입구 등 실제 확인된 접근정보
3. **도착 권장시각** — 코치가 실제로 수용 가능한 기준값만 사용
4. **복장·준비물** — 실제 체험수업 정책에 맞는 운동복·도복·물·실내외 신발 기준
5. **첫 수업에서 하는 것** — 실제 해당 반에서 제공하는 내용만 2~4개로 설명
6. **안전·변경 규칙** — 장신구·복장 제한, 지각·취소·일정변경 경로 등 확인된 정책
7. **추가 비용 또는 구매 필요 여부** — 체험비·도복대여·도복구매·보험·등록비 등을 `없음` 또는 확인된 금액으로만 표시

확인되지 않은 값은 임의 작성하지 않고 **운영정보 미확인**으로 둔다.

## 금지 표현

- `아무 준비 없이 오시면 됩니다` — 실제 준비물이 있는 경우 금지
- `도복 필요 없습니다` — 해당 수업 정책이 확인되지 않은 경우 금지
- `부상 걱정 없습니다`, `안전합니다` — 결과 보장형 안전표현 금지
- `무료`, `도복 무료대여`, `주차 무료` — 실제 정책 확인 전 금지
- `초보도 바로 대련 가능`, `첫날 메치기 가능` — 실제 수업범위와 코치 판단 확인 전 금지
- 가짜 희소성: `마지막 1자리`, `오늘 마감` — 실제 좌석 데이터 없으면 금지

## 채널별 적용

### 네이버

플레이스·예약·블로그의 정보가 충돌하지 않도록 동일한 기준값을 사용한다. 검색유입 콘텐츠는 `처음 가면 무엇을 하나 / 무엇을 입나 / 도복이 필요한가 / 몇 분 일찍 가나` 같은 실제 초보 질문을 해결하는 형태로 작성한다.

### 인스타그램

광고성 약속보다 `도착 → 인사 → 준비 → 첫 드릴 → 마무리`의 실제 동선을 보여주는 15~30초 과정형 콘텐츠를 우선 검토한다. 촬영 시 회원·미성년자의 초상권과 공개동의를 별도로 관리한다.

### 당근

동네생활·비즈프로필에서 `지역 + 대상 + 실제 체험가능시간 + 준비정보`를 연결한다. 실제 여석이 없는 반을 모집하지 않는다.

## 계측 규격

최소 이벤트는 다음과 같이 분리한다.

`inquiry → reservation_confirmed → guide_delivered → guide_opened(if measurable) → reschedule_requested → cancelled → verified_attendance → paid_within_14d → active_30d`

필수 집계값:

- 예약 확정 건수
- 실제 안내 전달 가능 건수
- 변경·취소 요청 건수
- 현장 확인 방문 건수
- 미확인 방문 여부 건수
- 첫 체험 후 14일 내 등록
- 등록 후 30일 활성
- 잘못된 안내/불편/중복연락 건수
- 담당자 처리시간

개인 이름·연락처·건강정보·개별 출석원장은 공개 GitHub에 저장하지 않는다.

## EXP-043에 반영할 변경

기존 EXP-043의 비교를 `정보가 적은 안내 vs 정보가 많은 안내`로 두지 않는다. 안전·가격·위치·변경방법 같은 필수정보는 양쪽에 동일하게 제공한다.

비교 가능한 요소는 예를 들어 다음과 같다.

- A: 필수정보를 현재 텍스트 순서대로 제공
- B: 동일한 필수정보를 7블록 카드/체크리스트 형식으로 구조화

주지표는 `종료된 확정예약 중 현장 확인 방문률`이며, 보조지표는 일정변경 성공률, 14일 내 등록률, 안내 관련 문의량, 직원 처리시간, 불편건수다.

기준선·최소개선폭·표본수는 **데이터 미연결**이며 임의 수치로 확정하지 않는다.

## 실행 게이트

다음 값이 확인되기 전 고객 발송 또는 자동화는 실행하지 않는다.

- 실제 지점·층·출입구
- 실제 체험 가능 시간
- 체험비·등록비·도복 정책
- 첫 수업 범위와 담당 코치
- 도착 권장시각
- 취소·변경 연락 경로
- 수신동의 및 자동알림 중복 여부

## Auditor

이 표준의 목표는 메시지를 더 많이 보내는 것이 아니라 **첫 방문 전에 필요한 사실을 정확하게 한 번에 전달하는 것**이다. 외부 유도장의 무료체험·도복대여·수업내용을 파이널유도 정책처럼 복제하지 않는다. `예약률`, `방문률`, `매출 상승` 효과는 현재 입증되지 않았으며 내부 데이터 연결 전에는 모두 **데이터 미연결**로 유지한다.
