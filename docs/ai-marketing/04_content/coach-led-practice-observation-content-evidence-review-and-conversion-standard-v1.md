# 코치 주도 수련 관찰형 콘텐츠 근거·검수·전환 기준 v1

- 문서 상태: 공개 운영 기준
- 적용 대상: 코치 개인 계정의 유도 수련·기술 연습·입문자 교육 콘텐츠
- 목적: 이해하기 쉬운 관찰 포인트를 제공하면서 기술 오지도, 과장된 효과 주장, 승인 없는 고객 행동 및 성과 과장을 방지한다.
- 적용 제외: 개인별 수련 처방, 부상·통증 상담, 경기 전략 처방, 확인되지 않은 코치 개인 경험, 회원 식별정보

## 1. 핵심 원칙

관찰형 콘텐츠는 기술을 완성시키는 원격 교본이 아니다. 독자가 수업에서 무엇을 보고 질문할지 준비하도록 돕는 콘텐츠다.

따라서 다음 세 층을 분리한다.

1. **관찰 질문**: 위치, 방향, 거리, 순서, 속도처럼 독자가 살펴볼 항목
2. **코치 검증이 필요한 기술 기준**: 특정 기술의 발 위치, 손의 사용, 진입 각도, 타이밍
3. **효과 주장**: 실력 향상, 부상 예방, 습득 기간, 승률, 체력 향상

관찰 질문은 공개 자료로 제작할 수 있다. 기술 기준과 효과 주장은 공식 자료 또는 코치 검증이 없으면 게시하지 않는다.

## 2. 콘텐츠 주장 등급

| 등급 | 예시 | 공개 전 요건 |
|---|---|---|
| O1 관찰 | “이번 반복에서 몸의 방향을 살펴보세요.” | 과장·보장 표현 점검 |
| O2 수업 비교 | “수업에서 안내받은 기준과 비교하세요.” | 해당 수업의 실제 기준을 임의로 만들지 않음 |
| T1 기술 설명 | 특정 기술의 발 위치·손 순서·진입 방향 | 공식 교본 또는 담당 코치 검증 |
| E1 효과 | 반복이 숙련·안전·성공률을 높인다는 주장 | 적용 대상과 한계를 포함한 적합한 근거 |
| B1 사업 정보 | 시간표·가격·체험·혜택·지점 정보 | 최신 공식 운영자료와 게시 승인 |

한 장에 여러 등급이 섞이면 가장 높은 검증 요건을 적용한다.

## 3. 허용 문구와 금지 문구

### 허용

- “한 번에 한 가지를 골라 살펴보세요.”
- “기술마다 기준과 순서는 다를 수 있습니다.”
- “헷갈린 장면은 수업에서 질문으로 남겨보세요.”
- “수업에서 안내받은 범위와 비교해 보세요.”

### 근거·검증 전 금지

- “이렇게 반복하면 반드시 빨리 늡니다.”
- “이 동작은 부상을 예방합니다.”
- “초보자도 며칠이면 익힙니다.”
- “모든 기술은 이 순서로 하면 됩니다.”
- “이 자세가 유일하게 맞는 자세입니다.”

관찰형 표현을 의학·안전·성과 보장으로 확대하지 않는다.

## 4. 코치 개인 계정의 발화 기준

- 확인된 자료가 없으면 “제가 수업에서 항상 강조합니다”와 같은 1인칭 경험을 쓰지 않는다.
- 실제 당일 수련, 지도 철학, 회원 변화, 대회 경험은 출처 자료와 공개 동의를 확인한다.
- 개인 계정의 설명은 브랜드 전체의 공식 정책이나 모든 지점의 공통 수업 방식으로 표현하지 않는다.
- 브랜드·지점 연결은 확인된 체험 문의 경로가 있을 때만 보조 행동으로 둔다.
- 한 게시물의 행동 유도는 저장, 질문, 팔로우, 수업 문의 중 하나만 선택한다.

## 5. 이미지·접근성·AI 표시 기준

### 최종 이미지 검수

- 캐러셀은 7~10장의 개별 이미지로 구성한다.
- 표지, 관찰 포인트, 정리, 마무리의 역할이 겹치지 않게 한다.
- 제목·핵심 문장·설명·보조 표기의 크기와 굵기를 구분한다.
- 모든 장에서 계정 표기, 장 번호, 비율, 색상 체계를 확인한다.
- 실제 촬영물이 아니면 실제 코치·회원·시설로 오인시키지 않는다.
- 회원 식별 촬영물은 공개 사용 동의 상태를 기록한다.

### 대체 텍스트

- 최종 이미지 확정 후 장별로 다시 작성한다.
- 자동 생성 설명과 수동 입력 상태를 구분한다.
- 대표 썸네일 확인을 캐러셀 전체 확인으로 계산하지 않는다.
- 이미지가 바뀌면 이전 대체 텍스트를 재사용하지 않는다.

### AI 생성 이미지

- 업로드 도구가 제공하는 AI 생성 콘텐츠 표시 항목을 게시 시점에 확인한다.
- 도구가 제공하는 표시를 임의로 우회하지 않는다.
- AI 이미지 사용 사실을 실제 촬영 사실로 표현하지 않는다.

## 6. 승인 상태와 외부 행동

| 상태 | 의미 | 허용 행동 |
|---|---|---|
| 제작 중 | 문구·이미지·근거가 미완성 | 내부 제작·검수 |
| 승인 대기 | 최종 미디어·순서·캡션·대체 텍스트 확정 | 대표에게 완성본 제시 |
| 승인 완료 | 해당 버전의 게시 승인 기록 존재 | 동일본 업로드·예약·발행 |
| 게시 완료 | 플랫폼 성공과 공개 URL 확인 | 성과 추적 |

- 승인 전에는 Instagram 업로드, 외부 초안 저장, 예약, 발행을 하지 않는다.
- 승인 이후 실질적 문구·미디어·순서 변경이 필요하면 변경본을 다시 승인받는다.
- 한 패키지는 한 번만 게시한다.
- 게시 실패 재시도 전 공개 여부를 확인한다.
- 접근성 보정을 위해 삭제·복제·재게시하지 않는다.

## 7. 채널별 재사용

### Instagram

- 저장 가능한 관찰 체크리스트로 구성한다.
- 저장 수와 문의 수를 분리한다.

### 네이버

- 게시물의 관찰 항목을 긴 설명으로 옮길 때도 기술 정답이나 효과를 새로 추가하지 않는다.
- 최신 시간표·가격·지점 정보는 공식 자료 연결 후에만 붙인다.

### 당근

- 지역 맥락은 지점 생활권·찾아오는 방법·확인된 수업 정보에 한정한다.
- 지역 타깃 노출을 실제 문의·방문으로 계산하지 않는다.

## 10. 실험 EXP-445

**목적:** 관찰형 교육 콘텐츠가 기술 오지도 없이 저장과 후속 질문을 만드는지 검증한다.

### 비교 단위

- A안: 한 게시물에서 여러 포인트를 동일한 비중으로 제시
- B안: 한 번에 한 관찰 포인트를 선택하도록 안내

### 성공 기준

- 기술 기준·효과·안전 보장 무근거 주장: 0건
- 코치 검증이 필요한 문장을 O1 관찰로 오분류: 0건
- 승인본과 게시본의 이미지·순서·캡션 불일치: 0건
- 장별 수동 대체 텍스트 누락: 0건
- 저장률: 저장 수 ÷ 도달 수, 도달이 0 또는 미연결이면 계산 불가
- 질문률: 관찰 포인트 관련 유효 댓글·문의 ÷ 도달 수, 도달이 0 또는 미연결이면 계산 불가
- 체험 참여율: 실제 체험 참여 ÷ 체험 예약, 예약이 0 또는 미연결이면 계산 불가
- 순수납 전환율: 순수납이 확인된 신규·복귀·재등록 ÷ 실제 체험 또는 공식 CRM 대상, 분모 미정이면 계산 불가

### 중단 기준

다음 중 하나라도 발생하면 자동 확대와 고객 발송을 중단한다.

- 검증되지 않은 기술·효과·안전 주장을 게시
- 코치 개인 경험을 자료 없이 1인칭 사실로 작성
- 회원 식별정보 또는 동의 미확인 촬영물을 공개
- 승인 대기 미디어·캡션을 공개 저장소에 게시
- 게시 승인을 다른 패키지로 확대
- 저장·댓글·예약을 실제 체험·등록·매출로 계산
- 신규·복귀·재등록 매출을 중복 귀속

## 11. 운영 체크리스트

### 제작 전

- [ ] 기존 게시물과 승인 대기 패키지의 중복 확인
- [ ] 주제의 주장 등급 판정
- [ ] 필요한 공식 근거 또는 코치 검증 범위 정의
- [ ] 실제 촬영 동의 여부 확인

### 승인 전

- [ ] 최종 미디어 7~10장 완성
- [ ] 업로드 순서 고정
- [ ] 캡션·해시태그·행동 유도 확정
- [ ] 최종 이미지 기준 대체 텍스트 확정
- [ ] AI 생성 표시 필요 여부 기록
- [ ] 오탈자·잘림·계정 표기·장 번호 확인

### 게시 후

- [ ] 성공 화면과 공개 URL 확인
- [ ] 캐러셀 전체 장수·순서 확인
- [ ] 캡션 일치 확인
- [ ] 수동 대체 텍스트 저장·재진입 확인
- [ ] 성과 수치의 기간과 원천 기록

## 12. 근거와 적용 한계

- IJF Academy는 2026년에도 유도 지도자와 코치 교육을 별도 과정으로 운영한다. 소셜 콘텐츠를 정식 지도자 교육이나 현장 수업의 대체물로 취급하지 않는다: https://academy.ijf.org/
- Meta는 생성형 AI 콘텐츠 표시에 기술 신호와 게시자 공개를 함께 사용한다고 설명한다. 모든 콘텐츠를 자동 식별할 수 있다는 의미는 아니다: https://about.fb.com/news/2024/02/labeling-ai-generated-images-on-facebook-instagram-and-threads/
- Instagram은 자동 생성 대체 텍스트와 사용자가 수정하는 대체 텍스트를 구분한다: https://help.instagram.com/503708446705527/
- W3C는 이미지의 목적과 전달 정보에 따라 대체 텍스트를 정하도록 안내한다: https://www.w3.org/WAI/tutorials/images/decision-tree/
- 2026년 미국의 한 지역 무술관 사례는 구조·집중·동료 관계를 함께 강조했다. 외부 사례이므로 파이널유도의 서비스나 성과 근거로 확대하지 않고 메시지 가설에만 사용한다: https://www.bigrapidsnews.com/news/article/coon-mma-big-rapids-builds-fighters-community-mma-22321523.php

## 13. 개인정보·브랜드 안전

- 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제자료를 공개 문서에 넣지 않는다.
- 미확정 행사, 내부 예산·손익·목표 인원, 비공개 승인 대기 콘텐츠를 공개하지 않는다.
- 코치 개인 계정과 브랜드 공식 발표 주체를 혼동하지 않는다.
- 내부 성과 데이터가 연결되지 않은 경우 `데이터 미연결`로 기록한다.
