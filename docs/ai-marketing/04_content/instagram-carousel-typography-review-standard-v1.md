# Instagram Carousel Typography Review Standard v1

- 기준일: 2026-09-13 (KST)
- 적용 대상: 파이널유도멀티짐 관련 공개 교육형 Instagram 캐러셀
- 상태: 공개 가능한 제작·검수 표준
- 개별 승인 대기 게시물의 이미지·캡션: **본 문서에 포함하지 않음**
- 회원수·도달·저장·문의·등록·매출: **데이터 미연결**

## 오늘의 판단

교육형 캐러셀의 품질 문제는 단순히 글자 크기가 크거나 작은 문제가 아니다. 표지, 핵심 문장, 설명, 계정 표기까지 모두 같은 크기와 굵기를 사용하면 사용자가 한 장에서 무엇부터 읽어야 하는지 판단하기 어렵다.

따라서 제작 기준을 다음 네 단계로 고정한다.

1. 제목
2. 핵심 문장
3. 설명·질문
4. 계정 표기·페이지 번호

모든 문장을 크게 만드는 방식 대신, 한 장마다 핵심어 1~2개만 색상 또는 굵기로 강조한다.

## 타이포그래피 4단계

### 1. 제목

- 한 장에서 가장 먼저 읽혀야 하는 문장
- 1~2줄을 기본으로 함
- 문장 전체가 3줄 이상이면 축약을 우선함
- 화면 너비를 꽉 채우지 않고 좌우 여백을 유지함
- 모든 장의 제목 크기를 무조건 동일하게 하지 않고 글자 수에 따라 안전 범위 안에서 조정함

### 2. 핵심 문장

- 제목을 보완하는 한 문장
- 제목보다 작고 본문보다 분명하게 설정
- 한 문장 전체를 굵게 하지 않고 핵심어만 선택적으로 강조
- 색상 강조는 한 장당 1~2곳으로 제한

### 3. 설명·질문

- 실제로 저장할 가치가 있는 내용
- 한 줄을 짧게 유지하고 충분한 행간을 확보
- 문장을 나열하기보다 질문, 체크리스트, 예시 문장 중 한 형식을 선택
- 한 장에 서로 다른 목적의 설명을 과도하게 섞지 않음

### 4. 계정 표기·페이지 번호

- 계정명과 01/08 같은 순서 정보는 항상 같은 위치에 배치
- 본문보다 작고 시선을 방해하지 않는 크기
- 계정 표기가 제목보다 먼저 보이지 않도록 대비를 낮춤
- 페이지 번호가 잘리거나 업로드 UI에 가려지지 않도록 안전여백 확보

## 한 장당 정보 구조

각 장은 다음 다섯 요소 중 필요한 것만 사용한다.

- 작은 소제목
- 제목
- 핵심 문장
- 설명·목록
- 그림 또는 사진

장수를 채우기 위해 같은 문장을 반복하지 않는다. 표지에서 약속한 질문 수와 실제 본문 장수가 일치해야 한다.

## 8장 기본 흐름

1. 표지: 독자가 얻을 정보 한 줄
2. 첫 번째 질문
3. 첫 번째 질문의 실제 문의 예시
4. 두 번째 질문
5. 세 번째 질문
6. 복사해 사용할 수 있는 완성 문장
7. 방문 전 정리 체크리스트
8. 요약과 단일 행동 유도

주제의 정보량에 따라 7~10장 범위에서 조정할 수 있다. 여러 장을 한 파일에 합친 콜라주는 개별 캐러셀 이미지로 보지 않는다.

## 크기·강조 검수

정확한 포인트 수보다 실제 4:5 모바일 미리보기에서의 읽기 순서를 우선한다.

필수 확인:

- 제목이 설명보다 먼저 보이는가
- 핵심 문장이 제목과 경쟁하지 않는가
- 작은 설명이 지나치게 굵지 않은가
- 한 장 안에서 굵은 문장이 과반을 차지하지 않는가
- 강조색이 모든 문장에 반복되지 않는가
- 제목이 이미지나 장식 요소를 압도하지 않는가
- 8장을 연속으로 볼 때 리듬 변화가 있는가
- 페이지 번호와 계정 표기가 동일 위치에 있는가

## 권장 색상 역할

- 아이보리: 기본 배경
- 차콜 또는 검정: 제목과 본문
- 딥그린: 작은 소제목, 핵심어, 체크 표시
- 세이지·베이지: 일러스트와 보조면

강조색은 의미가 있는 핵심어에만 사용한다. 색을 많이 쓰는 것을 정보 계층으로 착각하지 않는다.

## 이미지와 본문의 관계

- 그림은 본문을 다시 설명하거나 분위기를 보조해야 함
- 장식용 이미지가 텍스트 영역을 침범하지 않음
- 실제 사진이 아닌 일러스트는 실제 코치·회원·시설을 묘사한 것처럼 표현하지 않음
- 촬영물에는 성인 동의와 미성년자 보호자 동의를 별도로 확인
- 이름표, 학교명, 연락처, 건강·결제정보가 보이면 사용하지 않음

## 대체 텍스트

Instagram 도움말은 게시물의 대체 텍스트를 편집하는 기능을 안내한다. 이미지 안의 모든 문장을 그대로 반복하기보다 시각적 구조와 핵심 목적을 설명한다.

장별 대체 텍스트에는 다음을 포함한다.

- 이미지의 역할
- 주요 제목 또는 질문
- 핵심 시각요소
- 필요한 경우 목록의 요약

입력 기능이 실제 게시 화면에서 제공되지 않으면 설정했다고 주장하지 않는다.

## 최신 무도 콘텐츠 관찰

2026년 9월 공개 검색에서 유도 입문자용 Instagram 콘텐츠는 다음 질문을 반복적으로 다루고 있다.

- 완전한 초보자가 참여해도 되는가
- 첫 수업에서 무엇을 하는가
- 무엇을 입고 가는가
- 상대 연습을 바로 해야 하는가

## 채널별 적용

### Instagram

- 4:5 세로 개별 이미지
- 7~10장
- 표지·본문·마무리 흐름
- 단일 행동 유도
- 장별 대체 텍스트 준비
- 게시 전 전체 순서 미리보기

### 네이버

캐러셀 문장을 그대로 붙여넣지 않는다. 제목, 질문, 답변, 실제 운영정보를 장문 검색형 콘텐츠로 재구성한다.

### 당근

지역, 실제 지점, 실제 체험 가능 시간, 준비물을 확인한 뒤 별도 지역 게시물로 작성한다. Instagram 일러스트를 실제 시설사진처럼 사용하지 않는다.

## 실험

### EXP-278 Hierarchy Revision Review

가설:
제목·핵심문장·설명·보조표기의 크기와 굵기를 분리하면 모바일에서 읽기 순서가 더 명확해질 수 있다.

비교:
- A: 제목과 주요 문장이 모두 크고 굵은 버전
- B: 4단계 계층과 선택적 색상 강조를 적용한 버전

게시 전 평가:
- 4:5 축소 미리보기에서 첫 번째로 읽힌 문장
- 한 장당 평균 읽기시간
- 8장 순서 혼동 여부
- 오탈자·잘림·중복 문구 건수

게시 후 평가:
- 마지막 장 도달 또는 완주 관련 지표: 제공되는 경우만
- 저장
- 공유
- 프로필 방문: 귀속 가능한 경우만
- 유도 관련 질문
- 문의·예약·실방문

성공 기준:
- 게시 전 오탈자·잘림 0건
- 검토자가 제목→핵심문장→설명 순서를 일관되게 식별
- 게시 후 동일 관찰기간의 기존 캐러셀 기준선 대비 사전 승인 최소개선폭 충족
- 개인정보·초상권·저작권 문제 0건

중단 기준:
- 모바일 축소 시 본문 판독 불가
- 제목이 3줄 이상 반복
- 동일 문구가 불필요하게 여러 장에 중복
- 게시 승인본과 실제 업로드 파일의 순서 불일치
- 대체 텍스트 또는 캡션에 확인되지 않은 운영정보 포함

기존 캐러셀 기준선, 최소개선폭, 표본수는 **데이터 미연결**이다.

## 승인 절차

1. 고유 작업 ID와 버전 부여
2. 7~10장 전체 이미지 완성
3. 파일명 순서와 이미지 내부 페이지 번호 대조
4. 전체 미리보기, PDF 또는 ZIP 제공
5. 최종 캡션·해시태그·대체 텍스트 제시
6. 사용자의 해당 완성본 게시 승인
7. 승인 후에만 Instagram 업로드
8. 성공 화면과 실제 게시물로 완료 확인

승인 전에는 Instagram 파일 업로드, 외부 초안 저장, 예약, 발행을 하지 않는다.

## Auditor

- 타 계정의 타이포그래피 계층만 참고하고 문구·브랜드·이미지를 복제하지 않는다.
- 큰 글자가 많다고 가독성이 높다고 단정하지 않는다.
- 대체 텍스트를 해시태그나 키워드 반복 공간으로 사용하지 않는다.
- 실제 도장마다 다른 수업·복장·비용을 공통 사실로 만들지 않는다.
- 승인 대기 이미지·캡션을 공개 저장소에 올리지 않는다.
- 조회수·저장 수만으로 신규등록과 매출 증가를 주장하지 않는다.
