- 문서 상태: 공개 가능한 운영 기준
- 작성·검토일: 2026-09-15
- 적용 계정: `@ant.toe.98`
- 계정 운영 성격: 사용자가 지정한 코치 개인 콘텐츠 계정
- 내부 문의·회원·매출 데이터: 데이터 미연결
- 제외: 로그인·복구정보, 회원·보호자 개인정보, 개인별 문의·출석·결제 원장, 미확정 가격·혜택·행사, 승인 대기 게시물 미디어·캡션

## 1. 오늘의 판단

콘텐츠가 프로필 방문을 만들더라도 방문자가 `누구의 계정인지`, `무엇을 얻는지`, `어디로 문의하는지`를 확인할 수 없으면 체험 문의로 연결됐는지 측정할 수 없다.

따라서 게시량 확대 전에 코치 개인 계정의 정체성, 콘텐츠 약속, 단일 행동 유도, 검증된 문의 도착 경로를 분리해 확인한다. 프로필 수정은 대표 승인과 공개 재검증 후에만 완료로 처리한다.

## 2. 2026-09-15 공개 프로필 기준선

Instagram 로그인 브라우저에서 공개 프로필 화면을 직접 확인한 값이다. 이 값은 조회 시점의 화면 표시이며 장기 평균이나 사업 성과가 아니다.

## 3. 운영 성격과 플랫폼 설정 분리

- `코치 개인 계정`은 누가 어떤 목적으로 콘텐츠를 운영하는지에 관한 기준이다.
- `블로거`는 현재 Instagram 화면에 표시된 플랫폼 카테고리다.
- 개인·크리에이터·비즈니스는 Instagram의 계정 유형 설정이다. 현재 화면의 `블로거`만으로 계정 유형을 추정하지 않는다.
- 코치 개인 계정을 파이널유도멀티짐 공식 발표 계정처럼 표현하지 않는다.
- 지점·시간표·가격·혜택·행사 공지는 해당 사실과 공개 권한이 확인된 경우에만 보조 소재로 다룬다.

## 5. 프로필 준비 8개 항목

### 5.1 계정 소유 역할

- 표시 이름과 소개가 코치 개인 콘텐츠임을 혼동 없이 보여주는지 확인한다.
- 본관·브랜드 공식 발표 주체처럼 보이는 표현을 쓰지 않는다.
- 실제 확인되지 않은 자격·수상·경력·지도 철학을 추가하지 않는다.

### 5.2 콘텐츠 약속

방문자가 앞으로 볼 내용을 한 문장 안에서 이해할 수 있어야 한다.

사용 가능한 범위:

- 유도 입문자의 궁금증
- 유도복·기술·예절 설명
- 확인된 코치 본인의 수련 기록
- 확인된 수업 준비와 지도 설명 포인트

`당황하는 최코치`는 친근한 인상은 줄 수 있으나, 현재 문구만으로는 유도 콘텐츠와 코치 역할을 직접 설명하지 않는다.

### 5.3 근거 수준

- 공식 규정·공개 자료를 설명할 때 출처와 확인일을 남긴다.
- 1인칭 수련·지도 경험은 코치가 제공하거나 확인한 사실만 사용한다.
- 회원이 식별되는 사진·후기는 공개 사용 동의가 확인된 경우에만 사용한다.
- 실제 촬영물이 없으면 개념 일러스트임을 구분한다.

### 5.4 단일 행동 유도

프로필에서는 다음 중 하나만 우선 행동으로 정한다.

- 팔로우
- 콘텐츠 질문
- 수업 문의

신규 체험 확보를 우선하면 `수업 문의`가 후보지만, 실제 응대 가능한 경로·지점·운영 기준이 먼저 확인돼야 한다.

### 5.5 문의 도착 경로

필수 확인:

- 공개 가능한 도착 URL 또는 플랫폼 내 문의 기능
- 실제 담당 조직 또는 역할
- 응대 가능한 시간과 서비스 범위
- 지점 선택 방식
- 테스트 문의 식별 방법
- 수신동의·개인정보 처리 기준

현재 화면에서 경로를 확인하지 못했으므로 임의 전화번호, 오픈채팅, 예약 링크를 만들거나 삽입하지 않는다.

### 5.6 링크 도착 검증

링크를 추가할 때 다음 순서로 검증한다.

1. 승인된 URL과 표시 문구 대조
2. 모바일 공개 프로필에서 링크 노출 확인
3. 리디렉션 후 도착 페이지·브랜드·지점 확인
4. 비식별 테스트 문의 1건 도착 확인
5. 테스트 기록을 실제 문의 KPI에서 `TEST_VOID`로 제외
6. 오류 시 링크 제거 또는 이전 승인본 복구

클릭만으로 실제 문의가 접수됐다고 처리하지 않는다.

### 5.7 고정 게시물·하이라이트 역할

고정 여부를 먼저 확인한 뒤 최대 세 역할을 검토한다.

- 코치가 어떤 유도 콘텐츠를 설명하는지
- 입문자가 첫 수업 전에 확인할 내용
- 검증된 문의·방문 절차

현재 게시물의 고정 상태를 확인하지 못했으며 승인 없이 고정·해제하지 않는다.

### 5.8 공개 재검증

편집 화면 저장은 완료가 아니다. 로그아웃 또는 공개 관점에서 다음을 다시 확인한다.

- 사용자명·표시 이름·소개·카테고리
- 링크 노출과 도착
- 코치 개인 계정이라는 문맥
- 줄바꿈·잘림·오타
- 미확정 가격·혜택·행사 노출 여부

## 6. 승인용 최소 변경안

아래는 외부 계정에 적용하지 않은 제안이다.

### A안 — 문의 링크 확정 전

```text
유도 입문과 수련을 쉽게 설명합니다 🥋
기술·도복·예절을 코치의 시선으로 기록합니다
```

- 목적: 코치 역할과 콘텐츠 약속 명확화
- CTA: 팔로우 또는 게시물 질문
- 상태: 제안·미적용·대표 승인 필요

### B안 — 검증된 문의 링크 확정 후

```text
유도 입문과 수련을 쉽게 설명합니다 🥋
기술·도복·예절을 코치의 시선으로 기록합니다
수업 문의 ↓
```

- 목적: 콘텐츠에서 수업 문의로 단일 전환 경로 제공
- 선행 조건: 승인된 URL, 실제 도착 시험, 지점·응대 범위 확인
- 상태: 제안·미적용·대표 승인 및 링크 입력 필요

두 안 모두 실제 코치의 경력·철학·당일 수련을 창작하지 않는다. `수업 문의 ↓`는 링크가 실제로 보이고 작동할 때만 사용한다.

## 7. 변경 통제 절차

| 단계 | 필수 기록 | 완료 조건 |
|---|---|---|
| CURRENT | 현재 공개 화면·조회시각 | 변경 전 증거 확보 |
| PROPOSED | 정확한 문구·링크·카테고리 변경 여부 | 승인 객체 고정 |
| APPROVED | 대표 승인·범위·시각 | 같은 변경에만 유효 |
| APPLIED | 적용자·적용시각 | 저장 동작 확인 |
| PUBLIC_VERIFIED | 공개 화면·링크 도착 | 제안과 실제 공개값 일치 |
| MEASUREMENT_READY | 기준선·귀속키·관찰기간 | 성과 관찰 가능 |

실질적인 문구·링크·대상 계정 변경이 생기면 다시 승인한다. 로그인 만료나 오류가 발생해도 완료라고 주장하지 않는다.

## 9. 계산 규칙

분자·분모·기간·원천이 같은 범위로 연결될 때만 계산한다.

- 프로필→문의율 = 유효 문의 ÷ 프로필 방문 × 100
- 문의→예약률 = 체험 예약 ÷ 유효 문의 × 100
- 예약→참석률 = 실제 체험 참석 ÷ 체험 예약 × 100
- 참석→등록률 = 신규 등록 ÷ 실제 체험 참석 × 100
- 문의당 순수납 = 귀속 순수납 ÷ 유효 문의

분모가 0이거나 미제공이면 계산 불가다. 전체 팔로워 수 감소를 특정 게시물, 소개문구 또는 문의 경로 탓으로 귀속하지 않는다.

## 10. 실험 EXP-316

### 가설

코치 역할, 콘텐츠 약속, 검증된 단일 문의 경로를 공개 프로필에서 일치시키면 콘텐츠 조회 이후의 실제 문의를 빠짐없이 구분해 기록할 수 있다.

### 대상과 기간

- 대표가 승인한 최초 프로필 변경 1회
- 변경 전 공개 기준선 1회
- 변경 직후 공개·링크 도착 검증
- 제안 관찰: T+7일과 T+14일

관찰기간은 외부 업계 기준이 아니라 비교 조건을 맞추기 위한 내부 제안이다.

### 운영 성공 기준

- 승인 문구와 공개 소개 일치율 100%
- 외부 링크 공개 노출·도착 확인률 100%
- 프로필 CTA 1개
- 코치 개인 계정과 공식 브랜드 계정의 혼동 표현 0건
- 미확정 가격·혜택·행사 노출 0건
- 테스트 문의의 실제 문의 혼입 0건
- 프로필 방문·문의·예약·참석의 단계 혼합 0건

### 성과 기준

프로필 방문·유효 문의·예약 데이터의 기준선이 연결되기 전까지 최소 개선폭은 `데이터 미연결`이다. 팔로워 수만으로 성공을 판정하지 않는다.

### 보류 기준

- 승인된 문의 URL 또는 응대 주체 없음
- 프로필 방문 지표 접근 불가
- 문의 도착 원천 또는 귀속키 없음
- 승인 전후 관찰기간이 다름

### 중단 기준

- 승인 없이 소개·링크·카테고리 변경
- 작동하지 않는 링크 공개
- 개인 계정을 브랜드 공식 발표 주체로 표현
- 회원 개인정보·미확정 혜택·행사 공개

## 11. 채널 인계

- Instagram: 코치 개인의 설명·수련·지도 맥락을 보여주고 단일 CTA로 프로필 행동을 유도한다.
- 네이버: 검증된 지점·시간표·준비물·문의 경로를 검색 의도에 맞게 제공한다.
- 당근: 확인된 근거리 지점·참여 대상·문의 방법을 짧게 안내한다.
- CRM: Instagram 문의자를 체험 후 미등록·휴면·만료예정과 혼합하지 않고 별도 상태로 시작한다.
