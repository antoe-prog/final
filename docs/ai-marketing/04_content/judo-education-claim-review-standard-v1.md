# 유도 교육형 콘텐츠 주장 검수 기준 v1

- 적용일: 2026-09-14
- 목적: 유도 개념을 설명하는 콘텐츠가 지도 모형, 실제 경기 규정, 개인 경험, 제품·도장별 사실을 혼동하지 않도록 검수한다.
- 공개 범위: 재사용 가능한 사실·표현·측정 기준만 포함한다. 승인 대기 중인 개별 Instagram 미디어와 캡션은 포함하지 않는다.

## 1. 주장 유형을 먼저 구분한다

| 유형 | 사용할 수 있는 근거 | 표현 원칙 | 금지 예시 |
|---|---|---|---|
| 공식 규정 | 최신 국제·국내 공식 규정 원문 | 적용 대회·시점·범위를 표시 | 모든 도장과 모든 수련에 같은 숫자 규격 적용 |
| 교육 모형 | 공식 교육자료, 학술자료, 전문 교육문헌 | 설명을 위해 나눈 단계임을 표시 | 실제 움직임이 항상 완전히 분리된 순서라고 단정 |
| 코치 경험 | 확인된 코치 발언·수련 기록 | 1인칭 주체와 날짜를 명확히 표시 | 자료 없이 지도 철학이나 당일 경험 창작 |
| 제품 사례 | 제조사 공식 자료 | 해당 제품·제조사 사례로 한정 | 한 제품의 구조를 모든 도복에 일반화 |
| 도장 운영정보 | 확인된 실제 시간표·가격·준비물 | 지점·기준일을 표시 | 미확정 체험 혜택·가격·수업시간 생성 |

## 2. 교육 모형과 실제 움직임을 구분한다

기술을 여러 단계로 나누는 설명은 입문자가 관찰 지점을 이해하도록 돕는 교육 장치가 될 수 있다. 그러나 실제 기술은 상대의 반응과 이동 속에서 이어질 수 있으므로 다음 표현을 우선한다.

- 사용 가능: “수업에서는 이해를 돕기 위해 나눠 설명할 수 있습니다.”
- 사용 가능: “실제 움직임에서는 각 과정이 이어져 나타날 수 있습니다.”
- 피해야 함: “모든 기술은 반드시 세 동작을 완전히 따로 실행합니다.”
- 피해야 함: “이 순서만 따르면 누구나 상대를 메칠 수 있습니다.”

Kano Society의 문헌은 기울이기·만들기·걸기를 유도의 기본적인 교육 체계로 설명한다. 생체역학 검토 논문은 이 구분이 교육적으로 유용하지만 실제 효과적인 동작은 하나의 흐름으로 발생한다고 설명한다. 이를 안전·성공 보장으로 확대하지 않는다.

## 3. 짧은 콘텐츠 문장 검수

각 문장을 아래 네 단계로 검사한다.

1. **사실:** 출처가 직접 뒷받침하는가?
2. **범위:** 모든 도복·선수·도장에 해당한다고 잘못 넓히지 않았는가?
3. **정도:** “항상”, “완벽하게”, “무조건”, “부상을 막는다” 같은 과장어가 없는가?
4. **행동:** 독자가 영상만 보고 위험한 기술을 따라 하도록 유도하지 않는가?

기술 교육 콘텐츠는 관찰 포인트와 질문을 제공하되, 지도자 없이 던지기·넘어뜨리기를 시도하도록 안내하지 않는다.

## 4. 시각자료 검수

- 실제 회원·보호자·시설 촬영물은 공개 사용 동의가 확인된 경우에만 사용한다.
- 개념 일러스트는 실제 기술 시연, 실제 코치 소유 장비, 특정 지점 내부 사진으로 표현하지 않는다.
- 국제연맹·제조사 로고와 인증 라벨을 임의로 그리지 않는다.
- 제목·핵심 문장·설명·보조표기의 크기와 굵기를 구분한다.
- 한 장마다 새로운 역할을 부여하고 장수 채우기용 반복을 금지한다.
- 이미지 캐러셀은 7~10장의 개별 파일로 제작하고 업로드 순서를 고정한다.

## 5. 채널 목적과 사업 KPI

교육형 게시물의 1차 목적은 입문자의 이해와 신뢰 형성이다. 저장·질문·프로필 방문은 사업 성과의 중간 신호일 뿐 등록이나 매출로 간주하지 않는다.

| 단계 | 지표 |
|---|---|
| 콘텐츠 소비 | 조회수, 조회한 계정, 완주 여부 |
| 유용성 | 저장, 공유, 질문 댓글 |
| 관심 이동 | 프로필 방문, 외부 링크 클릭, 수업 문의 |
| 체험 퍼널 | 문의, 체험 예약, 실제 방문 |
| 회원 성과 | 14일 등록, 30일 활성, 휴면 복귀, 재등록 |
| 재무 성과 | 확인된 결제액, 환불·비용을 반영한 순기여 |

분자·분모·측정기간·출처가 모두 있을 때만 비율을 계산한다. 화면의 “--” 또는 “-”는 0으로 변환하지 않는다.

## 6. 채널별 재사용 경계

- Instagram: 한 게시물에 CTA 하나만 사용한다.
- 네이버: 확인된 근거와 지점별 실제 정보를 추가하기 전 게시하지 않는다.
- 당근: 지역·가격·체험 조건이 확정되기 전 전환형 광고로 변환하지 않는다.
- CRM: 공개 콘텐츠 반응을 개인별 회원 상태로 추정하지 않는다. 실제 메시지 발송은 수신동의와 대표 승인 이후 별도 실행한다.

## 7. 실험 — EXP-288 교육 개념 콘텐츠 기준선

- 가설: 입문자가 이해하기 어려운 유도 개념을 관찰 가능한 장면으로 풀면 저장 또는 질문 행동이 발생할 수 있다.
- 측정 시점: 게시 후 24시간, 72시간
- 성공 기준: 지정 CTA 1개, 동일 정의 측정 완료 100%, 사실·권리·승인 오류 0건
- 보류 기준: 조회한 계정 또는 반응 지표 미집계, 표본 부족
- 중단 기준: 안전·성공 보장, 교육 모형의 절대화, 승인본 불일치, 개인정보 공개
- 저장률·문의율·등록률 개선폭: 데이터 미연결

## 8. 공개·승인 경계

- 승인 대기 미디어·캡션은 공개 저장소에 올리지 않는다.
- 대표가 해당 완성본을 승인한 이후에만 동일 파일·순서·캡션으로 업로드한다.
- 승인 후 실질적 변경이 생기면 수정 완성본을 다시 검수한다.
- 비용, 광고, 고객 메시지, 게시물 수정·삭제는 별도 명시적 승인 없이 실행하지 않는다.
