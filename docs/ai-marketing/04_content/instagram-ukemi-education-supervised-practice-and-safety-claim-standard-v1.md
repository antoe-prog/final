# Instagram 낙법 교육 콘텐츠의 지도하 연습·안전 주장 기준 v1

- 기준일: 2026-09-16
- 적용 대상: 코치 개인 Instagram에서 낙법·넘어짐·초보자 기술을 설명하는 콘텐츠
- 목적: 입문자의 궁금증을 풀되, 짧은 콘텐츠가 독학 지침이나 부상 예방 보장으로 오인되지 않도록 한다.
- 공개 범위: 재사용 가능한 근거·표현·검수·측정 기준만 포함한다.
- 제외: 승인 대기 중인 개별 미디어·캡션, 회원·보호자 정보, 내부 예산·성과, 미확정 행사·가격·혜택

## 1. 오늘의 운영 판단

낙법 콘텐츠의 1차 역할은 **기술을 온라인에서 완성시키는 것**이 아니라, 처음 수업에서 왜 넘어지는 연습을 접하는지 이해시키고 실제 지도 환경을 확인하게 하는 것이다.

공식 교육 자료에 낙법 연습이 있다는 사실, 특정 단체가 초보 수업의 순서를 설명한 사실, 특정 연령·대회 규정의 안전 제한은 서로 다른 근거다. 하나를 다른 범위의 보장으로 확대하지 않는다.

## 2. 근거의 네 층

| 층 | 근거 | 사용할 수 있는 주장 | 확대 금지 |
|---|---|---|---|
| U1 공식 활동 목록 | IJF Judo in Schools 수업 자료 | 뒤·옆·구르기 등 여러 낙법 활동이 교육 자료에서 구분되어 제시됨 | 모든 도장의 실제 수업 순서·횟수 |
| U2 단체 교육 설명 | 국가 유도단체의 입문 안내 | 해당 단체가 수업에서 낙법을 먼저 다룬다고 설명함 | 모든 연령·도장에 동일하다는 절대화 |
| U3 특정 규정 | 연령·등급·대회가 명시된 기술 제한 | 그 적용 범위 안의 경기 제한과 이유 | 일반 성인 수련·모든 도장 운영으로 일반화 |
| U4 실제 도장 사실 | 대표가 확인한 수업안·코치 기록 | 해당 지점·수업·기준일의 실제 운영 | 다른 지점 또는 상시 운영으로 확대 |

U1~U3만 있을 때 코치가 실제로 어떤 순서와 방식으로 지도한다는 1인칭 경험을 만들지 않는다.

## 3. 안전 주장 등급

### S0 - 설명 가능

- “낙법은 넘어질 때 몸을 쓰는 연습입니다.”
- “IJF 수업 자료에는 여러 낙법 연습이 따로 제시됩니다.”
- “수업 구성은 도장과 수련자의 수준에 따라 달라질 수 있습니다.”
- “매트 위에서 코치의 지도를 받아 연습하세요.”

### S1 - 조건부 설명

- “낙법은 메치기 연습에서 상대 역할을 맡을 때도 사용됩니다.”
- “처음에는 단계와 범위를 조절해 연습합니다.”

이 문장들은 실제 도장 방식이나 특정 자세를 말할 때 U4 확인이 필요하다. 일반 설명에서는 ‘도장마다 다름’, ‘지도자의 판단에 따름’을 함께 쓴다.

### S2 - 사용 금지 또는 전문 검토 필요

- “낙법을 배우면 다치지 않습니다.”
- “이 동작 하나로 머리·목·손목 부상을 예방합니다.”
- “영상만 보고 집에서 따라 해도 안전합니다.”
- “모든 초보자는 반드시 같은 순서와 횟수로 해야 합니다.”
- 특정 건강 상태에 대한 재활·치료·의학적 효능 주장

공식 단체의 설명에 안전 관련 표현이 있더라도 이를 무부상 보장, 의학적 효과, 개인별 적합성 판정으로 바꾸지 않는다.

## 4. 규정과 일반 수업을 분리한다

British Judo의 2026년 기술 제한 자료는 적용 연령·등급 범위가 명시된 경기 규정이다. 이 자료의 위험 사례와 제한을 일반 성인 입문 수업 전체의 절대 규칙으로 가져오지 않는다.

규정 인용 전 확인할 항목:

1. 발행 단체
2. 시행일
3. 적용 국가
4. 대회 또는 일상 수련 여부
5. 연령·학년·등급
6. 금지 기술·그립의 정확한 범위
7. 이후 개정 여부

적용 범위가 하나라도 불명확하면 숫자·기술명·금지 단정은 보류한다.

## 5. 독학 유도 방지

낙법·메치기 콘텐츠는 다음 중 하나 이상을 포함한다.

- 지도자와 매트 환경에서 연습할 것
- 몸 상태와 경험에 따라 범위를 조절할 것
- 영상이 개인별 수련 지시를 대신하지 않는다는 점

다음 시각·문구는 사용하지 않는다.

- 바닥이 단단하거나 주변 장애물이 있는 장소에서의 시연
- 목·머리·관절에 충격이 집중되는 장면을 단계 설명 없이 반복
- ‘바로 따라 하기’, ‘혼자 완성’, ‘절대 안 다치는 법’ 같은 문구
- 실제 코치의 감독처럼 보이는 생성형 인물·시설 이미지
- 특정 통증·질환이 있는 사람에게 동작을 권하는 개인별 조언

## 6. 캐러셀 구조

7~10장 캐러셀은 다음 역할을 중복 없이 배치한다.

1. 입문자의 질문
2. 유도 상황과 질문의 연결
3. 용어의 짧은 정의
4. 연습 방향 또는 유형의 차이
5. 단계·수준 조절
6. 상대 연습과의 연결
7. 지도 환경·개인 상태 고지
8. 단일 CTA

CTA는 저장·질문·팔로우·수업 문의 중 하나만 고른다. 지점·시간표·가격·혜택·체험 가능 여부가 확인되지 않으면 방문·구매 조건을 넣지 않는다.

## 7. 시각자료 검수

- 실제 회원·보호자·시설 촬영은 공개 사용 동의와 지점 일치가 확인된 경우만 사용한다.
- 개념 일러스트는 실제 코치·회원·시설·당일 수업 기록으로 표현하지 않는다.
- 인체 관절·손가락·목 방향이 비정상적이면 해당 이미지를 제외한다.
- 위험한 기술을 ‘정답 동작’처럼 단일 프레임으로 확정하지 않는다.
- 생성형 이미지에 한글을 직접 넣지 않고 결정형 조판 후 철자·띄어쓰기를 확인한다.
- 제목·핵심 문장·설명·계정 표기의 크기와 굵기를 구분한다.
- 7~10개 개별 파일, 동일 비율, 고정된 업로드 순서와 SHA-256을 기록한다.
- 검토 PDF를 다시 렌더링해 페이지 수·순서·잘림·빈 페이지를 확인한다.

## 8. 사실 검수 체크리스트

게시 후보의 각 문장에 다음을 기록한다.

| 필드 | 질문 |
|---|---|
| 주장 | 독자가 사실로 받아들일 문장은 무엇인가? |
| 근거층 | U1~U4 중 어디에 해당하는가? |
| 원문 범위 | 연령·국가·대회·수업 범위는 무엇인가? |
| 공개 표현 | 원문보다 강해지지 않았는가? |
| 안전 등급 | S0~S2 중 어디인가? |
| 독학 위험 | 혼자 위험한 동작을 시도하게 만들 수 있는가? |
| 현실 주장 | 실제 코치·회원·시설로 오인될 요소가 있는가? |
| 승인 | 완성본의 이미지·순서·캡션이 잠겼는가? |

하나라도 불명확하면 게시 준비 완료가 아니라 `사실 확인 보류`로 둔다.

## 9. 채널별 재사용

### Instagram

- 질문 하나, 설명 흐름 하나, CTA 하나를 유지한다.
- 코치 개인 계정이며 브랜드 공식 발표처럼 쓰지 않는다.
- 승인 전에는 플랫폼·외부 예약 도구에 업로드하거나 저장하지 않는다.

### 네이버

- 공식 출처 링크와 확인일을 넣고 FAQ 형태로 확장할 수 있다.
- 실제 수업 순서·준비물·방문 방법은 지점별 사실 확인 후 추가한다.

### 당근

- 지역 주민이 이해할 짧은 생활체육 설명으로 바꾼다.
- 수업 문의·방문 CTA는 실제 지점·응대 담당·체험 좌석이 확인된 경우에만 사용한다.

### CRM

- 공개 게시물 반응을 특정 회원의 건강·실력·복귀 의향으로 해석하지 않는다.
- 체험후미등록·휴면·만료예정 회원 연락은 동의·수신거부·대표 승인 확인 뒤 별도 실행한다.

## 10. 퍼널과 KPI

| 단계 | 지표 | 판정 경계 |
|---|---|---|
| 콘텐츠 노출 | 조회, 도달 | 같은 계정의 반복 조회와 도달을 혼합하지 않음 |
| 유용성 | 저장, 공유, 질문 댓글 | 좋아요와 저장을 합산하지 않음 |
| 관심 이동 | 프로필 방문, 링크 클릭, 수업 문의 | 조회를 문의로 간주하지 않음 |
| 체험 | 예약, 실제 방문 | 예약과 참석을 분리 |
| 신규 | 계약 시작, 14일 등록, 30일 활성 | 결제와 초기 출석을 분리 |
| 복귀·유지 | 복귀 출석, 만족, 재등록 | 반응을 복귀·재등록으로 간주하지 않음 |
| 재무 | 결제, 환불, 비용, 순수납 | 콘텐츠 기여 근거 없이는 귀속하지 않음 |

분자·분모·기간·출처가 모두 있을 때만 비율을 계산한다. `-`, `--`, 미집계는 0으로 바꾸지 않는다. 내부 문의·체험·회원·매출 데이터는 연결 전까지 `데이터 미연결`이다.

## 11. 실험 - EXP-329 낙법 교육 콘텐츠의 유용성·안전 경계

- 가설: 입문자가 수업에서 낙법을 먼저 접하는 이유를 짧게 설명하고 지도하 연습 경계를 명시하면, 과장 없이 저장 또는 질문 신호를 얻을 수 있다.
- 대상: 대표 승인 후 공개되는 해당 유형 콘텐츠 1건과 후속 2건
- 관찰: 게시 후 24시간·72시간
- 성공 조건:
  - 문장별 근거층·범위 기록률 100%
  - 단일 CTA 유지율 100%
  - 공식 자료의 적용 범위 오류 0건
  - 무부상·의학 효능·독학 안전 보장 0건
  - 미동의 회원 이미지 0건
  - 승인본과 공개본의 이미지·순서·캡션 불일치 0건
  - 조회·도달·저장·공유·댓글의 원천별 기록률 100%
- 보류:
  - 도달 또는 저장 지표 미제공
  - 대표 승인 미완료
  - 실제 수업 정보를 주장하지만 U4 근거 없음
- 중단:
  - 위험 동작의 독학 시도를 직접 유도
  - 특정 규정을 범위 밖 성인 수업에 적용
  - 조회·좋아요를 문의·등록·매출로 보고
- 저장률·문의율·등록률 목표: 데이터 미연결

## 12. 대표 승인·입력

- 실제 도장별 낙법 수업 순서와 단계
- 코치가 공개 가능한 실제 설명 포인트
- 코치 단독 촬영·비식별 촬영 가능 범위
- 건강·부상 관련 문구의 내부 검토 책임자
- 지점별 체험 가능 좌석·문의 경로·응대 담당
- 게시물별 관찰기간과 사업 귀속 기준

## 14. Auditor 결론

- 낙법을 무부상·치료·재활 보장으로 표현하지 않았다.
- 아동 대상 설명과 특정 연령 경기 규정을 일반 성인 수업으로 확대하지 않았다.
- 공식 활동 목록을 실제 도장 수업 순서로 둔갑시키지 않았다.
- 실제 코치 경험·회원 후기·시설·시간표·가격·혜택을 만들지 않았다.
- 개인정보·승인 대기 개별 콘텐츠·미확정 FINAL ROAD·민감 경영자료를 포함하지 않았다.
- 확인되지 않은 내부 회원수·전환율·매출은 데이터 미연결로 유지했다.
