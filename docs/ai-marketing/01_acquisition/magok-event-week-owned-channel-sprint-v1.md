# Magok Event-Week Owned-Channel Sprint v1

- 작성일: 2026-09-12
- 목적: 마곡의 단기 지역 관심이 높아지는 행사 주간에, 유료광고·현장영업·제휴 사칭 없이 파이널유도멀티짐의 소유 채널 콘텐츠가 실제 체험 예약·실방문으로 이어지는지 검증
- 상태: 설계 완료, 실제 게시·광고·현장홍보·고객발송 전
- 공개범위: 공개 가능한 전략·계측 정의만 포함. 회원/보호자 식별정보, 연락처, 개인별 출석·결제원장, 비밀키·토큰, 승인되지 않은 경영자료는 포함하지 않음.

## 1. CMO 판단

이번 회차는 기존 `Magok Workplace Near-Site Judo Pilot`을 반복하지 않는다. 기존 문서는 마곡 직장인이라는 장기 세그먼트를 검증하는 구조이고, 이 문서는 **2026-09-15~17 마곡에서 예정된 지역 관심 집중 구간을 단기 콘텐츠 실험창으로 활용**하는 것이 목적이다.

2026-09-04 LG가 공개한 `LG SPARK 2026` 일정에 따르면 행사는 9월 7~17일 마곡 LG사이언스파크에서 열리고, 마지막 `컬처위크`는 9월 15~17일 LG 구성원·가족·산학인재·마곡 지역주민·소상공인이 함께 참여하는 프로그램으로 운영된다. 이는 파이널유도 수요 증가의 증거가 아니지만, **마곡 지역 자체에 대한 관심과 이동·검색이 평소보다 집중될 수 있는 단기 지역 신호**다.

따라서 이번 우선순위는 `행사장에 가서 전단을 뿌린다`가 아니라, 행사와 무관한 자체 채널에서 **마곡에서 퇴근·생활하는 사람이 바로 판단할 수 있는 위치·시간·첫 방문 정보가 명확한 콘텐츠를 준비하고, 실제 여석이 확인된 슬롯으로만 라우팅**하는 것이다.

내부 성과 데이터는 새로 연결되지 않았다. 신규문의 수, 마곡권역 유입비중, 예약→실방문률, 등록률, 30일 활성률, 재등록률, 귀속매출은 모두 `데이터 미연결`이다.

## 3. 이번 전략이 기존 문서와 다른 점

- `magok-workplace-nearsite-judo-pilot-v1.md`: 마곡 직장인이라는 장기 획득 세그먼트와 B2B 가능성 검증
- `capacity-first-open-dojo-week-v1.md`: 여석이 있는 반만 열어 도장 자체 체험주간 운영
- `hyperlocal-dooh-capacity-pilot-v1.md`: 유료 옥외광고 검증
- **이번 문서**: 특정 지역 관심 주간에 유료집행 없이 자체 채널 콘텐츠의 지역 적합성과 전환경로를 짧게 검증

따라서 이번 실험에서 별도의 오픈도장 행사나 기업 제휴를 만들지 않는다.

## 4. Growth Analyst — 퍼널과 병목

### 권장 퍼널

`owned_content_view → location_time_fit_check → inquiry → slot_selected → reservation → verified_attendance → visit_2 → paid_within_14d → active_30d → renewal`

### 새로 분리할 태그

- `campaign_context`: `magok_event_week_2026`
- `lead_source`: naver / instagram / daangn / direct / referral / other
- `audience_self_identified`: workplace / local_resident / parent / other / unknown
- `slot_id`
- `verified_attendance`
- `paid_within_14d`
- `active_30d`
- `renewal`

회사명, 근무지 상세주소, 직원명단은 기본 수집항목으로 두지 않는다. 본인이 직장인·지역주민임을 자발적으로 표시한 경우에도 공개 저장소에는 개인 단위 데이터를 남기지 않는다.

### 핵심 병목

이번 실험의 핵심 병목은 `content_view → inquiry`가 아니라 **`inquiry → reservation → verified_attendance`**다. 지역 행사 주간에 조회수만 늘어도 실제 수업 여석·방문으로 이어지지 않으면 성공으로 판단하지 않는다.

## 5. Acquisition Marketer — 캠페인 방향

### A. `마곡에서 퇴근 후 첫 유도` 정보형 콘텐츠

실제 확인된 정보만 사용한다.

- 본관 위치와 대중교통/도보 경로
- 실제 가능한 성인 체험시간
- 권장 도착시각
- 첫 방문 복장·준비물
- 첫 수업에서 다루는 범위
- 예약 또는 문의 CTA 1개

금지:
- `LG 임직원 추천`
- `LG SPARK 제휴`
- `행사 참가자 특별혜택`
- 실제 데이터 없는 `마감임박`, `마지막 자리`

### B. `가족/지역주민` 보조 콘텐츠

컬처위크가 가족·지역주민까지 포함한다는 외부 신호는 참고하지만, 현재 파이널유도의 가족 체험수요가 확인된 것은 아니다. 따라서 가족 패키지나 보호자 할인부터 만들지 않는다.

필요 시 기존 `Parent-to-Member Household Expansion` 및 `Youth Class-Fit Routing`으로 연결하고, 유소년 반은 안전정원과 연령/학년 적합성 확인 후에만 안내한다.

### C. `한 콘텐츠 = 한 CTA`

한 게시물에서 `성인체험 / 유소년체험 / 기업문의 / 이벤트 / 쿠폰 / 추천`을 동시에 제시하지 않는다.

이번 주간에는 우선 한 CTA를 `실제 여석이 확인된 성인 체험` 또는 `일반 문의` 중 하나로 제한한다. 어떤 CTA를 사용할지는 대표 승인 및 실제 시간표 확인 후 결정한다.

## 6. CRM Marketer — 후속 원칙

행사 주간이라는 이유로 메시지 횟수를 늘리지 않는다.

- 신규문의: 기존 체험 후속관리 흐름 사용
- 예약자: `Trial Pre-Visit Certainty` 기준으로 시간·위치·준비물만 명확히 제공
- 첫 체험 참석자: 기존 `Second-Visit Trial Bridge` 사용
- 장기 휴면회원: `마곡 행사주간`을 이유로 일괄 재활성 메시지 발송 금지

`campaign_context`는 성과 분석용 태그이지 연락 권한이 아니다.

## 7. Content Strategist — 채널별 실행안

### 네이버

목적: 지역 검색에서 첫 방문 정보를 한 번에 이해시키기

후보 주제:
- `마곡에서 퇴근 후 유도를 처음 시작할 때 확인할 5가지`
- `성인 유도 첫날: 준비물·도착시간·수업 흐름`

조건:
- 실제 영업시간과 체험 가능시간 확인 후 작성
- `마곡 행사`, `LG SPARK` 키워드를 제목 낚시용으로 사용하지 않음

### 인스타그램

목적: 첫 방문 과정을 시각적으로 보여주기

후보 흐름:
`도착 → 운동 준비 → 낙법/기본 움직임 → 기술 설명 → 정리 → 문의 CTA`

조건:
- 회원 얼굴·이름은 공개동의 없이는 노출하지 않음
- 특정 회사 로고·사원증·행사 시설을 배경으로 촬영해 제휴처럼 보이게 하지 않음

### 당근

목적: 실제 생활권 안에서 이용 가능한 시간대 제시

조건:
- 본관 실제 영업권역과 게시 가능 범위 확인
- 해당 슬롯의 체험 허용석 확인
- 실제 여석이 없으면 게시하지 않거나 대체시간/대기옵션으로 전환

## 8. Experiment Manager

### EXP-225 Event-Week Context Copy vs Generic Adult Copy

가설: 일반적인 `성인 유도 체험` 정보보다 `마곡 근거리 + 실제 시간 + 첫 방문 정보`를 명확히 한 콘텐츠가 실방문 전환을 개선할 수 있다.

비교:
- A: 일반 성인 유도 체험 콘텐츠
- B: 근거리·시간·첫 방문 정보 중심 콘텐츠

동일하게 유지할 것:
- 실제 가격
- 실제 안전정원
- 실제 예약 가능시간
- 체험 조건

주지표:
- `verified_attendance / completed_reservations`

보조지표:
- 콘텐츠→문의
- 문의→예약
- 예약→실방문
- 첫 방문→2회차
- 14일 내 유료등록
- 30일 활성
- 반복문의량

기준선·최소개선폭·표본수는 `데이터 미연결`이다.

중단 기준:
- 실제 여석보다 많은 예약 유도
- 시간·위치·비용 오안내
- 행사/기업과의 제휴 오인 유발
- 문의만 늘고 실방문 또는 30일 활성에 개선 신호가 없음
- 기존회원 수업혼잡·코치부담 증가

### EXP-226 Single-CTA vs Multi-CTA Content

가설: 하나의 지역형 콘텐츠에서 하나의 다음 행동만 제시하면 예약경로가 더 명확해질 수 있다.

A: 체험/기업/유소년/쿠폰 등 복수 CTA
B: 해당 콘텐츠 목적에 맞는 CTA 1개

주지표:
- `reservation / qualified_inquiries`

보조지표:
- 반복문의량
- 잘못된 반 예약률
- 취소율
- 실방문률

성공 기준은 내부 기준선 연결 후 설정한다.

## 9. 대표 승인 전 필요한 입력

1. 본관 실제 주소·층·출입경로
2. 성인 체험 가능한 요일·시간
3. 각 시간대 안전정원·체험 허용석
4. 체험비/등록비/도복 정책
5. 권장 도착시간과 첫 수업 실제 구성
6. 현재 네이버·인스타·당근의 운영 가능 채널과 게시 권한
7. 실제 게시 여부와 게시일 승인

확인 전 모든 값은 `데이터 미연결` 또는 `대표 승인 전`으로 유지한다.

## 11. Auditor — 브랜드·컴플라이언스 가드

- LG 및 LG SPARK와 공식 관계가 있는 것처럼 표현하지 않는다.
- 행사명·기업명을 이용한 매복광고, 현장영업, 무단전단 배포를 실행하지 않는다.
- 특정 회사 직원이라고 추정해 타깃 메시지를 보내지 않는다.
- `직장 스트레스 치료`, `생산성 향상`, `자신감 보장`, `다이어트 보장` 등 검증되지 않은 효능을 사용하지 않는다.
- 실제 안전정원과 시간표가 확인되지 않은 상태에서 `오늘 바로 체험`, `마지막 자리`를 사용하지 않는다.
- 공개 GitHub에는 전략과 집계 정의만 두고 개인·회원 데이터를 저장하지 않는다.

## 12. 결론

이번 단기 전략의 의미는 `큰 행사가 있으니 사람을 끌어오자`가 아니다. **마곡 지역에 관심이 집중되는 짧은 기간을 이용해, 파이널유도 자체 채널의 지역 적합성·시간 명확성·첫 방문 정보가 실제 예약과 실방문으로 이어지는지 검증하는 것**이다.

광고비, 할인, 고객발송, 현장영업, 기업제휴는 대표의 명시적 승인 없이는 실행하지 않는다.
