# Magok Workplace Near-Site Judo Pilot v1

- 작성일: 2026-09-12
- 목적: 마곡·강서권 직장인을 대상으로 한 B2B/근거리 성인 유도 신규획득 가능성 검증
- 상태: 설계 완료, 기업 접촉·광고·가격 확정·고객 모집 전
- 공개범위: 공개 가능한 전략·계측 정의만 포함. 회원/보호자 식별정보, 연락처, 개인별 출석·결제원장, 비밀키·토큰, 승인되지 않은 경영자료는 포함하지 않음.

## 1. CMO 판단

이번 파일럿의 핵심은 `기업복지 프로그램을 당장 판매한다`가 아니라, **마곡의 밀집된 업무권역에서 직장인이 퇴근 후 가까운 체육시설을 선택하는 수요가 파이널유도멀티짐의 실제 체험·등록·30일 활성로 연결되는지 먼저 검증**하는 것이다.

기존 신규획득 문서가 일반 지역주민, 친구추천, 여성 초보, 그래플링 경험자, 입문기수 등을 다룬다면 이 문서는 `workplace_source`가 확인되는 성인 문의와 기업 단위 자발적 문의를 별도 퍼널로 본다.

확인되지 않은 내부 회원수·매출·전환율·마곡 직장인 회원 비중은 모두 `데이터 미연결`로 유지한다.

## 2. 이번에 확인한 외부 변화

### 2.1 마곡 업무권역은 현재도 확장 중

서울시는 2026-09-10 마곡일반산업단지 내 복합용지 33필지의 일반분양을 공식 안내했다. 이는 파이널유도 수요 증가를 뜻하지 않지만, 마곡이 계속 업무·산업 기능을 확장하는 권역이라는 최신 지역 신호다.

- 서울특별시, `마곡일반산업단지 내 복합용지 일반분양 안내`, 2026-09-10
  - https://news.seoul.go.kr/economy/archives/574612

2026-03-30 보도 기준 마곡산업단지는 209개 대·중소기업 연구시설이 집적된 R&D 거점으로 소개됐다. 숫자는 시점에 따라 바뀔 수 있으므로 영업자료에 고정 수치로 쓰지 않고, 기업 밀집 권역이라는 참고 근거로만 사용한다.

- 뉴스1, `서울시, 마곡산단 대기업과 손잡을 스타트업 20개사 찾는다`, 2026-03-30
  - https://www.news1.kr/society/welfare-hr/6117539

### 2.2 국내 생활체육 선택에서 '가까움'과 '시간'이 핵심 마찰

문화체육관광부의 2025년 국민생활체육조사에서 체육시설을 자주 이용하는 이유 1위는 `거리상 가까워서` 38.7%였고, 최근 1년 체육활동 비참여자의 주요 이유 가운데 `체육활동 가능 시간이 부족해서`가 58.4%였다.

이는 유도 수요의 직접 증거가 아니지만, 직장인 획득 전략에서 `마곡에서 퇴근 후 이동이 짧다`, `정확한 시작·종료 시각을 알 수 있다`, `첫 방문 준비가 단순하다` 같은 편의성이 가격 할인보다 먼저 검증할 가치가 있음을 뒷받침한다.

- 문화체육관광부, `2025년 국민생활체육조사`, 2026-01-20
  - https://www.mcst.go.kr/site/s_policy/subPolicy/sportstour/sportstour29.jsp

### 2.3 2026 기업 웰니스는 로컬 파트너·유연한 접근성을 강조

Wellhub의 2026 기업 웰니스 트렌드는 온사이트 프로그램 하나만 제공하기보다 로컬 파트너 체육시설, 근거리 스튜디오, 유연한 시간 선택을 포함한 하이브리드형 접근을 강조한다. 공급사 자료이므로 그 효과 수치를 파이널유도의 예상성과로 사용하지 않는다.

- Wellhub, `Corporate Wellness Trends HR Must Know for 2026`
  - https://wellhub.com/en-us/blog/wellness-and-benefits-programs/corporate-wellness-trends/

국내 B2B 웰니스 업체 Dalam의 2026 보고서는 자사 프로그램 이용 로그 4,264건에서 9월 이용량이 가장 많았다고 발표했다. 특정 공급사 이용자료이며 일반 직장인 전체 수요를 대표하지 않으므로 `9월에 반드시 잘 팔린다`는 근거로 사용하지 않는다. 다만 현재 시점에 HR·웰니스 접점을 시험할 계절적 참고신호로만 본다.

- 매일경제, `2026 Corporate Wellness Report` 관련 기사, 2026-04-20
  - https://www.mk.co.kr/en/culture/12021893

### 2.4 무도시설도 기업 전용 체험상품을 실제 운영

현재 KD MMA는 회사 단체를 대상으로 약 60분 입문 세션, 사무실 또는 체육관 진행, 라이브 스파링 제외 구조의 기업 프로그램을 공개 운영하고 있다. Ippon Sports Academy도 기업 웰니스·팀 워크숍을 별도 상품으로 제공한다.

이 사례는 `기업 유도 프로그램이 효과가 있다`는 증거가 아니라, **무도시설이 일반 개인회원권과 별개로 낮은 진입장벽의 기업 체험상품을 설계할 수 있다는 운영 사례**다.

- KD MMA, Corporate Team Training & Wellness
  - https://www.kdmma.com/corporate
- Ippon Sports Academy, Corporate Wellness & Self-Defense Programs
  - https://ipponsportsacademy.com/pages/corporate/

## 3. 목표 우선순위

1. 신규 체험회원 확보: 마곡 근무자·기업 단체의 자발적 문의가 실제 실방문으로 이어지는지 확인
2. 매출 증대: 개인 등록과 기업 단체 세션을 분리 계측해 순기여 확인
3. 기존회원 만족·재등록: 신규 단체 유입이 기존 성인반 혼잡·코치부담을 만들지 않는지 보호
4. 휴면회원 복귀: 휴면회원 중 현재 마곡 근무자가 본인 의사로 복귀경로를 선택하는 경우에만 후속 검토

## 4. Growth Analyst — 퍼널과 병목

### 개인 직장인 퍼널

`workplace_content_or_source → inquiry → workplace_self_identified → slot_selected → reservation → verified_attendance → visit_2 → paid_within_14d → active_30d → renewal`

### 기업 단체 퍼널

`company_inquiry → needs_confirmed → capacity_safety_check → proposal_approved → session_reserved → verified_group_attendance → individual_opt_in → paid_registration → active_30d`

### 반드시 분리할 데이터

- `lead_source`: 네이버 / 인스타 / 당근 / 직접검색 / 소개 / 기업문의 / 기타
- `workplace_area`: 상세 회사명 없이 권역 수준부터 시작 가능
- `preferred_time`: 퇴근 후 / 점심 / 주말 / 기타
- `travel_time_band`: 자발적 응답 시 범주형으로만 수집
- `company_group_interest`: 개인 / 동료 동반 / 기업 단체
- `verified_attendance`
- `paid_within_14d`
- `active_30d`
- `renewal`
- `staff_minutes`
- `direct_cost`

회사명·직원명단·개인 연락처를 공개 저장소에 기록하지 않는다.

## 5. Acquisition Marketer — 제안 캠페인

### 캠페인 A: `퇴근 후 60분, 첫 유도`

핵심 메시지는 건강효과 보장이 아니라 **거리·시간·첫 방문 불확실성 제거**다.

승인 전 후보 메시지 방향:

- 마곡·강서권에서 퇴근 후 시작 가능한 성인 유도
- 처음 시작하는 직장인이 첫날 무엇을 배우는지 공개
- 시작·종료시각, 준비물, 도착경로를 명확히 제공

실제 `60분`, 요일, 시작시각, 체험비, 도복 정책은 대표 승인과 운영확인 전 외부에 확정 표현하지 않는다.

### 캠페인 B: `Coworker Pair Trial`

동료 1인과 함께 오고 싶다는 자발적 수요가 있는 경우만 선택지를 제공한다. 기존 `Buddy Referral`과 달리 현 회원의 추천 보상이 목적이 아니라 **직장 동료가 함께 첫 방문할 때 실방문 마찰이 줄어드는지**를 측정한다.

운영자가 직원 명단을 받거나 회사 메일주소를 긁어 대량 DM하지 않는다.

### 캠페인 C: `Company Intro Session`

기업 HR·총무·동호회 담당자가 먼저 문의하거나 공개 B2B 제안이 승인된 경우에만 검토한다.

권장 초기 구조:

- 비경쟁·초보자 중심
- 낙법·기본 이동·균형·그립 등 저위험 범위부터 검토
- 라이브 란도리/강한 메치기는 별도 안전 승인 없이는 포함하지 않음
- 참여 인원 상한은 매트 면적·코치 수·보험·안전정원 확인 후 결정
- 1회 체험과 정규 회원권을 강제 묶지 않음

## 6. CRM Marketer — 후속 구조

개인 직장인 체험자는 기존 `trial-followup-review`의 승인된 연락 흐름을 사용하고 메시지 횟수를 추가하지 않는다.

기업 단체 참가자는 회사가 제공한 명단을 개인 영업DB로 전환하지 않는다. 개인이 정규수업 정보를 직접 요청하거나 별도 opt-in 한 경우에만 일반 개인 퍼널로 전환한다.

휴면회원 대상으로 `마곡 직장인이니까`라는 추정 세그먼트를 만들지 않는다. 직장정보를 기존 데이터에서 임의 결합해 영업하지 않는다.

## 7. Content Strategist — 채널별 실행안

### 네이버

- `마곡 직장인 퇴근 후 운동, 유도 처음 시작할 때 확인할 것`
- `유도 첫날 준비물·도착시간·수업 흐름`
- 실제 시간표와 위치가 확인된 경우에만 거리·시간 관련 표현 사용

### 인스타그램

- 퇴근복 차림 도착 → 운동복 준비 → 기본 움직임 → 수업 종료까지의 정보형 릴스
- 특정 회사 로고·사원증·직원 얼굴을 무단 노출하지 않음
- `스트레스 치료`, `업무 생산성 향상 보장` 같은 효능 표현 금지

### 당근

- 본관 실제 영업권역과 체험 가능석이 확인된 경우에만 지역형 게시
- `마곡 직장인`을 과도하게 좁혀 개인정보 추정형 타기팅 문구로 사용하지 않음
- `선착순 마지막 자리`는 실제 좌석 데이터가 있을 때만 사용

## 8. Experiment Manager

### EXP-221 Near-Site Workplace CTA vs Generic Adult CTA

가설: `성인 유도 체험` 일반 메시지보다 `마곡·강서 근거리 + 정확한 소요시간/수업시간 + 첫 방문 정보` 메시지가 직장인 자발적 문의의 실방문 전환을 높일 수 있다.

주 KPI:

- 유효문의 → 예약
- 예약 → verified_attendance
- 첫 방문 → visit_2
- 실방문 → paid_within_14d
- 등록 → active_30d

보호 KPI:

- 잘못된 시간/거리 문의
- 기존 성인반 혼잡
- 코치 추가 처리시간
- 취소·노쇼
- 민원/불편

성공 기준: 최소 개선폭과 표본수는 `데이터 미연결`. 사전에 기준선을 연결한 뒤 확정한다.

중단 기준:

- 문의만 늘고 verified_attendance/active_30d가 개선되지 않음
- 안전정원 초과
- 기존회원 수업품질 저하
- 과장된 건강·업무성과 표현 필요

### EXP-222 Individual Trial vs Employer-Sponsored Intro

가설: 충분한 기업 자발적 문의가 확인될 경우 기업이 비용 또는 장소를 지원하는 1회 입문 세션이 개인 광고와 다른 신규유입 경로가 될 수 있다.

주 KPI:

- 제안 대상 기업수보다 `자발적·승인된 기업문의수`를 우선 기록
- 기업 세션 예약 → 실제 참석
- 참석 → 개인 opt-in
- opt-in → 정규 체험/등록
- active_30d
- 기업 세션 순기여

비용·가격·기업할인·출장비는 모두 대표 승인 전 `데이터 미연결`.

## 9. 필요한 대표 승인·입력

실제 실행 전 필요한 값:

1. 본관과 마곡 업무권역의 실제 이동 편의 및 외부 안내 가능한 기준
2. 성인반 실제 요일·시간·안전정원·체험 허용석
3. 직장인용 별도 체험시간을 만들 수 있는지 여부
4. 기업 단체 1회 세션을 받을 의향과 최대 인원
5. 외부출장 가능 여부
6. 보험·면책·안전 운영기준
7. 개인 체험비·기업 세션 가격·할인 허용범위
8. 최근 성인 문의의 비식별 lead_source / 예약 / 실방문 / 등록 / 30일 활성 데이터
9. 기존회원 수업품질 보호 기준

## 11. Auditor — 리스크 및 금지사항

- 마곡에 기업이 많다는 사실을 파이널유도 수요로 등치하지 않는다.
- `직장인 스트레스 감소`, `생산성 증가`, `번아웃 개선`을 의학·성과 보장처럼 광고하지 않는다.
- 기업 직원명단, 회사 이메일 패턴, LinkedIn 프로필 등을 수집해 무단 대량영업하지 않는다.
- 특정 기업과 제휴하지 않았는데 `LG 직원 프로그램`, `마곡 기업 전용 제휴`처럼 표현하지 않는다.
- 기업 세션 참가자를 자동으로 개인 마케팅 DB에 편입하지 않는다.
- 기존회원 반의 안전정원·수업품질을 침해하면서 B2B 매출을 우선하지 않는다.
- 외부 공급사의 ROI·참여율 수치를 파이널유도 예상성과로 전용하지 않는다.

## 12. 현재 결론

공개 데이터는 `마곡 업무권역이 계속 확장 중`, `생활체육 선택에서 가까운 거리와 시간 제약이 중요`, `기업 웰니스 시장에서 로컬 파트너 체육시설 모델이 실제 존재`한다는 점까지만 지지한다.

따라서 다음 단계는 기업 영업 대량발송이 아니라 **현재 성인 문의에서 직장/권역 출처를 비식별로 계측하고, 실제 여석이 있는 시간대에 근거리·시간확실성 메시지를 A/B 검증한 뒤 B2B 상품을 판단하는 것**이다.
