# Capacity-First Open Dojo Week — 신규획득 전략 v1

- 작성일: 2026-09-11
- 상태: 공개자료 기반 전략 설계 / 실제 모집·게시·광고 미집행
- 내부 회원수·매출·전환율·시간대별 정원: **데이터 미연결**
- 목표: 신규 체험 확보 + 기존회원 경험 보호 + 휴면 복귀 + 실질 여석의 매출화

## 오늘의 판단

이번 우선순위는 **CAPACITY-FIRST ACQUISITION**이다. 신규 문의를 무조건 늘리기보다 `실제 모집 가능한 시간대 → 제한된 체험석 → 실방문 → 유료등록 → 30일 활성` 순으로 모집한다.

2026년 9월 현재 유도·무도시설 사례에서는 Open Dojo/Open House를 단순 무료체험으로만 운영하지 않고, **기간·대상·시간·정원을 명확히 구분**하는 흐름이 확인된다. 특히 Judo & Ju-Jitsu Club Winterthur는 Open Dojo Days에서 어린이 유도는 회차당 최대 5명, 성인 유도·주짓수는 최대 10명으로 예약을 제한한다. Metz Judo는 9월 5일 대부분의 수업이 거의 찼다고 공지하고, 남은 특정 과정만 모집한다. 이는 `모집량`이 아니라 `수용 가능한 슬롯에 맞춘 모집`이 운영 품질을 지키는 핵심이라는 외부 사례다.

파이널유도의 실제 시간대별 안전정원·평균출석·여석은 **데이터 미연결**이므로 현재 어느 반을 모집해야 하는지 추정하지 않는다.

## 발견한 변화

### 1. 전국 단위 Open Dojo가 신규회원 확보 수단으로 운영됨

Swiss Judo & Ju-Jitsu Federation은 2026년 9월 7~13일 전국 Open Dojo Days를 운영하며 목표를 관심자에게 유도·주짓수를 경험시키고 신규회원을 확보하는 것으로 명시했다.

### 2. 체험회차를 정원 제한형으로 운영하는 실제 유도장 사례

Judo & Ju-Jitsu Club Winterthur는 같은 기간 체험을 연령·종목·요일별로 쪼개고, 어린이 유도 최대 5명, 성인 과정 최대 10명으로 제한한다. 참여자는 공식 예약페이지에서 사전등록한다.

### 3. `모든 반 모집`보다 남은 자리만 모집하는 운영

Metz Judo는 2026년 9월 5일 대부분의 수업이 거의 정원에 도달했다고 공지하면서 실제 자리가 남은 일부 연령·과정만 안내했다. 9월 7~13일에는 별도의 등록 상담시간도 운영한다.

### 4. Open House를 미니체험·시범·커뮤니티 경험으로 확장

Abbotsford Judo Club은 2026년 9월 20일 Open House에서 짧은 유도 체험, 상급자 시범, 가족 참여 활동, 클럽 역사 소개를 함께 제공한다. 단순 가격 프로모션보다 `도장을 이해하고 직접 경험하는 행사`로 설계한다.

## Growth Analyst — 필요한 퍼널

`slot_capacity → trial_seats_open → reservation → attendance → paid → active_30d → renewal → slot_revenue`

시간대 단위 최소 데이터:

- `class_id`
- `target_segment`
- `safe_capacity`
- `active_members`
- `avg_attendance_28d`
- `trial_seats_open`
- `trial_reserved`
- `trial_attended`
- `paid_14d`
- `active_30d`
- `waitlist_count`

현재 값은 모두 **데이터 미연결**이다. `safe_capacity - 회원수`만으로 체험석을 계산하지 않는다. 실제 출석 변동, 수업구성, 연령, 코치 인원, 안전조건을 함께 확인해야 한다.

## Acquisition Marketer — 모집안

### FINAL OPEN DOJO DISCOVERY WEEK

하나의 대형 무료행사를 무조건 여는 방식이 아니라, **여석이 확인된 기존 수업 또는 승인된 별도 입문 슬롯만 체험회차로 공개**한다.

공개 정보:

- 대상: `[확인된 연령/경험]`
- 날짜·시간: `[확인된 체험 가능 회차]`
- 모집석: `[실제 승인 체험석]`
- 준비물·비용: `[확인된 운영정보]`
- 신청: 기존 예약경로 또는 Self-Opt-In 신청링크

무료·도복대여·특정 승급·성과·잔여좌석은 확인 없이 광고하지 않는다.

## CRM Marketer — 기존 리드와 휴면회원 우선순위

신규 유료광고 전에 같은 여석을 아래 순서로 검토한다.

1. 체험후미등록자 중 해당 시간대가 맞는 고객
2. 휴면·복귀의향 회원 중 해당 시간대가 맞는 고객
3. 기존회원 Buddy Self-Opt-In 유입
4. 일반 신규 자연유입
5. 필요할 경우 승인된 유료획득

이는 우선순위 제안이며 실제 연락은 별도 승인 전 수행하지 않는다.

## Content Strategist — 채널별 역할

### 네이버

검색자의 불확실성을 줄이는 정보형 콘텐츠: `유도 초보 체험은 어떤 시간대에 참여할 수 있나요?`, `첫 체험에서 준비할 것`, `연령·경험별 수업 선택법`.

### Instagram

한 회차의 짧은 흐름을 시각화: `입장 → 기본 움직임 → 안전한 초보 드릴 → 코치 피드백 → 마무리`. 실제 회원 촬영·게시에는 동의가 필요하다.

### 당근

지역성과 실제 모집가능성을 결합한다. `[강서/해당 생활권] + [확인된 대상] + [확인된 날짜] + [실제 체험석]`만 표시한다. 여석을 확인하지 않은 `마감임박`, `딱 N자리` 같은 인위적 희소성 표현은 금지한다.

## 즉시 실행 3개

1. **Class Capacity Map 작성**: 시간대별 안전정원, 최근 실제 출석, 체험 허용석, 대기 여부를 연결한다. 현재 수치는 데이터 미연결.
2. **Discovery Week 후보 슬롯 선정**: 정원이 확인된 반만 후보로 만들고 어린이·청소년·성인 등 실제 운영 세그먼트별로 분리한다.
3. **예약 후속 흐름 연결**: 체험 예약 → 현장 출석 확인 → 14일 내 등록 → 30일 활성까지 기존 계측 규격과 연결한다.

## 실험

### EXP-187 Capacity-Gated Trial vs Always-On Trial

가설: 모든 시간대에 체험을 열어두는 방식보다 실제 여석이 있는 회차만 노출하면 수업 과밀을 줄이면서 체험→활성 전환의 품질을 높일 수 있다.

- KPI: 예약→실방문, 실방문→유료등록, 30일 활성, 수업 과밀/불편 사건
- 성공: 사전 정의한 최소 개선폭을 충족하고 기존회원 만족·안전 지표가 악화되지 않을 때 확대 검토
- 중단: 안전정원 초과, 코치부담 증가, 기존회원 불편 증가, 등록·활성 개선 부재

### EXP-188 Slot-Specific CTA vs Generic CTA

가설: `체험 문의하세요`보다 실제 가능한 대상·요일·시간을 명확히 보여주는 CTA가 예약 후 실방문까지의 불확실성을 줄일 수 있다.

- KPI: 콘텐츠→유효문의→예약→실방문
- 성공: 동일 채널·유사 도달 조건에서 사전 기준보다 하단 퍼널이 개선될 때 확대
- 중단: 문의량만 늘고 실방문이 개선되지 않거나 특정 반의 체험수요만 과밀해질 때 수정

두 실험의 기준선·표본수·최소개선폭은 **데이터 미연결**이며 임의 숫자를 확정하지 않는다.

## 필요한 대표 승인·입력

- 지점별 실제 수업표
- 시간대별 안전정원과 담당코치 수
- 최근 28일 시간대별 실출석
- 체험 허용 인원·비용·도복·준비물 정책
- 체험후미등록·휴면회원에게 연락 가능한 범위
- Open Dojo 형식의 행사성 운영 허용 여부
- 유료광고를 사용할 경우 별도 예산 승인

## Auditor

- `마감임박`, `잔여 N석`은 실제 정원·예약 현황이 확인되는 경우에만 사용한다.
- 해외 Open Dojo의 무료 정책·정원 숫자를 파이널유도 기준으로 복사하지 않는다.
- 체험 인원을 늘리는 것이 기존회원 경험과 안전을 악화시키면 신규획득 성공으로 보지 않는다.
- 단순 예약수를 성과로 보고하지 않고 현장 방문·유료등록·30일 활성까지 추적한다.
- 미성년자 촬영·후기·연락정보는 보호자 동의와 내부 정책을 확인한다.
- 비용발생, 광고집행, 고객 메시지 발송, 계정·운영DB 변경은 별도 명시적 승인 전 실행하지 않는다.
