# Grappling Crossover Acquisition v1

- 작성 기준일: 2026-09-12
- 상태: 전략·실험 설계 완료 / 고객 연락·가격변경·유료집행·제휴표기 전
- 목표: 주짓수·레슬링 등 인접 그래플링 종목 관심층을 유도 성인 체험으로 연결하고, 휴면 성인회원 복귀·기존 성인회원 만족·추가 매출 가능성을 함께 검증
- 내부 회원수·문의수·매출·전환율: **데이터 미연결**

## 오늘의 판단

이번 회차의 우선순위는 완전 초보를 대상으로 한 기존 `Skill-First Ukemi Gateway`와 별도로, **이미 주짓수·레슬링 등 그래플링 경험 또는 관심이 있는 성인에게 유도의 스탠딩·그립·균형·메치기 경험을 별도 진입경로로 제시하는 `Grappling Crossover Gateway`를 검증하는 것**이다.

2026년 9월 12일 강서구 가양레포츠센터에서는 공개 게시 기준 제2회 강서구주짓수회장배 주짓수 챔피언십이 예정되어 있고, 해외에서는 BJJ 아카데미가 9월 12일부터 별도 유도 수업을 추가하거나 Judo/BJJ/Wrestling을 한 캠프 안에서 결합하는 운영 사례가 확인된다. 이는 `강서구에서 유도 수요가 증가한다`는 증거가 아니라, **파이널유도 본관이 위치한 지역과 동시기 시장에서 인접 그래플링 종목 관심층이 실재하고, 종목 간 교차수련 상품이 실제로 운영되고 있다는 신호**로만 사용한다.

핵심 퍼널은 다음과 같다.

`adjacent_sport_interest → crossover_content → self_opt_in → crossover_trial → visit_2 → paid_within_14d → active_30d → renewal`

휴면회원은 별도 체인으로 본다.

`dormant_adult → voluntary_crossover_interest → crossover_session → standard_class_return → active_30d → renewal`

## 발견한 변화

### 1. BJJ 아카데미가 유도를 별도 수업으로 추가하는 사례

Ground Rules Academy는 2026년 9월 12일부터 기존 BJJ 중심 운영을 유지하면서 토요일 90분 유도 수업을 추가한다고 공개했다. 대상은 성인과 진지한 프리틴이며, 기존 BJJ 회원에게도 스탠딩·그립 파이팅·메치기와 지상 연결을 별도 가치로 제시한다.

파이널유도는 해당 클럽의 성과를 알 수 없으므로 `BJJ 회원은 유도에 잘 전환된다`고 해석하지 않는다. 다만 **인접 종목 회원에게 유도를 추가 기술경로로 판매하는 실제 최신 운영 사례**로 참고한다.

### 2. Judo·Wrestling·BJJ를 하나의 그래플링 가치로 묶는 상품

Let's Roll Academy의 2026년 9월 13~19일 포르투갈 캠프는 Wrestling, Judo, Jiu-Jitsu의 결합을 핵심 주제로 제시한다. 이것은 장기 회원권 모델과는 다른 캠프 사례지만, `종목명 하나`보다 `스탠딩-테이크다운-그라운드 연결 경험` 자체를 상품화할 수 있음을 보여준다.

### 3. 같은 시설에서 BJJ와 Judo Basic/All Level을 병렬 운영

Drive Asoke의 2026년 9월 공개 일정에는 BJJ All Level과 함께 Judo Basic, Judo All Level이 같은 시설 스케줄 안에 존재한다. 인접 종목을 완전 대체재로만 취급하지 않고 **같은 회원의 복수 수련 선택지**로 운영할 수 있다는 사례다.

### 4. 강서구 내 주짓수 대회가 9월 12일 열리는 지역 신호

강서구 소재 체육관 공개 게시물에는 `제2회 강서구주짓수회장배 주짓수 챔피언십`이 2026년 9월 12일 가양레포츠센터에서 열리며, 강서구체육회 주최·강서구주짓수회 주관으로 기재되어 있다. 이 자료는 공식 강서구체육회 페이지가 아니라 로컬 체육관 공개 게시물에서 확인한 것이므로 **지역 그래플링 활동의 존재 신호로만 사용**한다.

대회명·주최기관·로고를 파이널유도 홍보에 사용하거나 공식 연계·후원·제휴인 것처럼 표현하지 않는다.

## Acquisition Marketer — 신규 체험 캠페인

### Crossover Trial 후보

실제 여석·코치 가능시간이 확인될 때만 다음 중 하나를 파일럿으로 검토한다.

- `그래플러를 위한 유도 스탠딩 베이직`
- `그립·균형·메치기 입문`
- `스탠딩에서 그라운드까지 연결하는 유도 체험`

운영 내용은 실제 코칭 가능 범위로 제한한다. `BJJ 실력이 올라간다`, `테이크다운이 즉시 좋아진다`, `대회 성적이 향상된다` 같은 성과 보장 문구는 사용하지 않는다.

### 타겟 원칙

- 본인이 콘텐츠를 보고 자발적으로 신청하는 Self-Opt-In 방식 사용
- 경쟁 체육관 회원 명단 수집·DM 발송 금지
- 지역 대회 참가자 명단·연락처를 마케팅 데이터로 전용하지 않음
- 기존 유도 초보체험과 동일하게 안전정원·보험·복장·첫날 허용기술 확인 후 운영

## CRM Marketer — 대상별 후속 액션

1. **주짓수·레슬링 경험 신규체험자**: 첫 세션 후 `어떤 스탠딩 요소가 더 필요했는지`를 선택형으로 확인하고, 실제 가능한 다음 유도수업만 안내한다.
2. **체험 후 미등록자**: 종목 전환을 강요하지 않고 시간·난이도·비용·훈련목적 중 결정에 필요한 정보만 제공한다.
3. **휴면 성인 유도회원**: 과거 타 종목 관심이 내부에 명시적으로 기록된 경우에만 선택적으로 크로스오버 세션을 안내할 수 있다. 추정 세그먼트는 사용하지 않는다.
4. **기존 성인회원**: 신규 외부자 세션 때문에 기존 정규수업의 매트·코치 시간이 침해되지 않는지 별도로 관찰한다.

실제 고객 메시지 발송은 대표 승인 및 현재 연락 권한 확인 전에는 수행하지 않는다.

## Content Strategist — 채널별 기획

### 네이버

정보형 콘텐츠 후보:

- `주짓수·레슬링 수련자가 유도를 처음 배울 때 다른 점`
- `유도에서 그립과 균형을 어떻게 배우는가`
- `유도 체험 전에 알아둘 도복·낙법·메치기 기본`

경쟁종목을 낮춰 유도를 우월하게 보이게 하는 비교문구는 사용하지 않는다.

### 인스타그램

짧은 과정형 콘텐츠:

`그립 → 균형 무너뜨리기 → 안전한 메치기 드릴 → 착지 → 다음 동작`

실제 회원·외부 참가자를 촬영할 경우 별도 촬영·게시 동의를 전제로 한다.

### 당근

실제 여석과 일정을 확인한 뒤에만 지역·대상·시간을 명확히 한 `강서구 성인 그래플링 경험자 유도 체험` 형태를 검토한다.

오늘 열리는 지역 주짓수 대회 이름을 키워드 낚시로 사용하거나, 대회 직후 참가자를 특정해 광고한다고 표현하지 않는다.

## Experiment Manager

### EXP-213 Adjacent-Sport CTA vs Generic Adult Trial

- 가설: 그래플링 경험/관심을 자발적으로 표시한 성인에게 일반 `성인 유도 체험`보다 `스탠딩·그립·메치기` 중심 크로스오버 메시지가 실제 실방문을 늘릴 수 있다.
- 비교: 일반 성인 체험 CTA vs 크로스오버 CTA.
- 핵심 KPI: `self_opt_in → reservation → verified_attendance → visit_2 → paid_within_14d → active_30d`.
- 보조 KPI: 문의당 응답시간, 코치 추가시간, 기존수업 혼잡, 취소율.
- 성공 기준: 사전 정의한 최소 개선폭을 실방문·14일 등록·30일 활성 중 적어도 하단 퍼널에서 충족하고 기존수업 품질 악화가 없을 때 확대 검토.
- 중단 기준: 신청만 증가하고 실방문·등록이 개선되지 않거나, 안전정원·기존회원 만족·코치 집중도가 악화되면 중단.
- 기준선·최소개선폭·필요 표본: **데이터 미연결**.

### EXP-214 Crossover Clinic vs Direct Membership Ask

- 가설: 인접 종목 경험자에게 바로 회원권을 권하는 것보다 짧은 크로스오버 세션 후 정규 유도반을 안내하는 구조가 더 적합할 수 있다.
- 측정: `clinic_attended → standard_class_interest → visit_2 → paid_14d → active_30d → net_contribution`.
- 성공 기준: 등록뿐 아니라 30일 활성과 참가자당 순기여가 함께 개선될 때 유지.
- 중단 기준: 일회성 세미나 소비로 끝나거나 운영원가가 순기여를 초과하는 경우 확대하지 않음.
- 가격·세션 길이·정원·무료 여부: **데이터 미연결**.

## Auditor — 과장·브랜드·경쟁 리스크

- `주짓수에는 유도가 필수`, `유도를 배우면 테이크다운이 보장`, `대회 성적이 오른다` 같은 성과 보장 금지.
- 강서구 주짓수 대회와 공식 제휴·후원·협력 관계가 확인되지 않았으므로 로고·대회명·주최기관을 홍보 소재로 사용하지 않음.
- 경쟁 체육관 회원을 개인 단위로 식별하거나 공개 참가자 명단을 마케팅 명단으로 전용하지 않음.
- BJJ·레슬링을 열등한 종목처럼 표현하지 않고 `인접 종목 간 교차수련`으로 포지셔닝.
- 기존 유도회원의 매트시간과 코치 집중도가 우선이며 신규 외부자 유입 때문에 수업 품질을 훼손하지 않음.
- 해외 시설의 가격·무료체험·전환성과를 파이널유도 예상치로 복제하지 않음.

## 필요한 대표 승인·입력

- 성인반 중 외부 그래플링 경험자 체험을 수용할 수 있는 요일·시간·안전정원
- 크로스오버 체험에서 허용할 기술범위와 코치 담당 가능 여부
- 비회원 참가자의 보험·면책·복장·도복 정책
- 1회형 / 다회형 / 정규반 직접 연결 중 허용할 운영방식
- 체험비·세미나비·회원권 가격정책
- 휴면 성인회원에게 연락할 수 있는 현재 동의·권한 범위
- 기존회원 만족도와 수업 혼잡을 측정할 운영지표

비용 발생, 외부 참가자 모집, 제휴 요청, 고객 연락, 광고 집행, 가격 변경, 계정·운영DB 변경은 이번 문서 작성으로 승인된 것으로 보지 않는다.
