# Buddy Referral — Self-Opt-In 파일럿 v1

- 기준일: 2026-09-11
- 상태: 전략·실험 설계 완료 / 고객 발송·게시·비용집행 미실행
- 내부 회원수·매출·전환율: **데이터 미연결**

## 오늘의 판단

이번 최우선 과제는 **기존회원의 신뢰를 신규 체험으로 연결하되, 친구 연락처를 회원에게 받아 직접 마케팅하지 않는 `Self-Opt-In Buddy Referral` 구조를 검증하는 것**이다.

최근 무도시설 운영 사례에서는 9월에 Buddy Day/Week를 별도 모집 이벤트로 배치하는 흐름이 확인된다. YU Taekwondo Dubai는 2026-09-12 Buddy Day를, 오스트리아 YU Taekwondo는 2026-09-14~20 Buddy Week를 운영한다. 후자는 단순 동반이 아니라 추천받은 사람이 실제 신규회원으로 등록되어야 추천 보상 대상으로 인정한다. GIANT Martial Arts도 연간 캘린더에서 Buddy Week와 지역 축제 시연을 반복적으로 운영하고 있다.

파이널유도는 이 사례의 `친구 이름·전화번호를 기존회원이 적어 제출`하는 방식은 그대로 복제하지 않는다. 한국 개인정보 포털은 홍보·이벤트 안내 목적의 이름·휴대전화번호 처리 예시에서 정보주체의 동의와 거부권을 명시한다. 따라서 파일럿은 **기존회원에게 개인별 공유 링크/QR을 주고, 친구가 스스로 체험 신청과 연락 동의를 하는 구조**를 우선안으로 둔다.

## 발견한 변화

1. **획득:** 9월 무도시설 사례에서 `Open Day`와 `Buddy Week`가 별도 행동으로 운영되고 있다. YU Dubai는 9월 12일 Buddy Day와 9월 26일 Open Day를 따로 배치한다. 즉 기존회원 추천과 불특정 신규 체험을 같은 퍼널로 섞지 않는다.
2. **추천 품질:** 오스트리아 YU는 친구가 실제 회원으로 가입해야 추천 보상에 포함한다. QFit Gym은 2026년 추천 프로그램에서 추천받은 신규회원이 첫 달 이후 갱신한 뒤 기존회원 보상을 발생시키는 구조를 공개했다. 파이널유도에 동일 할인율을 적용할 근거는 없지만 `리드 발생 즉시 보상하지 않는다`는 설계는 허수 추천 억제 실험에 참고할 수 있다.
3. **사회적 운동:** ACSM 2026 Fitness Trends에서 Adult Recreation and Sport Clubs가 처음 Top 20에 진입했고, 재미·유연성·사회적 연결을 결합한 운동 참여를 성장 신호로 설명한다. 이는 파이널유도의 전환율 예측값이 아니라 Buddy형 체험을 시험할 외부 맥락이다.
4. **지역 경쟁:** 강서구공공체육시설은 2026년 9~11월 러닝·슬로우조깅·테니스·풋살·인라인 등 여러 생활체육 프로그램을 무료 또는 저비용으로 운영한다. 따라서 Buddy 파일럿은 가격 경쟁보다 `친구와 첫 방문 장벽을 낮추고 실제 유도 수업을 경험`시키는 가치에 초점을 둔다.

## 즉시 실행 3개

### 1. Buddy Pass 데이터 구조 설계

내부 운영시스템에 다음 최소 필드를 제안한다.

`referral_code / referrer_member_id / lead_self_opt_in_at / source_channel / desired_class / trial_reserved / trial_attended / first_paid_at / active_30d / reward_eligible`

공개 GitHub에는 실제 회원 ID·연락처·예약 ID를 저장하지 않는다. `lead_self_opt_in_at`이 없으면 CRM 마케팅 연락 대상으로 자동 등록하지 않는다.

### 2. 기존회원→친구 전달 구조를 `링크 공유`로 제한

권장 흐름:

`기존회원에게 Buddy 링크/QR 제공 → 기존회원은 링크만 친구에게 전달 → 친구가 직접 신청 → 개인정보 수집·연락 동의 → 수업 여석 확인 → 체험 예약 → 현장 출석 → 등록 → 30일 활성`

운영자가 기존회원에게 친구의 전화번호를 받아 먼저 연락하는 방식은 기본안에서 제외한다. 미성년자는 보호자 동의·연락 주체 확인을 별도 설계한다.

### 3. 채널 역할 분리

- 네이버: `친구와 유도 첫 체험을 하면 무엇을 하나요?` FAQ형 콘텐츠. 실제 체험비·시간·대여정책이 확인된 뒤 게시한다.
- Instagram: 기존회원+친구 2인이 따라할 수 있는 초보 드릴, 낙법·균형 미션, 첫날 분위기 중심. 촬영·초상권 동의 없는 회원 콘텐츠는 사용하지 않는다.
- 당근: 실제 승인된 날짜와 여석이 있을 때만 `강서구 친구동반 유도 체험` 소식형 게시를 검토한다. 당근 자체 데이터를 파이널유도 성과로 환산하지 않는다.

## 실험 1~3개

### EXP-184 Buddy vs Solo Trial

- 가설: 기존회원과 함께 방문하는 체험이 혼자 방문하는 체험보다 실제 참석·초기 활성에 유리할 수 있다.
- 핵심 KPI: 예약→현장확인 체험→유료등록→30일 활성.
- 비교: 동일 기간·유사 시간대의 Buddy 체험과 Solo 체험을 구분한다. 무작위 배정이 아니면 관찰 비교로만 해석한다.
- 성공 기준: 사전에 정한 최소 개선폭과 데이터 완결성 기준을 충족하면서 불편·과밀·안전 문제가 증가하지 않을 때 확대 검토.
- 중단 기준: 여석 초과, 동의 없는 연락, 기존회원 수업품질 저하, Buddy 체험의 하단 퍼널 개선이 없는데 운영부담만 증가할 때.

### EXP-185 Reward After Retention

- 가설: 추천 리드·체험 직후가 아니라 신규회원의 30일 활성 확인 뒤 보상하는 구조가 비용 누수와 허수 추천을 줄일 수 있다.
- KPI: 추천등록→30일 활성, 활성회원 1명당 추천비용, 추천자의 이후 재등록.
- 현재 보상금액·상품: **데이터 미연결 / 대표 승인 필요**.
- 중단 기준: 보상 비용이 늘지만 30일 활성 또는 추천량 개선이 확인되지 않을 때.

### EXP-186 Dormant + Buddy Return

- 가설: 휴면회원에게 `혼자 복귀` 외에 `친구와 함께 체험·복귀` 선택지를 주면 실제 재출석 장벽을 낮출 수 있다.
- KPI: 대상→자발적 응답→예약→현장 재출석→30일 활성.
- 중단 기준: 일반 복귀안내 대비 개선이 없거나 불필요한 외부인 유입으로 수업 운영이 악화될 때.

위 실험의 기준선·표본·성과 수치는 모두 **데이터 미연결**이다. 사전 기준 없이 몇 건의 사례만으로 승자를 선언하지 않는다.

## 필요한 대표 승인·입력

- 시간대별 안전정원과 Buddy 수용 가능 슬롯
- 최근 신규 체험의 예약·실방문·유료등록·30일 활성 집계
- 회원추천 유입경로를 현재 시스템에서 기록하는지 여부
- 휴면·만료예정자 연락 권한과 현재 CRM 정책
- Buddy 보상을 시험할 경우 보상 유형·비용 상한·회계 처리 기준
- 미성년 체험자의 보호자 동의 절차

실제 고객 메시지 발송, 링크 배포, 친구 연락처 수집, 무료체험 제공, 할인·상품 지급, 네이버·Instagram·당근 게시, 광고 집행은 대표의 별도 명시적 승인 없이 실행하지 않는다.

## KPI 상태

- 회원추천 신규문의: **데이터 미연결**
- Self-Opt-In 신청수: **데이터 미연결**
- Buddy 예약→실방문: **계산 불가**
- Buddy 체험→유료등록: **계산 불가**
- Buddy 신규회원→30일 활성: **계산 불가**
- 추천자의 재등록·만족 변화: **데이터 미연결**
- 휴면+Buddy 복귀율: **데이터 미연결**
- 추천 비용: **데이터 미연결**
- 추천 유입 매출: **데이터 미연결**

핵심 데이터 체인: `referrer → self_opt_in → reservation → attendance → paid → active_30d → renewal → referral_revenue`.

## Auditor

- YU의 전화번호 기반 Buddy Card는 해외 사례일 뿐이며 파이널유도 기본 설계로 복제하지 않는다.
- `친구와 오면 더 오래 다닌다`, `추천회원은 전환율이 높다` 같은 문구는 파이널유도 데이터가 연결되기 전에는 사실로 사용하지 않는다.
- 무료·할인·상품 보상은 비용·정책 승인 전에는 약속하지 않는다.
- 추천코드는 개인별 성과 추적용으로만 쓰고 공개 GitHub에 실제 회원 식별값을 남기지 않는다.
- 유소년 Buddy는 보호자 동의와 안전정원을 확인하기 전 예약 확정하지 않는다.
