# Youth Class-Fit Routing & Parent Decision Page v1

- 작성일: 2026-09-12
- 상태: 전략·계측 설계 완료 / 고객 메시지·광고·시간표 변경 전
- 목표: 유소년 신규문의의 반 선택 마찰을 줄이고 `문의 → 올바른 체험반 → 실제 방문 → 등록 → 30일 활성`을 분리 계측한다.
- 내부 회원수·매출·전환율·반별 정원: **데이터 미연결**

## 오늘의 판단

유소년 신규획득에서 `아이 유도 체험`이라는 하나의 CTA만 제공하기보다, 보호자가 자녀의 연령·학년·유도경험·가능시간을 기준으로 **어느 반이 맞는지 먼저 이해할 수 있게 하는 Class-Fit Routing**을 검증한다.

이 전략은 기존 `Fixed Beginner Intake Window`와 목적이 다르다. Fixed Beginner Intake Window가 **언제 시작하게 할지**를 다룬다면, 본 문서는 **어느 수업으로 보내야 하는지**를 다룬다. 또한 `Capacity-Aware Waitlist`가 만석 이후 대체시간·대기목록을 다룬다면 본 문서는 예약 전 올바른 클래스 선택을 다룬다.

핵심 퍼널은 다음과 같다.

`youth_inquiry → class_fit_view → recommended_slot → reservation → verified_attendance → paid_within_14d → active_30d → renewal`

성과 데이터가 연결되기 전에는 전환 개선을 추정하지 않는다.

## 발견한 변화

### 1. 2026년 9월 유도장들은 유소년 초보를 연령·수준·시간으로 세분화해 공개하고 있다

Mike's Judo Club의 2026년 9월 시간표는 `Beginners 6–10 years`, `Beginners 5–7 years`처럼 초보반을 연령으로 분리하고, 각 반에서 낙법·기본 메치기·간단한 굳히기·게임형 활동을 무엇을 배우는지 함께 설명한다. 단순히 `Kids Judo`라고만 표시하지 않는다.

출처: https://www.mikesjudoclub.co.uk/timetable

### 2. 학교 학년 기준 라우팅과 신규자 적합성 표시가 실제 운영되고 있다

St Albans Judo Club은 현재 Mini Judo, Dragons, Tigers, Wolves, Cranes를 **School Year Group** 기준으로 나누고, 일부 수업은 신규자에게 적합하지 않다고 명시한다. 2026년 9월 일부 유소년 그룹은 대기목록을 운영하고 있어 `연령/학년 적합성 + 신규자 적합성 + 수용능력`을 함께 보여주는 구조다.

출처: https://www.stalbansjudo.org.uk/

### 3. 짧은 유소년 입문과정도 대상 연령과 이후 정규반을 명확히 연결한다

SFD '75는 2026년 9월 10일부터 10–12세 어린이를 대상으로 6주 유도 워크숍을 운영하고, 워크숍 종료 후 이어지는 정규 훈련 요일·시간까지 공개한다. 가격·기간을 파이널유도에 복제하지 않고, **처음 체험하는 보호자에게 `대상 → 기간 → 수업시간 → 이후 경로`를 한 번에 보여주는 구조**만 참고한다.

출처: https://www.sfd.de/judo-workshop-fuer-kinder-ab-dem-10-september/

### 4. 강서구 공공 생활체육도 대상 학년·시간·정원을 구체적으로 공개한다

강서구공공체육시설의 2026년 여름방학 청소년 체육교실은 예를 들어 음악줄넘기를 `초등 1–4학년`, 시간 `13:00–14:00`, 모집인원 `20명`처럼 표시한다. 하반기 생활체육교실도 대상·요일·시간·장소·정원·준비물을 구체적으로 공개한다. 이는 파이널유도 전환성과의 증거는 아니지만, 지역 보호자가 생활체육 프로그램을 선택할 때 구체적인 Class-Fit 정보를 접하는 사용자 경험이 이미 존재한다는 참고 신호다.

## Growth Analyst — 퍼널과 필요한 데이터

내부 운영시스템에서 다음 집계를 연결한다. 개인 이름·보호자 연락처·학교명·건강정보는 공개 저장소에 저장하지 않는다.

| 단계 | 필요한 비식별 이벤트/집계 |
|---|---|
| 문의 | youth_inquiry, age_band 또는 school_grade_band, experience_level, preferred_time_band |
| 반 추천 | class_fit_viewed, recommended_class_id, recommendation_reason_code |
| 예약 | reservation_created, recommended_slot_accepted, alternate_slot_selected |
| 현장 | verified_attendance, misrouted_on_arrival, reassigned_class |
| 전환 | paid_within_14d, active_30d, renewal |
| 운영 | parent_repeat_question, coach_reassessment_minutes, capacity_exception |

현재 값은 모두 **데이터 미연결**이다.

`school_grade_band`는 학교명을 수집하는 필드가 아니다. 초등 저학년/고학년, 중등 등 반 배치에 필요한 최소 구간만 사용한다.

## Acquisition Marketer — 신규 체험 구조

유소년 랜딩 또는 상담 첫 화면에서 다음 네 가지 질문만으로 반 후보를 좁히는 구조를 우선 검토한다.

1. 연령 또는 학년 구간
2. 유도 경험: 처음 / 경험 있음
3. 가능한 요일·시간대
4. 체험 목적: 일반 수련 / 대회 관심 / 확인 필요

단, 위 질문만으로 자동 확정하지 않는다. 안전정원·반 수준·코치 판단이 필요한 경우 `REVIEW_NEEDED` 상태로 보낸다.

권장 상태값:

`FIT_AVAILABLE / FIT_ALT_SLOT / FIT_WAITLIST / REVIEW_NEEDED / NOT_CURRENTLY_OFFERED`

`NOT_CURRENTLY_OFFERED`를 억지로 다른 반에 배치하지 않는다.

## CRM Marketer — 보호자 후속 액션

예약 이후에는 새 메시지를 많이 추가하지 않고 기존 체험 사전안내와 연결한다.

- 올바른 반이 확인된 예약자: 확정 시간·도착정보·복장·첫 수업 흐름만 안내
- 희망시간이 맞지 않는 보호자: 실제 여석이 있는 대체반만 제안
- 대기 상태: 자발적 waitlist opt-in이 있는 경우에만 좌석 발생 시 안내
- 체험 후 미등록: 반 적합성·시간 적합성·난이도 중 무엇이 결정장벽이었는지 비식별 사유코드로 기록

실제 메시지 발송은 대표 승인 전 수행하지 않는다.

## Content Strategist — 채널별 기획

### 네이버

`우리 아이는 어떤 유도반에서 시작하나요?`를 핵심 FAQ로 두고 연령/학년, 초보 여부, 실제 가능한 시간, 첫 수업 내용을 한 페이지에서 보여준다.

### 인스타그램

`유치·초등 저학년 / 초등 고학년 / 중고등`을 단순 나이 광고가 아니라 실제 수업 장면의 차이, 지도방식, 첫날 흐름 중심으로 설명한다. 미성년자 얼굴·이름·학교가 노출되는 콘텐츠는 별도 동의 없이 사용하지 않는다.

### 당근

`초등 유도 체험`처럼 넓게 모집하기보다 실제 여석이 확인된 경우에만 `대상 구간 + 요일/시간 + 체험 가능 여부`를 명확히 표시한다. 가짜 희소성 문구는 금지한다.

## Experiment Manager

### EXP-223 — Class-Fit Page vs Generic Kids Trial CTA

**가설:** 일반적인 `유소년 체험 신청`보다 대상·시간·수업내용·신규자 적합성을 먼저 보여주는 페이지가 올바른 예약과 실제 방문에 도움이 될 수 있다.

- 주지표: `verified_attendance / 종료된 확정예약`
- 보조지표: recommended_slot_acceptance, misrouted_on_arrival, reassignment_rate, paid_within_14d, active_30d, parent_repeat_question
- 성공기준: 기존 기준선 대비 실방문·30일 활성 개선이 확인되고 오배치·반 재조정·반복문의가 악화되지 않을 것
- 중단기준: 자동 추천 오류, 안전정원 초과, 연령/수준 부적합 배치, 보호자 혼선 증가, 기존회원 수업품질 저하

기준선·최소 개선폭·필요 표본수는 **데이터 미연결**이다.

### EXP-224 — School-Grade Routing vs Age-Only Routing

**가설:** 파이널유도의 실제 반 편성이 학년/발달단계와 더 잘 맞는 경우, 단순 만 나이보다 학교 학년 구간을 함께 쓰는 것이 오배치를 줄일 수 있다.

실험 전제는 파이널유도의 실제 수업 편성 기준 확인이다. 내부 반 편성이 나이 기준이라면 이 실험은 실행하지 않는다.

- 주지표: misrouted_on_arrival, coach_reassessment_minutes
- 하단지표: verified_attendance, paid_within_14d, active_30d
- 중단기준: 학교급·학년 정보가 불필요하게 상세 수집되거나, 반 편성의 실제 기준과 불일치할 경우

## Auditor — 리스크 검토

- `몇 살이면 무조건 이 반`처럼 코치 판단을 배제하지 않는다.
- 학교명, 학급, 학생 이름 등 불필요한 미성년자 식별정보를 수집하지 않는다.
- `집중력 향상`, `성격 교정`, `학교폭력 예방`, `키 성장` 등 근거 없는 효과를 Class-Fit 설명에 결합하지 않는다.
- 외부 유도장의 무료체험·가격·도복 정책을 파이널유도의 정책처럼 표현하지 않는다.
- 실제 여석이 없는데 `체험 가능`, `마지막 자리`라고 표시하지 않는다.
- 동일 연령이라도 체격·경험·수업 적응도에 따라 코치 검토가 필요할 수 있으므로 자동배치 결과를 절대적 판정으로 사용하지 않는다.

## 필요한 대표 승인·입력

실제 적용 전 확인이 필요한 내부값은 다음과 같다.

- 본관 및 각 지점의 유소년 반 편성 기준: 연령 / 학년 / 띠·경험 / 혼합
- 각 반 실제 요일·시간·안전정원·체험 허용석
- 완전 초보를 받을 수 없는 반
- 체험 시 코치가 확인하는 최소 배치 기준
- 유소년 체험비·도복·보호자 참관·보험 정책
- 현재 신규문의→예약→실방문→등록→30일 활성 기준선

확인 전에는 모두 **데이터 미연결**이다.

## 결론

이번 전략은 유소년 광고를 더 많이 집행하는 계획이 아니다. **보호자가 `우리 아이가 어디서 시작하는지`를 정확히 이해하고, 실제로 맞는 반에 예약되도록 만드는 전환 품질 개선안**이다. 유입량보다 `올바른 반 선택 → 실제 방문 → 30일 활성`을 우선 지표로 둔다.
