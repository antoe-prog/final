# Women First-Step Judo Pilot v1

- 작성일: 2026-09-11
- 상태: 공개 조사 기반 제안 / 고객 모집·광고·가격변경 미실행
- 내부 회원수·매출·전환율: **데이터 미연결**

## 오늘의 판단

이번 우선순위는 **여성 초보 진입장벽을 별도로 검증하는 소규모 `Women First-Step Judo` 파일럿**이다. 기존 성인반을 대체하거나 상설 여성반을 바로 만드는 것이 아니라, 실제 여석이 있는 시간대에서 여성 초보자가 혼합반에 곧바로 들어가기 전에 `첫 1~2회 진입경험`을 다르게 설계할 가치가 있는지 확인한다.

직전 문서의 Capacity-First 원칙과 First Six Weeks Activation 구조를 유지한다. 즉 모집보다 먼저 안전정원·코치배치·체험허용석을 확인하고, 파일럿 이후에는 일반 성인반 또는 승인된 다음 단계로 자연스럽게 연결해야 한다.

## 발견한 변화

1. 국제유도연맹(IJF)은 2026-09-10, 이스탄불에서 15개국 35명 이상이 참여한 두 번째 `All Women Practical Session`을 공개했다. 기술교육뿐 아니라 여성 선수·코치·심판·리더가 겪는 기회와 장벽을 논의했다. 이는 여성 초보 수요의 크기를 증명하지 않지만, 유도 생태계에서 여성 참여환경과 지원을 별도 과제로 다루고 있다는 최신 공식 신호다.
2. Japan Arts Centre Police Sport UK Judo는 2026-09-14 시작하는 7~11세 여자 초보반을 별도로 운영하며, 균형·협응·체조 움직임·낙법·유도 드릴을 입문내용으로 제시한다. 이 사례의 무료기간·시간표를 파이널유도에 복제하지 않는다.
3. Nippon Judo Schools는 2026-10-31 여성 전용 체험 세션을 예고하고 있으며, 기존 여성 유도인뿐 아니라 `유도에 관심은 있지만 그 세션에서 메치기를 당하고 싶지 않은 여성`도 대상으로 명시한다. 재킷·띠 대여도 안내한다. 이는 일부 잠재고객에게 `첫날 무엇을 당하게 되는지`에 대한 불안이 메시지 설계 대상이 될 수 있음을 시사하지만, 파이널유도 고객에게 같은 불안이 존재한다고 단정하지 않는다.
4. 강서구공공체육시설은 현재 여성풋살·여성배구처럼 여성 전용 생활체육 프로그램을 실제 운영한다. 지역에서 성별 세분화 스포츠 프로그램이 운영되고 있다는 사실만 확인할 수 있으며, 여성 유도 수요를 증명하지는 않는다.
5. Aikido Shoshinkan은 2026-09-14 시작하는 5주 여성 초보과정을 `혼합수업이 부담스러운 초보자`를 포함한 대상으로 설명한다. 종목이 아이키도이므로 유도 성과근거로 사용하지 않고, 진입장벽 메시지 사례로만 참고한다.

## Growth Analyst — 퍼널과 필요한 데이터

핵심 퍼널은 다음과 같다.

`eligible_capacity → female_interest → self_opt_in → trial_reserved → verified_attendance → second_visit → paid → active_30d → renewal`

추가로 아래를 분리한다.

- 문의 시 가장 큰 우려: `UNKNOWN / 복장 / 체력 / 낙법 / 대련 / 접촉 / 혼합반 / 시간 / 비용 / 기타`
- 첫 체험 이후 다음 단계 선택: `일반 성인반 / 추가 입문회차 / 보류 / 중단`
- 코치 처리시간과 기존회원 수업 영향

현재 `여성 신규문의 비중`, `여성 체험→등록`, `여성 30일 활성`, `혼합반 진입 전 이탈`, `성인반 성비`, `시간대별 여석`은 모두 **데이터 미연결**이다.

## Acquisition Marketer — 파일럿 구조

상설반이 아니라 **2단계 진입경험**으로 설계한다.

### Step 1. First-Step Session
- 대상: 유도 경험이 없거나 장기 공백 후 다시 시작하는 성인 여성. 연령범위는 실제 운영정책 확인 후 확정.
- 내용 예시: 도장 이용방법, 낙법 기초, 이동·균형, 잡기 전 기본 움직임, 저강도 파트너 드릴.
- 실제 수업에서 하지 않는 내용을 광고에 약속하지 않는다.
- `대련 없음`, `메치기 없음`, `여성 코치 진행`, `도복 무료` 같은 표현은 실제 정책이 확인된 경우에만 사용한다.

### Step 2. Main-Class Bridge
첫 체험을 별도 이벤트로 끝내지 않고 실제 성인반 시간표·코치·수업구조를 보여주고, 참여자가 원하면 다음 회차를 선택하게 한다.

## CRM Marketer — 대상별 후속 액션

- **체험후미등록 여성:** 가격압박보다 `어떤 부분이 부담됐는지`를 선택형으로 확인한다. 실제 고객 메시지 발송은 승인 전 미실행.
- **휴면 여성회원:** 복귀 의향이 확인된 경우 `다시 시작하기 어려운 이유`를 확인하되 건강·가정사·체중을 추정하지 않는다.
- **만료예정 여성회원:** 실제 수업경험·목표·시간대 적합성을 점검한다. 여성 전용 파일럿 참여를 재등록 혜택처럼 자동 제안하지 않는다.
- **기존회원:** 여성 초보 파일럿이 일반반 운영에 미치는 혼잡·파트너 구성·수업품질 영향을 별도 확인한다.

## Content Strategist — 채널별 실행안

### 네이버
제목 후보: `성인 여성이 유도를 처음 시작할 때 가장 많이 궁금한 것`

본문은 `복장 / 낙법 / 체력 / 파트너 연습 / 첫날 진행 / 다음 단계`를 실제 운영정보 기준으로 설명한다. `여성에게 유도가 특히 안전하다`, `호신 효과가 보장된다` 같은 표현은 피한다.

### Instagram
`첫 10분 → 낙법 → 균형 → 초보 드릴 → 수업 후 다음 단계`의 과정형 리얼 콘텐츠를 제안한다. 촬영 동의 없는 회원은 등장시키지 않는다.

### 당근
실제 여석이 확인된 경우에만 `강서구 성인 여성 유도 첫걸음`처럼 지역·대상·날짜·시간을 명확히 제시한다. `마감임박`, `딱 N자리`는 실제 수용석과 예약현황이 확인된 때만 사용한다.

## Experiment Manager

### EXP-197 Women First-Step vs Standard Entry
- 가설: 여성 초보에게 별도의 첫 진입 세션을 제공하면 표준 성인반 직접 체험보다 `예약→실방문→2회차→30일 활성`의 마찰이 낮아질 수 있다.
- 비교: 같은 수용가능 시간대에서 표준 성인반 직접 체험과 First-Step 경로를 비교하되, 가격·필수 안전정보·등록조건은 동일하게 유지한다.
- 핵심 KPI: `예약→실방문`, `실방문→2회차`, `2회차→유료등록`, `등록→30일 활성`.
- 보조 KPI: 코치 처리시간, 기존회원 불편, 문의 중 우려유형, 안전사건.
- 성공 기준: 사전에 정한 최소 개선폭을 충족하면서 기존회원 수업품질과 코치부담이 허용범위 안에 있을 때만 확대 검토.
- 중단 기준: 안전정원 초과, 실제 수업과 다른 광고표현, 접촉·파트너 구성 관련 반복 불편, 코치업무 과부하, 하단 퍼널 개선 없이 문의만 증가하는 경우.
- 현재 기준선·최소개선폭·표본수: **데이터 미연결**.

### EXP-198 Barrier-Led FAQ
- 가설: 여성 초보 문의에서 실제 반복되는 우려를 FAQ에 반영하면 동일 질문 반복과 예약 전 이탈이 줄 수 있다.
- 데이터가 충분히 쌓이기 전에는 `여성은 혼합반을 싫어한다`, `호신이 주목적이다` 같은 가정을 콘텐츠에 사용하지 않는다.

## 필요한 대표 승인·입력

실제 파일럿 전 다음 내부값이 필요하다.

1. 성인 초보 수용 가능한 시간대와 안전정원
2. 현재 성인반의 여성 신규문의·체험·등록·30일 활성 비식별 집계
3. 여성 코치 또는 여성 파트너 배치가 실제 가능한지 여부
4. 도복 대여·체험비·복장·첫날 대련/메치기 정책
5. 미성년 여자 대상 파일럿을 별도 검토할 경우 보호자 동의·연령정책
6. 고객 연락·촬영·콘텐츠 공개 승인범위

이번 문서 작성으로 고객 메시지 발송, 할인·무료체험 확정, 공개 게시, 광고집행, 계정·운영DB 변경을 실행하지 않는다.

## Auditor

핵심 리스크는 `여성은 격투기를 무서워한다`, `유도는 호신에 반드시 효과적이다`, `여성 전용이 항상 더 좋다`와 같은 고정관념·과장이다. 최신 사례는 여성 전용 또는 여성 친화적 입문환경이 실제 운영되고 있음을 보여줄 뿐 파이널유도에서 같은 선호가 존재하거나 성과가 더 좋다는 증거가 아니다. 따라서 영구적인 여성반을 먼저 만들기보다 작은 opt-in 파일럿으로 검증한다.
