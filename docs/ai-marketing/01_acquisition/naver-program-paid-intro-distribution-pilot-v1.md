# Naver Program Paid Intro Distribution Pilot v1

- 상태: 설계 완료, 실제 상품 등록·가격설정·고객연락·광고집행 전
- 공개자료 확인일: 2026-09-12
- 목적: 신규 체험회원 확보 + 검색 노출 다변화 + 유료 입문상품의 실제 실방문·등록 전환 검증
- 적용 전제: 파이널유도멀티짐의 현재 네이버 예약/프로그램 사용 여부, 체험가격, 반별 체험정원, 전환율, 수수료 부담 허용선은 모두 `데이터 미연결`

## 1. 오늘의 판단

파이널유도멀티짐은 네이버 플레이스의 업체명 검색·일반 예약만으로 신규 유입을 관리하기보다, 네이버가 별도 검색 컬렉션으로 노출하는 `프로그램` 서비스를 신규 획득 채널 후보로 검증할 가치가 있다.

다만 기존 무료체험이나 기존 예약상품을 그대로 복제해 동시에 노출하는 방식은 공식 가이드상 허용되지 않는다. 따라서 실제 파일럿은 `기존 체험예약`과 다른 목적·내용을 가진 고정 날짜/회차형 유료 입문 클래스로 설계해야 한다.

이 전략은 기존 `Fixed Beginner Intake Window`와 다르다. 기존 문서는 초보자를 어떤 시작 시점에 받는지가 핵심이고, 이번 문서는 그 입문상품을 **네이버 검색의 프로그램 컬렉션이라는 별도 유통면에서 발견·결제·예약시키는 채널 실험**이다.

또한 기존 `Trial Pricing Free vs Paid-Credit`과도 다르다. 해당 문서는 첫 체험의 가격모델을 비교하는 전략이고, 이번 문서는 기존 체험과 겹치지 않는 **독립된 고정형 입문상품을 검색 상품으로 유통하는 것**이 핵심이다.

## 2. 최신 공개 변화와 근거

### A. 네이버 프로그램은 장소보다 `프로그램 자체`를 검색에 노출하는 별도 서비스

네이버 스마트플레이스 공식 안내에 따르면 프로그램 서비스는 체험·클래스·액티비티처럼 장소보다 프로그램 자체를 강조하고 싶은 사업자를 위한 서비스이며, 네이버 검색 결과의 `프로그램 컬렉션`에 별도로 노출될 수 있다.

- Source: https://help.naver.com/service/30026/contents/24221?lang=ko&osType=COMMONOS
- 확인일: 2026-09-12

### B. 유료·고정 일정·Npay 선결제가 전제

공식 안내상 사용 가능한 기본 유형은 날짜선택형 또는 회차형이며, Npay 선결제가 필요하다. 현재 판매수수료는 4%(부가세 별도)이고 Npay 수수료도 별도로 발생한다.

또한 동일한 내용의 예약상품과 프로그램상품을 동시에 등록할 수 없으므로, 파이널유도에서 프로그램을 시험하려면 기존 무료체험과 실질적으로 다른 상품이어야 한다.

- Source: https://help.naver.com/service/30026/contents/24224?lang=ko&osType=COMMONOS
- Source: https://new.smartplace.naver.com/notices/942

### C. 체험·클래스·액티비티 분야와 이용연령 정보를 등록할 수 있음

공식 고객센터는 체험·클래스·액티비티와 관련된 프로그램을 등록할 수 있고, 이용연령과 부가정보를 함께 설정하도록 안내한다. 다만 파이널유도멀티짐의 실제 업종·상품이 검수 대상 분야에 최종 승인되는지는 관리자 화면과 검수 결과 확인 전 확정하지 않는다.

## 3. 파이널유도 적용 후보

### 후보 상품 원칙

프로그램 상품은 기존 무료체험과 동일 내용으로 등록하지 않는다.

예시 구조:

- 상품명 후보: `성인 유도 첫걸음 클래스` 또는 `유도 안전입문 클래스`
- 유형: 회차형 또는 날짜선택형
- 대상: 대표 승인된 연령·세그먼트만
- 핵심 결과: 낙법, 기본 자세, 그립, 안전한 기초 기술 이해 등 실제 제공 가능한 범위만
- 일정: 실제 코치·매트·안전정원이 확정된 회차만
- 가격: `데이터 미연결` — 대표 승인 전 미정
- 정원: `데이터 미연결` — 반별 안전정원과 체험 허용석 확인 후 설정
- 기존 무료체험과의 차이: 독립된 커리큘럼·고정 회차·유료 참여·명확한 학습결과

### 금지

- 무료체험과 사실상 같은 상품을 프로그램에 중복 등록
- 실제 정원 확인 없이 `잔여 N석`, `마감임박` 사용
- 국가대표·공식기관과의 관계를 오인시키는 표현
- 검수 통과 전 `네이버 프로그램에서 예약 가능`이라고 외부 홍보
- 수수료를 무시하고 매출만 성과로 보고

## 5. 채널별 콘텐츠 기획

### 네이버

프로그램 상세는 `누구에게 / 무엇을 배우는지 / 실제 날짜·시간 / 준비물 / 참가비 / 환불기준`을 먼저 보여준다. 일반 플레이스 소개와 달리 프로그램 자체의 결과를 중심으로 작성한다.

### Instagram

고정 회차가 실제 승인된 경우 `첫걸음 클래스에서 배우는 3가지`처럼 교육형 콘텐츠를 만든다. 코치 자체 시연을 사용하고 방송영상·타 도장 이미지를 재사용하지 않는다.

### 당근

실제 프로그램이 승인·검수·판매 가능 상태가 된 뒤에만 지역형 게시 후보로 사용한다. `강서구 성인 유도 첫걸음 / 실제 날짜 / 실제 정원`처럼 구체적으로 제시하되 네이버 프로그램 구매를 강제하지 않고 파이널유도의 다른 합법적 문의 경로도 유지한다.

## 6. CRM 연결

- 프로그램 결제 후 미참석: 환불·노쇼 정책에 따라 처리, 별도 회원가입 압박 금지
- 프로그램 참석 후 등록 미완료: 자발적 후속 동의가 있는 경우에만 다음 정규반 안내
- 기존회원이 프로그램을 구매한 경우: 신규회원으로 집계하지 않음
- 휴면회원이 프로그램을 통해 재참여한 경우: `RETURNER`로 별도 집계
- 기존 무료체험 리드와 동일인이면 unique lead 기준으로 중복 제거

## 7. 실험

### EXP-254 Naver Program Discovery Pilot

**가설**  
기존 플레이스 업체검색·문의만으로는 포착하지 못하던 `클래스/체험 탐색 의도` 이용자에게 별도 프로그램 컬렉션 노출이 신규 실방문을 추가로 만들 수 있다.

**측정**
- program impression -> detail view
- detail view -> Npay purchase
- purchase -> verified attendance
- attendance -> membership inquiry
- attendance -> paid membership within 14d
- paid membership -> active 30d

**성공 기준**  
기준선, 최소 구매수, 허용 CAC, 허용 수수료율은 `데이터 미연결`. 실험 시작 전 대표 승인으로 확정한다.

**중단 기준**
- 검수 부적합 또는 업종 제한
- 기존 무료체험과 상품 중복 문제 발생
- 환불·노쇼·문의 대응 부담이 승인범위 초과
- 수수료 포함 순기여가 마이너스
- 프로그램 참석은 발생하지만 회원등록·30일 활성로 연결되지 않음

### EXP-255 Program-to-Membership Bridge

프로그램 참석자에게 즉시 할인 압박 대신 `정규반 적합시간 안내 + 다음 행동 선택`을 제공했을 때 14일 등록·30일 활성에 차이가 있는지 측정한다.

- control: 프로그램 종료 후 일반 안내
- test: 승인된 정규반 선택지와 명확한 다음 단계 제공
- 가격혜택은 별도 승인 없이는 제공하지 않는다.

- 네이버 프로그램 사용 가능 여부: **데이터 미연결**
- Npay 가맹 상태: **데이터 미연결**
- 프로그램 검색 노출수: **데이터 미연결**
- 상세조회수: **데이터 미연결**
- 구매전환율: **데이터 미연결**

- 참석→14일 회원등록률: **데이터 미연결**
- 등록→30일 활성률: **데이터 미연결**

- 귀속매출·순기여: **데이터 미연결**

## 10. Auditor

네이버 프로그램이 검색 노출면을 추가한다고 해서 신규회원 증가를 보장하는 것은 아니다. 또한 최신 해외 유도 워크숍이 유료로 운영된다는 사실은 파이널유도에 유료체험이 적합하다는 증거가 아니다.

따라서 실제 판단은 `노출 -> 구매 -> 실참석 -> 14일 등록 -> 30일 활성 -> 순기여`까지 연결된 데이터로만 한다.

특히 공식 가이드상 동일한 예약상품과 프로그램상품을 중복 등록할 수 없고, Npay와 판매수수료가 발생하므로 단순 노출 확대만 보고 도입해서는 안 된다. 검수·수수료·환불·정원·코치 운영 부담을 동시에 검증하는 것이 이 파일럿의 핵심이다.
