# 네이버 ADVoost 플레이스(Beta) 도입 적격성·예산·오프라인 전환 기준 v1

- 적용 조직: 파이널유도멀티짐 본관 및 운영이 확인된 지점
- 문서 상태: 공개 가능한 사전 검토·출시일 읽기 전용 확인 기준 / 광고 계정·예산·집행 변경 전
- 기준일: 2026-09-16
- 제품 적용 예정: 2026-09-16 오후, 네이버 공지상 일정 변경 가능
- 내부 광고비·문의·체험·등록·매출 데이터: **데이터 미연결**

## 1. 오늘의 판단

네이버가 2026년 9월 16일 오후 `ADVoost 플레이스(Beta)` 적용을 예고했지만, 파이널유도멀티짐은 즉시 활성화하지 않는다. 이 기능은 스마트플레이스 정보를 바탕으로 입찰·타겟팅·소재를 자동화하며 하루 예산이 전액 소진될 수 있다. 따라서 광고를 켜기 전에 **지점 정보, 자동 소재 원천, 체험 수용능력, 클릭 이후 문의·방문·등록·순수납 귀속**을 먼저 검증해야 한다.

핵심 의사결정 순서는 다음과 같다.

`지점 적격성 → 스마트플레이스 정보·이미지 검수 → 문의 경로 검증 → 체험 수용능력 → 예산·중단선 승인 → 단일 지점 파일럿 → 클릭 → 유효 문의 → 예약 → 실제 참석 → 등록 → 순수납`

클릭 최대화는 회원 확보 최대화가 아니다.

## 2. 네이버 공식 공지에서 확인한 변화

네이버 광고주센터는 2026년 9월 9일 공지를 게시하고 9월 11일 상품소개서 추가 내용을 갱신했다.

### 2.1 자동 운영 범위

ADVoost 플레이스는 다음을 자동 운영한다.

- 자동입찰: 하루 예산 안에서 클릭 수 최대화를 목표로 입찰가를 실시간 조정
- 자동 타겟팅: 별도 지역·성별·연령대·매체 설정 없이 적합한 지면과 사용자를 자동 판단
- 자동 소재 생성: 스마트플레이스의 업체 정보·이미지·혜택 정보를 사용해 소재 구성

### 2.2 광고주가 직접 통제하기 어려운 항목

- 자동입찰 광고그룹에서는 입찰가를 직접 설정할 수 없다.
- 지역·성별·연령대·매체 타겟팅을 직접 설정할 수 없다.
- 요일·시간대는 직접 설정할 수 있고 자동 타겟팅보다 우선한다.
- 자동 생성된 이미지와 홍보문구는 광고주센터에서 직접 수정할 수 없다.
- 스마트플레이스 정보가 바뀌면 광고 소재에도 자동 반영된다.

### 2.3 과금과 예산

- 과금 방식은 CPC다.
- 개별 플레이스 페이지 이동뿐 아니라 전화·예약·저장·길찾기·방문자 리뷰·플레이스 플러스 등 광고 요소 클릭도 과금 대상이라고 공지됐다.
- 설정한 하루 예산이 전액 소진될 수 있다.
- 자동입찰 광고그룹에는 캠페인의 하루 예산 균등 배분 옵션이 적용되지 않는다.

따라서 `과금 클릭`을 `문의`, `방문`, `체험`, `등록`으로 계산하지 않는다.

### 2.4 적용 방식

- 2026년 9월에는 광고주센터에서 먼저 이용할 수 있고 스마트플레이스센터 적용은 순차 준비 중이다.
- 신규 플레이스 광고그룹 생성 시 자동 운영이 기본 선택된다.
- 수동 운영을 원하면 수동 운영을 직접 선택해야 한다.
- 기존 광고그룹에는 자동 적용되지 않으며 직접 변경해야 한다.
- 광고 이용에는 스마트플레이스 업체 이미지가 1개 이상 필요하다고 공지됐다.

네이버의 2026년 9월 9일 공식 운영팁에서 추가로 확인한 범위는 다음과 같다.

- 별도 신규 광고상품이 아니라 기존 플레이스검색광고의 광고그룹별 자동 운영 방식이다.
- 기존 수동 광고그룹을 자동 운영으로 바꿔도 이전 입찰가·타겟팅 값은 저장되며, 다시 수동 운영으로 전환하면 이전 설정과 기존 소재가 복원된다고 안내한다.
- 스마트플레이스 이미지가 검색 상황에 따라 여러 장 조합될 수 있고, 광고주가 노출할 사진을 직접 지정할 수 없다고 안내한다.
- 이미지가 없으면 광고그룹 생성·저장이 되지 않는다고 설명한다.

이 안내는 운영 방식과 준비사항의 설명이며 파이널유도멀티짐 계정에서 기능이 실제 노출됐다는 증거는 아니다.

파이널유도멀티짐의 실제 계정 노출 여부, 업종 적격성, 각 지점의 광고 가능 상태는 **데이터 미연결**이다.

### 2.5 출시일 읽기 전용 확인 기준

2026년 9월 16일 오후 적용 예정이라는 공지만으로 출시 완료를 선언하지 않는다. 확인 시각이 예정 시각보다 이르면 `NOT_DUE`, 예정 시각 이후라도 실제 계정 화면을 확인하지 못하면 `ROLLOUT_UNVERIFIED`로 둔다.

출시 여부의 증거 우선순위는 다음과 같다.

1. 네이버 공식 공지의 적용일·수정일·일정 변경 문구
2. 권한이 확인된 광고주센터에서 기존 광고그룹의 운영 방식 메뉴가 보이는지
3. 새 광고그룹 화면에서 자동 운영 기본 선택과 수동 운영 선택지가 보이는지
4. 저장하지 않은 상태에서 표시되는 이미지·예산·요일·시간대 요구사항

읽기 전용 확인 중에는 다음 행동을 하지 않는다.

- 광고그룹 생성·저장
- 기존 광고그룹의 자동·수동 운영 전환
- 하루 예산·요일·시간대 변경
- 스마트플레이스 이미지·업체 소개·혜택 수정
- 결제수단·비즈머니·자동충전 변경
- 테스트 목적의 광고 제출·노출

메뉴 확인을 위해 반드시 생성·저장이 필요하다면 그 단계에서 중단하고 대표 승인을 요청한다. 마케팅 페이지 노출이나 공식 운영팁 게시만으로 실제 계정 이용 가능 상태를 확정하지 않는다.

## 3. 기존 기준과의 경계

- `local-discovery-profile-truth-standard-v1.md`: 공개 지점 정보와 문의 진입점의 정합성
- `multi-location-public-information-source-of-truth-and-inquiry-routing-standard-v1.md`: 다지점 기준정보와 문의 인계
- `capacity-aware-trial-acquisition-and-waitlist-standard-v1.md`: 수업별 체험 좌석과 대기명단
- 이 문서: 자동입찰·자동타겟팅·자동소재를 사용하는 유료 플레이스광고의 도입·예산·귀속·중단 기준

기존 문서의 `LIVE_VERIFIED`, `SESSION_OPEN_VERIFIED`, `TRIAL_ATTENDED`, `NET_COLLECTION_VERIFIED` 상태가 연결되지 않으면 유료 집행을 보류한다.

## 4. CMO — 도입 우선순위

1. 출시 직후 사용 가능 여부를 확인하되 광고그룹을 만들거나 운영 방식을 변경하지 않는다.
2. 스마트플레이스에 등록된 정보와 이미지가 자동 광고 소재로 사용돼도 되는지 먼저 검수한다.
3. 여러 지점을 동시에 집행하지 않고 대표가 승인한 한 지점에서만 검증한다.
4. 클릭보다 실제 참석·등록·순수납을 성공 기준으로 둔다.
5. 기존회원 수업 품질과 체험 수용능력을 침해하는 지점은 광고 확대 대상에서 제외한다.
6. 사전에 예산 상한·중단 조건·관찰기간을 승인하지 않으면 집행하지 않는다.

## 5. 도입 적격성 게이트

아래 항목을 모두 충족해야 `READY_FOR_OWNER_APPROVAL` 상태가 된다.

### 5.1 지점·계정

- 실제 운영 중인 지점이다.
- 광고할 플레이스와 실제 지점이 일치한다.
- 광고 계정과 플레이스 권한의 소유·위임 관계가 확인됐다.
- 다른 지점의 전화·예약 URL·이미지가 섞이지 않았다.

### 5.2 스마트플레이스 기준정보

- 공개 상호·주소·지도 핀이 현장과 일치한다.
- 영업시간과 수업시간표가 구분돼 있다.
- 휴무·임시변경·공휴일 정보가 최신이다.
- 전화·예약·문의 경로가 실제 담당에게 도착한다.
- 미확정 가격·무료 체험·혜택·이벤트가 없다.

### 5.3 이미지·문구 원천

- 업체 이미지가 최소 1개 존재한다.
- 각 이미지의 촬영·사용 권리와 회원 공개 동의가 확인됐다.
- 코치 개인 계정의 자산을 공식 지점 광고 자산으로 자동 재사용하지 않는다.
- 회원·미성년자 식별정보, 학교명, 건강정보가 노출되지 않는다.
- 이미지가 해당 지점·시설·수업을 실제로 보여주는지 확인됐다.
- 자동 홍보문구의 근거가 되는 혜택 정보가 승인·유효 상태다.

### 5.4 수용능력

- 광고 시간대에 체험 가능한 수업이 확인됐다.
- 수업별 지도자·정원·기존회원 예약·체험 좌석이 검증됐다.
- 만석·휴강·행사·대관 수업이 광고 대상에서 제외됐다.
- 문의 증가 시 응대·예약·재예약을 처리할 담당이 지정됐다.

### 5.5 측정과 예산

- 지점·캠페인·광고그룹 식별자가 있다.
- 과금 클릭과 실제 문의를 분리할 수 있다.
- 문의→예약→참석→등록→순수납 연결 원천이 지정됐다.
- 일 예산, 총 집행 상한, 관찰기간, 중단 권한이 사전 승인됐다.
- 환불·취소·차지백과 광고비를 반영한 순기여 계산 원칙이 있다.

하나라도 미확인이면 `NOT_READY` 또는 `DATA_UNCONNECTED`다.

## 6. 상태값

| 상태 | 의미 | 광고 실행 |
|---|---|---|
| NOT_DUE | 공식 적용 예정 시각 전 | 금지 |
| DISCOVERED | 공식 공지만 확인 | 금지 |
| ROLLOUT_UNVERIFIED | 예정 시각 이후지만 실제 계정 화면 미확인 | 금지 |
| UI_AVAILABLE_READONLY_VERIFIED | 권한이 확인된 계정에서 메뉴만 읽기 전용 확인 | 금지 |
| ACCOUNT_UNVERIFIED | 계정·플레이스 접근 미확인 | 금지 |
| PROFILE_REVIEW | 스마트플레이스 정보·이미지 검수 중 | 금지 |
| CAPACITY_UNVERIFIED | 체험 수용능력 미확인 | 금지 |
| MEASUREMENT_UNREADY | 클릭 이후 퍼널 원천 미연결 | 금지 |
| READY_FOR_OWNER_APPROVAL | 게이트 통과, 예산 승인 대기 | 금지 |
| APPROVED_NOT_LIVE | 대표 승인 완료, 아직 미집행 | 금지 |
| LIVE_PILOT | 승인된 단일 지점 파일럿 실행 중 | 승인 범위 내 |
| PAUSED | 예산·품질·수용능력·측정 문제로 중지 | 금지 |
| COMPLETED_AWAITING_MATURITY | 집행 종료, 전환 관찰 중 | 신규 집행 금지 |
| EVALUATED | 성숙 코호트 판정 완료 | 다음 결정 가능 |

공지 확인만으로 `READY_FOR_OWNER_APPROVAL` 또는 `LIVE_PILOT`로 올리지 않는다.

## 7. Growth Analyst — 데이터 사전 정의

### 7.1 플랫폼 데이터

- `branch_code`
- `campaign_id`
- `ad_group_id`
- `operation_mode`: AUTO / MANUAL
- `daily_budget`
- `approved_total_spend_cap`
- `started_at`, `ended_at`
- `spend`
- `charged_clicks`
- `click_type`: 제공 가능할 때 page / phone / booking / save / directions / review / other
- `impressions`: 플랫폼이 제공하고 정의가 확인될 때만

### 7.2 하단 퍼널 데이터

- `inquiry_received`
- `inquiry_validated`
- `trial_booking_confirmed`
- `trial_attended_verified`
- `membership_started`
- `net_collection_verified`
- `refund`, `cancellation`, `chargeback`
- `direct_campaign_cost`

개인정보가 아닌 캠페인·지점 식별자로 연결한다. 출처를 확인할 수 없는 문의는 `UNKNOWN`으로 남긴다.

### 7.3 시간 성숙도

- 클릭과 문의의 귀속 창
- 체험 예약과 실제 참석의 관찰기간
- 참석 후 등록 판정기간
- 환불·차지백 반영기간

이 네 기간은 내부 데이터와 계약 기준 없이 임의 설정하지 않는다. 관찰기간이 끝나지 않은 코호트를 실패로 판정하지 않는다.

## 8. Acquisition Marketer — 파일럿안

### 8.1 대상

- 대표가 승인한 실제 지점 1곳
- `LIVE_VERIFIED` 공개정보와 `SESSION_OPEN_VERIFIED` 체험 수업이 있는 기간
- 미확정 행사·가격·혜택 없이 상시 정보만 사용

### 8.2 사전 대조

1. 현재 스마트플레이스 화면을 캡처한다.
2. 자동 소재 후보가 될 이미지·업체정보·혜택을 목록화한다.
3. 전화·예약·길찾기 도착점을 테스트 레코드로 확인한다.
4. 광고 시간대와 실제 문의 응대·체험 가능 시간대를 맞춘다.
5. 대표가 일 예산·총상한·중단 조건을 승인한다.
6. 광고가 공개되면 일반 방문자 화면에서 실제 소재와 지점을 확인한다.

### 8.3 비교 설계

## 11. KPI 정의

분자·분모·기간·원천·지점을 함께 표시한다.

### 11.1 플랫폼 효율

- CPC = 광고비 / 과금 클릭
- 과금 클릭 구성 = 클릭 유형별 수 / 전체 과금 클릭

클릭 유형별 데이터가 제공되지 않으면 구성비를 계산하지 않는다.

### 11.2 퍼널 효율

- 클릭→유효 문의율 = 유효 문의 / 과금 클릭
- 유효 문의→예약률 = 확정 예약 / 유효 문의
- 예약→참석률 = 실제 참석 / 판정 완료 예약
- 참석→등록률 = 성숙한 등록 / 성숙한 실제 참석

### 11.3 비용·수익

- 유효 문의당 비용 = 광고비 / 유효 문의
- 실제 참석당 비용 = 광고비 / 실제 참석
- 검증 신규등록당 비용 = 광고비 / 검증 신규등록
- 순수납 = 수납 - 환불 - 취소 - 차지백
- 캠페인 기여 = 귀속 순수납 - 광고비 - 승인된 직접비

분모가 0이거나 귀속·관찰기간이 미확정이면 계산하지 않는다. 순수납이 확인되기 전 광고수익률을 보고하지 않는다.

### 11.4 기존회원 보호

- 광고 유입으로 인한 정원 초과 건수
- 기존회원 예약 침해 건수
- 문의 응답 지연 건수
- 도장 사정 체험 취소 건수
- 기존회원 만족·재등록 변화

마지막 지표들은 현재 **데이터 미연결**이며 광고 인과로 단정하지 않는다.
