# 체험·첫 방문 온보딩·후속·등록·매출 귀속 기준 v1

- 작성일: 2026-09-19
- 적용 대상: 파이널유도멀티짐의 신규 문의, 체험 신청, 첫 방문, 체험 수련, 체험후미등록 후속, 신규 등록
- 문서 성격: 공개 가능한 운영 설계안. 실제 가격·시간표·지점·정원·혜택·연락처·회원 데이터가 연결됐다는 뜻이 아니다.
- 현재 상태: 기준안 완성 / 실제 시스템 적용 전 / 대표 승인 및 데이터 연결 필요

## 1. 목적

신규 체험 퍼널에서 다음 항목을 서로 다른 사건으로 기록한다.

1. 문의
2. 체험 자격 확인
3. 체험 제안과 수락
4. 예약 요청과 예약 확정
5. 방문 전 안내 발송과 전달
6. 도착과 체크인
7. 오리엔테이션 시작과 완료
8. 실제 체험 참여
9. 체험 후 사람 응답
10. 등록 의사
11. 상품 선택
12. 결제 승인과 실수납
13. 회원권 활성화
14. 환불·차지백

폼 제출, 예약, 체크인, 오리엔테이션 완료, 등록 의사 또는 결제 승인만으로 신규 등록·매출을 확정하지 않는다.

## 2. 핵심 원칙

### 2.1 체험회원과 정회원을 분리한다

- 체험 신청자를 즉시 정회원으로 집계하지 않는다.
- 체험 이용권 부여와 정규 회원권 활성화를 별도 상태로 기록한다.
- 기존회원이 체험 상품을 다시 선택할 수 있는지는 운영 정책으로 통제한다.
- 체험 종료 후 정규 회원권으로 자동 전환되는 구조는 가격·기간·해지·환불 조건이 승인되고 고객에게 명확히 고지된 경우에만 검토한다.

### 2.2 행정 사건과 실제 참여를 분리한다

- 예약 확정은 참석이 아니다.
- 입장 또는 체크인은 수련 완료가 아니다.
- 동의서 작성은 오리엔테이션 완료가 아니다.
- 오리엔테이션 완료는 체험 수련 완료가 아니다.
- 체험 수련 완료는 신규 등록이 아니다.

### 2.3 지원을 판매보다 먼저 둔다

첫 방문에서는 다음을 우선한다.

- 실제 방문 장소와 도착 방법 확인
- 담당 코치 또는 직원 확인
- 공간·수업 진행·기본 예절·안전 안내
- 처음 참여자가 질문할 수 있는 방법 안내
- 수업 후 불편·궁금증 확인

검증되지 않은 효과, 즉시 등록 압박, 허위 마감, 미승인 할인·무료 체험·혜택을 사용하지 않는다.

## 4. 방문 전 안내 최소 항목

실제 발송 전 다음 정보가 승인돼 있어야 한다.

- 공식 지점명과 정확한 지도 목적지
- 건물·출입구·층 등 필요한 도착 정보
- 확정된 날짜·시각·수업
- 권장 도착 시각
- 승인된 복장·준비물 안내
- 예약 변경·취소 방법
- 승인된 비용·환불·노쇼 조건
- 문의 가능한 공식 채널
- 미성년자라면 보호자·참여자 관계와 필요한 동의

모르는 값은 추정하지 않고 `확인 필요`로 남긴다. 모든 지점에 같은 출입구·시간표·가격·정원·준비물을 복제하지 않는다.

## 5. 첫 방문 오리엔테이션 체크리스트

### 5.1 시작 전

- 예약 대상과 실제 참여자 확인
- 보호자·결제자·참여자를 혼동하지 않음
- 담당 코치 또는 직원 지정
- 체험이 가능한 수업과 정원 재확인
- 공개·촬영·후기 활용 동의와 수련 참여 동의를 분리

### 5.2 현장 안내

- 공간과 이동 동선
- 탈의·개인 소지품 관련 실제 운영 안내
- 수업의 대략적인 흐름
- 기본 예절과 질문 방법
- 안전상 멈춤·휴식·도움 요청 방법
- 장비·도복 사용 조건

### 5.3 수업 후

- 실제 참여 여부를 코치가 확인
- 불편·궁금증·추가 설명 필요 여부 기록
- 등록 압박 없이 다음 단계 선택지를 안내
- 건강정보·부상·민감정보는 필요한 최소 범위와 권한 안에서 별도 처리

## 6. 체험후미등록 후속 기준

### 6.1 발송 자격

다음을 모두 통과해야 후속 후보가 된다.

1. 실제 체험 참여 또는 적법한 후속 목적이 확인됨
2. 채널·목적별 연락 근거가 확인됨
3. 수신거부·억제 대상이 아님
4. 승인된 빈도와 냉각기간 안에 있음
5. 야간 발송 기준을 충족함
6. 보호자·미성년자·가구 중복을 확인함
7. 담당자가 사실과 문구를 검토함

### 6.2 후속 내용

- 방문과 참여에 대한 짧은 감사
- 궁금했던 점 또는 불편했던 점을 묻는 한 가지 질문
- 답변 가능한 사람 또는 공식 문의 경로
- 승인된 경우에만 다음 수업·등록 절차 안내
- 가격·혜택·마감은 승인된 사실만 사용

### 6.3 금지

- 무응답을 동의 또는 관심 지속으로 해석
- 읽음을 사람 응답으로 집계
- 문자 거부 후 DM·전화로 자동 전환
- 근거 없는 `오늘만`, `마감 임박`, `무료`, `효과 보장`
- 체험 중 관찰한 신체·건강정보를 판매 문구에 사용
- 개인별 경험을 공개 후기나 콘텐츠로 전환

## 7. 등록·매출 귀속 기준

### 7.1 신규 등록 완료

다음을 모두 충족할 때만 신규 등록 완료로 집계한다.

- 신규등록 자격 확인
- 승인된 회원권 선택
- 결제 및 계약 조건 확인
- 기준 원장의 실수납 확인
- 새 이용기간·권한 활성화

결제 실패·보류·승인 취소·환불·차지백은 별도 상태로 남긴다.

### 7.2 채널 귀속

다음 식별자를 분리한다.

- 최초 유입 채널과 콘텐츠
- 유효 문의 채널
- 체험 예약 채널
- 후속 연락 채널
- 최종 등록 담당자와 지점
- 결제·수납 원장

한 사람·가구·결제에 여러 지점·채널·캠페인이 연결돼도 신규 등록과 순수납은 한 번만 집계한다. 최초 접점과 최종 전환 접점을 동시에 보되, 각 값을 합산해 두 건으로 만들지 않는다.

### 7.3 순수납

`순수납 = 확인된 실수납 - 완료된 환불 - 완료된 차지백`

세금·수수료·내부 회계 기준은 대표와 회계 기준 원장이 확정해야 한다. 데이터가 연결되지 않으면 계산하지 않는다.

## 8. 다지점·가구·미성년자 예외

- `person_id`, `household_id`, `guardian_id`, `payer_id`, `location_id`를 구분한다.
- 보호자의 문의를 미성년 참여자의 사람 응답과 합치지 않는다.
- 같은 사람이 다른 지점을 문의했다고 신규 리드 두 명으로 만들지 않는다.
- 지점 이동을 신규 등록으로 집계하지 않는다.
- 보호자 결제를 참여자 두 명의 매출로 중복 귀속하지 않는다.
- 미성년자 촬영·후기·건강정보는 별도의 동의와 공개 범위를 확인한다.

- 채팅 시작을 유효 문의·예약·실참여로 자동 승격하지 않음

## 11. EXP-411 — 체험 온보딩·실참여·등록·순수납 귀속 정확도

### 목적

체험 신청부터 신규 등록까지 행정 사건과 실제 행동이 섞이지 않는지 검증한다.

### 합성 검증 세트

- 사람·가구·보호자·결제자 관계 480건
- 문의·체험·예약·도착·체크인·수련 사건 1,920건

## 14. 근거와 한계

- Gymdesk는 체험 이용자를 `Visitors`로 표시하고, 체험 이용권의 기간·가격·예약 가능 여부·훈련 접근·정원을 별도 설정할 수 있다고 설명한다. 이는 파이널유도에 해당 기능이 연결돼 있다는 뜻이 아니다.
- Gymdesk의 출석 문서는 회원과 방문자의 체크인이 하나의 출석 로그로 들어갈 수 있음을 보여준다. 따라서 체크인 원장만으로 체험 수련 완료를 확정하지 않는다.
- GymMaster는 첫 주 환영·오리엔테이션, 첫 예약, 첫 세션 후 확인을 온보딩 단계로 제안한다. 외부 사업자의 성과 수치와 자동화 권고를 파이널유도의 성과 근거로 사용하지 않는다.
- 개인정보, 광고성 연락, 환불·계약은 실제 운영 사실과 최신 국내 법령·분쟁해결기준을 별도로 검토해야 한다.
