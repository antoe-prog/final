# 당근 ‘브랜드 지점 방문 늘리기’ 도입 적격성·지점 연결·오프라인 전환 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 작성·검토일: 2026-09-15
- 적용 범위: 다지점 체육시설의 당근 브랜드프로필·비즈프로필·전문가모드 광고
- 관련 목표: 신규 체험 확보, 휴면 복귀, 기존회원 재등록·만족, 검증 순수납
- 제외: 실제 지점명·주소·계정 ID·예산·회원정보·개별 문의·승인 대기 콘텐츠·미확정 행사·가격·혜택

## 1. 오늘의 운영 판단

당근의 신규 광고 목표를 바로 집행하는 것보다 다음 세 가지를 먼저 확인해야 한다.

1. 공식 요건을 충족하는 실제 운영 지점이 충분한가
2. 본사 브랜드프로필과 각 지점 비즈프로필이 정확히 연결되어 있는가
3. 광고 클릭 이후 문의·체험·등록·순수납을 지점별로 구분할 수 있는가

플랫폼 명칭이 ‘지점 방문 늘리기’여도 광고 노출·클릭·프로필 도착만으로 실제 방문을 증명할 수는 없다.

## 2. 2026-09-15에 확인한 공식 기능

당근비즈니스가 2026-09-03 공개한 안내에서 확인한 내용은 다음과 같다.

- 당근 홈 피드에 노출되는 네이티브 광고의 신규 목표다.
- 최소 10개 이상의 지점을 보유한 프랜차이즈·다점포 브랜드를 위해 설계됐다고 안내한다.
- 본사 계정의 하나의 캠페인으로 여러 지점을 운영할 수 있다.
- 이용자 위치를 기준으로 방문 가능한 인근 지점에 연결한다.
- 행정구역뿐 아니라 도보 시간·차도 거리를 기준으로 지역 범위를 설정할 수 있다.
- 본사 브랜드프로필의 공통 소식을 연결된 지점에 함께 배포·수정할 수 있다.
- 전체 지점 또는 특정 지점에 예산·입찰가를 적용할 수 있다고 안내한다.
- 랜딩은 인근 지점의 브랜드 소식 또는 비즈프로필 홈으로 설계할 수 있다.

공식 페이지의 도보 20분·차도 3km는 기능 설명 예시다. 이를 파이널유도멀티짐의 권장 반경으로 사용하지 않는다.

## 3. 공식 안내만으로 확인되지 않는 것

아래 항목은 별도 원천 확인 전 모두 `데이터 미연결`이다.

- 실제 운영 지점 수
- 광고 상품의 현재 계정별 이용 자격
- 본사 브랜드프로필과 지점 비즈프로필의 연결 상태
- 각 지점의 공개정보 정확도
- 지점별 체험 가능 좌석
- 광고비·입찰가·과금 방식의 실제 계정 조건
- 광고 클릭·프로필 행동·채팅·전화 수
- 유효 문의·체험 예약·실제 참석
- 신규 등록·휴면 복귀·재등록
- 환불·차지백 반영 순수납
- 캠페인의 증분 기여

별도 내부 행사안이나 계획상 지점 수는 실제 운영 지점·플랫폼 적격 프로필의 증거가 아니다.

## 4. 기존 기준과의 경계

이 문서는 신규 광고 목표에 필요한 도입 판단만 다룬다.

- 지점명·주소·지도 핀·전화·운영시간의 원본은 `다지점 공개정보 원본·정합성·문의 귀속 기준`을 따른다.
- 체험 좌석과 대기 전환은 `수용능력 연동 체험 유입·대기열 기준`을 따른다.
- 문의·예약·참석·계약·순수납은 각각 별도 사건으로 유지한다.
- 미확정 가격·혜택·행사와 공개 동의 없는 회원 이미지는 소재에서 제외한다.

## 5. 도입 적격성 게이트

다음 항목을 모두 통과하기 전 광고 계정 생성·설정·집행을 보류한다.

### G1. 브랜드·지점 자격

- [ ] 실제 운영이 확인된 지점을 기준으로 공식 최소 지점 요건을 재확인했다.
- [ ] 각 지점의 운영 상태를 `ACTIVE_VERIFIED`로 확인했다.
- [ ] 동일 장소의 중복 프로필을 지점 수에 포함하지 않았다.
- [ ] 이전 예정·임시휴관·폐점 지점을 활성 지점으로 계산하지 않았다.
- [ ] 당근 담당 안내 또는 계정 화면에서 실제 상품 이용 가능 여부를 확인했다.

### G2. 계정·프로필 연결

- [ ] 본사 광고 계정과 브랜드프로필의 소유·관리 권한을 확인했다.
- [ ] 광고 대상 지점의 비즈프로필이 올바른 브랜드에 연결돼 있다.
- [ ] 지점별 공개명·주소·지도·운영시간·문의 경로가 실제와 일치한다.
- [ ] 공통 소식을 자동 배포할 지점 범위를 승인했다.
- [ ] 연결 오류 시 캠페인을 멈출 담당 역할을 정했다.

### G3. 지역 연결 정확성

- [ ] 이용자가 연결될 지점과 실제 방문 가능한 출입구를 대조했다.
- [ ] 지형·교통·생활권을 반영한 반경 근거를 정했다.
- [ ] 도보 시간과 차도 거리 중 무엇을 사용할지 승인했다.
- [ ] 본사 전체에 같은 반경을 일괄 적용할지 지점별로 다르게 설정할지 결정했다.
- [ ] 서로 가까운 지점의 중복 노출·오귀속 처리 규칙을 정했다.

### G4. 문의·체험 수용능력

- [ ] 지점별 문의 도착 경로와 응대 담당을 확인했다.
- [ ] 광고 대상 기간의 체험 가능 회차·좌석을 확인했다.
- [ ] 만석·휴강·응대 불가 시간의 제외 규칙을 정했다.
- [ ] 중앙 문의에서 지점으로 넘기는 인계 상태를 기록할 수 있다.
- [ ] 광고 클릭을 예약이나 참석으로 자동 변환하지 않는다.

### G5. 소재·사실·권리

- [ ] 브랜드 소식 또는 프로필 홈 중 랜딩 목적을 하나 선택했다.
- [ ] 공통 문구가 연결된 모든 지점에서 사실인지 확인했다.
- [ ] 지점별 시간표·가격·혜택을 본사 공통값으로 만들지 않았다.
- [ ] 촬영물의 공개 사용 권리와 회원 동의를 확인했다.
- [ ] 코치 개인 계정 콘텐츠를 브랜드 공식 발표물처럼 재사용하지 않았다.

### G6. 비용·중단 권한

- [ ] 대표가 일 예산·총상한·기간·입찰 범위를 승인했다.
- [ ] 전체 일괄값과 지점별 개별값의 우선순위를 정했다.
- [ ] 광고비 원천과 실제 청구·소진값을 대조할 수 있다.
- [ ] 정원 초과·오정보·문의 장애 시 즉시 중단할 역할이 있다.
- [ ] 플랫폼 프로모션을 무료 집행이나 수익성 증거로 해석하지 않는다.

## 6. 랜딩 선택 기준

### 6.1 브랜드 소식 랜딩

적합한 경우:

- 모든 대상 지점에서 같은 사실이 유효하다.
- 시작일·종료일·대상·제외 지점이 확정됐다.
- 가격·혜택·참가 조건이 대표 승인과 공개 원천에 일치한다.
- 소식에서 인근 지점의 정확한 정보로 이어진다.

보류하는 경우:

- 일부 지점만 참여한다.
- 시간표·가격·혜택이 지점별로 다르다.
- 행사 승인·개최일·참여 지점이 확정되지 않았다.
- 자동 배포 후 일부 지점에서 거짓 정보가 된다.

### 6.2 비즈프로필 홈 랜딩

적합한 경우:

- 프로모션보다 지역 내 지점 인지와 방문정보 확인이 목적이다.
- 지점명·주소·지도·시간·문의 경로가 최신이다.
- 프로필 행동 이후의 문의·예약을 분리 측정할 수 있다.

보류하는 경우:

- 지도 핀이나 문의 경로가 불일치한다.
- 영업시간과 수업시간이 혼합돼 있다.
- 프로필이 다른 지점이나 중앙 페이지로 잘못 연결된다.

## 7. 공통 소식 자동 배포 통제

본사에서 올린 공통 소식이 연결 지점에 자동 반영될 수 있으므로, 한 번의 오류가 여러 지점으로 확대될 수 있다.

배포 전:

1. 대상 지점 목록을 잠근다.
2. 문구의 각 사실을 지점별로 대조한다.
3. 제외 지점과 예외 조건을 기록한다.
4. 이미지 속 텍스트까지 검수한다.
5. 대표 승인본의 해시 또는 버전을 기록한다.

배포 후:

1. 대표 지점만 보지 않고 전체 대상 지점을 표본 또는 전수 확인한다.
2. 공개 문구·이미지·랜딩·지도 연결을 확인한다.
3. 잘못된 지점 노출 시 공통 소식과 캠페인을 함께 멈춘다.
4. 수정 제출과 실제 공개 반영을 구분한다.
5. 이전 버전이 남아 있지 않은지 다시 확인한다.

## 8. 지역 범위 설정 원칙

지역 범위는 ‘넓을수록 좋다’가 아니다.

- 지점별 실제 문의·방문자의 비식별 출발권역이 있으면 이를 우선한다.
- 데이터가 없으면 작은 검증 범위에서 시작하고 확대 조건을 미리 정한다.
- 강·산·간선도로·환승·주차·도보 출입구 등 실제 접근 장벽을 검토한다.
- 다른 지점의 권역과 겹칠 때 최초 클릭 지점과 최종 방문 지점을 모두 기록한다.
- 광고의 인근 지점 자동 연결을 실제 방문 의사나 지점 선택으로 해석하지 않는다.
- 공식 예시 수치를 내부 기본값으로 복사하지 않는다.

## 11. KPI

분자·분모·기간·원천이 연결될 때만 계산한다.

- 클릭률 = 광고 클릭 ÷ 노출
- 랜딩 도착률 = 랜딩 조회 ÷ 광고 클릭
- 프로필 행동률 = 프로필 행동 ÷ 랜딩 조회
- 유효 문의율 = 유효 문의 ÷ 광고 클릭 또는 추적 가능한 랜딩 조회
- 문의→예약률 = 체험 예약 ÷ 결과창이 성숙한 유효 문의
- 예약→참석률 = 실제 참석 ÷ 결과가 확정된 체험 예약
- 참석→신규 시작률 = 신규 계약 시작 ÷ 성숙한 실제 참석
- 유효 문의당 순광고비 = 순광고비 ÷ 유효 문의
- 참석당 순광고비 = 순광고비 ÷ 실제 참석
- 등록당 순광고비 = 순광고비 ÷ 신규 계약 시작
- 확인 순수납 = 환불·취소·차지백을 반영한 수납
- 증분 기여 = 승인된 비교설계에서 확인된 추가 순수납·기여

분모가 0이면 계산 불가, 원천이 없으면 `데이터 미연결`이다. 캐시백·지원 캐시는 총비용·플랫폼 크레딧·순광고비로 분리한다.

## 12. EXP-328 — 당근 다지점 광고 적격성·오프라인 전환 완전성

### 가설

공식 지점 요건, 프로필 연결, 수용능력, 문의 귀속을 먼저 검증하면 잘못된 지점 연결과 허위 방문 성과를 줄일 수 있다.

### 0단계: 무집행 검증

- 계정에서 상품 이용 가능 상태 확인
- 실제 운영 지점과 프로필 연결 전수 대조
- 공통 소식의 지점별 사실 일치 검사
- 합성 테스트로 인근 지점 연결·문의 인계·중단 절차 검증

### 1단계: 대표 승인 후 제한 파일럿
