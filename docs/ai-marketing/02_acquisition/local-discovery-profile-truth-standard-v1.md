# 지역 검색→체험 문의 정보 정합성 표준 v1

- 작성일: 2026-09-14
- 목적: 네이버 플레이스·Google 비즈니스 프로필·웹사이트·당근·Instagram에서 지점 정보가 충돌해 체험 문의가 이탈하거나 잘못 귀속되는 일을 방지
- 적용 범위: 공개 가능한 지점 정보의 확인·게시·측정 기준
- 현재 상태: 실제 지점 목록, 주소, 운영시간, 수업표, 문의 경로, 채널별 성과 데이터 미연결
- 외부 행동: 프로필 수정, 게시, 광고, 고객 메시지 미실행

## 오늘의 판단

지역 기반 신규 확보는 노출 확대 전에 방문 판단에 필요한 정보의 정확성과 출처를 맞춰야 한다. 조회·길찾기·통화 클릭은 실제 문의·방문·등록과 다른 사건이며, 채널마다 서로 다른 지점 정보가 표시되면 성과 귀속도 불가능해진다.

## 기존 문서와의 경계

- `marketing-to-verified-revenue-attribution-standard-v1.md`는 문의 이후 등록·검증 수납 귀속을 다룬다.
- `multi-branch-lifecycle-handoff-minimum-spec-v1.md`는 지점 사이의 담당·단계 인계를 다룬다.
- 이 문서는 문의 전에 사용자가 확인하는 공개 지점 정보와 문의 진입점의 정합성만 다룬다.

## 기준원천

대표가 승인한 내부 기준표 하나를 공개 정보의 기준원천으로 둔다. 기준표가 없거나 값이 확인되지 않으면 채널 프로필을 임의 수정하지 않는다.

| 정보군 | 필수 필드 |
|---|---|
| 지점 식별 | `branch_code`, `public_branch_name`, `verification_status` |
| 방문 정보 | `full_address`, `map_pin_checked_at`, `public_hours`, `special_hours` |
| 문의 정보 | `approved_contact_route`, `contact_route_owner`, `response_hours` |
| 수업 정보 | `verified_audience`, `verified_program_summary`, `schedule_checked_at` |
| 접근 정보 | `parking_status`, `arrival_note`, `accessibility_note` |
| 미디어 | `asset_source`, `public_use_consent_status`, `asset_checked_at` |
| 변경관리 | `last_verified_at`, `verified_by_role`, `next_review_at` |

실제 회원·보호자 정보, 연락처 원장, 출석·건강·결제 기록은 공개 저장소에 기록하지 않는다.

## 상태값

- `VERIFIED_CURRENT`: 기준원천과 채널 표시값이 일치하고 검증일이 있음
- `MISSING`: 필수 정보가 없음
- `CONFLICT`: 채널 사이 또는 기준원천과 값이 다름
- `PENDING_APPROVAL`: 수정안은 있으나 대표 승인 전
- `NOT_APPLICABLE`: 해당 채널에서 제공하지 않는 필드
- `UNKNOWN`: 확인할 수 없으며 추정하지 않음

`UNKNOWN`과 `MISSING`을 0이나 운영하지 않음으로 바꾸지 않는다.

## 채널 역할

| 채널 | 역할 | 공개 전 확인 |
|---|---|---|
| 네이버 플레이스 | 국내 지역 검색·지도에서 업체 정보 확인 | 상호, 업종, 지도 위치, 운영시간, 문의 경로 |
| Google 비즈니스 프로필 | Google 검색·지도에서 지역 정보 확인 | 인증 상태, 주소, 카테고리, 운영시간, 속성, 사진 |
| 웹사이트 | 지점별 상세 설명과 공식 문의 도착지 | 채널 프로필과 동일한 지점명·주소·연락 경로 |
| 당근 | 근거리 이용자에게 지역 맥락과 다음 행동 제시 | 실제 지역, 대상, 공개 가능한 문의 방법 |
| Instagram `@ant.toe.98` | 코치 개인의 설명·수련 관점·신뢰 형성 | 브랜드 공식 발표 주체로 표현하지 않음 |

코치 개인 Instagram의 프로필이나 게시물을 지점 운영시간·가격·행사의 기준원천으로 사용하지 않는다. 확인된 정보가 있을 때만 자연스럽게 수업 문의로 연결한다.

## 공개 정보 검수 순서

1. 지점별 기준원천의 승인 상태와 검증일을 확인한다.
2. 네이버·Google·웹사이트·당근의 공개값을 필드별로 비교한다.
3. `CONFLICT`는 노출 성과 측정보다 먼저 수정 후보로 기록한다.
4. 전화·채팅·예약·폼 등 문의 진입점이 실제 담당에게 도착하는지 테스트 레코드로 검증한다.
5. 테스트 문의는 실제 신규 문의에서 제외하도록 `test_record`로 표시한다.
6. 수정은 대표 승인 후 수행하고, 변경 시각과 변경 전·후 값을 내부 감사기록에 남긴다.
7. 공개 채널 수정 후 실제 표시값을 다시 확인한다.

## 콘텐츠 연결 규칙

- 네이버 콘텐츠: 검색 의도에 맞는 제목과 확인된 지점·방문 정보를 사용한다.
- 당근 콘텐츠: 실제 지역과 한 가지 문의 행동만 제시한다.
- Instagram 콘텐츠: 코치 개인 콘텐츠의 맥락을 유지하며, 확인되지 않은 지점·시간표·가격·무료 체험·혜택을 넣지 않는다.
- 한 채널의 문구를 그대로 복제하기보다 채널 역할에 맞게 재작성하되 사실값은 동일하게 유지한다.
- 지도 조회·프로필 조회·길찾기·전화 클릭을 실제 문의나 방문으로 간주하지 않는다.

## 퍼널 연결

`지역 검색 노출 → 프로필 조회 → 문의 행동 클릭 → 유효 문의 → 체험예약 → 실제 방문 → 등록 → 검증 수납`

| 지표 | 분자 | 분모 |
|---|---|---|
| 프로필→문의 행동률 | 문의 행동 클릭 수 | 프로필 조회 수 |
| 문의→예약률 | 체험예약 수 | 유효 문의 수 |
| 예약→방문률 | 실제 방문 수 | 체험예약 수 |
| 방문→등록률 | 등록 수 | 실제 방문 수 |

분모가 0이거나 채널·기간·지점이 연결되지 않으면 계산하지 않고 `데이터 미연결`로 남긴다. 문의 행동 클릭은 실제 문의 완료가 아니다.

## EXP-293 — 지역 정보 정합성 기준선

- 대상: 대표가 승인한 실제 지점과 공개 채널
- 기간: 승인 후 최초 전수점검 1회와 이후 14일
- 가설: 필수 공개 정보와 문의 진입점을 먼저 정합화하면 잘못된 문의 귀속과 방문 정보 충돌을 줄일 수 있다.
- 성공:
  - 적용 지점의 필수 정보 검증 상태 기록률 100%
  - 기준원천과 공개 채널의 중요 필드 충돌 0건
  - 문의 진입점 테스트 성공률 100%
  - 테스트 문의의 실제 문의 포함 0건
  - 유효 문의의 지점·원래 유입원 기록률 100%
  - 공개 개인정보·미확정 운영정보 0건
- 보류:
  - 실제 지점 목록·기준원천·담당·문의 경로 미승인
  - 채널 접근 또는 성과 데이터 미연결
- 중단:
  - 확인되지 않은 주소·시간표·가격·혜택 공개
  - 지도 클릭을 실제 방문으로 계산
  - 승인 없는 계정 수정·광고·고객 메시지
- 현재 문의율·방문율·등록률·매출 기여: 데이터 미연결
