## 1. 핵심 판단

지역 리뷰는 신규 고객의 판단에 영향을 줄 수 있지만, 리뷰를 많이 모으는 것보다 다음 세 가지가 우선이다.

1. 실제 경험에 기반한 리뷰만 요청한다.
2. 긍정·부정 여부를 기준으로 요청 대상을 선별하거나 보상하지 않는다.
3. 공개 리뷰 반응과 실제 문의·체험·등록·재등록·순수납을 분리한다.

리뷰 정책을 위반해 단기적으로 별점이 높아져도 리뷰 삭제, 신규 리뷰 제한, 기존 리뷰 비공개, 경고 표시 등으로 지역 신뢰가 훼손될 수 있다.

## 2. 기존 기준과의 경계

이 문서는 다음 기준을 대체하지 않는다.

- 다지점 지역검색 기준: 지점명·주소·지도 핀·시간·연락처·랜딩페이지 정합성
- 다채널 문의 기준: 동일 문의 식별·지점 라우팅·담당자·SLA·성과 귀속
- 체험 후 미등록 기준: 체험 참석부터 등록·실수납·회원권 활성화
- 서비스 회복 기준: 불편·휴강·변경·보강·환불의 실제 처리
- 가족·보호자 기준: 미성년 회원·보호자·결제자·동의·접근권한
- Instagram 승인 기준: 승인 대기·버전 잠금·업로드·발행·공개 검증

이 문서는 공개 리뷰 요청, 경제적 이해관계, 리뷰 응답, 내부 서비스 회복 인계, 리뷰에서 문의·등록까지의 측정을 다룬다.

## 4. 리뷰 요청 적격성

### 4.1 포함 조건

다음 조건을 모두 확인한 경우에만 REVIEW_REQUEST_ELIGIBLE로 분류한다.

- 대상이 실제 방문·수업·상담·서비스 경험을 가진 사람임
- 대상 채널의 최신 리뷰 정책을 확인함
- 요청 문구가 별점·방향·내용을 유도하지 않음
- 리뷰 작성·수정·삭제와 연결된 보상이 없음
- 현장에서 즉시 작성하도록 압박하지 않음
- 개인정보·미성년자·촬영물 공개를 요구하지 않음
- 연락 목적과 수신 적격성이 확인됨
- 동일 경험에 대한 과도한 반복 요청이 아님
- 수신거부·연락 금지 상태가 아님

### 4.2 제외 조건

다음 대상에게는 리뷰 요청을 보내지 않는다.

- 실제 경험 여부가 확인되지 않은 사람
- 직원, 전·현직 관계자, 거래업체 등 이해충돌 가능성이 있는 사람
- 할인·무료 서비스·경품·포인트와 리뷰 작성이 연결된 사람
- 불만을 철회하거나 리뷰를 수정·삭제하는 대가를 제안받은 사람
- 미성년자에게 직접 요청할 권한이 확인되지 않은 경우
- 개인정보·안전·분쟁·환불 사건이 해결되지 않은 경우
- 이미 동일 요청에 거부했거나 수신 중단을 요청한 사람
- 플랫폼이 요청을 금지하거나 기능을 제한한 경우

제외는 부정 리뷰를 막기 위한 선별이 아니라 권한·정책·연락 적격성 통제여야 한다.

## 5. 금지되는 리뷰 조작

Google의 현재 정책을 최소 공통 기준으로 삼아 다음을 금지한다.

- 리뷰 작성·수정·삭제의 대가로 현금, 할인, 무료 상품·서비스, 포인트, 경품 제공
- 긍정 경험자에게만 공개 리뷰 링크를 보내는 review gating
- 부정 응답자는 내부 설문으로만 보내고 긍정 응답자만 플랫폼 리뷰로 보내는 흐름
- 별점 5점 또는 긍정 표현 요구
- 특정 코치·직원 이름이나 특정 문구 포함 요구
- 직원별 리뷰 횟수 할당량 설정
- 현장 직원이 보는 앞에서 즉시 작성하도록 압박
- 태블릿·공용기기·공용 네트워크로 다수 리뷰 작성 유도
- 한 사람이 여러 계정으로 작성
- 가족·직원·거래업체가 이해관계를 숨기고 작성
- 경쟁 지점에 부정 리뷰 작성 또는 요청
- AI로 실제 경험이 없는 리뷰를 생성해 게시
- 부정 리뷰 수정·삭제를 조건으로 환불·보상 제공
- 리뷰 삭제를 암시하며 법적 위협 또는 불이익 고지
- 플랫폼별 정책을 확인하지 않고 Google 기준을 모든 채널에 동일 적용했다고 주장

## 6. 허용되는 중립적 리뷰 요청

다음 조건에서는 실제 경험을 가진 고객에게 중립적으로 리뷰를 요청할 수 있다.

- 긍정·부정 평가를 미리 묻지 않음
- 별점이나 특정 내용을 요구하지 않음
- 작성 여부가 완전히 선택임을 밝힘
- 보상이나 불이익이 없음
- 공식 리뷰 링크 또는 QR 코드로 이동함
- 개인정보·건강·아동 이름·사진을 쓰지 않도록 안내함
- 문제가 있었다면 별도의 공식 문의 경로를 함께 제공하되 공개 리뷰를 막지 않음
- 요청 발송, 링크 클릭, 리뷰 게시를 서로 다른 사건으로 기록함

중립 요청 예시의 구성 요소:

1. 실제 경험에 대한 솔직한 의견 요청
2. 작성은 선택이라는 안내
3. 보상 없음
4. 별점·내용 지시 없음
5. 개인정보 공개 주의
6. 공식 리뷰 링크
7. 별도 문의 경로

실제 문구 발송은 대표 승인과 채널별 정책 확인 후 진행한다.

## 7. 비공개 피드백과 공개 리뷰 분리

### 7.1 비공개 피드백

비공개 만족·불편 조사는 서비스 개선 목적이다.

- 응답을 공개 리뷰로 자동 전환하지 않는다.
- 높은 점수 응답자만 공개 리뷰로 유도하지 않는다.
- 낮은 점수 응답자의 공개 리뷰 작성을 막지 않는다.
- 응답 내용은 개인별 상담·민원 접근권한으로 제한한다.
- 만족 응답을 회원 전체의 만족으로 확대하지 않는다.

### 7.2 공개 리뷰

공개 리뷰는 플랫폼 이용자의 표현이다.

- 도장이 작성 방향을 통제하지 않는다.
- 리뷰 내용이 사실인지 내부 확인 전 확정하지 않는다.
- 별점만으로 만족·유지·재등록을 판단하지 않는다.
- 공개 리뷰를 광고·웹·Instagram에 재사용하려면 별도 사용 권한과 표시 기준을 확인한다.
- 원문 일부를 잘라 의미를 바꾸지 않는다.

### 7.3 후기 재사용

후기를 홍보 소재로 재사용할 때 다음을 기록한다.

- 원 작성자 확인
- 사용 권한
- 사용 채널
- 사용 기간
- 수정·축약 범위
- 경제적 이해관계
- 철회 처리
- 미성년자·보호자 동의
- 이미지·영상·음성 권리

공개 리뷰가 보인다는 사실만으로 다른 채널의 광고 소재 사용 권한이 생기지 않는다.

## 8. 경제적 이해관계와 체험단

### 8.1 이해관계 유형

- 무료 체험 또는 무료 이용
- 할인·쿠폰·포인트
- 상품·서비스 제공
- 현금·수수료
- 제휴·고용·가족 관계
- 대회·행사 지원
- 추천 보상
- 콘텐츠 제작비
- 향후 혜택 약속

### 8.2 표시 원칙

- 추천·보증 내용과 경제적 이해관계를 소비자가 쉽게 인식할 수 있도록 표시한다.
- 표시 위치·표현은 채널 형식과 최신 국내 심사지침을 대조한다.
- 해시태그 묶음 깊숙한 곳이나 더보기 뒤에만 숨기지 않는다.
- 실제 지급 전이라도 혜택 약속이 있으면 이해관계 여부를 검토한다.
- 체험단 후기를 일반 자발적 리뷰처럼 표현하지 않는다.
- 표시했다고 해서 플랫폼이 금지한 보상형 리뷰가 허용되는 것은 아니다.

Google 리뷰에는 보상 제공 자체가 금지되므로 경제적 이해관계 표시만으로 허용되지 않는다.

## 9. 채널별 운영 기준

### 9.1 Google Maps·Business Profile

- 실제 경험에 근거한 중립 요청만 사용한다.
- 리뷰 작성·수정·삭제 대가의 보상을 제공하지 않는다.
- 긍정 리뷰 선별 요청, 부정 리뷰 억제, 현장 압박을 하지 않는다.
- 직원별 요청 할당량이나 특정 직원 이름 포함 요청을 하지 않는다.
- 리뷰 링크·QR 코드 생성 기능은 요청 수단일 뿐 리뷰 작성 증거가 아니다.
- 정책 위반 시 리뷰 삭제 외에도 신규 리뷰 제한, 기존 리뷰 비공개, 경고 표시가 가능함을 위험 원장에 기록한다.
- 제한 통지를 받으면 원인·기간·영향 지점·이의제기 상태를 분리한다.

### 9.2 네이버 지도·스마트플레이스·블로그

- 리뷰·방문자 리뷰·영수증 인증·체험단·블로그 후기의 정책과 표시 요건을 각각 확인한다.
- 현재 정책을 직접 확인하기 전 Google과 동일한 기능·허용 범위라고 추정하지 않는다.
- 영수증·예약 인증이 실제 수업 참여나 만족을 증명한다고 보지 않는다.
- 체험단·제공받은 서비스의 경제적 이해관계를 명확히 표시한다.
- 지점별 리뷰를 다른 지점의 성과로 합산하지 않는다.

### 9.3 당근 비즈프로필

- 동네·지점·거래·후기 기능의 최신 정책을 확인한다.
- 채팅·관심·단골을 리뷰·문의·방문으로 혼용하지 않는다.
- 보상형 후기나 실제 경험이 없는 지역 추천을 만들지 않는다.
- 이용자와의 공개 논쟁에서 개인 거래·회원 정보를 노출하지 않는다.

### 9.4 공식 웹·랜딩페이지

- 후기 원문·출처·작성 시점·허용된 축약 범위를 관리한다.
- 대표적인 성공 사례처럼 보이게 극단적 사례만 선택할 때 오인 위험을 검수한다.
- 성과 보장, 통증 개선, 치료·재활 효과, 무부상 같은 주장을 근거 없이 넣지 않는다.
- 후기 옆의 지점·프로그램·기간이 실제 범위를 벗어나지 않게 한다.
- 게시 철회 또는 권한 만료 시 제거한다.

### 11.3 중립·부정 리뷰

1. 의견에 대한 감사 또는 유감 표현

4. 확인 후 조치하겠다는 범위 내 약속

- 해결 전 “완료” 표현

### 11.4 안전·건강·아동 관련 리뷰

## 16. KPI 정의

### 16.1 평판 운영

- 공개 리뷰 수 = 기간 내 공개가 확인된 고유 review_id
- 리뷰 요청 수 = 승인 후 발송된 고유 request_id
- 리뷰 응답 수 = 공개 답변이 확인된 review_id
- 응답 대기 수 = 응답 적격이지만 미게시인 review_id
- 정책 신고 수 = 플랫폼에 검토 요청한 고유 review_id
- 프로필 제한 수 = 실제 제한 통지가 확인된 지점·기간

### 16.2 서비스 개선

- 리뷰 유래 서비스 사건 수 = source_review_id가 있는 service_case
- 확인 완료 수 = 사실 확인 상태가 완료된 사건
- 조치 완료 수 = 승인된 corrective_action이 이행된 사건
- 재발 점검 완료 수 = recurrence_check_at가 확인된 사건

### 16.3 전환

- 리뷰 기여 문의 수 = 승인된 기여 증거가 있는 고유 inquiry_id
- 리뷰 기여 체험 예약 수 = 해당 문의 중 예약 확정
- 리뷰 기여 실참석 수 = 해당 예약 중 실제 참석
- 리뷰 기여 신규 등록 수 = 회원권 활성 확인
- 리뷰 기여 재등록 수 = 재등록 권리 활성 확인
- 리뷰 기여 순수납 = 실수납 - 환불 - 차지백 - 승인 조정

### 16.4 비율

- 요청→공개 리뷰율 = 공개 리뷰 수 / 전달된 리뷰 요청 수
- 리뷰 응답률 = 공개 답변 수 / 응답 적격 리뷰 수
- 리뷰 유래 사건 해결률 = 서비스 사건 종료 수 / 리뷰 유래 서비스 사건 수
- 리뷰 기여 문의→실참석률 = 실제 참석 수 / 리뷰 기여 고유 문의 수
- 리뷰 기여 실참석→등록률 = 신규 등록 수 / 리뷰 기여 실제 체험 참석 수

분자·분모·기간·지점·채널·출처·조회시각을 함께 표시한다. 분모가 0이거나 데이터가 없으면 계산하지 않는다.
