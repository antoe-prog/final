# 회원 추천·친구초대 동의·보상·자격·부정사용·전환 귀속 기준 v1

- 작성일: 2026-09-19
- 적용 목적: 신규 체험회원 확보, 기존회원 만족, 휴면 복귀, 재등록, 순수납 기여를 과장 없이 연결
- 적용 범위: 파이널유도멀티짐의 향후 회원 추천·친구초대 프로그램, 네이버·Instagram·당근·웹·오프라인 QR

## 1. 오늘의 판단

추천 프로그램은 게시물이나 보상 문구보다 먼저 `추천 링크 발급 → 회원의 자발적 공유 → 피추천인의 자발적 접촉 → 중복·자격 확인 → 체험 실참여 → 등록 → 실수납 → 보상 승인 → 환불·차지백 반영`을 연결해야 한다.

추천 보상과 후기 보상은 다른 행위다. 친구의 실제 체험·등록을 조건으로 한 추천 보상을 설계할 수는 있지만, 후기·별점·긍정적 문구 작성 또는 부정 후기 수정·삭제를 보상 조건에 섞지 않는다.

현재 가격·혜택·예산·회원 상태·동의·성과 데이터는 연결되지 않았다. 따라서 실제 프로그램 공개, 링크 배포, 고객 연락, 보상 지급, 광고 집행은 보류한다.

## 2. 공개 자료에서 확인한 변화

1. GymMaster의 체육시설 마케팅 자료는 추천 프로그램을 낮은 추가 획득비용으로 신규회원을 유치하는 방법으로 계속 제안하며, 해당 글은 2026년 8월 말 갱신됐다. 이는 업계 실행 아이디어이지 파이널유도의 성과 근거는 아니다.
2. Google은 할인·무료 상품·서비스 등 보상을 후기 작성·수정·삭제와 교환하는 것을 금지한다. 추천 보상의 조건에서 후기·별점 행위를 완전히 분리해야 한다.
3. 개인정보 보호 원칙상 친구의 연락처를 기존회원에게서 받아 자동 발송하는 방식보다, 회원이 공개 가능한 추천 링크나 코드를 직접 공유하고 피추천인이 스스로 접촉하도록 하는 방식이 안전하다.

## 3. 핵심 원칙

### 3.1 추천과 후기의 분리

- 추천 보상 조건: 승인된 프로그램에서 확인된 체험 실참여·등록·실수납 같은 사건만 사용한다.
- 금지 조건: 후기 작성, 특정 별점, 긍정 문구, 후기 수정·삭제, SNS 언급, 특정 직원을 지목한 칭찬.
- 추천인이 후기를 작성하더라도 추천 보상과 독립적으로 처리한다.
- 추천 관계가 포함된 후기나 콘텐츠를 재사용하려면 이해관계와 대가 여부를 별도로 표시하고 공개 동의를 확인한다.

### 3.2 연락처를 먼저 받지 않는 구조

- 기본안: 회원별 또는 캠페인별 추천 코드·링크를 발급하고 회원이 자신의 채널에서 직접 공유한다.
- 피추천인은 링크를 열고 자신이 선택한 공식 문의·예약 경로로 직접 접촉한다.
- 회원에게 친구 이름·전화번호·DM 계정·미성년자 정보를 입력하게 하지 않는다.
- 주소록 업로드, 친구 태그 강요, DM 스크래핑, 자동 초대 메시지, 무응답 대상 재발송은 하지 않는다.
- 예외적으로 연락처 수집이 필요한 경우 처리 목적·필수 항목·보유기간·연락 자격·삭제 절차를 승인받고 동의를 입증할 수 있어야 한다.

### 3.3 자격과 조건의 사전 확정

공개 전에 다음을 하나의 승인본으로 고정한다.

- 대상 지점·프로그램·기간
- 추천인과 피추천인의 자격
- 신규 회원의 정의와 과거 이용·가구·다지점 이력의 처리 방식
- 체험 예약, 실참여, 등록, 실수납 중 어떤 사건이 보상 조건인지
- 보상 종류·금액·수량·지급 시점·유효기간
- 취소·환불·차지백·휴회·양도 시 처리
- 자기추천, 가구 내 추천, 상호추천, 직원추천, 중복 코드의 처리
- 한 사람·가구·회원권·지점·기간별 지급 상한
- 문의·이의제기·오류 정정·보상 회수 절차

조건이 확정되지 않은 상태에서는 `무료`, `할인`, `혜택`, `선착순`, `오늘만`, `무조건 지급`을 공개하지 않는다.

## 5. 중복·부정사용 통제

### 5.1 자동 거절하지 않고 검토할 신호

- 추천인과 피추천인이 동일한 결제수단·연락처·기기·주소를 사용
- 같은 사람이 여러 지점에서 신규로 등록
- 기존회원의 탈퇴·재가입을 신규 추천으로 제출
- 여러 추천 코드가 한 예약·등록에 연결
- 가족·보호자·미성년자 관계가 존재
- 단시간에 비정상적으로 많은 추천·취소·환불 발생
- 보상 지급 직후 환불·차지백·양도 발생

신호는 조사 후보일 뿐 부정행위 확정이 아니다. 관계·동의·정정 절차 없이 사람을 자동 차단하지 않는다.

### 5.2 단일 귀속 규칙

- 동일 피추천인·동일 신규 등록 사건에는 승인된 추천인 한 명만 귀속한다.
- 다지점 이동·회원권 변경·재등록은 신규 추천과 분리한다.
- 최초 코드 입력, 최종 상담자, 수납 지점, 혜택 비용 지점을 각각 별도 필드로 둔다.
- 추천 기여와 광고·검색·네이버·당근·Instagram의 획득 기여를 동시에 기록할 수 있지만, 신규 등록과 순수납을 중복 합산하지 않는다.

## 8. EXP-407 — 추천 자격·동의·보상·순수납 귀속 정확도

### 목적

### 대상

- 합성 추천인·피추천인·가구·지점 관계 480건

### 변형 조건

- 신규·기존·휴면·재등록·다지점 이동

- 후기 작성·별점·후기 수정 요구가 섞인 잘못된 보상 조건

### 성공 기준
