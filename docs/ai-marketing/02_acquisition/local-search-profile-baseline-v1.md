# 파이널유도 지역 검색 프로필 기준선 점검표 v1

작성일: 2026-09-13 (KST)

공개 가능한 운영 기준입니다. Google 비즈니스 프로필의 존재·소유권·현재 내용·지점별 운영정보는 확인되지 않았습니다. 이 문서는 프로필 생성·수정, 리뷰 요청, 광고 집행을 승인하거나 실행했다는 뜻이 아닙니다.

## 목적

지역 검색에서 유도를 찾는 사람이 각 지점의 실제 정보와 일치하는 프로필을 발견하고, 문의·길찾기·웹사이트 방문으로 이동하는 과정을 측정한다. 신규 체험 획득에 사용하는 기준선이며 휴면복귀·재등록·매출 성과와 혼합하지 않는다.

## 1. 지점별 사실 확인

각 지점은 실제로 고객을 대면하는 독립 운영 장소인지 먼저 확인한다. 확인되지 않은 값은 추정하지 않고 `미확인`으로 남긴다.

| 항목 | 확인 기준 | 현재 상태 |
|---|---|---|
| 프로필 존재 | Google 검색·지도에서 해당 지점 프로필 확인 | 미확인 |
| 소유권·인증 | 운영 권한과 인증 상태 | 미확인 |
| 상호 | 간판·공식 웹사이트 등 실제 사용 상호와 일치 | 미확인 |
| 주소·핀 | 고객이 방문하는 실제 위치와 지도 핀 일치 | 미확인 |
| 전화·웹사이트 | 현재 연결 가능한 공식 경로만 사용 | 미확인 |
| 기본·특별 영업시간 | 평일·주말·휴일의 실제 운영시간 | 미확인 |
| 기본 카테고리 | 실제 핵심 업종을 가장 구체적으로 설명 | 미확인 |
| 추가 카테고리 | 제공하지 않는 서비스를 넣지 않고 최소화 | 미확인 |
| 서비스 설명 | 확인된 수업·대상만 기재 | 미확인 |
| 사진·영상 | 실제 지점이며 공개 권리가 확인된 자료 | 미확인 |
| 중복 프로필 | 동일 지점에 복수 프로필이 없는지 확인 | 미확인 |

Google은 실제 세계에서 사용하는 상호를 일관되게 표시하고, 정확한 주소·서비스 지역을 사용하며, 핵심 업종을 설명하는 최소한의 카테고리를 선택하고, 사업장당 하나의 프로필만 운영하도록 안내한다.

## 2. 검색 여정 점검

대표 또는 지점 담당자가 승인한 뒤 다음 검색어군을 같은 기기·기간 기준으로 관찰한다. 개인화된 단일 검색 결과를 공식 순위로 단정하지 않는다.

| 검색 의도 | 템플릿 | 확인 항목 |
|---|---|---|
| 브랜드 | 파이널유도 + 지점명 | 정확한 지점 프로필 노출 여부 |
| 지역·업종 | 지역명 + 유도 | 검색·지도 노출 여부 |
| 대상 | 지역명 + 성인 유도 / 어린이 유도 | 실제 제공 대상과 결과 일치 여부 |
| 방문 준비 | 지점명 + 시간 / 위치 / 주차 | 프로필 정보와 실제 안내 일치 여부 |
| 행동 | 지점명 + 전화 / 홈페이지 | 올바른 공식 경로 연결 여부 |

제공하지 않는 대상·프로그램을 검색어에 맞추기 위해 설명이나 카테고리에 넣지 않는다.

## 3. 성과 기준선

Google 비즈니스 프로필 성과 화면에서 동일 기간으로 내려받을 수 있는 지표만 기록한다.

- 프로필 조회
- 검색어
- 길찾기 요청
- 통화 버튼 클릭
- 웹사이트 클릭
- 예약 또는 예약 클릭: 연결된 예약 제공자가 있고 해당 지표가 제공되는 경우에만 사용
- 문의·체험예약·실방문·14일 등록: 내부 비식별 집계가 연결된 경우에만 사용

Google은 프로필 조회를 전체 Google 노출과 동일하게 계산하지 않으며, 사용자·기기·플랫폼에 따라 제한적으로 중복 집계될 수 있다고 설명한다. 지표 정의가 다른 Instagram 조회수와 합산하지 않는다.

## 4. 계산 규칙

- 프로필→웹사이트 클릭률 = `웹사이트 클릭 ÷ 프로필 조회 × 100`
- 프로필→길찾기율 = `길찾기 요청 ÷ 프로필 조회 × 100`
- 프로필→통화 클릭률 = `통화 버튼 클릭 ÷ 프로필 조회 × 100`
- 지역 검색 문의→예약률 = `예약 ÷ 지역 검색 유입 문의 × 100`
- 예약→실방문률 = `실방문 ÷ 예약 × 100`
- 실방문→14일 등록률 = `14일 내 등록 ÷ 실방문 × 100`

분모가 0이거나 데이터가 연결되지 않으면 계산하지 않는다. 통화·클릭을 실제 문의, 예약 또는 등록으로 대체 해석하지 않는다.

## EXP-282 Local Profile Completeness Baseline

- 가설: 광고나 상호 키워드 추가 없이도 지점별 사실정보와 측정 정의를 정리하면 지역 검색에서 발생한 행동을 문의·실방문과 구분해 관리할 수 있다.
- 1단계: 승인 전 28일 또는 확보 가능한 동일 기간의 원본 지표를 보존한다.
- 2단계: 대표가 승인한 사실정보만 수정한다.
- 3단계: 수정 후 같은 길이의 기간을 비교하되 계절·행사·광고·휴일 변화를 함께 표시한다.
- 성공: 지점별 필수 정보 확인 100%, 중복 프로필 0건, 원본 지표와 내부 퍼널의 정의 분리, 정책 위반 0건.
- 보류: 프로필 소유권, 지점별 상호·주소·시간·카테고리 또는 측정 기간 미확정.
- 중단: 상호명 키워드 삽입, 존재하지 않는 지점·서비스, 중복 프로필 생성, 리뷰 대가 제공, 권리 미확인 사진, 개인정보 공개.
- 순위·문의·매출 개선 기준: 데이터 미연결.

## 리뷰 운영 제한

실제 경험을 한 고객에게 정직한 리뷰를 요청할 수 있지만, 무료·할인·상품 등 대가를 제공해 리뷰를 작성·수정·삭제하도록 유도하지 않는다. 부정적 리뷰 삭제를 조건으로 혜택을 제안하지 않는다. 실제 리뷰 요청 문구와 발송 대상·채널·시점은 별도 승인 전 실행하지 않는다.

## 대표 확인이 필요한 입력

- 지점별 실제 상호, 주소·핀, 전화, 웹사이트, 운영시간
- 지점별 핵심 업종과 실제 제공 수업·대상
- 프로필 소유권·인증·중복 여부
- 공개 가능한 지점 사진의 촬영·초상·저작권 동의
- 비교할 기준 기간과 광고·행사·휴일 표시
- 지역 검색 유입 문의를 분류할 내부 비식별 집계 방식

## 감사 메모

Google은 지역 순위를 돈으로 요청하거나 구매할 수 없다고 안내한다. 관련성·거리·인지도는 통제 가능한 체크리스트가 아니라 결과에 영향을 주는 설명 변수다. 이 문서는 상위 노출, 문의 증가 또는 매출 증가를 보장하지 않는다.
