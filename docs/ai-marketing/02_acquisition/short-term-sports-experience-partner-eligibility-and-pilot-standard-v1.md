- 작성일: 2026-09-16
- 목적: 2026년 스포츠강좌이용권 단기스포츠체험강좌 협력파트너 공고를 파이널유도멀티짐의 신규 체험·지역 협력 경로로 검토할 때 적용할 적격성, 안전, 측정, 공개 커뮤니케이션 기준
- 상태: 공개 공고 검토 완료, 신청·접수·선정·사업승인 미실행
- 공개범위: 공개 공고와 비식별 운영 기준만 포함. 회원·보호자 식별정보, 연락처, 출석·결제 원장, 내부 원가·예산, 비밀키·토큰은 포함하지 않음

## 1. CMO 판단

국민체육진흥공단은 2026-08-18 단기스포츠체험강좌 협력파트너를 공개 모집했다. 최초 공모기간은 2026-08-18부터 08-28 18:00까지였고, 공고는 기간 이후 수시모집으로 전환한다고 명시한다.

이는 현재도 검토할 수 있는 공개 기회지만 파이널유도멀티짐이 신청 가능하거나 선정될 것이라는 뜻은 아니다. 공고의 대상은 상시·정기 강좌 개설이 어려운 종목 또는 스포츠 취약계층의 수요를 반영한 체험형 강좌를 기획·운영할 수 있는 기관·단체다.

따라서 우선순위는 홍보나 참가자 모집이 아니라 다음 적격성 대조다.

`기관 적격성 → 체험형 프로그램성 → 안전·사고 대응 → 전문인력·시설·장비 → 출석·정산 행정 → 비용·수용능력 → 대표 승인 → 공식 신청`

현재 상태는 `ELIGIBILITY_UNVERIFIED`다.

## 2. 공개 공고에서 확인된 조건

### 공모대상

- 스키·서핑 등 상시·정기 강좌 개설이 어려운 종목
- 또는 스포츠 취약계층 수요를 반영한 체험형 스포츠강좌
- 이를 기획·운영할 수 있는 기관·단체

유도는 공고 본문 예시에 명시되지 않았다. 유도 프로그램이 체험형 목적과 공고 취지에 맞는지는 공식 심사 전 확정할 수 없다.

### 자격조건

공고상 다음 요건을 모두 충족해야 한다.

1. 스포츠체험 프로그램 기획·운영 가능
2. 참여자 안전관리와 사고 대응체계 보유
3. 전문인력, 시설 또는 장비 확보
4. 사업기간 동안 강좌 운영, 출석관리, 정산 등 행정업무 수행 가능

시설·장비는 임대 또는 대여로 확보할 수 있다고 명시되어 있지만, 이를 외부 대관이나 장비 임차의 자동 승인으로 해석하지 않는다.

### 모집 상태

- 최초 공모: 2026-08-18~08-28 18:00
- 이후: 수시모집으로 전환
- 공식 접수: 공고에 기재된 이메일로 제출서류 일체 송부
- 방문·우편 접수: 불가

이 문서는 신청 이메일을 보내지 않는다. 실제 신청은 대표가 프로그램·예산·책임자를 승인한 뒤 별도 외부 제출 단계로 진행한다.

## 3. 일반 스포츠강좌이용권과 분리

단기스포츠체험강좌 협력파트너 공모는 일반 월 강좌의 가맹시설 등록·결제와 동일한 상태가 아니다.

다음 항목을 별도 기록한다.

| 구분 | 일반 월 강좌 | 단기스포츠체험강좌 |
|---|---|---|
| 지점·강좌 등록 | 공식 시설·강좌 조회 필요 | 협력파트너·프로그램 심사 필요 |
| 참가자 선정 | 이용권·지자체 기준 | 공고·프로그램별 기준 확인 필요 |
| 운영형태 | 정기 강좌 | 승인된 체험형 프로그램 |
| 결제·정산 | 이용권 온라인 결제 기준 | 협약·공고·정산 지침 확인 필요 |
| 홍보 권한 | 등록 상태 확인 후 | 선정·일정·대상 확정 후 |
| 현재 파이널유도 상태 | 데이터 미연결 | ELIGIBILITY_UNVERIFIED |

한 경로의 승인을 다른 경로의 승인으로 대체하지 않는다.

## 4. 목표 우선순위

1. 신규 체험회원 확보: 공공 체험 참여와 일반 체험·등록을 분리해 실제 후속 opt-in을 확인
2. 기존회원 만족·재등록: 외부 단기강좌가 기존 수업 좌석·코치·매트 안전을 침해하지 않도록 보호
3. 매출 증대: 사업비·직접비·코치시간·환수·정산을 반영한 순기여 확인
4. 휴면회원 복귀: 공공사업 참가자 모집이나 휴면회원 데이터 재사용과 혼합하지 않음

## 7. Acquisition Marketer — 파일럿 후보

### 후보: 초보자 대상 1회 유도 입문 체험

공고 적격성 확인 전에는 내부 검토안일 뿐이다.

검토 가능한 구성:

- 지도자 안내와 안전 브리핑
- 매트 적응과 기본 이동
- 지도하에 진행하는 기초 낙법 활동
- 비경쟁적 균형·그립 개념
- 수업 후 일반 유도 강좌에 관한 사실 안내

대표·안전 책임자·공고 담당자의 확인 전에는 정확한 회차, 시간, 인원, 대상, 비용, 지점, 모집일을 외부에 쓰지 않는다.

### 제외·보류

- 강한 메치기와 자유대련을 기본 체험으로 확정
- 안전정원보다 모집 규모 우선
- 미확정 보험·면책·이송체계
- 회원 식별 촬영을 홍보 조건으로 설정
- 참가자를 자동으로 마케팅 DB에 편입
- 공공사업 선정을 무료체험 또는 등록혜택으로 과장

## 8. CRM Marketer — 후속 원칙

- 공공사업 운영 안내와 광고성 연락 동의를 분리
- 보호자·참가자에게 필수 운영정보만 수집
- 사업 참가 명단을 휴면회원·일반 영업목록과 결합하지 않음
- 일반 수업 문의를 자발적으로 요청하거나 별도 동의한 사람만 후속 퍼널로 전환
- 체험 후 미등록을 실패로 단정하지 않고 `NO_OPT_IN`, `INFO_REQUESTED`, `TRIAL_BOOKED`, `DECLINED`를 구분
- 재등록·복귀 혜택은 공공지원과 혼합하지 않음

실제 메시지 발송은 대표 승인 전 금지한다.

## 10. Experiment Manager

### EXP-332 — 단기체험 협력파트너 신청 적격성

0단계: 합성 체크리스트와 공개 공고만으로 적격성 검토

성공 기준:

- 공고 요건별 증거 또는 미확인 상태 기록률 100%
- 기관·프로그램·안전·행정 책임 분리율 100%
- 기존 수업 좌석 침해 0건
- 선정 전 모집·홍보 0건
- 참가자 명단의 마케팅 자동 전환 0건
- 개인정보 공개 저장소 유입 0건
- 승인 없는 이메일 신청 0건

중단 기준:

- 유도가 공고 대상이라고 근거 없이 확정
- 안전·사고 대응 또는 보험 상태 미확인

- 기존회원 수업품질 저하
- 내부 부담과 정산 위험을 계산할 자료 부재 상태에서 신청

선정률·참석률·등록률·순기여 목표는 `데이터 미연결`이다.
