# 지역·다지점 프로필 정보 정확성·영업시간·카테고리·중복·문의 귀속 기준 v1

- 문서 버전: v1
- 검토일: 2026-09-19
- 적용 대상: 파이널유도멀티짐의 공개 가능한 지역 검색·프로필 운영 기준 초안
- 적용 채널: 네이버 스마트플레이스, Google 비즈니스 프로필·지도, 당근 비즈프로필·브랜드프로필, 자체 웹사이트
- 상태: 대표 승인 전 기준안
- 공개 제외: 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제 원장, 계정 권한·인증정보, 내부 가격·원가·손익, 미확정 행사, 승인 대기 Instagram 미디어·캡션

## 1. 목적

지역 프로필을 게시물 보관함이 아니라 실제 지점 방문을 돕는 운영정보 원장으로 관리한다.

다음 여정을 분리한다.

`공식 지점정보 승인 → 채널별 수정 제출 → 검토 대기 → 공개 반영 확인 → 프로필 노출 → 길찾기·통화·웹사이트 클릭 → 문의 → 체험 신청 → 예약 확정 → 실참여 → 등록 → 실수납`

이 기준의 목적은 다음과 같다.

1. 지점명·주소·지도 핀·연락처·운영시간·수업시간을 정확하게 구분한다.
2. 다지점 이름·카테고리의 일관성을 유지하고 중복 프로필을 통제한다.
3. 수정 제출과 실제 공개 반영을 구분한다.
4. 노출·클릭·길찾기·통화를 체험·등록·매출로 과장하지 않는다.
5. 네이버·Google·당근·웹사이트 간 지점 귀속의 중복을 막는다.

## 2. 핵심 판단

### 2.1 정확성이 홍보보다 먼저다

- 지점명에 검색어·혜택·시간표를 덧붙여 노출을 인위적으로 늘리지 않는다.
- 실제 간판·계약·공식 웹사이트와 다른 이름을 쓰지 않는다.
- 주소·출입구·층·호수·지도 핀을 서로 분리해 확인한다.
- 대표 운영시간과 프로그램별 수업시간을 혼동하지 않는다.
- 임시 휴관·공휴일·행사 운영은 일반 운영시간을 영구 변경하지 않는다.

### 2.2 플랫폼 입력은 완료가 아니다

- 수정 초안은 제출이 아니다.
- 수정 제출은 플랫폼 승인이나 공개 반영이 아니다.
- 공개 반영은 모든 사용자에게 동일하게 보인다는 보장이 아니다.
- 한 채널의 수정은 다른 채널에 자동 반영되지 않는다.
- 관리자 화면의 값과 비로그인 공개 화면을 따로 확인한다.

### 2.3 클릭은 전환이 아니다

- 프로필 노출은 클릭이 아니다.
- 길찾기 요청은 실제 방문이 아니다.
- 통화 버튼 클릭은 통화 연결이나 상담 완료가 아니다.
- 웹사이트 클릭은 문의 제출이 아니다.
- 예약 링크 클릭은 예약 확정이 아니다.
- 예약 확정은 체험 실참여가 아니다.
- 체험 실참여는 등록·실수납이 아니다.

### 2.4 다지점은 하나의 이름과 여러 실제 지점이다

- 브랜드 공통명과 지점 식별자를 분리한다.
- 각 지점은 실제 영업 장소·직원·운영 근거가 있어야 한다.
- 동일 지점에 중복 프로필을 만들지 않는다.
- 폐점·이전·이름 변경은 신규 생성 전에 기존 프로필 상태를 검토한다.
- 본관·지점·개별 코치의 공개 주체를 혼합하지 않는다.

- 회원·보호자 연락처
- 내부 매출·원가·성과 목표

## 5. 이름 기준

### 5.1 공통명과 지점명

- 모든 지점의 공통 브랜드 표기는 실제 간판·웹사이트·서류와 일치시킨다.
- 지점 식별자가 실제 공개 표기의 일부인지 확인한다.
- 본관·등촌점 등 지점 구분은 승인된 명칭만 사용한다.
- 키워드, 전화번호, 영업시간, 가격, 할인 문구를 업체명에 넣지 않는다.
- 코치 개인 계정명과 도장 공식 지점명을 혼합하지 않는다.

### 5.2 변경 관리

- 오탈자 수정과 브랜드 변경을 구분한다.
- 이름 변경 전 실제 간판·웹사이트·지점 안내를 확인한다.
- 플랫폼 재인증 가능성과 검색·후기 연속성을 검토한다.
- 한 채널만 먼저 변경해 장기간 이름이 불일치하지 않도록 순서를 승인한다.

## 6. 주소·지도 핀·출입구

### 6.1 주소

- 실제 고객이 방문하는 장소를 사용한다.
- 도로명 주소와 층·호수를 분리한다.
- URL·검색어·광고 문구를 주소 필드에 넣지 않는다.
- 이전 주소와 현재 주소를 동시에 활성 지점처럼 노출하지 않는다.

### 6.2 지도 핀

- 건물 중심점이 아니라 실제 방문 동선을 확인한다.
- 건물 뒤편·주차장·다른 출입구로 잘못 안내되는지 점검한다.
- 핀 수정 제출과 실제 길찾기 경로 반영을 구분한다.
- 길찾기 요청 수가 많아도 핀이 정확하다는 증거로 사용하지 않는다.

### 6.3 출입 안내

- 확인된 층·호수·출입구·엘리베이터·계단 정보만 작성한다.
- 주차 가능 여부·요금·시간 제한은 시설 운영자 확인 없이 만들지 않는다.
- “역에서 몇 분” 같은 이동시간은 경로·속도·출발점에 따라 달라지므로 고정 사실처럼 쓰지 않는다.

## 7. 운영시간과 수업시간

### 7.1 분리 원칙

| 항목 | 정의 | 혼동 금지 |
|---|---|---|
| 운영시간 | 고객 응대·방문이 가능한 시간 | 수업 시작표 |
| 수업시간 | 특정 프로그램의 실제 수업 일정 | 상시 영업시간 |
| 상담시간 | 전화·방문 상담 가능 시간 | 시설 운영시간 |
| 예약 가능 시간 | 시스템에서 예약 가능한 슬롯 | 실제 수업 확정 |
| 임시시간 | 공휴일·휴관·행사 예외 | 정규시간 |

### 7.2 입력 기준

- 플랫폼이 요구하는 “영업시간”의 의미를 확인한다.
- 프로그램별 수업이 여러 개인 경우 대표 운영시간과 수업표 링크를 분리한다.
- Google 공식 가이드는 수업처럼 활동별 시간이 크게 달라지는 일부 업종에 일반 시간을 쓰지 않는 사례를 제시하므로, 해당 적용 여부를 실제 프로필 유형에서 확인한다.
- 공휴일·임시휴관은 특별시간 또는 임시 상태로 관리한다.
- 24시간 운영, 연중무휴, 상시 상담을 근거 없이 표시하지 않는다.

### 7.3 변경 증거

- 변경 사유
- 적용 시작·종료일
- 영향 지점·프로그램
- 대표 승인
- 채널별 제출 시각
- 공개 반영 확인 시각
- 이전 값 복구 가능 여부

## 8. 카테고리와 서비스

### 8.1 카테고리

- 핵심 사업을 가장 구체적으로 설명하는 최소 카테고리를 사용한다.
- 검색어 확장을 위해 관련 없는 카테고리를 추가하지 않는다.
- 동일 서비스를 제공하는 지점은 주요 카테고리를 일관되게 유지한다.
- 지점별 실제 서비스가 다르면 차이와 근거를 기록한다.
- 플랫폼별 카테고리 체계가 다르므로 이름만 같다고 동일 코드로 간주하지 않는다.

### 8.2 서비스·프로그램

- 실제 운영이 확인된 프로그램만 표시한다.
- 연령·수준·선수반·성인부 등의 운영 여부를 지점별로 확인한다.
- 가격·무료 체험·할인·혜택은 승인본이 없으면 표시하지 않는다.
- 치료·재활·부상 예방을 보장하는 표현을 사용하지 않는다.

## 9. 연락처·웹사이트·예약 링크

### 9.1 연락처

- 지점이 직접 통제하고 실제 응답 가능한 번호를 사용한다.
- 공통 대표번호와 지점번호를 구분한다.
- 추적번호를 사용할 경우 실제 지점 연결·개인정보·통화기록 정책을 승인받는다.
- 통화 버튼 클릭을 통화 연결·상담 완료로 보지 않는다.

### 9.2 웹사이트

- 지점별 랜딩페이지가 있으면 정확한 지점으로 연결한다.
- 공통 홈페이지는 지점 선택이 명확해야 한다.
- 리디렉션이 다른 사업자·비공식 SNS·중간 광고 페이지로 이어지지 않도록 확인한다.
- URL에 이름·전화번호·건강정보 등 개인정보를 넣지 않는다.

### 9.3 예약 링크

- 링크 클릭, 양식 시작, 제출, 예약 확정, 체크인, 실참여를 분리한다.
- 지점·프로그램·시간대가 랜딩페이지와 실제 예약 시스템에서 일치해야 한다.
- 취소·대기·노쇼 처리 기준을 별도 운영 원장과 연결한다.

## 10. 중복 프로필

### 10.1 의심 신호

- 같은 주소·전화·이름의 복수 프로필
- 이전 상호와 현재 상호가 동시에 운영 중으로 표시
- 이전 주소와 현재 주소가 모두 활성 상태
- 본관·지점·코치 이름이 동일 장소에 별도 업체처럼 표시
- 다른 소유자 계정이 만든 프로필
- 자동 생성된 미인증 프로필과 공식 프로필의 동시 노출

## 11. 플랫폼별 기준

### 11.1 Google 비즈니스 프로필

- 실제 세계에서 사용하는 이름·주소·브랜드 표기를 반영한다.

- 실제 사업을 정확히 반영한다.
- 주소 또는 서비스 지역을 정확히 입력한다.
- 핵심 사업을 설명하는 최소 카테고리를 사용한다.
- 사업체·지점당 프로필 하나를 유지한다.
- 같은 서비스를 제공하는 다지점은 이름과 카테고리를 일관되게 관리한다.
- 이름·주소·영업시간·카테고리는 각 전용 필드에 넣는다.
- 길찾기·통화·웹사이트 클릭은 각각 해당 버튼·링크 행동 지표다.
- 다지점 성과 데이터는 내려받아 비교할 수 있다.
