# 다지점 지역 랜딩페이지·고유가치·도어웨이·대표 URL·전환 귀속 기준 v1

- 문서 상태: 공개 가능한 마케팅·검색 운영 기준
- 작성 기준일: 2026-09-19
- 적용 범위: 지점 소개·지역 검색·프로그램·체험 안내·문의·예약 랜딩페이지
- 목적: 지역 검색 유입을 실제 지점 정보와 유용한 콘텐츠로 연결하고, 복제 페이지·키워드 나열·잘못된 대표 URL로 인한 혼선과 전환 과장을 방지한다.
- 공개 제외: 실제 미승인 지점 주소·연락처·가격, 회원·보호자 식별정보, 개인별 출석·건강·결제 원장, 내부 손익, 승인 대기 Instagram 콘텐츠, 미확정 행사

> 이 문서는 페이지 제작·검수 기준이다. 현재 파이널유도 웹사이트, 검색 노출, Search Console, 웹 분석 또는 예약 시스템이 연결됐다고 가정하지 않는다.

## 1. 핵심 판단

다지점 지역 페이지는 도시명만 바꾼 복제본이 아니라, 방문자가 해당 지점의 실제 차이를 확인하고 다음 행동을 결정할 수 있는 **독립적으로 유용한 페이지**여야 한다.

`검색 노출 → 유효 지역 랜딩 → 지점 정보 확인 → 문의 행동 → 유효 문의 → 예약 확정 → 실참여 → 등록 → 실수납`

검색 노출·페이지뷰·버튼 클릭을 문의·체험·매출로 계산하지 않는다.

## 2. 기존 문서와의 경계

- `multi-branch-public-listing...`은 지도·지역 프로필의 이름·주소·시간·연락처 일치를 다룬다.
- `campaign-link-qr-utm...`은 배포 링크·QR·UTM과 전환 귀속을 다룬다.
- 이 문서는 **웹사이트의 지점·지역 랜딩페이지 구조, 고유 정보, 중복·도어웨이 위험, 대표 URL과 페이지 단위 성과**만 다룬다.

## 5. 지점 페이지의 고유가치

각 페이지는 승인된 범위에서 다음 중 실제 차이를 제공한다.

- 실제 지점명과 `location_id`
- 접근 방법·출입구·층·지도 목적지
- 해당 지점에서 실제 운영하는 프로그램
- 운영시간과 수업시간의 구분
- 대상 연령·수련 수준·예약 필요 여부
- 첫 방문 준비를 위해 확인할 항목
- 지점별 문의·예약 경로와 담당 범위
- 최신 확인일과 변경 책임자

다음만 바꾼 페이지는 공개 후보에서 보류한다.

- 도시·동 이름
- 제목과 메타 설명의 지역 키워드
- 지도 이미지 또는 전화번호 하나
- 동일 사진의 파일명·대체 텍스트
- 동일 본문의 어순·동의어

## 6. 도어웨이·대량 생성 위험

다음 패턴은 `DOORWAY_RISK`로 검토한다.

- 실제 지점이 없는 인접 도시·동별 페이지 생성
- 여러 지역 페이지가 동일한 대표 문의 페이지로만 중계
- 검색결과와 가까운 얇은 페이지를 대량 생성
- 지역명 목록을 본문·푸터에 반복 삽입
- AI로 지역명만 바꾼 페이지를 자동 배포
- 사용자가 원하는 답은 없고 문의 버튼만 있는 페이지
- 페이지 탐색 구조에서 고립된 검색 전용 URL

도어웨이 위험 표시만으로 정책 위반을 확정하지 않는다. 실제 구조·내용·사용자 가치와 최신 공식 정책을 검토한 뒤 결정한다.

## 7. 사람 우선 콘텐츠 검수

공개 전 다음 질문에 답할 수 있어야 한다.

1. 검색이 없어도 해당 지점 방문자에게 유용한가?
2. 실제 지점·코치·프로그램 근거가 있는가?
3. 다른 지점 페이지와 비교해 독립적인 정보가 있는가?
4. 제목이 페이지 내용을 정확히 요약하는가?
5. 읽은 사람이 다시 검색하지 않고 다음 행동을 판단할 수 있는가?
6. 작성자·검토자·최종 확인일을 내부에서 추적할 수 있는가?
7. 외부 자료를 복사하거나 단순 재작성하지 않았는가?
8. 미확정 가격·시간·혜택·성과·안전 보장이 없는가?

## 8. 대표 URL과 중복 처리

- URL 매개변수·캠페인 변형·HTTP/HTTPS·www 변형을 목록화한다.
- 실질적으로 같은 페이지는 대표 URL 후보를 정한다.
- `rel="canonical"`, 리디렉션, 사이트맵이 서로 다른 URL을 가리키지 않게 한다.
- 종료한 캠페인은 실제 대체 페이지가 있을 때만 관련 URL로 리디렉션한다.
- 실제 지점 페이지가 다른 지점 페이지를 대표 URL로 가리켜 고유 정보를 소실하지 않게 한다.
- 대표 URL 선언은 검색엔진이 그대로 채택했다는 뜻이 아니다.
- robots.txt 차단이나 URL 삭제 도구를 중복 정리 수단으로 간주하지 않는다.

## 10. 채널 연결

### 네이버·Google 지역 프로필

- 각 실제 지점 프로필은 해당 지점의 유용한 페이지로 연결한다.
- 모든 지점이 무조건 본관 페이지로 연결되게 하지 않는다.
- 프로필과 랜딩의 지점명·위치·시간·프로그램을 대조한다.

### Instagram @ant.toe.98

- 코치 개인 콘텐츠와 브랜드 공식 지점 페이지의 발표 주체를 구분한다.
- 확인되지 않은 지점·가격·시간표·혜택을 캡션이나 링크 문구로 만들지 않는다.
- 교육 콘텐츠에서 문의 랜딩으로 연결할 때 실제 목적지와 처리 주체를 확인한다.

### 당근

- 지역·지점이 실제 운영 범위와 일치하는 페이지만 연결한다.
- 지역명만 다른 복제 랜딩을 대량 배포하지 않는다.

## 11. 측정과 귀속

```
검색 노출
→ 검색 클릭
→ 유효 랜딩 세션
→ CTA 클릭
→ 유효 문의
→ 예약 확정
→ 실참여
→ 등록
→ 실수납
→ 환불·차지백
→ 순수납
```

- 검색 노출은 방문이 아니다.
- 랜딩 세션은 문의가 아니다.
- 전화·채팅·예약 버튼 클릭은 연결·제출·확정이 아니다.
- 여러 지역 페이지를 거친 한 사람을 여러 신규 문의로 계산하지 않는다.
- 페이지 보조 전환과 최초 획득 채널을 분리한다.
- 페이지별 매출은 실수납 원장과 중복 제거가 없으면 계산하지 않는다.

## 13. 역할별 실행

### CMO

- 지역 페이지 수보다 실제 지점 정보의 완전성·고유가치·전환 연결을 우선한다.

### Growth Analyst

- 검색 노출·세션·CTA·문의·예약·실참여·실수납을 분리한다.

### Acquisition Marketer

- 실제 지점과 승인된 프로그램에 한해 지역 랜딩을 제안한다.
- 도시명 교체형 대량 페이지를 만들지 않는다.

### CRM Marketer

- 랜딩에서 받은 문의를 담당 지점·목적·동의 상태와 함께 인계한다.

### Content Strategist

- 지점마다 실제 방문 판단에 필요한 고유 정보를 작성한다.
- 검색 키워드보다 방문자의 질문 해결을 우선한다.

### Experiment Manager

- 합성 페이지와 사건으로 중복·대표 URL·전환 귀속을 시험한다.

### Auditor

- 실제 지점 근거, 주장 출처, 고유가치, 도어웨이·키워드 나열 위험과 공개 범위를 검토한다.

## 14. 실험 EXP-404

**가설:** 실제 지점 근거와 고유가치 검수를 통과한 페이지만 공개하면 지역 검색 페이지의 중복과 잘못된 전환 귀속을 줄일 수 있다.

### 시험 데이터

- 합성 실제 지점 16개
- 합성 지역·지점·프로그램 페이지 320개
- URL·대표 URL·리디렉션 사건 960건
- 검색·세션·문의·예약·출석·결제 사건 2,400건

### 성공 기준

- 실제 지점 근거 없는 지역 페이지 공개 승인 0건
- 도시명만 교체한 복제 페이지 고유가치 통과 0건
- 서로 다른 실제 지점의 잘못된 대표 URL 통합 0건
- 대표 URL·리디렉션·사이트맵 충돌 0건
- 종료 캠페인의 무관한 페이지 리디렉션 0건
- 검색 노출의 랜딩 방문 오분류 0건
- CTA 클릭의 문의·예약 오분류 0건
- 페이지·지점·채널·결제 중복 귀속 0건
- 개인정보·비공개 관리 URL 공개 0건

### 중단 기준

하나라도 실패하면 지역 페이지 일괄 생성·자동 공개·전환 귀속을 중단하고 원인 수정 후 합성 데이터로 재검증한다.

## 15. 대표 승인·입력

- 운영 중인 전체 지점과 불변 `location_id`
- 지점별 공식 이름·주소·출입구·지도 목적지
- 실제 운영 프로그램·대상·시간·예약 여부
- 지점별 공식 문의·예약 목적지
- 지점 페이지 고유 정보와 공개 가능 사진 범위
- 페이지 작성·사실 검토·승인·만료 책임자
- 대표 URL·리디렉션·사이트맵 관리 담당자
- Search Console·웹 분석·CRM·예약·출석·결제 연결 범위

- Instagram 승인 대기 3건의 게시·수정·폐기 결정

## 16. 공개 근거

Google Search는 유사 검색어를 겨냥한 지역·도시별 페이지가 사용자를 한 목적지로 보내거나, 검색결과와 가까운 실질적으로 유사한 페이지를 만드는 행위를 도어웨이 남용 사례로 설명한다. 또한 지역명·도시명을 문맥 없이 나열하거나, 사용자 가치 없이 대량 생성한 페이지를 검색 스팸 위험으로 본다.

Google은 사람 우선 콘텐츠에 독창적 정보, 충분한 설명, 명확한 제목, 실제 경험과 전문성, 독자의 목표 달성을 돕는 만족스러운 경험이 있는지 검토하도록 안내한다. 비슷한 URL에는 리디렉션·`rel="canonical"`·사이트맵으로 대표 URL 신호를 줄 수 있지만, 신호 충돌을 피해야 하며 선언만으로 검색엔진 채택을 보장하지 않는다.
