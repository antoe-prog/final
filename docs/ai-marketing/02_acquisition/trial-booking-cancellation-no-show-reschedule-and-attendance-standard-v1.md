# 체험 예약·취소·노쇼·재예약·실방문 판정 기준 v1

- 문서 상태: 공개 운영 기준 초안
- 기준일: 2026-09-16
- 적용 범위: 신규 체험 예약, 일정 변경, 취소, 미방문 검토, 실제 방문, 후속 등록
- 소유 역할: CMO / Growth Analyst / Acquisition / CRM / Auditor
- 현재 상태: 고객 연락·예약 변경·수수료 부과 전
- 내부 예약·출석·등록·매출: **데이터 미연결**

## 1. 목적

체험 예약 수를 실제 신규 체험 성과로 오인하지 않도록 예약 이후의 사건을 분리한다.

`예약 생성 → 확정 → 변경·취소·예외 → 실제 방문 → 등록 → 순수납`

특히 다음 오류를 막는다.

1. 출석 확인 전 미방문을 자동으로 노쇼 처리
2. 사업자 취소나 시스템 오류를 고객 노쇼로 분류
3. 일정 변경으로 생긴 후속 예약을 신규 체험으로 중복 집계
4. 예약·노쇼 상태를 실제 방문·등록·매출로 간주
5. 승인되지 않은 연락, 수수료, 이용 제한 또는 계정 상태 변경

## 2. 핵심 원칙

### 2.1 예약은 방문이 아니다

예약 생성과 확정은 방문 의사를 나타낼 수 있지만 실제 수련 경험을 증명하지 않는다. 실제 방문은 승인된 출석 원천에서 별도로 확인한다.

### 2.2 미방문은 즉시 노쇼가 아니다

예약 시각이 지났다는 이유만으로 노쇼를 확정하지 않는다. 다음을 먼저 확인한다.

- 지점·수업·일시가 올바른지
- 출석 기록이 늦게 입력되거나 누락되지 않았는지
- 고객 취소·변경 요청이 다른 채널에 남아 있는지
- 사업자 취소·휴강·시간표 변경이 있었는지
- 예약·결제·알림 시스템 오류가 있었는지
- 대표가 승인한 도착 유예시간이 지났는지

증거가 부족하면 `NO_SHOW_PENDING_REVIEW`로 유지한다.

### 2.3 재예약은 신규 획득이 아니다

원래 예약과 변경 후 예약은 같은 체험 기회의 계보로 연결한다. 일정 변경으로 예약 레코드가 새로 생성돼도 신규 리드·신규 체험 예약으로 한 번 더 세지 않는다.

### 2.4 취소 주체와 원인을 분리한다

고객 취소, 사업자 취소, 플랫폼·결제 예외, 단순 일정 변경을 같은 “취소”로 묶지 않는다. 사업자 취소와 기술 예외는 고객의 약속 불이행 지표에서 제외한다.

### 2.5 상태 변경은 되돌리기 가능성을 확인한다

네이버 공식 도움말은 일부 취소·노쇼 처리의 복원 또는 철회가 제한될 수 있음을 안내한다. 되돌리기 어려운 상태 변경 전에는 증거 확인과 권한 분리를 적용한다.

### 2.6 외부 기준값을 내부 목표로 쓰지 않는다

2026년 체육시설 소프트웨어 업체들은 노쇼를 예약과 구분해 관리할 것을 권하지만 업종·상품·결제 구조별 편차가 크고 단일 권위 기준이 없다고 설명한다. 공급업체가 제시한 비율, 알림 시각, 취소 창구, 수수료는 파이널유도 기준으로 채택하지 않는다.

## 5. 판정 절차

### 5.1 예약 확정

1. 예약 생성 사건 수집
2. 지점·수업·일시·대상 확인
3. 결제형이면 결제 상태를 예약 상태와 분리
4. 확정 출처 확인
5. `BOOKING_CONFIRMED` 기록

예약 완료 화면 노출이나 알림 발송 성공만으로 실제 방문을 기록하지 않는다.

### 5.2 일정 변경

1. 변경 요청의 원예약 식별
2. 플랫폼·결제 방식별 변경 가능 여부 확인
3. 새 일시와 지점 확인
4. 원예약과 후속 예약을 같은 `booking_lineage_id`로 연결
5. 원예약은 변경 종료, 후속 예약은 활성 상태로 기록
6. 신규 예약 수에는 계보 최초 1건만 포함

네이버 공식 안내상 일정 변경 가능 범위는 결제 방식과 예약 상태에 따라 다를 수 있다. 실제 계정 상태를 확인하지 않고 변경 가능하다고 약속하지 않는다.

### 5.3 취소

1. 취소 주체 확인
2. 취소 요청·처리 시각 분리
3. 사업자 사유·기술 예외 검토
4. 적용 정책 버전 확인
5. 조기·지연 취소 판정
6. 환불이 있으면 예약 상태와 별도 기록
7. 되돌리기 어려운 처리 전 검수

취소 상태는 실제 방문·노쇼·등록으로 집계하지 않는다.

### 5.4 노쇼

1. 예약 시작 시각과 승인된 유예시간 확인
2. 출석 원천 확인
3. 고객의 취소·변경 요청 확인
4. 사업자 취소·휴강·시간표 변경 확인
5. 플랫폼·결제·알림 예외 확인
6. 증거와 검수자 역할 기록
7. 조건 충족 시에만 `NO_SHOW_VERIFIED`

누락 가능성이 있으면 마감하지 않는다. 고객에게 책임을 고지하거나 불이익을 적용하는 행위는 별도 승인 대상이다.

### 5.5 실제 방문과 등록

실제 방문은 체크인, 코치 확인, 승인된 출석 시스템 등 대표가 지정한 원천으로 확인한다. 이후 등록과 순수납은 각각 계약·정산 원천에서 별도로 확인한다.

## 6. 채널 운영 통제

### 6.1 네이버 예약

- 요청·확정·일정 변경·취소·이용완료·노쇼를 별도 사건으로 보존한다.
- 네이버 화면의 상태를 내부 출석 원천과 대조한다.
- 되돌리기 어려운 취소·노쇼 처리 전 근거를 확인한다.
- 네이버 예약지표의 완료·취소·노쇼 정의를 내부 신규등록·매출 정의와 혼합하지 않는다.
- 네이버페이와 비결제 예약의 변경·취소 가능 범위가 다를 수 있으므로 실제 상품 설정을 확인한다.

현재 파이널유도 지점별 예약 사용 여부, 결제 방식, 환불 기준과 권한은 **데이터 미연결**이다.

### 6.2 전화·문자·메신저·현장 예약

- 동일인의 예약을 채널별 신규 리드로 중복 집계하지 않는다.
- 변경·취소 요청의 수신 시각과 처리 시각을 분리한다.
- 직원 메모만으로 노쇼를 확정하지 않고 출석 원천과 대조한다.
- 실제 고객 메시지 발송은 대표 승인과 수신 적격성 확인 전 실행하지 않는다.

### 6.3 Instagram 코치 개인 계정

- `@ant.toe.98`의 댓글·DM·프로필 행동을 체험 예약으로 자동 판정하지 않는다.
- 지점·일시·확정 화면이 없는 질문은 문의 단계로 남긴다.
- 개인 계정을 지점 공식 예약 주체로 표현하지 않는다.
- 승인 대기 게시물의 미디어·캡션은 공개 저장소나 예약 시스템에 올리지 않는다.

## 7. 퍼널과 KPI

`유효문의 → 체험 예약 확정 → 실제 방문 → 신규 등록 → 30일 활성 → 재등록 → 순수납`

| KPI | 분자 | 분모 | 현재 |
|---|---|---|---|
| 예약 확정률 | 확정 예약 계보 | 유효 문의 | 데이터 미연결 |
| 예약→실방문률 | 검증 실방문 계보 | 성숙한 확정 예약 계보 | 데이터 미연결 |
| 검증 노쇼율 | 검증 노쇼 계보 | 실방문·검증 노쇼·고객취소가 판정된 성숙 예약 계보 | 데이터 미연결 |
| 고객 취소율 | 고객 취소 계보 | 성숙한 확정 예약 계보 | 데이터 미연결 |
| 사업자 취소율 | 사업자 취소 계보 | 성숙한 확정 예약 계보 | 데이터 미연결 |
| 재예약 회복률 | 후속 실방문 계보 | 재예약 연결 계보 | 데이터 미연결 |
| 실방문→등록률 | 검증 신규 등록 | 검증 실방문 | 데이터 미연결 |
| 등록→순수납률 | 검증 순수납 | 검증 신규 등록 | 데이터 미연결 |

분모가 0이거나 원천·관찰기간이 연결되지 않으면 계산하지 않는다. 사업자 취소와 기술 예외를 고객 노쇼 분모·분자에 넣지 않는다.

## 8. 실험 EXP-335

### 이름

체험 예약 상태·재예약 계보·실방문 판정 완전성

### 0단계

합성 레코드 16건으로 다음 경계를 검증한다.

- 정상 방문
- 조기·지연 고객 취소
- 사업자 취소
- 플랫폼·결제 예외
- 일정 변경 후 방문
- 일정 변경 후 취소
- 출석 지연 입력
- 노쇼 검토 대기와 확정
- 오분류 정정

### 1단계

대표 승인 후 비식별 체험 예약 20개 계보 또는 30일을 감사한다.

### 성공 기준

- 예약 계보 연결률 100%
- 취소 주체·원인 분류율 100%
- 출석 원천 확인률 100%
- 사업자 취소·기술 예외의 고객 노쇼 오분류 0건
- 일정 변경의 신규 예약 중복 집계 0건
- 증거 없는 노쇼 확정 0건
- 예약·방문·등록·순수납 혼합 판정 0건
- 승인 없는 연락·수수료·이용 제한·예약 변경 0건

### 보류 기준

- 지점별 예약 시스템과 출석 원천 미지정
- 취소 기준과 유예시간 미승인
- 플랫폼 권한과 상태 복구 가능 여부 미확인

### 중단 기준

- 예약 시각 경과만으로 자동 노쇼 확정
- 사업자 취소 또는 시스템 오류를 고객 책임으로 처리
- 재예약을 새 리드·새 체험으로 중복 집계
- 해지·수신중단 의사 뒤 후속 연락
- 승인 없는 수수료, 예약금, 이용 제한 또는 메시지 발송

출석률·등록률·회복률·순수납 목표는 **데이터 미연결**이다.
