# 스포츠강좌이용권 시설 적격성·결제·홍보 진실성 기준 v1

- 작성일: 2026-09-16
- 목적: 유·청소년 스포츠강좌이용권을 신규 체험·등록 경로로 검토할 때 지점·강좌 적격성, 결제·출석·정산, 보호자 안내, 공개 홍보를 분리 관리
- 상태: 공개 기준 완성, 파이널유도멀티짐 지점별 가맹·강좌 등록 상태 미확인
- 공개범위: 제도 공개정보와 비식별 운영 기준만 포함. 이용자·보호자 식별정보, 카드번호, 연락처, 개인별 출석·결제 기록, 내부 가격·정산자료는 포함하지 않음

## 1. CMO 판단

스포츠강좌이용권은 할인 캠페인이 아니라 공공 지원금 결제·출석·정산 규칙이 있는 별도 운영 경로다. 따라서 이용권 지원대상자가 존재한다는 사실만으로 파이널유도에서 사용할 수 있다고 홍보하지 않는다.

가장 먼저 확인할 것은 다음 세 가지다.

1. 각 지점이 현재 이용권 가맹시설로 승인되어 있는가
2. 해당 지점의 유도 강좌가 실제 운영 상태와 정확히 일치하게 등록되어 있는가
3. 온라인 결제·출석·정산을 제도 규정대로 처리할 담당자가 있는가

세 조건을 모두 확인하기 전 외부 상태는 `FACILITY_ELIGIBILITY_UNVERIFIED`로 유지한다.

## 2. 2026년 확인된 제도 변화와 현재 규칙

### 2.1 2027년 자동신청 서비스 도입

국민체육진흥공단은 2026-08-31 자동신청 서비스를 안내했다.

- 동의 대상: 스포츠강좌이용권 홈페이지 이용자
- 동의 기한: 2026-10-31 23:59
- 적용 시점: 2026-11-02
- 의미: 2027년 전국 동시신청 기간의 신청 절차를 자동으로 진행
- 주의: 자동신청은 자동선정 또는 자동갱신이 아니다

따라서 `자동신청하면 내년에도 확정`, `자동갱신` 같은 표현은 금지한다.

### 2.2 2026년 지원·결제 기본

공식 2026년 안내상 일반 스포츠강좌이용권은 다음과 같다.

- 대상: 5~18세 유·청소년 중 공지된 수급자격에 해당하는 사람
- 지원: 월 10만 5천 원 범위, 연간 12개월
- 2026년 결제 마감: 2026-12-10
- 결제: 이용권 홈페이지를 통한 온라인 결제
- 현장 결제: 공식 안내상 불가
- 당월 미사용 지원금: 자동 소멸
- 연속 3개월 미사용: 지원 중단 가능
- 출석률 50% 미만: 환수 가능성이 안내됨

대상 선정은 지자체 절차다. 도장이나 코치가 선정 여부를 약속하지 않는다.

### 2.3 당겨쓰기와 선결제 구분

2026-07-29 공식 공지는 최대 2개월분 지원금 당겨쓰기를 허용하지만 미래 강좌의 선결제로 사용하면 안 된다고 명시한다.

- 당겨쓰기: 월 지원금보다 비싼 현재 강좌 또는 방학 집중 이용 등 공지 목적에 맞게 지원한도를 당겨 사용
- 최대 결제 가능 예시: 3개월 지원한도 합계 31만 5천 원
- 선결제 금지: 향후 수강할 강좌를 미리 결제
- 결제 강좌: 결제일로부터 1개월 이내 실제 수강과 출석 완료
- 위반 위험: 이용권 지원 중단, 가맹시설 선정 취소, 목적 외 사용금액 환수 가능

따라서 `3개월 선납 가능`, `연말 잔액 미리 결제` 같은 영업 문구는 금지한다.

## 3. 상태 모델

### 시설 상태

- `FACILITY_ELIGIBILITY_UNVERIFIED`: 지점별 공개 조회와 관리자 확인 전
- `FACILITY_LISTED`: 공식 시설 조회에서 지점 확인
- `COURSE_LISTED`: 해당 지점의 현재 유도 강좌 확인
- `PAYMENT_READY`: 온라인 결제 흐름과 담당자 확인
- `ATTENDANCE_READY`: 출석 입력 책임·기한·검수 확인
- `SETTLEMENT_READY`: 정산·환수·취소 처리 책임 확인
- `MARKETING_READY`: 공개문구와 실제 상태 일치 승인
- `PAUSED`: 강좌 미운영, 정보 불일치, 정산 예외 등으로 신규 홍보 중단

### 이용자 사건 상태

- `INQUIRY_ONLY`
- `ELIGIBILITY_SELF_REPORTED`
- `SELECTED_BY_AUTHORITY`
- `COURSE_SELECTED`
- `ONLINE_PAYMENT_CONFIRMED`
- `ATTENDANCE_VERIFIED`
- `REFUND_OR_REVERSAL`
- `SETTLED`

문의자의 말만으로 `SELECTED_BY_AUTHORITY`나 `ONLINE_PAYMENT_CONFIRMED`를 만들지 않는다.

## 5. Acquisition Marketer — 공개 전 게이트

다음 순서를 모두 통과해야 이용권 관련 신규획득 콘텐츠를 공개할 수 있다.

`지점 가맹 확인 → 강좌 운영 확인 → 공개 가격 일치 → 온라인 결제 확인 → 출석 담당 확인 → 정산·환수 책임 확인 → 대표 승인 → 채널별 게시`

### 허용 가능한 문구 방향

지점·강좌 상태가 확인된 경우에만:

- 해당 지점에서 이용권으로 신청 가능한 유도 강좌 확인 방법
- 공식 홈페이지에서 시설·강좌를 조회하는 순서
- 온라인 결제와 실제 수강 전 확인할 항목
- 문의 시 지점·연령·희망 시간대를 확인하는 방법

### 금지 문구

- 모든 파이널유도 지점에서 사용 가능
- 이용권 대상자는 자동 등록
- 자동신청하면 2027년 지원 확정
- 현장에서 카드 결제 가능
- 남은 지원금 선결제 가능
- 출석하지 않아도 결제 가능
- 무료 수업 또는 전액 지원 보장
- 선정·지원기간·잔액·본인부담금에 대한 근거 없는 단정

## 6. CRM Marketer — 보호자·회원 후속

이용권 문의는 일반 광고성 CRM과 분리한다.

- 제도 문의 답변과 마케팅 수신 동의를 분리
- 선정·카드·결제 상태는 이용자 또는 보호자가 공식 화면에서 확인
- 도장은 필요한 서비스 제공 범위를 넘어 수급자격 증빙을 복제·보관하지 않음
- 결제 실패를 미납 또는 등록 포기로 자동 분류하지 않음
- 출석 누락이 발견되면 실제 수업 참여 증거와 시스템 기록을 먼저 대조
- 2~3개월 미사용자는 지원 중단 가능성을 사실 안내할 수 있으나, 확인되지 않은 자동 중단을 단정하지 않음
- 일반 회원권 전환 제안은 별도 동의·가격·혜택 승인을 거쳐야 함

고객 메시지는 대표 승인 전 발송하지 않는다.

적합한 콘텐츠는 제도 홍보가 아니라 `유도 입문 보호자가 첫 문의 전에 확인할 것` 같은 일반 안내다. 실제 지점 이용 가능 여부를 넣으려면 별도 승인과 지점별 근거가 필요하다.

- 마감 임박·잔여석 표현은 실제 좌석과 공식 일정이 연결된 경우에만 사용

## 8. Experiment Manager

### EXP-331 — 스포츠강좌이용권 지점 적격성·운영 완전성

대상: 실제 이용권 경로 검토 지점 1곳부터 시작

0단계는 읽기 전용 검증이며 시설 등록, 강좌 등록, 가격 변경, 고객 연락, 결제를 실행하지 않는다.

성공 기준:

- 지점과 공식 시설 등록 일치율 100%
- 강좌명·가격·운영시간 일치율 100%
- 온라인 결제 경로 확인율 100%
- 출석·취소·환수 담당 지정률 100%
- 자동신청과 자동선정의 혼동 0건
- 선결제 유도 0건
- 승인 없는 고객 연락 0건
- 개인정보의 공개 저장소 유입 0건

중단 기준:

- 공식 조회와 실제 지점 정보 불일치
- 미운영 강좌가 신청 가능 상태로 노출
- 현장 결제 또는 미래 강좌 선결제를 요구
- 실제 출석 없이 출석 처리
- 보호자·이용자 자격정보의 과다 수집
- 정산·환수 책임자 부재

문의율·등록률·3개월 지속률·순수납 목표는 `데이터 미연결`이다.
