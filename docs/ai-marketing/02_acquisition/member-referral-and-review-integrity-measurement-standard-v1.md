# 회원 추천·리뷰 무결성 및 성과 측정 기준 v1

- 문서 상태: 공개 운영 기준 초안
- 적용 범위: 파이널유도멀티짐의 회원 추천, 공개 리뷰 요청, 추천 유입 성과 측정
- 최초 기준일: 2026-09-14
- 최근 정책 검수: 2026-09-16
- 소유 역할: CMO / Growth Analyst / Acquisition / CRM / Auditor

## 1. 목적

기존회원의 만족을 신규 체험 문의로 연결하되 다음 사건을 서로 바꾸어 기록하지 않는다.

1. 만족 신호 확인
2. 공개 리뷰 요청
3. 리뷰 게시 또는 신고
4. 회원의 지인 추천
5. 추천받은 사람의 자발적 문의
6. 체험 예약
7. 실제 체험 참석
8. 등록 계약
9. 검증 결제
10. 추천 보상 자격과 실제 지급

리뷰 수나 별점은 추천 문의·등록·매출의 증거가 아니다. 추천 링크 공유도 실제 문의가 아니다.

## 2. 우선 원칙

### 2.1 리뷰와 추천 프로그램 분리

- 리뷰 요청은 실제 경험을 솔직하게 남길 선택권을 안내하는 행위다.
- 추천 프로그램은 회원이 지인에게 공개 링크나 추천 코드를 공유하는 별도 활동이다.
- 리뷰 작성·별점·내용을 추천 보상의 조건으로 묶지 않는다.
- 긍정 리뷰만 요청하거나 부정 리뷰를 내부 채널로 돌리는 리뷰 게이팅을 금지한다.
- 리뷰 수정·삭제·긍정 평가의 대가로 금전, 할인, 무료 상품·서비스를 제공하지 않는다.
- 리뷰 요청 대상은 만족도·불만 여부·긍정 평가 가능성이 아니라 검증된 실제 경험과 연락 적격성으로 정한다.
- 현장에서 리뷰 작성을 요구하거나 압박하지 않고, 직원에게 리뷰 수량 할당량을 부여하지 않는다.
- 특정 별점, 문구, 코치 이름, 키워드 또는 사진을 리뷰에 넣도록 요청하지 않는다.

### 2.2 개인정보 최소화

- 추천인은 지인의 연락처를 임의로 제출하지 않는다.
- 기본 경로는 추천인이 공개 링크 또는 코드를 공유하고, 지인이 직접 문의하는 방식이다.
- 내부 분석에는 비식별 추천 ID와 지점 코드만 사용한다.
- 이름, 전화번호, 보호자 정보, 개인별 출석·건강·결제 원장은 공개 저장소에 기록하지 않는다.
- 미성년자와 보호자 대상 운영은 별도 동의·연락 기준 승인 전 실행하지 않는다.

### 2.3 보상은 승인 후 별도 운영

추천 보상이 있다면 대표 승인 전에는 공지·약속·지급하지 않는다. 승인 문서에는 다음이 있어야 한다.

- 대상 회원과 추천받은 사람의 자격
- 자격 발생 사건
- 중복·자기추천·직원추천 처리
- 적용 지점과 유효기간
- 지급 형태, 금액 또는 수량, 예산
- 환불·취소·차지백 발생 시 처리
- 지급 담당, 지급 기한, 증빙 원천
- 종료 또는 변경 공지 기준

## 5. 판정 게이트

### 5.1 유효 추천 문의

아래를 모두 충족해야 한다.

1. 문의자가 직접 연락했다.
2. 승인된 추천 ID 또는 코드가 문의에 연결됐다.
3. 테스트·스팸·중복이 아니다.
4. 자기추천이 아니다.
5. 유입 시각과 지점이 기록됐다.

추천인이 지인의 연락처만 전달한 건은 직접 문의로 계산하지 않는다.

### 5.2 추천 등록

아래를 모두 충족해야 한다.

1. REFERRED_TRIAL_ATTENDED 또는 대표가 승인한 직접등록 경로가 있다.
2. 계약 기준원천에 유효 계약이 있다.
3. 추천 문의와 계약의 연결 근거가 있다.
4. 중복·이전회원·지점이동 규칙을 통과했다.

예약, 참석 의사, 결제 시도만으로 등록을 확정하지 않는다.

### 5.3 추천 순수납

- 검증 결제에서 환불·차지백을 차감한다.
- 세금·수수료 포함 방식은 회계 기준 승인 후 적용한다.
- 추천 보상 비용과 광고·제작비는 별도 비용 원천에서 연결한다.
- 연결되지 않은 금액은 데이터 미연결로 남긴다.

### 5.4 중립적 리뷰 요청 적격성

아래를 모두 충족할 때만 `REVIEW_REQUEST_ELIGIBLE`로 판정한다.

1. 실제 수업·체험·서비스 경험이 기준 시스템에서 확인된다.
2. 승인된 요청 문구와 채널을 사용한다.
3. 수신동의·수신중단·연락 빈도 기준을 통과한다.
4. 만족도·불만·별점 예상치로 대상을 거르지 않는다.
5. 리뷰 작성 여부와 별점·문구에 어떤 혜택도 연결하지 않는다.
6. 현장에서 즉시 작성하도록 압박하지 않는다.
7. 특정 별점·표현·코치 이름·사진을 넣도록 요구하지 않는다.

`REVIEW_REQUEST_SENT`는 발송 사실일 뿐 리뷰 게시, 추천, 문의 또는 매출이 아니다.

## 6. 채널별 실행 기준

### Instagram 코치 개인 계정

- 코치 개인의 공개 콘텐츠를 공유할 수 있는 경로만 제안한다.
- 공식 지점 혜택이나 보상 조건을 미확인 상태로 약속하지 않는다.
- 공개 댓글·DM 반응을 추천 문의로 자동 판정하지 않는다.
- 회원 식별 촬영물은 공개 사용 동의가 확인되지 않으면 사용하지 않는다.

### 네이버·Google

- 동일한 승인 적격성 기준을 통과한 실제 경험자에게 만족도와 관계없이 중립적으로 요청할 수 있다.
- 긍정 평가, 특정 문구·키워드·코치 이름, 별점, 리뷰 수정·삭제를 요구하지 않는다.
- 직원별 리뷰 수량 목표를 두거나 현장에서 작성을 압박하지 않는다.
- 리뷰와 추천 보상을 연계하지 않는다.
- 플랫폼 리뷰 수·별점은 문의·등록·매출 KPI와 별도 보고한다.

### 당근·웹사이트

- 승인된 공개 링크와 프로그램 조건만 사용한다.
- 지점, 기간, 자격, 중복 처리 기준을 동일하게 표시한다.
- 클릭 수를 문의나 방문으로 계산하지 않는다.

### CRM

- 추천 ID와 최초 유입원을 보존한다.
- 체험 예약·참석·등록·결제·순수납을 각각 다른 사건으로 기록한다.
- 연락 동의와 수신중단 상태를 우선 적용한다.

## 8. 실험 EXP-301

### 이름

회원 추천·리뷰 무결성 기준선

### 대상

대표 승인 후 최초 14일의 비식별 추천 코호트

### 성공 기준

- 유효 추천 문의의 referral_id 기록률 100%
- 최초 유입원·지점 기록률 100%
- 중복·자기추천 검토율 100%
- 리뷰 인센티브·긍정 리뷰 강요·리뷰 게이팅 0건
- 제3자 연락처의 무동의 수집·사용 0건
- 보상 지급 증빙률 100%
- 공개 개인정보 0건
- 예약·참석·등록·결제 혼합 판정 0건

### 보류 기준

- 프로그램 조건·예산·자격 사건 미승인
- 연락 동의·중복·자기추천 규칙 미확정
- 문의·계약·결제 기준 시스템 미지정
- 지점별 운영 책임자 미지정

### 중단 기준

- 리뷰 작성·별점·내용과 보상을 연계
- 허위 리뷰 또는 이해관계 충돌 리뷰 요청
- 승인 없는 할인·무료 제공·보상 지급
- 지인의 연락처를 동의 없이 마케팅에 사용
- 미검증 계약·결제를 등록·매출로 기록

### EXP-333 중립 리뷰 요청 적격성 감사

#### 대상

대표 승인 후 최초 14일의 비식별 리뷰 요청 후보. 실제 발송 전에는 합성 레코드 12건으로만 검증한다.

#### 성공 기준

- 실제 경험 확인률 100%
- 만족도·불만 여부를 이용한 대상 선별 0건
- 리뷰 인센티브·직원 할당량·현장 작성 압박 0건
- 특정 별점·문구·코치 이름 요구 0건
- 수신동의·수신중단·빈도 판정 기록률 100%
- 요청·게시·문의·등록·순수납의 상태 혼합 0건

#### 보류·중단 기준

- 실제 경험·연락 적격성 기준 시스템 미지정 시 보류
- 긍정 리뷰만 요청하거나 부정 경험자를 제외하면 중단
- 리뷰 작성·수정·삭제에 혜택을 연결하면 중단
- 현장 작성 압박, 직원별 수량 목표 또는 특정 내용 요구가 확인되면 중단

리뷰 게시율·문의율·등록률·순수납 목표는 **데이터 미연결**이다.

## 9. 대표 승인 체크리스트

- 추천 프로그램 운영 여부

## 10. 감사 메모

- 추천을 등록으로, 리뷰를 추천으로, 결제를 순수납으로 표현하지 않는다.
- 외부 사례의 보상 수준·전환율·발송 빈도는 파이널유도의 목표로 적용하지 않았다.
- 승인 대기 Instagram 미디어·캡션과 미확정 행사·혜택은 이 공개 문서에 포함하지 않았다.
- 개인정보·민감 원장은 공개 저장소 대상이 아니다.
