# 지역 리뷰 요청·답글·진정성·보상·귀속 기준 v1

- 적용 범위: 파이널유도멀티짐의 네이버 플레이스·Google Business Profile·당근·기타 지역 리뷰 채널
- 문서 목적: 실제 경험에 근거한 비선별 리뷰 요청, 개인정보를 노출하지 않는 답글, 어뷰징·보상성 후기 방지와 문의·체험·등록 귀속을 관리한다.
- 기존 기준과의 경계: `member-feedback-complaint-service-recovery-satisfaction-and-renewal-standard-v1.md`는 불만 접수와 서비스 회복 전체를 다루며, 이 문서는 공개 리뷰 요청·답글·신고·복구와 지역 획득 측정에 한정한다.
- 공개 제외: 회원·보호자 식별정보, 연락처, 리뷰 작성자 대응 이력, 상담 원문, 개인별 출석·건강·결제 원장, 관리자 계정, 승인 대기 Instagram 콘텐츠
- 작성일: 2026-09-17
- 내부 리뷰·문의·매출 데이터: **데이터 미연결**

## 1. 핵심 판단

다음은 서로 같은 사건이 아니다.

`리뷰 요청 적격성 확인 ≠ 요청 승인 ≠ 요청 발송 ≠ 전달 ≠ 리뷰 작성 ≠ 플랫폼 노출 ≠ 사업주 답글 ≠ 리뷰 수정·삭제 ≠ 프로필 방문 ≠ 문의 ≠ 체험 예약 ≠ 실제 방문 ≠ 등록 계약 ≠ 실수납`

리뷰 수나 평균 별점을 신규회원·만족·재등록·매출로 계산하지 않는다. 실제 경험자에게 중립적으로 요청할 수는 있지만, 할인·무료 서비스·보상과 교환하거나 긍정 경험자만 골라 요청하지 않는다. 부정 리뷰의 수정·삭제를 서비스 회복이나 보상 조건으로 삼지 않는다.

관리 순서는 다음과 같다.

`실제 경험 확인 → 연락 적격성·수신거부 확인 → 비선별 대상 규칙 적용 → 중립 문구 승인 → 발송·전달 분리 → 자발적 리뷰 노출 확인 → 답글 위험 분류 → 사실·개인정보 검수 → 공개 답글 승인·게시 → 문의·체험·등록·실수납 별도 귀속`

## 2. 네 목표와의 연결

| 목표 | 리뷰 운영이 제공할 수 있는 신호 | 별도로 확인할 성과 |
|---|---|---|
| 신규 체험회원 확보 | 지역 프로필의 실제 경험 정보 | 프로필 방문·직접 문의·예약·실방문·신규 실수납 |
| 휴면회원 복귀 | 과거 경험에서 반복되는 장벽 | 복귀 의사·예약·실제 참여·복귀 실수납 |
| 기존회원 재등록·만족 | 수업·응대·시설의 공개 피드백 | 해결 확인·만족 응답·재등록 계약·실수납 |
| 매출 증대 | 지역 신뢰와 문의 보조 접점 | 중복 제거된 귀속 순수납·증분 순수납 |

리뷰가 존재한다는 사실은 해당 이용자가 만족했다는 내부 조사 응답이 아니며, 리뷰 미작성은 불만이나 이탈이 아니다.

## 3. 공개 정책에서 확인한 기준

### 3.1 Google Maps

Google은 리뷰가 실제 장소·사업에 대한 진짜 경험을 반영해야 한다고 명시한다. 다음은 허용되지 않는다고 안내한다.

- 실제 경험에 근거하지 않은 리뷰
- 현금·할인·무료 상품·무료 서비스 등 대가를 제공한 리뷰
- 리뷰 수정·삭제와 보상을 교환하는 행위
- 부정 리뷰를 막거나 긍정 고객만 선별해 요청하는 행위
- 직원에게 리뷰 수량 목표나 특정 문구·직원명 언급을 요구하는 행위
- 한 사람이 여러 계정으로 게시하거나 경쟁사를 훼손하는 행위

Google은 보상이나 별점·내용 유도 없이 실제 경험을 중립적으로 요청하는 것은 허용한다고 설명한다. 따라서 `리뷰를 써 주세요`와 `별점 5점·코치 이름을 넣어 주세요`는 같은 요청이 아니다.

### 3.2 네이버 스마트플레이스

네이버 사업주 고객센터는 방문자 리뷰, 영수증 리뷰 답글, 비방성·명예훼손 리뷰 제외 요청과 업체 단위 비정상 행위 페널티를 별도 항목으로 운영한다. 따라서 리뷰가 불편하다는 이유와 정책 위반 신고 대상이라는 판단을 구분한다.

- 답글 작성과 리뷰 제외 요청은 다른 절차다.
- 리뷰 수 감소는 삭제·미노출·정책 처리 여부를 확인하기 전 성과 하락으로 단정하지 않는다.
- 업체 단위 페널티 관련 안내가 존재하므로 대행사를 통한 대량 리뷰·영수증 생성·반복 패턴은 금지한다.
- 네이버의 실제 노출 기준·페널티 적용 여부는 권한 있는 계정과 공식 안내에서 확인하기 전 추정하지 않는다.

### 3.3 체육시설 사례의 한계

2026년 지역 체육시설 자료는 최신 프로필과 리뷰가 발견·신뢰에 도움을 줄 수 있다고 설명하지만, 외부 리뷰 수·응답률·등록률을 파이널유도 목표로 복사하지 않는다. 리뷰는 문의·체험·등록으로 이어질 수 있는 보조 접점일 뿐 직접 매출이 아니다.

## 4. 리뷰 요청 대상 게이트

요청 후보마다 아래를 모두 확인한다.

1. 실제 체험·수업·시설 이용 경험이 기준 원천으로 확인됐다.
2. 잘못된 지점이나 다른 지점 링크를 보내지 않는다.
3. 운영안내와 광고성 리뷰 요청을 구분하고 적법한 연락 근거를 확인한다.
4. 통합 수신거부·채널 수신거부·보호자 권한을 확인한다.
5. 안전·아동 보호·개인정보·결제 분쟁이 진행 중이면 일반 리뷰 요청에서 제외한다.
6. 미해결 불만을 숨기기 위해 긍정 고객만 고르지 않는다.
7. 별점·특정 문구·코치 이름·사진·해시태그를 요구하지 않는다.
8. 할인·쿠폰·승급·도복·무료 수업·추첨 응모를 리뷰 조건으로 제공하지 않는다.
9. 현장에서 즉시 작성하도록 압박하거나 작성 화면을 검사하지 않는다.
10. 이미 요청했거나 작성 여부가 불명확한 사람에게 반복 압박하지 않는다.

적격성 자료가 없으면 `ELIGIBILITY_UNVERIFIED`, 연락 근거가 없으면 `CONTACT_NOT_ALLOWED`다.

## 5. 최소 상태 모델

### 5.1 요청 준비·발송

| 상태 | 의미 | 금지되는 오분류 |
|---|---|---|
| `EXPERIENCE_UNVERIFIED` | 실제 이용 경험 미확인 | 요청 가능 |
| `EXPERIENCE_VERIFIED` | 승인된 원천으로 실제 경험 확인 | 만족 고객 확정 |
| `CONTACT_ELIGIBILITY_REVIEW` | 연락 목적·동의·수신거부 확인 중 | 발송 허가 |
| `REQUEST_ELIGIBLE` | 비선별 규칙과 연락 조건 통과 | 발송 완료 |
| `REQUEST_APPROVED` | 문구·채널·지점 링크 승인 | 전달 완료 |
| `REQUEST_SENT` | 플랫폼·메시지 발송 실행 | 전달·열람 |
| `REQUEST_DELIVERED` | 전달 원천 확인 | 리뷰 작성 |
| `REQUEST_FAILED` | 결번·차단·기술 실패 | 고객 거절 |
| `DO_NOT_REQUEST` | 수신거부·고위험·권한 미확인 등 제외 | 부정 리뷰 예상자 |

리뷰를 쓰지 않은 사람에게 후속 광고를 자동 확대하지 않는다.

### 5.2 리뷰·답글·신고

| 상태 | 의미 |
|---|---|
| `REVIEW_OBSERVED` | 공개 리뷰가 보이는 시각과 채널 확인 |
| `REVIEW_PLATFORM_HIDDEN` | 플랫폼에서 미노출·제한 상태로 보임 |
| `RESPONSE_TRIAGE` | 일반·사실확인·고위험 분류 중 |
| `RESPONSE_DRAFTED` | 공개 답글 초안, 미게시 |
| `RESPONSE_APPROVED` | 지정 권한자가 게시본 승인 |
| `RESPONSE_POSTED_VERIFIED` | 실제 공개 답글을 다시 확인 |
| `PRIVATE_HANDOFF_OFFERED` | 공개 답글에서 공식 비공개 경로 안내 |
| `POLICY_REPORT_REVIEW` | 정책 위반 신고 근거 검토 중 |
| `POLICY_REPORT_SUBMITTED` | 플랫폼에 신고 제출 |
| `PLATFORM_DECISION_PENDING` | 플랫폼 판단 대기 |
| `PLATFORM_ACTION_VERIFIED` | 삭제·복원·유지 등 실제 결과 확인 |

신고 제출을 리뷰 삭제로, 답글 게시를 문제 해결로 집계하지 않는다.

## 6. 중립 요청 문구 기준

공개 저장소에는 템플릿 구조만 둔다. 실제 발송은 대표 승인과 연락 적격성 확인 후 진행한다.

필수 요소:

- 실제 이용 경험에 대한 자발적 의견 요청
- 긍정·부정 어느 방향도 유도하지 않는 표현
- 특정 별점·문구·코치명 요구 없음
- 보상·혜택 조건 없음
- 정확한 지점 링크
- 작성 여부가 서비스·승급·예약·환불에 영향을 주지 않음

금지 예시:

- `별점 5점 부탁드립니다`
- `좋았던 분만 리뷰를 남겨 주세요`
- `코치 이름과 유도 키워드를 꼭 써 주세요`
- `리뷰 작성 시 무료 수업·할인·추첨 제공`
- `리뷰 화면을 직원에게 보여 주세요`
- `부정 리뷰를 지우면 환불·보상하겠습니다`

## 7. 공개 답글 기준

### 7.1 모든 답글

- 작성자 이름 외에 출석·회원권·결제·부상·건강·보호자 관계를 공개하지 않는다.
- 실제 회원인지 공개 댓글에서 확인하거나 반박하지 않는다.
- 짧고 중립적으로 읽은 내용을 확인하고, 필요한 경우 공식 비공개 채널을 안내한다.
- 사실 확인 전 책임 인정·법률 판단·보상 약속을 확정하지 않는다.
- 지점과 답글 주체를 명확히 하고 코치 개인 계정이 브랜드 공식 결정을 대신 발표하지 않는다.

### 7.2 긍정 리뷰

- 복사·붙여넣기식 과도한 홍보 문구를 넣지 않는다.
- 다음 구매·재등록·추천·태그를 압박하지 않는다.
- 리뷰 내용을 회원 사례나 광고 소재로 재사용하지 않는다. 별도 공개 동의와 사용 범위가 필요하다.

### 7.3 부정 리뷰

- 방어적 논쟁, 작성자 비난, 공개 증거 제시를 피한다.
- 사실과 감정 평가를 구분하되 경험 자체를 무효화하지 않는다.
- 안전·아동 보호·개인정보·결제 사건은 일반 답글 자동화에서 제외한다.
- 해결·환불·보상은 비공개 사실 확인과 권한 승인 후 처리한다.
- 수정·삭제를 해결 조건으로 요구하지 않는다.

### 7.4 허위·무관·위반 의심 리뷰

- `기억에 없다`는 이유만으로 허위라고 확정하지 않는다.
- 예약·출석·결제 원천을 비공개로 대조하되 공개 답글에 세부정보를 쓰지 않는다.
- 정책 위반 범주와 증거를 기록하고 플랫폼 절차로 신고한다.
- 경쟁사·직원·가족 관계를 추정해 공개적으로 지목하지 않는다.

## 8. 다지점 운영 원칙

- 리뷰 요청 링크는 실제 이용 지점과 일치해야 한다.
- 본관이 지점 리뷰에 답할 때 승인된 주체와 담당 지점을 확인한다.
- 같은 사건이 여러 지점에 게시되면 삭제 요구보다 사건 계보와 대응 책임을 먼저 연결한다.
- 한 지점의 리뷰 수를 다른 지점의 획득 성과로 합산하지 않는다.
- 지점 이동 회원의 리뷰를 신규 획득으로 분류하지 않는다.
- 지점별 리뷰량 경쟁이나 직원별 할당량을 두지 않는다.

## 9. 채널별 역할

### 네이버

- 방문자 리뷰·영수증 리뷰·예약 리뷰의 플랫폼 정의를 보존한다.
- 답글 등록과 정책 신고·제외 요청을 별도 상태로 기록한다.
- 리뷰 수 감소는 원인 확인 전 삭제·성과 하락으로 단정하지 않는다.
- 대행사의 영수증·계정·대량 리뷰 생성 제안을 사용하지 않는다.

- 실제 경험자에게 보상 없이 중립 요청한다.
- 긍정 고객만 선별하는 review gating을 금지한다.
- 특정 별점·내용·직원명·리뷰 수량 목표를 요구하지 않는다.

- 코치 개인 계정의 댓글을 도장 공식 리뷰로 집계하지 않는다.
- 댓글·저장 CTA와 별점·후기 요청을 구분한다.
- 회원 경험·변화를 캡션 소재로 재사용하려면 별도 동의와 사실 근거가 필요하다.
- 공개 댓글의 분쟁을 개인 코치가 공식 책임 인정·보상 결정으로 답하지 않는다.

## 13. EXP-354 — 리뷰 요청·답글·정책·귀속 완전성

### 대상

실제 고객·계정 없이 합성 리뷰 여정 48건을 사용한다.

### 시나리오

- 실제 경험이 확인되지 않은 요청 후보
- 긍정 고객만 선별된 목록
- 별점 5점·코치 이름을 요구하는 문구
- 할인·무료수업·쿠폰과 리뷰를 교환하는 문구
- 수신거부자·미성년자 보호자 권한 미확인 대상
- 다른 지점 링크가 포함된 요청
- 발송됐으나 전달되지 않은 요청
- 긍정·부정·사실불명·안전·개인정보 리뷰
- 답글 게시와 정책 신고가 동시에 필요한 사건
- 리뷰는 있으나 문의·방문·등록이 없는 여정
- 동일인이 네이버·Google·전화로 문의한 여정

### 성공 기준

- 실제 경험 미확인 대상의 요청 적격 오분류 0건
- 긍정 고객 선별 또는 부정 고객 제외 0건
- 별점·특정 문구·직원명 강요 0건
- 리뷰와 보상·혜택 교환 0건
- 수신거부·보호자 권한 누락 0건
- 다른 지점 링크 발송 0건
- 발송의 전달·리뷰 작성 오분류 0건
- 답글의 문제 해결 오분류 0건
- 신고 제출의 삭제 완료 오분류 0건
- 공개 답글의 개인정보·건강·결제정보 노출 0건
- 리뷰·문의·예약의 신규 실수납 오분류 0건
- 승인 없는 실제 요청·답글·신고·혜택 제공 0건

### 중단 기준

- 실제 회원·보호자 데이터 사용
- 리뷰 대행·영수증 생성·다중계정 사용

- 승인 대기 Instagram 콘텐츠의 외부 업로드

리뷰 요청률·작성률·문의율·등록률·순수납 목표는 **데이터 미연결**이다.
