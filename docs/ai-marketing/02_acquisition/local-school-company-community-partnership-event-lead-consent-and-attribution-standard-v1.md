# 지역 학교·기업·커뮤니티 제휴·행사·리드·동의·귀속 기준 v1

- 문서 상태: 공개 가능한 운영 초안
- 기준일: 2026-09-17
- 적용 대상: 파이널유도멀티짐의 학교·학원·기업·아파트·주민센터·지역단체 등 기관 제휴 검토
- 목적: 지역 제휴를 개인정보 목록 구매나 단체 연락 수단이 아니라, 승인된 프로그램과 개인의 자발적 문의를 통해 신규 체험·복귀·재등록·실수납으로 연결하는 측정 가능한 경로로 운영한다.
- 제외: 실제 기관명·담당자·연락처, 미성년자 명단, 건강정보, 가격표·계약·결제 원장, 미확정 FINAL ROAD, 승인 대기 Instagram 콘텐츠

## 1. 핵심 원칙

1. 기관 제휴는 회원 추천과 다른 경로다.
   - 회원 추천: 개인이 개인을 소개하는 관계 기반 경로
   - 기관 제휴: 권한 있는 기관과 범위·책임·데이터 처리를 합의하는 경로
2. 기관의 협력 의사나 행사 승인은 참여자 개인의 광고 수신 동의를 대신하지 않는다.
3. 기관이 보유한 학생·직원·입주민 명단을 전달받아 마케팅 연락에 사용하지 않는다.
4. 행사 참석자는 자동으로 리드·체험회원·등록회원·매출이 되지 않는다.
5. 기관 로고·명칭·후원·협약·추천 표현은 상대 기관의 공개 승인 전 사용하지 않는다.
6. 미성년자 참여에는 보호자 권한, 공개 촬영 동의, 안전 책임과 비상 연락 절차를 분리해 확인한다.
7. 실제 프로그램의 가격·일정·좌석·혜택은 기준 시스템과 승인 버전이 확인될 때만 공개한다.

## 2. 제휴 유형과 목적

| 유형 | 가능한 공개 목적 | 별도 확인 사항 |
|---|---|---|
| 학교·학원 | 유도 가치·기초 움직임 소개, 승인된 체험 프로그램 | 학교 권한자, 보호자 동의, 아동 보호, 촬영, 시설·보험 |
| 기업·직장 | 구성원 대상 승인 프로그램 또는 복지 제휴 | 회사의 권한, 직원 개인 동의, 비용 부담 주체, 세금·계약 |
| 아파트·주민센터 | 지역 주민 대상 공개 체험·교육 행사 | 공간 사용, 안전 정원, 참가 신청 주체, 지역 광고 승인 |
| 지역 상점·단체 | 상호 홍보 또는 공동 행사 | 보상·추천료, 로고 사용, 리드 소유권, 과장 표현 |
| 체육·문화기관 | 공동 프로그램, 시설·강사 협력 | 지도 자격, 수업 책임, 일정 변경, 수납·환불 귀속 |

제휴 유형은 내부 추적용 분류이며 실제 제휴 가능성이나 성과를 뜻하지 않는다.

## 3. 필수 상태 흐름

다음 상태는 합치거나 건너뛰지 않는다.

1. `PARTNER_PROSPECT` — 기관 후보를 공개 정보로 식별
2. `AUTHORITY_UNVERIFIED` — 담당자 신원·대표 권한 미확인
3. `AUTHORITY_VERIFIED` — 협의 권한 확인
4. `SCOPE_DRAFTED` — 목적·대상·역할·비용·데이터 흐름 초안
5. `SAFETY_AND_DATA_REVIEWED` — 안전·보호자·개인정보·촬영 검토
6. `PARTNER_APPROVED` — 상대 기관이 범위를 승인
7. `FINAL_INTERNAL_APPROVED` — 내부 승인 완료
8. `PUBLICATION_VERIFIED` — 승인된 안내가 실제 채널에 반영됐음을 확인
9. `PARTICIPANT_REGISTERED` — 개인 또는 보호자가 직접 참가 신청
10. `EVENT_ATTENDED` — 실제 참석 확인
11. `INQUIRY_CREATED` — 별도 문의 의사 확인
12. `TRIAL_BOOKED` — 체험 예약 확정
13. `TRIAL_ATTENDED` — 실제 체험 참여
14. `CONTRACT_SIGNED` — 계약 체결
15. `PAYMENT_SETTLED` — 실수납 확인
16. `REFUNDED_OR_CHARGEDBACK` — 환불·차지백 반영

기관 승인만으로 `PUBLICATION_VERIFIED`, `PARTICIPANT_REGISTERED` 또는 `INQUIRY_CREATED`로 올리지 않는다. 행사 참석을 체험 참석으로, 계약을 실수납으로 오분류하지 않는다.

## 4. 기관 후보와 권한 확인

기관 후보는 공식 홈페이지·공식 지도 프로필·공공기관 목록 등 공개 출처로만 조사한다. 개인 휴대전화나 비공개 명단을 저장하지 않는다.

권한 확인 최소 항목:

- 기관 공식 명칭과 유형
- 공식 도메인 또는 공식 대표번호
- 협의 담당자의 역할과 제휴 협의 권한
- 계약·홍보·개인정보·촬영 승인권자가 각각 누구인지
- 다지점 기관이면 적용 지점과 적용 기간
- 기관 명칭·로고·사례 공개 가능 범위

담당자가 개인 계정으로 연락했다는 사실만으로 기관 권한을 확정하지 않는다.

## 5. 데이터와 동의 기준

### 5.1 수집하지 않는 기본값

- 기관의 전체 학생·직원·입주민·회원 명단
- 동의 상태가 확인되지 않은 전화번호·이메일·메신저 ID
- 개인별 건강·부상·장애·출석·결제 정보
- 미성년자의 학교·학년·반과 보호자 연락처를 결합한 목록
- 행사 현장에서 촬영된 식별 가능 얼굴의 무승인 공개 파일

### 5.2 개인이 직접 신청할 때의 최소 항목

- 신청 식별자
- 대상 지점 또는 프로그램
- 신청 시각과 출처 코드
- 연락 목적과 동의 버전
- 보호자 권한 상태가 필요한 경우 그 확인 상태
- 예약·취소·참석 상태

실제 필수 항목과 보유기간은 대표·개인정보 책임자의 승인 전 `DATA_SCHEMA_UNSET`으로 둔다.

### 5.3 제3자 제공

기관과 체육관 사이에 개인 데이터가 이동한다면 제공받는 자, 이용 목적, 제공 항목, 보유·이용 기간, 거부권과 불이익을 확인한다. 법적 근거가 불명확하면 명단 전달 대신 개인이 직접 신청하는 공개 링크·QR 경로를 기본으로 한다.

### 5.4 연락 동의

참가 안내, 안전 연락, 예약 운영, 광고성 후속 연락을 구분한다. 행사 참가 동의가 장기 광고 수신 동의가 되지 않으며, 수신거부가 발생하면 해당 광고 후속 큐에서 제외한다.

## 6. 미성년자·안전·촬영 게이트

미성년자 대상 프로그램은 다음이 모두 확인되기 전 공개 모집을 시작하지 않는다.

- 프로그램 책임 기관과 현장 책임자
- 지도 코치 자격·역할·대상 연령
- 시설·매트·안전 정원·보조 인력
- 응급 대응과 보호자 연락 절차
- 보험·책임 범위와 사고 보고 경로
- 보호자 동의와 인계·귀가 기준
- 사진·영상 촬영 여부와 공개 사용 동의
- 건강정보가 필요한 경우 별도 민감정보 처리 검토

촬영 동의가 없거나 상태가 불명확하면 코치 단독, 손발, 도복, 매트, 공간 중심 촬영안만 사용한다.

## 7. 프로그램·행사 공개 게이트

공개 전 필수 확인:

- `scope_version` — 목적·대상·내용 버전
- `schedule_version` — 날짜·시간·장소
- `capacity_version` — 안전·운영·예약 가능 정원
- `price_version` — 무료·유료·포함·제외 비용
- `cancellation_version` — 취소·변경·환불 기준
- `rights_version` — 기관명·로고·사진·후기 사용 권한
- `data_notice_version` — 수집·이용·제공·보유 안내
- `approval_record` — 기관과 내부 승인 기록

하나라도 미확정이면 모집 공지로 공개하지 않고 `PUBLICATION_BLOCKED`로 둔다.

## 9. CRM 분리

다음 대상을 같은 자동화에 섞지 않는다.

- 기관 담당자: 제휴 운영 연락
- 행사 신청자: 참가 운영 연락
- 신규 문의자: 체험 상담
- 체험 후 미등록자: 체험 후속
- 휴면회원: 복귀 여정
- 기존회원: 만족·재등록 여정
- 보호자: 미성년자 권한과 운영 연락

기관 담당자에게 보내는 제휴 연락과 개인 참가자에게 보내는 광고성 후속은 목적·동의·수신거부를 별도로 관리한다.

## 10. 비용·수납 분리

다음 금액은 별도 원장으로 관리한다.

- 기관이 체육관에 지급하는 프로그램비
- 참가자가 기관에 지급하는 금액
- 참가자가 체육관에 지급하는 금액
- 장소·보험·장비·인쇄·광고 비용
- 추천료·후원·현물 제공
- 환불·취소·차지백

협약 체결액, 견적액, 청구액은 실수납이 아니다. 행사 참가자 수와 문의 수는 매출이 아니다. 비용·환불이 연결되지 않으면 ROI는 계산하지 않는다.

## 11. 귀속 기준

### 11.1 필수 식별자

- `partner_id`
- `partnership_version`
- `program_id`
- `event_id`
- `source_channel`
- `source_code`
- `person_id` 또는 개인정보를 노출하지 않는 내부 식별자
- `consent_version`
- `branch_id`
- `booking_id`
- `attendance_id`
- `contract_id`
- `payment_id`

### 11.2 귀속 규칙

- 기관명 언급만으로 제휴 성과로 귀속하지 않는다.
- 승인된 링크·QR·코드 또는 본인 확인 답변으로 유입 근거를 남긴다.
- 직접 유입과 제휴 유입이 겹치면 중복 제거 규칙을 먼저 적용한다.
- 지점 이동은 신규회원으로 재집계하지 않는다.
- 귀속기간은 대표 승인 전 `ATTRIBUTION_WINDOW_UNSET`으로 둔다.
- 귀속성과와 제휴가 없었을 때의 증분성과를 구분한다.

|---|---|---|
| 유효 기관 후보율 | 권한·적합성 확인 후보 / 조사 후보 | 데이터 미연결 |
| 제안 수락률 | 기관 승인 제안 / 전달 확인 제안 | 데이터 미연결 |

| 행사 참석률 | 실제 참석자 / 확정 신청자 | 데이터 미연결 |

| 체험 실방문률 | 실제 체험 참여자 / 체험 예약 확정자 | 데이터 미연결 |

| 복귀율 | 복귀 실참여자 / 적격 휴면회원 | 데이터 미연결 |
| 재등록률 | 재등록 계약자 / 만료 도래 적격회원 | 데이터 미연결 |
| 제휴 CAC | 승인된 제휴 직접비 / 귀속 신규 실수납자 | 계산 불가 |

분자·분모·기간·출처가 없거나 분모가 0이면 계산하지 않는다.

| `consent_version` | 적용 동의 버전 |

| `evidence_ref` | 권한 제한된 근거 위치 |
| `reason_code` | 취소·거절·보류 등의 통제 코드 |

상담 원문·연락처·건강정보는 공개 분석 문서에 넣지 않는다.

## 14. 역할별 운영

- **CMO:** 제휴가 네 목표 중 어느 목표를 우선하는지, 채널·지점·비용 상한을 승인한다.
- **Growth Analyst:** 기관→행사→문의→체험→계약→수납의 상태와 중복을 검증한다.
- **Acquisition Marketer:** 지역·대상·승인 범위에 맞는 안내와 자발적 신청 경로를 설계한다.
- **CRM Marketer:** 행사 운영 연락과 광고 후속을 분리하고 복귀·재등록 대상의 기존 관계를 보존한다.
- **Content Strategist:** 기관·코치·브랜드의 발표 주체와 사용 권리를 채널마다 확인한다.
- **Experiment Manager:** 실제 고객 연락 전에 합성 데이터로 상태·동의·귀속 규칙을 검증한다.
- **Auditor:** 개인정보, 아동 보호, 안전, 가격, 권한, 과장, 중복 집계를 점검한다.
