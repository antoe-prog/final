# 수용능력 기반 체험 모집·대기명단 운영 기준 v1

- 문서 상태: 공개 운영 기준 초안
- 적용 범위: 파이널유도멀티짐 지점별 체험 모집, 예약, 정원, 대기명단, 참석 측정
- 기준일: 2026-09-14
- 소유 역할: CMO / Growth Analyst / Acquisition / CRM / Operations / Auditor

## 1. 목적

홍보 노출이나 문의를 늘리기 전에 실제 수업 수용능력을 확인한다. 다음 사건을 서로 다른 상태로 관리한다.

1. 공개 수업 정보 검증
2. 운영 가능한 수업 확정
3. 안전·지도 기준을 반영한 정원 승인
4. 기존회원 예약
5. 체험 가능 좌석 승인
6. 체험 예약
7. 대기명단 등록
8. 취소 좌석 발생
9. 대기자의 예약 전환
10. 실제 출석
11. 도장 사정 취소
12. 등록과 30일 활성

대기명단, 예약 요청, 예약 확정, 실제 출석은 같은 사건이 아니다.

## 2. 우선 원칙

### 2.1 수용능력 확인 전 모집 금지

수업별 아래 정보가 확인되지 않으면 특정 시각의 체험 가능을 공개하지 않는다.

- 지점 코드와 수업 ID
- 수업 날짜·시작·종료 시각
- 대상 연령 또는 프로그램
- 지도자와 보조 인력 배치
- 승인된 최대 정원
- 기존회원 예약 수
- 승인된 체험 좌석 수
- 공간·매트·안전 기준 확인 상태
- 휴강·대관·행사·공사 여부
- 마지막 검증 시각과 담당 역할

정원 수치는 공개 자료나 다른 지점 값을 복사하지 않는다.

### 2.2 기존회원 경험 보호

- 체험 모집 좌석은 기존회원 이용권과 수업 운영에 영향을 주지 않는 범위에서 별도 승인한다.
- 만석 수업에 광고·콘텐츠 CTA를 집중하지 않는다.
- 대기명단이 길다고 신규회원 수요가 확정됐다고 표현하지 않는다.
- 반복 만석은 추가 수업 검토 신호이지 즉시 증설 또는 매출 증가의 증거가 아니다.
- 지도자 부재나 도장 사정으로 취소된 예약을 고객 노쇼로 처리하지 않는다.

### 2.3 지점별 독립 판정

다지점 전체의 빈자리를 합산해 특정 지점의 체험 가능으로 표현하지 않는다. 지점 이동 제안은 거리·대상·시간·동의가 확인되고 대표가 승인한 경로에서만 수행한다.

### 4.2 계산식

가용 체험 좌석 = 승인 체험 좌석 수 - 확정 체험 예약 수

단, 아래 조건에서는 계산 결과와 관계없이 모집을 중단한다.

- 정원 미검증
- 지도자 배치 미확정
- 휴강·행사·대관 가능성 미해결
- 안전 점검 미완료
- 데이터 동기화 오류
- 기존회원 예약 정책 충돌

가용 좌석이 0이면 대기명단 안내만 가능하며 확정 예약으로 표현하지 않는다.

## 5. 모집 공개 게이트

### 5.1 공개 가능

아래를 모두 충족해야 한다.

1. SESSION_OPEN_VERIFIED 상태다.
2. 지점·수업·대상·시간이 승인된 기준정보와 일치한다.
3. trial_slot_limit가 승인됐다.
4. 문의 또는 예약 경로가 정상 작동한다.
5. 변경·취소 시 안내 책임 역할이 지정됐다.
6. 마지막 검증 시각이 승인된 유효기간 안이다.

### 5.2 공개 보류

- 시간표 또는 대상이 채널마다 다름
- 잔여 좌석 데이터가 오래됨
- 지점 담당자 확인 대기
- 체험 비용·준비물·취소 기준 미확정
- 회원 전용 수업인지 불명확
- 대기명단 규칙 미승인

### 5.3 즉시 중단

- 만석인데 잔여 좌석이 있다고 광고
- 대기명단 등록을 예약 완료로 안내
- 도장 취소를 고객 노쇼로 기록
- 미확인 지도자·시설·안전 상태로 모집
- 승인 없는 할인·무료 체험·우선 입장 약속

## 6. 대기명단 운영

### 6.1 등록

- 대기명단은 수업별로 관리한다.
- 등록 시 순번, 등록 시각, 연락 동의, 만료 시각을 기록한다.
- 여러 수업의 중복 대기는 승인된 중복 규칙을 적용한다.
- 대기 등록 자체로 좌석을 보장하지 않는다.

### 6.2 좌석 제안

- 취소 또는 정원 변경으로 실제 좌석이 생긴 뒤 제안한다.
- 제안 시각, 응답 기한, 제안 순서를 기록한다.
- 자동 또는 수동 제안 방식은 대표 승인 후 적용한다.
- 응답하지 않았다는 이유만으로 관심 없음 또는 휴면으로 판정하지 않는다.

### 6.3 확정

다음 조건을 모두 충족해야 WAITLIST_ACCEPTED_CONFIRMED가 된다.

1. 실제 좌석이 있다.
2. 대상자가 승인된 기한 안에 수락했다.
3. 중복 예약이 없다.
4. 수업 자격과 동의 기준을 통과했다.
5. 예약 시스템에 확정 상태가 기록됐다.

## 7. 채널별 실행 기준

### 네이버·Google·웹사이트

- 시간표는 기준정보와 일치할 때만 공개한다.
- 실시간 잔여 좌석을 제공하지 못하면 “가능 여부 문의”처럼 사실에 맞는 표현을 사용한다.
- 조회·길찾기·전화 클릭을 예약이나 참석으로 계산하지 않는다.

### 당근

- 지점·대상·기간이 승인된 지역 게시물만 사용한다.
- 특정 수업의 잔여 좌석을 수동으로 기재할 때 검증 시각을 내부 기록한다.
- 마감 후 게시물 또는 CTA를 종료할 담당을 지정한다.

### Instagram 코치 개인 계정

- 코치 개인의 교육 콘텐츠와 공식 수업 가능 여부를 구분한다.
- 확인되지 않은 시간표·잔여 좌석·무료 체험·혜택을 약속하지 않는다.
- 댓글·DM의 관심 표현을 예약으로 계산하지 않는다.
- 실제 문의 연결 시 지점 기준정보를 다시 확인한다.

### CRM·예약 시스템

- TRIAL_REQUEST_RECEIVED와 TRIAL_BOOKING_CONFIRMED를 구분한다.
- WAITLIST_JOINED는 예약 분모에서 제외한다.
- RESCHEDULED는 원 예약과 대체 예약을 연결한다.
- ATTENDED_VERIFIED는 출석 기준원천에서 확인한다.

## 9. 실험 EXP-302

### 이름

수용능력 기반 체험 모집 기준선

### 대상

대표 승인 후 최초 14일의 공개 체험 가능 수업과 비식별 예약

### 성공 기준

- 공개 수업의 지점·시간·대상 일치율 100%
- 모집 수업의 정원·지도자·안전 검증률 100%
- 확정 예약의 좌석 배정 근거 기록률 100%
- 대기 등록의 예약 오분류 0건
- 도장 취소의 노쇼 오분류 0건
- 승인 정원 초과 예약 0건
- 기존회원 좌석 정책 위반 0건
- 공개 개인정보 0건

### 보류 기준

- 지점별 정원·수업·지도자 기준 미확정
- 기존회원과 체험 좌석 배분 규칙 미승인
- 예약·출석 기준 시스템 미지정
- 대기 제안 방식·응답 기한 미승인
- 공개 시간표 기준정보 미연결

### 중단 기준

- 정원 초과 또는 안전 미확인 모집
- 대기자를 예약 완료로 안내
- 승인 없는 자동 알림·혜택·수수료 실행
- 도장 취소를 고객 책임으로 기록
- 조회·문의·대기를 참석·등록으로 과장

## 10. 대표 승인 체크리스트

- 실제 지점 목록과 지점 코드
- 수업별 대상·시간·지도자 역할
- 안전 기준을 반영한 승인 정원
- 기존회원 예약 보호 규칙
- 수업별 체험 좌석 한도
- 대기 순번·제안·응답 기한
- 취소·재예약·도장 취소 판정
- 예약·출석 기준 시스템
- 공개 채널별 시간표 책임자
- 비식별 지점별 집계 주기

## 11. 감사 메모

- 외부 소프트웨어의 권장 대기 인원이나 확인 시간을 파이널유도 기준으로 적용하지 않았다.
- 만석과 수요를 동일하게 해석하지 않았다.
- 수업 정원과 지도자 배치 수치는 데이터 미연결 상태다.
- 승인 대기 Instagram 미디어·캡션과 미확정 행사·혜택은 공개하지 않았다.
- 회원·보호자 식별정보와 개인별 출석·결제 원장은 공개 저장소 대상이 아니다.
