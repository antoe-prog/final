# 지역 프로필 지점별 예약 링크·라우팅·귀속 기준 v1

- 문서 상태: 공개 운영 기준 초안
- 기준일: 2026-09-16
- 적용 범위: Google 비즈니스 프로필, 네이버 스마트플레이스·예약, 당근, 웹사이트, Instagram 프로필에서 체험 문의·예약으로 이어지는 공개 링크
- 소유 역할: CMO / Growth Analyst / Acquisition / CRM / Auditor
- 현재 상태: 계정·링크·예약 설정 변경 전
- 내부 문의·예약·출석·등록·매출: **데이터 미연결**

## 1. 목적

여러 지점을 운영할 때 공개 프로필의 링크가 다음 조건을 충족하는지 판정한다.

1. 클릭한 프로필과 도착한 지점이 같다.
2. 사용자가 해당 페이지에서 의도한 행동을 실제로 완료할 수 있다.
3. 시간표·가격·체험 가능 여부 등 표시 정보가 승인된 원천과 일치한다.
4. 링크가 로그인·CAPTCHA·오류·지역 차단 없이 정상 작동한다.
5. 클릭, 문의, 예약, 실제 참석, 등록, 순수납을 서로 다른 사건으로 기록한다.

링크 클릭은 문의가 아니며, 예약 화면 진입은 예약 완료가 아니다. 공용 랜딩페이지에서 다른 지점을 다시 찾게 만드는 경로도 지점 전환 성과로 확정하지 않는다.

## 2. 핵심 원칙

### 2.1 지점 일치

- 지점별 프로필의 행동 링크는 해당 지점 전용 페이지로 연결한다.
- 같은 브랜드의 다른 지점이나 본관 공용 홈으로 보내지 않는다.
- 공용 선택 화면을 써야 한다면 사용자가 클릭한 지점이 기본 선택되고 지점명이 명확히 보여야 한다.
- 지점 코드, 주소, 전화, 운영시간, 문의 담당의 원천을 승인 문서로 지정한다.
- 지점 이동이 발생하면 최초 클릭 지점과 최종 선택 지점을 모두 보존한다.

### 2.2 행동 완료

예약 링크는 단순 소개 페이지가 아니라 다음 중 승인된 목표 행동을 완료할 수 있어야 한다.

- 체험 가능 여부 확인
- 수업 또는 상담 선택
- 방문 지점·일시 선택
- 필요한 동의 후 예약 또는 문의 제출
- 완료 상태와 다음 안내 확인

소셜미디어·메신저·앱스토어·단축 URL을 Google의 예약 행동 링크 대신 사용하지 않는다. 다른 채널의 공개 링크도 사용자가 목표 행동을 완료하지 못하고 다시 검색해야 한다면 전환 링크로 판정하지 않는다.

### 2.3 공개정보 진실성

다음 정보는 확인되지 않으면 랜딩페이지나 링크 주변 문구에 표시하지 않는다.

- 무료 체험
- 가격·할인·혜택
- 잔여 좌석
- 특정 수업 시간
- 코치 배정
- 연령·건강·경력별 참여 가능 여부
- 취소·환불 조건

미확정 정보는 **데이터 미연결** 또는 확인 필요로 남긴다.

### 2.4 변경 권한

읽기 전용 점검과 실제 설정 변경을 분리한다.

- 링크·공개 페이지 열람: 읽기 전용
- 링크 추가·삭제·선호 링크 지정: 대표 승인 필요
- 예약상품·가격·시간표·수용량 변경: 대표 승인 필요
- 제3자 예약 제공자 등록·해지: 계약·비용 확인과 대표 승인 필요
- 광고·고객 연락: 별도 승인 필요

## 5. 채널별 기준

### 5.1 Google 비즈니스 프로필

- 다지점 사업의 행동 링크는 특정 지점 전용 페이지로 연결한다.
- 예약 링크는 해당 행동을 직접 완료할 수 있어야 한다.
- 소셜미디어, 메신저, 앱스토어, 링크 단축 주소를 행동 링크로 사용하지 않는다.
- 페이지는 정상 응답을 반환하고 전체 리소스가 로드돼야 한다.
- 로그인·CAPTCHA·속도 제한·IP 차단·지역 차단으로 검증 크롤러 접근을 막지 않는다.
- 여러 링크가 있으면 대표 승인 후 올바른 지점 링크를 선호 링크로 지정한다.
- 제3자 링크가 자동 표시될 수 있으므로 링크 소유자와 제거 경로를 별도로 기록한다.
- Google 공식 도움말 간 카테고리별 링크 최대 수 설명이 다르므로 숫자 상한을 내부 운영 기준으로 사용하지 않는다. 운영 목적에 필요한 최소 링크만 유지한다.
- 맞춤 링크에는 Google 예약 성과 데이터가 제공되지 않는다는 공식 안내가 있으므로 클릭 이후 성과를 Google 내부 지표로 추정하지 않는다.

### 5.2 네이버 스마트플레이스·예약

- 스마트플레이스 업체와 예약 서비스의 지점·주인 권한이 일치하는지 확인한다.
- 예약/주문 서비스의 제작 완료와 플레이스 버튼 노출 설정을 별도 상태로 기록한다.
- 예약상품의 지점·시간·휴무·가격·노출 상태를 승인 원천과 대조한다.
- 버튼이 보인다는 사실을 예약 가능 좌석이나 정상 결제의 증거로 사용하지 않는다.
- 현재 파이널유도 지점별 예약 서비스·버튼·권한 상태는 **데이터 미연결**이다.

### 5.3 당근

- 동네 광고·비즈프로필에서 클릭한 지역과 도착 지점이 일치해야 한다.
- 광고 문구의 지점·대상·시간·혜택과 도착 페이지의 정보를 대조한다.
- 광고 클릭을 문의·예약·방문으로 계산하지 않는다.
- 유료 광고 집행·링크 변경은 대표 승인 전 실행하지 않는다.

### 5.4 Instagram 코치 개인 계정

- `@ant.toe.98`은 코치 개인 계정이며 지점 공식 발표 계정으로 표현하지 않는다.
- 프로필 링크를 추가·변경하려면 해당 링크의 주체와 도착 지점이 개인 계정 맥락에 맞는지 검토하고 대표 승인을 받는다.
- 게시물 댓글·DM·프로필 클릭을 체험 문의로 자동 판정하지 않는다.
- 승인 대기 게시물의 미디어·캡션을 링크 테스트나 공개 저장소에 사용하지 않는다.

## 6. 귀속 규격

### 6.1 최소 태그

자체 랜딩페이지를 사용할 경우 승인된 분석 체계에서 다음을 구분한다.

- source: google / naver / daangn / instagram
- medium: organic_profile / paid_local / social_profile
- campaign: local_profile 또는 승인된 캠페인 ID
- content: 비식별 branch_code
- landing_version
- first_touch_at
- inquiry_id
- booking_id
- attendance_id
- enrollment_id
- settlement_period

태그는 개인정보를 포함하지 않으며 공개 URL에 회원 ID·전화번호·이름을 넣지 않는다.

### 6.2 퍼널

`profile_view → action_link_click → landing_loaded → inquiry_started → inquiry_verified → booking_verified → attendance_verified → enrollment_verified → net_collection_verified`

각 단계는 별도 원천과 시각을 가져야 한다. 뒤 단계가 없으면 앞 단계만 보고한다.

### 6.3 비율

| KPI | 분자 | 분모 | 현재 |
|---|---|---|---|
| 링크 가용률 | 정상 로드 링크 | 감사 대상 링크 | 데이터 미연결 |
| 지점 일치율 | 지점 일치 링크 | 정상 로드 링크 | 데이터 미연결 |
| 행동 완료 가능률 | 완료 경로 확인 링크 | 정상 로드 링크 | 데이터 미연결 |
| 클릭→유효문의 | 유효 문의 | 성숙한 링크 클릭 | 데이터 미연결 |
| 문의→예약 | 예약 완료 | 유효 문의 | 데이터 미연결 |
| 예약→실방문 | 실제 방문 | 예약 완료 | 데이터 미연결 |
| 실방문→등록 | 검증 등록 | 실제 방문 | 데이터 미연결 |
| 링크 귀속 순수납 | 검증 순수납 | 해당 귀속 코호트 | 데이터 미연결 |

분모가 0이거나 원천이 연결되지 않으면 계산하지 않는다.

## 7. 읽기 전용 감사 절차

1. 대상 지점·채널·프로필 목록 확정
2. 공개 화면에서 행동 링크 수집
3. 최종 도착 URL과 리디렉션 기록
4. 프로필 지점과 도착 지점 대조
5. 모바일·데스크톱 정상 로드 확인
6. 로그인·CAPTCHA·오류·지역 차단 확인
7. 예약·문의 완료 직전까지 탐색
8. 가격·시간·혜택·좌석 문구 대조
9. 제3자·자동 링크 소유자 확인
10. 변경 후보와 위험도만 보고
11. 대표 승인 후 설정 변경
12. 공개 화면에서 반영 재확인

실제 예약 제출, 결제, 계정 설정 변경은 읽기 전용 감사에 포함하지 않는다.

- 승인 대기 Instagram 미디어·캡션, 회원정보, 미확정 FINAL ROAD 내용과 내부 예산은 공개하지 않았다.
