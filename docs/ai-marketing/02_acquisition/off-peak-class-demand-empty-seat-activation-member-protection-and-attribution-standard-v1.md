## 1. 핵심 판단

비인기 시간대의 빈자리를 채우기 전에 다음 사건을 분리해야 한다.

`수업 개설 승인 → 안전·운영 정원 → 기존회원 보호석 → 예약 가능석 → 예약 → 실제 참여 → 반복 참여 → 계약·실수납`

한두 번 참여가 적었다는 이유로 수업을 저수요로 확정하거나, 빈자리를 곧바로 할인·무료 체험·광고 대상으로 전환하지 않는다. 지점·요일·시각·대상·수업 유형별로 같은 조건의 회차를 관찰하고 휴강, 코치 변경, 공휴일, 신규 개설, 시스템 누락을 먼저 제외한다.

인기 시간의 대기 수요가 비인기 시간으로 자동 이동한다고 가정하지 않는다. 시간대를 옮길 수 있는 의사와 실제 예약·참여를 별도로 확인한다.

## 2. 네 목표와의 연결

| 목표 | 관리할 사건 | 잘못된 대체 지표 |
|---|---|---|
| 신규 체험회원 확보 | 시간대 적격 문의·예약·실제 체험·등록 | 게시물 조회·빈자리·문의 시작 |
| 휴면회원 복귀 | 복귀 제안 적격성·수락·실제 참여·재개 계약 | 발송·열람·관심 표시 |
| 기존회원 재등록·만족 | 예약 접근성·수업 품질·시간 이동의 자발성 | 단순 좌석 이용률 |
| 매출 증대 | 계약·실수납·환불·직접비 반영 순수납 | 정가×좌석·예약·견적 |

## 3. 분석 단위

지점 전체 평균으로 시간대 수요를 판단하지 않는다. 최소 분석 단위는 다음 조합이다.

`branch_id + class_type + audience_group + weekday + start_time + observation_window`

후보, 실험 승인, 실제 실행, 평가와 시간표 변경을 각각 구분한다.

### 4.2 사람의 행동 상태

- `CONTENT_VIEWED`: 콘텐츠 노출·조회
- `INQUIRY_STARTED`: 문의 시작
- `TIME_PREFERENCE_STATED`: 해당 시간대 선호 의사 표현
- `BOOKING_REQUESTED`: 예약 요청
- `BOOKING_CONFIRMED`: 기준 시스템에 예약 확정
- `ATTENDANCE_VERIFIED`: 실제 참여 확인
- `REPEAT_ATTENDANCE_VERIFIED`: 승인된 관찰창에서 반복 참여 확인
- `CONTRACT_EXECUTED`: 계약 성립
- `PAYMENT_SETTLED`: 실제 수납 확인
- `REFUND_OR_CHARGEBACK`: 환불·차지백 반영

조회·문의·선호·예약·참여·계약·수납을 한 단계로 합치지 않는다.

## 5. 저이용 후보 판정

### 5.1 분모

회차 이용률은 다음처럼 정의한다.

`회차 이용률 = 실제 참여 확인 인원 / 운영 정원`

- 안전 정원이 아니라 해당 회차의 승인된 운영 정원을 분모로 사용한다.
- 운영 정원이 0이거나 미확인이면 계산하지 않는다.
- 휴강·사업자 취소 회차는 정상 저이용 표본에서 제외한다.
- 예약 수나 체크인 시도 수를 실제 참여로 대체하지 않는다.
- 서로 다른 지점·대상·수업 유형의 분모를 단순 합산하지 않는다.

### 5.2 후보 판정 전에 제외할 사건

- 신규 수업의 준비·학습 기간
- 공휴일·대회·행사·학교 일정의 일시 영향
- 코치 변경·대체수업·합반·휴강
- 예약 페이지 오류·체크인 누락·출석 입력 지연
- 시간표가 채널별로 다르게 노출된 기간
- 시설 공사·날씨·교통 등 외부 사건
- 안전 정원이나 운영 정원이 중간에 변경된 기간

제외 사유와 영향을 확인하지 못하면 `DEMAND_REVIEW_PENDING`으로 남긴다.

### 5.3 금지되는 추정

- 성인은 늦은 시간만 선호한다는 일반화
- 유소년은 특정 시각에 반드시 참여한다는 일반화
- 휴면회원은 가격 때문에 쉬었다는 추정
- 빈자리가 많으므로 코치나 수업 품질이 낮다는 추정
- 인기 시간 대기자가 다른 시간으로 이동할 것이라는 추정
- 외부 업체의 이용률 임계값을 내부 성공 기준으로 복사

## 6. 활성화 우선순위

저이용 후보가 확인되면 다음 순서로 검토한다.

1. 시간표·지도·문의·예약 링크의 공개정보 일치 여부
2. 예약·취소·체크인·출석 데이터 완전성
3. 대상·난이도·수업 설명의 정확성
4. 기존회원의 자발적 시간 이동 가능성
5. 휴면·체험 후 미등록 대상의 연락 적격성
6. 신규 체험석의 안전·운영 가능성
7. 메시지·콘텐츠 실험
8. 시간 이동·수업 통합·중단 제안

할인이나 무료 혜택은 가격·프로모션 기준과 대표 승인이 연결된 경우에만 검토한다.

## 7. 대상별 운영 기준

### 7.1 신규 체험

- 실제 체험 가능석과 지도 가능 대상을 먼저 확인한다.
- 공개 콘텐츠의 시간대와 예약 시스템의 회차를 대조한다.
- 문의 시작을 체험 예약으로 집계하지 않는다.
- 예약 확정 뒤 실제 참여를 별도 확인한다.
- 체험 후 등록은 계약·실수납까지 분리한다.

### 7.2 휴면회원 복귀

- 휴면 판정·계약 상태·연락 동의·수신거부를 확인한다.
- 해당 시간대가 과거 출석 패턴과 맞는다고 자동 추정하지 않는다.
- 복귀 제안·의사·예약·실제 참여·재개 계약을 분리한다.
- 건강·가족·경제사정 등 중단 이유를 추정하지 않는다.

### 7.3 기존회원

- 기존회원 보호석과 계약상 이용 범위를 우선한다.
- 인기 시간 혼잡을 이유로 비인기 시간 이동을 강요하지 않는다.
- 시간 이동은 제안·자발적 수락·실제 이동을 구분한다.
- 활성화 실험이 수업 품질·코치 피로·재등록 의사에 미치는 영향을 함께 검토한다.

### 7.4 체험 후 미등록·만료예정

- 이전 체험과 계약 제안의 현재 상태를 대조한다.
- 체험 당시 가격·혜택을 현재도 유효하다고 재사용하지 않는다.
- 만료예정 안내와 광고성 시간대 제안을 분리한다.
- 계약·수납이 확인되기 전 재등록 성과로 집계하지 않는다.

## 8. 채널별 실행 기준

### 8.1 네이버

- 지점·수업 대상·시간·문의 또는 예약 경로를 정확히 표시한다.
- 업체 영업시간과 수업시간·예약 가능시간을 혼동하지 않는다.
- 잔여석·마감 임박·오늘 가능 표현은 기준 시스템 근거가 있을 때만 사용한다.
- 플레이스 조회·전화 클릭·예약 요청과 실제 방문을 구분한다.

### 8.2 Instagram `@ant.toe.98`

- 코치 개인의 설명·수련·지도 맥락을 우선한다.
- 브랜드 공식 시간표 발표 주체로 표현하지 않는다.
- 미확정 시간·좌석·가격·무료 체험을 게시하지 않는다.
- 해당 시간대 참여를 유도할 때도 CTA는 저장·질문·팔로우·수업 문의 중 하나만 사용한다.
- 승인 대기 패키지는 업로드·외부 초안 저장·예약·발행하지 않는다.

### 8.3 당근

- 실제 지점 생활권과 방문 가능한 시간대를 확인한다.
- 채팅 시작을 예약·방문으로 계산하지 않는다.
- 여러 지점의 빈자리를 하나의 수요로 합치지 않는다.
- 확인되지 않은 할인·쿠폰·무료 혜택을 만들지 않는다.

### 8.4 웹사이트·예약 페이지

- 지점·대상·수업시간·예약 가능상태의 버전을 일치시킨다.
- 신청과 확정을 구분한다.
- 마감·휴강·시간 변경의 실제 공개 반영을 모바일에서 다시 확인한다.
- 추적 파라미터에 개인정보를 넣지 않는다.

## 9. 메시지·콘텐츠 실험 원칙

허용 가능한 실험 요소:

- 수업의 대상과 입문 난이도 설명
- 해당 시간대의 이용 방법과 준비물
- 코치 개인 계정의 일반적인 유도 입문 정보
- 정확한 문의 경로
- 같은 정보의 제목·표지·CTA 차이

승인 없이는 사용하지 않는 요소:

- 가격·할인·쿠폰·무료 체험
- 잔여 좌석·마감 임박·선착순
- 실제 회원 후기·변화·대회 실적
- 코치의 확인되지 않은 1인칭 경험·지도 철학
- 미확정 지점·행사·시간표

## 10. 시간표 변경 게이트

수업 이동·통합·중단 제안에는 다음이 필요하다.

- 비교 가능한 관찰기간과 회차 수
- 데이터 누락·휴강·예외 제거 결과
- 기존회원의 예약 접근성과 이동 영향
- 신규 체험·복귀 수요의 실제 근거
- 코치·공간·안전 정원 검토
- 공개정보·예약 시스템 변경 계획
- 기존 예약자에 대한 서비스 회복 계획
- 대표 승인과 효력 시각

변경 승인 전 공개 공지, 고객 연락과 예약 이동을 실행하지 않는다.

## 11. 성과 귀속

### 11.1 퍼널

`콘텐츠 노출 → 링크·프로필 행동 → 문의 → 시간대 적격성 확인 → 예약 요청 → 예약 확정 → 실제 참여 → 반복 참여 → 계약 → 실수납 → 환불 반영 순수납`

각 단계는 고유 사건과 시각을 가져야 한다.

### 11.2 중복 제거

- 같은 사람이 네이버·Instagram·당근에서 여러 번 문의해도 한 사람의 여정으로 검토한다.
- 기존회원의 시간 이동을 신규회원으로 계산하지 않는다.
- 휴면 복귀를 신규 등록으로 계산하지 않는다.
- 지점 이동을 신규·복귀 성과로 자동 집계하지 않는다.
- 체험 예약 취소 후 재예약은 계보를 연결한다.

### 11.3 KPI

- 회차 이용률
- 예약 대비 실제 참여율
- 체험 실제 참여율
- 복귀 실제 참여율
- 해당 시간대 반복 참여율
