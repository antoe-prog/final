# 지역 후기 요청·응답·인센티브·게이팅·신고·전환 귀속 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 작성 기준일: 2026-09-19
- 적용 채널: 네이버·Google·당근 및 기타 지역 사업자 프로필
- 목표: 실제 이용자의 자발적 후기를 공정하게 요청하고, 공개 평판과 문의·체험·등록·실수납을 분리 측정한다.
- 공개 제외: 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제·민원 기록, 후기 요청 대상자 명단, 내부 예산·손익, 승인 대기 Instagram 콘텐츠

> 이 문서는 운영 통제안이다. 각 플랫폼의 최신 정책과 국내 표시·광고·개인정보 기준을 실제 집행 전에 다시 확인한다.

## 1. 핵심 판단

후기 마케팅의 우선 과제는 후기 수를 늘리는 것이 아니라 다음 상태를 분리하는 것이다.

`실제 이용 확인 → 연락 자격 확인 → 중립적 요청 → 전달 → 자발적 작성 → 공개 확인 → 운영자 응답 → 문의·체험·등록·실수납`

다음은 후기 성과가 아니다.

- 후기 링크 발송
- 메시지 전달·열람
- 후기 작성 의향
- 직원이 대신 작성한 문안
- 할인·무료 이용을 조건으로 받은 후기
- 긍정 응답자에게만 공개 후기 작성을 요청한 결과
- 후기 수정·삭제를 보상 또는 문제 해결의 조건으로 만든 결과
- 별점·후기 수 증가만으로 추정한 신규 문의·등록

## 2. 금지 원칙

### 2.1 인센티브 교환 금지

- 후기 작성과 현금·상품·할인·무료 이용·추가 수업을 교환하지 않는다.
- 긍정 후기, 특정 별점, 특정 문구를 조건으로 혜택을 제공하지 않는다.
- 부정 후기의 수정·삭제와 환불·보상·서비스 회복을 교환하지 않는다.
- 체험단·협찬·광고 관계가 있는 추천·보증은 일반 자발 후기처럼 표현하지 않는다.

### 2.2 리뷰 게이팅 금지

- 만족한 사람에게만 공개 후기 링크를 보내지 않는다.
- 내부 만족도 점수에 따라 공개 후기 요청 여부를 나누지 않는다.
- 불만을 제기한 사람을 자동 제외해 평점을 인위적으로 높이지 않는다.
- 직원이 회원에게 높은 별점이나 코치 이름·지점 장점을 넣도록 요구하지 않는다.

### 2.3 대리 작성·압박 금지

- 직원·가족·관계자가 실제 회원인 것처럼 후기 작성하지 않는다.
- 회원 계정에 대신 로그인하거나 기기를 조작하지 않는다.
- 현장에서 바로 작성하도록 압박하지 않는다.
- 목표 후기 수를 직원 개인 할당량으로 배정하지 않는다.

### 2.4 공개 답글에서의 금지

- 회원 여부, 수업일, 출석, 결제, 건강, 부상, 보호자 관계를 확인하거나 반박하지 않는다.
- 내부 기록을 근거로 공개 작성자의 신원을 특정하지 않는다.
- 법적 위협·비난·조롱·후기 삭제 요구를 하지 않는다.
- 확인되지 않은 사실을 공개 답글에서 확정하지 않는다.

## 4. 요청 자격

### 4.1 포함 검토

- 실제 체험에 참여한 사람
- 실제 수업 또는 시설을 이용한 회원
- 보호자 본인이 관찰한 경험을 가진 경우
- 연락 목적과 채널 사용 근거가 확인된 경우

### 4.2 자동 제외가 필요한 경우

- 실제 이용 여부를 확인할 수 없음
- 수신거부·연락 중단 상태
- 보호자 권한이 필요한데 확인되지 않음
- 안전·개인정보·결제·법적 분쟁이 진행 중이며 별도 담당자 검토가 필요함
- 동일 경험에 대한 승인 빈도 상한을 초과함

제외 사유를 `불만 고객`, `낮은 점수 예상`, `재등록 가능성 낮음`으로 자동 분류하지 않는다.

## 5. 중립적 요청 문안 기준

요청 문안은 다음을 충족해야 한다.

- 실제 경험을 솔직하게 남겨 달라고 요청한다.
- 긍정적 평가나 특정 별점을 요구하지 않는다.
- 특정 코치·프로그램·가격·효과를 언급하라고 지시하지 않는다.
- 작성 여부가 수업·혜택·환불·회원권에 영향을 주지 않음을 명확히 한다.
- 후기 작성 대신 내부 의견 전달 경로도 동등하게 제공한다.
- 미성년자에게 직접 공개 후기 작성을 요구하지 않는다.
- 공개 후기에는 건강·연락처·학교·수업시간 등 개인정보를 쓰지 않도록 안내한다.

### 공개 전 예시 초안

> 이용 경험에 대한 의견을 남기고 싶으시면 실제 느낀 점을 솔직하게 작성해 주세요. 작성 여부와 내용은 수업·회원권·혜택에 영향을 주지 않습니다. 공개를 원하지 않으시면 내부 의견으로 전달해 주셔도 됩니다. 개인정보나 건강정보는 공개 후기에 적지 말아 주세요.

이 예시는 실제 발송 문안이 아니며, 연락 근거·채널·대상·빈도 승인 전에는 사용하지 않는다.

## 6. 요청 대상 선정 통제

### 허용되는 기준

- 객관적으로 확인 가능한 실제 이용 사건
- 지점·프로그램·기간별 균형 표본
- 승인된 요청 빈도와 중복 제거
- 채널별 정책과 연락 자격

### 허용하지 않는 기준

- 만족도 높은 사람만 선별
- 긍정 메시지를 보낸 사람만 선별
- 불만·환불·휴회 이력이 있다는 이유만으로 제외
- 직원이 높은 별점을 줄 것 같은 사람만 선택
- 특정 목표 평점을 달성할 때까지 반복 요청

## 7. 후기 내용과 공개 사용

- 공개된 후기를 광고 소재·Instagram 카드·홈페이지 증언으로 재사용하려면 별도 범위와 표시를 검토한다.
- 공개 후기를 캡처할 때 작성자 이름·사진·활동내역을 불필요하게 노출하지 않는다.
- 문장을 축약·편집해 의미를 바꾸지 않는다.
- 회원의 변화·효과·실적을 일반적인 결과로 확대하지 않는다.
- 협찬·무료 제공·이해관계가 있으면 최신 표시 기준에 따라 공개 필요성을 확인한다.
- 삭제된 후기를 과거 캡처로 계속 광고하지 않는다.

## 8. 공개 답글 기준

### 긍정 후기

- 감사는 짧고 구체적으로 하되 회원의 수업·결제·출석 정보를 추가 공개하지 않는다.
- 재등록·추천·다른 플랫폼 후기 작성을 압박하지 않는다.
- 후기 내용을 광고 문구로 자동 전환하지 않는다.

### 중립·부정 후기

- 경험을 남겨 준 사실을 먼저 확인한다.
- 공개 공간에서 사실관계를 단정하거나 개인정보를 요구하지 않는다.
- 내부 확인이 필요하면 승인된 비공개 연락 경로를 안내한다.
- 단순히 부정적이라는 이유로 신고하지 않는다.
- 서비스 회복의 제안·승인·실행·회원 확인을 별도 CRM 사건으로 관리한다.

### 정책 위반 의심 후기

- 가짜·스팸·사칭·개인정보 노출·이해상충 등 구체적 정책 조항과 증거를 기록한다.
- 신고 제출과 플랫폼 삭제를 구분한다.
- 삭제되지 않았다는 이유로 같은 신고를 반복 자동화하지 않는다.
- 경쟁사 또는 작성자에 대한 보복성 후기를 작성하지 않는다.

## 9. 채널별 운영

| 채널 | 요청 전 확인 | 응답 전 확인 | 성과 단계 |
|---|---|---|---|
| Google | 실제 경험, 무인센티브, 비선별 요청 | 개인정보·정책 위반 여부 | 요청·게시·답글·프로필 행동 |
| 네이버 | 최신 리뷰 운영정책·영수증/방문 인증 방식 | 작성자 개인정보·사업자 답글 범위 | 리뷰·저장·전화·예약 |
| 당근 | 지역 사업자·후기 기능과 최신 정책 | 동네 이용자 개인정보·채팅 전환 | 후기·관심·채팅 시작 |
| Instagram | 후기 재사용 동의·작성자 표시 범위 | 댓글·DM 공개 범위 | 도달·저장·프로필 방문·문의 |

플랫폼 하나에서 공개된 후기를 다른 플랫폼에 자동 복제하지 않는다.

## 10. 퍼널과 귀속

```
실제 이용 확인
→ 중립 후기 요청
→ 전달·열람
→ 자발적 공개 후기
→ 사업자 답글
→ 프로필·랜딩 행동
→ 유효 문의
→ 체험 신청
→ 예약 확정
→ 체험 실참여
→ 신규 등록·복귀·재등록
→ 실수납
→ 환불·차지백 반영
→ 순수납
```

### 자동 승격 금지

- 요청 발송 → 후기 작성
- 후기 작성 의향 → 공개 후기
- 후기 게시 → 만족 확인
- 긍정 별점 → 재등록
- 후기 조회 → 문의
- 전화·채팅 버튼 클릭 → 상담 완료
- 예약 신청·체크인 → 체험 실참여
- 등록 의사 → 실수납

### 귀속 원칙

- `review_id`, `location_id`, `request_event_id`, `lead_id`를 비식별 키로 분리한다.
- 회원에게 공개 링크 추적을 위해 개인 식별값을 URL에 넣지 않는다.
- 최초 발견 채널, 후기 접촉, 후속 CRM, 수납 지점을 따로 기록한다.
- 한 등록·결제를 여러 후기·채널·지점에 중복 귀속하지 않는다.
- 후기와 전환의 시간적 선후만으로 인과관계를 단정하지 않는다.

## 12. 역할별 실행

### CMO

- 평점 목표보다 정책 준수·표본 편향·실제 전환 연결을 우선한다.
- 후기 대행·보상형 패키지는 플랫폼 정책과 표시 의무 검토 전 집행하지 않는다.

### Growth Analyst

- 요청·게시·답글·프로필 행동·문의·체험·수납을 별도 사건으로 측정한다.
- 후기 수 증가를 신규회원 증가로 자동 해석하지 않는다.

### Acquisition Marketer

- 네이버·Google·당근의 지점별 요청 링크와 소유권을 확인한다.
- 모든 실제 이용자에게 동일한 중립 기준을 적용한다.

### CRM Marketer

- 연락 자격·수신거부·보호자 권한·빈도 상한을 확인한다.
- 공개 후기 요청과 내부 만족도 조사·불만 처리를 분리한다.

### Content Strategist

- 후기 재사용 시 작성자 표시, 문맥, 편집 범위와 이해관계를 검수한다.
- 실제 회원 후기·효과·변화를 자료 없이 만들지 않는다.

### Experiment Manager

- 합성 데이터로 선택 편향·인센티브·상태 승격·중복 귀속을 먼저 시험한다.

### Auditor

- 공개 저장소에 후기 요청 명단·원문·계정·연락처를 올리지 않는다.
- 부정 후기를 숨기거나 수정하게 만드는 운영을 성과로 인정하지 않는다.

## 13. 실험 EXP-402

**가설:** 실제 이용 확인, 중립 요청, 게시 검증, 전환 귀속을 분리하면 후기 조작 위험 없이 지역 획득 성과를 측정할 수 있다.

- 문의·체험·등록·결제·환불 사건 720건

## 14. 대표 승인·입력

- 지점별 공식 네이버·Google·당근 프로필 URL과 소유권

## 15. 공개 근거

Google은 후기가 실제 경험에 기반하고 진정하며 편향되지 않아야 한다고 안내한다. 금전·할인·무료 상품 또는 서비스를 대가로 한 후기, 부정 후기의 수정·삭제와 혜택을 교환하는 행위, 부정 후기를 막거나 긍정 후기만 선별 요청하는 행위도 금지한다. 반면 보상 없이 평점·내용을 통제하지 않는 실제 경험 후기는 요청할 수 있다.

국내 추천·보증 및 후기 광고는 이해관계 공개와 기만성 여부를 포함해 최신 표시·광고 기준을 별도로 검토한다.
