# 다채널 문의 접수·중복 제거·담당 배정·응답·인계·예약·실참여·매출 기준 v1

- 문서 버전: v1
- 공개 기준일: 2026-09-20
- 적용 범위: Google·네이버·당근·Instagram·전화·웹폼·지점 CRM·예약·출석·계약·결제
- 목적: 메시지·알림·리드 생성과 실제 사람 응답·예약·체험·등록·순수납을 분리하고 다지점 문의 누락과 중복을 방지한다.
- 제외: 실제 이름·연락처·메시지 원문·건강정보·보호자 정보·출석·결제 원장·계정 토큰·승인 대기 콘텐츠

## 1. 경영 판단

프로필 조회와 링크 클릭을 연결한 다음 병목은 문의가 들어온 뒤의 인계다.

채널 알림, 리드 생성, 자동 회신, 담당 배정, 답변 작성, 발송, 전달, 사람 응답은 서로 다른 사건이다. 자동 회신만 보냈거나 담당자가 지정됐다는 이유로 상담 완료를 계산하지 않는다.

관리 순서는 다음과 같다.

문의 원천 → 접수 → 중복 검사 → 동의·연락 가능 상태 → 지점·프로그램 분류 → 담당 배정 → 담당 확인 → 실제 응답 → 유효 대화 → 예약 → 실제 체험 → 계약 활성 → 실정산

하위 사건을 확인할 원장이 없으면 데이터 미연결로 둔다.

## 4. 중복 제거

### 4.1 중복 후보

다음은 자동 병합이 아니라 검토 후보를 만든다.

- 같은 채널의 반복 전송
- 같은 사람이 여러 채널에서 문의
- 보호자와 참여자가 각각 문의
- 같은 가구의 형제자매 문의
- 지점 간 전달 과정에서 복제된 문의
- 예약 시스템이 별도 리드를 생성한 경우
- 휴면회원·기존회원이 신규 체험폼을 사용한 경우

### 4.2 병합 규칙

1. 원천 사건은 삭제하지 않는다.
2. 병합 전후 식별자를 감사 로그에 남긴다.
3. 전화번호·이메일만으로 같은 사람을 확정하지 않는다.
4. 참여자·보호자·결제자·연락 담당자를 분리한다.
5. 기존회원·휴면·체험 후 미등록·신규 후보를 상호 배타적으로 확정하지 않고 근거 상태로 관리한다.
6. 병합 취소가 가능해야 한다.
7. 공개 분석에는 직접 식별정보를 사용하지 않는다.

## 5. 배정과 인계

### 5.1 라우팅 우선순위

1. 문의자가 명시한 지점
2. 확정된 예약 지점
3. 승인된 지역·프로그램 규칙
4. 수동 분류 대기열

주소·현재 위치·학교·건강정보를 이용한 자동 지점 배정은 대표 승인과 개인정보 기준 없이는 사용하지 않는다.

### 5.2 담당자 상태

- 미배정
- 주담당 배정
- 대체 담당 배정
- 담당 확인
- 지점 이관 요청
- 지점 이관 수락
- 처리 중
- 종료 검토
- 종료
- 재개방

배정 알림 생성은 담당자의 확인이나 응답이 아니다. 지점 이관 요청은 상대 지점의 수락이 아니다.

### 5.3 응답 기한

응답 목표시간은 채널·운영시간·문의 유형별로 대표가 승인한다. 승인 전에는 임의의 5분·1시간·당일 기준을 성과 목표로 사용하지 않는다.

측정 시 다음을 분리한다.

- 접수→배정
- 배정→담당 확인
- 담당 확인→첫 사람 응답 발송
- 발송→전달
- 전달→문의자 회신
- 유효 문의→예약
- 예약→실제 체험

휴일·야간·휴관·시스템 장애·지점 이관 대기는 별도 예외 코드로 기록한다.

## 6. 채널별 통제

### Google 지역 프로필

전화 버튼 클릭, 웹사이트 클릭, 메시지 대화, 예약은 플랫폼 상호작용이다. 통화 연결·유효 문의·실제 체험을 자동 생성하지 않는다.

### 네이버·당근

알림 수신·채팅 시작·예약 요청을 사람 응답·예약 확정·실참여와 구분한다. 현재 연결 방식과 계정 권한이 검증되지 않으면 수동 원천으로 표시한다.

### Instagram @ant.toe.98

코치 개인 계정의 댓글·DM·프로필 행동을 본관이나 특정 지점의 공식 문의로 자동 분류하지 않는다. 계정 유형·API 권한·통합 상태를 직접 확인하기 전 자동 수집·응답 가능성을 가정하지 않는다.

### 전화·웹폼

부재중 전화, 음성메시지, 폼 제출, 자동 확인 메일은 각각 접수 신호다. 사람 응답과 유효 문의는 별도 확인한다.

## 7. 메시지와 동의

- 서비스 응답과 광고성 후속 연락을 구분한다.
- 문의 응답 동의를 휴면 복귀·재등록 광고 동의로 확대하지 않는다.
- 보호자·비상연락처·결제자 정보를 광고 수신자로 자동 전환하지 않는다.
- 수신 거부·철회·잘못된 연락처·연락 금지 상태를 모든 지점에 전파할 기준이 필요하다.
- 템플릿 선택, 미리보기, 승인, 발송, 전달, 회신, 예약을 별도 기록한다.
- 자동 발송과 실제 고객 발송은 대표 승인 전 실행하지 않는다.

## 8. 종료와 재개방

종료 사유는 다음처럼 분리한다.

- 중복 병합
- 잘못된 연락처
- 대상 프로그램 없음
- 지점 이관 완료
- 정보 요청 해결
- 예약 완료
- 체험 완료
- 등록 완료
- 문의자가 후속 연락 중단 요청
- 응답 없음
- 기타 수동 검토

응답 없음은 거절·불만족·이탈이 아니다. 이후 새 문의가 오면 기존 사건을 신규 획득으로 중복 계산하지 않고 재개방 또는 새 사건 연결 규칙을 적용한다.

## 10. EXP-430 — 문의·배정·응답·예약·실참여 판정 정확도

### 합성 데이터

- 지점 8개
- 채널 6개
- 가명 사람 1,200명
- 원천 문의 7,200건
- 중복 후보 2,400건
- 배정·이관 9,600건
- 응답 사건 14,400건
- 예약·출석·계약·결제 사건 6,000건

실제 연락처·대화 원문·회원·결제자료는 사용하지 않는다.

### 성공 기준

다음 오류가 모두 0건이어야 한다.

- 채널 알림을 문의 접수로 계산
- 리드 생성을 유효 문의로 계산
- 중복 후보를 자동 병합
- 보호자와 참여자를 같은 사람으로 병합
- 담당 배정을 담당 확인으로 계산
- 자동 회신을 첫 사람 응답으로 계산
- 발송을 전달·열람·사람 회신으로 계산
- 지점 이관 요청을 인계 완료로 계산
- 채팅 시작을 예약으로 계산
- 예약을 실제 체험으로 계산
- 실제 체험을 계약·실정산으로 계산
- 응답 없음을 거절·이탈로 분류
- 기존·휴면·재등록을 신규로 중복 계산
- 한 실정산을 여러 문의·채널·지점에 중복 귀속
- 동의 미확인 대상을 자동 발송 후보로 생성
- 코치 개인 계정의 문의를 지점 공식 문의로 자동 분류

하나라도 실패하면 자동 병합·배정·발송, 이탈 판정 및 채널별 신규·복귀·재등록·매출 보고를 중단한다.
