# 다지점 지역검색 프로필·링크·전화·문의·예약·실방문·등록·매출 귀속 기준 v1

- 문서 버전: v1
- 공개 기준일: 2026-09-20
- 적용 범위: Google·네이버·당근·Instagram·지점 랜딩페이지·예약·CRM·출석·결제
- 목적: 지역검색 상호작용을 실제 체험·등록·순수납과 혼동하지 않고, 지점별 신규·복귀·재등록 성과를 중복 없이 측정한다.
- 제외: 실제 지점명·주소·전화번호·프로필 ID·회원 식별정보·출석·결제 원장·비밀키·미확정 행사·승인 대기 콘텐츠

## 1. 경영 판단

지역검색에서 발생한 조회·전화 버튼 클릭·길찾기·웹사이트 클릭·예약은 모두 퍼널 신호다. 그 자체로 문의·실방문·체험·등록·매출을 증명하지 않는다.

따라서 노출 확대보다 먼저 다음 연결을 고정한다.

지점 프로필 → 공식 링크/전화 → 문의 → 예약 → 실제 방문 → 실제 체험 → 계약 활성 → 실정산

상위 단계만 존재하면 하위 전환은 데이터 미연결로 둔다.

### 2.2 다지점 규칙

1. 실제 한 지점에는 원칙적으로 하나의 대표 프로필만 둔다.
2. 같은 서비스의 지점명·핵심 카테고리는 실제 현장 표기에 맞춰 일관되게 관리한다.
3. 지점별 전화와 랜딩 경로는 실제 해당 지점으로 연결되어야 한다.
4. 소셜 프로필이나 제3자 리드 수집 페이지로 우회시키는 링크를 공식 지점 링크로 표시하지 않는다.
5. 코치 개인 Instagram 계정은 개인 콘텐츠 채널이며 지점 공식 프로필로 자동 분류하지 않는다.
6. 폐점·이전·임시휴업·권한 이관은 별도 상태로 관리하고 신규 프로필 생성으로 덮지 않는다.

## 3. 링크와 전화 통제

### 3.1 링크 원장

각 링크는 link_id, location_id, platform, link_role, destination_url, preferred_flag, owner, status, last_checked_at을 가진다.

플랫폼이 자동 추가한 제3자 링크는 공식 링크와 분리한다. 여러 예약 링크가 존재할 때는 대표 승인된 우선 링크를 별도로 표시하고, 다른 링크를 임의 삭제하거나 교체하지 않는다.

### 3.2 UTM 규칙

지점별 공식 랜딩 링크에는 승인된 utm_source, utm_medium, utm_campaign, utm_content 명명 사전을 사용한다. 값은 소문자와 승인된 구분자를 사용한다. UTM은 클릭 원천을 식별할 뿐 문의·방문·등록 증거가 아니다.

### 3.3 전화 규칙

- 전화 버튼 클릭과 실제 연결을 분리한다.
- 연결과 사람 응답을 분리한다.
- 사람 응답과 유효 문의를 분리한다.
- 유효 문의와 예약을 분리한다.
- 통화 녹음·연락처·내용은 공개 저장소에 넣지 않는다.

## 5. 채널 역할

### Google·네이버 지역 프로필

- 실제 지점 정보, 공식 문의·예약 링크, 운영 안내의 기준면으로 사용한다.
- 조회·길찾기·전화·클릭은 상단 퍼널 지표로만 본다.
- 플랫폼 예약은 실제 체험 출석과 분리한다.

### 당근

- 생활권 단위 콘텐츠와 지점별 캠페인 코드로 유입 원천을 구분한다.
- 채팅 시작을 유효 문의나 예약으로 자동 계산하지 않는다.

### Instagram @ant.toe.98

- 코치 개인의 설명·수련·지도 맥락을 보여주는 발견 채널이다.
- 본관·브랜드 공식 발표 주체 또는 지점 공식 프로필로 표현하지 않는다.
- 프로필·콘텐츠 유입은 공식 지점 문의·예약·실방문과 별도 사건으로 연결한다.

### CRM·출석·결제

- CRM은 문의·예약·상담 상태를 관리한다.
- 출석 원장은 실제 방문·실제 체험을 확인한다.
- 계약·결제 원장은 계약 효력·실정산·환불·차지백을 확인한다.
- 어느 한 시스템도 다른 시스템의 사건을 추정해 자동 생성하지 않는다.

## 6. 식별·중복 제거

1. 프로필 조회와 사람 수를 동일시하지 않는다.
2. 동일인이 여러 기기·채널·지점에서 행동할 수 있다.
3. 플랫폼 집계 수치와 CRM의 식별 가능한 사람을 직접 합산하지 않는다.
4. 가족·가구·보호자·결제자·실제 참여자를 분리한다.
5. 지점 간 이동은 신규 획득과 구분한다.
6. 체험 후 미등록·휴면 복귀·기존회원 재등록을 신규로 중복 계산하지 않는다.
7. 한 번의 실정산을 여러 채널·지점·추천인에 전액 중복 귀속하지 않는다.
8. 개인 식별정보는 공개 문서와 분석용 공개 이벤트에서 제외한다.

## 7. 귀속 모델

대표 승인 전에는 최초 접점·마지막 비직접 접점·보조 접점의 관찰기간, 지점 이동 귀속, 채널 우선순위, 매출 기준일을 확정하지 않는다.

보고서는 최초 접점, 마지막 접점, 보조 접점을 분리한다. 모델이 미승인·미연결이면 채널별 매출은 계산 불가로 표시한다.

## 10. EXP-429 — 지점 프로필부터 순수납까지 판정 정확도

합성 지점 8개, 플랫폼 5개, 프로필 160건, 링크·전화 960건, 상호작용 48,000건, 문의 6,000건, 예약 3,000건, 실제 체험 2,000건, 계약·결제·환불 1,500건으로 검증한다. 실제 개인정보·원장은 사용하지 않는다.

### 성공 기준

다음 오류가 모두 0건이어야 한다.

- 동일 실지점을 여러 프로필의 별도 지점으로 계산
- 프로필 조회를 리드로 계산
- 전화 버튼 클릭을 통화 연결·유효 문의로 계산
- 길찾기 요청을 실제 방문으로 계산
- 웹사이트 클릭을 문의로 계산
- 예약 생성을 실제 체험으로 계산
- 체크인을 실제 참여로 자동 승격
- 계약 동의를 실정산으로 계산
- 한 실정산을 여러 채널·지점에 전액 중복 귀속
- 대소문자 차이로 UTM을 별도 캠페인으로 분할
- 플랫폼 자동 추가·만료 링크를 공식 선호 링크로 계산
- 코치 개인 계정을 지점 공식 발표 계정으로 분류
- 소유권 미확인 전화·링크를 공식 경로로 계산
- 환불·차지백을 순수납에서 누락

오류가 하나라도 발생하면 자동 프로필 변경, 링크 교체, 고객 발송, 채널별 신규·복귀·재등록·매출 보고를 중단한다.
