# Instagram 유기적 콘텐츠 관찰창·소표본·CTA 학습·의사결정 기준 v1

- 적용 조직: 파이널유도멀티짐 공개 마케팅 실무
- 기준일: 2026-09-17
- 우선 적용 채널: 코치 개인 Instagram
- 문서 상태: 공개 가능한 분석·운영 기준
- 공개 제외: 승인 대기 미디어·캡션, 계정 로그인정보, 댓글·DM 원문, 회원·보호자 식별정보, 연락처, 개인별 출석·건강·계약·결제 기록, 내부 예산·원가·손익
- 현재 내부 전환·매출 상태: 데이터 미연결

## 1. 핵심 판단

게시물의 조회·도달이 매우 작거나 게시물마다 주제·형식·CTA·게시 후 경과시간이 다르면 단순 순위를 만들지 않는다.

다음 순서로 판단한다.

`게시 검증 → 측정 시작 → 동일 정의 스냅샷 → 관찰창 성숙 확인 → CTA별 1차 지표 확인 → 비교 가능성 검토 → 방향성 학습 → 다음 제작 결정 → 문의·체험·수납 별도 평가`

조회수가 가장 높은 게시물이 가장 좋은 게시물이라는 뜻은 아니다. 저장을 요청한 게시물은 저장, 질문을 요청한 게시물은 유효 질문, 문의를 요청한 게시물은 적격 문의가 1차 결과다.

## 2. 기존 기준과의 경계

이 문서는 다음을 다룬다.

- 게시물별 측정 시작·종료와 관찰창
- 소표본에서의 판정 보류
- CTA별 1차·보조 지표
- 비교 가능한 콘텐츠 묶음
- 다음 제작 결정을 위한 학습 기록

다음은 기존 교차채널 귀속 기준을 적용한다.

- Instagram 이후 네이버·당근·전화·방문으로 이어진 문의
- 동일인의 다채널 중복 제거
- 체험 예약·실방문·계약·실수납·환불
- 최초·문의·마지막·보조 접점 귀속

## 3. 네 목표와 콘텐츠 역할

| 목표 | 콘텐츠가 만들 수 있는 선행 사건 | 최종 확인 사건 | 금지할 대체 지표 |
|---|---|---|---|
| 신규 체험회원 확보 | 도달·저장·질문·프로필 활동·직접 문의 | 적격 문의·예약·실방문·신규 실수납 | 조회·좋아요 |
| 휴면회원 복귀 | 콘텐츠 재접촉·복귀 질문 | 복귀 예약·실제 참여·실수납 | 기존 계정의 좋아요 |
| 기존회원 재등록·만족 | 유용성 반응·질문·피드백 | 재등록 계약·실수납·확인된 만족 | 저장·댓글 수 |
| 매출 증대 | 문의·상담 시작 | 환불 반영 순수납 | 프로필 방문·계약액 |

콘텐츠는 최종 성과의 보조 접점이 될 수 있지만 플랫폼 반응만으로 신규·복귀·재등록·매출을 확정하지 않는다.

## 4. 데이터 상태

| 상태 | 의미 | 허용 판단 |
|---|---|---|
| `PUBLISHED_UNVERIFIED` | 게시 도구 성공만 확인 | 측정 시작 금지 |
| `PUBLISHED_VERIFIED` | 공개 URL·계정·미디어·캡션 확인 | 기준 스냅샷 가능 |
| `MEASUREMENT_NOT_STARTED` | 측정 시작시각 없음 | 성과 판정 금지 |
| `WINDOW_OPEN` | 관찰 중 | 잠정값만 표시 |
| `WINDOW_IMMATURE` | 사전 정의한 관찰시점 전 | 승자·실패 판정 금지 |
| `WINDOW_CLOSED` | 관찰 종료시점 도달 | 비교 가능성 검토 가능 |
| `DATA_PARTIAL` | 일부 지표만 제공 | 제공 지표만 보고 |
| `DATA_UNAVAILABLE` | 도구·플랜·권한·원천 미연결 | 데이터 미연결 |
| `SMALL_SAMPLE_HOLD` | 노출·반응이 너무 작아 방향성도 불안정 | 판정 보류 |
| `COMPARABILITY_HOLD` | 주제·CTA·형식·기간이 달라 직접 비교 불가 | 개별 학습만 기록 |
| `DIRECTIONAL_SIGNAL` | 제한된 범위의 반복 가능 신호 | 다음 가설 후보 |
| `DECISION_READY` | 사전 기준과 반복 근거 충족 | 다음 제작 결정 가능 |

`WINDOW_CLOSED`는 곧 `DECISION_READY`가 아니다. 관찰기간이 끝나도 표본이 부족하거나 비교 대상이 다르면 보류한다.

## 6. 관찰창 설계

### 6.1 기준점

관찰창의 시작은 실제 공개가 검증된 시각이다. 다음을 시작시각으로 사용하지 않는다.

- 제작 완료
- 사용자 승인
- 업로드 시작
- 예약 생성
- 게시 도구의 성공 메시지
- 외부 도구의 `Pending`·`Publishing`

### 6.2 제안 체크포인트

다음은 Instagram의 공식 권장시간이 아니라 내부 운영을 일관되게 하기 위한 제안값이다. 대표 승인 전에는 `PROPOSED`로 유지한다.

| 체크포인트 | 목적 | 허용 판단 |
|---|---|---|
| 공개 검증 직후 | URL·계정·형식·CTA 기준값 잠금 | 성과 판단 없음 |
| 게시 후 24시간 | 수집 오류·미디어 누락·비정상 0값 확인 | 오류 확인 |
| 게시 후 72시간 | 초기 분포와 CTA 사건 확인 | 잠정 신호 |
| 게시 후 7일 | 동일 형식·CTA의 1차 비교 | 조건부 방향성 |
| 게시 후 28일 | 긴 꼬리 반응·문의 보조 접점 확인 | 관찰창 종료 후보 |

원천 데이터가 나중에 갱신될 수 있으므로 모든 스냅샷에 조회시각을 붙인다. 체크포인트 사이의 증가가 없다는 사실만으로 콘텐츠 삭제·재게시를 결정하지 않는다.

### 6.3 성숙도

관찰창은 다음 조건을 모두 확인해야 성숙 후보가 된다.

- 공개 게시물이 동일 URL로 유지됨
- 지표 정의와 원천이 동일함
- 게시 후 경과시간이 비교 대상과 맞음
- 삭제·재게시·광고 부스팅·협업 확산 등 중대한 교란이 없음
- CTA 사건을 관찰할 수 있는 지표가 연결됨
- 수치가 테스트·관리자 행동과 섞이지 않음

## 7. CTA별 1차 지표

### 7.1 저장 CTA

1차 지표:

`저장률 = 확인된 저장 수 / 같은 스냅샷의 도달 계정 수`

보조 지표:

- 저장 수
- 공유 수
- 조회·도달
- 이후 직접 문의

분모가 0이거나 저장 지표가 제공되지 않으면 계산하지 않는다. 조회수 대비 저장률과 도달 대비 저장률을 혼용하지 않는다.

### 7.2 질문·댓글 CTA

1차 지표:

`유효 질문률 = 스팸·이모지·중복을 제외한 실제 질문 수 / 같은 스냅샷의 도달 계정 수`

보조 지표:

- 전체 댓글 수
- 일반 감상과 질문의 분리
- 공개 답변 가능·비공개 인계 필요 분류
- 후속 콘텐츠 후보 질문 수

댓글 원문과 계정 식별정보는 공개 저장소에 넣지 않는다. 댓글 1건이 체험 문의인지 여부는 내용과 후속 사건을 별도 확인한다.

### 7.3 팔로우 CTA

1차 지표:

`게시물 귀속 팔로우율 = 게시물에 귀속된 팔로우 수 / 같은 스냅샷의 도달 계정 수`

계정 전체 팔로워 증가와 게시물 귀속 팔로우를 구분한다. 귀속 데이터를 제공하지 않는 경우 계정 전체 증가를 특정 게시물 성과로 배분하지 않는다.

### 7.4 수업 문의 CTA

1차 지표:

`적격 문의율 = 중복 제거되고 실제 목적이 확인된 문의 수 / 같은 스냅샷의 도달 계정 수`

보조 지표:

- 프로필 방문
- 링크 클릭
- DM·채팅 수신
- 예약 제안·확정
- 실제 방문

프로필 방문·DM 수신·예약 제안은 적격 문의·예약·실방문으로 자동 승격하지 않는다.

## 8. 조회·도달·상호작용 해석

### 조회

- 같은 계정의 반복 조회가 포함될 수 있다.
- 도달보다 클 수 있다.
- 캐러셀의 완독이나 모든 장 확인을 의미하지 않는다.
- 서로 다른 형식의 조회 정의가 같다고 가정하지 않는다.

### 도달

- 플랫폼 정의에 따른 고유 계정 범주의 지표다.
- 실제 지역 잠재고객·성인 입문자·휴면회원 수를 의미하지 않는다.
- 도달 1건을 사람 1명의 신규 리드로 계산하지 않는다.

### 상호작용

- 좋아요·댓글·저장·공유가 어떤 조합인지 원천 정의를 확인한다.
- 합계만 있을 때 개별 CTA 결과를 추정하지 않는다.
- 상호작용 0은 콘텐츠가 무가치하다는 뜻이 아니다.

### 조회/도달 비율

`조회 빈도 참고값 = 조회 수 / 도달 계정 수`

이 값은 반복 노출 가능성을 보는 참고값일 뿐 완독·호감·문의 의향이 아니다. 소표본에서는 한 번의 반복 조회가 비율을 크게 바꾸므로 승자 판정에 사용하지 않는다.

## 9. 소표본 판정

### 9.1 판정 보류 조건

- 도달이 매우 작아 사건 1건이 비율을 크게 바꿈
- CTA 결과가 모두 0이고 노출 기회도 작음
- 비교할 동일 CTA·형식 게시물이 없음
- 게시 후 경과시간이 다름
- 계정의 기준선이 아직 없음
- 일부 지표가 플랜 제한·권한·수집 시작시점 때문에 없음
- 공개 게시물 수가 적어 주제·형식·CTA 효과를 분리할 수 없음

### 9.2 금지할 표현

- 최고 성과 콘텐츠
- 실패한 콘텐츠
- 참여율이 높다·낮다
- 알고리즘이 밀어줬다
- 팔로워가 좋아하는 주제
- 문의를 만들었다

위 표현은 비교 집합·기간·분모·근거가 준비된 경우에만 사용할 수 있다.

### 9.3 허용할 표현

- 조회 시점의 잠정값
- 직전 스냅샷과 동일·증가·감소
- CTA 사건이 관찰됨·관찰되지 않음
- 비교 불가
- 소표본으로 판정 보류
- 다음 반복에서 확인할 가설

## 10. 비교 집합

게시물을 직접 비교하려면 가능한 한 다음 조건을 맞춘다.

| 축 | 맞춰야 할 항목 |
|---|---|
| 계정 | 같은 계정·같은 발표 주체 |
| 형식 | 캐러셀끼리, 릴스끼리 |
| CTA | 저장끼리, 질문끼리, 문의끼리 |
| 관찰창 | 동일한 게시 후 경과시간 |
| 측정 원천 | 같은 도구·같은 지표 정의 |
| 유료 영향 | 모두 유기적이거나 유료 영향을 별도 표시 |
| 주제 | 같은 콘텐츠 축 또는 차이를 명시 |
| 제작 상태 | 승인·게시·검증 완료본 |
| 외부 확산 | 협업·공유·언급 등 교란 기록 |

모든 조건을 완전히 맞추기 어려우면 `COMPARABILITY_HOLD`로 두고 개별 학습만 기록한다.

## 11. 현재 초기 계정의 적용 원칙

- 게시물별 조회·도달·좋아요·댓글·저장·공유·팔로우를 원본 그대로 보존한다.
- 세 게시물의 주제와 목적이 다르면 조회수로 순위를 정하지 않는다.
- 도달이 한 자릿수인 스냅샷에서는 비율 비교를 공식 성과로 발표하지 않는다.
- 저장·댓글·공유가 0이면 `관찰된 사건 0`으로만 기록한다.
- 문의·예약·방문·등록·재등록·수납 원천이 없으면 `데이터 미연결`로 둔다.
- 승인 대기 콘텐츠는 게시 전이므로 성과 측정 대상이 아니다.
- 승인 대기 한도에 도달한 경우 신규 제작보다 승인·수정·폐기 결정을 우선한다.

## 12. 다음 제작 결정

### 유지

- 사실·브랜드·안전 문제가 없음
- CTA와 측정 지표가 일치함
- 비교할 반복이 더 필요함
- 소표본이므로 결론을 내리기 이름

### 개선

- CTA가 이미지와 캡션에서 다름
- 핵심 메시지·타이포그래피·순서가 읽기 어려움
- CTA 지표를 수집할 수 없음
- 공개 주체·근거·표현을 보완해야 함

### 반복 실험

- 같은 콘텐츠 축에서 한 변수만 바꿀 수 있음
- 비교 기간과 CTA를 맞출 수 있음
- 기존 승인 대기 한도를 넘지 않음
- 이전 게시물과 중복이 아니라 가설 검증임

### 중단·폐기

- 근거 없는 경험·회원 성과·가격·혜택 주장
- 개인정보·촬영동의·안전 위험
- 이미 게시된 승인본의 중복 게시 후보
- 폐기 지시가 있는 작업

낮은 조회수만으로 게시물을 삭제·재게시하거나 동일 미디어를 반복하지 않는다.
