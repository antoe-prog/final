# 교차채널 콘텐츠·유입원·문의·체험·등록·수납 귀속 기준 v1

- 문서 버전: v1
- 작성일: 2026-09-16
- 적용 대상: 파이널유도멀티짐의 공개 콘텐츠, 지역 채널, 문의, 체험, 등록, 재등록, 수납 성과 분석
- 공개 범위: 공개 가능한 운영 기준만 포함
- 제외 범위: 회원·보호자 식별정보, 연락처, 상담 원문, 개인별 출석·건강·계약·결제 원장, 내부 예산·원가·마진, 미확정 행사, 승인 대기 Instagram 미디어·캡션

## 1. 핵심 판단

콘텐츠의 조회·도달·반응과 사업 성과는 같은 지표가 아니다.

다음 사건은 반드시 분리한다.

1. 콘텐츠가 플랫폼에 노출됨
2. 사용자가 콘텐츠를 봄
3. 사용자가 반응하거나 저장함
4. 사용자가 프로필 또는 링크를 방문함
5. 사용자가 직접 문의함
6. 문의가 중복 제거되고 체험 가능 대상으로 확인됨
7. 체험을 예약함
8. 체험에 실제 참석함
9. 계약이 확정됨
10. 실제 결제가 확인됨
11. 등록 후 첫 수업에 실제 참여함
12. 환불·취소·직접 혜택비용을 반영한 순수납이 계산됨

조회수나 프로필 방문을 문의로, 문의를 체험 예약으로, 예약을 방문으로, 계약을 실수납으로 계산하지 않는다.

## 2. 적용 목표

### 2.1 신규 체험회원 확보

- 어떤 채널과 콘텐츠가 직접 문의를 만들었는지 기록한다.
- 문의 이후 체험 예약과 실제 참석을 분리한다.
- 동일인이 여러 채널로 문의해도 신규 리드를 중복 집계하지 않는다.

### 2.2 휴면회원 복귀

- 기존 관계가 확인된 대상은 신규 리드가 아닌 복귀 여정으로 분류한다.
- 복귀 의사, 복귀 예약, 실제 복귀 수업, 재등록 계약과 실수납을 분리한다.
- 공개 콘텐츠가 보조 접점이었더라도 기존 관계를 숨기고 신규 획득으로 집계하지 않는다.

### 2.3 기존회원 재등록·만족

- 기존회원의 저장·댓글·프로필 방문을 신규 문의로 계산하지 않는다.
- 재등록 문의, 계약, 결제와 이후 실제 참여를 각각 기록한다.
- 만족도 미응답을 긍정으로 간주하지 않는다.

### 2.4 매출 증대

- 청구액, 계약액, 실수납, 환불, 직접 혜택비용을 분리한다.
- 채널별 비용과 실수납이 연결되지 않으면 CAC와 ROI를 계산하지 않는다.
- 외부 업체의 성과 수치를 내부 목표나 실적으로 사용하지 않는다.

| `PLATFORM_REACH_OBSERVED` | 플랫폼 정의에 따른 도달 | 조회·문의 |

| source | 예시 |

| `instagram_brand_organic` | 확인된 브랜드 공식 계정 |
| `instagram_paid` | 승인된 Instagram 유료 광고 |
| `naver_place` | 네이버 플레이스·예약 |
| `naver_search` | 네이버 검색 결과·콘텐츠 |
| `naver_paid` | 승인된 네이버 유료 광고 |
| `daangn_profile` | 당근 비즈프로필 등 확인된 공개 접점 |
| `daangn_paid` | 승인된 당근 유료 광고 |
| `referral` | 친구가 직접 문의하며 추천 코드를 제시 |

| `walk_in` | 사전 디지털 접점 확인 없이 직접 방문 |
| `direct` | 저장 링크·직접 입력 등 출처 확인 불가 직접 유입 |
| `unknown` | 근거 부족으로 분류 불가 |

채널이 확인되지 않으면 추정값으로 채우지 않고 `unknown`으로 둔다.

### 4.2 UTM 기준

링크를 사용할 수 있을 때 아래 항목을 소문자와 일관된 구분자로 기록한다.

| 항목 | 역할 | 예시 |
|---|---|---|
| `utm_source` | 플랫폼·유입원 | `instagram` |
| `utm_medium` | 채널 유형 | `organic_social` |
| `utm_campaign` | 캠페인 단위 | `adult_beginner_faq_202609` |
| `utm_content` | 개별 콘텐츠·CTA | `coach_faq_carousel_a` |
| `utm_term` | 검색어 등 필요한 경우 | 승인된 키워드 코드 |

필수 운영 규칙:

- 같은 플랫폼에 여러 철자·대소문자를 사용하지 않는다.
- 게시물 ID와 버전을 `utm_content` 또는 내부 콘텐츠 코드에 연결한다.
- 승인 전 콘텐츠 링크를 외부에 만들거나 공개하지 않는다.
- UTM은 클릭 출처를 돕지만 신원·문의·계약·결제를 자동 증명하지 않는다.
- 링크가 없는 전화·방문·플랫폼 메시지는 고객의 직접 진술 또는 채널 원본 기록으로 분류한다.

## 5. 귀속 관점

### 5.1 최초 접점

`FIRST_TOUCH`는 확인 가능한 최초 접점을 기록한다.

- 인지 채널을 이해하는 회계 관점이다.
- 최초 접점이 등록을 단독으로 일으켰다는 인과 주장이 아니다.

### 5.2 문의 접점

`INQUIRY_TOUCH`는 직접 문의가 발생한 채널을 기록한다.

- Instagram 게시물을 본 뒤 네이버 예약으로 문의했다면 최초 접점과 문의 접점이 다를 수 있다.
- 문의 채널만 알고 이전 접점을 모르면 최초 접점을 추정하지 않는다.

### 5.3 마지막 비직접 접점

`LAST_NON_DIRECT_TOUCH`는 계약 또는 수납 전 확인 가능한 마지막 비직접 접점이다.

- `direct`가 이전 정보를 덮어쓰지 않도록 별도 표시할 수 있다.
- 귀속기간과 우선순위는 대표 승인 전 확정하지 않는다.

### 5.4 보조 기여

`ASSISTED_TOUCH`는 전환 경로에 있었으나 직접 문의 또는 최종 접점이 아닌 접점이다.

- 한 계약에 여러 보조 접점을 기록할 수 있다.
- 보조 접점의 수납을 각각 더해 전체 수납을 부풀리지 않는다.

### 5.5 미귀속

근거가 불충분하면 `UNATTRIBUTED`로 둔다.

`unknown`, `direct`, `walk_in`, `unattributed`는 서로 다른 상태다.

## 6. 중복 제거와 계보 연결

### 6.1 동일 문의 후보

다음 항목은 비공개 시스템에서만 비교한다.

- 정규화된 연락 수단
- 문의 시각과 지점
- 문의 목적
- 예약 식별자
- 기존 회원·보호자 관계

공개 문서나 공개 저장소에는 실제 식별값과 원문을 넣지 않는다.

### 6.2 중복 처리

- Instagram DM 후 네이버 예약을 했다고 신규 리드를 2명으로 세지 않는다.
- 전화 후 방문한 경우 전화 문의와 방문을 하나의 여정으로 연결한다.
- 보호자와 수련자가 각각 문의한 경우 권한과 관계를 확인하기 전 자동 병합하지 않는다.
- 지점 간 이관은 새 리드가 아니라 같은 여정의 책임자 변경으로 기록한다.
- 복귀회원과 지점 이동 회원을 신규 획득으로 집계하지 않는다.

## 7. 채널별 운영 기준

### 7.1 Instagram `@ant.toe.98`

- 사용자가 지정한 코치 개인 계정으로 기록한다.
- 브랜드 공식 발표 주체로 자동 분류하지 않는다.
- 플랫폼 설정상의 개인·크리에이터·비즈니스 유형은 직접 확인된 경우에만 기록한다.
- 조회, 도달, 좋아요, 저장, 댓글, 공유, 팔로우, 프로필 방문은 각각 별도 지표다.
- 댓글·DM이 있어도 체험 의사와 지점이 확인되기 전에는 적격 문의로 확정하지 않는다.
- 게시물별 콘텐츠 ID, 버전, 게시 URL, 게시 시각, 측정 기간, 원본 도구를 함께 기록한다.
- 승인 대기 미디어와 캡션은 공개 저장소에 넣지 않는다.

### 7.2 네이버

- 플레이스 조회, 길찾기, 전화 클릭, 예약 페이지 진입, 예약 신청, 예약 확정, 실제 방문을 분리한다.
- 예약자 수와 예약 상품 수가 다를 수 있으므로 원본 정의를 보존한다.
- 관리자 확인형 예약과 자동확정형 예약을 혼동하지 않는다.
- 쿠폰 발급·적용·사용·취소 복원은 각각 별도 사건으로 유지한다.

### 7.3 당근

- 게시물 조회, 프로필 방문, 채팅 시작, 실제 문의, 예약을 분리한다.
- 지역 노출 범위와 유료 광고 여부를 기록한다.
- 유료 광고비·채팅·체험 데이터가 연결되지 않으면 CAC를 계산하지 않는다.

### 7.4 오프라인·추천

- 직접 방문은 이전 디지털 접점이 확인되지 않을 때 `walk_in`으로 기록한다.
- 추천은 친구가 직접 문의하고 추천 코드를 제시한 경우에만 직접 귀속 후보가 된다.
- 추천인의 동의로 친구의 광고 수신동의를 대체하지 않는다.

## 8. 지점 귀속

- 문의 발생 지점, 최초 응답 지점, 체험 지점, 계약 지점, 실제 참여 지점을 각각 기록한다.
- 지점 이동을 새로운 신규회원으로 중복 계산하지 않는다.
- 본사 콘텐츠가 여러 지점을 보조한 경우 수납 전체를 각 지점에 반복 배분하지 않는다.
- 지점별 가격·좌석·시간표가 확인되지 않으면 콘텐츠가 특정 지점의 이용 가능성을 보장하지 않도록 한다.

수동으로 대조한 값은 자동 수집값과 구분하고 조회 시각을 남긴다.

## 11. KPI 계산 기준

### 11.1 콘텐츠에서 문의

`링크 클릭 대비 적격 문의율 = 귀속 가능한 적격 문의 수 / 동일 범위의 추적 가능한 링크 클릭 수`

- 클릭과 문의가 같은 기간·콘텐츠 코드로 연결될 때만 계산한다.
- 분모가 0이거나 연결되지 않으면 계산 불가다.

### 11.2 문의에서 체험

`체험 예약률 = 체험 예약 수 / 적격 문의 수`

`체험 실방문률 = 체험 실제 참석 수 / 체험 예약 수`

- 분자·분모의 코호트와 기간을 표시한다.
- 예약 취소와 사업자 예외를 별도 공개한다.

### 11.3 체험에서 등록

`계약률 = 신규 계약 수 / 체험 실제 참석 수`

`실수납 전환율 = 신규 실수납 인원 / 체험 실제 참석 수`

- 계약과 결제는 다른 사건이다.
- 복귀·지점 이동은 신규 코호트에서 제외한다.

### 11.4 획득비용과 수익

`CAC = 귀속 가능한 채널 비용 / 귀속된 신규 실수납 인원`

`증분 순수납 = 귀속된 실수납 - 실제 환불 - 직접 혜택비용 - 승인된 직접 캠페인 비용`

`마케팅 ROI = (귀속 매출 또는 순수납 - 마케팅 비용) / 마케팅 비용`

- 수익 정의, 비용 범위와 귀속기간을 함께 표시한다.
- 채널 비용·실수납·환불이 연결되지 않으면 계산하지 않는다.
- 보조 귀속 수납은 중복 합산하지 않는다.
- 단순 전후 비교를 인과효과로 단정하지 않는다.

## 13. 운영 역할

### CMO

- 조회수가 아니라 네 목표와 연결된 병목을 우선한다.
- 귀속 규칙과 지점 간 수납 중복을 승인한다.

### Growth Analyst

- 사건별 분자·분모·기간·출처를 고정한다.
- 미귀속과 데이터 미연결을 숨기지 않는다.

### Acquisition Marketer

- 캠페인·콘텐츠 코드와 UTM을 발행 전에 검수한다.
- 가격·좌석·혜택이 승인되지 않으면 CTA에 확정 표현을 넣지 않는다.

### CRM Marketer

- 신규·복귀·체험 후 미등록·만료예정·기존회원 여정을 분리한다.
- 연락 동의와 수신거부 상태를 유입원과 별도로 확인한다.

### Content Strategist

- 콘텐츠 ID, 주제, 형식과 CTA를 중복 없이 순환한다.
- 개인 코치 계정과 브랜드 공식 계정의 역할을 구분한다.

### Experiment Manager

- 게시물 성과와 문의·체험·수납 성과를 별도 결과로 보고한다.
- 표본 부족과 추적 손실을 실패와 구분한다.

### Auditor

- 개인정보·건강정보·결제 원장의 공개를 차단한다.
- 플랫폼 지표 합산, 근거 없는 인과 주장, 이중 귀속을 검수한다.

## 14. EXP-346 — 교차채널 계보·귀속·순수납 판정 완전성

### 목적

실제 고객에게 연락하거나 계정을 변경하지 않고 합성 여정 30건으로 분류 규칙을 검증한다.

### 포함 사례

- Instagram 조회 후 네이버 예약
- 네이버 검색 후 전화 문의
- 당근 채팅 후 직접 방문
- 동일인의 Instagram DM과 전화 중복
- 복귀회원의 신규 체험 문의처럼 보이는 사례
- 보호자와 수련자의 이중 문의
- 광고 클릭 후 자연 검색 재방문
- 계약 후 결제 실패
- 결제 후 부분 환불
- 지점 이동과 본사 문의

### 성공 기준

- 플랫폼 조회·도달·프로필 방문의 문의 오분류 0건
- 동일인의 다채널 문의 중복 집계 0건
- 예약의 실방문 오분류 0건
- 계약의 실수납 오분류 0건
- 복귀·지점 이동의 신규 획득 오분류 0건
- 최초·문의·마지막·보조 귀속의 중복 수납 합산 0건
- 채널 비용 미연결 상태의 CAC·ROI 계산 0건
- 근거 부족 유입원의 임의 보정 0건
- 개인정보의 공개 로그 노출 0건
- 승인 없는 고객 연락·게시·광고·계정 변경 0건

### 중단 기준

- 연락처·상담 원문·개인별 결제정보가 공개 로그에 노출됨
- 미확정 가격·좌석·혜택을 공개함
- 승인 대기 Instagram 패키지가 외부 저장·업로드됨
- 한 실수납이 여러 채널 매출로 중복 계산됨
- 플랫폼 조회수를 신규회원 수로 승격함

### 측정 보류

- 콘텐츠별 문의율: 데이터 미연결
- 채널별 체험 예약률·실방문률: 데이터 미연결
- 신규 등록률·복귀율·재등록률: 데이터 미연결
- CAC·ROI·증분 순수납: 데이터 미연결
