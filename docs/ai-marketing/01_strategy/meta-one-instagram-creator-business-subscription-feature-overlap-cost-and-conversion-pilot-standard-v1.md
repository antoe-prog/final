# Meta One Instagram 구독 기능·중복비용·전환 파일럿 판단 기준 v1

- 작성일: 2026-09-28
- 적용 대상: 파이널유도멀티짐의 Instagram 운영 검토
- 대상 계정 맥락: `@ant.toe.98`은 코치 개인 계정으로 운영하며, 브랜드 공식 발표 계정으로 간주하지 않는다.
- 상태: `NOT_SUBSCRIBED / NOT_EVALUATED`
- 목적: Meta One의 creator/business 유료 기능을 도입하기 전에 계정별 제공 여부, 기존 도구와의 중복, 비용, 보안, 실제 회원 전환 측정 가능성을 검증한다.

## 1. 공식 확인 사항

Meta는 2026-09-15 Meta One을 발표했고 다음을 안내했다.

- 무료 핵심 경험은 유지된다.
- 개인·creator·business 구독은 단계적으로 제공된다.
- creator/business Essential은 월 USD 14.99부터 시작한다.
- Advanced는 월 USD 49.99부터 시작하며 Story 사전 예약, 일반 게시물·Reels 링크, 내보낼 수 있는 분석, 심화 인사이트, 비밀번호 공유 없는 팀 접근 등의 기능을 포함한다고 안내했다.
- 상위 Expert·Max 플랜도 있으나 현재 운영 규모와 성과 데이터가 확인되지 않아 검토 대상에서 제외한다.
- 요금·기능·제공 여부는 지역·앱·계정마다 달라질 수 있다.

위 내용은 Meta 공식 발표 기준이며, 한국의 `@ant.toe.98` 계정에 같은 기능·가격이 실제 제공된다는 의미가 아니다.

## 2. CMO 우선 판단

현재 우선순위는 구독 도입이 아니라 다음 세 가지다.

1. 승인 대기 Instagram 패키지 5건·40장의 처리
2. 공개 게시물과 문의·체험·등록·재등록·실수납 연결
3. Metricool과 Meta One의 기능 중복 및 증분가치 확인

조회·도달 표본이 작고 사업 전환 데이터가 미연결인 상태에서는 유료 기능이 매출을 늘릴 것이라고 가정하지 않는다.

## 3. 계정·역할 경계

- `@ant.toe.98`: 코치 개인 계정의 전문성·친근함·유도 설명 콘텐츠에 사용
- 지점·브랜드 공지: 실제 발표 권한이 확인된 공식 채널에서만 사용
- 계정 유형: 개인/크리에이터/비즈니스 설정은 직접 확인 전 추정 금지
- 팀 접근: 비밀번호 공유 금지, 역할별 최소 권한과 회수 절차 필요
- 고객 응대 AI: 실제 운영시간·가격·혜택·시간표·지점 정보를 승인 원장과 대조할 수 있을 때만 검토

## 5. 퍼널·데이터 계약

구독 기능의 가치는 다음 이벤트를 분리해 평가한다.

`노출 → 프로필 방문 → 링크 클릭 → 유효 문의 → 체험 예약 → 실제 방문 → 신규 등록 또는 복귀 → 재등록 → 실수납 → 환불 → 순수납`

필수 필드:

- 이벤트 시각과 지점
- 계정·게시물·캠페인 식별자
- 신규/휴면/체험후미등록/기존회원 구분
- 예약과 실제 방문의 별도 상태
- 등록·재등록·환불·실수납의 별도 상태
- 개인정보 대신 내부 비식별 이벤트 ID

분모·기간·귀속 근거가 없으면 전환율과 ROI는 `계산 불가`로 남긴다.

## 6. EXP-458 — Meta One 증분가치·중복비용 검증

### 전제

대표가 비용 상한과 시험 계정을 명시적으로 승인한 뒤 한 계정·한 플랜·한 기능 묶음만 검토한다. 승인 전에는 구독 시작, 결제수단 등록, 계정 유형 변경, 팀 초대, 자동응답 설정을 하지 않는다.

### 비교

- 기준선: 현재 무료 Instagram + Metricool 운영
- 시험안: 실제 계정에 제공되는 Meta One 기능 중 승인된 기능만 사용
- 기간·최소 표본·목표 차이: 내부 기준선 연결 후 확정

### 성공 기준

- 계정별 기능·가격·세금·갱신 조건 확인률 100%
- 중복 게시·중복 예약·중복 전환 귀속 0건
- 승인 없는 비용·권한·계정 설정 변경 0건
- 미확정 가격·시간표·혜택 응답 0건
- 연결 가능한 퍼널 이벤트의 출처 연결률 95% 이상
- 기존 도구 대비 절감 시간 또는 증분 전환을 같은 기간·같은 정의로 산출 가능

### 중단 기준

- 한국 또는 대상 계정에 기능이 제공되지 않음
- 비밀번호 공유나 과도한 권한이 필요함
- 기존 Metricool 기능과 실질적으로 중복되며 측정 가능한 증분가치가 없음
- 자동응답이 민감정보·안전·환불·가격 문의를 신뢰성 있게 에스컬레이션하지 못함
- 문의·체험·등록·실수납 데이터가 계속 미연결임
- 환율·세금·갱신 조건을 포함한 실제 비용이 승인 상한을 초과함

## 7. 채널별 실행 원칙

- Instagram: 승인된 완성본만 업로드하고, 링크 기능이 제공돼도 실제 랜딩·지점·혜택이 확정되지 않으면 사용하지 않는다.
- 네이버: 동일 캠페인의 지역·시간표·가격 정보가 Instagram과 일치해야 한다.
- 당근: 생활권과 실제 지점 정보를 기준으로 운영하며 Meta 지표를 당근 성과로 합산하지 않는다.
- CRM: 휴면·체험후미등록·만료예정·기존회원을 분리하고 고객 메시지는 대표 승인 후 발송한다.

## 8. 대표 승인·입력

- 시험 대상 계정과 현재 Instagram 계정 유형
- 한국 계정에서 표시되는 Meta One 플랜·기능·실제 결제금액
- 월 비용 상한과 시험기간
- Metricool 유지·병행·대체 중 허용 범위
- 팀 접근이 필요한 역할과 최소 권한
- 링크 랜딩 페이지와 지점별 UTM 규칙
- 문의·체험·방문·등록·재등록·환불·실수납 데이터 연결
- 승인 대기 5건의 `APPROVE_EXACT / CHANGE / HOLD / DISCARD`
