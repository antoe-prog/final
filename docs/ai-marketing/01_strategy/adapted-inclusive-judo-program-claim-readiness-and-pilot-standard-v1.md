# 포용형·적응형 유도 프로그램 홍보 주장 준비도·제한 파일럿 기준 v1

- 문서 상태: 공개 가능한 운영 기준
- 기준일: 2026-09-25
- 적용 범위: 파이널유도멀티짐의 네이버·당근·Instagram·웹사이트·상담·CRM
- 대상 계정 주체: `@ant.toe.98`은 코치 개인 계정이며 브랜드·지점 공식 계정으로 간주하지 않음
- 사업 성과 상태: 문의·체험·신규 등록·복귀·재등록·실수납 데이터 미연결
- 현재 서비스 상태: 포용형·적응형 유도 프로그램의 실제 운영 승인·대상·지도역량·일정·가격·모집 여부 미확인

## 1. 목적

포용형 또는 적응형 유도에 관한 외부 사례를 실제 제공 서비스처럼 홍보하지 않도록 통제한다.  
프로그램 운영 역량, 안전, 지도 구조, 동의, 시설 접근성, 상담 책임과 성과 측정이 확인된 뒤에만 제한적으로 안내한다.

이 문서는 프로그램 개설 승인, 모집 공지, 의료·치료 효과 보장 또는 장애인 대상 서비스 제공 선언이 아니다.

## 2. 발견한 변화와 적용 범위

국제유도연맹은 2026년 9월 공개한 사례에서 다음 운영 요소를 강조했다.

1. 적절한 운영 틀, 준비와 지원이 있을 때 포용적 참여가 가능하다.
2. 코치뿐 아니라 클럽 운영자, 보호자와 연맹 관계자가 함께 교육·구조를 이해해야 한다.
3. 기술 내용, 행동과 능력을 관찰해 적절한 수준을 구분하는 절차가 필요하다.
4. 명확한 의사소통, 게임 기반 학습과 개인별 동작 조정이 지도 설계의 일부다.
5. 접근성은 기대 수준을 낮추는 일이 아니라 적절하고 존엄하며 공정한 참여 기회를 설계하는 일이다.

이는 해외 공식 사례이며 파이널유도멀티짐의 현재 서비스 역량이나 국내 수요를 증명하지 않는다.

## 3. CMO 판단

우선순위는 홍보물 제작이 아니라 **서비스 주장 준비도 확인**이다.

다음 중 하나라도 확인되지 않으면 `누구나 참여 가능`, `장애인 유도반 운영`, `맞춤 지도 제공`, `안전하게 참여 가능` 같은 모집 표현을 사용하지 않는다.

- 대표의 실제 추진 승인
- 적용 지점과 운영 책임자
- 코치의 관련 교육·경험과 역할 범위
- 대상·참여 기준과 사전 상담 절차
- 수업 구성·정원·보조 인력·비상 대응
- 시설 접근성과 이동·대기·보호자 동선
- 촬영·후기·개인정보 동의
- 일정·가격·취소·환불 조건
- 문의 목적지와 응답 담당자

## 4. 주장 준비도 상태

| 상태 | 의미 | 외부 표현 |
|---|---|---|
| `NOT_EVALUATED` | 운영 조건을 확인하지 않음 | 서비스 언급 금지 |
| `EVIDENCE_REQUESTED` | 확인 항목과 책임자를 지정 | 내부 검토 중 |
| `CAPABILITY_PARTIAL` | 일부 역량만 확인 | 모집·혜택 주장 금지 |
| `PILOT_APPROVED` | 대표가 범위·대상·지점·기간을 승인 | 승인 범위 내 파일럿만 안내 |
| `PILOT_ACTIVE` | 실제 파일럿 운영과 기록 시작 | 확정 조건만 안내 |
| `PILOT_REVIEWED` | 운영·안전·참여 결과 검토 완료 | 검토된 사실만 공개 |
| `PAUSED` | 안전·운영·동의·데이터 문제가 발생 | 신규 모집 중단 |
| `SERVICE_VERIFIED` | 지속 운영 조건과 책임 체계 확인 | 실제 제공 범위만 안내 |

상태 전환에는 책임자, 근거 문서, 확인일과 승인 범위를 남긴다. 구두 기대나 외부 사례만으로 상태를 올리지 않는다.

## 5. 운영 준비도 점검표

### 5.1 지도 역량

- 지도자별 관련 교육·자격·실무경험을 사실로 확인
- 지도자가 수행할 수 있는 조정과 수행할 수 없는 범위를 구분
- 개인의 장애·건강 정보를 마케팅 담당자가 임의로 해석하지 않음
- 보호자·참여자·코치 간 사전 의사소통 방식 지정
- 기술 설명, 시범, 반복, 휴식과 피드백 방식을 문서화
- 일반 수업 통합과 별도 수업의 기준을 사전에 정의

### 5.2 참여·수준 구분

- 진단명만으로 반·수준을 배정하지 않음
- 기술 수행, 의사소통, 행동, 이동과 지원 필요를 적절한 담당자가 확인
- 수준 구분이 낙인이나 공개 표식이 되지 않도록 통제
- 경쟁·대련·낙법·메치기·굳히기의 참여 조건을 각각 구분
- 중도 휴식·중단·보호자 연락 기준을 사전에 안내

### 5.3 안전·시설

- 매트·출입구·탈의·화장실·대기공간의 실제 접근성 점검
- 정원, 보조 인력, 위험 기술 제한과 응급 대응 책임자 지정
- 건강·복약·알레르기 정보는 필요한 최소 범위에서 비공개 처리
- 수업 전 확인과 사고·근접사고 기록 절차 마련
- 안전을 `무위험` 또는 `부상 걱정 없음`으로 홍보하지 않음

### 5.4 동의·개인정보

- 참가·보호자·결제자·촬영 동의 주체를 구분
- 장애·건강·행동·출석 정보는 민감 정보로 취급
- 공개 후기와 전후 변화는 별도 공개 동의가 없으면 사용 금지
- 회원 식별 촬영물은 승인 목적·채널·기간·철회 절차 확인
- 공개 GitHub에는 개인별 기록·연락처·건강·결제 원장을 저장하지 않음

## 7. Instagram 다음 작업 기준

포용형 유도 주제는 다음 두 형식으로 분리한다.

### 7.1 교육형 콘텐츠

IJF의 공식 사례와 일반 원칙을 출처와 함께 설명할 수 있다. 다만 다음 문구를 포함한다.

- 해외 공식 사례임
- 국내 특정 도장의 서비스 제공 근거가 아님
- 실제 참여 가능 여부는 각 도장의 운영 조건 확인이 필요함

코치 본인의 경험·지도 철학·수련 당일 사실은 제공된 근거가 있을 때만 1인칭으로 쓴다.

### 7.2 서비스·모집형 콘텐츠

`PILOT_APPROVED` 전에는 제작·승인 요청·업로드·예약·발행하지 않는다.  
승인 후에도 대상, 지점, 일정, 비용, 지원 범위, 상담 절차와 취소 조건을 실제 확정본과 대조한다.

현재 Instagram 승인 대기 적체가 해소되지 않았고 서비스 준비도도 확인되지 않았으므로 이 주제의 신규 게시 패키지는 추가하지 않는다.

## 8. 네 목표별 가설

| 목표 | 검증할 가설 | 성과로 인정하지 않는 값 |
|---|---|---|
| 신규 체험 | 명확한 참여 조건과 상담 절차가 적합한 문의를 늘리는가 | 콘텐츠 조회·좋아요 |
| 휴면 복귀 | 지원 필요와 수업 적합성을 다시 확인하면 실제 복귀가 늘어나는가 | 메시지 발송·열람 |
| 재등록·만족 | 개인별 수업 접근성과 의사소통이 지속 참여에 도움이 되는가 | 만족 표현 한 건 |
| 매출 | 승인된 서비스가 증분 실수납을 만드는가 | 예약·청구·총매출만의 증가 |

어떤 가설도 현재 성과로 확정하지 않는다. 내부 퍼널과 수납 데이터가 연결되기 전에는 계산 불가다.

## 10. EXP-451 — 포용형 유도 주장 준비도·제한 파일럿 판정

### 10.1 사전 조건

- 대표가 한 지점·한 기간·한 대상 범위를 명시적으로 승인
- 운영 책임자와 지도자 역할 확인
- 참여 기준·정원·수업안·안전·동의 절차 완료
- 실제 제공 조건과 대외 문구 대조 완료
- 문의부터 수납까지 이벤트 연결 가능

### 10.2 성공 기준

- 미확정 서비스 주장 0건
- 승인 밖 지점·대상·기간 확대 0건
- 동의 없는 민감정보 사용·촬영물 공개 0건
- 위험사건 누락 0건
- 이벤트 연결률 95% 이상
- 문의·예약·참여·등록·재등록·실수납 오귀속 0건

사업 효과는 사전에 정한 비교기간과 분모가 있을 때만 계산한다.

### 10.3 중단 기준

다음 중 하나라도 발생하면 신규 모집과 마케팅 확장을 중단한다.

- 지도·보조 인력 또는 안전 범위가 승인 조건을 충족하지 못함
- 참여자·보호자 동의 상태를 확인할 수 없음
- 시설·수업 접근성의 핵심 장애요인이 해결되지 않음
- 장애·건강 특성을 과장·낙인·치료 효과로 표현
- 기존회원 이동을 신규 유입으로 계산
- 환불·취소를 제외한 순수납을 계산할 수 없음

## 11. 대표 승인·입력

1. 이 주제의 실제 프로그램 검토 여부
2. 적용 지점·운영 책임자·지도자 역량 근거
3. 대상과 참여 기준, 사전 상담 책임자
4. 수업 구성·정원·보조 인력·비상 대응
5. 시설 접근성 점검 결과
6. 일정·가격·취소·환불 조건
7. 촬영·후기·민감정보 동의 절차
8. 파일럿 성과 원천과 비교기간

입력이 없으면 상태는 `NOT_EVALUATED` 또는 `EVIDENCE_REQUESTED`에 머문다.

## 12. Auditor 금지 규칙

- 외부 성공 사례를 내부 서비스 성과로 전환하지 않음

- 승인 대기 Instagram 미디어·캡션·대체 텍스트를 공개 저장소에 올리지 않음
