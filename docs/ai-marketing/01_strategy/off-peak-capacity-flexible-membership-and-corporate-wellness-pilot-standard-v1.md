# 비혼잡 시간대·이용 유연성·기업복지 제휴 파일럿 기준 v1

- 문서 상태: 공개 운영 기준
- 기준일: 2026-09-25
- 적용 범위: 파이널유도멀티짐의 신규 체험, 휴면 복귀, 재등록·만족, 매출 증대 검증
- 실험 ID: `EXP-450`
- 승인 원칙: 비용, 가격·상품 변경, 제휴 계약, 고객 메시지, 광고, 계정 변경은 대표 승인 전 실행하지 않는다.

## 1. 이번에 확인한 외부 변화

Wellhub가 2026년 9월 23일 공개한 *Fitness Business Growth Report 2026* 보도자료는 11개국 662개 체육시설·스튜디오 운영자 설문을 다음과 같이 요약한다.

- 86%는 2026년에 회원 기반이 성장했다고 응답했다.
- 56%는 이익률이 개선됐다고 응답했다.
- 95%는 최근 3년간 경쟁이 심화됐다고 응답했다.
- 86%는 고객의 가격 민감도가 높아졌다고 응답했다.
- 고객 요청으로 유연하거나 짧은 계약 66%, 디지털·하이브리드 선택지 65%, 회복 서비스 48%, 더 낮은 가격 46%가 제시됐다.
- 82%는 고객획득비용이 증가했다고 응답했다.
- 65%는 지난 1년간 CRM, 예약, 자동화, AI 등을 포함한 기술에 투자했다고 응답했다.
- 85%는 비혼잡 시간대에 시설의 최소 25%가 미사용이라고 응답했지만, 이를 수익화하는 전략이 있다고 답한 비율은 20%였다.

조사 기간은 2026년 3월 30일~4월 9일이다. 미국·브라질·영국·스페인·독일·이탈리아·포르투갈·루마니아·멕시코·칠레·아르헨티나가 포함됐고 한국은 포함되지 않았다.

## 2. 해석 제한

이 자료는 파이널유도의 수요·매출·전환율을 증명하지 않는다.

- 한국 시장과 유도장에 직접 일반화할 수 없다.
- 공급업체인 Wellhub가 발표한 조사이며 제휴 사업 이해관계가 있다.
- Wellhub 제휴 여부는 무작위 배정이 아니므로 제휴 시설과 비제휴 시설의 차이를 인과효과로 해석할 수 없다.
- ‘미사용 공간’은 파이널유도의 실제 정원·출석·코치 인력과 연결되지 않았다.
- ‘유연성’은 할인이나 저가 상품을 뜻하지 않는다. 시간, 계약, 예약, 수업 선택의 어떤 요소가 필요한지 별도 검증해야 한다.
- 회원수, 체험수, 복귀수, 재등록수, 매출, 수납, 원가, 시간대별 가동률은 현재 데이터 미연결이다.

## 3. 오늘의 전략적 판단

우선순위는 새로운 할인 상품 출시가 아니라 **시간대별 실제 가동률과 고객이 요구하는 유연성의 종류를 연결하는 것**이다.

```text
시간대별 공급 확인
  → 유효 문의의 시간 제약 확인
  → 체험 예약
  → 실제 방문
  → 신규 등록 또는 휴면 복귀
  → 30일 이용 지속
  → 재등록·순수납
```

각 단계가 연결되지 않으면 비혼잡 시간대 이용이 늘어도 신규 수요인지 기존 이용의 이동인지 판단할 수 없다.

## 4. 네 목표별 적용 가설

### 신규 체험회원 확보

가설: 일부 유효 문의는 가격보다 가능한 시간대 부족 때문에 체험 예약으로 진행되지 않는다.

검증할 항목:

- 최초 문의 시 선호 요일·시간대
- 안내 가능한 시간대 수
- 예약 여부
- 실제 방문 여부
- 미방문 사유
- 채널과 지점

확인 전에는 ‘시간대 선택 가능’, ‘기업 제휴 가능’, ‘짧은 계약 가능’을 광고 문구로 사용하지 않는다.

### 휴면회원 복귀

가설: 휴면 사유 중 일정 충돌이 확인된 집단에는 비혼잡 시간대의 실제 참여 가능 여부를 안내하는 것이 일반 복귀 문구보다 적합할 수 있다.

검증할 항목:

- 휴면 기준일과 사유 분류
- 일정 충돌 여부
- 안내한 실제 시간대
- 응답, 예약, 방문, 복귀
- 복귀 후 30일 출석

개별 사유·연락처·출석기록은 공개 저장소에 올리지 않는다.

### 기존회원 재등록·만족

가설: 가격 인하보다 일정 선택 가능성과 예약 예측 가능성이 만족과 재등록에 더 중요할 수 있다.

검증할 항목:

- 만료예정 기준
- 최근 30일 출석 빈도
- 시간대 불편 접수 여부
- 재등록 의향
- 실제 재등록
- 변경된 이용 시간대

만족도 응답과 실제 재등록을 같은 KPI로 합산하지 않는다.

### 매출 증대

가설: 비혼잡 시간대에 외부에서 유입된 신규 방문이 발생하면 기존 고정비 범위에서 추가 수입 가능성을 검증할 수 있다.

필수 분리:

- 기존회원의 시간 이동
- 휴면회원 복귀
- 신규 체험
- 신규 등록
- 제휴 채널 이용
- 실수납
- 환불·수수료·제휴비용을 제외한 순수납

총 방문 증가를 매출 증가로 계산하지 않는다.

## 5. 채널별 준비안

- ‘퇴근 후’, ‘등교 전’, ‘점심시간’ 등 생활권 표현은 해당 지점의 확정 시간표가 있을 때만 사용한다.
- 검색 노출, 전화, 길찾기, 문의, 체험 예약, 실제 방문을 분리한다.

### 당근

- 조회와 채팅을 체험으로 계산하지 않는다.
- 할인·무료·한정 혜택은 대표가 조건과 비용을 승인한 경우에만 쓴다.

### Instagram @ant.toe.98

- 지점 전체의 공식 시간표나 제휴 발표 주체로 표현하지 않는다.
- 현재 승인 대기 적체가 해소되기 전 새 게시 패키지를 추가하지 않는다.
- 게시물 조회·도달·저장·공유·팔로우와 문의·체험·등록을 분리한다.

## 6. 최소 데이터 계약

내부 비공개 원장에서 다음 이벤트를 익명 식별자로 연결한다.

| 단계 | 필수 필드 |
|---|---|
| 문의 | 이벤트 ID, 지점, 채널, 발생일, 선호 시간대, 유효 여부 |
| 체험 예약 | 예약 ID, 문의 ID, 예약일, 대상 시간대 |
| 실제 방문 | 방문 여부, 방문일, 불참 사유 |
| 등록·복귀 | 구분, 시작일, 연결된 문의·예약 ID |
| 이용 지속 | 7일·30일 출석 여부 |
| 재등록 | 만료일, 재등록일, 상태 |
| 수납 | 총수납, 환불, 채널 수수료, 순수납 |
| 공급 | 지점, 수업일, 시간대, 정원 정의, 실제 출석 |

분모가 0이거나 필드가 없으면 비율은 ‘계산 불가’로 남긴다.

## 7. EXP-450 — 비혼잡 시간대 수요·증분성 판정 실험

### 단계 A: 기준선 연결

대표가 승인한 지점에서 최소 4주간 기존 운영을 변경하지 않고 시간대별 정원 정의·실제 출석·문의 선호시간·예약·방문을 연결한다.

진행 조건:

- 정원 정의가 지점·수업별로 고정돼 있다.
- 문의→예약→방문 이벤트 연결률이 95% 이상이다.
- 기존회원 시간 이동과 신규·복귀 방문을 구분할 수 있다.
- 개인정보는 비공개 원장에만 보관한다.

조건을 충족하지 못하면 제휴·상품 실험으로 넘어가지 않는다.

### 단계 B: 유연성 수요 분류

고객에게 실제 발송하기 전 대표가 문항과 대상을 승인한다. 선택지는 가격 인하를 전제로 하지 않고 다음을 구분한다.

- 다른 요일
- 다른 시간대
- 예약 변경 편의
- 짧은 이용기간
- 디지털 보조자료
- 해당 없음

관심 응답을 예약이나 구매로 계산하지 않는다.

### 단계 C: 제한 파일럿

가격·기간·정원·대상·지점·중단 기준을 대표가 사전 승인한 경우에만 한 지점·한 유형으로 시험한다.

필수 비교:

- 기준선 대비 비혼잡 시간대 신규·복귀 실제 방문
- 기존회원 시간 이동을 제외한 증분 방문
- 체험 예약 대비 실제 방문
- 방문 대비 등록·복귀
- 30일 지속
- 환불·수수료를 제외한 순수납
- 혼잡도·코치 업무량·기존회원 불편

### 성공 기준

- 승인 밖 비용·메시지·가격·계정 변경: 0건
- 문의→예약→방문→등록 이벤트 오결합: 0건
- 기존회원 시간 이동을 신규 유입으로 계산: 0건
- 조회·채팅·관심 응답을 체험으로 승격: 0건
- 분자·분모·기간·지점·출처 누락: 0건
- 개인정보·내부 원장 공개 저장소 노출: 0건
- 대표가 사전 고정한 사업 기준을 충족할 때만 확대

### 중단 기준

다음 중 하나면 즉시 중단하고 원인을 기록한다.

- 정원 또는 기준선 정의가 실행 중 변경됨
- 신규·복귀·기존회원 이동을 구분할 수 없음
- 안전·수업 품질·기존회원 이용에 부정적 영향 발생
- 승인되지 않은 할인·혜택·제휴비용이 필요함
- 순수납 계산에 필요한 비용 데이터가 없음
- 표본이 부족한데 성과를 일반화하려 함
