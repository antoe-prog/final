# 마케팅 예산·승인·집행·청구·CAC·ROI·증분성 기준 v1

- 적용 범위: 파이널유도멀티짐의 네이버·Google·Meta·당근·제휴·콘텐츠 제작·CRM 캠페인
- 문서 목적: 예산 설정, 플랫폼 집행, 청구, 결제, 문의, 등록, 실수납을 분리해 광고비와 성과를 과장 없이 판단한다.
- 공개 범위: 상태 정의, 승인 게이트, 데이터 사전, 계산식, 합성 검증 기준
- 공개 제외: 실제 예산·원가·마진, 카드·계좌·세금계산서 원본, 고객 식별정보, 관리자 계정, 비밀키, 승인 대기 Instagram 콘텐츠
- 작성일: 2026-09-17
- 내부 광고비·전환·매출 상태: **데이터 미연결**

## 1. 핵심 판단

다음은 서로 다른 사건이다.

`예산안 작성 ≠ 예산 승인 ≠ 캠페인 설정 ≠ 심사 통과 ≠ 광고 게재 ≠ 플랫폼 비용 발생 ≠ 청구 확정 ≠ 결제 완료 ≠ 유효 문의 ≠ 체험 예약 ≠ 실제 방문 ≠ 신규 계약 ≠ 실수납 ≠ 순수납 ≠ 증분 성과`

일 예산은 실제 비용이 아니고, 플랫폼의 `amount spent`는 카드 결제나 회계상 확정 비용과 같지 않을 수 있다. 클릭·리드·예약을 신규회원 또는 매출로 계산하지 않는다. 광고에 귀속된 실수납이 있어도 광고가 없었다면 발생하지 않았을 **증분 성과**인지는 별도 검증한다.

관리 순서는 다음과 같다.

`목표·지점·수용능력 확인 → 예산·기간·중단선 승인 → 캠페인 버전 잠금 → 공개 전 검수 → 게재 확인 → 발생비용 수집 → 청구·결제·환급 대조 → 문의 중복 제거 → 예약·실방문·계약·실수납 연결 → 비용 완전성 검토 → CAC·ROAS·ROI 계산 → 증분성 판정`

대표의 명시적 승인 전에는 광고 집행, 결제수단 등록·변경, 예산 증액, 고객 연락을 하지 않는다.

## 2. 네 목표와의 연결

| 목표 | 비용과 연결할 실제 결과 | 금지되는 대체 지표 |
|---|---|---|
| 신규 체험회원 확보 | 유효 문의·체험 예약·실방문·신규 실수납 | 노출·클릭·폼 시작 |
| 휴면회원 복귀 | 적격 복귀 의사·실제 재참여·복귀 실수납 | 광고 조회·링크 클릭 |
| 기존회원 재등록·만족 | 재등록 계약·실수납·서비스 이행·확인된 만족 | 좋아요·메시지 열람 |
| 매출 증대 | 환불·직접비를 반영한 순수납과 검증된 증분 순수납 | 청구액·예약액·플랫폼 전환값 |

같은 캠페인이 네 목표 모두에 기여한다고 자동 분배하지 않는다. 캠페인마다 1차 목적을 하나 정하고, 나머지는 보조 결과로 분리한다.

## 3. 기존 기준과의 경계

- `naver-advoost-place-beta-readiness-budget-and-offline-conversion-standard-v1.md`: 네이버 ADVoost 플레이스의 기능·출시·자동소재·단일 지점 파일럿 준비
- `cross-channel-content-source-inquiry-trial-enrollment-and-revenue-attribution-standard-v1.md`: 접점·문의·체험·등록·수납의 교차채널 귀속
- `promotion-offer-discount-benefit-redemption-and-incremental-net-revenue-standard-v1.md`: 가격·혜택·쿠폰·사용·서비스 이행의 증분 순수납
- 이 문서: 모든 유료·제작·대행 활동의 예산 승인, 실제 발생비용, 청구·결제 대조, 비용 완전성, CAC·ROAS·ROI·증분성 판정

플랫폼별 운영 문서가 있어도 공통 비용 원장과 재무 대조를 생략하지 않는다.

## 4. 캠페인과 예산 객체

캠페인마다 변경 불가능한 `campaign_version`을 둔다.

| 필드 | 정의 |
|---|---|
| `campaign_id`, `campaign_version` | 캠페인 계열과 승인된 고정 버전 |
| `objective` | 신규 체험·복귀·재등록·순수납 중 1차 목적 |
| `branch_scope` | 적용 지점과 제외 지점 |
| `channel`, `platform_account_ref` | 채널과 내부 비공개 계정 참조값 |
| `start_at`, `end_at` | 승인된 집행 기간 |
| `budget_type` | DAILY / LIFETIME / TOTAL_CAP / PROJECT |
| `approved_budget_cap` | 승인된 최대 비용; 공개 저장소에는 실제값 제외 |
| `currency`, `tax_treatment` | 통화와 부가세 포함·별도 기준 |
| `owner`, `approver` | 운영 책임자와 승인권자 |
| `stop_rule` | 비용·품질·수용능력·정책 중단 조건 |
| `measurement_window` | 문의·방문·등록·환불 관찰기간 |

목표, 지점, 기간, 대상, 소재, 랜딩, 예산, 결제주체 중 하나라도 실질적으로 바뀌면 새 버전을 만든다. 단순 오탈자 수정도 공개 결과에 영향을 주면 변경 이력을 남긴다.

## 6. 예산 승인 게이트

다음이 모두 확인돼야 집행 승인을 요청할 수 있다.

1. 실제 운영 지점과 공개 상호·주소·문의 경로가 일치한다.
2. 광고할 수업의 운영시간, 코치, 안전 정원, 기존회원 보호석과 체험석이 확인됐다.
3. 미확정 가격·무료체험·잔여좌석·혜택·행사를 소재에 넣지 않았다.
4. 랜딩·전화·예약·메시지 도착점과 담당자 인계를 검증했다.
5. 신규·복귀·기존회원·지점 이동의 판정 기준이 있다.
6. 일 예산·총상한·기간·통화·세금·결제주체를 승인했다.
7. 비용이 예상보다 빠르게 발생할 때의 경보·일시중지·승인권자를 정했다.
8. 문의→예약→실방문→계약→실수납의 기준 원천과 관찰기간이 있다.
9. 광고비 외 제작·대행·랜딩·도구·수수료·혜택 직접비의 포함 범위를 정했다.
10. 개인정보·미성년자·촬영물·광고성 정보 동의와 수신거부를 확인했다.

하나라도 빠지면 `NOT_READY` 또는 `DATA_UNCONNECTED`다.

## 7. 플랫폼 예산을 해석하는 원칙

### 7.1 Google Ads

Google은 대부분 캠페인에서 평균 일 예산과 실제 일별 비용이 같지 않을 수 있고, 일·월 지출 한도를 별도로 설명한다. 따라서 `average_daily_budget`, `daily_spending_limit`, `monthly_spending_limit`, `served_cost`, `billed_cost`를 한 필드로 합치지 않는다. 예산 변경일에는 변경 전후 값을 시간과 함께 기록한다.

### 7.2 Meta 광고

Meta는 일 예산을 평균값으로 설명하며 하드 캡이 아니라고 안내한다. `budget`, `amount_spent`, 청구 내역과 실제 결제를 구분한다. 계정 지출 한도는 캠페인 예산의 대체물이 아니며, 한도 변경·재설정은 별도 승인 행동이다.

### 7.3 네이버·당근·기타

- 플랫폼의 클릭·문의·채팅·예약 정의를 그대로 보존한다.
- 자동 입찰·자동 소재·일 예산 소진 가능성을 사전에 기록한다.
- 선불 충전, 비즈머니, 쿠폰, 크레딧을 실제 광고비와 분리한다.
- 플랫폼이 제공하지 않는 지표를 0으로 만들지 않고 `NOT_AVAILABLE`로 둔다.

외부 플랫폼의 권장 예산·업계 평균은 내부 승인액이나 성공 기준으로 사용하지 않는다.

## 8. 비용 원장의 범위

### 8.1 직접 미디어 비용

- 플랫폼 발생비용
- 청구 조정·세금·환율 차이
- 환급·크레딧·무효 클릭 조정

### 8.2 캠페인 직접비

- 외부 대행 수수료
- 콘텐츠 제작·디자인·촬영·편집비
- 랜딩페이지·폼·추적도구의 캠페인 귀속 비용
- 쿠폰·증정·제휴 보상 등 직접 혜택비용

### 8.3 내부비용

내부 인건비·코치 응대시간·공간 기회비용은 포함 범위와 계산 규칙을 승인한 경우만 사용한다. 연결되지 않은 비용을 0으로 가정하지 않는다.

### 8.4 다지점 배분

- 한 캠페인의 비용을 문의 건수 비율로 자동 배분하지 않는다.
- 지점 전용 소재·랜딩·전화번호가 있으면 직접 귀속한다.
- 공용 캠페인은 승인된 배분 키와 버전을 기록한다.
- 문의 지점, 방문 지점, 계약 지점, 수납 지점이 다르면 각각 보존한다.
- 지점 이동·기존회원의 타 지점 등록을 신규 획득으로 만들지 않는다.

실제 값은 권한이 제한된 내부 시스템에 저장하고 공개 저장소에는 스키마만 둔다.

## 10. KPI와 계산식

모든 값에 분자·분모·기간·캠페인 버전·지점·원천·관찰 성숙도를 붙인다.

| KPI | 계산식 | 제한 |
|---|---|---|
| 유효 문의당 비용 | 완전한 캠페인 비용 ÷ 중복 제거 유효 문의 | 클릭·폼 시작 제외 |
| 체험 예약당 비용 | 완전한 캠페인 비용 ÷ 예약 확정자 | 예약 제안 제외 |
| 실제 체험당 비용 | 완전한 캠페인 비용 ÷ 실제 참석자 | 노쇼·사업자 취소 분리 |
| CAC | 완전한 캠페인 비용 ÷ 실수납 확인 신규회원 | 계약만 있고 미수납이면 제외 |
| 복귀 획득비용 | 복귀 목적 완전비용 ÷ 실수납 확인 복귀회원 | 신규 CAC와 분리 |
| 재등록 획득비용 | 재등록 목적 완전비용 ÷ 실수납 확인 재등록회원 | 유지비용 범위 승인 필요 |

| 마케팅 ROI | (캠페인 귀속 순기여 - 완전한 캠페인 비용) ÷ 완전한 캠페인 비용 | 순기여 원가 기준 필요 |
| 증분 CAC | 완전한 캠페인 비용 ÷ 검증된 증분 신규회원 | 증분성 미검증이면 계산 금지 |
| 증분 ROI | 검증된 증분 순기여 ÷ 완전한 캠페인 비용 | 비교 가능 대조 필요 |

분모가 0이면 `DIVISION_UNAVAILABLE`, 데이터가 없으면 `DATA_UNCONNECTED`, 관찰기간 전이면 `IMMATURE`다. 외부 업체의 권장 CAC·ROAS·ROI를 내부 목표로 복사하지 않는다.

## 11. 귀속과 증분성

### 11.1 귀속

- 최초 접점, 문의 발생 접점, 마지막 비직접 접점, 보조 접점을 분리한다.
- Instagram·네이버·당근·전화·웹 문의의 동일인을 비공개 기준 시스템에서만 중복 제거한다.
- 플랫폼 자체 보고 전환과 내부 확인 전환을 나란히 보존한다.
- 자연유입, 추천, 기존 관계가 확인되면 유료 광고의 단독 성과로 확정하지 않는다.
- 귀속창이 끝나지 않은 캠페인을 실패로 판정하지 않는다.

### 11.2 증분성

가능하면 안전·수용능력을 해치지 않는 지점·기간 교대, 홀드아웃 또는 단계적 도입을 사용한다. 대조군은 동일 지점·수업·계절·가격·정원·운영환경의 비교 가능성을 확인한다.

다음 경우 `INCREMENTALITY_UNVERIFIED`를 유지한다.

- 광고 전 기준선이 없음
- 동시에 가격·시간표·코치·혜택·지점 정보가 바뀜
- 대조군 노출 오염 여부를 알 수 없음
- 유료·자연·추천 문의가 중복됨
- 환불·차지백 관찰기간이 끝나지 않음
- 수용능력 부족으로 실제 예약을 받을 수 없음

## 12. 중단·경보 기준

수치 임계값은 내부 데이터와 대표 승인 없이 임의로 정하지 않는다. 아래 사건은 값과 관계없이 검토를 시작한다.

- 승인된 총상한 또는 플랫폼 지출 한도에 접근
- 승인되지 않은 예산·기간·지점·소재 변경
- 다른 지점의 주소·전화·가격·이미지 노출
- 문의가 담당자에게 도착하지 않거나 중복 생성
- 체험석 부족, 기존회원 보호석 침해, 코치·안전 정원 미확인
- 미확정 가격·무료·한정·성과 주장 노출
- 결제수단·청구·플랫폼 발생비용 간 설명되지 않는 차이
- 개인정보·미성년자·촬영 동의 문제
- 플랫폼 정책 위반·계정 제한·부정 클릭 의심

일시중지 클릭만으로 중단 완료를 선언하지 않고 공개 게재와 후행 비용을 재확인한다.

## 14. EXP-353 — 예산·집행·청구·CAC·ROI 판정 완전성

### 목적

실제 광고 계정과 고객을 사용하지 않는 합성 캠페인 48건으로 상태·비용·성과 계산이 오분류되지 않는지 검증한다.

### 합성 시나리오

- 일 예산과 실제 일비용이 다른 캠페인
- 승인 후 예산이 변경된 캠페인
- 게재 중지 후 후행 비용이 발생한 캠페인
- 발생비용·청구액·지급액·환급액이 다른 캠페인
- 세금·대행·제작비가 누락된 캠페인
- 다지점 공용 캠페인과 지점 이동 문의
- 클릭은 있으나 실제 문의가 없는 캠페인
- 예약 후 미방문·계약 후 미수납·수납 후 환불 사례
- 자연유입·추천·유료 문의가 중복된 사례
- 관찰기간이 끝나지 않은 코호트

### 성공 기준
