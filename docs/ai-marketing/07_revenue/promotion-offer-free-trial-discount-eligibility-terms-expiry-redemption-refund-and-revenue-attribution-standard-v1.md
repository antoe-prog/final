# 체험·무료·할인·기간한정·혜택·쿠폰·환불·매출 귀속 기준 v1

- 상태: 공개 가능한 마케팅·매출 운영 기준
- 기준일: 2026-09-19
- 적용 범위: 파이널유도멀티짐의 네이버·Instagram·당근·웹·오프라인 안내와 신규 체험, 휴면 복귀, 기존회원 재등록 캠페인
- 공개 제외: 회원·보호자 식별정보, 연락처, 개인별 출석·건강·결제 원장, 비밀키, 내부 원가·예산·손익, 미확정 행사, 승인 대기 Instagram 미디어·캡션
- 핵심 원칙: 광고 문구, 혜택 청구, 자격 확인, 실제 사용, 결제 승인, 실수납, 환불과 순수납을 서로 다른 사건으로 기록한다.

## 1. 목적

체험·할인·혜택은 문의 장벽을 낮출 수 있지만, 승인되지 않은 가격이나 조건을 공개하거나 클릭·쿠폰 발급을 매출로 집계하면 고객 신뢰와 성과 측정이 함께 무너진다. 이 기준은 다음 오류를 막는다.

1. 내부 초안 또는 검토 중인 혜택을 공개하는 오류
2. 무료 체험의 대상·횟수·기간·제외 조건을 빠뜨리는 오류
3. 근거 없는 `오늘만`, `마감 임박`, `선착순` 문구를 쓰는 오류
4. 한 지점의 혜택을 모든 지점 공통으로 표현하는 오류
5. 신규·휴면·기존회원 자격을 서로 바꾸어 적용하는 오류
6. 쿠폰 발급이나 코드 입력을 실제 사용으로 계산하는 오류
7. 등록 의사·청구서 발행·결제 승인을 실수납으로 계산하는 오류
8. 환불·취소·차지백을 제외하지 않고 매출을 보고하는 오류
9. 같은 결제를 지점·광고·CRM·추천 성과로 중복 귀속하는 오류
10. 코치 개인 Instagram을 브랜드 공식 가격 공지 주체로 오인시키는 오류

## 2. 오늘의 우선 판단

현재 승인된 가격표, 무료 체험 정책, 할인·쿠폰 정책, 회원·결제 원장이 연결되지 않았다. 따라서 프로모션 전환율, 할인 사용률, 순수납과 ROI는 계산할 수 없다.

외부 공개보다 먼저 아래 순서를 고정한다.

1. 대표가 혜택 목적과 예산을 승인한다.
2. 대상 지점·프로그램·회원 상태·기간을 확정한다.
3. 가격·비용·중복 사용·취소·환불 조건을 검토한다.
4. 채널별 최종 문안과 랜딩 정보를 승인한다.
5. 공개 후 청구·자격 확인·사용·실수납·환불을 각각 기록한다.
6. 순수납과 유지·복귀 결과를 중복 제거해 평가한다.

## 4. 공개 전 필수 승인 원장

각 프로모션은 `offer_id` 하나를 부여하고 다음을 확정한다.

| 필드 | 필수 내용 |
|---|---|
| offer_id | 캠페인별 고유값 |
| objective | 신규 체험·휴면 복귀·재등록·만족 중 하나의 1차 목표 |
| owner | 운영 책임자와 백업 담당자 |
| approval_version | 대표가 승인한 문안·조건 버전 |
| eligible_locations | 적용 지점 |
| eligible_programs | 적용 수업·프로그램 |
| eligible_member_status | 신규·휴면·만료예정·기존회원 등 |
| start_at / end_at | 시작·종료 시각과 Asia/Seoul 시간대 |
| benefit_type | 무료·정액 할인·정률 할인·크레딧·추가 수업 등 |
| standard_price | 비교 기준 가격과 적용 근거 |
| payable_price | 고객이 실제 지급할 가격 |
| quantity_or_capacity | 실제 한도가 있을 때만 수량·정원 |
| claim_limit | 1인·가구·계정·결제수단별 청구 제한 |
| stacking_rule | 다른 혜택·추천·제휴와 중복 가능 여부 |
| exclusions | 제외 프로그램·기간·품목·회원 상태 |
| cancellation_rule | 예약 변경·취소 기준 |
| refund_rule | 환불·부분 사용·차지백 처리 |
| guardian_rule | 미성년자 보호자 확인 방식 |
| channels | 네이버·Instagram·당근·웹·현장 등 |
| approved_assets | 승인된 이미지·문안·랜딩 버전 |
| source_systems | 청구·예약·출석·결제 기준 시스템 |

값이 정해지지 않은 필드는 `미확정`으로 남기고 공개하지 않는다. 임의의 기본값을 채우지 않는다.

## 5. 문구 기준

### 5.1 반드시 명확히 할 내용

- 무엇이 무료 또는 할인되는지
- 누구에게 적용되는지
- 어느 지점·프로그램에서 적용되는지
- 언제 시작하고 종료되는지
- 별도 비용이나 제외 항목이 있는지
- 중복 사용 가능 여부
- 예약·취소·환불의 확인 경로
- 정원이나 수량 제한이 사실일 때 그 기준

모든 내용을 이미지 한 장에 밀어 넣지 않아도 된다. 다만 핵심 자격·가격·기간을 숨긴 채 `자세한 내용은 문의`만 두지 않는다.

### 5.2 금지 또는 보류 문구

승인·증거 없이 다음 표현을 사용하지 않는다.

- `무조건 무료`, `전원 증정`, `평생`, `100%`
- `오늘만`, `마감 임박`, `마지막 기회`
- `선착순 N명` 또는 `잔여 N자리`
- `최저가`, `최대 할인`, `반값`
- `지금 등록하면 반드시 효과`
- 실제 표준가격 근거가 없는 취소선 가격
- 별도 비용이 있는데 `완전 무료`
- 특정 지점만 적용되는데 전 지점 공통처럼 보이는 문구

실제 정원 감소나 종료 임박을 표시할 때도 원천 시스템, 갱신 시각과 공개 담당자를 기록한다. 수동 카운트는 자동 실시간 값처럼 표현하지 않는다.

## 6. 채널별 적용

### 6.1 네이버·Google 지역 프로필

- 상시 사업 소개는 서비스·운영 정보를 중심으로 유지한다.
- 가격·특가를 사업명이나 상시 설명에 삽입하지 않는다.
- 기간성 안내는 승인된 게시 영역에서 정확한 기간·지점·조건을 제시한다.
- 프로필 노출·길찾기·통화·웹 클릭을 혜택 사용이나 방문으로 계산하지 않는다.

### 6.2 코치 개인 Instagram `@ant.toe.98`

- 코치 개인 계정임을 유지하고 브랜드 본사의 공식 발표 주체처럼 쓰지 않는다.
- 일반 유도 교육 콘텐츠와 가격·혜택 공지를 구분한다.
- 브랜드 프로모션을 소개할 때는 승인된 주체·지점·조건으로 연결한다.
- 승인 대기 미디어·캡션은 Instagram, 외부 초안 저장소 또는 공개 GitHub에 올리지 않는다.
- 완성본의 이미지·순서·캡션·계정·형식에 대한 게시 승인을 받은 뒤에만 업로드·예약·발행한다.

### 6.3 당근과 지역 커뮤니티

- 실제 적용 지역과 지점을 좁혀 표시한다.
- 지역명만 바꾼 동일 게시물을 무차별 반복하지 않는다.
- 채팅 시작을 예약·체험·등록으로 자동 승격하지 않는다.
- 지역별 가격이나 제공 조건이 다르면 하나의 공통 혜택처럼 합치지 않는다.

### 6.4 현장 안내

- 포스터·상담 스크립트·결제 화면의 조건 버전을 맞춘다.
- 종료된 인쇄물을 회수하고 예외 약속은 승인자와 이행 상태를 기록한다.
- 직원의 구두 약속을 공식 정책으로 자동 확대하지 않는다.

## 7. 자격과 중복 사용

### 7.1 회원 상태

`신규`, `휴면`, `만료예정`, `기존`, `복귀`, `재등록`의 기준일과 원천 시스템을 대표가 정한다. 연락이 없었다거나 출석 공백이 있다는 이유만으로 휴면 자격을 추정하지 않는다.

### 7.2 중복 제거

아래 키는 공개하지 않고 내부 통제 환경에서만 사용한다.

- 회원 또는 보호자 내부 ID
- 회원권·예약·결제 ID
- 지점·프로그램 ID
- offer_id와 claim_id
- 가구 중복 검토용 내부 신호

동일 주소·성·결제수단만으로 부정사용을 자동 확정하지 않는다. 검토 신호와 최종 판정을 분리한다.

### 7.3 중복 혜택

추천 혜택, 제휴 할인, 복귀 혜택, 재등록 혜택과의 중복 순서를 사전에 정한다. 적용 순서가 정해지지 않으면 결제를 보류하고 담당자가 확인한다.

## 8. 종료·철회·오류 대응

1. 종료 시각이 지나면 신규 노출·청구 경로를 중단한다.
2. 예약·발행·고정 게시물·하이라이트·랜딩·QR을 함께 확인한다.
3. 종료 전 유효하게 청구한 사람의 이행 기준을 별도로 적용한다.
4. 잘못된 가격·조건이 공개되면 증거를 보존하고 신규 사용을 보류한다.
5. 수정·사과·이행·환불 여부는 사실관계와 승인권자가 결정한다.
6. 삭제만으로 오류 사건을 종결하지 않는다.
7. 종료 또는 철회가 기존 결제의 자동 환불을 의미하지 않는다.

## 9. 결제와 매출 귀속

### 9.1 금액 구분

| 값 | 정의 |
|---|---|
| 표준가격 | 비교 기준이 되는 승인 가격 |
| 할인액 | 표준가격에서 차감된 승인 금액 |
| 결제예정액 | 청구 예정 금액 |
| 승인액 | 결제수단 승인 금액 |
| 실수납액 | 실제 수납이 확인된 금액 |
| 환불액 | 환불 완료 금액 |
| 차지백액 | 차지백 완료 금액 |
| 순수납액 | 실수납액 - 환불액 - 차지백액 |
| 직접 변동비 | 대표가 승인한 혜택·결제·제공 원가 |
| 순기여 | 순수납액 - 직접 변동비 |

내부 원가·예산·손익 수치는 공개 저장소에 저장하지 않는다.

### 9.2 귀속 원칙

- 쿠폰 발급은 사용이 아니다.
- 혜택 사용은 체험 실참여가 아니다.
- 체험 실참여는 신규 등록이 아니다.
- 등록 완료는 실수납이 아니다.
- 결제 승인은 최종 순수납이 아니다.
- 환불 대기 중 금액은 순수납 확정에서 보류한다.
- 한 결제의 1차 획득 채널과 후속 CRM 채널을 분리한다.
- 추천·광고·지역 프로필·Instagram의 중복 귀속을 제거한다.

| 등록 전환율 | 등록 완료 | 체험 실참여 | 데이터 미연결 |
| 수납 전환율 | 실수납 발생 등록 | 등록 완료 | 데이터 미연결 |
| 환불률 | 환불 완료 건 | 실수납 건 | 데이터 미연결 |
| 순수납 | 실수납액 - 환불액 - 차지백액 | 해당 없음 | 데이터 미연결 |
| 프로모션 순기여 | 순수납액 - 직접 변동비 | 해당 없음 | 데이터 미연결 |
| ROI | 순기여 / 승인 집행비 | 승인 집행비 | 데이터 미연결·계산 불가 |

모든 비율은 기간, 시간대, 지점, 프로그램, 대상 상태, 분자, 분모와 원천 시스템을 함께 표시한다. 분모가 0이면 계산하지 않는다.

## 11. 채널 실행 초안

실제 가격·혜택을 넣기 전의 구조만 정의한다.

### 네이버

`[대상]을 위한 [프로그램] 안내입니다. 적용 지점은 [지점], 기간은 [시작~종료], 포함 내용은 [내용]입니다. 가격·준비물·취소 기준은 승인된 상세 안내에서 확인해 주세요.`

### 당근

`[지역]에서 [대상]이 참여할 수 있는 [프로그램]을 안내합니다. 실제 운영 지점·시간·자격·비용은 아래 확정 정보를 확인해 주세요.`

### 상담 체크리스트

1. 문의한 지점과 프로그램
2. 신규·휴면·기존회원 등 자격 기준
3. 적용 기간과 잔여 정원 근거
4. 포함·제외 비용
5. 중복 혜택 여부
6. 예약·취소·환불 기준
7. 안내한 조건 버전

승인된 값이 없으면 문안을 공개하거나 고객에게 발송하지 않는다.

## 12. EXP-399 — 프로모션 승인·조건·사용·환불·순수납 귀속 정확도

### 대상

- 합성 프로모션 240건
- 노출·청구·자격·사용 사건 720건
- 등록·결제·환불·차지백 사건 720건
- 개인정보가 없는 합성 데이터만 사용

### 성공 기준

1. 초안·검토 중 혜택의 공개 0건
2. 종료된 혜택의 신규 청구 허용 0건
3. 지점·프로그램·회원 상태 자격 오판 0건
4. 근거 없는 희소성·마감 문구 0건
5. 쿠폰 발급의 실제 사용 오분류 0건
6. 예약의 체험 실참여 오분류 0건
7. 등록·청구서·결제 승인의 실수납 오분류 0건
8. 환불·차지백 미차감 0건
9. 지점·가구·채널·결제 중복 귀속 0건
10. 개인정보 또는 승인 대기 Instagram 콘텐츠의 공개 0건

### 중단 기준

성공 기준 중 하나라도 실패하면 실제 프로모션 공개, 자동 자격 판정, 자동 혜택 지급과 성과 귀속을 중단한다. 오류 원인과 수정 버전을 기록한 뒤 합성 데이터로 다시 검증한다.

## 14. 근거와 적용 한계

- Google Business Profile은 사업 설명이 특가·가격·오퍼 판매에 집중되지 않도록 안내한다. 지역 프로필의 상시 소개와 기간성 프로모션을 분리하는 근거로 사용했다.
- 대한민국 표시·광고 관련 법령은 거짓·과장·기만 등 부당 표시·광고를 금지하는 기본 틀을 제공한다. 실제 문안과 사실관계는 최신 법령 및 전문가 검토가 필요하다.
- 소비자분쟁해결기준은 분쟁 시 합의·권고의 참고 기준이다. 실제 환불은 계약, 이용 상태, 결제수단과 최신 법령을 함께 검토한다.
- 외부 플랫폼의 기능이나 정책이 파이널유도멀티짐 시스템에 연결되었다고 간주하지 않는다.
- 본 문서는 공개 가능한 운영 기준이며, 법률·세무·회계 자문을 대체하지 않는다.
