# 체험·복귀·재등록 오퍼 비용·증분기여 판정 기준 v1

- 문서 상태: 공개 운영 기준 초안
- 작성일: 2026-09-15 (Asia/Seoul)
- 적용 범위: 신규 체험, 체험 후 등록, 휴면 복귀, 만료 전 재등록, 기존회원 유지에 사용하는 가격 할인·무료 제공·쿠폰·사은품·추가 이용권
- 현재 상태: 가격·원가·수용능력·계약·결제·출석 데이터 미연결
- 외부 행동: 가격 변경, 할인·쿠폰·무료 체험 제공, 광고 집행, 고객 메시지, 채널 게시 미실행

## 1. 목적

오퍼를 많이 사용하거나 등록 건수가 늘었다는 사실만으로 마케팅 성공 또는 매출 증가라고 판단하지 않는다.

다음 사건을 분리한다.

`오퍼 설계 → 사실·원가 검증 → 승인 → 공개 → 문의 → 적격 판정 → 사용 요청 → 실제 적용 → 체험 참석 → 계약 시작 → 정산 → 환불·차지백 → 관찰 성숙 → 증분 판정`

이 기준은 네 가지 목표를 함께 보호한다.

1. 신규 체험회원 확보: 무료·유료 체험을 같은 정의로 비교한다.
2. 휴면회원 복귀: 자연 복귀와 오퍼 영향 복귀를 분리한다.
3. 기존회원 재등록·만족: 이미 재등록할 회원에게 불필요한 할인을 지급하는 것을 측정한다.
4. 매출 증대: 표시 가격이나 계약액이 아니라 검증 순수납과 직접비를 연결한다.

## 2. 핵심 원칙

### 2.1 할인은 전략이 아니라 비용이 있는 가설이다

- 가격 할인, 가입비 면제, 무료 수업, 사은품, 추가 기간은 모두 경제적 비용을 가질 수 있다.
- 현금 지출이 없더라도 좌석·코치 시간·물품·결제수수료·기존회원 경험에 영향을 줄 수 있다.
- 비용이 연결되지 않으면 오퍼 ROAS·ROI·기여이익을 계산하지 않는다.
- 할인율이 크다는 이유로 문의·참석·등록이 개선된다고 단정하지 않는다.

### 2.2 무료 체험과 유료 체험 중 하나를 보편적 정답으로 정하지 않는다

- 무료 체험은 문의 문턱을 낮출 수 있지만 실제 참석·등록·순수납은 별도 확인한다.
- 유료 체험은 결제 의사가 있는 사람을 모을 가능성이 있지만 문의량 감소와 환불·결제 마찰을 함께 측정한다.
- 외부 사례의 가격·전환율·참석률을 파이널유도의 목표값으로 복사하지 않는다.
- 지점, 대상, 시간대, 수용능력, 유입원, 체험 구성, 관찰기간이 같을 때만 비교한다.

### 2.3 가치 추가와 가격 인하를 분리한다

- `PRICE_DISCOUNT`: 기존 가격을 직접 낮춤
- `FEE_WAIVER`: 등록비·부대비용 등 검증된 항목을 면제
- `VALUE_ADD`: 가격은 유지하고 승인된 수업·물품·서비스를 추가
- `TRIAL_PAID`: 정해진 체험 구성에 체험비 부과
- `TRIAL_FREE`: 체험비 없이 참여
- `CREDIT`: 기존 잔여가치 또는 승인 금액을 다음 계약에 반영

유형이 다르면 비용 구조와 성공 기준도 다르게 기록한다.

### 2.4 오퍼 노출은 사용이 아니다

- 게시물 조회, 쿠폰 보기, 링크 클릭, 문의, 코드 요청, 실제 적용을 각각 분리한다.
- 오퍼를 언급한 문의를 오퍼 사용으로 계산하지 않는다.
- 직원이 말로 약속했지만 시스템에 적용되지 않은 상태를 사용 완료로 계산하지 않는다.
- 실제 적용됐더라도 계약·정산·출석이 없으면 등록 또는 활성으로 계산하지 않는다.

### 2.5 총등록보다 증분 결과를 본다

- 오퍼를 받지 않아도 등록·복귀·재등록했을 사람에게 제공한 할인은 증분 성과가 아닐 수 있다.
- 자연 유입, 기존 재등록 의향, 다른 채널의 영향과 오퍼 효과를 구분한다.
- 대조군이 없으면 절대 건수와 코호트 결과만 보고하고 인과효과라고 표현하지 않는다.

## 5. 오퍼 유형별 통제

### 5.1 신규 체험 오퍼

- 체험 문의, 예약, 참석, 상담, 계약, 정산을 분리한다.
- 무료 체험은 가격 0원으로 기록하되 비용 0원으로 자동 처리하지 않는다.
- 유료 체험은 결제 완료와 체험 참석을 분리한다.
- 체험비를 최종 등록비에 반영한다면 `CREDIT`로 별도 기록한다.
- 기존회원 수업 품질·좌석을 해치지 않는 범위에서만 모집한다.

### 5.2 체험 후 등록 오퍼

- 체험 참석자가 오퍼를 보기 전에 이미 등록 의사를 표현했는지 기록한다.
- 계약 시작일과 결제 정산일을 분리한다.
- 즉시 결정을 압박하는 미확정 마감·희소성 문구를 사용하지 않는다.
- 오퍼 미사용 등록과 오퍼 사용 등록을 같은 코호트에서 구분한다.

### 5.3 휴면 복귀 오퍼

- 휴면 후보와 검증 휴면을 구분한다.
- 캠페인 이전에 발생한 자연 복귀 예약·출석은 오퍼 성과에서 제외한다.
- 복귀 의사, 예약, 실제 출석, 계약 재시작, 순수납, 재활성을 분리한다.
- 연락 동의·수신거부·연락 중단 상태를 확인한다.

### 5.4 만료예정·재등록 오퍼

- 만료 도래 여부와 재등록 가능 상태를 계약 원천에서 확인한다.
- 이미 재등록한 회원, 자동연장된 회원, 해지 요청 회원을 제외한다.
- 조기 재등록 건수와 최종 만료 시점의 실제 재등록률을 함께 본다.
- 단순히 결제 시점을 앞당긴 결과를 증분 재등록으로 계산하지 않는다.

### 5.5 기존회원 만족 오퍼

- 보상·감사·서비스 회복·충성 혜택의 목적을 구분한다.
- 불만 해결을 공개 리뷰·추천과 교환하지 않는다.
- 참석 횟수나 등급을 근거로 사용할 때 원천과 개인정보 최소화를 확인한다.
- 제공 완료와 만족도 개선을 분리한다.

## 6. 가격·비용 기준

### 6.1 기준 가격

기준 가격은 실제로 적용 가능하고 검증된 정상 가격이어야 한다.

다음은 기준 가격으로 사용하지 않는다.

- 실제 판매 이력이 없거나 곧바로 할인하기 위해 만든 가격
- 다른 지점·프로그램·대상에 적용되는 가격
- 만료된 가격표
- 구두로만 존재하는 가격
- 세금·등록비·필수 비용 포함 여부가 불명확한 가격

### 6.2 오퍼 직접비

연결 가능한 경우 다음을 분리한다.

- 가격 할인액
- 면제한 비용
- 사은품 실제 원가
- 추가 수업의 변동 코치비
- 결제수수료
- 배송·제작·소모품 비용
- 승인된 광고비
- 환불·차지백·폐기 비용

고정 임차료·상근 인건비를 오퍼 한 건에 임의 배분하지 않는다. 회계 기준이 승인되기 전에는 `미연결`로 둔다.

### 6.3 검증 순수납

`정산 완료 수납액 - 완료 환불액 - 확정 차지백액 - 확인된 상계액`

### 6.4 오퍼 직접기여

`검증 순수납액 - 연결된 오퍼 직접비`

이는 회계상 영업이익 또는 순이익이 아니다.

### 6.5 증분기여

`오퍼군의 성숙 코호트 직접기여 - 비교 가능한 비오퍼군의 성숙 코호트 직접기여`

무작위 또는 사전 승인된 비교가 없으면 인과적 증분기여로 보고하지 않는다.

## 7. 중복·남용·형평성 통제

- 한 계약에 적용 가능한 오퍼 수를 승인된 규칙으로 제한한다.
- 오퍼 ID 없이 수기 할인하지 않는다.
- 직원·지점별 임의 가격 변경을 금지한다.
- 대상 조건은 사전에 명시하고 동일 조건에 일관되게 적용한다.
- 신규회원 가격과 기존회원 가격의 차이가 있으면 목적·기간·전환 후 가격을 명확히 한다.
- 가족·형제·소개·복귀 오퍼의 중복 조건을 별도로 정한다.
- 코드 유출이나 중복 사용이 의심되면 임의 처벌하지 않고 사실 검토 상태로 전환한다.
- 데이터 오류나 직원 실수를 회원의 부정 사용으로 추정하지 않는다.

- 승인된 오퍼를 연결할 때도 코치 개인 콘텐츠와 공식 신청·문의 경로의 역할을 구분한다.
- 댓글·저장·프로필 방문을 쿠폰 사용·등록·매출로 계산하지 않는다.
- 승인 대기 게시물에 오퍼를 사후 삽입하지 않는다. 문구나 CTA가 바뀌면 새 버전 승인을 받는다.

## 10. KPI 정의

모든 비율은 분자·분모·기간·지점·오퍼 ID·원천을 함께 표시한다.

### 10.1 문의→예약률

`오퍼 연결 체험예약 수 ÷ 오퍼 관련 유효 문의 수`

### 10.2 예약→실제 참석률

`오퍼 연결 실제 체험 참석 수 ÷ 오퍼 연결 확정 예약 수`

### 10.3 참석→계약 시작률

`오퍼 연결 계약 시작 수 ÷ 오퍼 연결 실제 체험 참석 수`

### 10.4 오퍼 적용→정산률

`PAYMENT_SETTLED_WITH_OFFER 수 ÷ 결제가 필요한 OFFER_APPLIED_VERIFIED 수`

### 10.5 성숙 재등록률

`관찰기간 안에 재등록 효력이 확인된 수 ÷ 재등록 판정기간이 성숙한 적격 회원 수`

### 10.6 성숙 복귀 재활성률

`승인된 기간 안에 계약과 실제 출석이 확인된 복귀 수 ÷ 관찰기간이 성숙한 오퍼 적용 복귀 수`

### 10.7 오퍼 직접기여

정산·차감·직접비가 모두 연결될 때만 계산한다.

### 10.8 증분기여

비교 가능한 대조 조건과 성숙 코호트가 있을 때만 계산한다. 현재 상태는 `데이터 미연결`이다.

## 11. 실험 설계

### 비교 단위

- 동일 지점·프로그램·대상
- 동일하거나 비교 가능한 유입 채널
- 동일 시간대와 관찰기간
- 유사한 수용능력
- 동일한 퍼널 정의

### 최소 비교 후보

1. 무료 체험 대 유료 체험
2. 가격 할인 대 가치 추가
3. 오퍼 제공 대 비오퍼
4. 조기 재등록 오퍼 대 일반 재등록 안내

동시에 여러 조건을 바꾸지 않는다. 가격, 기간, 구성, CTA, 채널을 한꺼번에 바꾸면 원인을 판별할 수 없다.

## 12. EXP-320 — 오퍼 비용·증분기여 완전성

- 대상: 대표 승인 후 동일 목적의 최초 2개 오퍼 또는 성숙 코호트 각 20건
- 목적: 높은 등록 건수가 아니라 측정 가능한 순수납·직접기여 기준 구축
- 성공 기준:
  - 오퍼 ID·버전·가격·기간·대상 기록률 100%
  - 적용 사건과 예약·참석·계약·정산 연결률 100%
  - 할인·면제·사은품·광고의 직접비 연결률 100%
  - 미성숙 코호트의 최종 성공·실패 판정 0건
  - 자연 복귀·기존 재등록의 오귀속 0건
  - 승인 없는 할인·쿠폰·무료 제공 0건
  - 공개 조건과 실제 적용 조건 불일치 0건
- 보류 기준:
  - 기준 가격·원가·수용능력·계약·결제 원천 미연결
  - 관찰기간 또는 대조 조건 미승인
  - 표본 미성숙
- 중단 기준:
  - 미확정 가격·마감·희소성 공개
  - 기존회원 수업 품질 또는 안전 정원 훼손
  - 환불·차지백 제외한 매출 보고
  - 개인정보 또는 개인별 가격을 공개 저장소에 기록
- 현재 기준선: 데이터 미연결

## 13. 역할별 운영

### CMO

- 오퍼 수보다 네 사업 목표 중 어떤 병목을 해결하는지 우선한다.
- 신규 확보를 위해 기존회원 만족·좌석·가격 신뢰를 훼손하지 않는다.

### Growth Analyst

- 오퍼 노출부터 순수납까지 사건을 연결한다.
- 절대 건수, 성숙 전환, 증분 효과를 구분한다.

### Acquisition Marketer

- 무료·유료 체험을 외부 벤치마크가 아니라 내부 동일 조건으로 비교한다.
- CTA와 신청 경로를 하나로 유지한다.

### CRM Marketer

- 휴면·체험후미등록·만료예정·기존회원의 대상 조건을 섞지 않는다.
- 동의·수신거부·연락 종료를 확인하고 승인 전 발송하지 않는다.

### Content Strategist

- 네이버·당근·Google에는 검증된 공식 조건만 사용한다.
- 코치 개인 Instagram에서 미확정 오퍼를 공식 공지로 발표하지 않는다.

### Experiment Manager

- 한 번에 한 핵심 변수를 바꾸고 사전 성공·중단 기준을 잠근다.
- 등록률만이 아니라 참석·정산·환불·직접기여를 함께 본다.

### Auditor

- 기준 가격, 오퍼 적용, 수납, 직접비, 환불·차지백을 대조한다.
- 외부 사례의 숫자를 내부 목표로 복사하거나 작은 표본으로 승패를 선언하지 않는다.

## 14. 대표 승인·입력

- 직접기여에 포함할 비용 범위
- 오퍼별 관찰기간과 대조군 허용 여부
- 공개 채널·문구·게시 권한
